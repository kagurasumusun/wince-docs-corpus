This message retrieves the bounding rectangle of a part in a status window. 

SB_GETRECT wParam = (WPARAM) iPart; 
lParam = (LPARAM)(LPRECT) lprc;

Parameters

iPart
Zero-based index of the part whose bounding rectangle is to be retrieved.
lprc
Long pointer to a RECT structure that receives the bounding rectangle.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
