This macro searches for a list view item with the specified characteristics. You can use this macro or send the LVM_FINDITEM message explicitly. 

int ListView_FindItem( 
HWND hwnd, 
int iStart, 
const LV_FINDINFO FAR* plvfi );

Parameters

hwnd
Handle to the list view control.
iStart
Index of the item after which to begin the search, or –1 to start from the beginning.
plvfi
Pointer to an LVFINDINFO structure that contains information about what to search for.

Return Values

The index of the item indicates success. –1 indicates failure.

Remarks

Related message: LVM_FINDITEM

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
