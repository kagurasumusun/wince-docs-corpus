This macro conditionally outputs a debugging message.

DEBUGMSG (Expression, Message)

Return Values

None.

Remarks

This macro is a wrapper around NKDbgPrintfW that uses a subset of printf formatting characters to format debugging message output. This macro may be used to conditionally output a debugging message formatted in printf style. The printf-style message parameter is output if the Boolean input expression evaluates to TRUE. Note that the parameter Message must be enclosed by parentheses to prevent syntax errors being generated by the preprocessor.

A format specification consists of optional and required fields. The following example shows the form of a printf format specification.

%[flags] [width] [precision] [{h|1|I64}]type

Each field of the format specification is a single character or a number signifying a particular format option. The simplest format specification contains only the percent sign and a type character, for example, %s. If a percent sign is followed by a character that has no meaning as a format field, the character is copied to stdout. For example, to print a percent-sign character, use %%.

The optional fields, which appear before the type character, control other aspects of the formatting.

flags
Optional character or characters that control justification of output and printing of signs, blanks, decimal points, and octal and hexadecimal prefixes. More than one flag can appear in a format specification.

The following table shows the valid flags.

Flag Description Default
- Left-align the result within the given field width. Right-align.
0 If width is prefixed with 0, zeros are added until the minimum width is reached. If 0 and - appear, the 0 is ignored. If 0 is specified with an integer format (i, u, x, X, o, d), the 0 is ignored. No padding.
# When used with the o, x, or X format, the # flag prefixes any nonzero output value with 0, 0x, or 0X, respectively. No blank appears.
width
Optional nonnegative decimal integer that specifies the minimum number of characters printed. IF the number of characters in the output value is less than the specified width, blanks are added to the left or right of the values, depending on whether the - flag for left-alignment is specified, until the minimum width is reached. If width is prefixed with 0, zeros are added until the minimum width is reached; however, this is not useful for left-aligned numbers.

The width specification never causes a value to be truncated. If the number of characters in the output value is greater than the specified width, or if width is not given, all characters are printed, subject to the values provided for precision.

precision
Optional nonnegative decimal integer preceded by a period (.). This number specifies the maximum number of characters printed, the number of decimal places, or the number of significant digits. Unlike the width specification, the precision specification can cause either truncation of the output value or rounding of a floating-point value. If precision is specified as 0 and the value to be converted is 0, the result is no characters printed. The following example shows this situation. 
printf( "%.0d", 0);   /* No characters output */

If the precision specification is an asterisk (*), an int argument from the argument list supplies the value. In the argument list, the precision argument must precede the value being formatted.

The following table shows how the type determines the interpretation of precision and provides default values for when precision is omitted.

Type Description Default
c The precision has no effect. Character is printed.
d, i, u, o, x, X The precision specifies the minimum number of digits to be printed. If the number of digits in the argument is less than precision, the output value is padded on the left with zeros. The value is not truncated when the number of digits exceeds precision. Default precision is 1.
s The precision specifies the maximum number of characters to be printed. Characters in excess of precision are not printed. Characters are printed until a null character is encountered.
[{h|l|I64}]
Optional prefixes to type that specify the size of the argument. The size can be long or short, single-byte character or wide character, depending upon the type specifier that is modified. These prefixes are Microsoft extensions and are not ANSI-compatible.

The following table shows how to combine the prefixes with type specifiers in wprintf functions to specify the interpretation of arguments.

To specify this format Prefix to use Associated type specifier
long int l d, i, o, x, or X
long unsigned int l u
short int h d, i, o, x, or X
short unsigned int h u
__int64 I64 d, i, o, u, x, or X
Single-byte character with wprintf functions h c
Wide character with wprintf functions l c

Wide-character string with wprintf functions l s

The following table shows how to combine format specifiers with the wprintf function to print characters.

To print character in this format Function to use Associated format specifier
Single-byte wprintf hc
Wide wprintf c, lc
type
Required character that determines whether the associated argument is interpreted as a character, a string, or a number. The type character is the only required format field. It appears after any optional format fields are specified.

The following table shows printf type field characters.

Character Type Output format
c WCHAR Wide character.
d int Signed decimal integer.
i int Signed decimal integer.
o int Unsigned decimal integer.
u int Unsigned decimal integer.
p Pointer to void Unsigned hexadecimal integer, using "ABCDEF."
x int Unsigned hexadecimal integer, using "abcdef."
X int Unsigned hexadecimal integer, using "ABCDEF."
a String Specifies a single-byte character string. Characters are printed up to the first null character or until the precision value is reached.
s String Specifies a wide-character string. Characters are printed up to the first null character or until the precision value is reached.
