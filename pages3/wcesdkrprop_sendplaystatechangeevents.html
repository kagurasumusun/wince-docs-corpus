Sets or retrieves a value specifying whether the Microsoft Windows Media Player control sends play state change events.

Compatibility: Windows Media Player

MediaPlayer.SendPlayStateChangeEvents [ = bSendPlayState ]

Parameters

bSendPlayState
Boolean value specifying whether play state change events are enabled. If true, the Windows Media Player control sends play state change events. This property is read/write with a default value of true.
