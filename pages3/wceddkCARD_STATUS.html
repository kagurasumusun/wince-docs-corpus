This structure is used by the CardGetStatus function to return data.

typedef struct { 
CARD_SOCKET_HANDLE hSocket; 
UINT16 fCardState; 
UINT16 fSocketState; 
} CARD_STATUS, *PCARD_STATUS;

Members

hSocket
Handle to a socket and function pair.
fCardState
[OUT] Specifies a bitmask indicating current card state.
fSocketState
[OUT] Specifies a bitmask indicating card state changes.
