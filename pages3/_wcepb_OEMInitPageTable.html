This function initializes the entries in the x86 page directory. The page directory is 4KB in size, and contains 1024 four-byte entries. Each entry is a pointer to a page table or a 4MB page.

void OEMInitPageTable (void);

Return Values

None.

Remarks

On entry, the EBX register points to the start of the page directory in RAM. To implement this function, the OEM must initialize the entries in the page directory for all hardware resources that are mapped into the statically-mapped virtual address space between 0x80000000 and 0xBFFFFFFF. RAM and ROM are examples of these. Map the region between 0x80000000 and 0x9FFFFFFF with caching enabled; map the region between 0xA0000000 and 0xBFFFFFFF with caching disabled.

This function is required only on systems that use an x86 microprocessor.
