Receiving Messages from a Queue

Important:

To receive messages from a queue the receiving application:

  1. Opens a queue by name.
  2. Retrieves a message (or peeks at a message).
  3. Sends any required response messages.

Call MQReceiveMessage to read a message in a queue. As with the desktop implementation, an application can either peek at messages without removing them from the queue, or retrieve the messages, which removes them from the queue. Messages can be read synchronously or asynchronously. Windows CE does not support reading from a remote queue.
