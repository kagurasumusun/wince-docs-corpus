Extensible Markup Language

Extensible Markup Language (XML) is a meta-markup language that provides a format for describing structured data, and allows developers to easily describe and deliver rich, structured data from any application in a standard, consistent way. XML facilitates more precise declarations of content and provides more meaningful search results across multiple platforms. In addition, XML enables a new generation of Web-based applications for viewing and manipulating data.

In XML, you can define an unlimited set of tags. While you can use Hypertext Markup Language (HTML) tags to display a word in bold or italic, you use XML to provide a framework for tagging structured data. An XML tag can indicate that the data that is associated with the tag is a retail price, a sales tax, a book title, an amount of precipitation, or any other desired data. As an organization adopts XML tags throughout the intranet for the organization, and as others across the Internet also adopt these tags, the ability to search for and manipulate data regardless of the applications within which the data resides increases. Once an application locates XML data, the application can deliver the data over the network and present the data in a Web browser such as the Microsoft Internet Explorer web browser in any number of ways, or the application can hand off the data to other applications for further processing and viewing.

This document describes the differences between using XML on a Windows CE-based platform and on a Windows-based desktop computer. For general information about XML, see the MSDN Web site.
