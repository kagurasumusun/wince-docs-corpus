Providing User Feedback

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

In addition to receiving user input, a UI provides feedback by displaying messages. A message is a communication to the user that is displayed on the screen. Messages inform the user of system status or prompt the user to complete some action. Effective messages are clear and concise.

When you include an identification number in message text, place the number at the end of the message text, and not in the title bar or at the beginning of the text where it might decrease the user's ability to quickly read the message.
