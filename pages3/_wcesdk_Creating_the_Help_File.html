To create Help for a Windows CE platform, first create the appropriate files. Use an HTML editor, such as NotePad or Microsoft FrontPage, a web site creationto do so. For Windows CE 2.0 and previous, use the .htp extension when naming your help files. For Windows CE 2.01 and later, use the .htm extension.

Note   Other than the file extension, .htp and .htm files are identical.
