Differences Between Microsoft XML 2.0 and Microsoft XML 2.5

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

Windows CE does not support the following features, which were introduced in the Microsoft XML 2.5 parser:

  • Support of simple data types on attributes
  • Addition of a data type of "id" for elements
  • Assignment of data types through element names

These features are discussed in detail at this Microsoft Web site.

Note   Windows CE does support the instantiation of Component Object Model (COM) objects within blocks of XSL script, even though this feature was not available for Windows-based desktop computers before Microsoft XML 2.5.
