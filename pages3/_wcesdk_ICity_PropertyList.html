Return Values

Each property method supports the standard HRESULT return values, including S_OK.

Remarks

Most of the cities used by the World Clock are provided in ROM and cannot be deleted. If you attempt to delete a city that is stored in ROM, you get the error code E_CITYINROM. You can set the values for any city's property that supports the put_ method. However, the changes are stored in RAM. If the user cold-boots the device, property values revert to the initial values stored in ROM and any user-created cities are lost.

If you are running a version of Pocket Outlook earlier than 1.1 and you try to save changes to properties of a city stored in ROM, the Save method returns E_CITYINROM.
