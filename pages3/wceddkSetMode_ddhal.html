SetMode

The SetMode function is used to change the current display mode, and conditionally update the current GDI surface. You are required to implement the GPE version of this function. You should also override DDGPE's version of the function to allow it to operate properly.

The DDGPE::SetMode function is similar to the GPE::SetMode function. The difference between the two versions of the function is the addition of the bChangeGDISurfaceMode parameter for DDGPE. If this parameter is TRUE, the behavior of SetMode should be identical to that expected of the GPE version. If the parameter is FALSE, however, the SetMode function should simply change the physical mode. In both cases, the m_dwPhysicalModeID DDGPE member variable should be updated.

virtual SCODE SetMode (
int modeNo,
HPALETTE *pPalette,
BOOL bChangeGDISurfaceMode );

Parameters

modeNo
The requested mode number.
pPalette
The palette for the requested mode, if applicable. If the palette does not apply or if the default palette should be used, this parameter should be NULL.
bChangeGDISurfaceMode
Indicates whether the GDI surface mode should be changed as a result of the SetMode. If this parameter is TRUE, the current GDI mode is modified, and the GDI surface is reallocated, if necessary. Otherwise, this function simply sets the hardware's mode and updates the physical mode settings.

Return Values

None
