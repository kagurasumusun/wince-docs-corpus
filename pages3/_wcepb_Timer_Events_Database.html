Timer Events Database

The DB_notify_queue database stores timer events sorted by notification start time. Every record in this database has two fields: notification start time and a binary large object (BLOB) that records an event's notification parameters, such as which application to launch or which dialog box to display. A thread monitors the database for the earliest nonactive timer event. This thread also verifies that notification packets are created for all expired events. The following table shows the fields in the DB_notify_queue database:

Field name Description
PROPIDR_TIME PROP_TAG(CEVT_FILETIME, 1)
PROPIDR_PACKET PROP_TAG(CEVT_BLOB, 2)

The PROPIDR_TIME field stores the notification activation time and the PROPIDR_PACKET field stores the notification packet, which defines the notification type.
