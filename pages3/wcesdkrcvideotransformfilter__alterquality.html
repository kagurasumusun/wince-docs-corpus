Receives a quality-control notification and provides an opportunity to alter the quality of the media stream. 

virtual HRESULT AlterQuality(
Quality q );

Parameters

q
Quality-control notification message.

Return Values

This member function returns E_FAIL by default.

Remarks

This member function overrides the CTransformFilter::AlterQuality member function. It is called by the CTransformOutputPin::Notify member function before calling the CBaseInputPin::PassNotify member function to pass the quality control message upstream. This function sets the m_itrLate data member to the value Quality structure's Late member so that the filter can determine whether to skip frames. It returns E_FAIL so that the renderer downstream will continue to handle quality control.
