This function converts system time to file time format.

BOOL KSystemTimeToFileTime ( 
LPSYSTEMTIME lpst, 
LPFILETIME lpft );

Parameters

lpst
Pointer to the system time that is to be converted.
lpft
Pointer to the FILETIME structure in which the converted value is returned.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

This kernel function, a version of the function SystemTimeToFileTime, is made available to the OAL and can be called by device drivers. For reference documentation for the SYSTEMTIME and FILETIME structures, see the Windows CE SDK.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Nkintr.h
