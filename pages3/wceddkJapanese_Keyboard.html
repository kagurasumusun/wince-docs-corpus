The BREAK key is sent as the sequence E1, left CTRL, NUMLOCK. The keyboard driver must convert the E1+left CTRL sequence to the BREAK key and ignore the NUMLOCK.

The next part of the Japanese keyboard is the virtual key to character mapping. This mapping is dependent upon the state of other modifier keys. Some characters are shown as symbol names, which are described after these tables. The processing of virtual keys should be performed in the order in which the following tables are laid out.
