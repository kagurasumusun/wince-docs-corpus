This function sets the specified number of pages for the object store. 

DWORD SetSystemMemoryDivision ( 
DWORD dwStorePages );

Parameters

dwStorePages
Specifies the number of pages to allocate for the store.

Return Values

The function returns SYSMEM_CHANGED if it is executed successfully. The function returns SYSMEM_FAILED if the dwStorePages parameter is out of range. If SYSMEM_FAILED is returned, you can get further information by calling GetLastError.

Remarks

You cannot shrink system memory or the object store memory to be less that 256 KB each, including space for existing files and records.

If a reboot is necessary for the change to take effect, the function returns SYSMEM_MUSTREBOOT. If a previous call returned SYSMEM_MUSTREBOOT, the function returns SYSMEM_REBOOTPENDING. In this situation, the boundary cannot be adjusted further until the reboot occurs.
