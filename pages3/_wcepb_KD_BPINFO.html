This structure contains breakpoint information used by OEMKDIoControl. 

typedef struct _KD_BPINFO {
int nVersion; 
ULONG ulFlags; 
ULONG ulAddress; 
ULONG ulHandle; 
ULONG ulCount;
} KD_BPINFO, *PKD_BPINFO;

Members

nVersion
The version number of the request. This is set to 1 for Windows CE 3.0.
ulFlags
Identifies the properties of the I/O request. The KDFLAG_INUSE flag indicates that the breakpoint is currently set.
ulAddress
The hardware address to use for the breakpoint.
ulHandle
The handle value that is associated with a breakpoint.
ulCount
The number of breakpoints or position in a list of breakpoints.

Requirements
