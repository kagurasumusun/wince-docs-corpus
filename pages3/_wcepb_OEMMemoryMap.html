OEMMemoryMap

This global variable array provides the virtual-to-physical mapping that is required by a PPC kernel. Prior to calling KernelStart from the OAL, OEMMemoryMap must be initialized. After initialization, the physical address of OEMMemoryMap is stored in r3. 

globl OEMMemoryMap

Remarks (PPC403 kernel)

The OEMMemoryMap array defines the mapping from the 4-GB physical address space to the kernel's 512-MB unmapped space. The kernel creates two ranges of virtual addresses from this array: One range, from 0x80000000 to 0x9FFFFFFF, has caching and buffering enabled. The other range, from 0xA0000000 to 0xBFFFFFFF, has caching and buffering disabled.

Each entry in the table consists of the virtual base address to map to, the physical base address to map from, and the number of megabytes to map. The size must be a multiple of 16 MB.

The following is the virtual memory map for the PPC403 on an ODO:

0x80000000 - 0x83FFFFFF: 64MB for RAM (0x00-0x3F)
0x84000000 - 0x87FFFFFF: 64MB for Housekeeping FPGA (0x40-0x4F)
0x8C000000 - 0x8FFFFFFF: unused
0x90000000 - 0x93FFFFFF: 64MB for System ASIC, FPGA, etc. (0x40-0x4F)
0x94000000 - 0x94FFFFFF: 16MB PCMCIA 16 bit attr memory window
0x95000000 - 0x95FFFFFF: 16MB PCMCIA 16 bit common memory window
0x96000000 - 0x96FFFFFF: 16MB PCMCIA 16 bit I/O window
0x97000000 - 0x97FFFFFF: 16MB PCMCIA UNUSED
0x98000000 - 0x98FFFFFF: 16MB PCMCIA 8 bit attr memory window
0x99000000 - 0x99FFFFFF: 16MB PCMCIA 8 bit common memory window
0x9A000000 - 0x9AFFFFFF: 16MB PCMCIA 8 bit I/O window
0x9B000000 - 0x9BFFFFFF: 16MB PCMCIA PCMCIA status regs (8 bit)
0x9C000000 - 0x9DFFFFFF: unused
0x9E000000 - 0x9FFFFFFF  32MB for flash memory
OEMMemoryMap:
// -------------------------------------------------------------
//    Virtual Addr  Physical Addr   MB
// -------------------------------------------------------------
.long 0x80000000,   0x00000000,     64  // RAM
.long 0x84000000,   0x78000000,     64  // HouseKeeping
.long 0x90000000,   0x7c000000,     32  // System Asic
.long 0x94000000,   0x70000000,     16 // PCMCIA 16 bit attr
.long 0x95000000,   0x71000000,     16 // PCMCIA 16 bit comm
.long 0x96000000,   0x74000000,     16 // PCMCIA 16 bit IO
.long 0x98000000,   0x72000000,     16 // PCMCIA 8 bit attr
.long 0x99000000,   0x73000000,     16 // PCMCIA 8 bit comm
.long 0x9b000000,   0x77000000,     16 // PCMCIA status
.long 0x9e000000,   0x7e000000,     32 // FLASH
.long 0x00000000,   0x00000000,     0  // Must be zero

For an example, see Fw403.s in the %_WINCEROOT%\Platform\Odo\Kernel\Hal\Ppc directory.

Remarks (PPC821 kernel)

OEMMemoryMap defines the mapping from the 4-GB physical address space to the kernel's 512-MB unmapped spaces The kernel creates two ranges of virtual addresses from this table: One range, from 0x80000000 to 0x9FFFFFFF, has caching and buffering enabled. The other range, from 0xA0000000 to 0xBFFFFFFF, has caching and buffering disabled.

Each entry in the table consists of the virtual base address to map to, the physical base address to map from, and the number of megabytes to map. The size must be a multiple of 16 MB.

The first 16-MB frame (0x00000000–0x00ffffff) must be mapped to the first kernel virtual frame (0x80000000–0x80ffffff). For an example, see Fw821.s in the %_WINCEROOT%\Platform\Odo\Kernel\Hal\Ppc directory.

The following is the virtual memory map for the PPC821 on an ODO:

OEMMemoryMap:
// -------------------------------------------------------------
//    Virtual Addr  Physical Addr   MB
// -------------------------------------------------------------
.long 0x80000000,   0x00000000,     256  // PPC 821 ODO maps 80000000h directly to 0 for 512MB.
.long 0x90000000,   0x10000000,     256
.long 0         ,   0         ,     0    // Table terminator

For an example, see Fw821.s in the %_WINCEROOT%\Platform\Odo\Kernel\Hal\Ppc directory.
