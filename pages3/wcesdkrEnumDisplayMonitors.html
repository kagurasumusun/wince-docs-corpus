EnumDisplayMonitors

This function enumerates the display monitors that intersect a region formed by the intersection of a specified clipping rectangle and the visible region of a specified device context, including invisible pseudomonitors associated with the mirroring drivers.

BOOL EnumDisplayMonitors(
HDC hdc,
LPCRECT lprcClip,
MONITORENUMPROC lpfnEnum,
LPARAM dwData
);

Parameters

hdc
[in] Handle to a display device context that specifies the visible region of interest. When this parameter is NULL, the hdcMonitor parameter that EnumDisplayMonitors passes to the MonitorEnumProc callback function is NULL, and the visible region of interest is the virtual screen that encompasses all of the displays on the desktop.
lprcClip
[in] Pointer to a RECT structure that specifies a clipping rectangle. The region of interest is the intersection of the clipping rectangle with the visible region specified by hdc. If hdc is not NULL, specify the coordinates of the clipping rectangle relative to the origin of the hdc. If hdc is NULL, specify virtual screen coordinates. Set lprcClip equal to NULL if you do not want to clip the region specified by hdc.
lpfnEnum
[in] Pointer to an application-defined MonitorEnumProc callback function that you want EnumDisplayMonitors to call for each monitor that EnumDisplayMonitors enumerates. This parameter cannot be NULL.
dwData
[in] DWORD that specifies application-defined data that you want EnumDisplayMonitors to pass directly to MonitorEnumProc.

Return Values

TRUE indicates success. FALSE indicates failure, or that lpfnEnum is NULL. To get extended error information, call GetLastError. When lpfnEnum is NULL, GetLastError returns ERROR_INVALID_PARAMETER.

Remarks

You should call the EnumDisplayMonitors function if you want to:

  • Draw optimally into a device context that spans several display monitors.
  • Obtain a handle and position rectangle for one or more display monitors.

EnumDisplayMonitors calls an application-defined MonitorEnumProc callback function once for each monitor that EnumDisplayMonitors enumerates.

In contrast to calling EnumDisplayMonitors, calling the GetSystemMetrics function with the SM_CMONITORS flag counts only the display monitors, and not the invisible pseudomonitors associated with the mirroring drivers.

By setting the hdc parameter to NULL, you can use EnumDisplayMonitors to obtain a handle and position rectangle for one or more display monitors. The following table shows how the four combinations of NULL and non-NULL hdc and lprcClip values affect the behavior of EnumDisplayMonitors.

Value of hdc Value of lprcRect Behavior of EnumDisplayMonitors
NULL NULL Enumerates all display monitors, and passes a NULL hdc to the callback function.
NULL non-NULL Enumerates all display monitors that intersect the clipping rectangle, and passes a NULL hdc to the callback function. Use virtual screen coordinates for the clipping rectangle.
non-NULL NULL Enumerates all display monitors that intersect the visible region of the device context, and passes an hdc for each specific display monitor to the callback function.
non-NULL non-NULL Enumerates all display monitors that intersect the visible region of the device context and the clipping rectangle, and passes an hdc for each specific display monitor to the callback function. Use device context coordinates for the clipping rectangle.

The following code example shows how to paint in response to a WM_PAINT message, using the capabilities of each monitor.

case WM_PAINT:
  hdc = BeginPaint(hwnd, &ps);
  EnumDisplayMonitors(hdc, NULL, MyPaintEnumProc, 0);
  EndPaint(hwnd, &ps);

The following code example shows how to paint the top half of a window using the capabilities of each monitor.

GetClientRect(hwnd, &rc);
rc.bottom = (rc.bottom - rc.top) / 2;
hdc = GetDC(hwnd);
EnumDisplayMonitors(hdc, &rc, MyPaintEnumProc, 0);
ReleaseDC(hwnd, hdc);

The following code example shows how to paint the entire virtual screen optimally for each display monitor.

hdc = GetDC(NULL);
EnumDisplayMonitors(hdc, NULL, MyPaintScreenEnumProc, 0);
ReleaseDC(NULL, hdc);

The following code example shows how to get information about all of the display monitors.

EnumDisplayMonitors(NULL, NULL, MyInfoEnumProc, 0);
