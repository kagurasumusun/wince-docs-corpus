Preparing your Display Driver

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

This section describes the steps you could take to create a non-GPE display driver that is prepared for DirectDraw support.

First, you should consult the DDI for Windows CE Programmer's Guide. You should create a working display driver using the methods described in that document.

You should then test the driver and ensure that it works properly. You may also wish to use this opportunity to add acceleration to certain operations in your display driver.

Once you have your basic Windows CE display driver written and tested, you should continue to the next section.
