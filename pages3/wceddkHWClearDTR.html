This function clears the Data Terminal Ready (DTR) signal.

VOID HWClearDTR(
PVOID pContext );

Parameters

pContext
Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.

Return Values

None.

Remarks

This function supports the implementation of the PDDs of serial port drivers.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Serhw.h
