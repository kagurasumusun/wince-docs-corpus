IContact::Save

This method is not supported in Windows CE Platform Builder 3.0.

This method saves a Contact item.

HRESULT Save();

Return Values

S_OK indicates that the Contact item was saved successfully. If the Contact cannot be saved, the appropriate HRESULT value is returned.

Remarks

In order to save a contact, you must specify at least one of the following four properties: FirstName, LastName, CompanyName, and FileAs.

Code Example [Visual Basic]

The following Visual Basic code snippet creates and saves a new contact:

Sub SaveContact(polApp As PocketOutlook.Application)
Dim polContact As PocketOutlook.ContactItem
Set polContact = polApp.GetDefaultFolder(olFolderContacts).Items.Add
pContact.FirstName = "Brian"
pContact.LastName = "Fleming"
pContact.Company = "Microsoft"
pContact.FileAs = "Fleming"
pContact.Save;
End Sub

Code Example [C++]

The following C++ code snippet creates and saves a new contact:

void SaveContact(IPOutlookApp *polApp)
{
IContact *pContact;
IFolder *pFolder;
IPOutlookItemCollection *pItems;

// Create a new contact
polApp->GetDefaultFolder(olFolderContacts, &pFolder);
pFolder->get_Items(&pItems)
pItems->Add(&pContact)
pContact->put_FirstName(TEXT("Brian"));
pContact->put_LastName(TEXT("Fleming"));
pContact->put_Company(TEXT("Microsoft"));
pContact->put_FileAs(TEXT("Fleming"));

// Save the new contact
pContact->Save();

// Release objects
pContact->Release();
pFolder->Release();
pItems->Release();
}
