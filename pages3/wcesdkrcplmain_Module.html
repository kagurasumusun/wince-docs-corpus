cplmain Module

The cplmain module is the main control-panel application module. It supports a set of components, each of which provides a specific control-panel functionality. Examples of control-panel applications are the backlight application and the date and time application.

The cplmain module exposes no public functions.

Components

The cplmain module includes the following components.

Components Description Notes
BACKLIGHT Backlight control-panel application component of the cplmain module. Exposes no public functions.
COLORSCHEME Color schemes control-panel application component of the cplmain module. Exposes no public functions.
COMM Common control-panel application component of the cplmain module. Exposes no public functions.
DATETIME Date and time control-panel application component of the cplmain module. Exposes no public functions.
DIALING Dialing control-panel application component of the cplmain module. Exposes no public functions.
DISPLAY Display control-panel application component of the cplmain module. Exposes no public functions.
KEYBOARD Keyboard control-panel application component of the cplmain module. Exposes no public functions.
MOUSE Mouse control-panel applet component of the cplmain module. Exposes no public functions.
NETWORK Network control-panel applet component of the cplmain module. Exposes no public functions.
OWNER Owner control-panel applet component of the cplmain module. Exposes no public functions.
PASSWORD Password control-panel applet component of the cplmain module. Exposes no public functions.
POINTERCMN Control-panel applet component of the cplmain module that provides routines that are common to both the mouse and the stylus. Exposes no public functions.
POWER Power control-panel applet component of the cplmain module. Exposes no public functions.
SIP Soft input-panel control-panel applet component of the cplmain module. Exposes no public functions.
SOUNDS Sounds control-panel applet component of the cplmain module. Exposes no public functions.
STYLUS Stylus control-panel applet component of the cplmain module. Exposes no public functions.
SYSTEM System control-panel applet component of the cplmain module. Exposes no public functions.
