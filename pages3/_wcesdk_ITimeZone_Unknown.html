This interface is not supported in Windows CE Platform Builder 3.0.

The ITimeZone interface is a read-only object to check whether a time zone supports Daylight Saving Time and find when it converts between Standard and Daylight Saving Time. You can call the IPOutlookApp::GetTimeZoneFromIndex method to get a time zone object.

A time zone object enables you to retrieve values for the following read only properties. Note that if a time zone does not support daylight saving time (SupportsDST is FALSE), all subsequent values in the table are undefined.
