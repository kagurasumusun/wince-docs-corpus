Loading the Dictionaries

After the SplInit function creates the spelling-checker handle, it loads the four required dictionaries and any other optional dictionaries:

  • First, the SplInit function loads the read-only main dictionary. Microsoft defines the main dictionary for each localized version of Windows CE. Currently, Windows CE does not support replacement of the main dictionary with a dictionary that is supplied by an application. However, Windows CE can specify additional dictionaries to load while it initializes the spelling checker.
  • Then, in addition to loading the main dictionary, the SplInit function creates three internal user dictionaries for each spelling session. When SplInit creates these dictionaries, they are empty. During a spelling session, you can add to and modify these dictionaries. However, Windows CE does not save these dictionaries specifically when you exit a spelling session.

You can instruct the SplInit function to load external user dictionaries at the beginning of a spelling session. An external user dictionary is a dictionary that is defined by an application, a user, or another third party. A common use of an external user dictionary is to store unique words that are not found in the main dictionary, but that are used commonly by an individual user. You can save the external dictionary at the end of a spelling session and load it again at the beginning of the next spelling session.

Use the ppwz parameter of the SplInit function to point to a list of external user dictionaries. Each element on the list includes the dictionary path and file name. SplInit assigns identifiers to the internal user dictionaries and to any external user dictionaries that are pointed to by ppwz.

The following table describes the values that you can provide in the ppwz parameter.

Dictionary name nID value Description
SPL_IGNORE_LEX –3 Contains words that the spelling checker finds, but that the user does not want to change. The spelling checker ignores the words in this list for the remainder of the spelling session.
SPL_CHANGE_ALWAYS_LEX –2 Contains words that the spelling checker finds and that are paired with words with which the spelling checker replaces subsequent occurrences of the word. For example, "thru" is paired with "through".
SPL_CHANGE_ONCE –1 Contains words that the spelling checker finds and that the user changes. The spelling checker continues to find subsequent occurrences of these words.
External user dictionary 1 0 The first external user dictionary that is described in the ppwz parameter.
External user dictionary 2 1 The second external user dictionary that is described in the ppwz parameter.
External user dictionary clex clex–1 The last external user dictionary that is described in the ppwz parameter.

You can use the nID value to direct the spelling-checker API to a specific dictionary. The clex value represents the total number of external dictionaries that you provide in the ppwz parameter.
