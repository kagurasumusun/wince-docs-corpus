The following example illustrates how to load the Hapi.exe script interpreter and how to set the general test-parameters that tell Hapi.exe to start running the NDISTest client-side base script. Hapi.exe automatically reads the Hapi.ini at startup time.

The following table shows the test cases.

Test case Description
LAN Tests the LAN miniport driver

The following table shows the general test-case parameters.

Option Description
Hapi -r\NDISTest\scripts\nd_cli.tst Loads the Nd_cli.tst script under the NDISTest directory

The following code sample shows the contents of a sample Hapi.ini file.

[DLLs]
ndistst.dll

[Variables]

G_TestOptions=0x00001
G_WorkCard="ne20001"
G_TrustedCard=" xircomce21"
G_MessageCard="irsir1"
G_Ndis30Flag=0
G_ScriptName="" 

To run functional tests and log verbose output:
G_TestOptions=0x10001

To test the first NE2000-compatible card in the system:
G_WorkCard="ne20001"

To use a Xircom CE2 card as the trusted card to assist in testing an NE2000 card:
G_TrustedCard="xircomce21"

To test an NE2000-compatible card and use it also for commands:
G_WorkCard="ne20001"
G_MessageCard="ne20001"

Assume that all script files reside on Windows CE under "\NDISTest". The following is a command line for a sample LAN miniport test:

Hapi  -r\NDISTest\   scripts\nd_cli.tst
