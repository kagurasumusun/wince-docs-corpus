This function retrieves the handle to the window that currently has the clipboard open. 

HWND GetOpenClipboardWindow(void);

Return Values

The handle of the window that has the clipboard open indicates success. NULL indicates that no window has the clipboard open. To get extended error information, call GetLastError.

Remarks

If an application or dynamic-link library (DLL) specifies a NULL window handle when calling the OpenClipboard function, the clipboard is opened but is not associated with a window. In such a case, GetOpenClipboardWindow returns NULL.
