This function is the OHCD power-off handler.

void OhcdPdd_PowerDown(
DWORD dwDeviceContext );

Parameters

dwDeviceContext
[IN] Specifies a pointer to the device context returned from the OhcdPdd_Init function.

Remarks

This function is called when the system is turned off. This function must call the OhcdMdd_PowerDown function to enable the MDD to save state information. Then, any processing specific to the platform, such as removing power from the host controller hardware, is performed. No system calls can be made from within this function.
