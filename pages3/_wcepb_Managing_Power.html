Managing Power

The original equipment manufacturer (OEM) uses power management to reduce the power consumption of a Windows CE–based target device and to maintain and preserve the file system in RAM during the reset, on, idle, and suspend power states.

The following table shows the power states for a Windows CE–based target device.

Power state Description
No power The power state in which a device is typically shipped, with no power supplied to RAM. Also, a target device on which the absence of primary and backup power has caused the loss of the Windows CE file system in RAM.
On The power state of standard, normal operation during which the CPU is operational and power is distributed to all devices that are managed by the kernel and any device drivers.
Idle An intentional non-operational period during which the CPU is running, but all other devices are shut down.
Suspend The CPU is stopped and all peripherals are off. This power state is entered during an inactivity timeout or user request — for example, by pressing the OFF switch.
Critical-off The CPU is set to the suspend state; refresh voltage is applied to RAM to preserve the file system and power to the peripherals and devices is immediately shut down. Recovery is the same as a warm boot transition.

The following table shows the transitions between power states for a Windows CE–based target device.

Transition Description
Power-on reset Target device clears working RAM and initializes the file system.
Cold boot First application of power — for example, when a backup battery is installed.
Warm boot Transition from the on power state.
On-to-idle Transition from a fully running state to a state in which the CPU is using little power.
Idle-to-on Transition of the CPU from low-power to full-power operation.
On-to-suspend Transition to a stopped CPU, as a result of certain events. A device driver's power down function is called.
Suspend-to-on Transition of a stopped CPU to full-power operation based on specific wake-up events. A device driver's power up function is called.
Critical-to-off Transition when critically low battery power is detected. This preserves the Windows CE file system during an imminent power failure. You must implement the function for transitioning to the critical-off state for your device.
