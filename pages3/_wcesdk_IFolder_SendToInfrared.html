IFolder::SendToInfrared

This method is not supported in Windows CE Platform Builder 3.0.

This method sends items in the Infrared folder over the IR port. This method is supported only for the infrared folder. 

HRESULT SendToInfrared();

Return Values

S_OK indicates success, and E_ABORT indicates that the user canceled the infrared transfer. If an error occurs, the appropriate HRESULT value is returned.
