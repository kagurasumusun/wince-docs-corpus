Adding a Help File to the All Topics List

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

The All Topics list is a list of HTML links to all the available Help files on a Windows CE platform. The All Topics list for Help for Windows CE versions 2.0 and 2.01 is a separate HTML file that lists links to all the Help files on the Windows CE platform. The manufacturer creates this file; do not alter it. Version 2.10 creates an All Topics list dynamically by selecting the name of the first topic in each Help file and a corresponding link (.lnk) file.

To add a topic to the All Topics list for version 2.10

  1. Name the first topic in each Help file Main_Contents.

    Place this name only in files that you want to include in the table of contents.

  2. Include "Main_Contents" in the <META> tag for each of these files.

    The following code example shows how to include a topic in the dynamic table of contents. 

    <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">
<HTML>
<HEAD>
<META HTTP-EQUIV="Htm-Help" CONTENT="word.htm#Main_Contents">
<TITLE>Pocket Word Help</TITLE>
</HEAD>
<BODY BGCOLOR="#FFFFFF" TEXT="#000000">
<!-- PegHelp -->
<P>
<A NAME="Main_Contents"></A><B>Pocket Word Help</B></P>

<A HREF="word.htm#overview">About Pocket Word</A><BR>
<A HREF="word.htm#selecting_and_editing_text">Selecting and Editing Text</A><BR>
<A HREF="word.htm#formatting_text">Formatting Text</A><BR>
<A HREF="word.htm#adjusting_what_you_see">Adjusting the Display</A><BR>
<A HREF="word.htm#working_in_outline_view">Working in Outline View</A><BR>
<A HREF="word.htm#symbols">Inserting Symbols</A><BR>
<A HREF="word.htm#printing_a_document">Printing a Document</A><BR>
<A HREF="word.htm#setting_a_password_for_a_document">Setting a Password for a Document</A><BR>
<A HREF="word.htm#conversion">Converting Documents</A><BR>
<A HREF="word.htm#pocket_word_keyboard_shortcuts">Shortcuts</A><BR>
<A HREF="word.htm#index">Index</A><BR>

<BR CLEAR=ALL><!-- PegHelp --><HR>

<!-- ************************Topic Break************************* -->
  3. Create a link file for each Help file in the table of contents.

    Create a link file with NotePad or another ASCII editor. For example, the Pocket Word Help file is word.htm and the link file is wordhlp.lnk. The text in the link file tells Help for Windows CE where to aim the link in the table of contents. The following code example is one entry in the wordhlp.lnk file: 

    17#\windows\word.htm

    The number 17 in this example represents the number of characters in \Windows\word.htm

  4. During installation, install your link file in the \Windows\Help directory.

    Install the Help file anywhere you want in the Windows CE platform, as long as you specify the location of the Help file in the link file. For information about installing an application on a Windows CE-based device, see Installing Applications.

Note   An OEM can include the Help file and link file when building an OS image by updating the .bib file. An OEM cannot include a link file that has a file name that contains spaces in the .bib file, because having spaces in a file name causes problems when building an OS image. An OEM can, however, modify the .dat file to change the name of the file after the file is installed on the device. The new name of the file on the device can contain spaces. For information about using .bib files and .dat files, see the documentation for Microsoft Windows CE Platform Builder.
