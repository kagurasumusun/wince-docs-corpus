Packet Filter

As the gateway device receives packets that are destined for devices on the home network, NAT consults the existing port mappings and replaces the address and port information for the public network with the corresponding address and port information for the home network. This process allows a packet to pass through the NAT from the Internet to the home network only if a mapping is already established, unless you have designated an internal exposed host.

You can easily configure the gateway to prevent applications on the gateway device that runs NAT from receiving unknown traffic, thus providing minimal packet filtering capabilities. This Internet packet filter provides the gateway device with similar protection from many types of Internet network security threats that NAT provides to devices on the home network, while providing users a rich browsing, collaboration, and game-playing experience.

Users that take advantage of the packet filter have limited protection from hackers who try to scan their systems or connect to their resources. In exchange, users that take advantage of the packet filter trade away the capability to easily configure their systems as servers to others across the Internet.

To enable the packet filter

  • Set the HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\EnablePacketFiltering registry key equal to a non-zero value.
