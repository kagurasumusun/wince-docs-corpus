The modules that are included in the server group provide server support for Windows CE–based platforms.

The server group contains the following modules.

Module Description Notes Import file
ASP Supports Active Server Pages. Contains components. Asp.lib
HTTPD Supports the Web server implementation. Contains components. Httpd.lib
HTTPDADM Provides administrative functionality for the Web server. Exposes no public functions. Httpdadm.lib
MSMQADMEXT Supports the Message Queuing administration Internet Server Application Programming Interface (ISAPI) plug-in. Exposes no public functions. Msmqadmext.lib
