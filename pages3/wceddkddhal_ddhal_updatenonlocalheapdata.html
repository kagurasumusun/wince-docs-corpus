DDHAL_UPDATENONLOCALHEAPDATA

The DDHAL_UPDATENONLOCALHEAPDATA structure contains the heap information required by the UpdateNonLocalHeap callback. 

typedef struct _DDHAL_UPDATENONLOCALHEAPDATA
{
LPDDRAWI_DIRECTDRAW_GBL    lpDD;
DWORD                      dwHeap;
FLATPTR                    fpGARTLin;
FLATPTR                    fpGARTDev;
DWORD                      dwReserved;
HRESULT                    ddRVal;
LPDDHAL_UPDATENONLOCALHEAP UpdateNonLocalHeap;
} DDHAL_UPDATENONLOCALHEAPDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
dwHeap
Pointer to the heap index.
fpGARTLin
Indicates the linear graphic address remapping table (GART) address of the start of the heap.
fpGARTDev
Indicates the high physical GART address of the start of the heap.
dwReserved
Reserved for future use.
ddRVal
Passes the DirectDraw return values.
UpdateNonLocalHeap
This member is used by DirectDraw and should not be filled in by the driver.
