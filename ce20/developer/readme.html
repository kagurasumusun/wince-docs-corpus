Finding a News Reader - Microsoft Internet News

You will need a news reader program to participate in the discussion newsgroups. We recommend Microsoft Internet News as it supports multiple news servers.

Please see http://www.microsoft.com/ie/download to install this product. Note that the news reader is a component of Internet Explorer 3.0 and requires Windows 95 or Windows NT 4.0 operating systems.

Other news readers are available and a couple are listed below. As these products are not from Microsoft, we cannot provide assistance during the beta in using these news readers.
    • WinVN - A public-domain news reader. The official FTP site for WinVN is at

ftp://ftp.ksc.nasa.gov/pub/winvn/

You can get more information from:

http://www.ksc.nasa.gov/software/winvn/winvn.html
    • Agent and FreeAgent - Forte Inc. makes a popular news reader for Windows 95. According to Forte's web page (http://www.forteinc.com), FreeAgent is for use by individuals and educational institutions while Agent is available for corporate users. If you use Agent or FreeAgent, you may be obligated to pay a licensing fee to Forte Inc.

NOTE: If you have support problems or other questions about these products, you will have to contact their manufacturer, as Microsoft neither recommends nor supports either of these products.

Tips for Using News Reader Programs

Please follow the individual instructions for each news reader to set up and configure the news reader. NOTE: The authentication system being used requires that your news reader be pre-configured with Server Name, User Name, and Password before attempting to connect to the beta newsgroup server.
    • The News Server for this beta program is: Privatenews.microsoft.com
    • Your "User Account" is: Preview
    • Your "Password" is: CETools
    • You may need to log onto your Internet Service Provider prior to starting your news reader. You can use MSN with Internet-Access by opening your Dial Up Networking folder and double-clicking on the MSN connection, or by having Auto-Dial selected in the Internet component of the Windows 95 Control Panel.
    • You can configure some of these programs for SMTP/POP3 mail also. Your Internet Service Provider will have to provide you with a SMTP/POP3 email server and configuration instructions. MSN does not offer this type of email at this time, although you will have to configure FreeAgent to point to mail.msn.com as an SMTP server if you do not have any other SMTP mail account.
    • Most news readers include the ability to "Subscribe" to specific newsgroups. This is just a data file located on your local computer that provides a way to "group" the newsgroups into two categories - subscribed and unsubscribed. It makes it easier to follow topics you find interesting and ignore others.
    • Once you are connected, you may have to Download Newsgroup Headers. When you are connected, you have to Refresh Newsgroup Headers in order to see newer postings, including your own postings. Different news readers have different ways of doing this.
    • Please read the REAME files and use the HELP information provided with each package to learn more about subscribing, downloading, reading and posting using your news reader.

You should NOT discuss this beta in ANY other newsgroups.

Configuring Microsoft Internet News

Microsoft Internet News is a "news reader" that lets you read bulletin board discussion groups, such as USENET newsgroups, using NNTP-based news servers.

Getting Set Up

The first time you run Microsoft Internet News, you will be asked for the following information:
    • The name of your news server (Privatenews.microsoft.com).
    • Your account name and password on this server. Your account name is Preview
    • Your "Password" is: CETools
    • Your full email address. For example, "PatSmith@acme.com" This is the address that people should use when responding to a message that you post into a discussion group.
