Windows CE Logo Program
The Windows® CE Logo Program enables customers to quickly identify software and hardware designed specifically for the Microsoft Windows CE operating system. The Windows CE Logo Program provides partners with a way to demonstrate that their products provide extra benefits and have been tested and integrated with Windows CE. Before receiving the license to use the Windows CE logo, both hardware and software products must be tested by Microsoft® against a rigorous set of technical criteria.

Windows CE Resource Guide
Designed to maximize your exposure to users of Windows CE-based devices, the Microsoft Windows CE Resource Guide is published by Affinity Publishing, and is distributed with Windows CE Handheld PC devices by Windows CE hardware partners. The Resource guide is also available online as part of the Microsoft Windows CE Web site. Advertising space is now available.

Microsoft Windows CE Third Party Showcase
The Windows CE Third Party Showcase is a database on the Microsoft Windows CE Web site designed to match users of Windows CE-based devices to your hardware and software product. The Third Party Showcase is a searchable database of Windows CE based hardware and software accessible by our customers on the Microsoft Windows CE web site. To inquire about adding your company/product to the showcase or for more information, send email to the webmaster.
