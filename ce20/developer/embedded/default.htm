The Win32 Programming Model: A Primer for Embedded Software Developers
Microsoft® Windows® CE is a compact, highly efficient and scalable operating system that is being used in a wide variety of embedded products, from hand-held PCs to specialized industrial controllers and consumer electronic devices. Windows CE has proven itself capable of handling the most demanding 32-bit embedded applications. Equally important, Windows CE brings the full power of the Microsoft 32-bit Windows-based development tools to the embedded systems designer.

Introducing the Windows CE Embedded Toolkit for Visual C++ 5.0
The Microsoft Visual C++® development system has been established as the premier development tool for advanced desktop Windows®-based applications. With the introduction of the Windows CE Embedded Toolkit for Visual C++ 5.0, Visual C++ has been extended to provide the same level of features and support to developers of embedded software and complete embedded systems.
