Microsoft® Windows® CE Embedded Toolkit for Visual C++® 5.0
The Power of Windows Development Comes to Embedded Systems

The Windows CE Embedded Toolkit for Visual C++ 5.0 gives you access to all the power of an integrated development environment, as well as to the tools needed to custom configure Windows CE for the needs of your embedded systems.

Build with the power of Developer Studio.

The Windows CE Embedded Toolkit for Visual C++ 5.0 combines an integrated development environment (IDE) with rich, Win32®-based embedded development technology. Take advantage of the Developer Studio IDE and the Win32 API to build embedded applications for a variety of leading CPU architectures.

Discover all the tools you need - in one package.

The Windows CE Embedded Toolkit for Visual C++ 5.0 includes tools designed specifically for embedded development. The Windows CE platform is a 32-bit, preemptive, multitasking, multithreaded operating system designed from the ground up to support embedded systems.

Use the embedded toolkit to choose components for building a customized version of the Windows CE operating system to meet the unique requirements of your hardware. Then easily build applications and device drivers that target your operating system configuration.

A ROM image maker is also included for creating a binary image of your application or driver for burning into ROM. And because this toolkit supports several hardware development platforms, you can begin your development early¾without being limited by hardware availability.

The embedded toolkit uses the latest Microsoft C11 compiler technology, with CPU-specific optimizations, to produce fast, small 32-bit applications tuned for performance. Cross-compilers for all supported CPUs are provided-covering MIPS, PPC, SH3, and x86-allow for a single set of source code to be used.

Remote tools, including a source-level debugger, Process Viewer, Heap Walker, and Registry Editor, increase your productivity by performing common development chores over a standard connection. Use the Remote Application Debugger to set breakpoints, single step through code, control program execution, view register values-all from within the Developer Studio environment on your PC.

All the tools you need to develop embedded applications for the Windows CE platform. Comprehensive set of productivity-enhancing features.
· Developer Studio. - The integrated set of windows, IDE, menus, toolbars, directories, and other elements allows you to create, test, and refine your application from a single environment.

· Easy access to tools - Use your text editor, resource editors, project build facilities, incremental linker, source code browser, integrated debugger, and online user's guide, all from the Developer Studio IDE.

· Drop-down build bar. - Pull down this menu to easily retarget your application for any of the Windows CE-supported processors.

· Resource editor - Add, edit, and delete program resources efficiently.

· Project workspace. - Use the Class View, File View, and Info View project tools to view program files and help you organize them for the way you work best.

· Project management. - Microsoft Visual SourceSafe™ project-oriented version control integrates into the Developer Studio environment for efficient team development (available separately).

Get a complete set of tools for building embedded applications.
· Cross-compilers and assemblers - Target any Windows CE-supported processor, including MIPS, PPC, SH3, and x86.

· Remote application debugger. - Debug applications that are running remotely on a Windows CE-based target through a standard connection.

· Auto download. - Develop on your PC, and rely on the IDE to automatically download builds of your application to the Windows CE-based device for testing.

· Embedded-specific tools. - Use tools such as Cesysgen, ROM Image Maker, and Parallel Port Shell to build applications and low-level device drivers for ROM.

· Support for Hardware Development Platform. - Supports several Hardware Development Platforms out of the box and delivers the tools to support any reference platforms available that use Windows CE-supported processors.

· Complete documentation. - API reference, sample applications, and information about embedded programming are included with InfoViewer online help.

Program with a subset of the Win32 API.
· Mature API. - Benefit from a rich set of application programming interfaces that covers graphical as well as non-graphical elements of programming.

· Microsoft Foundation Classes (MFC) and Active Template Library (ATL) support. - The Win32 API supports several levels of encapsulation, including Windows CE versions of MFC and ATL, for easy access to Windows CE services.

· Win32 resources. - Take advantage of a robust combination of resources available to Win32 developers, including libraries, tools, and training.

Specifications
To run Microsoft Windows CE Embedded Toolkit for C++ version 5.0, Beta 1.0, you need:
· PC with a 486/66 MHz or higher processor.

· Microsoft Windows NT Workstation operating system version 4.0

· Microsoft Visual C++, Professional or Enterprise edition, version 5.0

· 24 MB of RAM; 32 MB recommended

· 1,250 MB of available hard-disk space

· CD-ROM drive compatible with multimedia PC specification

· Microsoft Mouse or compatible pointing device
