Microsoft® Windows® CE Toolkit for Visual C++® 5.0
Bringing the Power of Visual C++ to Windows CE

Create powerful applications for the latest generation of Windows CE-based devices. By combining your existing Win32skills with optimized cross-compiler technology, you can begin developing for the exciting new Windows CE platform today.

The Microsoft Windows CE operating system is a 32-bit, multithreaded operating system for embedded systems and consumer devices such as the handheld PC. With its broad processor support, plus industry backing for a number of future non-PC devices, Windows CE provides a wealth of development opportunities.

Tap into the power of Visual C++.

Apply your current knowledge of the Visual C++ programming model, environment, and language to building Windows CE-based applications. The Windows CE Toolkit for Visual C++ 5.0 is an add-in to Visual C++ 5.0. Capitalize on your knowledge of Microsoft Foundation Classes (MFC) and the Active Template Library (ATL) with Windows CE versions of each. Plus, Windows CE 2.0 exports more than 600 Win32 API functions that support Windows CE 2.0 features such as demand paging, TrueType® fonts, communications protocols, and many others.

Now you can produce the smallest, fastest 32-bit applications using the most current C++ compiler technology. Cross-platform tools, including Win32 libraries, remote tools and debuggers¾plus a built-in emulation system¾make your development easy. These tools and technology are all seamlessly integrated with the Microsoft Developer Studio integrated development environment (IDE). Download, link, edit, debug, compile, and run applications-all from within a single development environment.

Develop efficiently.

The Windows CE Toolkit for Visual C++ 5.0 puts a leading-edge emulator on your PC that gives you the look and function of a Windows CE-based device. Develop, test, and debug your programs on your desktop-no device is needed.

When you can work directly with a Windows CE-based device, programs are transferred to it automatically through a standard connection. Then, using familiar tools such as Spy, Zoomin, and Registry Editor, you can monitor and debug your applications remotely, right from your PC.

Plus, Windows CE cross-compilers mean you can code your Windows CE-based applications once, and then easily cross-compile them for a variety of processors.

Invest in the future of computing. Now, you can develop a new breed of applications with the Windows CE Toolkit for Visual C++ 5.0¾and get a head start on the future of computing today.

Build with the power of Visual C++ for the Windows CE platform. Get the tools you need to streamline development.
· Enhanced emulation technology - Build Windows CE-based applications using an emulator that provides the look and function of a Windows CE-based device on your PC¾no device is needed.

· Microsoft Foundation Classes (MFC) for Windows CE - Make the most of your knowledge of MFC (as well as your code base) for creating Windows CE-based applications. Includes Windows CE versions of AppWizard and ClassWizard, which work in conjunction with the MFC Library for Windows CE.

· Active Template Library (ATL) for Windows CE - Easily create ActiveX™ Controls for Windows CE development using new ATL for Windows CE support.

· Developer Studio integration - Take advantage of your expertise with the Visual C++ IDE, as well as remote versions of Spy, Zoomin, Registry Editor, and Process Viewer, which work over a standard connection.

· Autodownload. - Develop on your PC, and let the Windows CE Toolkit for Visual C++ 5.0 automatically download and execute builds of your application on the Windows CE-based device for testing.

· Remote application debugger. - Debug applications that are running remotely on a Windows CE-based device through a standard connection.

· Single set of source code. - Easily create ActiveX™ Controls for Windows CE development using new ATL for Windows CE support.

· Complete SDK. - All the headers, libraries, samples, and tools you need to build Windows CE applications, device drivers, and ActiveX Controls are contained in the SDK.

· Support for Internet connectivity - Take advantage of full TCP/IP support, in addition to support for subsets of the RAS, Unimodem, and telephony APIs.

· Extensive sample applications - Build applications for Windows CE-based devices using a robust set of C, C++, MFC, and ATL sample applications that make it fast and easy.

· New Windows CE 2.0 functionality! - Take advantage of new features such as printing, color displays, and demand paging in your Windows CE-based applications.
