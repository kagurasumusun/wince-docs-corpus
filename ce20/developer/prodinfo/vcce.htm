The Power of Visual C++® for Windows® CE-based Development

The Windows CE Toolkit for Visual C++ makes it easy for developers using Visual C++ to apply their existing 32-bit Windows code and development experience to create Windows CE-based applications and take advantage of new market opportunities.

The Windows CE Toolkit for Visual C++ includes cross-compilers based on Microsoft C11 compiler technology for all supported processors , MFC for Windows CE 2.0 along with versions of the MFC AppWizard and ClassWizard for Windows CE, and ATL for Windows CE 2.0 to easily create ActiveX™ Controls for Windows CE-based development.

Developers can take advantage of their expertise with the Visual C++ IDE, as well as remote versions of Spy, Zoom-in, Registry Editor and Memory Viewer, which work over a standard serial connection. The toolkit also includes the Windows CE 2.0 Platform SDK, extensive sample applications, and a complete set of development and CPU reference documentation online.
