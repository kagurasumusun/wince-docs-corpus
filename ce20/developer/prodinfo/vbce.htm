Bringing the ease of Visual Basic® programming to Windows® CE.

The Windows CE Toolkit for Visual Basic 5.0 allows Visual Basic developers to apply their knowledge in Visual Basic to building applications targeting Windows CE-based mobile and embedded devices. The Windows CE Toolkit for Visual Basic 5.0 utilizes the same Visual Basic code editor, form editor, and property pane, with new Windows CE specific functionality exposed and unsupported Visual Basic functionality hidden.

Many of the common Visual Basic controls that developers use are available with the Windows CE Toolkit for Visual Basic 5.0, and combined with an accompanying set of sample projects make it easy for developers to get started developing applications for Windows CE devices. Microsoft is also licensing the Visual Basic run-time for Windows CE as part of the Windows CE v2 operating system, enabling OEMs to include in ROM the Visual Basic run-time for their devices.

With the introduction of the Windows CE Toolkit for Visual Basic 5.0, corporations can now utilize existing Visual Basic developer resources to develop and deploy mobile Windows CE-based applications, which communicate with powerful desktop applications and server-based infrastructure.
