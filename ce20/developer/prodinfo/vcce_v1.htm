Microsoft® Visual C++® for Windows® CE brings the power of Visual C++ to Windows CE development. With Visual C++ for Windows CE, developers using Visual C++ can use their existing programming skill and investment to easily create Windows CE based applications.

Visual C++ for Windows CE breaks new ground as it extends Visual C++ with new specific tools and technologies for Windows CE seamlessly integrated with the Visual Studio™ environment. But you get the best of both worlds, as Visual C++ for Windows uses Microsoft's award winning Visual C++ technology to provide a complete, state of the art development environment for Windows CE based programming.
