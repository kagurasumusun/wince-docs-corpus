Microsoft® Visual C++® for Windows CE

Bringing the Power of Visual C++ to Windows CE-Based Development

Visual C++ for Windows CE lets developers quickly and easily develop robust Windows CE applications, building on their expertise with the Win32 API and the award-winning Microsoft Visual C++ development system.

Introduction

The Microsoft® Visual C++® development system for the Windows® CE operating system is Microsoft Corp.’s first development tool for the new Windows CE platform. The Windows CE operating system was created specifically for nontraditional PC devices, the first of which is the Handheld PC (H/PC) currently being manufactured by Casio Computer Co., Compaq Computer Corp., Hewlett-Packard Co., Hitachi Ltd., LG Electronics Inc., NEC Corp. and Philips Electronics. Windows CE was built from the ground up to address emerging market opportunities presented by non-PC devices:
    • Windows CE is a general-purpose operating system with a small footprint, low power consumption and modular design.
    • Windows CE is compact, providing high performance in limited memory configurations.
    • Windows CE is scalable, supporting a range of embedded, mobile and multimedia product lines.
    • Windows CE is portable, provides choice in microprocessors, and has integrated power management, enabling long battery life on mobile devices.

The familiar Windows user interface facilitates ease of use. Windows CE uses the same user, GDI and memory models as Windows, and, most important for developers, it is based on the Win32® API, lowering the programming bar for the many professional developers for Windows in the industry. Windows CE delivers a core set of Win32 APIs and adds new extensions, enabling developers to take advantage of device-specific technology for their Windows CE-based applications.

In addition to delivering leading platform technology to developers, Microsoft is also delivering the tools that developers need to be successful. The majority of developers today are programming for the Microsoft Windows family of operating systems and have come to expect a high level of quality in the tools they use, including state-of-the-art tools such as Microsoft Visual C++, to help make them more productive and successful. Given the quality of tools available for Windows-based programming, Microsoft had a high standard to meet in delivering tools for Windows CE-based development. Not only did Microsoft need to provide the same industry-leading technology and tool innovation, it also had to address new issues created by the Windows CE device form factors, CPUs, etc. In response, Microsoft introduces Visual C++ for Windows CE, an add-on to Visual C++ 5.0.

Evaluating C++ Tools for Windows CE

Criteria for evaluation of a C++ tool for Windows CE should include how effective the tool is at allowing developers to use their existing programming skills and investment, as well as how it delivers new technology designed to take advantage of the Windows CE platform. In addition, developers should be able to expect the same level of technology delivered by tools for the other Windows platforms.

Easy for Developers to Use Existing Expertise
    • Makes it easy for developers to use their existing code base by supporting Win32 APIs and standard language extensions
    • Enables developers to take advantage of their expertise with their current PC-based integrated development environment (IDE)

State-of-the-Art Technology
    • Same high-quality code generation technology used by PC-based development tools
    • Same level of robust debugging support
    • Same tools used to assist PC-based development (such as process viewers, message spys, etc.), integrated into their development environment
    • A single package that contains all of the software needed to begin development (such as the SDK and DDK)
    • Abundant, well-commented samples that provide easy-to-follow coding examples
    • Comprehensive online documentation, integrated into the development environment, that includes language reference, guides to programming and processor manuals
    • Cross-CPU compilers that supply CPU-specific optimizations, enabling the best performance possible on each CPU

 

Easy to Use
    • Remote development features allow the development tool to be used in conjunction with a Windows CE-based device.
    • No additional hardware is required beyond having a commercially available Windows CE-based device. (Many times, additional hardware boards, and therefore additional expense, are required to develop and test on these types of devices.)
    • Developers can create Windows CE-compatible applications on the PC using emulation of Windows CE-based devices. New hardware devices may be hard to obtain in the early phases of the device development cycle.
    • Clear, concise documentation covers the new hardware designs and their special feature sets.
    • Documentation covers Win32 for Windows CE, making it very easy to tell what is identical to or different from Win32.

Visual C++ for Windows CE

The goal of Visual C++ for Windows CE is to provide developers using Win32 with the same power and ease of use for Windows CE-based development delivered by Visual C++ on the PC. Visual C++ for Windows CE combines Microsoft’s industry-leading Visual C++ technology with new technology created specifically for Windows CE to provide a complete development environment for Windows CE-based applications. Visual C++ for Windows CE lets developers quickly and easily develop robust applications for Windows CE, building on their expertise with the Win32 API and the award-winning Microsoft Visual C++ development system.

Seamlessly Integrated With Visual Studio

Visual C++ for Windows CE is seamlessly integrated into the Visual Studio™ development system. Visual C++ for Windows CE allows developers to edit code and resources, compile, link and download their applications to a device, and run or debug, all from within Visual Studio. Integrating Visual C++ for Windows CE into the Visual Studio environment ensures that developers using Visual C++ can take advantage of the Visual Studio productivity-enhancing features as well as use their expertise with the IDE.

Visual C++ for Windows CE also provides Windows CE-specific versions of the tools developers using Visual C++ know and value, such as Spy, Zoomin, Registry Editor and MemView.

Figure 2. Tools menu

The Visual C++ for Windows CE add-on package contains all the additional software developers need to start developing for Windows CE, including the complete Windows CE SDK and DDK.

 

A core design goal for Visual C++ for Windows CE was to ensure that no extra hardware beyond a PC and a Windows CE-based device was required to perform development targeting the Windows CE-based device. For the Handheld PC,
Visual C++ for Windows CE accomplishes this goal using the serial connection on the Handheld PC. No extra hardware is needed, just the cable provided with the commercially purchased device. Communicating with the target device was facilitated by adding a set of APIs for Windows CE specifically for communicating with remote devices. These APIs allow the desktop to communicate with the Windows CE-based device through a standard serial cable connected to the device through the desktop com port. Serial communication allows the Visual C++ for Windows CE tools to remotely manipulate the Windows CE-based device. This same serial connection also allows developers for Windows 95 and the Windows NT® operating system to add value to their desktop applications by creating companion applications that run on Windows CE-based hardware devices.

Win32, MFC, Class and App Wizards Simplify Development

With Visual C++ for Windows CE, developers familiar with Win32 can use their existing programming skill to easily create Windows CE-based applications. The Win32 API for Windows CE consists of about 500 calls, most of which are identical to their Win32 counterparts. Also, new Win32 calls — such as built-in object store database support and the Remote API — take advantage of unique Handheld PC features.

Visual C++ for Windows CE also supports the same Microsoft extensions to the ANSI C++ standard supported by Visual C++, so developers can reuse existing code without worrying about changes to existing C++ extensions.

The Visual C++ for Windows CE add-on also includes the Microsoft Foundation Classes (MFC) for Windows CE. Developers can take advantage of their knowledge of MFC (as well as their code base) to create MFC-based Windows CE-compatible applications. Visual C++ for Windows CE even includes MFC for Windows CE versions of AppWizard and ClassWizard, making it easy to build Windows CE-compatible MFC applications.

Figure 3. ClassWizard view

Samples

Visual C++ for Windows CE provides an extensive set of sample applications: A robust set of C, C++ and MFC sample applications makes it easy to understand the similarities and differences between programming techniques for Windows 95, Windows NT and Windows CE.

Sample code was also written to highlight the Windows CE feature set, making it easy to understand the similarities between Windows and Windows CE and showing how to take advantage of new technology.

Complete Documentation

The complete set of development documentation for Windows CE is provided through the online InfoViewer in the Visual Studio development System. Visual C++ for Windows CE includes the complete Windows CE SDK and DDK documentation as well as CPU documentation sets for Windows CE-supported CPUs. Visual Studio also allows the developer access to the documentation on Windows CE as well as to the Microsoft Developer Network library and standard documentation on Win32 and Visual C++ without having to open another window or change files.

The Visual C++ for Windows CE documentation includes chapters on programming for Windows CE, including a chapter on porting existing code. Other chapters describe the use of the Remote API, the mail transport system and other special features of Windows CE.

The Windows CE API reference contains documentation on all of the APIs supported on Windows CE. Any changes from standard Win32 are highlighted in sections called Windows CE Notes. There is additional documentation on new APIs that were added for Windows CE, including remote communication and database APIs.

State-of-the-Art Compiler Technology

Visual C++ for Windows CE uses Microsoft’s latest C++ compiler technology for producing fast, small 32-bit applications tuned for performance. Cross-compilers for all supported CPUs allow a single set of source code to be used. Compiled code can be optimized specifically for the targeted CPU.

After the application has been compiled, the IDE downloads the application to the Windows CE-based device through the standard serial connection, eliminating the need for manually transferring files.

Emulation — Develop Without a Windows CE-Based Device

With Visual C++ for Windows CE, users get a complete emulation environment, enabling them to build and execute applications on a Windows CE-based device emulated on their PC. Developers are able to begin developing before hardware is available! And, if users just want to speed development, Visual C++ for
Windows CE automatically runs their application in the emulator, freeing them from the waiting time associated with downloading applications to a Windows CE-based device.

 

Figure 4. Reversi sample running in emulation

Remote Debugging

The Remote Application Debugger is a powerful tool that allows users to debug applications running remotely on the Windows CE-based device. The Remote Debugger retains all of the functionality of the original Visual C++ application debugger, including the DataTips® pop-up information, multiple watch windows and advanced "locals" windows. Developers can set breakpoints, control program execution, view register values — all from within the Visual Studio environment on their PC.

 

Figure 5. Remote Debugger running on the desktop

Remote Development Tools

Remote tools, the extended family of tools created for developing for remote Windows CE-based devices, retain the same user interface and functionality as their desktop versions. Visual C++ for Windows CE supports Windows CE-specific versions of Spy, Zoomin, Registry Editor and Memory Viewer. With these new hardware platforms, developers accustomed to Win32 use the same familiar tools.

 

Visual C++ for Windows CE also provides tools for accessing all of the object stores used during development. With the Remote Object Viewer, developers can browse the emulation file system and object store, remote device file system and object store, and the local drive. They can also use drag and drop to delete, move and copy folders, files and databases between object stores.

Figure 6. Remote Object Viewer

Remote Connection Server is a tool that acts as a communication placeholder, an empty remote client "template." This makes starting other remote tools easier and can be used in developing applications that use a remote connection. Synchronization and other relationships will not be attempted, so developers can use Remote Connection Server in place of H/PC Explorer when a quick connection to the device is necessary.

Conclusion

Windows CE has opened vast inroads to the future of non-PC computing. The Handheld PC is a great example of how Microsoft is helping lead developers to new markets. To that end, Microsoft Visual C++ for Windows CE builds upon the knowledge base of hundreds of thousands developers who develop applications for the Windows platform.

 

With the addition of Microsoft Visual C++ for Windows CE to the Visual Tools family, developers obtain a complete solution for creating applications for the new family of Windows CE-based devices.

 

Availability and Further Information

Visual C++ for Windows CE is available directly from Microsoft. Visual C++ for
Windows CE requires that Visual C++ 5.0 be installed on the system.

For more information on Visual C++ for Windows CE as well as development for the Windows CE platform, please visit our Web site at http://www.microsoft.com//windowsce/developer/
