Microsoft Leads The Way at Embedded Systems Conference and Software Development East!

New Windows CE Development Tools Generate Significant Interest Among Embedded and Win32 Developers

Microsoft made big news with the September 29th announcement of the new Windows CE Embedded Toolkit and Toolkits for Visual Basic 5.0, Visual C++ 5.0, and Visual J++ 1.1 at the Embedded Systems Conference and Software Development East.

In case you were not able to attend either of these events, here are a few pictures from the Embedded Systems Conference.



Microsoft kicks off the Embedded Systems Conference!


It was "standing room only" as show attendees learned about the new Windows CE Toolkits in a packed Microsoft Theater.


The Microsoft booth provided an opportunity for attendees to look at the new Windows CE tools and technologies.


Plenty of one-on-one sessions and demonstrations provided a great opportunity to learn more about the Embedded Toolkit and Windows CE-based technologies.
