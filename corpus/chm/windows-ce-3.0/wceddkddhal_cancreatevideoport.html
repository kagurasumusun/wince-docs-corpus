CanCreateVideoPort

The CanCreateVideoPort callback function indicates whether a video port with the specified description can be created. This callback is required. 

DWORD __stdcall CanCreateVideoPort(
LPDDHAL_CANCREATEVPORTDATA pccvpd );

Parameters

pccvpd
Pointer to a DDHAL_CANCREATEVPORTDATA structure that contains the information required for the driver to determine whether a video port can be created.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
