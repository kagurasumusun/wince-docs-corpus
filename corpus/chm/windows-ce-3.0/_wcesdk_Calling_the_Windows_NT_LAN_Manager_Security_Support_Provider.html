Calling the Windows NT LAN Manager Security Support Provider

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

Windows CE applications can interact with Microsoft Windows NT workstations or Windows CE servers that are running the LAN Manager Security Support Provider service (Windows NT LMSSP). The Windows NT LMSSP is based on the Windows NTLM (Windows NT LAN Manager) authentication protocol.
