Using the Sleep Timer

Windows CE uses the Sleep function and the Wait* functions to help control timing and synchronization. In Windows CE 2.x, an OEM sets the frequency and duration of timer calls. Each time the timer is fired, Windows CE 2.x signals the kernel to schedule a new thread. Because of threading, any call to Sleep returns on a schedule tick. Therefore, a Sleep(1) call is really a Sleep(25) call.

The Windows CE 3.0 OS always sets the timer to 1 millisecond under normal working conditions when there are threads to schedule. Therefore, you can now call Sleep(1) and expect to receive approximately 1> n < 2 ms accuracy. However, the accuracy depends on the priority of your thread, the priority of other threads, and whether ISRs are running.
