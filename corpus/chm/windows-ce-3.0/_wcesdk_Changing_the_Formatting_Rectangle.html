Changing the Formatting Rectangle

Important:

The visibility of the text of an edit control is governed by the dimensions of the window rectangle and the formatting rectangle of the edit control. The window rectangle is the client area of the window that contains the edit control. The formatting rectangle is a construct that is maintained by Windows CE for the formatting of the text that is displayed in the window rectangle. When an edit control is first displayed, the two rectangles are identical on the screen. An application can make the formatting rectangle larger or smaller than the window rectangle. Making the formatting rectangle larger limits the visibility of the text of the edit control; making it smaller creates extra white space around the text.

You can set the coordinates of the formatting rectangle of an edit control by sending an EM_SETRECT message to the edit control. The EM_SETRECT message automatically redraws the text of the edit control. To establish the coordinates of the formatting rectangle without redrawing the text of the control, send the control an EM_SETRECTNP message. To retrieve the coordinates of the formatting rectangle, send the control an EM_GETRECT message. These messages apply to multiline edit controls only.
