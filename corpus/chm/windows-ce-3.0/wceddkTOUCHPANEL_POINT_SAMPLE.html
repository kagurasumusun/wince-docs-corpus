TOUCHPANEL_POINT_SAMPLE

This structure defines the values available for each sample from the analog-to-digital converter.

typedef struct {
USHORT XSample;
USHORT XzaSample;
USHORT XzbSample;
USHORT YSample;
USHORT YzaSample;
USHORT YzbSample;
} TOUCHPANEL_POINT_SAMPLE;

Members

XSample
Specifies the x-coordinate in pixels. The top left corner is (0,0).
XzaSample
Not used.
XzbSample
Not used.
YSample
Specifies the y-coordinate in pixels.
YzaSample
Not used.
YzbSample
Not used.

Remarks

This structure supports the implementation of the touch screen PDD.

Requirements

Windows CE OS 1.0 and later Tchaud.h
