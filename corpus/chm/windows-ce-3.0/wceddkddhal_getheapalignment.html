The GetHeapAlignment callback function queries the surface alignment requirements. 

DWORD __stdcall GetHeapAlignment(
LPDDHAL_GETHEAPALIGNMENTDATA lpGhaData );

Parameters

lpGhaData
Pointer to a DDHAL_GETHEAPALIGNMENTDATA structure that contains the heap alignment information.
