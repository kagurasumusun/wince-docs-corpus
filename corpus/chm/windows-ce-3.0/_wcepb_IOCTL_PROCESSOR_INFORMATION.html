IOCTL_PROCESSOR_INFORMATION

Important:

This input/output control is a request by an application to retrieve microprocessor information from the OAL and store it in the PROCESSOR_INFO structure. This input/output control is optional, but it is recommended that all OEMs support it. Applications that need this information use the KernelIoControl API to query the OEM for information.

Parameters

dwIoControlCode
Set to IOCTL_PROCESSOR_INFORMATION.
lpInBuf
Set to NULL.
nInBufsize
Set to 0.
lpOutBuf
Pointer to the output buffer. This is set to a buffer allocated to hold the PROCESSOR_INFO structure.
nOutBufSize
Maximum number of bytes that can be returned in lpOutBuf. Set to the size of the PROCESSOR_INFO structure.
lpBytesReturned
Actual number of bytes returned in lpOutBuf.

Return Values

If TRUE is returned then the input/output control was successfully processed; otherwise FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
