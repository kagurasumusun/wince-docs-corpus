This function handles the interrupts for the debug Ethernet adapter.

void OEMEthISR (void);

Return Values

Interrupt mask of interrupts that occurred.

Remarks

This function is called by the Ethernet debug subsystem to process an interrupt event. It should perform any hardware specific processing required, and return a mask of the interrupt events that are present. For the Ethernet sample code, currently the only event that the EDBG subsystem processes is a receive interrupt event, namely INTR_TYPE_RX. If this value is returned, the OEMEthGetFrame function is called to read the received data.
