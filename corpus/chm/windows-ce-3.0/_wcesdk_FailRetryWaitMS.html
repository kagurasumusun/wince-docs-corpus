Specifies the amount of time, in milliseconds, during which further calls to auto dial return an error immediately and do not result in attempts to call the remote access server (RAS) functions, if three attempts to establish a RAS connection have previously failed within the same length of time.

Path

HKEY_LOCAL_MACHINE\Comm\Autodial

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF

Default Value

0, which specifies that calls to auto dial do not return an error or result in a failure to call the RAS functions, regardless of whether previous attempts to establish a RAS connection failed.
