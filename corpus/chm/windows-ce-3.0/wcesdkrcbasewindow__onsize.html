Handles the WM_SIZE message. 

virtual BOOL OnSize(
LONG Width,
LONG Height);

Parameters

Width
Window width.
Height
Window height.

Return Values

No return value.

Remarks

This member function stores the window width and height so that they can be returned from the CBaseWindow::GetWindowHeight and CBaseWindow::GetWindowWidth member functions.
