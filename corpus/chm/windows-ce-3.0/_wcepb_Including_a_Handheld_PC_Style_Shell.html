Including a Handheld PC Style Shell

The Handheld PC style shell is similar to the shell on Windows-based desktop platforms. It provides a familiar interface for accessing documents, launching applications, switching between tasks, browsing the file system, and performing other services. To include this shell on your device, include the Explorer, Asform, and Ceshell components in your Cesysgen.bat file. Refer to the Cesysgen.bat file in the Maxall configuration for an example of how to include these components.

Along with the Handheld PC style shell, Platform Builder includes the following Windows CE applications: Pocket Internet Explorer, Pocket Word, Inbox, and Help for Windows CE.

Note   The version of Pocket Word that is included with Platform Builder does not support the spelling-checker feature. The version of Inbox that is included with Platform Builder does not support the Calendar, Contacts, and Tasks features. The Handheld PC style shell, and associated applications, were designed for graphical displays larger than 480 x 240. This shell cannot run in the same configuration as the Sample shell.
