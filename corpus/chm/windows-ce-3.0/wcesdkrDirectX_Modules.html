DirectX Modules

The DirectX modules implement Microsoft DirectX functionality and provides support for the DirectX API. For a list of all the modules and components that are required to build DirectX functionality into your platform, see the Cesysgen.bat file for the MaxDX configuration.

The following table lists the DirectX modules that expose a set of API elements.

DirectX module API set exposed
directxdraw DirectDraw
directsound DirectSound
mixerapi Audio Mixer API
quartz DirectShow
msdxm & dxmasf Windows Media Technologies SDK

All other DirectX modules or components fall under one of the following three groups:

  • Modules/components that provide support for a specific media type; for example the l3filter module adds MP3 support to DirectShow.
  • Sample device drivers; for example the ddi_igs5 module includes a sample IGS5000 display driver.
  • Sample applications; for example the ceplayer module includes a sample Windows Media Player application.

The following table lists all of the modules that provide DirectX functionality. These modules that have public functions or components are linked to topics that describe them in greater detail.

Module Description

AMSTREAM Supports DirectShow multimedia streaming.

DDCAPS Provides a DirectDraw capabilities viewer sample application.

DDI_DS3V Provides a sample ddi/ddhel for the S3 Virge.
DDSAMPLES Contains DirectDraw sample applications (ddex1, ddex2, ddex3, ddex4, mosquito, donuts, foxbear).

DXVIEW Includes a viewer sample application with general DirectX capabilities.
DIRECTSOUND Selects all core DirectSound components.
DMUSIC Provides a MIDI playback engine. Required for MIDI playback.
DMSYNTH Provides a software synthesizer. Required for MIDI playback.
DSHOWSAMPLES Contains DirectShow sample programs (ceplayit, playall, playwnd).
DSOUND Provides support for DirectSound mixers.
DSPLAY Includes a simple DSound sample application that allows you to play .wav files with DirectSound.
DXMASF Contains all WMT core components.
ES1371 Provides the Ensoniq PCI 1371/1373 wavedev driver.
ICCVD Supports the Cinepak video codec.
ICM Supports the Video Compression Manager.
IDSES1371 Provides a DirectSound HAL driver for CreativeLabs Ensoniq AudioPCI ES1371 sound card.
IDSWAVE Includes an IDsDriver wrapper to make DSound work with wavedev drivers.
IGS5000 Supports the IGS 5000/5050 wavedev driver.
IMAADPCM Provides support for the IMA ADPCM audio codec.
L3FILTER Supports the Fraunhofer MP3 codec.
MIXERAPI Contains the mixer API client-side DLL.
MMTIMER Provides multimedia services required by quartz.
MPEG4V3 Supports the MPEG4 v3 codec.
MSACMCE Contains the ACM driver used by DirectShow.
MSADPCM Supports the Microsoft ADPCM audio codec.
MSDLS Contains a wave sample for software synthesizer. Required for MIDI playback.
MSDXM Selects all Windows Media Player core components.
MSG711 Supports the G.711 audio codec.
MSGSM610 Provides support for the GSM 6.10 audio codec.
MSRLE32 Supports the RLE8 video codec.
PCMCONV Includes a PCM bit/sample rate ACM conversion codec.
QUARTZ Provides DirectShow functionality. Core DirectShow module.
SL_ANET Supports the Sipro ACELP.net codec.
VRCTL Implements a windowless video control.
WAVEBUFF Exposes wavedev interfaces to waveapi.dll, so that waveOut works on top of DSound.
WMAUDIO Supports the Windows Media Audio codec 2.0.
