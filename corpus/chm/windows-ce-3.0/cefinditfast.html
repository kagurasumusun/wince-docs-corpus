Windows CE Application Development

What are the Application Development tools for Windows CE?

To develop applications for any Windows CE-based platform, you'll need Microsoft® eMbedded Visual Tools 3.0, a standalone desktop development environment for creating applications and system components for Windows CE-based devices. The eMbedded Visual Tools product includes eMbedded Visual Basic® and eMbedded Visual C++®, and SDKs for the Pocket PC, Palm-size PC, and Handheld PC. For more information, or to download a free copy, go to the Mobile Devices Tools Web site.

Is there a Windows CE Software Development Kit (SDK)?

There is no generic SDK for Windows CE 3.0. Because Windows CE-based platforms include so many customized components, you need the specific SDK for your target platform. There is, however, a complete API reference.

How can I find the Pocket PC SDK, or other information on developing Pocket PC applications?

The Pocket PC SDK is included in the MSDN Library.

For additional technical resources, see the Developer Technical Resources Web site.

Where can I find the Handheld PC SDK, or other information on developing HPC applications?

The Handheld PC SDK is included in the MSDN Library.

For additional technical resources see the Developer Technical Resources Web site.

Where can I find the Auto PC SDK, or other information on developing Auto PC applications?

See the AutoPC Developers Web site.

Windows CE Device Driver Development

Where can I find the Windows CE DDK?

The complete Driver Development kit for Windows CE ships with Platform Builder. The documentation for the Windows CE version 3.0 DDK is in the MSDN Library.

Where is the Windows CE DDTK located?

The complete Driver Development Test Kit for Windows CE ships with Platform Builder. The documentation for the Windows CE 3.0 DDTK is available in the MSDN Library.

What types of hardware does Windows CE support?

For a list of hardware peripherals that are compatible with the Microsoft Windows CE operating system versions 2.11 and 3.0, see the MSDN Library.

For a list of supported microprocessors, see the Microsoft Windows CE Embedded Web site.

Platform Builder for Windows CE

How do I upgrade my PocketPC to the latest version of Windows CE?

If you have a Pocket PC, then you do have the most recent version of the Windows CE operating system, plus a number of other features available only on the Pocket PC platform. For information on updates to your Pocket PC device, contact the manufacturer.

Where can I find more information about developing a Windows CE-based operating system?

Visit the Windows CE Embedded Web site.

NT Embedded Application Development

What application development tools for NT Embedded are available?

You can use the same development environment, debugging tools, and source files that you would use to develop an application for Windows NT 4.0. For information specific to a particular Embedded NT device, contact the OEM.

Where can I find the SDK/DDK for NT Embedded?

Because NT Embedded 4.0 has the same architecture and feature set as Windows NT 4.0, there is no separate SDK or DDK. For information specific to a particular NT Embedded device, contact the OEM.

Target Designer for NT Embedded

Tell me more about Target Designer and Component Designer.

The best way to learn about these development tools is to try them! The Windows Embedded Evaluation Kit includes full-featured versions of Windows CE Platform Builder 3.0 and Windows NT Embedded 4.0, allowing you to evaluate which OS is right for your next project.
