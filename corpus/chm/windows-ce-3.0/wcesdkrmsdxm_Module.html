The msdxm module selects all Windows Media Player components.

Msdxm Components

The msdxm module contains the following components.

Component Description
STATBAR Implements a status bar.
BKGNDBMP Supports a background bitmap that is displayed in media window while media is loading.
TOOLBAR Implements transport controls, such as Play and Pause.
