CeGetReplChangeBitsEx

This function identifies if an object has changed and which partner has not synchronized the change.

BOOL CeGetReplChangeBitsEx(
PCEGUID pguid,
CEOID oid,
LPDWORD lpbits,
DWORD dwFlags
);

Parameters

pguid
Pointer to a CEGUID that identifies a mounted database volume or the internal object store.
oid
Object identifier to query.
lpbits
Buffer that retrieves the record change bits. The first two bits identify for which partner the record has changed when the bit is set.
dwFlags
Operation flags that determine the behavior of the function. It is one of the following values.
Value Description
0 No additional functionality.
REPL_CHANGE_WILLCLEAR Turns on the tri-state bit of the object. An object must set this bit before a partner's bit can be cleared with CeClearReplChangeBitsEx.

Return Values

If the function succeeds, then TRUE is returned; otherwise, FALSE is returned.

Remarks

The tri-state bit enables a type of transaction on the object's replication bit. You must first check the state of the dirty bit. Then, after the data is synchronized, the replication bit is cleared. If something happens between the time you read the dirty bit and synchronize the data, the dirty bit will remain in the same state to prevent a loss of synchronization data.
