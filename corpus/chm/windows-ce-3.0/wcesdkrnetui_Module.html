The netui module supports the Network User Interface (NetUI), which defines configuration settings for the Communications icon in Windows CE Control Panel.

Functions for Operating System Developers

The netui module contains the following functions for operating system configuration, which are defined in the netui.h header file. To import these functions, you need to link to the netui.lib file.
