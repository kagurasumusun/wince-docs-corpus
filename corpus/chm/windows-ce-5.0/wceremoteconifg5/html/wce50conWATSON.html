WATSON

This module configures Watson support for the Remote Configuration Framework.

The following table shows the configurable settings for WATSON.

Value : Type Access Index Description
DontUpload : DWORD Read-only Not applicable If this value is set to 1, error reporting files are kept but not uploaded to the Watson Web site. If this value is set to 0, error reporting information is uploaded to the Watson Web site.
DumpEnabled : DWORD Read-only Not applicable If this value is set to 1, error report generation is enabled. If this value is set to 0, error report generation is disabled.
NoConsentRequired : DWORD Read-only Not applicable If this value is set to 1, no user consent is required for error reporting upload. If this value is set to 0, consent is required for error reporting upload.
