Platform Builder for Microsoft Windows CE 5.0  

RAS

This module configures the Remote Access Service (RAS) settings and creates Point-to-Point Protocol over Ethernet (PPPoE) connectoids.

The following table shows the configurable settings for RAS.

Value : Type Access Index Description
PPPoEDeviceName : STRING Read-write EntryName Specifies the name of the connectoid to set and delete.
PPPoEServiceName : STRING Read-write EntryName Specifies the name of the PPPoE service.
PPPoEUserName : STRING Read-write EntryName Specifies the user name.
PPPoEPassword : STRING Read-write EntryName Specifies the password for a specific user name.
PPPoEDomain : STRING Read-write EntryName Specifies the network domain.
PPPoEDelete : STRING Write-only EntryName Specifies the PPPoE setup that is to be deleted.
