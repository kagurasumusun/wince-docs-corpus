Remote Configuration Framework Migration

SYSGEN_REMOTEADMIN does not exist in Windows CE 5.0. To migrate an OS design that uses SYSGEN_REMOTEADMIN to Windows CE 5.0, define SYSGEN_REMOTECONFIG_FRAMEWORK.
