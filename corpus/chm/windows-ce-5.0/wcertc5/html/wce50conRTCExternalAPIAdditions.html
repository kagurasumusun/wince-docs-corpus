RTC Client API External API Additions

The following list shows the changes in the external RTC Client API between Windows CE .NET 4.2 and Windows CE 5.0:

  • RTC_TERMINATE_REASON. New RTCTR_NOT_SUPPORTED value in this enumeration
  • RTC_BUDDY_SUBSCRIPTION_TYPE. New RTCBT_POLL value in this enumeration
  • RTCSI_ constants. New RTCSI_APPLICATION constant
  • RTCIF_ constants. New RTCIF_ENABLE_SERVER_CLASS constant and new RTCIF_DISABLE_STRICT_DNS constant
Note   This list provides information about changes in the exposed API. It does not list the members of the API with modified implementations that do not affect the exposed API.
