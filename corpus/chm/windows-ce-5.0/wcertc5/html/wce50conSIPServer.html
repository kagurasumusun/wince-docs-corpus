SIP Servers

A SIP server does the following:

  • Functions as the SIP registrar for location information and the SIP proxy server for call routing. For more information about SIP, see SIP.
  • Registers presence information.
  • Establishes Windows CE-SIP client, Windows CE-phone, and messaging sessions.
  • Uses URIs to handle call signaling and call setup.

    After a communication link is established, the devices communicate directly using RTP. For more information about RTP, see RTP/RTCP.
