RTC Client API ACM Sample Registry Configuration

The following example registry settings show the registry path and keys for a typical ACM driver registry entry.

HKEY_CURRENT_USER\Software\Microsoft\RTC\ACM
    G711
        Driver = rtcg711.acm
        PayloadType = REG_DWORD 0x0000007f
        CodecRank = REG_DWORD 0x0000003c
        FrameDuration = REG_DWORD 0x0000001e
        WaveFormat
            FormatTag = REG_DWORD 0x00000042
            Channels = REG_DWORD 0x00000001
            SamplesPerSec = REG_DWORD 0x00001f40
            AvgBytesPerSec = REG_DWORD 0x00000320
            BlockAlign = REG_DWORD 0x00000004
            BitsPerSample = REG_DWORD 0x00000000
            bSize = REG_DWORD 0x00000002

The following example registry settings show the registry path and keys for defining the preferred codec.

HKEY_CURRENT_USER\Software\Microsoft\RTC\Codec
    PreferredAudioCodec = REG_DWORD 0x0000007f 
    UsePreferredCodec = REG_DWORD 0x00000001
