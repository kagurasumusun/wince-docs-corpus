Session Settings

The following session settings define basic information about the session. For more information about the XML schema that defines these settings, see RTC Client API XML Schema.

party
The party type can be first-party or third-party, depending on who initiates the call.

The call is first-party if the client application initiates the call.

The call is third-party if another computer initiates the call.

type
The session types that the server can support.

These can be any session type listed in the RTC_SESSION_TYPE enumeration type.
