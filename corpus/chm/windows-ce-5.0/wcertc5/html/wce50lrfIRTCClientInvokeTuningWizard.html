IRTCClient::InvokeTuningWizard

This method is not supported in Windows CE. 

HRESULT InvokeTuningWizard(
  OAHWND hwndParent
);

Parameters

hwndParent
[in] Handle to the parent window.

A value of NULL indicates that there is no parent window.

It is recommended that this parameter not be set to NULL.

Return Values

This method returns E_NOTIMPL.

Requirements

OS Versions: Not supported in Windows CE.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
