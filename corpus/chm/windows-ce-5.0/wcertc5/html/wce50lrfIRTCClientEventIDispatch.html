IRTCClientEvent:IDispatch

This interface retrieves information about an event of type RTCE_CLIENT. This type of event indicates changes in the presence state of a client.

Methods

The following tables show the methods for this interface in vtable order.

This is the order in which the compiler calls the methods.

This interface inherits the methods for the IUnknown and IDispatch interfaces.

The following table shows the IDispatch methods.

Method Description
GetIDsOfNames Maps a single member name and an optional set of parameter names to a corresponding set of integer dispatch identifiers (DISPIDs).

These identifiers can then be used on subsequent calls to IDispatch::Invoke.

GetTypeInfo Retrieves the type information for an object.
GetTypeInfo Retrieves the number of type information interfaces provided by an object, either zero (0) or 1.
Invoke Provides access to properties and methods exposed by an object.

The following table shows the IRTCClientEvent methods.

Method Description
EventType Gets the event type.
Client Gets the Client object.

Obtaining a Pointer

When an application's implementation of the IRTCEventNotification::Event method indicates an RTC_EVENT enumeration value of RTCE_CLIENT, the method's pEvent parameter is an IDispatch pointer for the IRTCClientEvent interface.
