Provider Settings

The following provider settings specify contact information and other provider-specific data. For more information about the XML schema that defines these settings, see RTC Client API XML Schema.

calldisplay
The URI that should be displayed for marketing information by the client application during a call.
data
ITSP-specific information.

This is a binary large object (BLOB) of XML that the client application can understand, but that the RTC Client API does not handle. This can be used to pass the provisioning version or other account information.

helpdesk
The provider help desk URI that the client can display.
homepage
The provider home page URI that the client can display.
idledisplay
The URI that should be displayed for marketing information within the client when no call is in progress.
name
The name of the Internet telephony service provider.
personal
The URI that the provider uses to display the account details of the client.
