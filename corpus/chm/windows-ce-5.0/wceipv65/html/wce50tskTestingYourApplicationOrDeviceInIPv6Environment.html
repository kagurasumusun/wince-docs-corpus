Testing your Application or Device in an IPv6 Environment

It is important to test your application or device in an IPv6 environment before deploying it in a production environment. You can test your application in the following ways:

  • In an IPv6 test lab that you set up that is internal to your organization.

    For information about how to set up this lab, see How to Set Up and Use an IPv6 Test Lab.

  • In an online IPv6 environment.

    The 6bone is a portion of the Internet for testing IPv6. For information about connecting to this test Internet, see Connecting to the Test Internet (6bone).

To test your application or device in an IPv6 environment

  1. Run your application.

    The following list shows the expected behavior, including in the user interface:

    • Changes accommodate both IPv6 and IPv4 addresses.
    • Protocol address display locations, such as informational dialog boxes, handle IPv6 addresses properly.
