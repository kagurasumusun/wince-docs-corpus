IPv6 ppt

This command displays the prefix policy table.

ipv6 [-p] ppt

Parameters

-p
Saves the setting in the registry.

Remarks

The prefix policy table is used to specify the policies for source and destination address selection.

For information about the prefix policy table, see Default Address Selection for IPv6.
