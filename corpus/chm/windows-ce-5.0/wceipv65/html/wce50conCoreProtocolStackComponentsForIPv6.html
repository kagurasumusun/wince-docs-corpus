Core Protocol Stack for IPv6

The core protocol stack includes the technologies shown between the NDIS and Winsock in the illustration included in TCP/IP Architectural Model.

The Microsoft TCP/IPv6 technology is implemented in Tcpip6.dll. This stack is accessible through the Winsock 2.2 interface. The Winsock interface for Windows CE does not provide raw access to the protocol stack.
