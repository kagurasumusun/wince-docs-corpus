Configuring CLIENT2

In the IPv6 test lab, configure CLIENT2 as a client computer.

To configure CLIENT2

  1. Configure the TCP/IP protocol using the following addresses:
    • IP address: 10.0.3.2
    • Subnet mask: 255.255.255.0

    For more information, see Configuring a Device with a Static Address for the IPv6 Test Lab.

  2. Verify the integrity of the routing infrastructure by pinging 10.0.1.3 from the CLIENT2 computer. If there is no response to the ping, configure the network again.

    For more information, see Pinging a Host in the IPv6 Test Lab by Using a Link-Local Address.
