IPv6

The IPv6 tool configures the IPv6 protocol and enables you to query and configure interfaces, addresses, caches, and routes. Ipv6.exe has numerous commands, each with its own set of parameters.

You can perform tasks for specific areas using IPv6 commands. The following table shows task groupings by area. To view the command syntax, choose the IPv6 command associated with a task.

Area Tasks IPv6 commands
Interfaces Display interface information IPv6 if
Interfaces Control interface attributes IPv6 ifc
Interfaces Delete an interface IPv6 ifd
Interfaces Add or remove a unicast or anycast address assignment on an interface IPv6 adu
Interfaces Display the values of the global parameters for the IPv6 protocol IPv6 gp
Interfaces Set the value of the Hop Limit field IPv6 gpu
Interfaces Display the prefix policy table IPv6 ppt
Interfaces Delete the prefix policy IPv6 ppd
Interfaces Update the prefix policy table IPv6 ppu
Interfaces Renew the IPv6 configuration for all interfaces IPv6 renew
Addresses Display the contents of the site prefix table IPv6 spt
Addresses Add, remove, or update a prefix in the site prefix table IPv6 spu
Addresses Determine whether temporary addresses are used IPv6 gpu UseTemporaryAddresses
Addresses Set the number of times that a temporary address is checked for uniqueness IPv6 gpu MaxTempDADAttempts
Addresses Set the valid and preferred lifetimes of temporary addresses IPv6 gpu MaxTempLifetime
Addresses Set the period of time within which to generate a new temporary address IPv6 gpu TempRegenerateTime
Addresses Set the maximum temporary random time IPv6 gpu MaxTempRandomTime
Addresses Set the minimum temporary random time IPv6 gpu TempRandomTime
Cache Display the contents of the neighbor cache IPv6 nc
Cache Remove a neighbor cache entry IPv6 ncf
Cache Display the contents of the route cache IPv6 rc
Cache Remove a route cache entry IPv6 rcf
Cache Set the maximum number of entries in the neighbor cache IPv6 gpu NeighborCacheLimit
Cache Set the maximum number of entries in the route cache IPv6 gpu RouteCacheLimit
Routes Display the current contents of the routing table IPv6 rt
Routes Add or remove a route in the routing table IPv6 rtu
Routes Update router link address IPv6 rlu
