IPv6 nc

This command displays the contents of the neighbor cache.

ipv6 nc [IfIndex [Address]]

Parameters

IfIndex
Indicates the interface index number for which to display neighbor cache. If an interface number is specified, only the contents of that interface's neighbor cache are displayed. Otherwise, the contents of all of the interface's neighbor caches are displayed.
Address
Indicates an IPv6 address for which to display neighbor cache. If an interface is specified, you can specify an IPv6 address, displaying only the single neighbor cache entry.

Remarks

The interface, IPv6 address, link-layer address, and reachability state are displayed for each neighbor cache entry.
