LASS Samples

The following table shows the LASS and LAP related samples in Windows CE.

Name Description
LASSCTL LASSCTL is a utility that enables you to configure and test LASS and its associated LAPs. LASSCTL can force LAP enrollment, set or reload a LASS configuration and force LASS to reload its settings.

To include the LASSCTL utility in your design template, go to %_WINCEROOT%\Public\Common\Sdk\Samples\Lassctl from the build window, and type build. This will add LASSCTL to your design template.
Sample LAP Sample LAPs are located in the %_WINCEROOT%\Public\Common\Sdk\Samples\Lap directory. This folder contains samples for a Password LAP and Smartcard LAP.
