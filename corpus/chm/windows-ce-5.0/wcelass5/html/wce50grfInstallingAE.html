Installing an AE

To install an AE, you must first generate a GUID for the AE, and then add a new key with the generated GUID to the HKEY_LOCAL_MACHINE\Comm\Security\LASSD\AE registry key.

The following registry entry shows how to install an AE policy.

;AE_GUID_STARTUI {1B38A686-7CDC-4017-A5E9-4C6A9DD7E5BA}
[HKEY_LOCAL_MACHINE\Comm\Security\LASSD\AE\{1B38A686-7CDC-4017-A5E9-4C6A9DD7E5BA}]
"FriendlyName"="Device Startup"
"DisplayText"="System Startup"
; Every Time
"AEFrequencyType"=dword:0
"AEFrequencyValue"=dword:0

In this example, {1B38A686-7CDC-4017-A5E9-4C6A9DD7E5BA} is the GUID of the AE that is to be installed.

For more details on each subkey, see LASS Registry Settings.

LASSReloadConfig must be called or the device must be rebooted for changes to take effect.
