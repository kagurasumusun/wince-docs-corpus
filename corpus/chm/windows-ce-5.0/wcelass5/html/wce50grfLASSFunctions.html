LASS Functions

The following table shows the LASS functions that an application would call, with a description of the purpose of each.

Programming element Description
CreateEnrollmentConfigDialog This function displays the LAP enrollment dialog.
LASSReloadConfig This function causes the LASS to reload its settings.
VerifyUser This function authenticates the user to the LASS.
