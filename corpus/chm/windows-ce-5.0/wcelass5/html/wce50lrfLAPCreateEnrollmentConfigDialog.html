LAPCreateEnrollmentConfigDialog

This function displays the LAP enrollment dialog box.

BOOL LAPCreateEnrollmentConfigDialog(
   HWND hParentWindow,
   DWORD dwOptions
);

Parameters

hParentWindow
[in] Handle to the parent window.
dwOptions
[in] Bitmask VU_HANDLE_MASTER_KEY that specifies to handle master key encryption and decryption if master key encryption and decryption is supported.

Return Values

Returns TRUE on success, and FALSE otherwise.

Remarks

LAPCreateEnrollmentConfigDialog is called by LASS into a LAP on behalf of an application calling CreateEnrollmentConfigDialog. The LAP should use this call to dispaly its enrollment dialog.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: lap.h.
Link Library: Coredll.lib.
