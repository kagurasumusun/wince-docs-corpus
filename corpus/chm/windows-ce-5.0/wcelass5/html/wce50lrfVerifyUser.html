VerifyUser

This function authenticates the user to the LASS.

BOOL VerifyUser(
  const GUID *AEKey,
  LPCWSTR wszAEDisplayText,
  HWND hWndParent,
  DWORD dwOptions,
  PVOID pExtended
);

Parameters

AEKey
[in] This is the authentication event identifier.
wszAEDisplayText
[in] The text that will be displayed in the plugin. If this value is NULL, the value set in the registry is used.
hWndParent
[in] The handle to the parent window if it is available, otherwise the handle to the desktop window.
dwOptions
[in] Bitmask of possible options are shown in the following table.
Flag Description
VU_NO_UI Return from VerifyUser without displaying the UI. Return true only if a call to the LAP is not necessary.
VU_HANDLE_MASTER_KEY Handle master key encryption and decryption if master key encryption and decryption is supported.
Note   The VU_HANDLE_MASTER_KEY option is valid only when it is set by a trusted application.
VU_UNTIL_SUCCESS Keep calling into the LAP until the user cancels, or until the user successfully logs in.
pExtended
Reserved. Must be zero.

Return Values

Returns TRUE if the user is verified, and FALSE if the user is not verified. To get extended error information, call GetLastError.

Remarks

If the user cancelled the verification request, GetLastError will return ERROR_CANCELLED. If the user failed authentication, GetLastError returns ERROR_NOT_AUTHENTICATED.

VerifyUser can be called by any application, whether it is trusted or untrusted.

Example Code

The following code example shows how you can use VerifyUser to authenticate the user before calling any secure function. CallSecureFunction and TellUserVerificationFailed in this code example are user-defined functions.

  if (VerifyUser(&AEKeyForFoo,"App A", hMyWindow, VU_UNTIL_SUCCESS, 0))
    CallSecureFunction(); // User successfully authenticated
  else 
    TellUserVerificationFailed(GetLastError())); // User failed verification or cancelled call into LAP

Requirements

OS Versions: Windows CE 5.0 and later.
Header: lass.h.
Link Library: Coredll.lib.
