Setting an AE policy

After installing an AE, you must set it. An AE policy defines the policy that is used to verify the user. The subkeys AEFrequencyType and AEFrequencyValue in the HKEY_LOCAL_MACHINE\Comm\Security\LASSD\AE registry key are used to specify the desired settings. For more information about other related registry settings, see LASS Registry Settings.

AEFrequencyType and AEFrequencyValue are the methods that are available to control the policy associated with the AE. AEFrequencyValue depends on the value of AEFrequencyType. AEFrequencyType controls the type of frequency counter used for AE.

AEFrequencyType Named Constant AEFrequencyType Value Description
FT_Every_FV 0 Authenticate user every AEFrequencyValue times. The policy for AE_EVERYTIME is AEFrequencyType = 0 and AEFrequencyValue=0 which causes every call to AE_EVERYTIME to authenticate.

When AEFrequencyType is set to 0, AEFrequencyValue can be any one of the following values:

  • 0xFFFFFFFF : Never call into LAP
  • 0 : Call LAP everytime VerifyUser is called
  • 1 : Call LAP every other time VerifyUser is called
  • 2 : Call LAP every three times VerifyUser is called
FT_Minutes_Since_Any_AE_Verified 2 Authenticate user if there hasn't been a successful call to VerifyUser for any AE in the last AEFreqencyValue minutes.

For example, if AEFrequencyType is 2 and AEFrequencyValue is 5, then the user will be authenticated if there has not been a successful call to VerifyUser for any AE in the last 5 minutes.
FT_Minutes_Since_This_AE_Verified 3 Authenticate if there hasn't been a successful call to VerifyUser for this AE in last AEFreqencyValue minutes.

For example, if AEFrequencyType is 2 and AEFrequencyValue is 5, then the user will be authenticated if there has not been a successful call to VerifyUser for a given AE in the last 5 minutes

For convenience, the following common AEs are predefined for LASS.

AE name Description
AE_EVERYTIME Will force an Authentication every time it is called.
AE_DEFAULT_POLICY Use the default LASS policy, may be low or high depending on the environment and user settings.

LASSReloadConfig must be called or the device must be rebooted for changes to take effect.
