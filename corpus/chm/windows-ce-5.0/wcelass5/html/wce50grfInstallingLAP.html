Installing a LAP

LAPs are installed by using the registry. To make a LAP available to the system, you must add a subkey to the HKEY_LOCAL_MACHINE\Comm\Security\LASSD\LAP registry key and specify the name of the LAP DLL. The following code example shows examples of installed LAPs.

; Install a password LAP
[HKEY_LOCAL_MACHINE\Comm\Security\LASSD\LAP\lap_pw]
   "Dll"="lap_pw.dll"
; Install a smart card LAP
[HKEY_LOCAL_MACHINE\Comm\Security\LASSD\LAP\lap_scard]
   "Dll"="lap_smartcard.dll"

In these two examples, lap_pw and lap_scard are the LAP identifiers that will be used to set the active LAP.

LASSReloadConfig must be called or the device must be rebooted for changes to take effect.
