Comparing LASS and Password Authentication

The following table shows how a LASS authentication compares with password authentication.

Password authentication LASS authentication
A password is the only mechanism that is available to authenticate the user. LAPs are replaceable authentication mechanisms. They include password, smartcard, fingerprint, and more for authentication.
CheckPassword is used to authenticate a user. VerifyUser is used to authenticate a user.
SetPassword prompts the user for a password. CreateEnrollmentConfigDialog is used to obtain information such as a password, or a fingerprint.
SetPasswordActive and SetPasswordStatus are used to configure if passwords are necessary at startup. Authentication Events (AEs) provide more versatility for setting policies that determine when the user verification should occur.
