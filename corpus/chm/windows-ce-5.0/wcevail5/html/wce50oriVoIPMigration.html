VAIL Migration

The following items are important to understand when migrating an OS design that uses VAIL:

  • The VoIP Application Interface Layer (VAIL) Catalog item exists in the Voice over IP Phone Services Catalog tree beneath Core OS / Windows CE devices.

    In past versions this Catalog item was called Voice over IP Phone (VoIP) and existed in the Networking Features tree beneath Core OS / Windows CE devices / Communication Services and Networking.

  • The provisioning mechanism, APIs, and SYSGEN variables have changed. For detailed information about this change, see Migrating to New Initialization and Provisioning APIs.
  • Windows CE .NET 4.2 included a SYSGEN variable called SYSGEN_VOIPPHONE. This variable included both the VAIL and RTC Client API Catalog items. This SYSGEN variable has been removed from Windows CE 5.0. To include the same functionality in a Windows CE 5.0 OS design, set the appropriate VAIL and RTC Client API SYSGEN variables for the functionality you want in your OS design. For more information about VAIL and RTC Client API SYSGEN variables, see VAIL OS Design Development and RTC Client API OS Design Development.
