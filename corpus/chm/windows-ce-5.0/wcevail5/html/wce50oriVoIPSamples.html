VAIL Samples

The VAIL source code is provided in the %_WINCEROOT%\Public\VoIP\Oak\Phone\VAIL directory.

The Telephony User Interface (TUI) application is a fully functional and customizable sample application that offers standard and advanced phone functionality, and uses the VAIL heavily.

To view the TUI and see how it operates, create an IP phone for a CEPC or for the Emulator. For information, see How to Create a Default IP Phone on a CEPC and How to Create a Default IP Phone on an Emulator.

TUI source code is in %_WINCEROOT%\Public\VoIP\Oak\Phone\TUI.

For more information about TUI functionality, see Telephony User Interface (TUI). For general information about the IP phone functionality in Windows CE, see Developing an IP Phone.
