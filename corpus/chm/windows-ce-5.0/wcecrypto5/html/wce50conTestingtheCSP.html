Testing the CSP

Testing the CSP uses the digital signature provided by Microsoft and Windows CE. You can use the Platform Builder Kernel Debugger, which disables signature verification. To ensure that the Microsoft-provided digital signature works, however, it is best to test without the debugger.

To test the CSP

  1. Install the CSP, using the setup program discussed in Writing a CSP.
  2. Run test code that makes calls to the CSP by using CryptoAPI.
