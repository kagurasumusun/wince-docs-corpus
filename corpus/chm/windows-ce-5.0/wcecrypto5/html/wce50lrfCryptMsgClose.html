CryptMsgClose

This function closes a cryptographic message handle. At each call to this function, the reference count on the message is reduced by one. When the reference count reaches zero, the message is fully freed.

BOOL WINAPI CryptMsgClose(
  HCRYPTMSG hCryptMsg
);

Parameters

hCryptMsg
[in] Handle of the cryptographic message to be closed.

Return Values

If the function succeeds, the return value is non-zero (TRUE).

If the function fails, the return value is zero (FALSE). For extended error information, call GetLastError.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Wincrypt.h.
Link Library: Coredll.lib.
