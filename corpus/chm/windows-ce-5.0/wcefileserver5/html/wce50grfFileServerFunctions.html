File Server Functions

The following table shows the File Server functions.

Programming element Description
Change_ACL Changes the list of allowed users for a share.
Add_Share Creates a new share for a file or print server.
Del_Share Deletes a share.
List_Connected_Users Copies a set of strings of type MULTI_SZ into a buffer. Each string specifies a user who is connected to the file server.
QueryAmountTransfered Retrieves the number of bytes that have been transferred to and from the server.
