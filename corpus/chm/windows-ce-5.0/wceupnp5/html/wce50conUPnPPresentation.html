UPnP Presentation

In a UPnP-enabled network, a control point can control a device or view its status through a presentation HTML page (or series of pages), which the UPnP device returns. A presentation page enables people to view and control a device through an interface that the device provides, rather than through an interface that a control point builds and provides.

Presentation pages are not required; if a device does not have a presentation page, it can still be controlled through standard UPnP control messages.

If the device supports a presentation page, the device description document contains the URL for the presentation page in the <presentationURL> tag. (The <presentationURL> tag is required; if the device has no presentation page, the tag should be empty.)

To retrieve the presentation page, the control point submits an HTTP GET request using the presentation URL.
