UPnP Generic Control Point and Device Samples

Windows CE includes a few different samples that demonstrate use of the generic (that is, non-DCP-specific) UPnP Control Point and Device Host APIs.

These samples are located in the following directories.

  • %_WINCEROOT%\Public\Servers\Oak\Samples\UPnP\DiscoverService
  • %_WINCEROOT%\Public\Servers\SDK\Samples\UPnP\Device
  • %_WINCEROOT%\Public\Servers\SDK\Samples\UPnP\GenericUCP
  • %_WINCEROOT%\Public\Servers\SDK\Samples\UPnP\UPnPSpy
