IUPnPDescriptionDocument::ReadyState

This method returns the status of the document load operation. This status indicates the state of the IUPnPDescriptionDocument::Load or IUPnPDescriptionDocument::LoadAsync method. These states are the standard ready-state values.

HRESULT get_ReadyState(
  LONG* plReadyState
);

Parameters

plReadyState
[out] Receives a reference to the ready state. The values this parameter can receive are:
plReadyState Value Description
READYSTATE _COMPLETED The load operation is finished.
READYSTATE _INTERACTIVE The load operation is not yet completed. Some data may be available.
READYSTATE _LOADED The load operation has been initialized.
READYSTATE _LOADING The load operation is in progress.
READYSTATE_UNINITIALIZED The load operation has not been started.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
