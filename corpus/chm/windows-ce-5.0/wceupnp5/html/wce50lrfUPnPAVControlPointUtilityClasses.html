UPnP AV Control Point Utility Classes

The UPnP AV Framework contains classes that provide additional functionality to control point applications. For an overview of all of the classes provided by the UPnP AV Framework, see UPnP AV Framework Class Organization.

Note   The UPnP AV Framework defines an object structure used by the parser object. Because object is a structure, it is documented in UPnP AV Structures.

The following table shows the UPnP AV Framework control point utility classes.

Class Description
MediaRendererDevice Used by UPnP AV control points to retrieve an IConnectionManager reference.
MediaServerDevice Used by UPnP AV control points to retrieve IConnectionManager and IContentDirectory references.
parser Provides an object-oriented representation of a DIDL-Lite XML fragment.
