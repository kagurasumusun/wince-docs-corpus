UPnP Samples

Windows CE includes a variety of samples that demonstrate the UPnP functionality provided by Windows CE.

In This Section

UPnP Generic Control Point and Device Samples
Introduces samples that demonstrate use of the generic UPnP Control Point and Device Host APIs.
UPnP AV Renderer Sample
Explains the AV renderer sample, which uses the AV Device API Catalog item to implement a UPnP AV MediaRenderer device.
UPnP AV Control Point Sample
Explains the AV control point sample, which uses the AV Control Point API Catalog item to implement a basic UPnP AV control point.
UPnP Internet Gateway Device Schema Sample
Introduces the included sample implementation of the Internet Gateway Device (IGD) DCP.
