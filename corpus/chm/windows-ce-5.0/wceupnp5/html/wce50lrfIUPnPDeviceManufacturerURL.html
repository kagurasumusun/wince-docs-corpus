IUPnPDevice::ManufacturerURL

This method returns the URL for the manufacturer's Web site.

HRESULT get_ManufacturerURL(
  BSTR* pbstr
);

Parameters

pbstr
[out] Receives a reference to a string that contains the URL. This string must be released when it is no longer required. If the device does not specify this URL, this parameter is set to NULL.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Remarks

This property is optional and can return NULL.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
