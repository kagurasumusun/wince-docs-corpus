Universal Plug and Play (UPnP)

The Universal Plug and Play (UPnP) implementation in Microsoft® Windows® CE provides an architectural framework for creating self-configuring, self-describing devices and services. Because UPnP supports automatic discovery, devices managed by UPnP require no set up by users or network administrators. UPnP enables a device to dynamically join a network, obtain an IP address, and convey its capabilities upon request.
