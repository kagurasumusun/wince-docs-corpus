Simplified Chinese MSPY 3.0 IME Configuration

The following table shows MSPY 3.0 functionality that is configurable through the registry.

Functionality Description
EUDP support Enable or disable EUDP for the selected input method.
Accelerator behavior Always display accelerator in the candidate list or hide the accelerator when the Software-based Input Panel (SIP) is active.
Default input mode Set default Pinyin input mode - Full Pinyin or Shuang Pin.
Status window behavior Display or hide the status window.
Candidate list orientation Set the orientation of the candidate list to vertical or horizontal.
Property UI behavior Display or hide the Property button on the status window.
Auto-switch input mode according to SIP state Specify the input mode for the following SIP states:
  • Activated
  • Deactivated

For more information about how to configure these settings through the registry, see Simplified Chinese MSPY 3.0 IME Configuration Registry Settings.

Windows CE also allows you to configure the hot keys for your MSPY 3.0 implementation through the registry. For more information, see Simplified Chinese MSPY 3.0 IME Hot Key Registry Settings.
