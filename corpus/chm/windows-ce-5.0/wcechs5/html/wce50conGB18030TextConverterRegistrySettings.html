GB18030 Text Converter Registry Settings

The HKEY_LOCAL_MACHINE\NLS\Codepage registry key is used to set the GB18030 text converter for the PRC. This registry key has the following setting.

Value : type Description
54936 : REG_SZ Default set to "gb18030.dll" to use the GB18030 text converter for the PRC.
