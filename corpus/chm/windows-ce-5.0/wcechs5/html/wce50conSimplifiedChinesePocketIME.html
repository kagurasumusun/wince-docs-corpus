Simplified Chinese Pocket IME

Microsoft® Windows® CE supports the Simplified Chinese Pocket Input Method Editor (IME). Pocket IME is a small IME that can support both keyboard systems and keyboard-less embedded systems that have small screens and a minimum memory footprint.

The Simplified Chinese Pocket IME provides options for customizing its behavior in your OS design. The following list describes functionality that the IME supports:

  • Source code for the IME user interface (UI) module is included as a sample. The Pocket IME kernel conversion module exposes interfaces that allow OEMs to implement their own UI module.
  • Registry keys for configuring the default behavior of the IME can be set by the OEM.
