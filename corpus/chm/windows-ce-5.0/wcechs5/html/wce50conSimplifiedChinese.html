Platform Builder for Microsoft Windows CE 5.0  

Chinese (Simplified)

Windows CE provides support for the Simplified Chinese locale.

In This Section

Chinese (Simplified) OS Design Development
Provides information about the Simplified Chinese locale that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement Simplified Chinese, and Simplified Chinese implementation considerations.
Simplified Chinese MSPY 3.0 IME
Provides information about configuring Microsoft Pinyin (MSPY) Input Method Editor (IME) 3.0 for Simplified Chinese, managing the End User-Defined Phrase (EUDP), and setting the input method programmatically. Includes reference pages for the MSPY 3.0 functions.
Simplified Chinese Pocket IME
Describes the architecture of the Simplified Chinese Pocket Input Method Editor (IME) technology, and outlines how OEMs can supply a custom module for this IME.
GB18030 Data Converter
Provides an overview of the GB18030 data converter that converts GB18030-based content to a native encoding that the operating system is able to display.
Chinese (Simplified) Registry Settings
Provides information about the configurable registry settings for Simplified Chinese MSPY 3.0 and Simplified Chinese Pocket IME.
Chinese (Simplified) Samples
Provides sample-related information for Simplified Chinese.

Related Sections

Input Method Manager (IMM)
Provides an overview of the Input Method Manager (IMM) technology, the import method system that Windows CE supports, and the Input Method Editor (IME) user interface. Shows how to use the IMM API to customize IME behavior.
