Simplified Chinese Pocket IME UI Configuration Registry Settings

You can use the registry to configure some of the settings for the Simplified Chinese Pocket IME UI.

The following table shows the named values for the HKEY_CURRENT_USER\Control Panel\Chinese IME UI\Settings registry key.

Value : type Description
ShowState : REG_DWORD Default set to zero (0). Setting this value to 1 will display the status window for Simplified Chinese Pocket IME. Setting this value to 0 will hide the status window.
AutoCandAccel : REG_DWORD Default set to 1. Setting this value to 1 will hide the accelerators when the Software-based Input Panel (SIP) is active. Setting this value to zero (0) will display the accelerators.
