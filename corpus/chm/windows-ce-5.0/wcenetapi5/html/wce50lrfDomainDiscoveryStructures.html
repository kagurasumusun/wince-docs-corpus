Domain Discovery Structures

The following table shows the Domain Discovery structures with a description of the purpose of each.

Programming element Description
DOMAIN_CONTROLLER_INFO Used with the DsGetDcName function to receive data about a domain controller.
DSROLE_PRIMARY_DOMAIN_INFO_BASIC Used with the DsRoleGetPrimaryDomainInformation function to contain domain data.
