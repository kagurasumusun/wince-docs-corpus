Domain Discovery Implementation Considerations

You can include the Domain Discovery Catalog item in your OS design by choosing the item from the Catalog. Choosing this Catalog item sets the appropriate Sysgen variables for enabling Domain Discovery.

The following table shows the Sysgen variables that enables Domain Discovery.

Sysgen variable Description
SYSGEN_NETAPI32 When this variable is set, Domain Discovery is included in the OS design.
SYSGEN_REDIR When this variable is set, Windows Networking API/Redirector (SMB/CIFS) is included in the OS design. If you want to enable flat domain name querying, you must include this Catalog item in your OS design.
