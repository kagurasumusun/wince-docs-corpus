ICS Samples

Internet Connection Sharing (ICS) provides support for Internet address sharing through Network Address Translation (NAT). A code sample for the NAT editor is located in the %_WINCEROOT%\Public\Common\oak\drivers\netsamp\ipnat\editsamp directory. For more information about the NAT Editor, see NAT Editor.

A sample remote user interface enables users to view the event logs generated by the Gateway Logging engine. A code sample for this remote UI is located in the %_WINCEROOT%\public\servers\oak\samples\logging\logger directory. For more information about the Gateway Logging engine, see Gateway Logging.

ICS samples have not been tested and are not intended for production use.
