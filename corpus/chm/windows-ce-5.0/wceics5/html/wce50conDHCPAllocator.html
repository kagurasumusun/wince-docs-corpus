DHCP Allocator

ICS can configure clients on the network automatically by using DHCP. Although Windows CE does not support the services required to operate a full DHCP server, it does support a subset of these services called the DHCP allocator. Windows CE implements the DHCP allocator as part of the ipnat module (Ipnat.dll).

Typically, the DHCP allocator is contained in a gateway device. The gateway always checks if another DHCP Server is available. A full DHCP Server always supercedes the gateway DHCP allocator.
