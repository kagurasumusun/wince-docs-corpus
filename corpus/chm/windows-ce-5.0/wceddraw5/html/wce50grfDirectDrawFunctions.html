DirectDraw Functions

The following topics contain information about the following DirectDraw global functions.

Programming element Description
DirectDrawCreate This function creates an instance of a DirectDraw object.
DirectDrawCreateClipper This function creates an instance of a DirectDrawClipper object not associated with a DirectDraw object.
DirectDrawEnumerate This function is superseded by the DirectDrawEnumerateEx function.
DirectDrawEnumerateEx This function enumerates all DirectDraw devices installed on the system.
