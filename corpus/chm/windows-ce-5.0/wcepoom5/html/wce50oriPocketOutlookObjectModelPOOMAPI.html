Pocket Outlook Object Model (POOM) API

The Pocket Outlook Object Model (POOM) functionality in Windows® CE uses a modified and set of reduced functionality to permit Microsoft® Outlook® data to be shared between a desktop computer and the more-limited storage space on a Windows CE-based device. The Pocket Outlook Object Model (POOM) is based on the Outlook model.

Applications access Outlook data through the Pocket Outlook Object Model. This COM-based library provides an object hierarchy that simplifies the process of creating, modifying and displaying appointments, tasks and contacts.
