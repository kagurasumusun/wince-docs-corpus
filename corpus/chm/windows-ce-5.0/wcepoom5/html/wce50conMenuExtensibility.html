Menu Extensibility

The Calendar, Tasks, and Contact applications support menu add-ins for external applications. A menu item appears on the Tools menu for each of your add-ins. Selecting a menu item calls a function in a registered dynamic-link library (DLL), passing the object identifiers of those items selected in the application when the menu item was selected.

To register your application, you need to create a registry key under the HKEY_LOCAL_MACHINE root. The registry key will exist under Software\Microsoft\PimApps\PimExtensions\PIMAPP\AddIns and can be named whatever you want. To avoid conflict with other add-ins, it is suggested that your key contain your company's name. PIMAPP should be replaced with Contacts, Tasks, or Calendar, depending on which application you want your menu to appear under.

This key requires two entries. The first is DLL, whose value should have the name of your DLL. The second is Menu, whose value is the menu name you want displayed on the Tools menu. Because several developers might add menu items, you should choose a name that includes the name of the application to reduce the change of a conflict.

For example, if you have a phone dialer application that you want to register in the Contacts application, you might create the registry key Software\Microsoft\PimApps\PimExtensions\Contacts\AddIns\MicrosoftDialer. The following code example shows what the entries off this registry key might be.

DLL\"dialer.dll"
Menu\"Dial Contact"

The DLL you register must expose the following function, which is called when the user selects your menu option.

void CePimCommand (HWND hWnd, PIMTYPE ptData, UINT uDataCount, HANDLE *rghData, void *pReserved);

PIMTYPE is an enumeration, defined as follows.

typedef enum tagPIMTYPE
{
  PT_CALENDAR = 0,
  PT_TASKS,
  PT_CONTACT
} PIMTYPE;
Parameter Description
hWnd Application window handle.
ptData The application calling this function.
uDataCount The number of items in rghData array.
*rghData A Windows CE object identifier array indicating which items are currently selected.
*pReserved Reserved parameter. NULL in current version.

You can manipulate items from their object identifier by calling GetItemFromOid in the Application object.
