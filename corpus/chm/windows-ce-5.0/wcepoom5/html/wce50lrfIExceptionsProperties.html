IExceptions Properties

The IExceptions interface reads the properties described in the following table.

Properties in Vtable Order

Property Description
Count 
HRESULT get_Count
(/* [out] */ int *piCount);
 Returns the number of items in the collection.
Application 
HRESULT get_Application
(/* [out] */ IPOutlookApp **ppIPOutlookApp);
 Returns a pointer to the main Pocket Outlook application object.

Return Values

Each property method supports the standard HRESULT return values, including S_OK.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Pimstore.h.
Link Library: Pimstore.lib.
