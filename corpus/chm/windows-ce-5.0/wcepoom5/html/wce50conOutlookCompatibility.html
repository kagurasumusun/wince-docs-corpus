Outlook Compatibility

The Pocket Outlook Application object property was added to allow independent software vendors to know whether the Windows CE-based device is partnered with a Microsoft Schedule+ or Outlook desktop. The reason is that tasks behave differently, depending on whether they are compatible with Schedule+ or Outlook.

If you are partnered with a Schedule+ desktop, tasks with a None start date must also have a None due date. Recurrences are computed with respect to the due date. If you are partnered with an Outlook desktop, recurrences are computed with respect to the start date.
