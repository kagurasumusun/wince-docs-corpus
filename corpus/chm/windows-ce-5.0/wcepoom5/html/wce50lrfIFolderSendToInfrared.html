IFolder::SendToInfrared

This method transmits items in the Infrared folder over the IR port. This method is supported only for the Infrared folder.

HRESULT SendToInfrared ();

Return Values

S_OK indicates success. E_ABORT indicates the user canceled the infrared transfer. If an error occurs, the appropriate HRESULT is returned.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Pimstore.h.
Link Library: Pimstore.lib.
