Pocket Outlook Object Model Security

Applications access Outlook data through the Pocket Outlook Object Model (POOM). POOM is a COM-based library that provides an object hierarchy that simplifies the process of creating, modifying and displaying appointments, tasks, and contacts. Because Outlook data is being accessed through POOM, the privacy of your Outlook data is potentially at risk if a rogue application gains access to the device.

Best Practices

Download applications only from a trusted source

Do not download applications to your device if they are not from a trusted source, because a rogue application can potentially gain control of your private data and corrupt it or use it in a wrong manner.

Default Registry Settings

There are no configurable registry settings for POOM.

Ports

No specific ports are used for POOM.
