Korean Soft Keyboard IM Registry Settings

The HKEY_CURRENT_USER\ControlPanel\SIP registry key is set when using the soft keyboard Korean IM and SIP. The following table shows the named values for the registry key.

Value : type Description
AllowChange : REG_DWORD Default set to 1. Specifies whether applications can change the SIP settings or not.
DragStyle : REG_DWORD Default set to 1. Specifies whether the SIP is dragable or not.
DefaultIm : REG_SZ Default set to "{8D018493-3945-4c6a-A3B1-BABAEEC568D6}"for the soft keyboard Korean IM. Specifies the CLSID for the input method.
