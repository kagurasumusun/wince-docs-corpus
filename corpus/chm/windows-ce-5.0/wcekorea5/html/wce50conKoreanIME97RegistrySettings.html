Korean IME97 Registry Settings

The following registry keys are set when the locale is 0412 and IME97 is used.

The following table shows the named values for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0010412 registry key.

Value : type Description
Layout Text : REG_SZ Default set to "KBD e0010412". Specifies the layout text settings.
Ime File : REG_SZ Default set to "mshime97.dll". Specifies the name of the DLL for the IME.

The following table shows the named values for the HKEY_CURRENT_USER\Keyboard Layout\Preload\1 registry key.

Value : type Description
@ : REG_SZ Default set to "e0010412." Specifies the keyboard layout settings for IME.

The following table shows the named values for the HKEY_CLASSES_ROOT\CLSID\{E9FBDEF9-A48D-4C68-9D96-E4EEB922938A}\InprocServer32 registry key.

Value : type Description
@ : REG_SZ Default set to "\\windows\\kimeui.dll." Specifies the name of the DLL for IME 97.
