Exchange Client Samples

The Exchange Client source code is provided in the %_WINCEROOT%\Public\VoIP\Oak\Phone\OWAExchangeClient directory.

The Exchange Client provides functionality to the Telephony User Interface (TUI) Catalog item.

TUI includes full source code and provides a full-featured user telephony interface.

TUI uses the following Exchange Client functionality:

  • Global address list (GAL) search
  • Contacts retrieval
  • Free/busy data retrieval

To see code that uses the Exchange Client, look at the TUI source code for instances of IExchangeClient and other Exchange Client interfaces.

TUI source code is located at %_WINCEROOT%\Public\VoIP\Oak\Phone\TUI.

You can examine the source code for the Exchange Client at %_WINCEROOT%\Public\VoIP\Oak\Phone\OWAExchangeClient.
