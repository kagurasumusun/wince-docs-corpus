RDP Samples

The file redirection filter is implemented by using a file system driver. A sample driver, Filterfsd.dll, that contains an implementation that limits file redirection to external storage is provided in public code. You can customize this sample driver to filter the file system in a manner that suits your needs.

The TS CAL Maintenance tool is provided in public code in the following directory: %_WINCEROOT%\Public\Rdp\Oak\Uit\licinfo.cpp. If it meets your needs for CAL maintenance, you can use it as it is.
