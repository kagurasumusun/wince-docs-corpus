IMsRdpClientAdvancedSettings Property Descriptions

The IMsRdpClientAdvancedSettings interface enables you to obtain or set a number of properties specifying the advanced settings for an RDP client. This interface was added for RDP clients (version 5.1 and later).

For an alphabetic list of the properties, see IMsRdpClientAdvancedSettings Properties.

The properties of the IMsRdpClientAdvancedSettings interface can be grouped as follows.

  • Bitmap and Caching Properties
  • Connection, Timeout, Interval and Event Properties
  • Keyboard and Mouse Properties
  • Redirection Properties
  • Other

Unless otherwise noted, these properties cannot be set when the control is connected.
