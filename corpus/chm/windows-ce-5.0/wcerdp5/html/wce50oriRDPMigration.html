RDP Migration

Windows NT Terminal Server uses RDP 4.0 as its native data protocol. Windows 2000 Terminal Services uses RDP 5.0, while Windows XP Professional Edition uses RDP 5.1. Microsoft Windows CE 5.0 uses RDP 5.5. All versions are compatible, so Microsoft® Windows® CE clients can connect to any of these servers.
