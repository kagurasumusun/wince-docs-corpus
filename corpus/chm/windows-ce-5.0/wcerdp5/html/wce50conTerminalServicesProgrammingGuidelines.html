Terminal Services Programming Guidelines

Although most Windows applications do not need to be modified to run correctly in the Terminal Services environment, some perform better than others. The following topics offer guidelines for developing applications that perform well under Terminal Services.

Peripheral Hardware

Terminal Services Client Configuration through the .rdp File

Some guidelines are simply good programming practices for any applications in any environment. However, some optimizations, such as limiting graphic effects, are appropriate only when running under Terminal Services.
