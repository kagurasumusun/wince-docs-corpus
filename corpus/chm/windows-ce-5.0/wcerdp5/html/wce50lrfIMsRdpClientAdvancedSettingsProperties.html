IMsRdpClientAdvancedSettings Properties

You can set and retrieve a set of properties using the IMsRdpClientAdvancedSettings interface. Unless otherwise indicated, access is read/write. This interface was added for RDP clients (version 5.1 and later).

For a description of each property, information about its syntax, and a functional grouping of the properties, see IMsRdpClientAdvancedSettings Property Descriptions.

IMsRdpClientAdvancedSettings derives from the IMsTscAdvancedSettings interface. For additional properties, see the IMsTscAdvancedSettings interface.
