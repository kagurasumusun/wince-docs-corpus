Platform Builder for Microsoft Windows CE 5.0  

OID_PAN_CONNECT

This object identifier (OID), when set, connects to the specified network. You can specify the network by passing the service identifier as a parameter in a standard GUID format. You must also specify the address of the Bluetooth device in the BD_ADDR structure.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: bt_ddi.h
