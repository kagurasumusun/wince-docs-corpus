PAN Profile Object Identifiers

The following table shows the Bluetooth Personal Area Network (PAN) profile object identifiers with a description of the purpose of each.

Programming element Description
OID_PAN_CONNECT This object identifier connects a Bluetooth device to the specified network.
OID_PAN_DISCONNECT This object identifier disconnects a Bluetooth device from the specified network.
OID_PAN_AUTHENTICATE This object identifier sets or resets authentication for the specified Bluetooth PAN adapter.
OID_PAN_ENCRYPT This objects identifier sets or resets encryption for the specified Bluetooth PAN adapter.
