Platform Builder for Microsoft Windows CE 5.0  

BTH_HCI_IOCTL_GET_NUM_UNSENT

This IOCTL retrieves the number of packets pending before being sent to the card.

Parameters

hDeviceContext
[in] Device context handle.
fSelector
[in] Equals BTH_HCI_IOCTL_GET_NUM_UNSENT.
cInBuffer
[in] Equals 0.
pInBuffer
Not used.
cOutBuffer
[in] Equals 4.
pOutBuffer
[in] Must point to an aligned unsigned integer.

[out] Gets the number of packets.

pcDataReturned
[out] Equals cOutBuffer.

Return Values

If the call succeeds, the return value is ERROR_SUCCESS.

If the function fails, the following table shows a list of possible error values.

Error value Description
ERROR_INVALID_PARAMETER Parameters are invalid (buffers are not properly sized).
ERROR_SERVICE_NOT_ACTIVE HCI is not active or there is no hardware.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bt_ddi.h.
