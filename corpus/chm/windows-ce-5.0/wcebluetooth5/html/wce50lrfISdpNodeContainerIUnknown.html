ISdpNodeContainer:IUnknown

This interface manages the contents of a node.

Methods

The following table shows the methods for this interface in alphabetical order. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Method Description
AppendNode Appends NodeData at pData to the end of the container.
CreateFromStream Creates a record from a stream.
CreateStream Creates a stream from a record.
GetNode Retrieves the contents of a node.
GetNodeCount Retrieves the number of nodes in the Service Discovery Protocol (SDP) container.
GetNodeStringData Retrieves the string data of a node.
GetStreamSize Retrieves the size of the stream.
GetType Retrieves the SDP container, sequence, or alternative type.
LockContainer Locks or unlocks the container.
SetNode Modifies the contents of a node.
SetType Sets the SDP container, sequence, or alternative type.
Walk Walks the SDP container and the containers within it.
WriteStream Converts the contents of the container into a valid, well-formed raw SDP stream.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
