BTH_HCI_IOCTL_HANDLE_AUTHENTICATED

This IOCTL retrieves the authentication status of the connection.

Parameters

hDeviceContext
[in] Device context handle.
fSelector
[in] Equals BTH_HCI_IOCTL_HANDLE_AUTHENTICATED.
cInBuffer
[in] Equals 2.
pInBuffer
Must be an aligned pointer to an unsigned short handle.
cOutBuffer
[in] Equals 4.
pOutBuffer
[in] Must point to an aligned unsigned integer.

[out] Contains TRUE if the connection is authenticated.

pcDataReturned
[out] Equals cOutBuffer.

Return Values

If the call succeeds, the return value is ERROR_SUCCESS.

If the function fails, the following table shows a list of possible error values.

Error value Description
ERROR_CONNECTION_INVALID The connection handle was not found.
ERROR_INVALID_PARAMETER Parameters are invalid (buffers are not properly sized).
ERROR_SERVICE_NOT_ACTIVE HCI is not active or there is no hardware.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bt_ddi.h.
