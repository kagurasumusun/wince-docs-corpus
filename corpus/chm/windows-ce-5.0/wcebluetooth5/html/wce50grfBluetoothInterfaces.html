Bluetooth Interfaces

The following table shows the Bluetooth interfaces with a description of the purpose of each.

Programming element Description
ISdpNodeContainer This interface manages the contents of a node.
ISdpRecord This interface manages the contents of an SDP record.
ISdpStream This interface manages streamed data.
ISdpWalk This interface walks the stream.
