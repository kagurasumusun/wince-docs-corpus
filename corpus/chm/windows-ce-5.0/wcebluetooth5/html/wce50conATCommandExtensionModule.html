AT Command Extension Module

The AT Command Extension module enables you to extend the default command parsing and handling provided by the Audio Gateway Core Component. This extension module makes available a set of functions that you can use to implement custom parsing of AT commands and override the default responses to commands by creating custom handlers.

The following list shows the AT Command Extension functions that are called by the Audio Gateway (AG) service.

  • BthAGATSetCallback
  • BthAGATHandler
