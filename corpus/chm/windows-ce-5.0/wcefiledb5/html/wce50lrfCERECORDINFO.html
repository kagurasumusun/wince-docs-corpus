CERECORDINFO (CEDB)

This structure contains information about a record object. 

typedef struct _CERECORDINFO {
  CEOID oidParent; 
} CERECORDINFO;

Members

oidParent
Object identifier of the parent database.

Remarks

Earlier versions of Windows CE assigned object identifiers to objects in other file systems, such as the FAT file system. These object identifiers were guaranteed to be unique within a volume, but not across multiple volumes. In Windows CE 3.0 and later, only objects in the object store have valid, unique object identifiers and the object store is the only volume that can return an object identifier.

Requirements

OS Versions: Windows CE 1.01 and later.
Header: Windbase.h.
