Implementing a Service Provider

The values for the following registry key define a service provider.

HKEY_LOCAL_MACHINE\Software\Microsoft\Windows CE Services\Services\Synchronization\All\object-type
Key (String): Display Name
Key (String): Plural Name
Key (String): Default Icon

After you register a service provider, ActiveSync automatically adds it to the list of service providers in the New Partnership and Options dialog boxes. ActiveSync also displays the default icon for the service provider if it is specified and available. If no icon is available, ActiveSync uses a generic icon. When a service provider is enabled, it is listed in the main window of ActiveSync.
