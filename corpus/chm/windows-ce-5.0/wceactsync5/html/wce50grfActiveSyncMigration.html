ActiveSync Migration

This topic contains information useful for migrating this functionality from earlier versions of Windows CE.

For general migration information, see Migrating from an Earlier Version of Windows CE.

Changes Effective in Windows CE .NET 4.2

  • SYSGEN_PIM is no longer valid in Windows CE .NET 4.2 and later. If you have SYSGEN_PIM set to 1 in your OS design, the build system in Windows CE .NET 4.2 will cause SYSGEN_AS_BASE, SYSGEN_AS_FILE, SYSGEN_AS_MAIL, SYSGEN_AS_PIM and SYSGEN_PMAIL to be set to 1.

    There is no support for SYSGEN_PIM in Windows CE 5.0.
