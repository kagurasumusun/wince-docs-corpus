OBJTYPEINFO

This structure is used to store information about an object type.

typedef struct tagObjTypeInfo {
  UINT cbStruct;
  OBJTYPENAMEW szObjType;
  UINT uFlags;
  WCHAR szName[80];
  UINT cObjects;
  UINT cbAllObj;
  FILETIME ftLastModified;
} OBJTPYEINFO, *POBJTYPEINFO;

Members

cbStruct
[in] Size of the structure in bytes.
szObjType
[in] Null-terminated string that contains the name of the object type.
uFlags
Reserved.
szName
[out] Null-terminated string that contains the name of a file system object storing all these objects.
cObjects
[out] Number of existing objects of this type.
cbAllObj
[out] Total number of bytes used to store existing objects.
ftLastModified
[out] Specifies the last time any object was modified.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Cesync.h.
