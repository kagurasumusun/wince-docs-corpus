ActiveSync Functions

The following table shows the ActiveSync functions, with a description of the purpose of each.

Programming element Description
CeSvcAdd This function adds a handle.
CeSvcClose This function closes a handle previously returned by CeSvcOpen or CeSvcOpenEx.
CeSvcDelete This function deletes a handle.
CeSvcDeleteVal This function removes a named value from the specified registry key.
CeSvcEnumProfiles This function enumerates all the profiles currently stored in the registry.
CeSvcGetBinary This function reads a binary value from a registry subkey and copies the data into a buffer.
CeSvcGetDword This function reads a DWORD value from a registry key and copies the data into a buffer.
CeSvcGetString This function reads a string value from a registry subkey and copies the data into a buffer.
CeSvcOpen This function opens and returns a handle to the registry root for a specified logical position, as specified by CEUTIL constants.
CeSvcOpenEx This function, given a handle to an already open registry, opens a nested subkey underneath.
CeSvcQueryInfo This function requests information about a service.
CeSvcRemove This function removes a handle.
CeSvcSetBinary This function writes a binary value to a registry subkey.
CeSvcSetDword This function writes a DWORD value to a registry subkey.
CeSvcSetString This function writes a string value to a registry subkey.
InitObjType This function allows an ActiveSync service provider on the device to either initialize data and pass a pointer to the IReplObjHandler interface at loading, or free allocated resources at termination.
Install_Exit This function is called after installation completes. It is used for operations such as handling errors that occurred during installation or launching the application.
Install_Init This function is called before installation begins. It is used for operations such as checking the version of an application during reinstallation or seeing whether a dependent application is present.
ObjectNotify This function is called by the server when there is a change or deletion to an object in the device's object store.
ReportStatus The server calls this function to obtain status information on the Windows CE-based platform synchronization objects.
Uninstall_Exit This function is called after the uninstallation completes. It can be used for custom operations such as saving database data into a file and deleting the database, informing the user on where the user data files are stored, or informing the user on how to reinstall the application.
Uninstall_Init This function is called before the uninstallation begins. It can be used for custom operations such as closing a running application.
