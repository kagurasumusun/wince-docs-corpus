Platform Builder for Microsoft Windows CE 5.0  

IPegasusFileFilter:IUnknown

This interface is implemented by a file converter DLL. The Pocket Internet Explorer uses OLE to create an instance of an IPegasusFileFilter object.

Method Description
FilterOptions Displays a dialog box that lets the user select among the file filtering options supported by a file filter.
FormatMessage Formats a message string.
NextConvertFile Called by the Pocket Internet Explorer when the user selects a conversion type from the Pocket Internet Explorer conversion selection dialog box.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Replfilt.h.
Link Library: Coredll.lib.
