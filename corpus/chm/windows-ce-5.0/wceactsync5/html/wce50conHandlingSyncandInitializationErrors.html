Handling Sync and Initialization Errors

Except for general service-provider errors, ActiveSync does not display error messages during synchronization. When errors occur that prevent synchronization of individual items, the items are recorded as unresolved. ActiveSync displays the total number of unresolved items on the summary pane and the count of unresolved items for each service provider in the details pane. The ActiveSync status icon in the top right corner of the summary pane also displays a red exclamation mark.

When a user clicks Resolve items, either on the Tools menu or in the summary pane, ActiveSync runs a synchronization cycle limited to those items marked as unresolved. This cycle proceeds through the following steps for each unresolved item.

  1. The service provider tries to synchronize the item.
  2. If the problem was transient and the synchronization is successful, ActiveSync proceeds to the next unresolved item.
  3. If synchronization is unsuccessful, the service provider displays a dialog box that prompts the user to resolve the problem.
  4. The user either chooses a resolution and closes the dialog box, or dismisses the dialog box without making a choice.
  5. Based on the user's selection, the service provider attempts to synchronize the item. The service provider displays no dialog boxes or messages.

After completing these steps for each unsynchronized item, ActiveSync exits the resolution cycle and updates the summary and detail panes.
