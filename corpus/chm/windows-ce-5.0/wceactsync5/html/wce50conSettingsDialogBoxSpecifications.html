Settings Dialog Box Specifications

The service provider owns its Settings dialog box, so you can develop it to satisfy the needs of the service provider. If more settings information is needed than can fit in this dialog box, use tabs to group related settings. For consistency, follow these dialog box guidelines:

  • fixed width of 356 pixels
  • variable height of at least 417 pixels
  • The title bar should display the following string.

    program-name Synchronization Settings

  • application icon in the upper left corner
  • A bold descriptor label next to the icon should display the following string.

    program-name Synchronization

  • Summary text under the label, similar to text displayed by service providers shipped with ActiveSync
  • OK button to apply changes and close the dialog box
  • Cancel button to discard changes and close the dialog box
  • Apply button to apply changes without closing the dialog box
