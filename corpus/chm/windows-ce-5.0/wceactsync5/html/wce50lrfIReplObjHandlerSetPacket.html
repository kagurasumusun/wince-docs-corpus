IReplObjHandler::SetPacket

This method is a user-implemented method that deserializes one or more packets into an object after the packets were transmitted between the Windows CE–based device and the desktop computer.

HRESULT SetPacket(
  LPBYTE lpbData,
  DWORD cbData
);

Parameters

lpbData
Long pointer to the incoming packet.
cbData
Stores the packet size.

Return Values

Returns NOERROR if the packet was successfully used to deserialize the object. Returns RERR_SKIP_ALL if the method failed to apply the packet toward the object. In this case skip all remaining packets for the object.

Remarks

SetPacket is called repeatedly until the last packet is received. These packets are guaranteed to be received in the same order as were are created by IReplObjHandler::GetPacket.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Cesync.h.
Link Library: Coredll.lib.
