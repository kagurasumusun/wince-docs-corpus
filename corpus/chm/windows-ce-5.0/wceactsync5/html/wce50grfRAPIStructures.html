RAPI Structures

The following table shows the RAPI structures, with a description of the purpose of each.

Programming element Description
CE_FIND_DATA This structure describes a file found by the CeFindAllFiles (RAPI) function.
CEDB_FIND_DATA This structure contains information about a database in the Windows CE object store. This structure is used by the CeFindAllDatabases (RAPI) function.
CEOSVERSIONINFO This structure contains operating system version information. The information includes major and minor version numbers, a build number, a platform identifier, and descriptive text about the operating system. This structure is used with the CeGetVersionEx (RAPI) function.
RAPIINIT This structure contains information used to initialize a RAPI connection.
