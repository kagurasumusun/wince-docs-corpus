Internet Explorer 6 Migration

Effective in Microsoft® Windows® CE 5.0, the registry-based favorites functionality is disabled by default. In this release, favorites are stored in shell folders. To store favorites in the registry, set the RegBasedFavorites value to 0. This value is located under the HKEY_LOCAL_MACHINE\Software\Microsoft\Internet Explorer\Main key. For more information about IESample registry settings, see IESample Registry Settings.

Effective with Windows CE .NET 4.0, the GenIE Internet browser was replaced with Microsoft Internet Explorer 5.5 for Windows CE. In Windows CE .NET 4.2, this browser Catalog item was upgraded to Microsoft Internet Explorer 6 for Windows CE. The following topics contain migration infomation about Windows Internet Services (WinInet) and URL Moniker Services:

  • URL Moniker Services Migration
  • WinInet Migration

For general migration information about Windows CE, see Migrating from an Earlier Version of Windows CE.
