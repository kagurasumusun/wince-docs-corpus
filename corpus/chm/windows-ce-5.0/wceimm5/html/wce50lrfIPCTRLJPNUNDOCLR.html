Platform Builder for Microsoft Windows CE 5.0  

IPCTRL_JPN_UNDOCLR

This control identifier requests the conversion service to revert the entire composition string to a non-converted state. Set the value to IPCTRLPARAM_DEFAULT.

Remarks

The entire composition string will have the ATTR_INPUT attribute after the conversion service processes this function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msime.h.
