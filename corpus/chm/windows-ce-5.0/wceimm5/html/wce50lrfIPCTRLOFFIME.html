IPCTRL_OFFIME

This control identifier requests the conversion service to stop IME processing. Set the value to IPCTRLPARAM_DEFAULT.

Remarks

After IME processing has been stopped, most function calls will fail. You can use only the following functions after IME processing has been stopped:

  • IPCTRL_ONIME
  • IPCTRL_OFFIME
  • IPCTRL_PRECONVERSION
  • IPCTRL_SETCONVERSIONMODE
  • IPCTRL_GETCONVERSIONMODE

The composition string and the result string kept in the conversion service are cleared.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msime.h.
