IMC_GETSTATUSWINDOWPOS

This message is sent by an application to an IME window to get the position of the status window.

msg = (UINT) WM_IME_CONTROL;
wParam = (WPARAM) IMC_GETSTATUSWINDOWPOS;
lParam = 0;

Parameters

lParam
Not used.

Return Values

A POINTS structure that contains the x- and y-coordinates of the status window position indicates success.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Imm.h.
