OBEX Samples

The samples provide a base for implementing the OBEX technology. These samples have not been tested and are not intended for production use.

All samples are located in %_WINCEROOT%\Public\Servers\SDK\Samples\OBEX.

The following table lists the OBEX samples.

Sample Description
OBEXFTP This sample application illustrates how to establish FTP services using the Windows CE–based Bluetooth stack over OBEX.
OBEXTool This sample application provides a UI to manage or establish FTP services using the Windows CE–based Bluetooth stack over OBEX.
