Customizing the IME Toolbar Buttons

You can customize the buttons that are displayed on the IME toolbar.

The following table shows the IME toolbar buttons.

Button Description
Conversion Mode Switches the conversion mode.
Sentence Mode Switches the sentence mode.
Properties Displays the properties for the IME.
Dictionary Tool Launches the dictionary tool.
Register Word Registers the selected word.
Tools Displays the tools that are available for the IME.
CAPS Turns Caps on and off.
KANA Turns the Kana input mode on and off.

You can use the registry to specify which buttons are displayed on the IME toolbar. The values that identify each button on the toolbar are set in the Buttons sub key, which is located under the HKEY_LOCAL_MACHINE\Software\Microsoft\IMEJP\3.1\Window registry key. For more information about how to specify toolbar buttons through the registry, see Japanese IME 3.1 Registry Settings.
