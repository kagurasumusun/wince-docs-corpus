Japanese IME 3.1 Classes

The following table shows the Japanese IME 3.1 classes.

Programming element Description
CImeCUIDefCompWindow Provides the ability to draw the default composition window.
CImeCUIToolBar Provides the functionality to draw the Input Method Editor (IME) toolbar window.
CImeCUICandWindow Provides the ability to draw the IME candidate window.
