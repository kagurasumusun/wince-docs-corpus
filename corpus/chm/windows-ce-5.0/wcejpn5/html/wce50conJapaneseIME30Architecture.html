Japanese IME 3.1 Architecture

The following table shows the dynamic-link libraries (DLLs), executables, and data files that comprise the Microsoft Input Method Editor (IME) 3.1.

File Description
Imjp31.dll IME UI and interfaces to Input Method Manager (IMM).
Imjp31c.dll Advanced settings dialog box that require landscape orientation.
Imjp31dx.exe Dictionary tool. Landscape and portrait versions are available.
Imjp31k.dll IME core functionality.
Imjp31m.exe System tray icon support.
Imjp31s.dic Lexical database.
Imjp31s.grm Grammar dictionary.
Imjp31u.dll Property dialog box. Landscape and portrait versions are available.
Imjp31ux.exe Stub for the property dialog box.
