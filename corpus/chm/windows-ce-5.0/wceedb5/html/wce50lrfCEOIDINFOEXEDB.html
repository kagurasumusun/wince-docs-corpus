CEOIDINFOEX (EDB)

This structure contains information about an object in the volume. The structure is used when calling the CeOidGetInfoEx2 (EDB) function.

typedef struct CEOIDINFOEX {
  WORD wVersion;
  WORD wObjType;
  union {
    CEFILEINFO infFile;
    CEDIRINFO infDirectory;
    CEDBASEINFO infDatabase;
    CERECORDINFO infRecord;
  };
} CEOIDINFOEX;

Members

wVersion
Specifies the version of this structure; must set to 2.
wObjType
Specifies the type of the object. It is one of the following values:
  • OBJTYPE_DATABASE, if the object is a database.
  • OBJTYPE_RECORD, if the object is a record.
infDatabase
Specifies a CEDBASEINFOEX (EDB) structure that contains information about a database. This member is valid only if wObjType is set to OBJTYPE_DATABASE.
infRecord
Specifies a CERECORDINFO (EDB) structure that contains information about a record in a database. This member is valid only if wObjType is set to OBJTYPE_RECORD.
Note   EDB does not support the CEFILEINFO and CEDIRINFO types. The infFile and infDirectory members are ignored.

Remarks

The following list highlights the differences between this structure and the CEDB equivalent structure:

  • EDB only supports database and record OID types. EDB does not support the OBJTYPE_FILE and OBJTYPE_DIRECTORY OID types.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Windbase.h.
Link Library: Coredll.lib.
