Storage Manager Structures

The following table shows the Storage Manager structures.

Programming element Description
CE_VOLUME_INFO This structure contains information about a volume.
PARTINFO This structure contains information about a partition.
STORAGECONTEXT This structure contains information that allows the OAL to choose which partition, if any, to format.
STORAGEDEVICEINFO This structure contains information about a storage device.
STOREINFO (Storage Manager) This structure contains information about a store.
