getElementMapper Method

This method creates and returns a type mapper for the specified XML Schema Definition (XSD) element node. If the addElement method identifies a custom mapper for the element, the getElementMapper method returns that mapper. Otherwise, the getElementMapper method determines the type of the element and returns a mapper for that type.

HRESULT getElementMapper(
  IXMLDOMNode* pElementNode, 
  ISoapTypeMapper** ppSoapTypeMapper
);

Parameters

pElementNode
[in] Element node in an XSD file.
ppSoapTypeMapper
[out] Type mapper for the element.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.
