Init Method (ISoapTypeMapper)

The method initializes the type mapper object.

HRESULT Init(
  ISoapTypeMapperFactory* pFactory,
  IXMLDOMNode* pSchema,
  enXSDType xsdType
);

Parameters

pFactory
[in] ISoapTypeMapperFactory object interface pointer that can be used to create additional type mappers.
pSchema
[in] Reference to the complexType or simpleType node in the schema that defines the type. Use this parameter to extract any needed information from the schema.
xsdType
[in] For custom type mappers, a value that is always enXSDUndefined (-1).

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
