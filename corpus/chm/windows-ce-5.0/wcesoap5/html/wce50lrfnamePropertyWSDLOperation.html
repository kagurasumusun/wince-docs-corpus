name Property (WSDLOperation)

This property returns the operation's name as specified in the Web Services Description Language (WSDL) file.

HRESULT get_name(
  BSTR* pbstrOperationName
);

Parameters

pbstrOperationName
[out] Operation's name.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
