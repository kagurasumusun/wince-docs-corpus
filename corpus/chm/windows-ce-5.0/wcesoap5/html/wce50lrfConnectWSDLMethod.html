ConnectWSDL Method

This method initializes the SoapConnector object (accessed using the ISoapConnector interface) and prepares the connection. This method uses the port information in the Web Services Description Language (WSDL) file to perform the necessary transport level setup.

HRESULT ConnectWSDL( 
  IWSDLPort* Port
);

Parameters

Port
[in] Port to which a connection is to be established. If this parameter is not null, the ConnectWSDL method initializes the connector's properties using the information provided for the specified port. If null, you must initialize the connector's properties explicitly before calling ConnectWSDL.

The value of the IWSDLPort property must be obtained from the WSDLReader object or set to NULL.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
