Chinese (Traditional) Samples

Windows CE provides the following three sample IMs for Traditional Chinese:

Sample Location
Phonetic Input (Bopomofo) %WINCEROOT%\Public\Common\Sdk\Samples\CHTIM
Input by Radical (Chang Jei) %WINCEROOT%\Public\Common\Sdk\Samples\CHTIM
Mboxcht HWX Sample UI %WINCEROOT%\Public\Common\Sdk\Samples\MBOXCHT
