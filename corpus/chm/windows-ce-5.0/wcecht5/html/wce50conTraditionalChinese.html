Platform Builder for Microsoft Windows CE 5.0  

Chinese (Traditional)

Windows CE provides support for the Traditional Chinese locale.

In This Section

Chinese (Traditional) OS Design Development
Presents information about the Traditional Chinese locale that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement Traditional Chinese, and Traditional Chinese implementation considerations.
Traditional Chinese Input Methods
Provides a list that describes all the Traditional Chinese input methods that Windows CE supports.
Traditional Chinese Pocket IME
Describes the architecture of the Traditional Chinese Pocket Input Method Editor (IME) technology, and outlines how OEMs can supply a custom module for this IME.
Chinese (Traditional) Registry Settings
Provides information about the configurable registry settings for Traditional Chinese Pocket IME and the Traditional Chinese Handwriting Sample input method.
Chinese (Traditional) Samples
Describes sample code that is available in the %WINCEROOT%\Public\Common\Sdk\Samples directory.

Related Sections

Input Method Manager (IMM)
Provides an overview of the Input Method Manager technology, the import method system that is supported in Windows CE, and the (IME) user interface. Shows how to use the IMM API to customize IME behavior.
