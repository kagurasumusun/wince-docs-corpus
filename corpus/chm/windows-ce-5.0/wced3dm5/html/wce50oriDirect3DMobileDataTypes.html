Direct3D Mobile Data Types

This section contains information about the data types used with Microsoft® Direct3D® Mobile.

The following table shows these data types.

Data Type Description
D3DMVALUE This data type describes a generic 32-bit value. Values stored in this type can either be fixed or floating point.
D3DMCOLOR This data type represents a color using the D3DMFMT_A8R8G8B8 format.
