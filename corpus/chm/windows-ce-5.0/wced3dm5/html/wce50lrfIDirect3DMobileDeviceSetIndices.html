IDirect3DMobileDevice::SetIndices

This method sets index data.

HRESULT SetIndices(
  IDirect3DMobileIndexBuffer* pIndexData
);

Parameters

pIndexData
[in] Pointer an IDirect3DMobileIndexBuffer interface that represents the index data to be set.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DMERR_INVALIDCALL (see D3DMERR Values).

Remarks

The IDirect3DMobileDevice::SetIndices method sets the current index array to an index buffer. The single set of indices is used to index all streams.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
