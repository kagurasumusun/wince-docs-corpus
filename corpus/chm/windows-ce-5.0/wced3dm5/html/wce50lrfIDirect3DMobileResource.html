IDirect3DMobileResource

This interface is a base interface for working with resource objects such as texture maps, vertex buffers, and index buffers.

Methods

The following table shows the methods for this interface by functional grouping. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Grouping Method
Devices GetDevice
Priorities GetPriority

SetPriority
Resources GetType

PreLoad

Obtaining a Pointer

You can obtain a pointer to an IDriect3DMobileResource interface by calling IUnknown::QueryInterface on any interface to a resource object and specifying IID_IDirect3DMobileResource.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
