Basic Lighting Formulas

The output of the lighting stage is the diffuse and possibly the specular colors of the vertex in ARGB format. The D3DMRS_LIGHTING render state (see D3DMRENDERSTATETYPE) controls whether the lighting computations are performed.

If the lighting computations are not enabled, the vertices color values are computed as follows:

  • D3DMRS_COLORVERTEX is ignored.
  • If the diffuse vertex color is present then it is passed on through the rendering pipeline, otherwise the diffuse color is the default diffuse color value 0xFFFFFFFF (white) is used.
  • If the specular vertex color is already present then it is passed on through the rendering pipeline, otherwise the specular color is the default specular color 0 (black) is used.

If the lighting computations are enabled, then the vertex colors are computed and then clamped (0.0 to 1.0) and scaled (0 to 255) before being passed to the rasterizer.

If vertex normals are not specified, all of the dot products involving the vertex normal are set to 0 and the lighting computation is still performed.

Diffuse Lighting

The diffuse color, D, is computed using the following equation:

DRGB = Va * La + sum( Vd X (N.Ldi) * AtteniLci + Va * Lcai)

where X denotes the vector cross product. The value of Va is determined by the conditions shown in the following table.

Value Condition 
Va = Vcd
 Used if color vertex is enabled and the ambient material source is D3DMMCS_COLOR1 and the diffuse vertex color is present. 
Va = Vcs
Used if color vertex is enabled and the ambient material source is D3DMMCS_COLOR2 and the specular vertex color is present. 
Va = Ma
 Used otherwise.

The value of Vd is determined by the conditions shown in the following table.

Value Condition 
Vd = Vcd
 Used if color vertex is enabled and the diffuse material source is D3DMMCS_COLOR1 and the diffuse vertex color is present. 
Vd = Vcs
Used if color vertex is enabled and the diffuse material source is D3DMMCS_COLOR2 and the specular vertex color is present. 
Vd = Ma
 Used otherwise.

The value of AtteniLci is evaluated based on the conditions shown in the following table.

Value Condition 
Atteni = 1
 Used if the light is a directional light. 
Atteni = 0
 Used if the distance between the light and the vertex exceeds the light's range. 
Atteni = 1/(LAttoi + LAtti1i * Ldi + LAtti2i * Ldi2)
 Used otherwise.

The alpha component of the diffuse color, Dalpha, is computed based on the conditions shown in the following table.

Equation Condition 
Dalpha = Vcd alpha
 Used if color vertex is enabled and the diffuse material source is D3DMMCS_COLOR1 and the diffuse vertex color is present. 
Dalpha = Vcs alpha
 Used if color vertex is enabled and the diffuse material source is D3DMMCS_COLOR2 and the specular vertex color is present. 
Dalpha = Mdalpha
 Used otherwise.

Specular Lighting

The specular color, S, is set to (0,0,0,0) if the D3DMRS_SPECULARENABLE render state is set to FALSE, otherwise S is computed as follows:

If (N.Ldi) <= 0, then S = 0 because specular highlights do not extend beyond 180 degrees and if the light points away from the normal, there will be no highlight.

Otherwise:

SRGB = Vs * sum((N.hi)Mp * LCSi * Atteni)

The value of Vs is determined by the conditions shown in the following table.

Value Condition 
Vs = Vcd
 Used if color vertex is enabled and the specular material source is D3DMMCS_COLOR1 and the diffuse vertex color is present. 
Vs = Vcs
 Used if color vertex is enabled and the specular material source is D3DMMCS_COLOR2 and the specular vertex color is present. 
Vs = Ms
 Used otherwise.

The value of Atteni is determined in the same was as for diffuse lighting.

The vector, hi is the halfway vector between the normal and the direction to the light. The computation of the halfway vector depends on the D3DMRS_LOCALVIEWER render state. If the render state is set to TRUE, then the halfway vector is computed as camera relative. If the render state is set to FALSE, the halfway vector is computed orthogonally (viewer is at infinity.) Applications that use orthogonal projection should set this render state to FALSE, which is the default value. The following table shows how hi is computed based on the render state setting for D3DMRS_LOCALVIEWER.

D3DMRS_LOCALVIEWER Setting Computation
TRUE 
hi = norm(norm(Vpe) + Ldi)
FALSE 
hi = norm((0,0,-1) + Ldi)

The alpha component of the specular color, Salpha, is computed based on the conditions shown in the following table.

Equation Condition 
Salpha = Vcd alpha
 Used if color vertex is enabled and the specular material source is D3DMMCS_COLOR1 and the diffuse vertex color is present. 
Salpha=Vcs alpha
Used if color vertex is enabled and the specular material source is D3DMMCS_COLOR2 and the specular vertex color is present. Also used if D3DMRS_SPECULARENABLE is FALSE. 
SAlpha=Msalpha
 Used otherwise.
