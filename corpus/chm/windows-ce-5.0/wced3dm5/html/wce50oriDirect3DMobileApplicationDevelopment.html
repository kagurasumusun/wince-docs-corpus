Direct3D Mobile Application Development

The Microsoft® Direct3D® Mobile API provides basic support for hardware accelerated 3-D graphics. It provides a device-independent way for you to access the 3-D acceleration hardware on your target device. It is ideal for computer-aided design (CAD) applications, games, visualization tool, or other applications that require 3-D data rendering.
