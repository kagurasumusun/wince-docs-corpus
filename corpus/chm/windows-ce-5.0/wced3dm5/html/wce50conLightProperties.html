Light Properties

Light properties describe a light source's type and color. Depending on the type of light being used, a light can have properties for attenuation and range. But, not all types of lights use all properties. Microsoft® Direct3D® Mobile uses the D3DMLIGHT structure to carry information about light properties for all types of light sources. This section contains information for all light properties. Information is divided into the following groups:

  • Light Type
  • Light Color
  • Light Position, Range, and Attenuation
  • Light Direction

Light properties affect how a light source illuminates objects in a scene.

For more information, see Using Lights, Setting Light Properties, and Lighting Equations.
