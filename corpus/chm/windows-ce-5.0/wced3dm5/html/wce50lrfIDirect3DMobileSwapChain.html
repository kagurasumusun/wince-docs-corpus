IDirect3DMobileSwapChain

This interface is used to manipulate swap chains that are outside of the primary swap chain that is implicitly created when the Direct3D Mobile device is created. By definition in Direct3D Mobile, a swap chain includes a primary surface, a back buffer, and a depth buffer.   

Methods

The following table shows the methods for this interface by functional grouping. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Grouping Methods
Back Buffers IDirect3DMobileSwapChain::GetBackBuffer
Presentation IDirect3DMobileSwapChain::Present

Obtaining a Pointer

You can obtain a pointer to an IDirect3DMobileSwapChain interface by calling the IDirect3DMobileDevice::CreateAdditionalSwapChain method.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
