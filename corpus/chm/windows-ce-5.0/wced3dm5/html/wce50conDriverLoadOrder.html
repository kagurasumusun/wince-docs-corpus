Driver Load Order

If the application specifies adapter ordinal 1 to IDirect3DMobile::CreateDevice, then the middleware attempts to load the registered software device (if one is present). If the application specifies adapter ordinal 0, the middleware attempts to setup a remote hook. If that fails, the middleware will attempt to initialize the locally hooked driver (if one is present).
