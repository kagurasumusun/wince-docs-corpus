Platform Builder for Microsoft Windows CE 5.0  

SysReAllocString

This function does the following:

  • Allocates a BSTR
  • Copies the passed string into the BSTR
  • Frees the BSTR referenced by pbstr
  • Resets pbstr to point to the new BSTR
HRESULT SysReAllocString(
  BSTR FAR* pbstr, 
  OLECHAR FAR* sz 
);

Parameters

pbstr
[in, out] Pointer to a variable that contains a BSTR.
sz
[in] Null-terminated string to copy.

Return Values

This function returns TRUE if it reallocated the string successfully and FALSE if insufficient memory exists.

Remarks

Windows CE supports only Unicode strings.

Passing invalid (and under some circumstances NULL) pointers into this function causes an unexpected termination of the application.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oleauto.h.
Link Library: Oleaut32.lib.
