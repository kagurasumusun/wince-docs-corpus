ISupportErrorInfo

This interface ensures that error information can be propagated up the call chain correctly. Automation objects that use the error handling interfaces must implement ISupportErrorInfo.

Methods

The following table shows the method for this interface. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Method Description
ISupportErrorInfo::InterfaceSupportsErrorInfo This method indicates whether or not an interface supports the IErrorInfo interface.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
