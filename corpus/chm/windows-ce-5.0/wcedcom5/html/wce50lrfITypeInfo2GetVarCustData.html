ITypeInfo2::GetVarCustData

This method gets the variable for the custom data. 

HRESULT GetVarCustData( 
  unsigned int index, 
  REFGUID guid, 
  VARIANT* pVarVal 
);

Parameters

index
[in] Index of the variable for which to get the custom data.
guid
[in] GUID used to identify the data.
pVarVal
[out] Pointer to where to put the retrieved data.

Return Values

The following table shows the return values for this function.

Value Description
S_OK Success.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
