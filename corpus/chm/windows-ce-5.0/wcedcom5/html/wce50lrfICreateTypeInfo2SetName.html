ICreateTypeInfo2::SetName

This method sets the name of the typeinfo. 

HRESULT SetName( 
  OLECHAR FAR* szName
);

Parameters

szName
[in] Null-terminated string that contains the name to be assigned to the typeinfo.

Return Values

The following table shows the return values for this function.

Value Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.
TYPE_E_INVALIDSTATE The state of the typeinfo is not valid for this operation.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
