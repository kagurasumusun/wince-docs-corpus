DCOM Security Configuration Utility

DCOMCNFG is a utility that allows you to configure various DCOM-specific settings in the registry. You can use the registry to specify default permissions for objects on the system, such as Access, Launch, and Configuration.

The Windows CE counterpart of DCOMCNFG is provided (including source code) in the %_WINCEROOT%\Public\Dcom\Sdk\Samples\Dcomcnfg.
