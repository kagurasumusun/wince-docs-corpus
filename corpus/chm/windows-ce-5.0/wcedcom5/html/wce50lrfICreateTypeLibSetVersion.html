ICreateTypeLib::SetVersion

This method sets the major and minor version numbers of the type library.

HRESULT SetVersion( 
  unsigned short wMajorVerNum, 
  unsigned short wMinorVerNum
);

Parameters

wMajorVerNum
[in] Major version number for the library.
wMinorVerNum
[in] Minor version number for the library.

Return Values

If the method succeeds, the return value is S_OK.

If the state of the type library is not valid for this operation, the return value is TYPE_E_INVALIDSTATE.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
