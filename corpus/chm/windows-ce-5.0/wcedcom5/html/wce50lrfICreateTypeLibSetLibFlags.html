ICreateTypeLib::SetLibFlags

This method sets library flags, such as LIBFLAG_FRESTRICTED.

HRESULT SetLibFlags( 
  unsigned int uLibFlags
);

Parameters

uLibFlags
[in] Flags to set for the library.

Return Values

The following table shows the return values for this function.

Value Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.
TYPE_E_INVALIDSTATE The state of the type library is not valid for this operation.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
