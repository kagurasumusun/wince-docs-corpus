IDccMan::Unadvise

This method is called by a client application when it wants to stop receiving connection notifications.

HRESULT STDMETHODIMP IDccMan::Unadvise( 
  DWORD dwContext
);

Parameters

dwContext
DWORD value that was returned in the call to the IDccMan::Advise method.

Return Values

NOERROR indicates success. If an error occurs, the appropriate HRESULT value is returned.

Remarks

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
