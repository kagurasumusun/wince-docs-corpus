IDccManSink::OnLogDisconnection

This method indicates that the connection manager has terminated the connection between the desktop computer and the Windows CE–based device. 

STDMETHODIMP IDccManSink::OnLogDisconnection(void);

Parameters

None.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogDisconnection method is implemented by a client application and is called when the Windows CE connection manager terminates the connection between the desktop computer and the Windows CE–based device.

When this notification is made, the Windows CE connection manager starts any applications that are registered with the registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\AutoStartOnDisconnect.

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
