ELEMDESC

This structure is used for holding the type description and process transfer information for a variable, a function, or a function parameter.

typedef struct tagELEMDESC {
  TYPEDESC tdesc;
  union {
    IDLDESC idldesc;
    PARAMDESC paramdesc;
  };
} ELEMDES, *LPELEMDESC;

Members

tdesc
Type of the element.
idldesc
Information for remoting the element; provides backward compatibility.
paramdesc
Information about the parameter.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h.
