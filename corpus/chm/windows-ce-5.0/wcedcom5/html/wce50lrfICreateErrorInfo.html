ICreateErrorInfo

This interface returns error information for applications that return rich error information.

Methods

The following table shows the methods for this interface in the order that the compiler calls the methods. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Method Description
ICreateErrorInfo::SetGUID This method sets the globally unique identifier (GUID) of the interface that defined the error.
ICreateErrorInfo::SetSource This method sets the language-dependent programmatic identifier for the class or application that raised the error.
ICreateErrorInfo::SetDescription This method sets a textual description of the error.
ICreateErrorInfo::SetHelpFile This method sets the path of the Help file that describes the error.
ICreateErrorInfo::SetHelpContext This method sets the Help context identifier for the error.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
