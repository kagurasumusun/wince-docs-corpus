Handwriting Recognizer Engine (HWX) Samples

Windows CE contains four samples for using Handwriting Recognition Engine (HWX) for the Traditional Chinese, Korean, and Japanese locales. These samples are located in the %_WINCEROOT%\Public\Common\Sdk\Samples directory. The following table shows the samples for HWX.

Sample Description
mboxkor Sample input method (IM) for Korean handwriting input that works with HWX.
mboxcht Sample IM for Traditional Chinese handwriting input that works with HWX.
multibox Sample user interface for Japanese input that works with HWX. This IM automatically updates a list of possible character candidates with each character stroke that the user draws.
cacjpn Sample user interface for Japanese handwriting input that works with IME 3.1, Pocket IME, and HWX.
