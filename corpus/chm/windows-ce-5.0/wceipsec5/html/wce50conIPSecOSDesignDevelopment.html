IPSec OS Design Development

IPSec v4 enables two client devices on a network to establish peer-to-peer communication using the IP Security (IPSec) protocol.

OS Design Information

The following table shows operating system design information for IPSec v4.

Element Information
Dependencies Capi2, rsacsp, ddsh
Hardware considerations None

Modules and Components

The following table shows the components and modules that implement IPSec v4.

Item Module Component
Domain Discovery Ipsec_api None

IPSec v4 Implementation Considerations

You can include the IPSec v4 item in your OS design by choosing the item from the Catalog. Choosing this Catalog item sets the appropriate Sysgen variable for enabling IPSec v4.

The following table shows the Sysgen variable that enables IPSec v4.

Sysgen variable Description
SYSGEN_IPSEC When this variable is set, IPSec v4 is included in the OS design.
