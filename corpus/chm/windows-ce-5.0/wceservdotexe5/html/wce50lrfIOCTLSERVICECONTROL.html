Platform Builder for Microsoft Windows CE 5.0  

IOCTL_SERVICE_CONTROL

This IOCTL contains information specific to a certain service passed by the calling application.

Parameters

The definition of the input and output parameters varies depending on the service.

Return Values

Returns TRUE if successful, FALSE otherwise. To obtain extended error information, call the SetLastError function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Service.h.
