ITargetFrame::GetFrameSrc Method

Retrieves the URL to load into the frame.

Syntax

HRESULT GetFrameSrc(      
    LPWSTR *ppszFrameSrc
);

Parameters

ppszFrameSrc
[out] Address of a pointer to a string that contains the URL to load into the frame.

Return Value

Returns S_OK if successful, or an error value otherwise.
