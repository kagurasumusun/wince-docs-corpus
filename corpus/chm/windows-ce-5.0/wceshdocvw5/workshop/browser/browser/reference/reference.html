Associated Browser Reference

This section describes various application programming interfaces (APIs) that provide access to browser functionality in addition to the MSHTML, WebBrowser control, and hosting references.

Interfaces

ITargetContainer

This interface retrieves information about the container for the frames.

ITargetFrame

This interface provides methods for retrieving and setting frame data.

ITargetFrame2

This interface provides methods for retrieving and setting frame data.

ITargetNotify

This interface provides methods to receive notifications about the creation of windows for new frames.

Functions

LaunchConnectionDialog

Launches the Internet Properties dialog box with the Connections tab displayed.

LaunchInternetControlPanel

Launches the Internet Properties dialog box with the General tab displayed.

LaunchSecurityDialog

Launches the Internet Properties dialog box with the Security tab displayed.

Enumerations

FINDFRAME_FLAGS

Defines a set of flags used with the ITargetFrame2::FindFrame method.

FRAMEOPTIONS_FLAGS

Defines a set of flags used with the ITargetFrame2::GetFrameOptions and ITargetFrame2::SetFrameOptions methods.
