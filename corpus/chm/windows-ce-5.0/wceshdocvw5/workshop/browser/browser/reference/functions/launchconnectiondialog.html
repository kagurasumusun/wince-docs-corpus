LaunchConnectionDialog Function

Launches the Internet Properties dialog box with the Connections tab displayed.

Syntax

BOOL LaunchConnectionDialog(      
    HWND hParent
);

Parameters

hParent
Handle to the window that is the parent of the Internet Properties dialog box. This parameter can be NULL.

Return Value

Returns TRUE if successful, or FALSE otherwise.

Remarks

Use the LoadLibrary and GetProcAddress functions to import LaunchConnectionDialog from Inetcpl.cpl.

Example

This example shows how to use LoadLibrary and GetProcAddress to load and call LaunchConnectionDialog.

Security Alert  Using LoadLibrary incorrectly can compromise the security of your application by loading the wrong dynamic-link library (DLL). Refer to the LoadLibrary documentation for information on how to correctly load DLLs with different versions of Microsoft® Windows®.

typedef BOOL (WINAPI *LAUNCHCPL) (HWND);
HMODULE hInetcpl;
HWND hParent;
LAUNCHCPL cpl;

hInetcpl = LoadLibrary("inetcpl.cpl");

if (hInetcpl == NULL)
{
   //Error loading module -- fail as securely as possible
   return;
}
   
cpl = (LAUNCHCPL)GetProcAddress(hInetcpl, "LaunchConnectionDialog");
if(cpl)
{
  cpl(hParent);
}
FreeLibrary(hInetcpl);
