IEnumTravelLogEntry::Next Method

Retrieves the next items in the enumeration sequence.

Syntax

HRESULT Next(      
    ULONG cElt,
    ITravelLogEntry **rgElt,
    ULONG *pcEltFetched
);

Parameters

cElt
[in] Integer that specifies the number of items requested. The cElt parameter is a ULONG; therefore, you cannot pass a negative number to go backward.
rgElt
[out] Pointer to an array of ITravelLogEntry interface pointers. The size of the array is determined by cElt; the number of valid pointers is determined by the value returned in pcEltFetched. The caller is responsible for allocating and freeing the rgElt array.
pcEltFetched
[out] Pointer to an integer that receives the number of items supplied. This parameter may be set to NULL if you do not need to know the number of elements retrieved.

Return Value

Returns S_OK if successful, or S_FALSE otherwise.

Remarks

When you reach the end of the enumeration, the cursor remains there. If you need to return to the beginning, you must call IEnumTravelLogEntry::Reset.

If you request more elements than exist in the sequence between the current element and the end, the method retrieves the remaining elements and returns S_FALSE. The cursor stays at the end of the enumeration.
