IWebBrowser2::Height Property

Sets or retrieves the height of the Microsoft® Internet Explorer main window.

Syntax

HRESULT IWebBrowser2::get_Height(long *pl);
HRESULT IWebBrowser2::put_Height(long Height);

Parameters

pl
Pointer to a variable of type long that receives the height, in pixels, of the main window.
Height
long that specifies the height, in pixels, of the main window.

Return Value

Returns S_OK if successful, or an error value otherwise.

See Also

IWebBrowser2::ClientToWindow, IWebBrowser2::Width
