IWebBrowser2::TheaterMode Property

Sets or retrieves a value that indicates whether the object is in theater mode.

Syntax

HRESULT IWebBrowser2::get_TheaterMode(VARIANT_BOOL *pbRegister);
HRESULT IWebBrowser2::put_TheaterMode(VARIANT_BOOL bRegister);

Parameters

pbRegister
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
bRegister
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEDefault. Object is in normal mode.
VARIANT_TRUEObject is in theater mode.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The WebBrowser object ignores this property.

In theater mode, the object's main window fills the entire screen and displays a toolbar with a minimal set of navigational buttons. A status bar is also provided in the upper right-hand corner of the screen. Channels, Search, History, and Favorites browser bars appear (if enabled) as an autohide pane on the left edge of the screen in theater mode.
