DWebBrowserEvents2::OnMenuBar Event

Fires when the IWebBrowser2::MenuBar property is changed.

Syntax

void OnMenuBar(      
    VARIANT_BOOL MenuBar
);

Parameters

MenuBar
[in] VARIANT_BOOL value that specifies whether the menu bar is shown.
VARIANT_TRUE
Menu bar is shown.
VARIANT_FALSE
Menu bar is hidden.

Return Value

No return value.

Event DISPID

DISPID_ONMENUBAR

The DISPID for this event is defined in exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

The WebBrowser object ignores this event.

When using scripting in an HTML page, this event corresponds to the IWebBrowser2::MenuBar property passed in the open method.
