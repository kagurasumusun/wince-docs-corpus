DWebBrowserEvents::NewWindow Event

Fires when a new window is to be created.

Syntax

void NewWindow(      
    IDispatch **&ppDisp,
    VARIANT_BOOL *&Cancel
);

Parameters

ppDisp
[in, out] Address of an interface pointer that, optionally, receives the IDispatch interface pointer of either a new WebBrowser or InternetExplorer object.
Cancel
[in, out] VARIANT_BOOL value to determine whether the current navigation should be canceled.
VARIANT_TRUE
Cancel the navigation.
VARIANT_FALSE
Do not cancel the navigation.

Return Value

No return value.

Event DISPID

DISPID_NEWWINDOW

The DISPID for this event is defined in exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

This event is obsolete. Use the DWebBrowserEvents2::NewWindow2 event instead.
