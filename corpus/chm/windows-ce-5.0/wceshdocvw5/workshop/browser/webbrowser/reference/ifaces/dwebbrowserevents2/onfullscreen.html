DWebBrowserEvents2::OnFullScreen Event

Fires when the IWebBrowser2::FullScreen property is changed.

Syntax

void OnFullScreen(      
    VARIANT_BOOL FullScreen
);

Parameters

FullScreen
[in] VARIANT_BOOL value that specifies whether the browser window is in full-screen mode.
VARIANT_TRUE
Browser window is in full-screen mode.
VARIANT_FALSE
Browser window is not in full-screen mode.

Return Value

No return value.

Event DISPID

DISPID_ONFULLSCREEN

The DISPID for this event is defined in exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

The WebBrowser object ignores this event.

When using scripting in an HTML page, this event corresponds to the IWebBrowser2::FullScreen property passed in the open method.
