Download Event Status Document Elements

This reference section groups all the XML elements that are used in the status report document sent by the client, device, to the server during the download event.

The following table shows the XML elements that comprise the status report to the server:

Element Description
Status Root element of the Status document.
StatusMessage Top element of a status message sent to the server.
Parameter Additional information about the status message.

For more information about this XML document, see Download Event Status Reports.
