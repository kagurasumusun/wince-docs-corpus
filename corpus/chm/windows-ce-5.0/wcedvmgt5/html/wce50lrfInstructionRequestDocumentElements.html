Instruction Request Document Elements

This reference section groups all the XML elements that are used in the instruction request document sent to the server.

The following table shows the instruction request XML elements.

Element Description
InstructionsRequest Root element of the instructions request document.
Package Top-level element of the section that describes a particular package.

For more information about this XML document, see Instruction Request to the Server.
