Device Management Client OS Design Development

The Device Management functionality in Microsoft® Windows® CE allows you to install applications and software updates without involving the user. It supports polling, download, failure recovery, logging, and status reporting.

Device Management consists of the device management client, and the Microsoft® Systems Management Server Device Management Feature Pack. The Windows CE-based device client periodically polls a server for new application offerings or packages, while the Systems Management Server Device Management Feature Pack is a substitute between the Windows CE-based device client and the Systems Management Server infrastructure.

OS Design Information

The following table shows the operating system design information for Device Management.

Concept Description
Dependencies A Systems Management Server providing device management capabilities or any other compatible server is needed. A proper provisioning model is also required.
Hardware considerations The hardware you use should provide a hard-coded target device identifier. Some form of network connection should also be available.
