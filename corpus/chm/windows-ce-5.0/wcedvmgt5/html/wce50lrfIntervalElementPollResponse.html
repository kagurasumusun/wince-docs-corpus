Interval Element (Poll Response)

This element can exist within the SoftwareInventorySettings element, FileCollectionSettings element, and the MachineInventorySettings element. In all these case, it is used to denote the interval at which the client will generate the appropriate report and send it to the server.

The value is in the format "<4 digit year>-<2 digit month>-<2 digit day> <hours>:<minutes>:<seconds>".

/>

None.
