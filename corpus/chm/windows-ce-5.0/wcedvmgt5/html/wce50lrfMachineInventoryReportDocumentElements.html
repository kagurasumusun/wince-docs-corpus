Machine Inventory Report Document Elements

This reference section groups all the XML elements that are used in the machine or hardware inventory report document that the client, or device, sends to the server.

The following table shows the machine inventory report XML elements.

Element Description
Inventory Root element of the hardware inventory report.
InventoryItem Used to describe file system directories currently on the client system.
Property Used to describe the files that exist on the client system.

For more information on about this XML document, see Machine or Hardware Inventory Report.
