Device Management Client XML Elements

The Device Management Client uses an open and simple XML-based protocol to communicate with the Systems Management Server and the Windows CE client proxy. This reference section describes the XML elements that are used in the XML documents for this protocol.

The XML elements in this reference section have been grouped based on the following XML documents in which they occur.

  • Poll Request Document
  • Poll Response Document
  • Instruction Request Document
  • Instruction Response Document
  • Package Location Request Document
  • Package Location Response Document
  • Download Event Status Document
  • Software Inventory Report Document
  • Machine Inventory Report Document Elements
