Systems Management Server Device Management Feature Pack

The Systems Management Server Device Management Feature Pack is responsible for acting as a proxy between the Windows CE-based device client and the Systems Management Server infrastructure. The Systems Management Server Device Management Feature Pack performs the following functions:

  • Maintains a mapping between the Systems Management Server identifier of a target device and the Unique Device identifier as specified by the target device.
  • Responds to target device polling requests and, when appropriate, supplies a correctly formatted XML document as the response.
  • Retrieves information from Systems Management Server.
  • Tells the target device whether inventory reports, for example Software, File Collection, or Machine reports, are required.
  • Collects inventory from the target device and reports inventory information to the Systems Management Server.
  • Adds a Windows CE Devices environment to the existing Systems Management Server installation to allow an Systems Management Server administrator to target devices.

The proxy server's role is to make each target device client behave as similarly as possible to a native Systems Management Server client, so that as few changes as possible are necessary to the Systems Management Server to allow Systems Management Server to manage the target device clients.
