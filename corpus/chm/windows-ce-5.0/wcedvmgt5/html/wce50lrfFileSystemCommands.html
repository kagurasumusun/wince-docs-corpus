File System Commands

The following table shows the file system commands.

Command Definition
copy (Device Management Client) Copies a file or directory tree.
createdir Creates a file system directory.
delete Deletes a file or directory tree.
rename Renames a file or directory.
setattrs Changes the attribute word of a file or directory.
