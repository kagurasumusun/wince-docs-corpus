IImage::GetImageInfo

This method returns basic information about the image object.

HRESULT GetImageInfo(
  ImageInfo* imageInfo
);

Parameters

imageInfo
[out] A pointer to an ImageInfo structure containing information about the image.

Return Values

If successful, this method returns S_OK.

This method may return one of the following error values if it fails:

  • IMGERR_CODECNOTFOUND
  • IMGERR_OBJECTBUSY
  • E_INVALIDARG
  • E_FAIL

For more information, see Error Codes for the Imaging API.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
