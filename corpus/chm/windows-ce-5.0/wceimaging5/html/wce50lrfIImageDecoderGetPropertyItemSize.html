IImageDecoder::GetPropertyItemSize

This method retrieves the size, in bytes, of a property item for the current image in the decoder. 

HRESULT GetPropertyItemSize(
  PROPID propId, 
  UINT*  size
);

Parameters

propId
[in] A PROPID value specifying the property item that the size is to be retrieved for.
size
[out] A pointer to a UINT value that receives the size, in bytes, of the property item.

Return Values

If successful, this method returns S_OK.

This method may return one of the following error values if it fails:

  • IMGERR_PROPERTYNOTFOUND
  • E_INVALIDARG

For more information, see Error Codes for the Imaging API.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
