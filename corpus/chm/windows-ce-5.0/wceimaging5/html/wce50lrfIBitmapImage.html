IBitmapImage

This interface allows applications to access pixel data of a bitmap image object.

Methods

The following table shows the methods for this interface by functional grouping. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Grouping Methods
Information GetPixelFormatID

GetSize
Locking LockBits

UnlockBits
Palette Management GetPalette

SetPalette

Obtaining a Pointer

To obtain a pointer to an IBitmapImage interface, use one of the following methods.

  • IImagingFactory::CreateBitmapFromBuffer
  • IImagingFactory::CreateBitmapFromImage
  • IImagingFactory::CreateNewBitmap
  • IImagingFactory::CreateNewBitmap
  • IBasicBitmapOps::Clone
  • IBasicBitmapOps::Flip
  • IBasicBitmapOps::Resize
  • IBasicBitmapOps::Rotate
