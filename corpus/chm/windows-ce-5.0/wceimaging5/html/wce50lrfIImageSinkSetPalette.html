IImageSink::SetPalette

This method is used by an image source to pass color palette information to the image sink.

You must call this method before image data transfer takes place.

HRESULT SetPalette(
  const ColorPalette* palette
);

Parameters

palette
[in] A pointer to a ColorPalette structure containing the color palette information about the image that will be sent to the image sink.

Return Values

If successful, this method returns S_OK.

This method may return E_NOTIMPL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.
