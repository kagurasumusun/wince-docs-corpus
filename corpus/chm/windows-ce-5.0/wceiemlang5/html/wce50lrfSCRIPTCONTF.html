SCRIPTCONTF

This enumeration contains the script identifiers for the IMLangFontLink2::GetScriptFontInfo method.

  sidDefault,
  sidMerge,
  sidAsciiSym,
  sidAsciiLatin,
  sidLatin,

  sidLim,
  sidFEFirst = sidHangul,
  sidFELast = sidHan
} SCRIPTCONTF;

Elements

sidDefault
Value that indicates that the default script should be used.
sidMerge
Value that indicates that the text marked with sidMerge will be rendered with a merged run without font switching.

Identifier for ASCII symbols.
