IEnumCodePage::Skip

This method advances the position of the Code Page Enumeration object in the enumeration sequence by the specified amount. 

HRESULT Skip( 
  ULONG celt
);

Parameters

celt
[in] Number of elements to advance in the enumeration sequence.

Return Values

Returns NOERROR.

Example Code

The following code example retrieves the first and third MIMECPINFO structures from the enumeration sequence. 

pMultiLanguage->EnumCodePages(MIMECONTF_BROWSER,
    &pEnumCodePage);
PMIMECPINFO pcpInfo;
ULONG ccpInfo;
pcpInfo = (PMIMECPINFO)CoTaskMemAlloc(sizeof(MIMECPINFO)*2);
pEnumCodePage->Next(1, pcpInfo, &ccpInfo);
pEnumCodePage->Skip(1);
pEnumCodePage->Next(1, pcpInfo + 1, &ccpInfo);
// Use the information on the first and third code pages.
CoTaskMemRealloc((void*) pcpInfo, sizeof(MIMECPINFO)*ccpInfo);

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
