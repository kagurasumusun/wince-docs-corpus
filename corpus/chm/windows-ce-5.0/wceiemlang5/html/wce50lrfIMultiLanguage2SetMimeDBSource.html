IMultiLanguage2::SetMimeDBSource

This method sets the MIME database to be used by MLang.

HRESULT SetMimeDBSource( 
  MIMECONTF dwSource
);

Parameters

dwSource
[in] Specifies the MIMECONTF value that indicates which MIME database to use. This parameter can have one of the following values:
  • MIMECONTF_MIME_IE4
  • MIMECONTF_MIME_LATEST
  • MIMECONTF_MIME_REGISTRY

Return Values

Returns S_OK if successful or an error value otherwise.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
