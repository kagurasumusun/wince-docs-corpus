IMultiLanguage::GetRfc1766Info

This method retrieves an RFC1766INFO structure that corresponds to the given locale identifier (LCID) value. 

HRESULT GetRfc1766Info( 
  LCID Locale,
  PRFC1766INFO pRfc1766Info
);

Parameters

Locale
[in] LCID about which the caller wants information.
pRfc1766Info
[out] Address of the buffer that receives the RFC1766INFO structure.

Return Values

The following table shows the possible return values for this method.

Value Description
S_OK Success.
E_FAIL The method could not get the information from the database or the system.
E_POINTER An invalid pointer was specified.
E_INVALIDARG One or more arguments are invalid.

Remarks

A caller uses this method to retrieve a Windows-defined locale name as well as an RFC1766-conforming locale name, both of which correspond to the given LCID.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
