Peer-to-Peer Common Enumerations

The following table shows the common enumerations with a description of the purpose of each.

Programming element Description
PEER_CONNECTION_FLAGS_TAG Specifies the types of connections a peer can have.
PEER_RECORD_CHANGE_TYPE_TAG Specifies the changes that can occur for a record.
