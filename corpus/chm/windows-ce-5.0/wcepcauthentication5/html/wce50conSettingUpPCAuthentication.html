Setting Up PC Authentication

Using the PC Authentication functionality requires two steps:

  • On the Windows CE-based device, registering the PC Authentication LAP in order to handle authentication requests sent to LASS. For detailed instructions, see Setting up the PC Authentication LAP on a Windows CE Device.
  • On the desktop computer running Windows , running the PC Authentication PC application in order to listen for requests from the LAP running on a Windows CE-based device. For detailed instructions, see Setting up the PC Authentication PC Application.
