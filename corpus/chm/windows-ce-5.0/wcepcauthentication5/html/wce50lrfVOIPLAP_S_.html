VOIPLAP_S_

These constants are returned when a function succeeds.

The following table shows the VOIPLAP_S_ constants.

Value Description
VOIPLAP_S_PCUNLOCKED = 0 The desktop computer was connected to, authenticated, and was unlocked.
VOIPLAP_S_PCLOCKED = 1 The desktop computer was connected to successfully and was locked.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Voiplap.h.
