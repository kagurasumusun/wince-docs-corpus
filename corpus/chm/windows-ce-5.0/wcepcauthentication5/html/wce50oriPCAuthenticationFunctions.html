PC Authentication Functions

The following table shows the PC Authentication functions.

Programming element Description
AttemptConnection Attempts to connect to the associated desktop computer to determine if the desktop computer is locked or unlocked. Times out after a longer period of time than VerifyUser.
GetPCSyncName Returns the machine name or IP address of the desktop computer from which the LAP attempts to retrieve lock/unlock status.
SetPCSyncName Sets the machine name or IP address of the desktop computer from which the LAP attempts to retrieve lock/unlock status.

The PC Authentication Catalog item also implements the four required LASS functions:

  • VerifyUser
  • InitLAP
  • DeinitLAP
  • LAPCreateEnrollmentConfigDialog

For more information about the PC Authentication implementation of these functions, see PC Authentication Implementation of LASS Functions. For more information about LASS in general, see Local Authentication Subsystem (LASS).
