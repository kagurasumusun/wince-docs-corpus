PC Authentication Implementation of LASS Functions

LASS provides a general-purpose architecture that enables Windows CE-based applications to call a single LASS function, VerifyUser (exported from coredll), to authenticate a user.

LASS then calls the LAP-specific implementation of VerifyUser — which is a completely different function and is exported from the LAP DLL — to actually authenticate the user.

Note   Desktop computers that use IPsec can cause the desktop computer application and the LAP to communicate differently. For more information, see PC Authentication and IPsec.

VerifyUser

The PC Authentication version of this function attempts to connect to the associated PC to determine if the desktop computer is locked or unlocked. If the desktop computer is contacted, authenticated, and unlocked, this function returns TRUE and the user is considered authenticated. If the desktop computer is locked, or cannot be contacted, this function returns FALSE and the user is not authenticated.

If this function returns FALSE, you can use the GetLastError function to retrieve any error value, including those described in the VOIPLAP_E_ topic.

This function times out if a response is not received from the desktop computer in the number of milliseconds represented by the c_cmsNormalTimeout constant. The AttemptConnection function performs the same steps as this function but times out in a much longer time, represented by the c_cmsExtendedTimeout constant. Both constants are defined in %_WINCEROOT%\Public\VoIP\Oak\Phone\Lap\Sync\PCQueryBot.cpp.

For general information about this LASS function, including function signature and parameter data, see VerifyUser.

InitLAP

The PC Authentication LAP version of this function takes no action and returns TRUE.

For general information about this LASS function, including function signature and parameter data, see InitLAP.

DeinitLAP

The PC Authentication LAP version of this function takes no action.

For general information about this LASS function, including function signature and parameter data, see DeinitLAP.

LAPCreateEnrollmentConfigDialog

The PC Authentication LAP version of this function takes no action and returns TRUE.

For general information about this LASS function, including function signature and parameter data, see LAPCreateEnrollmentConfigDialog.
