GetObjectType

This function returns the type of the specified object. 

DWORD GetObjectType(
  HGDIOBJ h
);

Parameters

h
[in] Handle to the graphics object.

Return Values

If the function succeeds, the return value identifies the object.

This value can be one of the following.

Value Description
OBJ_BITMAP Bitmap
OBJ_BRUSH Brush
OBJ_FONT Font
OBJ_PAL Palette
OBJ_PEN Pen
OBJ_REGION Region
OBJ_DC Device context
OBJ_MEMDC Memory device context

Windows CE 1.0 and 1.01 do not support the OBJ_PAL return value.

If the function fails, the return value is zero.

To get extended error information, call GetLastError.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windows.h.
Link Library: Coredll.lib.
