GWES Overview

The Shell and User Interface functionality in Microsoft® Windows® CE 5.0 includes the parts of the Graphics, Windowing, and Events Subsystem (GWES) that are included in all display-based OS designs by default. GWES is the interface between the user, your application, and the operating system (OS).

The following table shows the Sysgen variables for the GWES.

Sysgen variable Description
SYSGEN_GDI_ALPHABLEND Set this variable to enable the AlphaBlend API function.
SYSGEN_MINGDI When this variable is set, the Minimal GDI Configuration is included in the OS image.
SYSGEN_MINGWES When this variable is set, the Minimal GWES Configuration is included in the OS image.
SYSGEN_MININPUT When this variable is set, the Minimal Input Configuration is included in the OS image.
SYSGEN_MINWMGR When this variable is set, the Minimal Window Manager Configuration is included in the OS image.
SYSGEN_CONNMC When this variable is set, the Network User Interface Catalog item is included in the OS design.
SYSGEN_GDI_GRADFILL When this variable is set, support for gradient fill is enabled.
SYSGEN_GDI_RASTERFONT When this variable is set, support for raster fonts is enabled. A raster font glyph is a tiny bitmap that represents a single character size. Because the bitmaps for each glyph in a raster font are designed for a specific resolution on a particular device, raster fonts are generally considered device-dependent.
SYSGEN_MENU_OVERLAP When this variable is set, the Overlapping Menus Catalog item is included in the OS design.
SYSGEN_MENU_TAP_UI When this variable is set, Tap UI menus are included in the OS design.
SYSGEN_MSGDLGBOXCUSTOMIZE When this variable is set, a version of the MessageBox function customized by the OEM is included in the OS design.
SYSGEN_MULTIMON When this variable is set, support for the Multiple Screens Catalog item is included in the OS design.
SYSGEN_PPC When this variable is set, support for the Controls Option B Catalog item is included in the OS design.

Controls Option B enables a set of controls with slightly different behavior than the default option, to enable Pocket PC applications to be compatible with Windows CE-based devices.

The default option is Controls Option A. This enables standard Windows controls and other common controls necessary to develop GUI based applications on Windows CE-based devices.
SYSGEN_PRINTING When this variable is set, Printing support is included in the OS design.

When this variable is not set, Printing support is excluded from the OS design.
SYSGEN_XPSKIN When this variable is set, the Windows XP-like sample skin is included in the OS design.
