Menus Messages

The following table shows the menu messages, with a description of the purpose of each.

Programming element Description
WM_COMMAND This message is sent when the user selects a command item from a menu, when a control sends a message to its parent window, or when an accelerator keystroke is translated.
WM_ENTERMENULOOP This message informs an application's main window procedure that a menu modal loop has been entered.
WM_EXITMENULOOP This message informs an application's main window procedure that a menu modal loop has been exited.
