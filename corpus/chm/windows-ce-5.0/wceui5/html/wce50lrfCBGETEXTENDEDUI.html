CB_GETEXTENDEDUI

This message is sent by an application to determine whether a combo box has the default user interface or the extended user interface.

CB_GETEXTENDEDUI wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

TRUE indicates that the combo box has the extended user interface. FALSE indicates that the combo box has the default user interface.

Remarks

By default, the F4 key opens or closes the list and the DOWN ARROW key changes the current selection. In a combo box with the extended user interface, the F4 key is disabled and pressing the DOWN ARROW key opens the drop-down list.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
