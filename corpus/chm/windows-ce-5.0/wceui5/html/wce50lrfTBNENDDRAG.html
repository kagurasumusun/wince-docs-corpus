TBN_ENDDRAG

This message notifies the toolbar's parent window that the user has stopped dragging a button in a toolbar. It is sent in the form of a WM_NOTIFY message.

TBN_ENDDRAG 
  lpnmtb = (TBNOTIFY FAR *) lParam;

Parameters

lpnmtb
Long pointer to an NMTOOLBAR structure. The iItem member contains the command identifier of the button being dragged.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
