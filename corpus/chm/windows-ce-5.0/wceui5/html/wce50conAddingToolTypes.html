Adding Tool Types

A ToolTip control can support any number of tools. To support a particular tool, you must register the tool with the ToolTip control by sending a TTM_ADDTOOL message to the control. This message includes the address of a TOOLINFO structure that provides information that the ToolTip control requires to display text for the tool.

The following code example shows the syntax for the TOOLINFO structure.

typedef struct tagTOOLINFO{
   UINT cbSize;
   UINT uFlags;
   HWND hwnd;
   WPARAM uId;
   RECT rect;
   HINSTANCE hinst;
   LPTSTR lpszText;
   LPARAM lParam;
} TOOLINFO, NEAR *PTOOLINFO, FAR *LPTOOLINFO;

A ToolTip control supports tools that are implemented as child windows, control windows, or rectangular areas within the client area of a window. When you add a tool that is implemented as a rectangular area, the hwnd member of the TOOLINFO structure must specify the handle to the window that contains the area and the rect member must specify the client coordinates of the bounding rectangle of the area. In addition, the uId member must specify the application-defined identifier for the tool.

When you add a tool that is implemented as a window, the uId member of the TOOLINFO structure must contain the window handle to the tool. Also, the uFlags member must specify the TTF_IDISHWND value, which tells the ToolTip control to interpret the uId member as a window handle.
