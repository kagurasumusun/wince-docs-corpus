NM_CLICK

This message is sent by a list view control when the user clicks an item with the left mouse button. It is sent in the form of a WM_NOTIFY message. 

NM_CLICK lpnmlv = (LPNMLISTVIEW) lParam;

Parameters

lpnmlv
Long pointer to an NMLISTVIEW structure that contains additional information about this message. The iItem, iSubItem, and ptAction members of this structure contain information about the item.

Return Values

The return value for this message is not used.

Remarks

This message is identical to the standard NM_CLICK message except that the list view supplies a NMLISTVIEW structure instead of an NMHDR structure for the lParam.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
