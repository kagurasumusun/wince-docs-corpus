Windows CE Explorer Registry Settings

Settings for Windows CE Explorer are controlled by values under the following registry key.

[HKEY_LOCAL_MACHINE\Explorer]
    "Suspend"=dword:0

If the value of Suspend equals zero, then suspend is not supported on the target device. If the value of Suspend is non-zero or not found, Windows CE Explorer attempts to suspend by calling the GwesPowerOffSystem function.

If a browser is available in the run-time image, you can enable or disable in-place browsing for Windows CE Explorer by setting the following registry value.

[HKEY_LOCAL_MACHINE\Explorer]
    "BrowseInPlace"=dword:0

If the value of BrowseInPlace equals zero, then in-place browsing is disabled. If the value of BrowseInPlace is non-zero, in-place browsing is enabled.

If the HKEY_LOCAL_MACHINE\Explorer\BrowseInPlace registry value does not exist, the value of HKEY_LOCAL_MACHINE\Explorer\BrowseInPlace is set to 1 by default.
