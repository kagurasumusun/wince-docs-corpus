LVM_SETINFOTIP

This message sets the ToolTip text.

To send this message, call the SendMessage function as follows. 

lResult = SendMessage(
  (HWND) hWndControl,     // handle to destination control
  (UINT) LVM_SETINFOTIP,  // message ID
  (WPARAM) wParam,        // = 0; not used, must be zero
  (LPARAM) lParam         // = (LPARAM) (PLVSETINFOTIP) plvSetInfoTip;
);

Parameters

wParam
Must be zero.
plvSetInfoTip
Pointer to a LVSETINFOTIP structure that contains the information to set.

Return Value

Returns TRUE if the ToolTip text is set successful, or FALSE otherwise.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
