TrackBarView_t

This class provides methods for drawing a trackbar.

Method Description
TrackBarView_t::DrawChannel Draws the trackbar channel.
TrackBarView_t::DrawFocus Draws the focus rectangle for the trackbar.
TrackBarView_t::DrawThumb Draws the thumb for a trackbar.
TrackBarView_t::DrawTics Draws all of the tick marks for a trackbar.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Trackbarview.hpp.
