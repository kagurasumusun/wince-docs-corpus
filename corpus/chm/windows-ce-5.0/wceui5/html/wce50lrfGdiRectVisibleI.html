Gdi::RectVisible_I

This method determines whether any part of the specified rectangle lies within the clipping region of the specified device context.

static WINGDIAPI BOOL WINAPI RectVisible_I(
  HDC hdc, 
  CONST RECT* lprc
);

Parameters

hdc
[in] Handle to the device context.
lprc
[in] Long pointer to a RECT structure that contains the logical coordinates of the specified rectangle.

Return Values

Nonzero indicates that some portion of the specified rectangle lies within the clipping region.

Zero indicates that no portion of the specified rectangle lies within the clipping region.

Remarks

This method is an internal version of the RectVisible function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Gdi.hpp.
