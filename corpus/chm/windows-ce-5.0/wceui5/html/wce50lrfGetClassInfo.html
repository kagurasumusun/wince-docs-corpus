GetClassInfo

This function retrieves information about a window class. 

BOOL GetClassInfo( 
  HINSTANCE hInstance, 
  LPCTSTR lpClassName, 
  LPWNDCLASS lpWndClass
);

Parameters

hInstance
Handle to the instance of the application that created the class. To retrieve information about classes defined by the system (such as buttons or list boxes), set this parameter to NULL.
lpClassName
Long pointer to a null-terminated string that contains the class name. The name must be that of a preregistered class or a class registered by a previous call to the RegisterClass function. Alternatively, this parameter can be an integer atom. If so, it must be a global atom created by a previous call to the GlobalAddAtom function. The atom, a 16-bit value less than 0xC000, must be in the low-order word of lpClassName; the high-order word must be zero.
lpWndClass
Long pointer to a WNDCLASS structure that receives the information about the class.

Return Values

Nonzero indicates that the function finds a matching class and successfully copies the data. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

If lpClassName is an atom, it must be an atom returned from RegisterClass.

On MIPS devices, applications should not make direct calls to the function pointer returned by GetClassInfo. They should use CallWindowProc instead.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
