LB_SETCARETINDEX

This message is sent by an application to set the focus rectangle to the item at the specified index in a multiple-selection list box. If the item is not visible, it is scrolled into view. 

LB_SETCARETINDEX wParam = (WPARAM) index;
  lParam = MAKELPARAM(fScroll, 0);

Parameters

index
Zero-based index of the list box item that is to receive the focus rectangle.
fScroll
Boolean that is set to FALSE if the item is scrolled until it is fully visible, or to TRUE if the item is scrolled until it is at least partially visible.

Return Values

LB_ERR indicates that an error has occurred.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
