AYGShell Interfaces

The following table shows the AYGShell interfaces, with a description of the purpose of each.

Programming element Description
INewMenuItemServer This interface serves as an object handler for items created by the New button.
IShellNotificationCallback This interface is used by the shell to interact with a notification.
