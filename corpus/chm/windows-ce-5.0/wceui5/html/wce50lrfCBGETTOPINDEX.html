Platform Builder for Microsoft Windows CE 5.0  

CB_GETTOPINDEX

This message is sent by an application to retrieve the zero-based index of the first visible item in the list box portion of a combo box. Initially the item with index zero is at the top of the list box, but if the list box contents have been scrolled, another item may be at the top. 

CB_GETTOPINDEX wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

The index of the first visible item in the list box of the combo box indicates success. CB_ERR indicates failure.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
