RB_INSERTBAND

This message inserts a new band in a rebar control. 

RB_INSERTBAND wParam = (WPARAM)(UINT) uIndex;
  lParam = (LPARAM)(LPREBARBANDINFO) lprbbi;

Parameters

uIndex
Zero-based index of the location where the band will be inserted. If you set this parameter to –1, the control will add the new band at the last location.
lprbbi
Long pointer to a REBARBANDINFO structure that defines the band to be inserted. Set the cbSize member of this structure to sizeof(REBARBANDINFO) before sending this message.

Return Values

Nonzero indicates success. Zero indicates otherwise.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
