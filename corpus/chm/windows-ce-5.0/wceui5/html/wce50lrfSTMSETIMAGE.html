Platform Builder for Microsoft Windows CE 5.0  

STM_SETIMAGE

This message is sent by an application to associate a new image — icon or bitmap — with a static control.

STM_SETIMAGE wParam = (WPARAM) fImageType; 
  lParam = (LPARAM)(HANDLE) hImage;

Parameters

fImageType
Specifies the type of image to associate with the static control. It is one of the following values:
  • IMAGE_BITMAP
  • IMAGE_ICON
hImage
Handle to the image to associate with the static control.

Return Values

A handle to the image previously associated with the static control, if any, indicates success. NULL indicates otherwise.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
