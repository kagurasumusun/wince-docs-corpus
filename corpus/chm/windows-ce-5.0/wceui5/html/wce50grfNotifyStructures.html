Notify Structures

The following table shows the notify structures, with a description of the purpose of each.

Programming element Description
CE_NOTIFICATION_INFO_HEADER This structure contains information about notification events.
CE_NOTIFICATION_TRIGGER This structure defines what event activates a notification.
CE_USER_NOTIFICATION This structure contains information used to initialize the user notifications settings dialog box, and receives the user's notification preferences entered by way of the dialog box.
