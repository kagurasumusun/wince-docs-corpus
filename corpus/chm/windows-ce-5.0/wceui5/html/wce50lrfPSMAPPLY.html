PSM_APPLY

This message simulates the choice of the Apply Now button, indicating that one or more pages have changed and the changes need to be validated and recorded. 

PSM_APPLY wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

TRUE indicates that all pages successfully applied the changes. FALSE indicates failure.

Remarks

The property sheet sends the PSN_KILLACTIVE message to the current page. If the current page returns FALSE, the property sheet sends the PSN_APPLY message to all pages. You can send the PSM_APPLY message explicitly or by using the PropSheet_Apply macro.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
