Platform Builder for Microsoft Windows CE 5.0  

EN_UPDATE

This message indicates that an edit control is about to display altered text. This message is sent after the control has formatted the text but before it displays the text. This timing makes it possible to resize the edit control window, if necessary. The parent window of the edit control receives this message through the WM_COMMAND message. 

EN_UPDATE 
  idEditCtrl = (int) LOWORD (wParam);
  hwndEditCtrl = (HWND) lParam;

Parameters

idEditCtrl
Identifier of the edit control.
hwndEditCtrl
Handle to the edit control.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windows.h.
