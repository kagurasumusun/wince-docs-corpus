UpdownView_t

This class provides methods for drawing an up-down control.

Method Description
UpdownView_t::HorzDrawSettings Draws a horizontal up-down control.
UpdownView_t::VertDrawSettings Draws a vertical up-down control.
UpdownView_t::SetSunkenBorder Sets the border style for an up-down control.

Remarks

This class implements the default constructor, the default copy constructor, the default assignment constructor, and the default destructor.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Updownview.hpp.
