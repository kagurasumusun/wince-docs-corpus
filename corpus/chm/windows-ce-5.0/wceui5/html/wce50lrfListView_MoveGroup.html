ListView_MoveGroup

This macro moves the group to the specified zero based index. You can use this macro or send the LVM_MOVEGROUP message explicitly. 

ListView_MoveGroup(
   HWND hwnd,
   int iGroupId,
   int toIndex
);

Parameters

hwnd
Handle to the list-view control.
iGroupId
Value of type int that contains the identifier (ID) of the group to move.
toIndex
Value of type int that specifies the index of the item where the group moves. If it is -1. the group is moved to the end of the list.

Return Values

Returns the index of the item that the group was moved to, or -1 if the operation failed.

Remarks

None.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
