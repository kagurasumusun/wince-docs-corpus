Platform Builder for Microsoft Windows CE 5.0  

CacheView_t

This class stores a cache of drawing objects necessary for the Graphics, Windowing, and Events Subsystem (GWES).

Method Description
CacheView_t::ComputeMinWindowSize Retrieves the minimal size at which a window can be drawn.
CacheView_t::GWECacheSetSysColors Sets the colors that the operating system uses for user interface (UI) elements.
CacheView_t::Init Initializes the cache of objects for GWES controls.
CacheView_t::SystemMetrics Retrieves the metrics of specific window elements.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Gcacheview.hpp.
