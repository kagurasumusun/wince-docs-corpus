Creating a Static Control

A static control is a control that is used to display text, to draw frames or lines that separate other controls, or to display icons. A static control does not accept user input, but it can notify its parent window of a stylus tap if the static control is created by using the SS_NOTIFY style. The following screen shot shows two static controls.

Although you can use static controls in overlapped, pop-up, and child windows, they are designed for use in dialog boxes, where Windows CE standardizes their behavior. Windows CE does not support owner-drawn static controls. If the WS_EX_LAYOUTRTL window style is set, the static control has to be mirrored. The reading order can be also be controlled by WS_EX_RTLREADING window style.
