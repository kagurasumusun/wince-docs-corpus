Platform Builder for Microsoft Windows CE 5.0  

TBM_GETSELEND

This message retrieves the ending position of the current selection in a trackbar. 

TBM_GETSELEND wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

Returns a 32-bit value that specifies the ending position of the current selection range.

Remarks

A trackbar can have a selection range only if you specified the TBS_ENABLESELRANGE style when you created it.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
