TabCtrl_DeleteItem

This macro removes an item from a tab control. You can use this macro or send the TCM_DELETEITEM message explicitly.

BOOL TabCtrl_DeleteItem( 
  HWND hwnd, 
  int iItem 
);

Parameters

hwnd
Handle to the tab control.
iItem
Index of the item to delete.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
