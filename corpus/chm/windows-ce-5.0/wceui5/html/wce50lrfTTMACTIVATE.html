Platform Builder for Microsoft Windows CE 5.0  

TTM_ACTIVATE

This message activates or deactivates a ToolTip.

TTM_ACTIVATE wParam = (WPARAM) (BOOL) fActivate;
  lParam = 0;

Parameters

fActivate
Boolean that specifies whether to activate or deactivate the ToolTip. TRUE activates the ToolTip. FALSE deactivates the ToolTip.
lParam
Not used. Set to 0.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Commctrl.h.
