GetWindowThreadProcessId

This function retrieves the identifier of the thread that created the specified window and, optionally, the identifier of the process that created the window.

DWORD GetWindowThreadProcessId(
  HWND hWnd, 
  LPDWORD lpdwProcessId 
);

Parameters

hWnd
[in] Handle to the window.
lpdwProcessId
[out] Pointer to a 32-bit value that receives the process identifier. If this parameter is not NULL, GetWindowThreadProcessId copies the identifier of the process to the 32-bit value; otherwise, it does not.

Return Values

The return value is the identifier of the thread that created the window.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
