EM_GETLINECOUNT

This message retrieves the number of lines in a multiline edit control. 

EM_GETLINECOUNT 
  wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used; set to 0.
lParam
Not used; set to 0.

Return Values

An integer specifying the number of lines in the multiline edit control indicates success. 1 indicates that the edit control contains no text.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windows.h.
