POINT

This structure defines the x- and y-coordinates of a point. 

typedef struct tagPOINT { 
  LONG x; 
  LONG y; 
} POINT;

Members

x
Specifies the x-coordinate of the point.
y
Specifies the y-coordinate of the point.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windef.h.
