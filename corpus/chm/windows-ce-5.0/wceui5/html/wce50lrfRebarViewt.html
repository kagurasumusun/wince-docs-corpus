RebarView_t

This class provides methods for drawing a rebar gripper and for customizing the spacing between items in a rebar.

Method Description
RebarView_t::DrawGripper Draws a gripper bar on a band in a rebar.
RebarView_t::InitSpacingValues Retrieves the spacing between items in a rebar.
RebarView_t::SetEdgeBorderType Sets the style of the edge of the rebar control.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rebarview.hpp.
