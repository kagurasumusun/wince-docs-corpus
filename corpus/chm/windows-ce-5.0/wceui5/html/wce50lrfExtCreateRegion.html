ExtCreateRegion

This function creates a region from the specified region data. 

HRGN ExtCreateRegion(
  CONST XFORM* lpXform,
  DWORD nCount,
  CONST RGNDATA* lpRgnData
);

Parameters

lpXform
[in] Not supported; set to NULL.
nCount
[in] DWORD that specifies the size of the structure, in bytes, to which the lpRgnData parameter points.
lpRgnData
[in] Pointer to an RGNDATA structure that contains the region data in logical units.

Return Values

A handle to the region indicates success.

NULL indicates failure.

Remarks

Region coordinates are represented as 27-bit signed integers.

An application can retrieve data for a region by calling the GetRegionData function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Windows.h.
Link Library: Coredll.lib.
