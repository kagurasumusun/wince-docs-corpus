GDI Messages

The following table shows the GDI messages, with a description of the purpose of each.

Programming element Description
WM_PAINT This message is sent by an application when Windows or another application makes a request to paint a portion of an application's window.
WM_PALETTECHANGED This message is sent by the OS to all top-level and overlapped windows after the window with the keyboard focus realizes its logical palette.
WM_QUERYNEWPALETTE This message informs a window that it is about to receive the keyboard focus, giving the window the opportunity to realize its logical palette when it receives the focus.
WM_SETREDRAW This message is sent by an application to a window to enable changes in that window to be redrawn or to prevent changes in that window from being redrawn.
WM_SYSCOLORCHANGE This message is sent to all top-level windows when a change is made to a system color setting.
