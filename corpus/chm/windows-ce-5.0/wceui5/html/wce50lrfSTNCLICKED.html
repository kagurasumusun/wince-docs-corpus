STN_CLICKED

This message is sent when the user clicks a static control that has the SS_NOTIFY style. The parent window of the control receives this message through the WM_COMMAND message.

STN_CLICKED idStatic = (int) LOWORD(wParam); 
  hwndStatic = (HWND) LOWORD(lParam);

Parameters

idStatic
Identifier of the static control.
hwndStatic
Handle to the static control.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
