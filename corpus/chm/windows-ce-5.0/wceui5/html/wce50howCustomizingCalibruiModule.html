Customizing the Calibrui Module

You can customize the appearance of the touch screen calibration window by modifying the source files in the cloned module. The following list shows the two main source files in this module:

  • Calibrui.cpp. This defines the touch screen calibration UI component. You can customize the UI component by making changes to this file. For information about the functions defined for Calibrui, see Customizing the Touch Screen (Stylus) Calibration User Interface Component.
  • Calibrui_Clone.rc. This is the resource file associated with the Calibrui component.
    Note   You must never change the name of the resource file in a cloned module. It should always be called Calibrui_Clone.rc.

For this how-to, you will change one of the string text messages in the Calibrui_Clone.rc file and verify that the change occurs in the GWES executable file.

To modify the resource file

  1. It is recommended that you make a copy of the Calibrui_Clone.rc file before you make changes to it. Use Windows explorer to navigate to the directory %_WINCEROOT%\PBWorkspaces\ReplaceCalibrui\CalibrUi where the cloned Calibrui module resides.

    Right-click the CalibrUi_clone.rc file and select Rename. Rename the file to CalibrUi_clone_copy.rc.

  2. Select the FileView tab in the workspace. Expand the Projects node, and right-click the Calibrui (gwe2 clone) node to highlight it .
  3. From the Project menu, choose Insert and then choose Resource.
  4. In the Insert Resource dialog box, select String Table and choose New.

    An empty window opens in the IDE for the new resource file.

  5. To populate the empty resource file, open CalibrUi_clone_copy.rc. To open this file, choose File –and then choose Open. To select and copy all of the resource strings in the CalibrUi_clone_copy resource file, choose Edit –and then choose Select All –and then choose Copy. To close the CalibrUi_clone_copy file, choose File –and then choose Close.
  6. To paste the resource strings in the new resource file window choose Edit –and then choose Paste.
  7. You can change a resource string in the new resource file by double clicking a string, and then changing it in the dialog box that appears.

    For example, double-click the string "Press the Esc Key to cancel". In the dialog box that appears, modify the text in the Caption text box to "Press the Esc Key to cancel. Test String". When you press Enter, the dialog box will close.

  8. To save the new resource file, choose File –and then choose Save As, and choose the name the file CalibrUi_clone.rc. To close the file, choose File –and then choose Close.
