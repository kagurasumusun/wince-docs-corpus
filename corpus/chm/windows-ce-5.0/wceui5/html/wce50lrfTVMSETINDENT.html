TVM_SETINDENT

This message sets the width of indentation for a tree view control and redraws the control to reflect the new width. You can send this message explicitly or by using the TreeView_SetIndent macro. 

TVM_SETINDENT wParam = (WPARAM) indent; 
  lParam = 0;

Parameters

indent
Width, in pixels, of the indentation. If this parameter is less than the system-defined minimum width, the new width is set to the system-defined minimum.

Return Values

The return value is not used.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
