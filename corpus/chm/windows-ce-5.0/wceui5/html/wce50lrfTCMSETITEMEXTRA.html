TCM_SETITEMEXTRA

This message sets the number of bytes per tab reserved for application-defined data in a tab control. You can send this message explicitly or by using the TabCtrl_SetItemExtra macro. 

TCM_SETITEMEXTRA wParam = (WPARAM)(int) cb; 
  lParam = 0;

Parameters

cb
Number of extra bytes.
lParam
Not used.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

By default, the number of extra bytes is four. An application that changes the number of extra bytes cannot use the TCITEM structure to retrieve and set the application-defined data for a tab. Instead, you must define a new structure that consists of the TCITEMHEADER structure followed by application-defined members.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
