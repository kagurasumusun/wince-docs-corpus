ListView_SetGroupInfo

This macro sets group information. You can use this macro or send the LVM_SETGROUPINFO message explicitly. 

int ListView_SetGroupInfo(
   HWND hwnd,
   int iGroupId,
   PLVGROUP pgrp
);

Parameters

hwnd
Handle to the list-view control.
iGroupId
Identifier (ID) that specifies the group whose information is set.
pgrp
Pointer to an LVGROUP structure that contains the information to set.

Return Values

Returns the index of the group if successful, or -1 otherwise.

Remarks

None.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
