Supporting Full-Screen Dialog Boxes

On Windows CE-based devices with smaller displays, full-screen child windows, or dialog boxes, can be used to present information. They provide more screen area and command the user's attention. This is a common technique used in applications developed for the Pocket PC.

The AYGShell API extensions, which are used to extend the standard shell, provides the SHInitDialog function for creating full-screen dialog boxes with an OK button on the caption for the dialog box. Additionally, the SHDoneButton function is provided for applications that need to dynamically show or hide the OK button based on an application's state.
