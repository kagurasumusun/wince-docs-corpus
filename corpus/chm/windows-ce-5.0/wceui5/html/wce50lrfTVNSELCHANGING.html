TVN_SELCHANGING

This message notifies a tree view control's parent window that the selection is about to change from one item to another. It is sent in the form of a WM_NOTIFY message. 

TVN_SELCHANGING pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv
Pointer to an NM_TREEVIEW structure. The itemOld and itemNew members contain valid information about the currently selected item and the newly selected item. The action member indicates whether a mouse or keyboard action is causing the selection to change. For a list of possible values, see the description of the TVN_SELCHANGED message.

Return Values

TRUE prevents the selection from changing.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
