LVM_SUBITEMHITTEST

This message determines which list-view item or subitem is at a specified position.

LVM_SUBITEMHITTEST wParam = 0;
  lParam = (LPARAM)(LVHITTESTINFO FAR *)pInfo;

Parameters

wParam
Not used.
pInfo
Pointer to an LVHITTESTINFO structure. The POINT structure within LVHITTESTINFO should be set to the client coordinates to be hit-tested.

Return Values

Returns the index of the item or subitem tested, if any, or –1 otherwise. If an item or subitem is at the specified coordinates, the members of the LVHITTESTINFO structure will be filled with the applicable hit data.

Remarks

Related macro: ListView_SubItemHitTest

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
