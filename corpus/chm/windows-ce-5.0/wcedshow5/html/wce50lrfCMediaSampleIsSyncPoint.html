CMediaSample::IsSyncPoint

Determines if the beginning of a sample is a synchronization point. 

HRESULT IsSyncPoint(void);

Parameters

None.

Return Values

Returns S_OK if the sample is a synchronization point and S_FALSE if not; otherwise, returns an HRESULT error value.

Remarks

This member function implements the IMediaSample::IsSyncPoint method.

It returns the value of the m_dwFlags Sample_SyncPoint property flag.

If the bTemporalCompression member of the AM_MEDIA_TYPE structure is FALSE, all samples are synchronization points.

A filter can begin a stream at any synchronization point.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
