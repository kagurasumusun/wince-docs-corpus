CBaseFilter::Pause

Transitions the filter to State_Paused state if it is not in this state already. 

HRESULT Pause (void);

Parameters

None.

Return Values

Returns an HRESULT value.

Remarks

This member function implements the IMediaFilter::Pause method.

If the filter is in State_Stopped state, the CBasePin::Active member function is called for each of the filter's pins to which it is connected.

If this member function succeeds, the filter's m_State member variable is set to State_Paused.

If any pin returns a failure return value from its Active method, the function fails and the state is not changed.

This member function holds the filter's lock.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 3.0 and later.
