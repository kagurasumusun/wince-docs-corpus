Platform Builder for Microsoft Windows CE 5.0  

CPosPassThru::put_Rate

Sets the rate of playback relative to normal speed. 

HRESULT put_Rate(
  double dRate 
);

Parameters

dRate
Rate to set.

Return Values

Returns E_INVALIDARG if dRate is zero. Otherwise, returns the HRESULT value returned from calling IMediaPosition::put_Rate on the connected pin.

Remarks

This property allows an application to speed up or slow down playback relative to the normal default playback speed.

A rate of 1.0 indicates normal playback speed.

Specifying 2.0 causes playback at twice the normal rate: a video created for 10 frames per second (fps) will be played back at 20 fps, if resources permit.

Audio streams played back at above-normal speed increase the pitch rather than drop frames.

Negative rates indicate reverse play. Not all media will support reverse play.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
