CBaseControlWindow::get_WindowState

Retrieves the current window state. 

HRESULT get_WindowState(
  long* pWindowState
);

Parameters

pWindowState
Window state.

Return Values

Returns an HRESULT value.

Remarks

This member function returns a subset of the parameters of the Win32 ShowWindow function.

In particular, it returns SW_SHOW and SW_HIDE, depending on the current visibility of the window.

It also returns SW_MINIMIZE and SW_MAXIMIZE, depending on whether the window is an icon or is expanded.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 3.0 and later.
