CBaseRenderer::ResetEndOfStream

Resets the end-of-stream flag. 

virtual HRESULT ResetEndOfStream(void);

Parameters

None.

Return Values

Returns an HRESULT value.

Remarks

This member function is typically called when changing to stopped states.

A renderer must keep track of when it gets told that no more data will arrive (this is done when the sourcing filter calls IPin::EndOfStream). At this point the renderer finishes rendering data it has and sends an EC_COMPLETE event to the filter graph manager.

However, when the filter is stopped, the whole state is cleared. When the filter is subsequently run, the source filter signals the end of stream again if it has no data to send.

In this case, the renderer should signal another EC_COMPLETE event to the filter graph manager.

This member function resets the state so that when next requested it will send an EC_COMPLETE event.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
