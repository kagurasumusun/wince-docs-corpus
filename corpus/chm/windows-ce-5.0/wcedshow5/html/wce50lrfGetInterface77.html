GetInterface (DirectShow)

This function retrieves an interface pointer. 

HRESULT GetInterface(
  LPUNKNOWN pUnk,
  void** ppv
);

Parameters

pUnk
Pointer to the IUnknown interface.
ppv
Retrieved interface.

Return Values

Returns an HRESULT value.

Remarks

This member function performs a thread-safe increment of the reference count.

To retrieve the interface and add a reference, call this function from your overriding implementation of the INonDelegatingUnknown::NonDelegatingQueryInterface method.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
