IOverlay::GetPalette

This method retrieves the current system palette. 

HRESULT GetPalette(
  DWORD* pdwColors,
  PALETTEENTRY** ppPalette
);

Parameters

pdwColors
[out] Number of colors present.
ppPalette
[out] Retrieved palette structure.

Return Values

Returns an HRESULT value that depends on the implementation.

HRESULT can be one of the following standard constants, or other values not listed.

Value Description
E_FAIL Failure.
E_POINTER Null pointer argument.
E_INVALIDARG Invalid argument.
E_NOTIMPL Method is not supported.
S_OK or NOERROR Success.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
