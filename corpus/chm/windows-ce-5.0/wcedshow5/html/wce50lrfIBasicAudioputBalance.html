IBasicAudio::put_Balance

This method sets the balance of the audio signal. 

HRESULT put_Balance(
  long lBalance
);

Parameters

lBalance
[in] Value to which to set the Balance property.

The allowable input range is –10,000 to 10,000.

A value of 0 sets a neutral balance: both left and right speakers are given the same amplitude audio signal.

Return Values

Returns an HRESULT value.

E_INVALIDARG is returned for values outside the allowable input range and E_FAIL is returned if the underlying device returns an error.

Remarks

As with the Volume property, units correspond to .01 decibels (multiplied by –1 when lBalance is a positive value). For example, a value of 1000 indicates –10 dB on the right channel and –90 dB on the left channel.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
