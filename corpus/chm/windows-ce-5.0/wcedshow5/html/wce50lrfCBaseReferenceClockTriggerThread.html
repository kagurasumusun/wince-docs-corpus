CBaseReferenceClock::TriggerThread

Triggers the advise thread's event. 

void TriggerThread( );

Parameters

None.

Return Values

None.

Remarks

The clock uses a worker thread that should wake up and call CAMSchedule::Advise at the appropriate time.

If the clock adds an event that should be fired earlier than an outstanding event, the worker thread must be awoken to reevaluate its wait time.

The TriggerThread member function wakes the worker thread so this can take place.

If a derived clock causes time to jump forward, TriggerThread should be called so the wait time can be reevaluated; otherwise, the events fire late.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
