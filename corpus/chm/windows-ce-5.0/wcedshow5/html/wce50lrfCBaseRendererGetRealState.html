CBaseRenderer::GetRealState

Retrieves the actual state of the renderer. 

FILTER_STATE GetRealState(void);

Parameters

None.

Return Values

Returns m_State, the state flag for the renderer.

Remarks

This member function provides an internal way of getting the real state.

Calling through the IBaseFilter interface to get the state would require the main filter critical section to be taken; this internal method does not do this.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
