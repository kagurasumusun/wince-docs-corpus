CBaseRenderer::OnReceiveFirstSample

Provides derived classes with an opportunity to render static data. 

virtual void OnReceiveFirstSample(
  IMediaSample* pMediaSample
);

Parameters

pMediaSample
Media sample.

Return Values

None.

Remarks

This member function is unimplemented.

It is primarily used by video renderers. When they receive their first sample while paused, they typically draw the frame as a poster image. This virtual method is called by the base classes when the first sample arrives.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
