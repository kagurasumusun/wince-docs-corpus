Supported Audio Codecs and Renderers

The following table shows all the audio codecs and renderers supported by DirectShow on Windows CE.

Catalog item Function Windows CE version
Waveform Audio Renderer A generic audio rendering filter that you can connect to the output of any of the following filters, if they contain WAV audio:
  • File source (Async)
  • File source (URL)
  • MPEG-1 stream splitter
  • AVI splitter
  • WAVE parser
  • Any audio transform filter
 2.12 or later
MPEG-1 Layer 1 and 2 Audio Codec The MPEG Audio Decoder filter decompresses MPEG-1 layers 1 and 2 audio data. 2.12 or later
