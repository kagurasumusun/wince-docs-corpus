CBaseReferenceClock::SetTimeDelta

Sets a delta on the time that CBaseReferenceClock::GetPrivateTime will return. 

HRESULT SetTimeDelta(
  const REFERENCE_TIME& TimeDelta
);

Parameters

TimeDelta
REFERENCE_TIME delta to be added.

Return Values

Returns NOERROR.

Remarks

CBaseReferenceClock::GetTime never returns a time earlier than a previously returned time. Thus, if you set the clock to a time in the past, successive calls to CBaseReferenceClock::GetTime return the current value until this new time is reached, and the clock starts to increment again.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
