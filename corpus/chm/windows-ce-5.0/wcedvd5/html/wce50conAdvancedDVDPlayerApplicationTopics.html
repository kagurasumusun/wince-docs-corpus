Advanced DVD Player Application Topics

With the DVD-Video API, you can write applications that go beyond simple play-pause-stop functionality on a separate monitor. You can create applications that are fully integrated into your Windows CE device, including playback in a window on your device's screen.

These subjects are discussed in the following topics:
