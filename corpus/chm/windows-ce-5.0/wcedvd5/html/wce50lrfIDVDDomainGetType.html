IDVDDomain::GetType

This method returns the type of the current domain.

HRESULT GetType(
  EDVDDomainType* pDType
);

Parameters

pDType
[out] Returns an EDVDDomainType indicating the current domain type.

Return Values

This method always succeeds. The return value is S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
