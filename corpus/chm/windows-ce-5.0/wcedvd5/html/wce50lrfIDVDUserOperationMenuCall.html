IDVDUserOperation::MenuCall

This method calls the system menu specified by byteMenu_ID.

HRESULT MenuCall(
  BYTE byteMenu_ID
);

Parameters

byteMenu_ID
[in] Specifies one of the following system menus.
Value System menu
DVD_MENU_TITLE Title menu
DVD_MENU_ROOT Root menu
DVD_MENU_SUBPICTURE Subpicture menu
DVD_MENU_AUDIO Audio menu
DVD_MENU_ANGLE Angle menu
DVD_MENU_PTT Part of title (PTT) menu

Return Values

If the function succeeds, the return value is S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdnav.h, Dvdnav.idl.
Link Library: Ddvdids.lib.
