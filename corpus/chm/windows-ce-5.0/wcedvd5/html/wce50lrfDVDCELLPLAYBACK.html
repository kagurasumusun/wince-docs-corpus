DVD_CELL_PLAYBACK

This structure contains cell playback information (C_PBI).

typedef struct {
  UINT32 cellCategory;
  UINT32 cellPlaybackTime;
  UINT32 startFirstVobu;
  UINT32 endFirstIlvu;
  UINT32 startLastVobu;
  UINT32 endLastVobu;
} DVD_CELL_PLAYBACK;

Members

cellPlaybackTime
C_PBTM element of C_PBI.
startFirstVobu
C_FVOBU_SA element of C_PBI.
endFirstIlvu
C_FILVU_EA element of C_PBI.
startLastVobu
C_LOVOB_SA element of C_PBI.
endLastVobu
C_LVOUBU_EA element of C_PBI.

Requirements
