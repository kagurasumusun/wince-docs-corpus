IDVDDataSearchInfo::GetUnitEndAddress

This method returns the video object unit end address (VOBU_EA) from the data search information general information (DSI_GI).

HRESULT GetUnitEndAddress(
  UINT32* pRLBN
);

Parameters

pRLBN
[out] Pointer to the relative logical block number (RLBN) of the last pack in the video object unit (VOBU).

Return Values

If the function succeeds, the return value is S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
