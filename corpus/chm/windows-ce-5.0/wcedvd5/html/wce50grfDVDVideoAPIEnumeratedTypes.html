DVD-Video API Enumerated Types

The following enumerated types are used with the DVD-Video API.

Programming element Description
EDDVDPlaybackState Identifies the playback state of the DVD player.
EDVDDomainType Lists the DVD-Video domains.
EDVDNavException Lists the types of navigation errors that can occur.
EDVDSParamEvent Lists the categories of events that require a player application to initialize system parameter (SPRM) values.
ENavCmdArea Lists the program (PG) commands.
EPGCLinkType Lists the program chain navigation links (PGC_NV_CTL).
EPGCPlaybackMode Lists the possible playback modes for a program chain.
