IDVDDomain::GetVOBUTablePtr

This method returns pointer to an array of video object (VOB) addresses for the current domain.

HRESULT GetVOBTablePtr(
  UINT32** ppVOBUAddressArray 
);

Parameters

ppVOBUAddressArray
[out] Pointer to the array of VOB addresses for the current domain.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be the following error value.

Error value Description
E_NOINTERFACE The method was unable to obtain and return an interface pointer.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
