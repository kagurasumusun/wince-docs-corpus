DVD-Video API Structures

The following structures are used with the DVD-Video API.

Programming element Description
DVD_AUDIO_MU_ATTR Provides video title set audio stream attributes for a single audio stream, VTS_MU_AST_ATR(1) and VTS_MU_AST_ATR(2).
DVD_AUDIO_STREAM_ATTR Contains the contents of one of the three different kinds of audio stream attributes, VMGM_AST_ATR, VTSM_AST_ATR, or VTS_AST_ATR.
DVD_CELL_PIECE Contain the contents of one of the three different kinds of cell piece information, VMGI_CPI, VTS_CPI, or VTSM_CPI.
DVD_CELL_PLAYBACK Contains cell playback information (C_PBI).
DVD_ISRC Contains International Standard Recording Code (ISRC) information.
DVD_NAV_CMD Contains program chain navigation control (PGC_NV_CTL) information.
DVD_POS_CODE Corresponds to POS_CD as defined in the DVD Specification for Read-Only Disc.
DVD_PROVIDER_ID Contains provider-unique identifier (PVR_ID) data.
DVD_RECT This structure contains the position and size coordinates for a button, derived from BTN_POSI.
DVD_SUBPICTURE_STREAM_ATTR Contains video title set subpicture stream attribute (VTS_SPST_ATR) information.
DVD_TEXT_ITEM Contains item text search pointer (IT_TXT_SRP) data.
DVD_TEXT_LANGUAGE_UNIT Contains text data language unit search pointer (TXTDT_LU_SRP) data.
DVD_TITLE_SET_INFO Contains title search pointer (TT_SRP) data.
DVDUserGOPData Contains user data in the group of pictures (GOP) layer.
