IDVDROM::ReadVTSI

This method returns the video title set information (VTSI). This method is used internally by the DVD-Video API and is not generally used by applications.

HRESULT ReadVTSI
  UINT32* length,
  UINT8** bufPtr 
);

Parameters

length
[out] Contains the length of the VTSI if the call succeeds.
bufPtr
[out] Contains the VTSI if the call succeeds.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_FAIL The method failed.
E_HANDLE The method encountered an invalid handle.
E_UNEXPECTED The method encountered an unexpected error.
E_OUTOFMEMORY There was not enough memory available for the operation.

Remarks

A call to IDVDROM::ReleaseMem, passing bufptr, must be made to free the memory allocated by IDVDROM::ReadVTSI when the VTSI is no longer needed.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
