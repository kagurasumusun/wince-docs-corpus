DVD-Video API Object Architecture

The DVD-Video API is a COM-based middleware framework that provides playback of DVD-Video. The DVD player application uses the DVD-Video API to start and control DVD playback.

The DVD-Video API is implemented by two COM components: DVDDataObject and DVDNavigationManager.

A DVDData object is responsible for binding to a physical media and parsing all information on a DVD volume. You bind a DVDData object to a DVD volume by providing a Unicode path to the DVD-Video information.

This allows you to read DVD-Video data from a variety of sources, including traditional DVD discs and DVD data files. A player application may examine DVD content and logical DVD data with the rich set of data access interfaces exposed in the DVDData object.

The DVDNavigationManager object uses DVDData object interfaces to access all necessary data for media playback, user interaction, and navigation command execution, all according to the DVD-Video specification.

This allows DVD-Video player applications a great deal of flexibility in controlling DVD playback operations. An application can use all DVDData object interfaces as needed to access navigational information for implementation of advanced user interface and navigation control.

The application creates an object that implements the interfaces for IDVDNavDataStatusSink to provide what are essentially callbacks from the middleware when certain events, such as navigation pack and highlight changes, occur during playback.
