IDVDProgramChain::GetNavCommandsCount

This method reads the program chain general information (PGC_GI) for the current program chain (PGC) and returns the number of program command of a specified type from the PGC command table information (PGC_CMDTI).

HRESULT GetNavCommandsCount(
  ENavCmdArea eArea,
  UINT16* pCount
);

Parameters

eArea
[in] Specifies the type of command count according to the following values.
Value Command type
0 Pre command (PRE_CMD)
1 Post command (POST_CMD)
2 Cell command (C_CMD)
pCount
[out] Pointer to the number of commands found for the command type specified by eArea (PRE_CMD_Ns, POST_CMD_Ns, and C_CMD_Ns) .

Return Values

If this method succeeds, the return value is S_OK.

If this method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments is invalid.
E_NOINTERFACE The method was unable to obtain and return an interface pointer.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
