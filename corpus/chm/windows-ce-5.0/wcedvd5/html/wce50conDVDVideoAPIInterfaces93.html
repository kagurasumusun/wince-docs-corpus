DVD-Video API Interface Map

The DVD-Video API provides its functionality through application programming interfaces (APIs) implemented by its objects.

There are two ways to obtain pointers to DVD-Video API interfaces.

  • You can obtain a pointer to an interface implemented by an object by running a IUnknown::QueryInterface on the object.
  • Some interface methods will return pointers to other interfaces.

The following illustration shows the natural hierarchy of the DVDData object's interfaces.

The arrows show cases where one interface will return a pointer to another interface through a method. Given that it is possible to obtain a pointer to an interface at any time through QueryInterface on a DVDData object, it is important for you to be aware of how you obtained a pointer to a DVD-Video API interface when you are working with it.

For example, suppose that you obtained a pointer to an IDVDTitleSet interface by calling the IDVDDomain::GetTitleSet method.

A call to IDVDTitleSet::GetDomain would return a pointer to the IDVDDomain interface.

On the other hand, if you obtained your IDVDTitleSet pointer by calling QueryInterface on a DVDData object, a call to IDVDTitleSet::GetDomain would return a pointer to a new instance of IDVDDomain.
