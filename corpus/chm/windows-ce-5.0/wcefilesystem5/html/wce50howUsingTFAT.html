Using TFAT

Once you have chosen to use TFAT as the file system for a volume, you can then implement TFAT. After you have implemented TFAT on a volume, your volume will include the transaction-safe functionality that TFAT provides. To implement TFAT on a volume, you must perform one of the following three procedures.

To use TFAT on a volume

  1. In the Windows CE Control Panel, choose Storage Manager.
  2. In the FAT Utility dialog box, choose the desired partition to format, or create a partition if one is not available.
  3. From the Properties menu, choose Format.

    - or -

    Set the FormatTfat registry setting for FATFS to 1.

    If this value is set to 1, any unformatted volume will automatically be formatted as a TFAT volume.

    - or -

    If a volume has already been formatted as a FAT volume, enable TFAT by setting the FATFS_FORCE_TFAT registry flag for the FAT volume.

    The FAT volume must have 2 FATs in order to be converted to TFAT. Operations in directories that have already been created using FAT may not be transaction-safe.
