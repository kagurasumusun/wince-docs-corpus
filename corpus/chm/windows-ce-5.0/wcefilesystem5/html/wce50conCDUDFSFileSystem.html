CD/UDFS File System

The Compact Disc File System (CDFS) and Universal Disc File System (UDFS) are used to read compact discs (CDs), digital video discs (DVDs), and CD-ROMs. CDFS and UDFS use the ATAPI block driver for navigating and audio/video playback. The CDFS follows to the ISO 9660 specification and supports long file names.

The following table shows the environment variables to set to use either the CDFS or UDFS.

Environment variable Catalog Item
SYSGEN_1394 IEEE 1394
SYSGEN_UDFS CDFS/UDFS
SYSGEN_USB Univeral Serial Bus (USB)
