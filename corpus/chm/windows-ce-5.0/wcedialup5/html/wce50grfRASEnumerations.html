RAS Enumerations

The following table shows the RAS enumerations with a description of the purpose of each.

Programming element Description
RASCONNSTATE This enumeration type contains values that specify the states that may occur during a RAS connection operation.
RASPROJECTION This enumeration type defines values that specify a particular authentication protocol or Point-to-Point Protocol (PPP) control protocol.
