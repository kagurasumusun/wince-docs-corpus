Relevant RFCs for PPP

PPP is a standardized Internet protocol. Its specifications have been published in a set of requests for comments (RFCs) issued by the Internet Engineering Task Force (IETF). The following table shows the RFCs that contain specifications for PPP.

1471 The Definitions of Managed Objects for the Link Control Protocol of the Point-to-Point Protocol
