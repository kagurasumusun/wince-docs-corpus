Fonts Security

In addition to supporting True Type and raster font technologies, Windows CE provides a wide range of fonts from which to choose to implement in your device. Windows CE also provides an OEM the flexibility to add third party font files into the run-time image. However, use caution when you include font files from a third party in your run-time image, because malicious code can potentially threaten the security of your device.

Best Practices

Always use a font file from a trusted source

You must always use a font file from a trusted source in your run-time image, because a malicious font file in the run-time image can potentially threaten the security of your device.

Default Registry Settings

You should be aware of the registry settings that impact security. If a value has security implications, you will find a Security Note in the registry settings documentation.

For Fonts registry information, see Font Registry Settings.

Ports

No specific ports are used for Fonts.
