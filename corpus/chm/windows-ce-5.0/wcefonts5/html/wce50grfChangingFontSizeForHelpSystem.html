Changing the Font Size for the Help System

Windows CE determines the font size selected for Help based on registry settings. When the user opens Help for the first time, the HKEY_CURRENT_USER\Software\Apps\PocketIE\ZoomSetting registry setting for the Pocket Internet Explorer browser determines the font size. The possible values for this registry entry are 0, 1, 2, 3, and 4. These zoom settings correspond to the smallest, smaller, medium, larger, and largest font sizes for the browser. If this registry entry does not exist, Help uses the medium font size (2) by default.

If a user changes the font size within Help, the new font size is saved in the HKEY_CURRENT_USER\SOFTWARE\Microsoft\HELP\ZoomSetting registry entry. Help uses the font size specified by this registry setting, rather than the size specified by the registry setting for Pocket Internet Explorer, when the user subsequently uses Help.
