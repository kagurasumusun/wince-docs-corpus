Smart Card Migration

The following items are important to understand when you migrate an OS design that uses Smart Card:

Migrating from Windows CE .NET 4.2 to Windows CE 5.0

  • If you are using the Smart Card Reader helper library you must relink your Windows CE 4.x driver in Windows CE 5.0. Due to changes in the interface between the private Smart Card Reader helper library and the Smart Card resource manager, Windows CE 4.x drivers will not function as expected in an OS design based on Windows CE 5.0 unless they are relinked.

For general migration information, see Migrating from an Earlier Version of Windows CE.
