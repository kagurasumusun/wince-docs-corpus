Retrieving MSMQQueueInfo.BasePriority

The priority level of a queue specifies a single base priority for all messages sent to a public queue.

By default, the priority level of a queue is 0.

Note   If your application does not have MQSEC_GET_QUEUE_PROPERTIES access rights for the queue, an MQ_ERROR_ACCESS_DENIED error is returned to MSMQQueueInfo.Refresh.

To retrieve MSMQQueueInfo.BasePriority

  1. Declare the MSMQQueueInfo variable for the queue.
  2. Obtain an MSMQQueueInfo object.
  3. (Optional) Call MSMQQueueInfo.Refresh if other applications may have changed the priority level of the queue.
  4. Use MSMQQueueInfo.BasePriority as needed.
