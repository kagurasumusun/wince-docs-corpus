Sending a Date in a Message (COM)

Sending a message consists of the following processes:

  • Opening a queue with send access
  • Creating the message
  • Calling the Send method
  • Closing the queue

The following procedure and example code show how this is done when sending a message whose body contains a Date type.

To send a Date in a message

  1. Declare MSMQQueueInfo, MSMQQueue, and MSMQMessage objects.
  2. Create a destination queue and open it with send access.
  3. Send the message with a Date body type.
  4. Close the queue.
