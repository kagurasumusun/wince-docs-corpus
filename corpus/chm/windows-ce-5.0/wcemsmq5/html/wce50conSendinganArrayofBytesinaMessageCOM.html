Sending an Array of Bytes in a Message (COM)

Sending a message consists of the following processes:

  • Opening a queue with send access
  • Creating the message
  • Calling the MSMQMessage.Send method
  • Closing the queue

The following procedure shows how this is done when sending a message whose body contains an array of bytes.

To send an array of bytes in a message body

  1. Declare MSMQQueueInfo, MSMQQueue, and MSMQMessage objects.
  2. Create a destination queue and open it with send access.
  3. Send the message with an array of bytes in the message body.
  4. Open the destination queue with receive access and retrieve the message.
  5. Verify that the body of the retrieved message body is an array of bytes.
