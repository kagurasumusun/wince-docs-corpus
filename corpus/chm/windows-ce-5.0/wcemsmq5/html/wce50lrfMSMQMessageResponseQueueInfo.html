MSMQMessage.ResponseQueueInfo

This property specifies a queue for receiving response messages returned from the receiving application.

HRESULT get_ResponseQueueInfo( 
  IMSQQueueInfo** ppinfoResponse 
);
HRESULT putref_ResponseQueueInfo( 
  IMSQQueueInfo* pinfoResponse
);

Parameters

ppinfoResponse or pinfoResponse
Queue information (MSMQQueueInfo) object that represents the response queue.

Return Values

The following table describes the common return values.

Value Description
S-OK Success
E_INVALIDARG One or more arguments are invalid
E_NOTIMPL The function contains no implementation
E_OUTOFMEMORY Out of memory

Remarks

ResponseQueueInfo is used to send the format name of another queue to the receiving application. Typically, this is done so the receiving application can send response messages back to the sending application.

Note   The MSMQQueueInfo object of a private queue (which is inaccessible otherwise) can also be sent using ResponseQueueInfo.

Messages returned to the response queue are application defined. The application must define what is in the messages as well as what is to be done when a message is received.

You can also set and retrieve the response queue when using Message Queuing function calls.

For information on See
Setting and retrieving the response queue using Message Queuing function calls PROPID_M_RESP_QUEUE
