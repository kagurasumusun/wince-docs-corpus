Using Multiple Screen Applications on Different Systems

If you are developing an application that runs on both single screen and multiple screen systems, you should be aware of the following issues:

  • A parent or related window can be on a different screen than a child window. To locate the screen that contains a window, applications should use the MonitorFromWindow function.
  • To map mouse input sent in absolute coordinates to the coordinates of the entire virtual screen, use the INPUT structure with the MOUSEEVENTF_ABSOLUTE and MOUSEEVENTF_VIRTUALDESKTOP mouse events. For more information about mouse events, see the mouse_event function.
  • The BitBlt function works well for multiple screen systems. In contrast, the MaskBlt and StretchBlt functions fail if the source and destination device contexts differ.
