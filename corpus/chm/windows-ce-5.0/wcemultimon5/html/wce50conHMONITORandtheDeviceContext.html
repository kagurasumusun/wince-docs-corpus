HMONITOR and the Device Context

The OS represents each physical screen by a handle of type HMONITOR. A valid HMONITOR is guaranteed to be non-NULL. A screen has the same HMONITOR as long as the screen remains part of the system.

Any function that returns a display device context normally returns a device context for the primary screen. To obtain the device context for another screen, use the EnumDisplayMonitors function. Alternatively, you can use the screen name that the GetMonitorInfo function retrieves in the MONITORINFOEX structure to create a device context with the CreateDC function. However, if a function, such as GetWindowDC or BeginPaint, retrieves a device context for a window that spans more than one screen, the device context also spans multiple screens.

To create support for a secondary display, an application must call the CreateDC function with the name of the secondary display driver as the first parameter. The application creating the device context is responsible for all of the drawing to that display surface. Set the Sysgen variable SYSGEN_MULTIMON=1 to enable multiple monitors.
