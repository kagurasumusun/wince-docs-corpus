ldap_search_abandon_page

This function terminates a paged-results search.

ULONG ldap_search_abandon_page(
  LDAP* ExternalHandle,
  LDAPSearch* SearchBlock
);

Parameters

ExternalHandle
[in] Session handle.
SearchBlock
[in] Handle to the search block for the current search.

Return Values

If this function succeeds, the return value is LDAP_SUCCESS.

If this function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Call this function after a search has completed (when the server returns LDAP_NO_RESULTS_RETURNED) to perform necessary cleanup. You can also use this function to abandon a search at any time after the search block has been allocated.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
