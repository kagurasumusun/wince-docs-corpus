Differences Between the LDAP Implementation in Windows CE and Windows Server 2003

If you are familiar with the Windows Server 2003 implementation of LDAP, you will be similarly familiar with the implementation available in Windows CE, which has been ported from Windows Server 2003. The following table shows the support distinctions:

Technology Available Support
Client-side operations Supported
Server-side operations Not supported
Unicode Supported
Active Directory Service Interface (ADSI) Not supported

In Windows Server 2003, the registry setting of type DWORD for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\LDAP\LdapClientIntegrity key is not set by default. In Windows CE, this registry key is set to 0 by default. For more information, see LDAP Registry Settings.
