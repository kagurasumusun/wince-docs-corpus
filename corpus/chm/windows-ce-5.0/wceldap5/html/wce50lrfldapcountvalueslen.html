ldap_count_values_len

This function counts the number of values in a list.

ULONG ldap_count_values_len(
  struct berval** vals
);

Parameters

vals
[in] Array of values returned by ldap_get_values_len.

Return Values

If this function succeeds, it returns the number of values.

If this function fails, the return value is 0.

Remarks

This function returns the number of binary values in an array of berval structures. To count the values in an array of character strings, call the ldap_count_values function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
