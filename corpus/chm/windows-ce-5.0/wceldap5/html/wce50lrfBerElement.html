BerElement

This structure is used for basic encoding rules (BER) encoding. 

typedef struct berElement {
  UNICODE PTCHAR opaque; 
} BerElement;

Members

opaque
Pointer to an opaque buffer. Do not try to access it.

Remarks

This is an opaque data structure that the ldap_first_attribute function allocates and returns to indicate the current position during a traversal of an attribute list. Pass the pointer to this structure to the ldap_next_attribute function.

Note   You do not free the memory associated with this structure or its pointer when the BerElement is no longer needed.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
