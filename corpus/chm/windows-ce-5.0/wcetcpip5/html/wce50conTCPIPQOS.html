TCP/IP and QOS

Quality of Service (QOS) is an industry-wide initiative that enables more efficient use of the network. It is a collection of components that are used to provide preferential treatment to specific data, enabling that data to traverse the Internet or intranet with higher quality transmission.

The following list shows how developers can use QOS:

  • Create or retrofit mission-critical applications to operate as if network traffic conditions were ideal, even when the network is extremely congested.
  • Create real-time applications, such as IP telephones or streaming multimedia, that receive transmission service that enable optimal functioning, regardless of traffic conditions between sender and receiver.
  • Create or retrofit applications that efficiently use the network such that their transmissions adhere to agreed-upon characteristics. By doing so, the entire QOS-enabled network becomes more manageable and more efficient to use.

QOS achieves these capabilities through programmatic interfaces, the cooperation of multiple components, and communication with network devices throughout the end-to-end network solution.

The Internet Engineering Task Force (IETF) has provided many documents in the form of Internet drafts and Request for Comments (RFC) that outline QOS capabilities. For more information, see the Internet Engineering Task Force Web site.
