IcmpParseReplies

This function parses the reply buffer provided and returns the number of ICMP responses found.

DWORD IcmpParseReplies(
  LPVOID ReplyBuffer,
  DWORD ReplySize
);

Parameters

ReplyBuffer
The same buffer that was passed to IcmpSendEcho2. This is rewritten to hold an array of ICMP_ECHO_REPLY structures; that is, the type is PICMP_ECHO_REPLY.
ReplySize
The size of the above buffer.

Return Values

Returns the number of ICMP responses found. If there is an error, the return value is zero. To get extended error information, call GetLastError.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: icmpapi.h.
Link Library: Iphlpapi.dll.
