IP_PER_ADAPTER_INFO

This structure contains information specific to a particular adapter.

typedef struct _IP_PER_ADAPTER_INFO {
  UINT AutoconfigEnabled;
  UINT AutoconfigActive;
  PIP_ADDR_STRING CurrentDnsServer;
  IP_ADDR_STRING DnsServerList;
} IP_PER_ADAPTER_INFO, *PIP_PER_ADAPTER_INFO;

Members

AutoconfigEnabled
Specifies whether auto-configuration is enabled on this adapter.
AutoconfigActive
Specifies whether auto-configuration is active on this adapter.
CurrentDnsServer
Not used.
DnsServerList
Specifies the list of possible DNS servers for this adapter.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Iptypes.h.
