ICMP Structures

The following table shows the ICMP structures with a description of the purpose of each.

Programming element Description
ICMP_ECHO_REPLY This structure describes the data returned in response to an echo request (IcmpSendEcho).
IP_OPTION_INFORMATION This structure describes the options to be included in the header of an IP packet.
