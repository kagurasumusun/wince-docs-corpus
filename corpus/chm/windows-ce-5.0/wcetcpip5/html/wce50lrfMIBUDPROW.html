MIB_UDPROW

This structure contains address information for sending and receiving User Datagram Protocol (UDP) datagrams.

typedef struct _MIB_UDPROW {
  DWORD dwLocalAddr; 
  DWORD dwLocalPort; 
} MIB_UDPROW, *PMIB_UDPROW;

Members

dwLocalAddr
Specifies the IP address on the local computer.
dwLocalPort
Specifies the port number on the local computer.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Iprtrmib.h.
