IP Helper Enumerations

The following table shows the IP Helper structures with a description of the purpose of each.

Programming element Description
IF_OPER_STATUS Specifies the operational status of an interface.
IP_DAD_STATE Specifies information about the duplicate address detection (DAD) state.
IP_PREFIX_ORIGIN Specifies the origin of an IP address prefix, and is used with the IP_ADAPTER_UNICAST_ADDRESS structure.
IP_SUFFIX_ORIGIN Specifies the origin of an IP address suffix, and is used with the IP_ADAPTER_UNICAST_ADDRESS structure
SCOPE_LEVEL Identifies scope levels for IPv6 addresses, and is used with IP_ADAPTER_ADDRESSES.
