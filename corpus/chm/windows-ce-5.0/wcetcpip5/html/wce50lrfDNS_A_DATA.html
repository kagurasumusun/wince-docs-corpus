DNS_A_DATA

This structure represents a DNS address (A) record.

typedef struct {
   IP4_ADDRESS IpAddress;
} DNS_A_DATA, *PDNS_A_DATA;

Members

IpAddress
[in] IP address, in the form of an IP4_ADDRESS datatype.

Remarks

This structure is used in conjunction with the DNS_RECORD structure to programmatically manage DNS entries.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Windns.h.
