Internet Protocol Helper APIs

Internet Protocol Helper (IP Helper) provides application programming interfaces (APIs) that assist in the network administration of the local computer. You can use IP Helper to programmatically retrieve information about the network configuration of the local computer, and to modify that configuration. IP Helper also provides notification mechanisms to ensure that an application is signaled when certain aspects of the network configuration change on the local computer.

IP Helper supports IPv6. For more information about IPv6, see Core Protocols of IPv6 and IPv6 Addressing.

IP Helper provides capabilities in the following areas:

  • Retrieving Information About Network Configuration
  • Managing Network Adapters
  • Managing Interfaces
  • Managing IP Addresses
  • Using the Address Resolution Protocol
  • Retrieving Statistics for IP and ICMP
  • Managing Routing
  • Receiving Notification of Network Events
  • Retrieving Statistics for TCP and UDP
