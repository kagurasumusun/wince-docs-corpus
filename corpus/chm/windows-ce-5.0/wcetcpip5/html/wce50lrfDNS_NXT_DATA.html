DNS_NXT_DATA

This structure represents a DNS next (NXT) record.

typedef struct {
   LPTSTR pNameNext;
   WORD wNumTypes;
   WORD wTypes[1];
} DNS_NXT_DATA, *PDNS_NXT_DATA;

Members

pNameNext
[in] Pointer to a string representing the name of the next domain.
wNumTypes
[in] Number of elements in the wTypes array.
wTypes
[in] Array of resource record type mnemonics for the owner name of the next resource record.

Remarks

This structure is used in conjunction with the DNS_RECORD structure to programmatically manage DNS entries.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Windns.h.
