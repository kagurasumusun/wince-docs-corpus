IElementBehaviorLayout::GetPosition Method

Retrieves the position of the element.

Syntax

HRESULT GetPosition(      
    LONG lFlags,
    POINT *pptTopLeft
);

Parameters

lFlags
[in] Specifies the type of layout control that is a value from the BEHAVIOR_LAYOUT_MODE enumeration.
pptTopLeft
[in, out] Pointer to a POINT structure that specifies the upper left corner of the layout rectangle.

Return Value

Returns S_OK if successful, or an error value otherwise.
