IElementBehaviorRender::GetRenderInfo Method

Retrieves rendering information for the Dynamic HTML (DHTML) behavior.

Syntax

HRESULT GetRenderInfo(      
    LONG *plRenderInfo
);

Parameters

plRenderInfo
[in, out, retval] Pointer to an unsigned long integer value that specifies how the DHTML behavior is rendered. It can be one or more of the following values.
BEHAVIORRENDERINFO_BEFOREBACKGROUND
Renders the behavior before rendering the background.
BEHAVIORRENDERINFO_AFTERBACKGROUND
Renders the behavior after rendering the background.
BEHAVIORRENDERINFO_BEFORETEXT
Renders the behavior before rendering the text.
BEHAVIORRENDERINFO_AFTERTEXT
Renders the behavior after rendering the text.
BEHAVIORRENDERINFO_BEFOREFOREGROUND
Renders the behavior before rendering the foreground.
BEHAVIORRENDERINFO_AFTERFOREGROUND
Renders the behavior after rendering the foreground.
BEHAVIORRENDERINFO_DISABLEBACKGROUND
Disables MSHTML rendering of the background.
BEHAVIORRENDERINFO_DISABLENEGATIVEZ
Disables MSHTML rendering of negative z positions.
BEHAVIORRENDERINFO_DISABLETEXT
Disables MSHTML rendering of text.
BEHAVIORRENDERINFO_DISABLEPOSITIVEZ
Disables MSHTML rendering of positive z positions.
BEHAVIORRENDERINFO_HITTESTING
Behavior participates in hit testing.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method is available in Microsoft® Internet Explorer 5 but is not supported in later versions. Instead, use the IHTMLPainter and IHTMLPaintSite interfaces.
