IElementNamespaceFactoryCallback::Resolve Method

Provides MSHTML with information about the implementation of an element behavior.

Syntax

HRESULT Resolve(      
    BSTR bstrNamespace,
    BSTR bstrTagName,
    BSTR bstrAttrs,
    IElementNamespace *pNamespace
);

Parameters

bstrNamespace
[in] BSTR that specifies the name of the namespace.
bstrTagName
[in] BSTR that specifies the name of the element behavior.
bstrAttrs
[in] BSTR that specifies the attributes used with the element behavior. This argument contains a structure of name/value pairs; see examples for more information.
pNamespace
[in] Address of IElementNamespace interface for the namespace to which any tags are added.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method is implemented by the host of MSHTML. It is invoked in response to the IElementNamespaceTable::AddNamespace method with the ELEMENTNAMESPACEFLAGS_QUERYFORUNKNOWNTAGS flag.

When implementing this method, a host that supports the tag given in bstrTagName can call IElementNamespace::AddTag to add the tag to the namespace.

Examples

The bstrAttrs argument is a BSTR containing a packed name/value pair structure, as indicated by the following snippet:

[Name1][NULL][Value1][NULL]
[Name2][NULL][Value2][NULL]
...
[NameX][NULL][ValueX][NULL][NULL]

A NULL Name indicates the end of the name/value sequence. Any of the Value strings may be empty.
