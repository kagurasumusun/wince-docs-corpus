IElementBehaviorLayout::GetSize Method

Enables a behavior to take part in the layout process.

Syntax

HRESULT GetSize(      
    LONG dwFlags,
    SIZE sizeContent,
    POINT *pptTranslateBy,
    POINT *pptTopLeft,
    SIZE *psizeProposed
);

Parameters

dwFlags
[in] BEHAVIOR_LAYOUT_MODE enumeration that specifies the layout mode.
sizeContent
[in] SIZE that specifies the dimensions of the content during rendering.
pptTranslateBy
[in, out] Pointer to a POINT structure that specifies the amount to translate the rendered behavior.
pptTopLeft
[in, out] Pointer to a POINT structure that specifies the upper left corner of the rendered behavior.
psizeProposed
[in, out] Pointer to a SIZE structure that specifies the proposed size of the behavior.

Return Value

Returns S_OK if successful, or an error value otherwise.
