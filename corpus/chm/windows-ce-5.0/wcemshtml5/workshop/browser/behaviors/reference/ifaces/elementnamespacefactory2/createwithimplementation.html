IElementNamespaceFactory2::CreateWithImplementation Method

The method invoked by MSHTML on creation of an element behavior in Internet Explorer 6 and later versions.

Syntax

HRESULT CreateWithImplementation(      
    IElementNamespace *pNamespace,
    BSTR bstrImplementation
);

Parameters

pNamespace
[in] Pointer to the IElementNamespace that owns the element behavior.
bstrImplementation
[in] The implementation name for the behavior or the Uniform Resource Name (URN), for a host-provided namespace. This value can also be NULL.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If the IElementNamespaceFactory2 interface is implemented by the host, CreateWithImplementation method is called by MSHTML instead of IElementNamespaceFactory::Create.
