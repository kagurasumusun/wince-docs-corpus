IElementNamespaceFactory2 Interface

This interface extends IElementNamespaceFactory and provides a standard mechanism for creating an element behavior for a specific namespace and implementation.

Remarks

In Internet Explorer 6 and later versions, MSHTML queries for this interface before it queries for IElementNamespaceFactory, and if it is implemented, the IElementNamespaceFactory2::CreateWithImplementation method is called.
