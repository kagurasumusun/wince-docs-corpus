IElementBehaviorLayout Interface

This interface is implemented by a binary element behavior in order to take part in the layout process.

Remarks

A binary element behavior exposes an IElementBehaviorLayout interface in order to take part in the layout process. The layout engine requests this interface. If the interface exists, the layout engine calls the IElementBehaviorLayout::GetLayoutInfo method. The behavior returns a value that indicates whether it will register for layout participation before or after natural sizing occurs.

During the layout of the element, MSHTML synchronously calls the behavior's IElementBehaviorLayout::GetSize method if the behavior registers for full delegation. MSHTML passes the proposed size, which is the parent's size, to the behavior callback. MSHTML then uses the callback's returned size as the element size. If the behavior requests full delegation, MSHTML skips natural sizing altogether.

If the behavior does not request full delegation, MSHTML performs its own natural sizing. If the behavior requests that the natural value be modified, MSHTML calls the behavior's IElementBehaviorLayout::GetSize method while calculating element size. MSHTML passes the proposed size of the element and the natural size of the content to the method, and the behavior modifies the element's size. The proposed size of the element is based on normal formatting of the element due to its properties, the size of its parent, and the content size.

Because MSHTML calls the behavior's IElementBehaviorLayout::GetSize method synchronously, it is important not to call any functions that might alter the document tree.
