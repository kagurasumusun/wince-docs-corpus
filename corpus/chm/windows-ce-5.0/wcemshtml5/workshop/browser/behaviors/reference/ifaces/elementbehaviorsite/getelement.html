IElementBehaviorSite::GetElement Method

Retrieves the element to which a Dynamic HTML (DHTML) behavior is attached.

Syntax

HRESULT GetElement(      
    IHTMLElement **ppElement
);

Parameters

ppElement
[out, retval] Address of a pointer to an IHTMLElement interface that specifies the element to which the DHTML behavior is attached.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

A DHTML behavior can access the host DHTML Object Model through the element that is retrieved by this method.

This method can be successfully called after the DHTML behavior has received the BEHAVIOREVENT_CONTENTREADY notification through a call to the IElementBehavior::Notify method.

This method returns a pointer to the master element of a behavior. Do not cache the pointer returned by this method, instead cache a pointer to IElementBehaviorSite itself, during the IElementBehavior::Init call, and use the GetElement method whenever necessary.

If the ppElement pointer is cached, then Microsoft® Internet Explorer calls AddRef to increment the reference count on the behavior; this practice can cause memory leaks when the behavior is shut down, because references to the behavior remain.
