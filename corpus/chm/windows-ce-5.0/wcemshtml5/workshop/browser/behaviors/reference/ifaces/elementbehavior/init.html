IElementBehavior::Init Method

Notifies the Dynamic HTML (DHTML) behavior that it has been instantiated.

Syntax

HRESULT Init(      
    IElementBehaviorSite *pBehaviorSite
);

Parameters

pBehaviorSite
[in] Pointer to the IElementBehaviorSite interface through which the DHTML behavior communicates with MSHTML.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method is the first notification received by the DHTML behavior after it is instantiated by MSHTML, through a call to the IElementBehaviorFactory::FindBehavior method. Any initialization required for the DHTML behavior can be done at this point.

You can query the IElementBehaviorSite interface that is passed to the IElementBehavior::Init method for the IElementBehaviorSiteOM, IElementBehaviorSiteCategory, IBindHost, and IServiceProvider interfaces.

The IElementBehaviorSite::GetElement method can be used to retrieve a pointer to the element to which the DHTML behavior is attached. It is important to note that the pointer returned by a call to the IElementBehaviorSite::GetElement method should not be cached, because doing so prevents the behavior from receiving a detach call.

The IElementBehavior::Init method is analogous to running an inline script during the parsing phase of a behavior that uses an HTML Component (HTC) file. Therefore, IElementBehavior::Init should not be used to implement code that references, creates, or modifies content in the primary document. Instead, the IElementBehavior::Notify method should be used to detect the oncontentready and ondocumentready events, which provide notification on the successful parsing of the element to which the behavior is attached, and the primary document, respectively.

MSHTML calls the IElementBehavior::Notify method to indicate when the element and document to which the DHTML behavior is attached are fully parsed. If the DHTML behavior needs to be downloaded, the contents of the document might be parsed before the IElementBehavior::Init method is called and IElementBehavior::Notify is not called.
