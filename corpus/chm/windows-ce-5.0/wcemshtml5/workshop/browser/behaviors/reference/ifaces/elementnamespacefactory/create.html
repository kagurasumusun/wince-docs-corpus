IElementNamespaceFactory::Create Method

Method implemented by element behaviors and invoked by MSHTML on creation of the element behavior.

Syntax

HRESULT Create(      
    IElementNamespace *pNamespace
);

Parameters

pNamespace
[in] Address of the IElementNamespace that owns the element behavior.

Return Value

Returns S_OK if successful, or an error value otherwise.

Example

The following example shows an implementation of the Create method that adds the "MyTag" element behavior to the namespace pointed to by pNamespace.

HRESULT CMyFactory::Create(IElementNamespace *pNamespace)
{
    BSTR bstrTagName = SysAllocString(L"MyTag");
    HRESULT hr = pNamespace->AddTag(bstrTagName, 0);
    SysFreeString(bstrTagName);
    return hr;
}
