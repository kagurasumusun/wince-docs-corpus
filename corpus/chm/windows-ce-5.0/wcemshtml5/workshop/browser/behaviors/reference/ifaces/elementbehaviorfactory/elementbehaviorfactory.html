IElementBehaviorFactory Interface

This interface provides a standard mechanism for MSHTML to locate and instantiate a Dynamic HTML (DHTML) behavior.

Remarks

MSHTML attempts to locate and instantiate a DHTML behavior when it locates a reference to the behavior during the parsing of an HTML document.

MSHTML initially calls the host application's IServiceProvider::QueryService, specifying the SID_SHTMLElementBehaviorFactory identifier, to request the IElementBehaviorFactory interface. The hosting application provides this service through its client site.

If the IElementBehaviorFactory interface is available, MSHTML calls the IElementBehaviorFactory::FindBehavior method to instantiate the DHTML behavior. If successful, this method returns an IElementBehavior interface.

If the DHTML behavior is not available, MSHTML queries the object elements on the page to see if they implement the DHTML behavior.

The object element serving the behavior factory should be positioned before any IMPORT statements, so that when custom elements are read into the namespace, Microsoft® Internet Explorer is able to find the IElementNamespaceFactory.

The component object that implements the IElementBehaviorFactory interface does not necessarily have to be safe for scripting or persistence. If an object is not safe, then Internet Explorer prompts with a warning dialog, providing the choice between downloading and instantiating the behavior and canceling the operation.

The IObjectSafety interface enables a DHTML behavior component object to be identified as safe for scripting; for more details, see Supporting the IObjectSafety Interface. Also, see Signing Code with Microsoft Authenticode Technology, which provides information on how to sign component objects and mark them as safe.
