IElementBehaviorSiteOM::RegisterEvent Method

Registers a custom Dynamic HTML (DHTML) behavior event.

Syntax

HRESULT RegisterEvent(      
    LPOLESTR pchEvent,
    LONG lFlags,
    LONG *plCookie
);

Parameters

pchEvent
[in] Pointer to a string that specifies the name of the event to register.
lFlags
[in] Reserved. Must be set to NULL.
plCookie
[out, retval] Pointer to a variable of type LONG that identifies the custom event specified by pchEvent. This value is used by the IElementBehaviorSiteOM::FireEvent and IElementBehaviorSiteOM::GetEventCookie methods.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

A DHTML behavior must call this method for MSHTML to recognize the custom event.
