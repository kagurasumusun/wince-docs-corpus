IElementBehaviorSiteLayout2 Interface

This interface extends the IElementBehaviorSiteLayout interface, which allows behaviors to control the layout process.

What's New for Internet Explorer 6

This interface extends the IElementBehaviorSiteLayout interface, which allows behaviors to control the layout process. The IElementBehaviorSiteLayout2 interface exposes the ElementBehaviorSiteLayout2::GetFontInfo method, which provides the LOGFONT information for the element.

Remarks

The host application can call QueryInterface on MSHTML for the IElementBehaviorSiteLayout2 interface and, if it is available, the ElementBehaviorSiteLayout2::GetFontInfo method can then be called to obtain the LOGFONT information the element.
