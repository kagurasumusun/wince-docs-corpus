showPageSetupDialog Method

Displays the Page Setup dialog box.

Syntax

bProceed = TEMPLATEPRINTER.showPageSetupDialog()

Return Value

Boolean. Returns one of the following values:

falseUser closed the Page Setup dialog box with the Cancel button.
trueUser closed the Page Setup dialog box with the OK button.

Applies To

TEMPLATEPRINTER
