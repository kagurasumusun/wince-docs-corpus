MARGINTOP Attribute | marginTop Property

Sets or retrieves the top margin of the document to be printed.

Syntax

XML<ELEMENT MARGINTOP = iTop... >
ScriptingTEMPLATEPRINTER.marginTop(v) [ = iTop ]

Possible Values

iTopInteger that specifies or receives the top margin of the document to be printed, in 1/100ths of an inch.

The property is read/write. The property has no default value.

Remarks

This property is always measured in 1/100ths of an inch, even if the user has changed the measurement system in the Regional Settings to metric.

Applies To

TEMPLATEPRINTER

See Also

marginLeft, marginRight, marginBottom
