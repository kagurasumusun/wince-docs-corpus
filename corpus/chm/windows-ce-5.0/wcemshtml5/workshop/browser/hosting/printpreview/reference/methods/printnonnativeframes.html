printNonNativeFrames Method

Sends the non-HTML documents, such as Microsoft® Word documents, to the printer from a page containing frames.

Syntax

TEMPLATEPRINTER.printNonNativeFrames(oDocument, bActiveFrame)

Parameters

oDocument Required. A document object that specifies the document to be printed.
bActiveFrame Required. Boolean value that specifies one of the following values:
truePrint the document in the active frame.
falsePrint the documents in all frames.

Return Value

No return value.

Applies To

TEMPLATEPRINTER
