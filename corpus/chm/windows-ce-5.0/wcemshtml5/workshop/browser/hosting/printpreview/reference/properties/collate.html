COLLATE Attribute | collate Property

Sets or retrieves whether the pages of a document are collated when printed.

Syntax

XML<ELEMENT COLLATE ... >
ScriptingTEMPLATEPRINTER.collate(v) [ = bCollate ]

Possible Values

bCollateBoolean that specifies or receives one of the following values.
falseDefault. Pages are not collated.
truePages are collated.

The property is read/write. The property has a default value of false.

Remarks

When you print collated copies of a document, the pages are printed in the correct sequence. For example, a three-page document prints page one, page two, and page three, and then starts with page one again.

Applies To

TEMPLATEPRINTER
