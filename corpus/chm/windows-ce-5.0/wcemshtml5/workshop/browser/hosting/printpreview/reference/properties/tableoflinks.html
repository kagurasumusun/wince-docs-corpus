TABLEOFLINKS Attribute | tableOfLinks Property

Sets or retrieves whether to print a table of links as part of the current print job.

Syntax

XML<ELEMENT TABLEOFLINKS ... >
ScriptingTEMPLATEPRINTER.tableOfLinks(v) [ = bTable ]

Possible Values

bTableBoolean that specifies or receives one of the following values.
falseTable of links is not printed.
trueTable of links is printed.

The property is read/write. The property has no default value.

Applies To

TEMPLATEPRINTER
