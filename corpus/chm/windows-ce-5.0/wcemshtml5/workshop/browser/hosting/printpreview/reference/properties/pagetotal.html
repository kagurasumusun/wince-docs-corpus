PAGETOTAL Attribute | pageTotal Property

Sets or retrieves the page total that the HeaderFooter behavior uses when generating HTML for headers and footers.

Syntax

XML<ELEMENT PAGETOTAL = iPages... >
ScriptingHEADERFOOTER.pageTotal(v) [ = iPages ]

Possible Values

iPagesInteger that specifies or receives the total number of pages in the current print job.

The property is read/write. The property has no default value.

Applies To

HEADERFOOTER
