CONTENTSRC Attribute | contentSrc Property

Sets or retrieves the content source for a LAYOUTRECT element in a print template.

Syntax

XML<ELEMENT CONTENTSRC = sURL... >
ScriptingLAYOUTRECT.contentSrc(varContentSrc) [ = sURL ]

Possible Values

sURLString that specifies or receives the URL of the document to be used as the source for the LAYOUTRECT or the following flag.
documentSpecifies that the source content for the print template comes from the document currently displayed in the WebBrowser control.

The property is read/write. The property has no default value.

Applies To

LAYOUTRECT

See Also

contentDocument, nextRect
