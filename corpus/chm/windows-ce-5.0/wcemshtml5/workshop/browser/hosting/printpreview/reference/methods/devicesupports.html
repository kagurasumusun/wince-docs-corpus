deviceSupports Method

Checks whether the printer supports a specified feature.

Syntax

vSupports = TEMPLATEPRINTER.deviceSupports(sProperty)

Parameters

sProperty Required. String that indicates which property to query. This parameter can be set to one of the following three strings.
copiesNumber of copies supported.
collateSupport for collating.
duplexSupport for duplex printing.

Return Value

Variant. Returns the requested information.

Remarks

The type of information returned by this method depends on which property you query for.

copiesInteger value indicating how many copies the printer can make.
collateBoolean value indicating whether the printer can collate.
duplexBoolean value indicating whether the printer supports duplex printing.

Applies To

TEMPLATEPRINTER
