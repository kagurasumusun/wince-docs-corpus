IHTMLElement3::onresizestart Property

Sets or retrieves a pointer to the event handler function that fires when the user begins to change the dimensions of the object.

Syntax

HRESULT IHTMLElement3::get_onresizestart(VARIANT *p);
HRESULT IHTMLElement3::put_onresizestart(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT that receives a pointer to the event handler function, or NULL otherwise.
v
VARIANT that specifies a pointer to the event handler function, or NULL otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.
