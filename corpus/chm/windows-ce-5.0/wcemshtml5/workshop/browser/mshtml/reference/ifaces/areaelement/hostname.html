IHTMLAreaElement::hostname Property

Sets or retrieves the host name part of the location or URL.

Syntax

HRESULT IHTMLAreaElement::get_hostname(BSTR *p);
HRESULT IHTMLAreaElement::put_hostname(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the host and domain name, or the numerical IP address.
v
BSTR that specifies the host and domain name, or the numerical IP address.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If no host name is available, this property returns an empty string.
