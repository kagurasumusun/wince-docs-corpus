IHTMLDocument4::createDocumentFromUrl Method

Creates a new document object from an existing URL.

Syntax

HRESULT createDocumentFromUrl(      
    BSTR bstrUrl,
    BSTR bstrOptions,
    IHTMLDocument2 **oNewDoc
);

Parameters

bstrUrl
[in] BSTR that specifies the URL of the page from which to create the new document.
bstrOptions
[in] BSTR that specifies the media type for applying media style sheets upon creation of the document. It can be one of the following values:
print
Sets the media value for printing or print preview.
null
Ignores the media value.
oNewDoc
[out, retval] Address of a pointer to an IHTMLDocument2 interface that receives the newly created document.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The page specified by bstrUrl is loaded asynchronously. The onload event is fired on the new document object when the Dynamic HTML (DHTML) object model is available.
