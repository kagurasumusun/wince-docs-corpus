IHTMLCurrentStyle::fontStyle Property

Retrieves the font style of the object as italic, normal, or oblique.

Syntax

HRESULT IHTMLCurrentStyle::get_fontStyle(BSTR *p);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.

Possible Values

normalDefault. Font is normal.
italicFont is italic.
obliqueFont is italic.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The oblique value is available as of Microsoft® Internet Explorer 4.0. Internet Explorer 4.0 renders italic and oblique identically.

While, Internet Explorer is shipped with a default IHTMLCurrentStyle::fontStyle, this default can be changed by accessing Internet Options.
