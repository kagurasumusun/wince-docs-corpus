IHTMLBGsound::volume Property

Sets or retrieves the volume setting for the sound.

Syntax

HRESULT IHTMLBGsound::get_volume(VARIANT *p);
HRESULT IHTMLBGsound::put_volume(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_BSTR or VT_I4 that receives the volume setting. Valid values range from -10,000 to 0, with 0 being full Wave Output volume.
v
VARIANT of type VT_BSTR or VT_I4 that specifies the volume setting. Valid values range from -10,000 to 0, with 0 being full Wave Output volume.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The higher the setting, the louder the sound.
