IHTMLDOMAttribute Interface

This interface provides the ability to programmatically access the properties and methods that are common to all element objects.

IHTMLDOMAttribute Members

nodeName Retrieves the name of a particular type of node.
nodeValue Sets or retrieves the value of a node.
specified Retrieves whether an attribute has been specified.

Remarks

To obtain a pointer to this interface, use the IHTMLAttributeCollection::item method to obtain a pointer to the object's IDispatch interface, then use the QueryInterface method to obtain a pointer to the IHTMLDOMAttribute interface.
