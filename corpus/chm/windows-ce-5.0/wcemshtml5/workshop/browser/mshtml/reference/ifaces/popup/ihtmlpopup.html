IHTMLPopup Interface

This interface implements an overlapped window typically used for ToolTips, drop-down menus, and other temporary windows that appear outside an application's main window.

IHTMLPopup Members

document Retrieves the HTML document in a given popup window.
hide Closes the pop-up window.
isOpen Retrieves a value indicating whether the popup window is open.
show Displays the pop-up window on the screen.
