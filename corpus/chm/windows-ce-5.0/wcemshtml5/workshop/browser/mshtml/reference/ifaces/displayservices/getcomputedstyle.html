IDisplayServices::GetComputedStyle Method

Retrieves the rendered style, such as bold, italic, and so on, for the element containing a markup pointer.

Syntax

HRESULT GetComputedStyle(      
    IMarkupPointer *pPointer,
    IHTMLComputedStyle **ppComputedStyle
);

Parameters

pPointer
[in] Pointer to an IMarkupPointer interface that specifies the position at which the rendered style is to be retrieved.
ppComputedStyle
[out] Address of a pointer to a variable that receives an IHTMLComputedStyle interface pointer for the object that accesses the rendered style information.

Return Value

Returns S_OK if successful, or an error value otherwise.
