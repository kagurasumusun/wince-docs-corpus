IHTMLStyleSheet2::addPageRule Method

Creates a new page object for a style sheet.

Syntax

HRESULT addPageRule(      
    BSTR bstrSelector,
    BSTR bstrStyle,
    long lIndex,
    long *plNewIndex
);

Parameters

bstrSelector
[in] BSTR that specifies the selector for the new page object.
bstrStyle
[in] BSTR that specifies the style assignments for this page object. This style takes the same form as an inline style specification. For example, "color:blue" is a valid style parameter.
lIndex
[in] long that specifies the zero-based position in the IHTMLStyleSheet2::pages collection where the new page object should be placed.
-1
Default. The page object is added to the end of the collection.
plNewIndex
[out, retval] Reserved. long that always specifies -1.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Each page object represents a style sheet that corresponds to a @page rule in the document.
