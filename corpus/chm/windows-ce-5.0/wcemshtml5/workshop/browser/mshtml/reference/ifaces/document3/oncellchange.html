IHTMLDocument3::oncellchange Property

Sets or retrieves a pointer to the event handler function associated with the oncellchange event.

Syntax

HRESULT IHTMLDocument3::get_oncellchange(VARIANT *p);
HRESULT IHTMLDocument3::put_oncellchange(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_DISPATCH that receives the IDispatch interface of an object with a default method that is invoked when the event occurs.
v
VARIANT of type VT_DISPATCH that specifies the IDispatch interface of an object with a default method that is invoked when the event occurs.

Return Value

Returns S_OK if successful, or an error value otherwise.

See Also

IHTMLDocument3::attachEvent, IHTMLElement2::attachEvent
