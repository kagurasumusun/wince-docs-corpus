IHTMLElement::offsetParent Property

Retrieves a reference to the container object that defines the IHTMLElement::offsetTop and IHTMLElement::offsetLeft properties of the object.

Syntax

HRESULT IHTMLElement::get_offsetParent(IHTMLElement **p);

Parameters

p
Address of a pointer to a variable of type IHTMLElement interface that receives the container object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Most of the time the IHTMLElement::offsetParent property returns the body object.

Note  In Microsoft® Internet Explorer 5, the IHTMLElement::offsetParent property returns the table object for the td object; in Internet Explorer 4.0 it returns the tr object. You can use the IHTMLElement::parentElement property to retrieve the immediate container of the table cell.
