IHTMLInputElement::createTextRange Method

Creates a TextRange object for the element.

Syntax

HRESULT createTextRange(      
    IHTMLTxtRange **range
);

Parameters

range
[out, retval] Address of a pointer to an IHTMLTxtRange interface that receives a TextRange object if successful, or NULL otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Use a text range to examine and modify the text within an object.
