IDisplayPointer::SetDisplayGravity Method

Sets the display gravity for the display pointer.

Syntax

HRESULT SetDisplayGravity(      
    DISPLAY_GRAVITY eGravity
);

Parameters

eGravity
[in] DISPLAY_GRAVITY enumeration that specifies the display gravity.

Return Value

Returns S_OK if successful, or an error value otherwise.
