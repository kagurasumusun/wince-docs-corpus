IHTMLDialog::dialogWidth Property

Sets or retrieves the width of the modal dialog window.

Syntax

HRESULT IHTMLDialog::get_dialogWidth(VARIANT *p);
HRESULT IHTMLDialog::put_dialogWidth(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT that receives the width of the dialog window (see Remarks for default unit of measure).
v
VARIANT that specifies the width of the dialog window (see Remarks for default unit of measure).

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLDialog::dialogWidth property applies only to windows created using the IHTMLWindow2::showModalDialog and IHTMLWindow3::showModelessDialog methods.

The default unit of measure for dialogHeight and dialogWidth in Microsoft® Internet Explorer 4.0 is the em; in Internet Explorer 5 it is the pixel. The value can be an integer or floating-point number, followed by an absolute units designator (cm, mm, in, pt, pc, or px) or a relative units designator (em or ex). For consistent results, specify the dialogHeight and dialogWidth in pixels when designing modal dialog boxes.
