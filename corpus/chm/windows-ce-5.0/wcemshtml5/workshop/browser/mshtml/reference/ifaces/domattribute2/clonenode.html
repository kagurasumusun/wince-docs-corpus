IHTMLDOMAttribute2::cloneNode Method

Produces an identical copy, or clone, of the node.

Syntax

HRESULT cloneNode(      
    VARIANT_BOOL fDeep,
    IHTMLDOMAttribute **clonedNode
);

Parameters

fDeep
[in] VARIANT_BOOL that specifies whether to copy the subtree of the node.
VARIANT_TRUE
Copy the node's subtree recursively.
VARIANT_FALSE
Default. Copy only the node, including any attributes.
clonedNode
[out, retval] Address of a pointer to an IHTMLDOMAttribute interface that receives a reference to the copy of the node.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLDOMAttribute2::parentNode property of the copy of the node is NULL.

This method copies all of the node's attributes and their values, but does not copy any text the node contains unless the fDeep parameter is set to true, because the text is contained in a child TextNode object.

Copying an attribute object directly, as opposed to copying an attribute as part of copying an element, returns a IHTMLDOMAttribute::specified attribute (IHTMLDOMAttribute::specified is true). Copying any other type of node simply returns a copy of this node.
