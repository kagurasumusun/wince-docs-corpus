ISelectionServices::SetSelectionType Method

Sets the selection type and clears any existing selection.

Syntax

HRESULT SetSelectionType(      
    SELECTION_TYPE eType,
    ISelectionServicesListener *pIListener
);

Parameters

eType
[in] SELECTION_TYPE enumeration that specifies the type of selection to set.
pIListener
[in] Pointer to an ISelectionServicesListener interface specifying the interface to associate with this selection. Set to NULL if unused.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The pIListener parameter is optional. However, without it the editor will not be able to restore the selection.
