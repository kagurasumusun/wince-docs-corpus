IHTMLAreasCollection Interface

This interface is a collection of areas that make up the image map.

IHTMLAreasCollection Members

_newEnum Retrieves an enumerator for the collection.
add Adds an element to the areas, controlRange, or options collection.
item Retrieves an object from the all collection or various other collections.
length Sets or retrieves the number of objects in a collection.
remove Removes an element from the collection.
tags Retrieves a collection of objects that have the specified HTML tag name.

Remarks

Areas can be added or removed from the collection. If duplicate names are found, a collection of those named items is returned. Collections of duplicate names must be referenced subsequently by ordinal position.
