IHTMLFormElement Interface

This interface specifies that the contained controls take part in a form.

IHTMLFormElement Members

_newEnum Retrieves an enumerator for the collection.
action Sets or retrieves the URL to which the form content is sent for processing.
dir Sets or retrieves the reading order of the object.
elements Retrieves an interface pointer to a zero-based collection of the elements in the form.
encoding Sets or retrieves the MIME encoding for the form.
item Retrieves an object from the all collection or various other collections.
length Sets or retrieves the number of objects in a collection.
method Sets or retrieves how to send the form data to the server.
name Sets or retrieves the name of the object.
onreset Sets or retrieves a pointer to the event handler function associated with an event.
onsubmit Sets or retrieves a pointer to the event handler function associated with an event.
submit Submits the form.
tags Retrieves a collection of objects that have the specified HTML tag name.
target Sets or retrieves the window or frame at which to target content.

Remarks

When the form is programmed, all control-like elements are added as named items. In addition, these items are exposed through the IHTMLFormElement::item method.

When the focus is on a control in a form, pressing the ESC key once causes the value of the control to revert to the last value. Pressing ESC again resets the form.

If only one text box is on a form, pressing ENTER fires the onsubmit event. If the form has a submit button, the button appears with a dark border, indicating that pressing ENTER submits the form.

The form element is a block element.
