IHTMLEditServices::MoveToSelectionEnd Method

Moves a markup pointer to the current selection's end.

Syntax

HRESULT MoveToSelectionEnd(      
    IMarkupPointer *pIEndAnchor
);

Parameters

pIEndAnchor
[in] Pointer to an IMarkupPointer interface to move to the current selection's end.

Return Value

Returns S_OK if successful, or an error value otherwise.
