IHTMLCaret::GetLocation Method

Retrieves the horizontal and vertical coordinates of the insertion point's (caret's) location, in pixels.

Syntax

HRESULT GetLocation(      
    POINT *pPoint,
    BOOL fTranslate
);

Parameters

pPoint
[out] Pointer to a variable of type POINT that receives the insertion point's coordinates.
fTranslate
[in] BOOL value that specifies TRUE if the coordinates of the insertion point should be given from a global frame of reference, or FALSE if the coordinates should be given from the frame of reference of the flow layout element containing the insertion point.

Return Value

Returns S_OK if successful, or an error value otherwise.
