IHTMLInputTextElement::select Method

Highlights the input area of a form element.

Syntax

HRESULT select(VOID);

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Use this method with the IHTMLControlElement::focus method to highlight a field and position the cursor for a user response.
