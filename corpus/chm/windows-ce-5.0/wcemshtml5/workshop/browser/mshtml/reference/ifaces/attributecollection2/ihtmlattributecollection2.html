IHTMLAttributeCollection2 Interface

This interface extends the IHTMLAttributeCollection interface.

IHTMLAttributeCollection2 Members

getNamedItem Retrieves an IHTMLDOMAttribute specified with the IHTMLDOMAttribute2::name property using the IHTMLAttributeCollection interface.
removeNamedItem Removes an IHTMLDOMAttribute specified with the IHTMLDOMAttribute2::name property from an element using the IHTMLAttributeCollection interface.
setNamedItem Adds an IHTMLDOMAttribute to an element using an IHTMLAttributeCollection interface.
