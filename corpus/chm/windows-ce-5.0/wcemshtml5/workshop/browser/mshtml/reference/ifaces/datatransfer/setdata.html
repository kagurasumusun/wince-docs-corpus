IHTMLDataTransfer::setData Method

Assigns data in a specified format to the dataTransfer or clipboardData object.

Syntax

HRESULT setData(      
    BSTR format,
    VARIANT *data,
    VARIANT_BOOL *pret
);

Parameters

format
[in] BSTR that specifies the format of the data to be transferred, using one of the following values:
Text
Transfers data formatted as text.
URL
Transfers data formatted as a URL.
data
[in] VARIANT of type VT_BSTR that specifies the data supplied by the source object. This information can be descriptive text, a source path to an image, or a URL for an anchor. When you pass "URL" as the format parameter, you must use the data parameter to provide the location of the object being transferred.
pret
VARIANT_BOOL. Returns one of the following possible values:
VARIANT_TRUE
The data was successfully added.
VARIANT_FALSE
The data was not added.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The value of the format parameter is not case-sensitive.
