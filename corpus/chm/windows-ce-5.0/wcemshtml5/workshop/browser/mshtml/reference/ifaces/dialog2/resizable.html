IHTMLDialog2::resizable Property

Sets or retrieves the IHTMLDialog2::resizable property of the window.

Syntax

HRESULT IHTMLDialog2::get_resizable(BSTR *p);
HRESULT IHTMLDialog2::put_resizable(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the value of the property.
v
BSTR that specifies the value of the property.

Possible Values

no | 0Default. This value causes the window to have a fixed height and width but does not prevent the window from being repositioned on the screen.
yes | 1This sets the window to IHTMLDialog2::resizable so that the edges and corners of the window frame can be adjusted individually.

Return Value

Returns S_OK if successful, or an error value otherwise.

See Also

IHTMLWindow2::showModalDialog, IHTMLWindow3::showModelessDialog
