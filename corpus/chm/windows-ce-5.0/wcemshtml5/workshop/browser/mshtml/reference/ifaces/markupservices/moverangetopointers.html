IMarkupServices::MoveRangeToPointers Method

Positions the beginning and end of a text range at the positions of two markup pointers.

Syntax

HRESULT MoveRangeToPointers(      
    IMarkupPointer *pPointerStart,
    IMarkupPointer *pPointerFinish,
    IHTMLTxtRange *pIRange
);

Parameters

pPointerStart
[in] Pointer to an IMarkupPointer interface that specifies the start point of the range.
pPointerFinish
[in] Pointer to an IMarkupPointer interface that specifies the end point of the range.
pIRange
[in] Pointer to an IHTMLTxtRange interface that specifies the text range to move.

Return Value

Returns S_OK if successful, or an error value otherwise.
