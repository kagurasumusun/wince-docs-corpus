IHTMLDOMTextNode::splitText Method

Divides a text node at the specified index.

Syntax

HRESULT splitText(      
    long offset,
    IHTMLDOMNode pRetNode
);

Parameters

offset
[in] long that specifies the index of the string that indicates where the separation occurs. If a value is not provided, a new text node with no value is created.
pRetNode
Returns a text node object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The text node that invokes the IHTMLDOMTextNode::splitText method has a IHTMLDOMNode::nodeValue equal to the substring of the value, from 0 to offset. The new text node has a IHTMLDOMNode::nodeValue of the substring of the original value, from the specified index to the value length. Text node integrity is not preserved when the document is saved or persisted.
