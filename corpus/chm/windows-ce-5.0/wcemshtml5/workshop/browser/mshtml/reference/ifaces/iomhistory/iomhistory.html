IOmHistory Interface

This interface provides the ability to access the history object for the client.

IOmHistory Members

back Loads a previous URL from the History list.
forward Loads the next URL from the History list.
go Loads a URL from the History list.
length Retrieves the number of elements in the History list.

Remarks

The history object contains information about the URLs that have been visited by the client.
