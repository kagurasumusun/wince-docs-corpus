IHTMLDialog::returnValue Property

Sets or retrieves the value returned from the modal dialog window.

Syntax

HRESULT IHTMLDialog::get_returnValue(VARIANT *p);
HRESULT IHTMLDialog::put_returnValue(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT that receives the value returned from the window.
v
VARIANT that specifies the value returned from the window.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property applies only to windows created using the IHTMLWindow2::showModalDialog method.

For event handler functions, the value of this property takes precedence over values returned by the function, such as through a return statement.
