IHTMLNamespace Interface

This interface provides a means to dynamically import an element behavior into a document.

IHTMLNamespace Members

attachEvent Binds the specified function to an event, so that the function is called whenever the event fires on the object.
detachEvent Unbinds the specified function from the event, so that the object stops receiving notifications when the event fires.
doImport Dynamically imports an element behavior.
name Retrieves the name of the namespace.
onreadystatechange Sets or retrieves a pointer to the event handler function associated with the onreadystatechange event.
readyState Retrieves the current state of the object.
tagNames Not currently implemented.
urn Sets or retrieves the Uniform Resource Name (URN) of the object.

Remarks

Use IHTMLDocument4::namespaces to obtain a collection containing the namespaces, if any, that are declared in a document.
