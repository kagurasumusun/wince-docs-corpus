IMarkupPointer2::MoveToContent Method

Moves a markup pointer to a particular element in a markup container.

Syntax

HRESULT MoveToContent(      
    IHTMLElement *pIElement,
    BOOL fAtStart
);

Parameters

pIElement
[in] Pointer to an IHTMLElement interface for the element to which to move the markup pointer.
fAtStart
[in] BOOL that specifies TRUE if the markup pointer is to be placed at the start of the element, or FALSE if it is to be placed at the end.

Return Value

Returns S_OK if successful, or an error value otherwise.
