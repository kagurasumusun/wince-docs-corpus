IHTMLRect::bottom Property

Set or retrieves the bottom coordinate of the rectangle surrounding the object content.

Syntax

HRESULT IHTMLRect::get_bottom(long *p);
HRESULT IHTMLRect::put_bottom(long v);

Parameters

p
Pointer to a variable of type long that receives the bottom coordinate of the rectangle, in pixels.
v
long that specifies the bottom coordinate of the rectangle, in pixels.

Return Value

Returns S_OK if successful, or an error value otherwise.
