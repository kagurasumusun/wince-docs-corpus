IHTMLCurrentStyle::clipLeft Property

Retrieves the left coordinate of the object clipping region.

Syntax

HRESULT IHTMLCurrentStyle::get_clipLeft(VARIANT *p);

Parameters

p
Pointer to a variable of type VARIANT of type VT_BSTR that receives one of the values listed in Possible Values.

Possible Values

autoLeft side of object is fully exposed—that is, the left side is not clipped.
lengthFloating-point number, followed by an absolute units designator (cm, mm, in, pt, pc, or px) or a relative units designator (em or ex). For more information about the supported length units, see CSS Length Units.

Return Value

Returns S_OK if successful, or an error value otherwise.
