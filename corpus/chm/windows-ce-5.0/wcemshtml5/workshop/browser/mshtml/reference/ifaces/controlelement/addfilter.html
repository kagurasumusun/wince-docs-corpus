IHTMLControlElement::addFilter Method

Adds the specified filter to the list of filters influencing this element.

Syntax

HRESULT addFilter(      
    IUnknown *pUnk
);

Parameters

pUnk
[in] Pointer to the IUnknown interface of the filter to be added.

Return Value

Returns S_OK if successful, or an error value otherwise.
