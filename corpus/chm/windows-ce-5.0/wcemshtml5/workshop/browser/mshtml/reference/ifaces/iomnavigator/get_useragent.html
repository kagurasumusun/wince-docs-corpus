IOmNavigator::userAgent Property

Retrieves a string equivalent to the HTTP user-agent request header.

Syntax

HRESULT IOmNavigator::get_userAgent(BSTR *p);

Parameters

p
BSTR that specifies a valid HTTP user agent.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The HTTP user-agent request header contains information about compatibility, the browser, and the platform name. For more information about the browser, see the IOmNavigator::appName property. For more information about the platform, see the IOmNavigator::appVersion property.

The IOmNavigator::userAgent property dynamically returns a different value depending on the browser and platform versions. For example, Microsoft® Internet Explorer 6 returns the following string for Microsoft Windows® XP. 

Mozilla/4.0 (compatible; MSIE 6.0; Windows NT 5.1)

Examples

The following function retrieves the user agent string and returns it through the out parameter, pbstrUA.

// Equivalent to document.parentWindow.navigator.userAgent
HRESULT GetUA(IHTMLDocument2* pDoc, BSTR* pbstrUA)
{
   IHTMLWindow2* pWindow = NULL;

   if (!pDoc)
   {
      return E_INVALIDARG;
   }

   hr = pDoc->get_parentWindow(&pWindow);
   if (FAILED(hr) || !pWindow)
   {
      return hr;
   }

   IOmNavigator* pNavigator = NULL;
   hr = pWindow->get_navigator(&pNavigator);
   if (FAILED(hr) || !pNavigator)
   {
      goto Error;
   }

   hr = pNavigator->get_userAgent(pbstrUA);

Error:
	if (pWindow) pWindow->Release();
	if (pNavigator) pNavigator->Release();
	return hr;
}
