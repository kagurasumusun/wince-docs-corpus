ISegment::GetPointers Method

Positions markup pointers at the start and end of the selection segment.

Syntax

HRESULT GetPointers(      
    IMarkupPointer *pIStart,
    IMarkupPointer *pIEnd
);

Parameters

pIStart
[in] Pointer to an IMarkupPointer interface that specifies the markup pointer to position at the beginning of the segment.
pIEnd
[in] Pointer to an IMarkupPointer interface that specifies the markup pointer to position at the end of the segment.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method does not create markup pointers. The markup pointers given to this method must already have been created by calling IMarkupServices::CreateMarkupPointer.
