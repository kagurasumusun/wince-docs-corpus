IHTMLImgElement::loop Property

Sets or retrieves the number of times a sound or video clip will loop when activated.

Syntax

HRESULT IHTMLImgElement::get_loop(VARIANT *p);
HRESULT IHTMLImgElement::put_loop(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_I4 that receives one of the values listed in Possible Values.
v
VARIANT of type VT_I4 that specifies one of the values listed in Possible Values.

Possible Values

-1Loops infinitely.
0Loops one time.
countNumber of times to loop.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

To restart a sound or video clip after changing its IHTMLImgElement::loop property, set the IHTMLBGsound::src property or IHTMLInputElement::dynsrc property to itself. For example: 

oBGSound.src = oBGSound.src

In Microsoft® Internet Explorer 4.0, when you restart a video by changing its IHTMLImgElement::loop property, the video opens and plays in a new window.

The following are descriptions of how the IHTMLImgElement::loop property works for some boundary cases.
<BGSOUND src="file:///c:\win95\system\msremind.wav">Loops one time
<BGSOUND src="file:///c:\win95\system\msremind.wav" LOOP>Loops one time.
<BGSOUND src="file:///c:\win95\system\msremind.wav" LOOP=>Loops one time.
<BGSOUND src="file:///c:\win95\system\msremind.wav" LOOP=0>Loops one time.
<BGSOUND src="file:///c:\win95\system\msremind.wav" LOOP=-1>Loops infinitely.
