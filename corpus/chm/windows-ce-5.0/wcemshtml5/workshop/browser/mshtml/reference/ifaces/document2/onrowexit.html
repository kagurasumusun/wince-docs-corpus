IHTMLDocument2::onrowexit Property

Sets or retrieves a pointer to the event handler function associated with the onrowexit event.

Syntax

HRESULT IHTMLDocument2::get_onrowexit(VARIANT *p);
HRESULT IHTMLDocument2::put_onrowexit(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT that receives the IDispatch interface of an object with a default method that is invoked when the event occurs.
v
VARIANT that specifies the IDispatch interface of an object with a default method that is invoked when the event occurs.

Return Value

Returns S_OK if successful, or an error value otherwise.

See Also

IHTMLDocument3::attachEvent, IHTMLElement2::attachEvent
