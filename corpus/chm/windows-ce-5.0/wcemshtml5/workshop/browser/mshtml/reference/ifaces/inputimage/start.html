IHTMLInputImage::start Property

Sets or retrieves when a video clip file should begin playing.

Syntax

HRESULT IHTMLInputImage::get_start(BSTR *p);
HRESULT IHTMLInputImage::put_start(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

fileopenDefault. Video begins as soon as it finishes loading.
mouseoverVideo begins when the user moves the mouse over the animation.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLInputImage::start property applies only to img objects with the IHTMLImgElement::dynsrc property specified.
