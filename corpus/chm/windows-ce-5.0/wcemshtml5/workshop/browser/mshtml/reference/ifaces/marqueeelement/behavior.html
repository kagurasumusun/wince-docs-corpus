IHTMLMarqueeElement::behavior Property

Sets or retrieves how the text scrolls in the marquee.

Syntax

HRESULT IHTMLMarqueeElement::get_behavior(BSTR *p);
HRESULT IHTMLMarqueeElement::put_behavior(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

scrollDefault. Marquee scrolls in the direction specified by the IHTMLMarqueeElement::direction property. The text scrolls off the end and starts over.
alternateMarquee scroll direction reverses when its content reaches the edge of the container.
slideMarquee scrolls in the direction specified by the IHTMLMarqueeElement::direction property. The text scrolls to the end and stops.

Return Value

Returns S_OK if successful, or an error value otherwise.
