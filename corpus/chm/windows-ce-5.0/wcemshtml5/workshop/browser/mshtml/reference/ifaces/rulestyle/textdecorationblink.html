IHTMLRuleStyle::textDecorationBlink Property

Sets or retrieves a Boolean value that indicates whether the object's IHTMLRuleStyle::textDecoration property has a value of "blink."

Syntax

HRESULT IHTMLRuleStyle::get_textDecorationBlink(VARIANT_BOOL *p);
HRESULT IHTMLRuleStyle::put_textDecorationBlink(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_TRUEThe IHTMLRuleStyle::textDecoration property is set to "blink."
VARIANT_FALSEThe IHTMLRuleStyle::textDecoration property is not set to "blink."

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property currently has no visible effect because "blink" is not currently implemented as a possible value of the IHTMLRuleStyle::textDecoration property.
