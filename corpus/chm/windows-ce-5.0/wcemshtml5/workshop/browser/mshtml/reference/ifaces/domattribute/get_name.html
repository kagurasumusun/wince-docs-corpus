IHTMLDOMAttribute::nodeName Property

Retrieves the name of a particular type of node.

Syntax

HRESULT IHTMLDOMAttribute::get_nodeName(BSTR *p);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.

Possible Values

#textNode is a TextNode object.
tagNameName of the element, also available through the IHTMLElement::tagName property.
attrNameName of the attribute, where the node is an attribute object.

Return Value

Returns S_OK if successful, or an error value otherwise.
