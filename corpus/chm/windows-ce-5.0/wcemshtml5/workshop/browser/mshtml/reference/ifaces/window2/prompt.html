IHTMLWindow2::prompt Method

Displays a dialog box that prompts the user with a message and an input field.

Syntax

HRESULT prompt(      
    BSTR message,
    BSTR defstr,
    VARIANT textdata
);

Parameters

message
[in] BSTR that specifies the message to display in the dialog box. By default, this parameter is set to "".
defstr
[in] BSTR that specifies the default value of the input field. By default, this parameter is set to "undefined".
textdata
[out, retval] BSTR or int. Returns the value typed in by the user.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The title of this dialog box cannot be changed.
