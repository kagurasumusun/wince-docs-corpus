IHTMLComputedStyle Interface

This interface provides access to the current style of objects as they are displayed on the screen. The interface also enables you to take a snapshot of the internal formatting of one object at a particular point in time and compare it to the internal formatting of another object.

IHTMLComputedStyle Members

backgroundColor Retrieves the color behind the content in the object.
blockDirection Retrieves a value that indicates whether the content in a block element flows from left to right or from right to left.
bold Retrieves a value that indicates whether text in the object is bold.
direction Retrieves a value that indicates whether content in the object flows from left to right or from right to left.
explicitFace Retrieves a value that indicates whether a font family is specified for the text in the object.
fontName Retrieves the font family of the text in the object.
fontSize Retrieves the size of the text in the object.
fontWeight Retrieves the weight of the text in the object.
hasBgColor Retrieves a value that indicates whether a color is specified for the background of the object.
IsEqual Compares the internal formatting of two IHTMLComputedStyle objects.
italic Retrieves a value that indicates whether the text in the object is italic.
OL Retrieves a value that indicates whether the object is an ordered list.
overline Retrieves a value that indicates whether text in the object has a line drawn over it.
preFormatted Retrieves a value that indicates whether the text in the object is preformatted.
strikeOut Retrieves a value that indicates whether text in the object has a line drawn through it.
subScript Retrieves a value that indicates whether text in the object is rendered slightly below the baseline of surrounding text, usually in smaller type.
superScript Retrieves a value that indicates whether text in the object is rendered slightly above the surrounding text, usually in smaller type.
textColor Retrieves the color of the text in the object.
underline Retrieves a value that indicates whether text in the object has a line drawn below it.

Remarks

Use IDisplayServices::GetComputedStyle to obtain an IHTMLComputedStyle interface pointer.
