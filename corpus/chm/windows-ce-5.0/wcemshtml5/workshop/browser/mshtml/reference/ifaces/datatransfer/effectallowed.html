IHTMLDataTransfer::effectAllowed Property

Sets or retrieves, on the source element, which data transfer operations are allowed for the object.

Syntax

HRESULT IHTMLDataTransfer::get_effectAllowed(BSTR *p);
HRESULT IHTMLDataTransfer::put_effectAllowed(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

copySelection is copied.
linkSelection is linked to the drop target by the data transfer operation.
moveSelection is moved to the target location when dropped.
copyLinkSelection is copied or linked, depending on the target default.
copyMoveSelection is copied or moved, depending on the target default.
linkMoveSelection is linked or moved, depending on the target default.
allAll drop effects are supported.
noneDropping is disabled and the no-drop cursor is displayed.
uninitializedDefault. No value has been set through the IHTMLDataTransfer::effectAllowed property. In this case, the default effect still works, although it cannot be queried through this property.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Set the IHTMLDataTransfer::effectAllowed property in the ondragstart event. This property is used most effectively with the IHTMLDataTransfer::dropEffect property.

This property can be used to override the default behavior in other applications. For example, the browser script can set the IHTMLDataTransfer::effectAllowed property to copy for a text field and thereby override the Microsoft® Word default of move. Within the browser, copy is the default IHTMLDataTransfer::effectAllowed behavior, except for anchors, which are set to link by default, and text fields, which are set to move by default.

Setting IHTMLDataTransfer::effectAllowed to none disables dropping but still displays the no-drop cursor. To avoid displaying the no-drop cursor, cancel the IHTMLEventObj::returnValue of the ondragstart window.
