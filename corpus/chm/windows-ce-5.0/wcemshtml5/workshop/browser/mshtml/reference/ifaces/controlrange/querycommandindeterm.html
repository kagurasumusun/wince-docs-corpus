IHTMLControlRange::queryCommandIndeterm Method

Returns a Boolean value that indicates whether the specified command is in the indeterminate state.

Syntax

HRESULT queryCommandIndeterm(      
    BSTR cmdID,
    VARIANT_BOOL *pfRet
);

Parameters

cmdID
[in] BSTR that specifies a command identifier.
pfRet
[out, retval] Pointer to a VARIANT_BOOL that returns one of the following possible values:
VARIANT_TRUE
The command is in the indeterminate state.
VARIANT_FALSE
The command is not in the indeterminate state.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method is a wrapper function for the IOleCommandTarget::QueryStatus method to enable scriptable execution of some command constants. You can obtain an IOleCommandTarget interface by calling QueryInterface on the IHTMLControlRange interface using IID_IHTMLControlRange for the interface identifier (IID).
