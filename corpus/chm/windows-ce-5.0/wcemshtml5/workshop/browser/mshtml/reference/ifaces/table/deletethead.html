IHTMLTable::deleteTHead Method

Deletes the tHead element and its contents from the table.

Syntax

HRESULT deleteTHead(VOID);

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If only one tHead element exists in the source, the IHTMLTable::deleteTHead method deletes the table header. If multiple tHead elements have been defined, the next tHead element in the source order is promoted as the table header.
