IHTMLDocument3::createDocumentFragment Method

Creates a new document and returns a pointer to the newly created document.

Syntax

HRESULT createDocumentFragment(      
    IHTMLDocument2 **pNewDoc
);

Parameters

pNewDoc
[out, retval] Address of a pointer to an IHTMLDocument2 interface that receives the newly created document.

Return Value

Returns S_OK if successful, or an error value otherwise.
