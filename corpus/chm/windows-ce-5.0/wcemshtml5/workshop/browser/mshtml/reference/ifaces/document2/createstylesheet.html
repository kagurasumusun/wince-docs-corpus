IHTMLDocument2::createStyleSheet Method

Creates a style sheet for the document.

Syntax

HRESULT createStyleSheet(      
    BSTR bstrHref,
    long lIndex,
    IHTMLStyleSheet **ppnewStyleSheet
);

Parameters

bstrHref
[in] BSTR that specifies how to add the style sheet to the document. If a file name is specified for the URL, the style information will be added as a link object. If the URL contains style information, this information will be added to the style object.
lIndex
[in] long that specifies the index that indicates where the new style sheet is inserted in the styleSheets collection. The default is to insert the new style sheet at the end of the collection.
ppnewStyleSheet
[out, retval] Address of a pointer to a styleSheet object.

Return Value

Returns S_OK if successful, or an error value otherwise.
