IHTMLTable::deleteRow Method

Removes the specified row (tr) from the element and from the rows collection.

Syntax

HRESULT deleteRow(      
    long index
);

Parameters

index
[in] long that specifies the zero-based position in the rows collection of the row to remove.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If you delete a row from a tFoot, tBody, or tHead, you also remove the row from the rows collection for the table. Deleting a row in the table also removes a row from the rows collection for the tBody.

If you delete a row from a tFoot, tBody, or tHead, index must contain the IHTMLTableRow::sectionRowIndex of the tr. When deleting a row from the table, index must contain the IHTMLTableRow::rowIndex of the tr.

See Also

IHTMLTable::insertRow, IHTMLTableRow::rowIndex, rows, IHTMLTableRow::sectionRowIndex
