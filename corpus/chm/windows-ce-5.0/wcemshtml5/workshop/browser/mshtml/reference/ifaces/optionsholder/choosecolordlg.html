IHTMLOptionsHolder::choosecolordlg Method

Opens the system color-selection dialog box.

Syntax

HRESULT choosecolordlg(      
    VARIANT initColor,
    long *rgbColor
);

Parameters

initColor
[in] VARIANT of type VT_BSTR that specifies the name of the initial color selected in the color-selection dialog box. For a complete list of colors, see the Color Table.
rgbColor
[out] Pointer to a long integer that specifies the value of the color selected by the user in the color-selection dialog box. The value is specified as 0xrrggbb where rr is the red hex value, gg is the green hex value, and bb is the blue hex value. For a complete list of colors, see the Color Table.

Return Value

Returns S_OK if successful, or an error value otherwise.
