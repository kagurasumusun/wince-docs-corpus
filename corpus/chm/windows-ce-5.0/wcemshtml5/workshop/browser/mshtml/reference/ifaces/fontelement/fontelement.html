IHTMLFontElement Interface

This interface specifies a new font face, size, and color to use for rendering the enclosed text.

IHTMLFontElement Members

color Sets or retrieves the color to be used by the object.
face Sets or retrieves the current typeface family.
size Sets or retrieves the font size of the object.
