IHTMLEditServices2::MoveToSelectionEndEx Method

Moves a display pointer to the current selection's end.

Syntax

HRESULT MoveToSelectionEndEx(      
    IDisplayPointer *pIEndAnchor
);

Parameters

pIEndAnchor
[in] Pointer to an IDisplayPointer interface to move to the current selection's end.

Return Value

Returns S_OK if successful, or an error value otherwise.
