IHTMLRenderStyle::textUnderlineStyle Property

Sets or retrieves the appearance of the underline decoration of the object.

What's New for Microsoft® Internet Explorer 6

This property supports the thick-dash value as of Internet Explorer 6.

Syntax

HRESULT IHTMLRenderStyle::get_textUnderlineStyle(BSTR *p);
HRESULT IHTMLRenderStyle::put_textUnderlineStyle(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

undefinedDefault. Text decoration has no specified style. The value is set automatically; for example, by default or inheritance.
singleText has one line drawn below it.
doubleNot currently implemented.
wordsNot currently implemented.
dottedText has a dotted line drawn below it.
thickNot currently implemented.
dashNot currently implemented.
dot-dashNot currently implemented.
dot-dot-dashNot currently implemented.
waveText has a wavy line drawn below it.
single-accountingNot currently implemented.
double-accountingNot currently implemented.
thick-dash  Internet Explorer 6 and later. Text has a dashed line drawn below it that has thicker width.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property specifies the style of the text underline decoration. To turn this decoration on or off, use the IHTMLRenderStyle::textDecoration property.
