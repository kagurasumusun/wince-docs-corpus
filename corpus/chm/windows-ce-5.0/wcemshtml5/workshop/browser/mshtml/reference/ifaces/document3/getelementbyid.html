IHTMLDocument3::getElementById Method

Returns a reference to the first object with the specified value of the ID attribute.

Syntax

HRESULT getElementById(      
    BSTR v,
    IHTMLElement **pel
);

Parameters

v
[in] BSTR that specifies the value of an ID attribute.
pel
[out, retval] Address of a pointer to the first object with the same ID attribute as the specified value.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If the ID value belongs to a collection, the IHTMLDocument3::getElementById method returns the first object in the collection.
