IHTMLStyle3::layoutFlow Property

Sets or retrieves the direction and flow of the content in the object.

Syntax

HRESULT IHTMLStyle3::get_layoutFlow(BSTR *p);
HRESULT IHTMLStyle3::put_layoutFlow(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

horizontalDefault. Content in the object flows from left to right, and the next horizontal line is positioned underneath the previous line. This layout is used in most Roman-based documents.
vertical-ideographicContent in the object flows from top to bottom, and the next vertical line appears to the left of the previous one. This layout is used in East Asian typography.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This is a deprecated property; use the IHTMLStyle3::writingMode property instead.

This property is read-only for the IHTMLCurrentStyle2 interface.
