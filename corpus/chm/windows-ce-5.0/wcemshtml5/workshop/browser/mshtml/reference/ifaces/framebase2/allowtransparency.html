IHTMLFrameBase2::allowTransparency Property

Sets or retrieves whether the object can be transparent.

Syntax

HRESULT IHTMLFrameBase2::get_allowTransparency(VARIANT_BOOL *p);
HRESULT IHTMLFrameBase2::put_allowTransparency(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEDefault. Object is opaque. It cannot be transparent.
VARIANT_TRUEObject can be transparent.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

When the property is set to VARIANT_FALSE, the IHTMLStyle::backgroundColor property of the object can only be that of the window. When the property is set to VARIANT_TRUE, the IHTMLStyle::backgroundColor property of the object can be set to any value, including the default value of transparent.
