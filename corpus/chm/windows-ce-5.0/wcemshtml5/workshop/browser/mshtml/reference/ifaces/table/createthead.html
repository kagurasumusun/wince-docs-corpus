IHTMLTable::createTHead Method

Creates an empty tHead element in the table.

Syntax

HRESULT createTHead(      
    IDispatch **head
);

Parameters

head
[out, retval] Address of a pointer to an IDispatch interface that receives the tHead element object if successful, or null otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If a tHead already exists, IHTMLTable::createTHead returns the existing element. Otherwise, it returns a pointer to the element created.
