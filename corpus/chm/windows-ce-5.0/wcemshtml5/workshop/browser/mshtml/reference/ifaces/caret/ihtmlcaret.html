IHTMLCaret Interface

This interface provides methods that control the insertion point (caret) in the editor.

IHTMLCaret Members

GetCaretDirection Retrieves a value that indicates which direction is defined as the insertion point's forward direction.
GetLocation Retrieves the horizontal and vertical coordinates of the insertion point's (caret's) location, in pixels.
Hide Makes the insertion point invisible.
InsertText Inserts text at the insertion point's (caret's) position.
IsVisible Determines whether the insertion point (caret) is visible on the display.
MoveCaretToPointer Moves the insertion point position to that of a display pointer.
MoveCaretToPointerEx Moves the insertion point position to that of a display pointer and makes it visible or invisible.
MoveDisplayPointerToCaret Moves a display pointer to the insertion point's (caret's) position.
MoveMarkupPointerToCaret Moves a markup pointer to the insertion point's (caret's) position.
ScrollIntoView Scrolls the insertion point (caret) into view.
SetCaretDirection Specifies which direction is defined as the insertion point's forward direction.
Show Makes the insertion point (caret) visible.
