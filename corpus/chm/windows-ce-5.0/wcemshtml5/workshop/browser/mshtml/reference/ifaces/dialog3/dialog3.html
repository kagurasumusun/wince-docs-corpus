IHTMLDialog3 Interface

This interface provides access to information about an HTML dialog box.

IHTMLDialog3 Members

dialogHide Sets or retrieves the IHTMLDialog3::dialogHide property of the dialog window.
unadorned Sets or retrieves the IHTMLDialog3::unadorned property of the dialog window.

Remarks

The dialog object is the special window object created by the IHTMLWindow2::showModalDialog and IHTMLWindow3::showModelessDialog methods. From within the dialog window, scripts reference the dialog object as the top-level window property.
