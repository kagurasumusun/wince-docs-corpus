IHTMLObjectElement2::namedRecordset Method

Retrieves the recordset object corresponding to the named data member from a data source object (DSO).

Syntax

HRESULT namedRecordset(      
    BSTR dataMember,
    VARIANT *hierarchy,
    IDispatch **ppRecordset
);

Parameters

dataMember
[in] BSTR that specifies the name of the data member, or an empty string, which indicates the default data member.
hierarchy
[in] Address of a VARIANT of type VT_BSTR that specifies a path to a hierarchical data set. May be set to NULL.
ppRecordset
Address of a pointer to an IDispatch interface for the recordset. You can query this interface for an IADORecordset or IADORecordBinding interface. This parameter will be NULL if the specified data member or subchapter is unavailable.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Valid names for a data member are specific to the DSO implementation. Check the DSO documentation to determine whether it supports named data members and to determine the valid names for those data members.

If NULL values or empty strings are passed to the IHTMLObjectElement2::namedRecordset method, the default recordset is returned. This is identical to referring to the IHTMLObjectElement::recordset property directly.

If the second parameter is omitted, the top-level recordset is returned. If the first parameter is omitted but the second parameter is specified, the specified subchapter of the default recordset is returned.
