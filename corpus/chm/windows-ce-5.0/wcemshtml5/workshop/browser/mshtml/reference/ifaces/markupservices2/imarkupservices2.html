IMarkupServices2 Interface

This interface provides methods, along with the IMarkupContainer2 and IMarkupPointer2 interfaces, that enable you to edit the contents of an HTML document from your C++ program.

IMarkupServices2 Members

ParseGlobalEx Parses an HTML string and inserts the results in a markup container.
SaveSegmentsToClipboard Saves the segments contained in the segment list to the Clipboard.
ValidateElements Validates the content between two specified markup pointers in a markup container.
