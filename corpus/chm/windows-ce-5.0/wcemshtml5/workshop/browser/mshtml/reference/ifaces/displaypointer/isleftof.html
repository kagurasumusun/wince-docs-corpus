IDisplayPointer::IsLeftOf Method

Determines whether the display pointer this interface refers to is to the left of another one.

Syntax

HRESULT IsLeftOf(      
    IDisplayPointer *pDispPointer,
    BOOL *pfIsLeftOf
);

Parameters

pDispPointer
[in] Pointer to an IDisplayPointer interface that specifies the display pointer to compare to this one.
pfIsLeftOf
[out] Pointer to a variable of type BOOL that receives TRUE if the display pointer represented by this interface is to the left of pDispPointer, or FALSE otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.
