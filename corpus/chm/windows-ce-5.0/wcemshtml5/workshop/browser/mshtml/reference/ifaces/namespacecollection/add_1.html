IHTMLNamespaceCollection::add Method

Creates a new namespace object and adds it to the collection.

Syntax

HRESULT add(      
    BSTR bstrNamespace,
    BSTR bstrUrn,
    VARIANT implementationUrl,
    IDispatch **ppNamespace
);

Parameters

bstrNamespace
[in] BSTR that specifies the name of the namespace.
bstrUrn
[in] BSTR that specifies the Uniform Resource Name (URN) of the namespace to create.
implementationUrl
[in] VARIANT that specifies the URL of the element behavior to import into the namespace. Specifying this parameter is the same as calling the IHTMLNamespace::doImport method.
ppNamespace
[out, retval] Address of a pointer to an IDispatch interface that receives a namespace object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Adding a new namespace with the same name as an existing namespace will replace the existing namespace.
