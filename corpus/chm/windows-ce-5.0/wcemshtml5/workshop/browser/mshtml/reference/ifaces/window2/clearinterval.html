IHTMLWindow2::clearInterval Method

Cancels the interval previously started using the IHTMLWindow2::setInterval method.

Syntax

HRESULT clearInterval(      
    long timerID
);

Parameters

timerID
[in] long that specifies the interval to cancel. This value must have been previously returned by the IHTMLWindow2::setInterval method.

Return Value

Returns S_OK if successful, or an error value otherwise.
