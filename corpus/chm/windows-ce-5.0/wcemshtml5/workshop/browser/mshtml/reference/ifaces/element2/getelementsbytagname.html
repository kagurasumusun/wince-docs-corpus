IHTMLElement2::getElementsByTagName Method

Retrieves a collection of objects based on the specified element name.

Syntax

HRESULT getElementsByTagName(      
    BSTR v,
    IHTMLElementCollection **pelColl
);

Parameters

v
[in] BSTR that specifies the name of an element.
pelColl
[out, retval] Address of a pointer to an IHTMLElementCollection interface.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

When you use the IHTMLElement2::getElementsByTagName method, all child and nested child elements with the specified tag name are returned.
