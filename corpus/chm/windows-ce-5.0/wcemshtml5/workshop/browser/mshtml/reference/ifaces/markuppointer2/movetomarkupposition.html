IMarkupPointer2::MoveToMarkupPosition Method

Moves a markup pointer to a given position in a given markup container.

Syntax

HRESULT MoveToMarkupPosition(      
    IMarkupContainer *pContainer,
    long lMP
);

Parameters

pContainer
[in] Pointer to an IMarkupContainer interface for the markup container in which to place the markup pointer.
lMP
[in] Long integer that specifies the new position.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If the markup pointer is already positioned in a markup container, then pContainer can be set to NULL to move the pointer within its current container.

Setting lMP to -1 invalidates the pointer's positioning.
