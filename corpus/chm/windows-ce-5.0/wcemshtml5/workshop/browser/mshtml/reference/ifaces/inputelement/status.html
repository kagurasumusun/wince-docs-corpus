IHTMLInputElement::status Property

Sets or retrieves the value indicating whether the control is selected.

Syntax

HRESULT IHTMLInputElement::get_status(VARIANT_BOOL *p);
HRESULT IHTMLInputElement::put_status(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEDefault. Control is not selected.
VARIANT_TRUEControl is selected.
NULLControl is not initialized.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Setting the IHTMLTextAreaElement::status property of a textArea object updates the value of the property and causes the HTMLElementEvents::onpropertychange event to fire. However, this change has no visual effect on the textArea object.
