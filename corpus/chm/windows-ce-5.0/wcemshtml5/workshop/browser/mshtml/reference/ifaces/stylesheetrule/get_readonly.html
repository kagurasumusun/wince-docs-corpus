IHTMLStyleSheetRule::readOnly Property

Retrieves whether the rule or style sheet is defined on the page or is imported.

Syntax

HRESULT IHTMLStyleSheetRule::get_readOnly(VARIANT_BOOL *p);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEDefault. Rule or style sheet is obtained through a link object or the @import rule.
VARIANT_TRUERule or style sheet is defined on the page.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

You cannot modify style sheets obtained through a link object or the @import rule while the IHTMLDocument2::designMode property is enabled. For more information, see Introduction to MSHTML Editing.
