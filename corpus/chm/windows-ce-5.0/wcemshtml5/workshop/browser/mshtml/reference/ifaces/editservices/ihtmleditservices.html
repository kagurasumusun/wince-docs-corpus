IHTMLEditServices Interface

This interface provides methods that enable you to add or remove edit designers and control the current selection.

IHTMLEditServices Members

AddDesigner Registers an IHTMLEditDesigner interface to receive event notification from the editor.
GetSelectionServices Retrieves an ISelectionServices interface for a markup container.
MoveToSelectionAnchor Moves a markup pointer to the location of the current selection's anchor.
MoveToSelectionEnd Moves a markup pointer to the current selection's end.
RemoveDesigner Stops an IHTMLEditDesigner interface from receiving further event notification from the editor.

Remarks

To obtain an IHTMLEditServices interface pointer, use the following steps.

  1. From an IHTMLDocument interface call QueryInterface, requesting an IServiceProvider interface (IID_IServiceProvider).
  2. Call IServiceProvider::QueryService to obtain an IHTMLEditServices interface, using SID_SHTMLEditServices for the guidService parameter and IID_IHTMLEditServices for the riid parameter.
