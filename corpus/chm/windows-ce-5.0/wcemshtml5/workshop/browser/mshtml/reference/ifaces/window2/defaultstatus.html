IHTMLWindow2::defaultStatus Property

Sets or retrieves the default message displayed in the status bar at the bottom of the window.

Syntax

HRESULT IHTMLWindow2::get_defaultStatus(BSTR *p);
HRESULT IHTMLWindow2::put_defaultStatus(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the message for the status bar.
v
BSTR that specifies the message for the status bar.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Do not confuse IHTMLWindow2::defaultStatus with IHTMLWindow2::status. The IHTMLWindow2::status property reflects a priority or transient message in the status bar, such as the message that appears when an onmouseover event occurs over an anchor.
