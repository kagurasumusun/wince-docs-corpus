IHTMLCurrentStyle::borderWidth Property

Retrieves the width of the left, right, top, and bottom borders of the object.

Syntax

HRESULT IHTMLCurrentStyle::get_borderWidth(BSTR *p);

Parameters

p
Pointer to a variable of type BSTR that receives up to four of the values listed in Possible Values.

Possible Values

mediumDefault.  
thinWidth less than the default.
thickWidth greater than the default.
widthWidth consisting of a floating-point number, followed by an absolute units designator (cm, mm, in, pt, pc, or px) or a relative units designator (em or ex).

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Up to four different widths can be specified, in the following order: top, right, bottom, left. If one width is specified, it is used for all four sides. If two widths are specified, the first is used for the top and bottom borders, and the second is used for left and right borders. If three widths are specified, they are used for top, right/left, and bottom borders, respectively.

As of Microsoft® Internet Explorer 5.5, this property applies to inline elements. With earlier versions of Internet Explorer, inline elements must have an absolute IHTMLCurrentStyle::position or layout to use this property. Element layout is set by providing a value for the IHTMLCurrentStyle::height property or the IHTMLCurrentStyle::width property.

The IHTMLCurrentStyle::borderWidth property does not render if the IHTMLCurrentStyle::borderStyle property is set to none.
