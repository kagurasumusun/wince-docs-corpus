IHTMLEventObj2::clientX Property

Sets or retrieves the x-coordinate of the mouse pointer's position relative to the client area of the window, excluding window decorations and scroll bars.

Syntax

HRESULT IHTMLEventObj2::get_clientX(long *p);
HRESULT IHTMLEventObj2::put_clientX(long v);

Parameters

p
Pointer to a variable of type long that receives the x-coordinate, in pixels.
v
long that specifies the x-coordinate, in pixels.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Because the IHTMLEventObj2::clientX property returns a value relative to the client, you can add the value of the IHTMLElement2::scrollLeft property to determine the distance of the x-coordinate from the edge of the body element.

Within a viewlink, the client area begins at the edge of the master element.
