IHTMLStyle::removeAttribute Method

Removes the given attribute from the object.

Syntax

HRESULT removeAttribute(      
    BSTR strAttributeName,
    LONG lFlags,
    VARIANT_BOOL *pfSuccess
);

Parameters

strAttributeName
[in] BSTR that specifies the attribute name.
lFlags
[in] long that specifies whether to use a case-sensitive search to locate the attribute. By default, this value is set to 1 to indicate that the uppercase and lowercase letters in the specified strAttributeName parameter must exactly match those in the attribute name. If there are multiple attributes specified with different case sensitivity, the attribute returned might vary across platforms.
pfSuccess
[out, retval] Pointer to a VARIANT_BOOL that specifies one of the following possible values:
VARIANT_TRUE
The attribute was successfully removed.
VARIANT_FALSE
The attribute was not removed.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

IHTMLStyle::removeAttribute always returns S_OK as its HRESULT value. Check the pfSuccess parameter to determine if the attribute is successfully removed.

If two or more attributes have the same name—differing only in uppercase and lowercase letters—and lFlags is set to 0, this method removes only the last attribute to be created with this name. All other attributes of the same name are ignored.

When removing the CLASS attribute using this method, specify the strAttributeName to be "className", which is the corresponding Dynamic HTML (DHTML) property.

This method is used only by events created from HTML Components.
