IHTMLTable::deleteCaption Method

Deletes the caption element and its contents from the table.

Syntax

HRESULT deleteCaption(VOID);

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If there are multiple captions in the table, the IHTMLTable::deleteCaption method deletes only the first caption and all its contents.
