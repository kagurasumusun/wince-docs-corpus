IMarkupTextFrags::FindTextFragFromMarkupPointer Method

Looks for a markup text fragment at the location of a specified markup pointer.

Syntax

HRESULT FindTextFragFromMarkupPointer(      
    IMarkupPointer *pPointerFind,
    long *piFrag,
    BOOL *pfFragFound
);

Parameters

pPointerFind
[in] Pointer to an IMarkupPointer interface that specifies the markup pointer to check.
piFrag
[out] Pointer to a variable of type long that receives the index of the text fragment, if there is one.
pfFragFound
[out] Pointer to a variable of type BOOL that receives TRUE if there is a text fragment at the location of the markup pointer, or FALSE otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.
