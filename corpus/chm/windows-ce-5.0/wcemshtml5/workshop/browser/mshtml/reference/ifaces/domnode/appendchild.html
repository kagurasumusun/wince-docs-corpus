IHTMLDOMNode::appendChild Method

Appends an element as a child to the object.

What's New for Microsoft® Internet Explorer 6

This method now applies to the attribute object.

Syntax

HRESULT appendChild(      
    IHTMLDOMNode *newChild,
    IHTMLDOMNode **node
);

Parameters

newChild
[in] Pointer to an IHTMLDOMNode interface that specifies the element to append.
node
[out, retval] Address of a pointer to an IHTMLDOMNode interface that receives a reference to the element that is appended to the object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLDOMNode::appendChild method appends elements to the end of the childNodes collection.
