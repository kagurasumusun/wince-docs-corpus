IMarkupServices::Remove Method

Removes content between two pointers.

Syntax

HRESULT Remove(      
    IMarkupPointer *pPointerStart,
    IMarkupPointer *pPointerFinish
);

Parameters

pPointerStart
[in] Pointer to an IMarkupPointer interface that specifies the start point of text to be removed.
pPointerFinish
[in] Pointer to an IMarkupPointer interface that specifies the end point of text to be removed.

Return Value

Returns S_OK if successful, or an error value otherwise.
