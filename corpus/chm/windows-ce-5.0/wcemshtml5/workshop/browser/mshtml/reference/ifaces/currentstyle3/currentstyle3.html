IHTMLCurrentStyle3 Interface

This interface extends the IHTMLCurrentStyle2 interface.

IHTMLCurrentStyle3 Members

minHeight Sets or retrieves the minimum height for an element.
textOverflow Sets or retrieves a value that indicates whether to render ellipses(...) to indicate text overflow.
whiteSpace Retrieves a value that indicates whether lines are automatically broken inside the object.
wordSpacing Retrieves the amount of additional space between words in the object.
