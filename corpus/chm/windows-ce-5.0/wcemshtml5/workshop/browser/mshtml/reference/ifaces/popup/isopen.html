IHTMLPopup::isOpen Property

Retrieves a value indicating whether the popup window is open.

Syntax

HRESULT IHTMLPopup::get_isOpen(VARIANT_BOOL *p);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.

Possible Values

VARIANT_TRUEPop-up window is open.
VARIANT_FALSEPop-up window is closed.

Return Value

Returns S_OK if successful, or an error value otherwise.
