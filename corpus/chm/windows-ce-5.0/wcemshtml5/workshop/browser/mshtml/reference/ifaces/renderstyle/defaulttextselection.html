IHTMLRenderStyle::defaultTextSelection Property

Sets or retrieves whether to use the default text selection style and ignore all other properties of the IHTMLRenderStyle interface.

Syntax

HRESULT IHTMLRenderStyle::get_defaultTextSelection(BSTR *p);
HRESULT IHTMLRenderStyle::put_defaultTextSelection(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

falseDefault. Properties are not ignored.
trueProperties are ignored.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

When this property is set to true, the default text selection style is used and properties of the IHTMLRenderStyle interface are ignored.

The purpose of the IHTMLRenderStyle::defaultTextSelection property is to support the standard default text selection style.
