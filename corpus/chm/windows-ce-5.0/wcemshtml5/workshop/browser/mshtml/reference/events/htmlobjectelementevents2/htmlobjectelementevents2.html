HTMLObjectElementEvents2 Dispinterface

This dispinterface provides a connection point so that an application or control can intercept events fired by an object element.

HTMLObjectElementEvents2 Members

Event nameDescription#define for the event (for use when implementing IDispatch::Invoke)
onafterupdateFires on a databound object after successfully updating the associated data in the data source object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONAFTERUPDATE
onbeforeupdateFires on a databound object before updating the associated data in the data source object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONBEFOREUPDATE
oncellchangeFires when data changes in the data provider.DISPID_HTMLOBJECTELEMENTEVENTS2_ONCELLCHANGE
ondataavailableFires periodically as data arrives from data source objects that asynchronously transmit their data. DISPID_HTMLOBJECTELEMENTEVENTS2_ONDATAAVAILABLE
ondatasetchangedFires when the data set exposed by a data source object changes. DISPID_HTMLOBJECTELEMENTEVENTS2_ONDATASETCHANGED
ondatasetcompleteFires to indicate that all data is available from the data source object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONDATASETCOMPLETE
onerrorFires when an error occurs during object loading.DISPID_HTMLOBJECTELEMENTEVENTS2_ONERROR
onerrorupdateFires on a databound object when an error occurs while updating the associated data in the data source object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONERRORUPDATE
onreadystatechangeFires when the state of the object has changed. DISPID_HTMLOBJECTELEMENTEVENTS2_ONREADYSTATECHANGE
onrowenterFires to indicate that the current row has changed in the data source and new data values are available on the object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONROWENTER
onrowexitFires just before the data source control changes the current row in the object. DISPID_HTMLOBJECTELEMENTEVENTS2_ONROWEXIT
onrowsdeleteFires when rows are about to be deleted from the recordset. DISPID_HTMLOBJECTELEMENTEVENTS2_ONROWSDELETE
onrowsinsertedFires just after new rows are inserted in the current recordset.DISPID_HTMLOBJECTELEMENTEVENTS2_ONROWSINSERTED
