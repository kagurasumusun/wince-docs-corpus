IHTMLObjectElement3::standby Property

Sets or retrieves a character string that can be used to implement your own IHTMLObjectElement3::standby functionality for the object.

Syntax

HRESULT IHTMLObjectElement3::get_standby(BSTR *p);
HRESULT IHTMLObjectElement3::put_standby(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the value for the standby property.
v
BSTR that specifies the value for the standby property.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property has no default value

There is no functionality implemented for this property unless defined by the author.
