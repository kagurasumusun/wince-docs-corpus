IHTMLNamespaceCollection::item Method

Retrieves a namespace object from the IHTMLNamespaceCollection collection.

Syntax

HRESULT item(      
    VARIANT index,
    IDispatch **ppNamespace
);

Parameters

index
[in] VARIANT of type VT_I4 or VT_BSTR that specifies the namespace to retrieve. If this parameter is an integer, it is the zero-based index of the object. If this parameter is a string, the namespace matching the string is retrieved.
ppNamespace
[out, retval] Address of a pointer to an IDispatch interface for the namespace if successful, otherwise NULL.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Call QueryInterface on ppNamespace to obtain an IHTMLNamespace interface pointer.

This method returns an error if the namespace is not found. When retrieving a namespace by name, index is case-insensitive.

Examples

This example uses the IHTMLAttributeCollection::item method to retrieve a namespace from the namespace collection, import an element behavior, and dynamically add the element behavior to the document. Assume m_spDoc is a valid pointer to an IHTMLDocument2 interface.

IHTMLDocument4* pDoc4;
IDispatch* pNSCollDisp;
IHTMLNamespaceCollection* pNSColl;
IDispatch* pNSDisp;
IHTMLNamespace* pNS;
IHTMLElement* pElem;
IHTMLDOMNode* pElemNode;
IHTMLElement* pBody;
IHTMLDOMNode* pBodyNode;

BSTR bstrHTCPath = SysAllocString(L"editBox.htc");
BSTR bstrTagName = SysAllocString(L"xx:editBox");
BSTR bstrNSName = SysAllocString(L"xx");

VARIANT vNSName;
vNSName.vt = VT_BSTR;
vNSName.bstrVal = bstrNSName;

m_pDoc->QueryInterface(IID_IHTMLDocument4, (void**)&pDoc4);
pDoc4->get_namespaces(&pNSCollDisp);
pNSCollDisp->QueryInterface(IID_IHTMLNamespaceCollection, (void**)&pNSColl);

pNSColl->item(vNSName, &pNSDisp);
pNSDisp->QueryInterface(IID_IHTMLNamespace, (void**)&pNS);

pNS->doImport(bstrHTCPath);

m_pDoc->createElement(bstrTagName, &pElem);
pElem->QueryInterface(IID_IHTMLDOMNode, (void**)&pElemNode);

m_pDoc->get_body(&pBody);
pBody->QueryInterface(IID_IHTMLDOMNode, (void**)&pBodyNode);
pBodyNode->appendChild(pElemNode, NULL);

SysFreeString(bstrNSName);
SysFreeString(bstrHTCPath);
SysFreeString(bstrTagName);

pDoc4->Release();
pNSCollDisp->Release();
pNSColl->Release();
pNSDisp->Release();
pNS->Release();
pElem->Release();
pElemNode->Release();
pBody->Release();
pBodyNode->Release();
