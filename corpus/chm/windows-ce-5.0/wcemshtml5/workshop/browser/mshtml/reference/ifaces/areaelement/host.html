IHTMLAreaElement::host Property

Sets or retrieves the hostname and port number of the location or URL.

Syntax

HRESULT IHTMLAreaElement::get_host(BSTR *p);
HRESULT IHTMLAreaElement::put_host(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the host name and port number.
v
BSTR that specifies the host name and port number.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLAreaElement::host property is the concatenation of the hostname and port properties, separated by a colon (hostname:port). When the IHTMLAreaElement::port property is null, the IHTMLAreaElement::host property is the same as the IHTMLAreaElement::hostname property.
