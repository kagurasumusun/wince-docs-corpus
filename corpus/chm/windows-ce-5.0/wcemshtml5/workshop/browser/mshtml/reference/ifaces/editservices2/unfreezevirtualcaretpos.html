IHTMLEditServices2::UnFreezeVirtualCaretPos Method

Restores control of the virtual caret position to the MSHTML Editor after a previous call to IHTMLEditServices2::FreezeVirtualCaretPos.

Syntax

HRESULT UnFreezeVirtualCaretPos(      
    BOOL fReset
);

Parameters

fReset
[in]  One of the following required values:
TRUE
Reset the virtual caret position to an undefined value.
FALSE
Use the virtual caret position from the previous call to IHTMLEditServices2::FreezeVirtualCaretPos as the current virtual caret position.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The virtual caret tracks the "ideal" movement of the insertion point relative to some given starting point. In horizontal text, the virtual caret position is an X coordinate value used to calculate left-right placement of the insertion point during up/down line movement. In vertical text, it is a Y coordinate value used to calculate up-down placement of the insertion point during left/right line movement.

For instance, consider three lines of text in a contentEditable region—a long line, a short line and another long line—with the insertion point located near the end of the first line.

When the user presses the down arrow key, the visible insertion point moves to the end of the short line. There is also an invisible virtual caret located under the point where the caret was positioned in the first line.

When the user presses the down arrow again, the real insertion point moves to the third line so that it is located (as nearly as possible) under the position the caret occupied when it was in the first line—the position of the virtual caret. As the real insertion point moves from line to line, its visible position will always be as close to the virtual caret position as possible.

The virtual caret position might be undefined if there has been no previous up/down movement. The MSHTML Editor resets the virtual caret position under various circumstances. For instance, the virtual caret position resets when the user presses the left or right arrow keys (for horizontal text), or when the user moves the insertion point to a new location with the mouse.

When IHTMLEditServices2::FreezeVirtualCaretPos is called, the MSHTML Editor will NOT reset the virtual caret position (as it normally does) until the virtual caret position has been released by a call to IHTMLEditServices2::UnFreezeVirtualCaretPos.
