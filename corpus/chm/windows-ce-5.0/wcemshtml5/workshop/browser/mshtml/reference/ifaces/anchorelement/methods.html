IHTMLAnchorElement::Methods Property

Sets or retrieves the list of HTTP methods supported by the object.

Syntax

HRESULT IHTMLAnchorElement::get_Methods(BSTR *p);
HRESULT IHTMLAnchorElement::put_Methods(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the comma-separated list of HTTP methods supported by the object for public use.
v
BSTR that specifies the comma-separated list of HTTP methods supported by the object for public use.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

These methods are more accurately given by the HTTP protocol when it is used. However, for reasons similar to those for the IHTMLElement::title property, it can be useful to include the information in advance in the link. The HTML user agent can choose a different rendering as a function of the methods allowed; for example, if an object has a method that supports searching, an icon denoting this can be rendered.
