IHTMLDataTransfer::clearData Method

Removes one or more data formats from the clipboard through dataTransfer or clipboardData object.

Syntax

HRESULT clearData(      
    BSTR format,
    VARIANT_BOOL *pret
);

Parameters

format
[in] BSTR that specifies one or more of the following data format values:
Text
Removes the text format.
URL
Removes the URL format.
File
Removes the file format.
HTML
Removes the HTML format.
Image
Removes the image format.
pret
[out, retval] Pointer to a VARIANT_BOOL that receives VARIANT_TRUE or VARIANT_FALSE based on the success or failure of the call to IHTMLDataTransfer::clearData.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If no format parameter is passed, the data formats are cleared.

For drag-and-drop operations, the IHTMLDataTransfer::clearData method of the dataTransfer object is generally used in source events, such as ondragstart. When overriding the default behavior of the target, use IHTMLDataTransfer::clearData in the ondrop event. It is particularly useful for selectively removing data formats when multiple formats are specified.
