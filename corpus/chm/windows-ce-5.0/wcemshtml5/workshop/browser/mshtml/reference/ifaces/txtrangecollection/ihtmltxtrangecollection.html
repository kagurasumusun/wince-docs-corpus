IHTMLTxtRangeCollection Interface

The IHTMLTxtRangeCollection interface provides access to a collection of TextRange objects. The IHTMLTxtRangeCollection interface is returned from the createRangeCollection method of the selection object.

IHTMLTxtRangeCollection Members

_newEnum Retrieves an enumerator for the collection.
item Retrieves an object from the filters collection or various other collections.
length Retrieves the number of objects in a collection.

Remarks

Microsoft® Internet Explorer 5.5 does not provide a multiple selection mechanism and returns a collection consisting of a single TextRange object.

Host applications can provide a multiple selection mechanism and can return a collection of TextRange objects that represents discontinuous selections.
