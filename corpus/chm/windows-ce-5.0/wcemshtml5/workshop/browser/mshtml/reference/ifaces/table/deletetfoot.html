IHTMLTable::deleteTFoot Method

Deletes the tFoot element and its contents from the table.

Syntax

HRESULT deleteTFoot(VOID);

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If only one tFoot element exists in the source, the IHTMLTable::deleteTFoot method deletes the table footer. If multiple tFoot elements have been defined, the next tFoot element in the source order is promoted as the table footer.
