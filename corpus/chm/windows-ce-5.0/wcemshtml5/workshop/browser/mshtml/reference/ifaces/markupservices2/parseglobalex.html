IMarkupServices2::ParseGlobalEx Method

Parses an HTML string and inserts the results in a markup container.

Syntax

HRESULT ParseGlobalEx(      
    HGLOBAL hglobalHTML,
    DWORD dwFlags,
    IMarkupContainer *pContext,
    IMarkupContainer **ppContainerResult,
    IMarkupPointer *pPointerStart,
    IMarkupPointer *pPointerFinish
);

Parameters

hglobalHTML
[in] Handle to a NULL-terminated string to parse.
dwFlags
[in] Reserved. Must be set to 0.
pContext
[in] Pointer to an IMarkupContainer interface that provides a context for the parser to look up names if the markup to be inserted contains an element behavior.
ppContainerResult
[out] Address of a pointer to a variable that receives an IMarkupContainer interface pointer for the markup container that receives the result of parsing hglobalHTML.
pPointerStart
[in] Pointer to an IMarkupPointer interface for a markup pointer that will be positioned at the HTML comment <!--StartFragment--> in the string source when the string comes from the Clipboard in the CF_HTML format. Set to NULL, if unneeded.
pPointerFinish
[in] Pointer to an IMarkupPointer interface for a markup pointer that will be positioned at the HTML comment <!--EndFragment--> in the string source when the string comes from the Clipboard in the CF_HTML format. Set to NULL, if unneeded.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

A string in CF_HTML format will include two comments in the form <!--StartFragment--> and <!--EndFragment--> that delimit the actual copied selection in the Clipboard string.
