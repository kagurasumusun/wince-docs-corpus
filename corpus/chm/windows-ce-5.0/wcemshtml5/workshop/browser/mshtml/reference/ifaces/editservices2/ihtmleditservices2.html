IHTMLEditServices2 Interface

This interface extends IHTMLEditServices.

IHTMLEditServices2 Members

FreezeVirtualCaretPos Anchors the virtual caret's position at the current position of the real caret or virtual caret.
MoveToSelectionAnchorEx Moves a display pointer to the location of the current selection's anchor.
MoveToSelectionEndEx Moves a display pointer to the current selection's end.
UnFreezeVirtualCaretPos Restores control of the virtual caret position to the MSHTML Editor after a previous call to IHTMLEditServices2::FreezeVirtualCaretPos.

Remarks

To obtain an IHTMLEditServices2 interface pointer, use the following steps.

  1. From an IHTMLDocument interface, call QueryInterface requesting an IServiceProvider interface (IID_IServiceProvider).
  2. Call IServiceProvider::QueryService to obtain an IHTMLEditServices interface, using SID_SHTMLEditServices for the guidService parameter and IID_IHTMLEditServices for the riid parameter.
  3. Call QueryInterface on the IHTMLEditServices interface pointer obtained in step 2, requesting an IHTMLEditServices2 interface (IID_IHTMLEditServices2).
