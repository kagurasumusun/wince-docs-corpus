IOmNavigator::javaEnabled Method

Returns whether Java is enabled.

Syntax

HRESULT javaEnabled(      
    VARIANT_BOOL *enabled
);

Parameters

enabled
[out, retval] Pointer to a VARIANT_BOOL. Returns one of the following possible values:
VARIANT_TRUE
Java is enabled.
VARIANT_FALSE
Java is not enabled.

Return Value

Returns S_OK if successful, or an error value otherwise.
