IHTMLDocument2::expando Property

Sets or retrieves a value indicating whether arbitrary variables can be created within the object.

What's New for Microsoft® Internet Explorer 6

This property now applies to the attribute object.

Syntax

HRESULT IHTMLDocument2::get_expando(VARIANT_BOOL *p);
HRESULT IHTMLDocument2::put_expando(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_TRUEDefault. Creation of arbitrary variables is allowed.
VARIANT_FALSECreation of arbitrary variables is not allowed.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

You can extend the properties on an object by creating arbitrary properties with values.
