IHTMLOptionsHolder Interface

This interface provides the access methods to pass and control the contents and characteristics of a dialog window.

IHTMLOptionsHolder Members

anythingAfterFrameset Not currently supported.
choosecolordlg Opens the system color-selection dialog box.
document Retrieves a pointer to the parent document of the dialog box.
errorCharacter Retrieves or sets a number indicating the character at which the error occurred, measured from the beginning of the line where the error occurred.
errorCode Retrieves or sets the current error code for the error being reported.
errorDebug Retrieves or sets the value that indicates whether to debug this error.
errorLine Retrieves or sets the line number for the error being reported.
errorMessage Retrieves the string text of the error message to be displayed.
execArg Sets or retrieves the variant argument of any additional parameters that were passed in.
findText Sets or retrieves the text used in a find operation.
fonts Retrieves a collection of all the system-supported fonts.
getCharset Not currently supported.
isApartmentModel Not currently supported.
openfiledlg Opens the system Open File dialog box.
savefiledlg Opens the system Save File dialog box.
showSecurityInfo Opens the Internet security information dialog box for the zone based on the document's IHTMLDocument2::URL.
sizes Receives a collection of the sizes available for the font that is passed in as a parameter.
unsecuredWindowOfDocument Retrieves the parent document's window, which is not wrapped by a security proxy and thus is not considered secure.

Remarks

The IHTMLOptionsHolder object is a container for various options that can be passed as arguments into a dialog window presented from the browser.
