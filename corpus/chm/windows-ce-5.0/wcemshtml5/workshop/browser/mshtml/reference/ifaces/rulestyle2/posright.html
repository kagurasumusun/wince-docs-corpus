IHTMLRuleStyle2::posRight Property

Sets or retrieves the right position of the object in the units specified by the IHTMLRuleStyle2::right attribute.

Syntax

HRESULT IHTMLRuleStyle2::get_posRight(float *p);
HRESULT IHTMLRuleStyle2::put_posRight(float v);

Parameters

p
Pointer to a variable of type float that receives any valid floating-point number that uses the same length units as the IHTMLRuleStyle2::right attribute.
v
float that specifies any valid floating-point number that uses the same length units as the IHTMLRuleStyle2::right attribute.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property reflects the value of the Cascading Style Sheets (CSS) IHTMLRuleStyle2::right attribute for positioned items. This property always returns zero for nonpositioned items because "right" has meaning only when the object is positioned. If the IHTMLRuleStyle2::right attribute is not set, the IHTMLRuleStyle2::posRight property returns zero.

Setting this property changes the value of the right position but leaves the units designator for the property unchanged.

Unlike the IHTMLRuleStyle2::right property, the IHTMLRuleStyle2::posRight property value is a floating-point number, not a string.

For more information about how to access the dimension and location of elements on the page through the Dynamic HTML (DHTML) Document Object Model (DOM), see Measuring Element Dimension and Location.
