IMarkupTextFrags::InsertTextFrag Method

Inserts a new markup text fragment at a specified markup pointer.

Syntax

HRESULT InsertTextFrag(      
    long iFrag,
    BSTR bstrInsert,
    IMarkupPointer *pPointerInsert
);

Parameters

iFrag
[in] long that specifies the index for the text fragment.
bstrInsert
[in] BSTR value that specifies the text to use for the text fragment.
pPointerInsert
[in] Pointer to an IMarkupPointer interface that specifies the location to put the new text fragment.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If 0 <= iFrag <= IMarkupTextFrags::GetTextFragCount, then the markup pointer for the location at which to insert the text fragment must be between the text fragments whose current indexes are iFrag - 1 and iFrag. After the fragment is inserted, the following fragment's indexes will be incremented by 1.

If iFrag = -1, the text fragment will be unconditionally placed at the markup pointer's location. If there is already a text fragment at that location, the new text fragment will be placed just before it.
