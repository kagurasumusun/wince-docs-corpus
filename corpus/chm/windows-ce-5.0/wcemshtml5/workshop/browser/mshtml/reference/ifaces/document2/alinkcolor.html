IHTMLDocument2::alinkColor Property

Sets or retrieves the color of all active links in the document.

Syntax

HRESULT IHTMLDocument2::get_alinkColor(VARIANT *p);
HRESULT IHTMLDocument2::put_alinkColor(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT that receives one of the color names or RGB values in the Color Table.
v
VARIANT that specifies one of the color names or RGB values in the Color Table.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Some browsers do not recognize color names, but all browsers should recognize and correctly display RGB color values.
