IHTMLDocument5::createAttribute Method

Creates an IHTMLDOMAttribute interface with a specified name.

Syntax

HRESULT createAttribute(      
    BSTR bstrattrName,
    IHTMLDOMAttribute **ppattribute
);

Parameters

bstrattrName
[in] BSTR that sets the IHTMLDOMAttribute2::name property.
ppattribute
[out, retval] Address of a pointer variable that receives an IHTMLDOMAttribute2 pointer.

Return Value

Returns S_OK if successful, or an error value otherwise. Returns INVALID_CHARACTER_ERR if the specified name contains an illegal character.

Remarks

This method will fail if the bstrattrName parameter value contains invalid (non Unicode transformation format (UTF)-16) characters .
