IHTMLOptionsHolder::sizes Method

Receives a collection of the sizes available for the font that is passed in as a parameter.

Syntax

HRESULT sizes(      
    BSTR fontName,
    IHTMLFontSizesCollection **pSizesCollection
);

Parameters

fontName
[in] BSTR value that specifies the name of the font from which to obtain the font size information.
pSizesCollection
[out] Address of a pointer to an IHTMLFontSizesCollection interface that receives the collection of available font sizes.

Return Value

Returns S_OK if successful, or an error value otherwise.
