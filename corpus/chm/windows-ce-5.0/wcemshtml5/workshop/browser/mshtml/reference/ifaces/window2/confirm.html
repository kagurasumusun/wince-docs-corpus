IHTMLWindow2::confirm Method

Displays a confirmation dialog box that contains an optional message as well as OK and Cancel buttons.

Syntax

HRESULT confirm(      
    BSTR message,
    VARIANT_BOOL *confirmed
);

Parameters

message
[in] BSTR that specifies the message to display in the confirmation dialog box. If no value is provided, the dialog box does not contain a message.
confirmed
[out, retval] Pointer to a VARIANT_BOOL that receives one of the following possible values:
VARIANT_TRUE
The user clicked the OK button.
VARIANT_FALSE
The user clicked Cancel button.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The title bar of the confirmation dialog box cannot be changed.

See Also

IHTMLWindow2::alert, IHTMLWindow2::prompt
