IHTMLComputedStyle::IsEqual Method

Compares the internal formatting of two IHTMLComputedStyle objects.

Syntax

HRESULT IsEqual(      
    IHTMLComputedStyle *pComputedStyle,
    VARIANT_BOOL *pfEqual
);

Parameters

pComputedStyle
[in] Pointer to an IHTMLComputedStyle interface that specifies the object for the comparison.
pfEqual
[out] Pointer to a VARIANT_BOOL that receives one of the following values, based on the comparison of the two IHTMLComputedStyle objects.
VARIANT_FALSE
One or more properties of the objects are different.
VARIANT_TRUE
All of the properties of the objects are equal.

Return Value

Returns S_OK if successful, or an error value otherwise.
