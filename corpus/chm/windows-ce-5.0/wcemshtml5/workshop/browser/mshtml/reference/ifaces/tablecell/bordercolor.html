IHTMLTableCell::borderColor Property

Sets or retrieves the border color of the object.

Syntax

HRESULT IHTMLTableCell::get_borderColor(VARIANT *p);
HRESULT IHTMLTableCell::put_borderColor(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_BSTR or VT_I4 that receives one of the color names or RGB values in the Color Table.
v
VARIANT of type VT_BSTR or VT_I4 that specifies one of the color names or RGB values in the Color Table.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Some browsers do not recognize color names, but all browsers should recognize RGB color values and display them correctly.

See Also

IHTMLTable::border, IHTMLTable::borderColorDark, IHTMLTable::borderColorLight
