IHTMLOptionElementFactory::create Method

Creates a new instance of the option element.

Syntax

HRESULT create(      
    VARIANT text,
    VARIANT value,
    VARIANT defaultselected,
    VARIANT selected,
    IHTMLOptionElement **__MIDL_0017
);

Parameters

text
[in] Value or string that specifies the text of the element.
value
[in] BSTR that specifies the value of the element.
defaultselected
[in] Value that indicates whether this option is selected by default. If TRUE, this option is selected by default; otherwise, it isn't.
selected
[in] Value that indicates whether this is the default option in the select block. If TRUE, this option is the default; otherwise, it isn't.
__MIDL_0017
[out, retval] Address of a pointer to a variable that receives the interface for the new option element.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

You can add the element to a select block by using the IHTMLSelectElement::add method.
