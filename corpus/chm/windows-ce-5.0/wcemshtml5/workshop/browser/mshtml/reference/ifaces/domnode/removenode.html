IHTMLDOMNode::removeNode Method

Removes the object from the document hierarchy.

Syntax

HRESULT removeNode(      
    VARIANT_BOOL fDeep,
    IHTMLDOMNode **removed
);

Parameters

fDeep
[in] VARIANT_BOOL that specifies one of the following values:
VARIANT_FALSE
Default. IHTMLDOMNode::childNodes collection of the object is not removed.
VARIANT_TRUE
IHTMLDOMNode::childNodes collection of the object is removed.
removed
[out, retval] Address to a pointer that returns a reference to the object that is removed.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This property is accessible at run time. If elements are removed at run time, before the closing tag is parsed, areas of the document might not render.
