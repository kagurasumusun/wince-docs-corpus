IHTMLWindow2::frames Property

Retrieves an interface pointer to a zero-based collection of frames in an HTML document.

Syntax

HRESULT IHTMLWindow2::get_frames(IHTMLFramesCollection2 **p);

Parameters

p
Address of a pointer to a variable of type IHTMLFramesCollection2 interface that receives the collection of frames.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLWindow2::frames property returns a collection of FRAME elements in the document, if the document contains the frameSet element. If the document contains the BODY element, the IHTMLWindow2::frames property returns a collection of all iframe elements in the document. The elements are in the same order as they appear in the document, regardless of whether the document contains the BODY element or the frameSet element.

The collection is indexed first by name, then by ID. If duplicate names are found, a collection of those named items is returned. The resulting collection can be only referenced by ordinal position.
