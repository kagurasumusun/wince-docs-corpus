IDisplayPointer::GetPointerGravity Method

Retrieves the pointer gravity for the display pointer.

Syntax

HRESULT GetPointerGravity(      
    POINTER_GRAVITY *peGravity
);

Parameters

peGravity
[out] Pointer to a variable of type POINTER_GRAVITY that receives the term pointer gravity value.

Return Value

Returns S_OK if successful, or an error value otherwise.
