IHTMLCurrentStyle::rubyPosition Property

Retrieves the position of the ruby text specified by the rt object.

Syntax

HRESULT IHTMLCurrentStyle::get_rubyPosition(BSTR *p);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.

Possible Values

aboveDefault. Ruby text is positioned above the base text.
inlineRuby text is positioned inline with the base text.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLCurrentStyle::rubyPosition property specifies the position of the ruby text defined by the rt object, and is set on the ruby object.

See Also

IHTMLCurrentStyle::rubyAlign, IHTMLCurrentStyle::rubyOverhang
