IHTMLWindow4 Interface

This interface provides access to an additional property and method of the window object, which represents an open window in the browser.

IHTMLWindow4 Members

createPopup Creates an IHTMLPopup window.
frameElement Retrieves the frame or iframe object that is hosting the window in the parent document.
