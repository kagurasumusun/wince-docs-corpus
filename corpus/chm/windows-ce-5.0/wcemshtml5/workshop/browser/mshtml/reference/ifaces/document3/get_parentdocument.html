IHTMLDocument3::parentDocument Property

Retrieves an interface pointer that provides access to the parent object's document interface.

Syntax

HRESULT IHTMLDocument3::get_parentDocument(IHTMLDocument3 **p);

Parameters

p
Address of a pointer to a variable of type IHTMLDocument3 interface that receives the interface of the parent object. The variable receives NULL if the current object is the top-most object.

Return Value

Returns S_OK if successful, or an error value otherwise.
