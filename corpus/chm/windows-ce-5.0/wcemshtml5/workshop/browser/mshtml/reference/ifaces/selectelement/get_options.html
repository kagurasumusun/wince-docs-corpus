IHTMLSelectElement::options Property

Retrieves an interface pointer for the select object.

Syntax

HRESULT IHTMLSelectElement::get_options(IDispatch **p);

Parameters

p
Address of a pointer to a variable of type IDispatch interface that receives the select object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Do not use this property to retrieve the collection of option objects within the select object. Instead, use the IHTMLSelectElement::length property and IHTMLSelectElement::item method to iterate over the option objects.
