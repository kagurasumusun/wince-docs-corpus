IHTMLFrameBase2::onreadystatechange Property

Sets or retrieves a pointer to the event handler function associated with the onreadystatechange event.

Syntax

HRESULT IHTMLFrameBase2::get_onreadystatechange(VARIANT *p);
HRESULT IHTMLFrameBase2::put_onreadystatechange(VARIANT v);

Parameters

p
Pointer to a VARIANT of type VT_DISPATCH that implements the event handler function.
v
VARIANT of type VT_DISPATCH that implements the event handler function.

Return Value

Returns S_OK if successful, or an error value otherwise.

See Also

IHTMLDocument3::attachEvent, IHTMLElement2::attachEvent
