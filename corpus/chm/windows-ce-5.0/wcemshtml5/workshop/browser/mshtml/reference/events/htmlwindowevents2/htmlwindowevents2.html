HTMLWindowEvents2 Dispinterface

This dispinterface provides a connection point so that an application or control can intercept events fired by an window element.

HTMLWindowEvents2 Members

Event nameDescription#define for the event (for use when implementing IDispatch::Invoke)
onafterprintFires on the object immediately after its associated document prints or previews for printing. DISPID_HTMLWINDOWEVENTS2_ONAFTERPRINT
onbeforeprintFires on the object before its associated document prints or previews for printing. DISPID_HTMLWINDOWEVENTS2_ONBEFOREPRINT
onbeforeunloadFires prior to a page being unloaded. DISPID_HTMLWINDOWEVENTS2_ONBEFOREUNLOAD
onblurFires when the object loses the input focus. DISPID_HTMLWINDOWEVENTS2_ONBLUR
onerrorFires when an error occurs during object loading.DISPID_HTMLWINDOWEVENTS2_ONERROR
onfocusFires when the object receives focus. DISPID_HTMLWINDOWEVENTS2_ONFOCUS
onhelpFires when the user presses the F1 key while the browser is the active window. DISPID_HTMLWINDOWEVENTS2_ONHELP
onloadFires immediately after the browser loads the object. DISPID_HTMLWINDOWEVENTS2_ONLOAD
onresizeFires when the size of the object is about to change. DISPID_HTMLWINDOWEVENTS2_ONRESIZE
onscrollFires when the user repositions the scroll box in the scroll bar on the object. DISPID_HTMLWINDOWEVENTS2_ONSCROLL
onunloadFires immediately before the object is unloaded. DISPID_HTMLWINDOWEVENTS2_ONUNLOAD
