IHTMLFormElement::method Property

Sets or retrieves how to send the form data to the server.

Syntax

HRESULT IHTMLFormElement::get_method(BSTR *p);
HRESULT IHTMLFormElement::put_method(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

getAppend the arguments to the action URL and open it as if it were an anchor.
postSend the data through an HTTP post transaction.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

When using the post method, there is no theoretical limit to the amount of data that can be sent to the HTTP server. The amount of data may be constrained by the physical limits of the client computer.

When using the get method to send data to an HTTP server, the amount of data that can be sent is limited by the maximum length of a URL. In this case the URL cannot be longer than 2048 bytes.
