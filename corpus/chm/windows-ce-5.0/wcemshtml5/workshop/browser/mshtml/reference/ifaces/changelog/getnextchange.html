IHTMLChangeLog::GetNextChange Method

Retrieves the next change record stored in the change log.

Syntax

HRESULT GetNextChange(      
    BYTE *pbBuffer,
    long nBufferSize,
    long *pnRecordLength
);

Parameters

pbBuffer
[in] Pointer to a variable of type BYTE that specifies the first byte of a caller-allocated buffer in which to store the record.
nBufferSize
[in] Long integer that specifies the size of the caller-allocated buffer, in bytes.
pnRecordLength
[out] Pointer to a variable of type long that receives the size of the record, in bytes.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Change records vary in length and have no maximum length. This method therefore has two uses: 1) to get a change record and 2) to determine how big a buffer you need to allocate for the next record. IHTMLChangeLog::GetNextChange will always retrieve the value for pnRecordLength, even if the method fails. If your buffer is too small and this method returns S_FALSE, use the value in pnRecordLength to reallocate your buffer so that it is large enough for the next record, and call IHTMLChangeLog::GetNextChange again.

If no further changes are pending, this method will set pnRecordLength to zero.
