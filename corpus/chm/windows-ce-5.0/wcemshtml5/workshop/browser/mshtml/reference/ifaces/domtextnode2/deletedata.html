IHTMLDOMTextNode2::deleteData Method

Removes a specified range of characters from the object.

Syntax

HRESULT deleteData(      
    long offset,
    long Count
);

Parameters

offset
[in] long that specifies the offset from which to start.
Count
[in] long that specifies the number of characters to remove.

Return Value

Returns S_OK if successful, or an error value otherwise.
