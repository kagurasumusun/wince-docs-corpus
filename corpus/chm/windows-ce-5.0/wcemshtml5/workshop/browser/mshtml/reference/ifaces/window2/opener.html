IHTMLWindow2::opener Property

Sets or retrieves a reference to the window that created the current window.

Syntax

HRESULT IHTMLWindow2::get_opener(VARIANT *p);
HRESULT IHTMLWindow2::put_opener(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_BSTR or VT_I4 that receives the window reference.
v
VARIANT of type VT_BSTR or VT_I4 that specifies the window reference.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLWindow2::opener property is available only for frame and iframe pages.
