ILineInfo Interface

This interface provides properties that contain information about a line of text in a rendered HTML document.

ILineInfo Members

baseLine Retrieves the y-coordinate of the line's baseline, relative to its containing element.
lineDirection Retrieves the direction in which a line of text is read, either from left to right or from right to left.
textDescent Retrieves the amount that a line's descenders fall below the baseline.
textHeight Retrieves the height of a line of text.
x Retrieves the horizontal distance from the edge of the flow layout element containing a line of text to the beginning of the line.

Remarks

ILineInfo is used in conjunction with display pointers to provide information about the line on which a display pointer is located. You can obtain a pointer to an ILineInfo interface by calling IDisplayPointer::GetLineInfo.
