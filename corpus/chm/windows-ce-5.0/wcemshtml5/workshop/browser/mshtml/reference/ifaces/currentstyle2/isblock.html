IHTMLCurrentStyle2::isBlock Property

Retrieves a value that indicates whether the object is a block-level object.

Syntax

HRESULT IHTMLCurrentStyle2::get_isBlock(VARIANT_BOOL *p);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEObject is not a block-level object.
VARIANT_TRUEObject is a block-level object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Block-level objects cause a line break before and after their content. Some objects, such as div and p objects, are block-level objects by default. Other objects become block-level objects when you can set their IHTMLStyle::display property to block.
