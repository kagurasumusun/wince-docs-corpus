IMarkupPointer2 Interface

This interface provides methods that move a markup pointer within a markup container and gather information about the contents of the container.

IMarkupPointer2 Members

GetMarkupPosition Retrieves the position of a markup pointer.
IsAtWordBreak Determines if the markup pointer is positioned at a word break.
IsInsideURL Determines if a markup pointer is located inside of, at the beginning of, or at the end of text that is formatted as a URL.
MoveToContent Moves a markup pointer to a particular element in a markup container.
MoveToMarkupPosition Moves a markup pointer to a given position in a given markup container.
MoveUnitBounded Moves a markup pointer to a specified location in a specified direction, but not past another given markup pointer.
