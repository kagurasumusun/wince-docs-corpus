IHTMLElement::isTextEdit Property

Retrieves whether a TextRange object can be created using the object.

Syntax

HRESULT IHTMLElement::get_isTextEdit(VARIANT_BOOL *p);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.

Possible Values

VARIANT_FALSETextRange object cannot be created.
VARIANT_TRUETextRange object can be created.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

To create a TextRange object, you can use only the body, button, and textArea objects and an input object with one of the following types: button, hidden, password, reset, submit, or text.
