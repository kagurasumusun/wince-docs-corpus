IHTMLObjectElement Interface

This interface inserts an object into the HTML page.

IHTMLObjectElement Members

align Sets or retrieves how the object is aligned with adjacent text.
altHTML Sets the optional alternative HTML script to execute if the object fails to load.
BaseHref Retrieves a string of the URL where the object tag can be found. This is often the IHTMLBaseElement::href of the document that the object is in, or the value set by a base element.
classid Retrieves the class identifier for the object.
code Sets or retrieves the URL of the file containing the compiled Java class.
codeBase Sets or retrieves the URL of the component.
codeType Sets or retrieves the Internet media type for the code associated with the object.
data Retrieves the URL that references the data of the object.
form Retrieves a reference to the form that the object is embedded in.
height Sets or retrieves the height of the object.
hspace Sets or retrieves the horizontal margin for the object.
name Sets or retrieves the name of the object.
object Retrieves the contained object.
onerror Sets or retrieves a pointer to the event handler function associated with the onerror event. An onerror event occurs when loading the object causes an error.
onreadystatechange Sets or retrieves a pointer to the event handler function associated with the onreadystatechange event.
readyState Retrieves the current state of the object.
recordset Sets or retrieves from a data source object a reference to the default record set.
type Sets or retrieves the MIME type of the object.
vspace Sets or retrieves the vertical margin for the object.
width Sets or retrieves the width of the object.

Remarks

The object element is a block element.
