IHTMLWindow2::showHelp Method

Displays a Help file. This method can be used with Microsoft HTML Help.

Syntax

HRESULT showHelp(      
    BSTR helpURL,
    VARIANT helpArg
);

Parameters

helpURL
[in] BSTR that specifies the URL of the file to be displayed as help.
helpArg
[in] VARIANT that specifies a string or integer that indicates a context identifier in a Help file.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Only files of types .chm and .htm are supported as help files.

When implementing this method, a second Help dialog box appears when the user presses F1 or clicks Help on the menu bar. You can prevent the default Help dialog box from appearing by setting IHTMLEventObj::returnValue to false.
