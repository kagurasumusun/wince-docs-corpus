IHTMLStyle3::textAlignLast Property

Sets or retrieves how to align the last line or only line of text in the object.

Syntax

HRESULT IHTMLStyle3::get_textAlignLast(BSTR *p);
HRESULT IHTMLStyle3::put_textAlignLast(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

autoDefault. Text is aligned like the other lines in the object, using the value of the IHTMLStyle::textAlign property.
centerText is centered.
inheritText is aligned like the text in the parent object.
justifyText is justified.
leftText is aligned to the left.
rightText is aligned to the right.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The property is read-only for the IHTMLCurrentStyle2 interface.

The property applies to block elements.
