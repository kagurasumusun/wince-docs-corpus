IHTMLFormElement3::namedItem Method

Retrieves an object or a collection from the specified collection.

Syntax

HRESULT namedItem(      
    BSTR name,
    IDispatch **pdisp
);

Parameters

name
[in] BSTR that specifies the name or id property of the object to retrieve. A collection is returned if more than one match is made.
pdisp
[out, retval] Address of a pointer to a variable that receives an IDispatch interface for the object or collection if successful, or NULL otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method first searches for an object with a matching id attribute. If a match is not found, the method then searches for an object with a matching name attribute, but only on those elements that are allowed a name attribute.
