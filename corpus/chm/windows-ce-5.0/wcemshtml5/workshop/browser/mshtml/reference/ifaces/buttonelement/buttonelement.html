IHTMLButtonElement Interface

This interface renders content as an HTML button.

IHTMLButtonElement Members

createTextRange Creates a TextRange object for the element.
disabled Sets or retrieves the status of the object.
form Retrieves a reference to the form that the object is embedded in.
name Sets or retrieves the name of the object.
status Sets or retrieves the value indicating whether the control is selected.
type Retrieves the classification and default behavior of the button.
value Sets or retrieves the default or selected value of the control.

Remarks

The button element is a block element.
