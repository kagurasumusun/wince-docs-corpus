IHTMLTextAreaElement::disabled Property

Sets or retrieves the status of the object.

Syntax

HRESULT IHTMLTextAreaElement::get_disabled(VARIANT_BOOL *p);
HRESULT IHTMLTextAreaElement::put_disabled(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_FALSEDefault. Element is not disabled.
VARIANT_TRUEElement is disabled.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

When an element is disabled, it appears dimmed and does not respond to user input. Disabled elements do not respond to mouse events, nor will they respond to the IHTMLElement3::contentEditable property.

If an element's IHTMLTextAreaElement::disabled property is set to false but it is contained within a IHTMLTextAreaElement::disabled element, it cannot override the IHTMLTextAreaElement::disabled state of its container.
