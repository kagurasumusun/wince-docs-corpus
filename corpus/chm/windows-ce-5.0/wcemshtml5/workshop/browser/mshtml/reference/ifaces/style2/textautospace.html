IHTMLStyle2::textAutospace Property

Sets or retrieves the autospacing and narrow space width adjustment of text.

Syntax

HRESULT IHTMLStyle2::get_textAutospace(BSTR *p);
HRESULT IHTMLStyle2::put_textAutospace(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

noneDefault. No effect takes place—that is, no extra space is added.
ideograph-alphaCreates extra spacing between runs of ideographic and non-ideographic text, such as Latin-based, Cyrillic, Greek, Arabic, or Hebrew text.
ideograph-numericCreates extra spacing between runs of ideographic text and numeric characters.
ideograph-parenthesisCreates extra spacing between a normal (non-wide) parenthesis and an ideograph.
ideograph-spaceExtends the width of the space character when it is adjacent to ideographs.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

An ideograph is a character in an Asian writing system that represents a concept or an idea, but not a particular word or pronunciation.
