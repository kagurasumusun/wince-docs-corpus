IHTMLCommentElement2::data Property

Sets or retrieves the URL that references the data of the object.

What's New for Microsoft® Internet Explorer 6

This property now applies to the comment object.

Syntax

HRESULT IHTMLCommentElement2::get_data(BSTR *p);
HRESULT IHTMLCommentElement2::put_data(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the URL of the data.
v
BSTR that specifies the URL of the data.

Return Value

Returns S_OK if successful, or an error value otherwise.
