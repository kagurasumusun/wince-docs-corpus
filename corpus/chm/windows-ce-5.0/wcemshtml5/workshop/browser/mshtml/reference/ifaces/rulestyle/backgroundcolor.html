IHTMLRuleStyle::backgroundColor Property

Sets or retrieves the color behind the content of the object.

Syntax

HRESULT IHTMLRuleStyle::get_backgroundColor(VARIANT *p);
HRESULT IHTMLRuleStyle::put_backgroundColor(VARIANT v);

Parameters

p
Pointer to a variable of type VARIANT of type VT_BSTR or VT_I4 that receives one of the values listed in Possible Values.
v
VARIANT of type VT_BSTR or VT_I4 that specifies one of the values listed in Possible Values.

Possible Values

transparentDefault. Color of the next parent object through which the background is visible.
colorAny color value, including those specified in the Color Table.

Return Value

Returns S_OK if successful, or an error value otherwise.
