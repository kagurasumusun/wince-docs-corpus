IHTMLParamElement::value Property

Sets or retrieves the value of an input parameter for an element.

What's New for Microsoft® Internet Explorer 6

The IHTMLParamElement::value property is now read/write.

Syntax

HRESULT IHTMLParamElement::get_value(BSTR *p);
HRESULT IHTMLParamElement::put_value(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the value which is passed to an applet, embed, or object element.
v
BSTR that specifies the value which is passed to an applet, embed, or object element.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

In Internet Explorer 3.02 and later, IHTMLParamElement::value is an attribute of param. Beginning in Internet Explorer 6, IHTMLParamElement::value is a read/write property.
