IHTMLDOMNode::cloneNode Method

Copies a reference to the object from the document hierarchy.

What's New for Microsoft® Internet Explorer 6

This method applies to the attribute object as of Internet Explorer 6.

Syntax

HRESULT cloneNode(      
    VARIANT_BOOL fDeep,
    IHTMLDOMNode **clonedNode
);

Parameters

fDeep
[in] VARIANT_BOOL that specifies one of the following values:
VARIANT_FALSE
Default. Cloned objects do not include childNodes.
VARIANT_TRUE
Cloned objects include childNodes.
clonedNode
[out, retval] Address of a pointer to an IHTMLDOMNode interface that receives a reference to the newly created node.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLDOMNode::cloneNode method copies an object, attributes, and, if specified, the childNodes.

A collection is returned when referring to the ID of a cloned element.

The IHTMLDOMNode::cloneNode method will not work on an IFRAME directly. You must call it through the all collection. The following example demonstrates how to call IHTMLDOMNode::cloneNode on an IFRAME. 

<HTML>
<SCRIPT>
function fnBegin(){
    var fr = document.all.oFrame.cloneNode();
    alert(document.body.innerHTML);
}    
</SCRIPT>
<BODY onload="fnBegin()">
    <IFRAME id="oFrame" src="about:blank" 
        style="border:1px solid black; position:absolute; top:20px; left:30px;
            width:350px; height:300px;"></IFRAME>
</BODY>    
</HTML>
