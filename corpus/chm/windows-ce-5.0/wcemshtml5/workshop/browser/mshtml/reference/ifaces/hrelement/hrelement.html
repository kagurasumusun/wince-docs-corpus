IHTMLHRElement Interface

This interface draws a horizontal rule.

IHTMLHRElement Members

align Sets or retrieves the alignment of the object relative to the display or table.
color Sets or retrieves the color to be used by the object.
noShade Sets or retrieves whether the horizontal rule is drawn with 3-D shading.
size Sets or retrieves the height of the hr object.
width Sets or retrieves the width of the object.

Remarks

The hr element is a block element.
