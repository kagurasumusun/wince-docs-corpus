IHTMLEditServices2::MoveToSelectionAnchorEx Method

Moves a display pointer to the location of the current selection's anchor.

Syntax

HRESULT MoveToSelectionAnchorEx(      
    IDisplayPointer *pIStartAnchor
);

Parameters

pIStartAnchor
[in] Pointer to an IDisplayPointer interface to move to the location of the selection's anchor.

Return Value

Returns S_OK if successful, or an error value otherwise.
