IHTMLRect::right Property

Sets or retrieves the right coordinate of the rectangle surrounding the object content.

Syntax

HRESULT IHTMLRect::get_right(long *p);
HRESULT IHTMLRect::put_right(long v);

Parameters

p
Pointer to a variable of type long that receives the right coordinate of the rectangle, in pixels.
v
long that specifies the right coordinate of the rectangle, in pixels.

Return Value

Returns S_OK if successful, or an error value otherwise.
