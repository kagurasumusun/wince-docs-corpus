IHTMLAreasCollection::add Method

Adds an element to the areas, controlRange, or options collection.

Syntax

HRESULT add(      
    IHTMLElement *element,
    VARIANT before
);

Parameters

element
[in] Pointer to an IHTMLElement interface that specifies the element to add to the collection.
before
[in] VARIANT of type VT_I4 that specifies the index position in the collection where the element is placed. If no value is given, the method places the element at the end of the collection.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Before you can add an element to a collection, you must create it first by using the IHTMLDocument2::createElement method.

This method can be used to add elements only after the page loads.
