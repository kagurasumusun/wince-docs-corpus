IHTMLControlRange::item Method

Retrieves an object from the controlRange collection.

Syntax

HRESULT item(      
    long index,
    IHTMLElement **pdisp
);

Parameters

index
[in] long that specifies the zero-based index of the object to retrieve.
pdisp
[out, retval] Address of a pointer to the IHTMLElement interface that returns an element object if successful, otherwise NULL.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

This method returns S_OK even if the element is not found. You should check the value of the IDispatch pointer returned by this call. If the value of the pointer is NULL, the element was not found and the call was not successful.
