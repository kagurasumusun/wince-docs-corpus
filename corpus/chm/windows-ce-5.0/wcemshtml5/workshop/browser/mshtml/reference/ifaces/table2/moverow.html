IHTMLTable2::moveRow Method

Moves a table row to a new position.

Syntax

HRESULT moveRow(      
    long indexFrom,
    long indexTo,
    IDispatch row
);

Parameters

indexFrom
[in] long that specifies the index in the rows collection of the table row that is moved.
-1
Default.
indexTo
[in] long that specifies where the row is moved within the rows collection.
-1
Default.
row
Object. Returns a reference to the table row that is moved.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Rows between the indexFrom and indexTo positions in the rows collection are shifted based on the direction the row moves.
