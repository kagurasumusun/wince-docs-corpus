IHTMLFrameBase2::contentWindow Property

Retrieves the IHTMLWindow2 object of the specified IHTMLFrameElement or IHTMLIFrameElement.

Syntax

HRESULT IHTMLFrameBase2::get_contentWindow(IHTMLWindow2 **p);

Parameters

p
Address of a pointer to a variable of type IHTMLWindow2 interface that receives the IHTMLWindow2 object.

Return Value

Returns S_OK if successful, or an error value otherwise.
