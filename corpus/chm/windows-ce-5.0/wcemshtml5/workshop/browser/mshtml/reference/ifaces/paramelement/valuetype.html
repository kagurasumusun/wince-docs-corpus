IHTMLParamElement::valueType Property

Sets or retrieves the data type of the IHTMLParamElement::value attribute.

Syntax

HRESULT IHTMLParamElement::get_valueType(BSTR *p);
HRESULT IHTMLParamElement::put_valueType(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the type of data specified in the IHTMLParamElement::value attribute of the param element.
v
BSTR that specifies the type of data specified in the IHTMLParamElement::value attribute of the param element.

Possible Values

dataDefault. The value specified by the IHTMLParamElement::value attribute will be evaluated and passed to the applet, embed, or object element as a string.
refThe value specified by the IHTMLParamElement::value attribute is a Uniform Resource Identifier (URI) that designates a resource where run-time values are stored. This allows support tools to identify URIs given as parameters.
objectThe value specified by the IHTMLParamElement::value attribute is an identifier (ID) that refers to an object declaration in the same document. The ID must be the value of the id attribute set for the declared object element.

Return Value

Returns S_OK if successful, or an error value otherwise.
