IHTMLDocument2::protocol Property

Sets or retrieves the protocol portion of a URL.

Syntax

HRESULT IHTMLDocument2::get_protocol(BSTR *p);
HRESULT IHTMLDocument2::put_protocol(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives the protocol used to transfer information.
v
BSTR that specifies the protocol used to transfer information.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The IHTMLDocument2::protocol property specifies how to transfer information from the host to the client. Microsoft® Internet Explorer supports several predefined protocols, including http and ftp.
