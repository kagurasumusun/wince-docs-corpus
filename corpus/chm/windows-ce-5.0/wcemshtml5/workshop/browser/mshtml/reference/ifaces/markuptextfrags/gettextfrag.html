IMarkupTextFrags::GetTextFrag Method

Retrieves the text fragment for a specified index and positions a markup pointer at the fragment's location.

Syntax

HRESULT GetTextFrag(      
    long iFrag,
    BSTR *pbstrFrag,
    IMarkupPointer *pPointerFrag
);

Parameters

iFrag
[in] Long integer that specifies the index of the text fragment to retrieve.
pbstrFrag
[out] Pointer to a variable of type BSTR that receives the text of the text fragment.
pPointerFrag
[in] Pointer to an IMarkupPointer interface that specifies the location of the text fragment in the document.

Return Value

Returns S_OK if successful, or an error value otherwise.
