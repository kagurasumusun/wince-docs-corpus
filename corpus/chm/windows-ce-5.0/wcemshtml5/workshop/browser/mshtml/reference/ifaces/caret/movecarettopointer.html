IHTMLCaret::MoveCaretToPointer Method

Moves the insertion point position to that of a display pointer.

Syntax

HRESULT MoveCaretToPointer(      
    IDisplayPointer *pDispPointer,
    BOOL fScrollIntoView,
    CARET_DIRECTION eDir
);

Parameters

pDispPointer
[in] Pointer to an IDisplayPointer interface that specifies the display pointer to which to move the insertion point.
fScrollIntoView
[in] BOOL value that specifies TRUE if the insertion point should scroll into view during the move, or FALSE otherwise.
eDir
[in] CARET_DIRECTION enumeration value that indicates which direction should be the insertion point's forward direction after it's placed.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

In documents that have mixed languages and text flow (left to right and right to left) on the same line, the direction of insertion point movement can be ambiguous. The eDir parameter resolves this ambiguity.

For example, in the line "This is CIBARA[c] text." that contains an insertion point at [c] and where CIBARA is in Arabic (which reads from right to left), the insertion point's position might be interpreted in two ways. It could be at the beginning of CIBARA (in which case the insertion point's forward direction is to the left) or at end of CIBARA (in which case the forward direction is to the right).
