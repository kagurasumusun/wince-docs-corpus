IMarkupServices::GetNameForTagID Method

Retrieves the name of the element, given its tag identifier (ID).

Syntax

HRESULT GetNameForTagID(      
    ELEMENT_TAG_ID tagId,
    BSTR *pbstrName
);

Parameters

tagId
[in] Value of type ELEMENT_TAG_ID that specifies the type of element.
pbstrName
[out] Pointer to a variable of type BSTR that receives the name of the element.

Return Value

Returns S_OK if successful, or an error value otherwise.
