IHTMLBodyElement::bgProperties Property

Sets or retrieves the properties of the background picture.

Syntax

HRESULT IHTMLBodyElement::get_bgProperties(BSTR *p);
HRESULT IHTMLBodyElement::put_bgProperties(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

empty stringDefault. Background can scroll.
fixedBackground is fixed and cannot scroll.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The property, for example, specifies whether the picture is a fixed watermark or scrolls with the page. This attribute/property is supported only by Microsoft® Internet Explorer.
