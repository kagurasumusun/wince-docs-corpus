IHTMLStyle::textDecorationNone Property

Sets or retrieves the Boolean value indicating whether the IHTMLStyle::textDecoration property for the object has been set to none.

Syntax

HRESULT IHTMLStyle::get_textDecorationNone(VARIANT_BOOL *p);
HRESULT IHTMLStyle::put_textDecorationNone(VARIANT_BOOL v);

Parameters

p
Pointer to a variable of type VARIANT_BOOL that receives one of the values listed in Possible Values.
v
VARIANT_BOOL that specifies one of the values listed in Possible Values.

Possible Values

VARIANT_TRUEProperty is set to none.
VARIANT_FALSEProperty is not set to none.

Return Value

Returns S_OK if successful, or an error value otherwise.
