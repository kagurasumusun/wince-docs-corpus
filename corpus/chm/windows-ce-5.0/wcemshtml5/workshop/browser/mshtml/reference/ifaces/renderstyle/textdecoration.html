IHTMLRenderStyle::textDecoration Property

Sets or retrieves whether the text in the object renders with a blink, line-through, overline, or underline decoration.

Syntax

HRESULT IHTMLRenderStyle::get_textDecoration(BSTR *p);
HRESULT IHTMLRenderStyle::put_textDecoration(BSTR v);

Parameters

p
Pointer to a variable of type BSTR that receives one of the values listed in Possible Values.
v
BSTR that specifies one of the values listed in Possible Values.

Possible Values

autoDefault. Style of the decoration is determined by the browser; for example, by default or inheritance.
noneText has no decoration.
underlineText has a line drawn below it.
overlineText has a line drawn over it.
line-throughText has a line drawn through it.
blinkNot currently implemented.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If the object is empty or does not contain text, this property has no effect.

See Also

IHTMLRenderStyle::textDecorationColor, IHTMLRenderStyle::textLineThroughStyle, IHTMLRenderStyle::textUnderlineStyle
