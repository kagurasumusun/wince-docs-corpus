IMarkupServices2::SaveSegmentsToClipboard Method

Saves the segments contained in the segment list to the Clipboard.

Syntax

HRESULT SaveSegmentsToClipboard(      
    ISegmentList *pSegmentList,
    DWORD dwFlags
);

Parameters

pSegmentList
[in] Pointer to an ISegmentList interface that specifies the list of segments to save to the Clipboard.
dwFlags
[in] DWORD that specifies an SAVE_SEGMENTS_FLAGS enumeration value to indicate save options.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Segments are saved to the Clipboard in CF_HTML format, ASCII text, Unicode text, and Rich Text Format (RTF).
