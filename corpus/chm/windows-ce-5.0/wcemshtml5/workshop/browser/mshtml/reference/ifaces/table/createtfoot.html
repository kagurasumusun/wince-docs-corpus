IHTMLTable::createTFoot Method

Creates an empty tFoot element in the table.

Syntax

HRESULT createTFoot(      
    IDispatch **foot
);

Parameters

foot
[out, retval] Address of a pointer to an IDispatch interface that receives the tFoot element object if successful, or null otherwise.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If a tFoot already exists for the table, the IHTMLTable::createTFoot method returns the existing element. Otherwise, it returns a pointer to the element created.
