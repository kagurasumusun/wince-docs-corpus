IHTMLDocument3::createTextNode Method

Creates a text string from the specified value.

Syntax

HRESULT createTextNode(      
    BSTR text,
    IHTMLDOMNode **newTextNode
);

Parameters

text
[in] BSTR that specifies the IHTMLDOMNode::nodeValue property of the text node.
newTextNode
[out, retval] Address of a pointer to an IHTMLDOMNode interface that receives the created TextNode object.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

While this method always returns S_OK, check the returned newTextNode value. If newTextNode is NULL, the method failed to create a new text node.
