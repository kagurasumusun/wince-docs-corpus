IHTMLAttributeCollection2::getNamedItem Method

Retrieves an IHTMLDOMAttribute specified with the IHTMLDOMAttribute2::name property using the IHTMLAttributeCollection interface.

Syntax

HRESULT getNamedItem(      
    BSTR bstrName,
    IHTMLDOMAttribute **newretNode
);

Parameters

bstrName
[in] BSTR that specifies the name of the IHTMLDOMAttribute to retrieve.
newretNode
[out, retval] Address of a pointer to a IHTMLDOMAttribute with the specified name.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

If the IHTMLDOMAttribute applies to an element but is not specified, this method returns the IHTMLDOMAttribute with the specified name set to an empty string.

If the IHTMLDOMAttribute does not apply to the element and is not specified, then an error is returned.

If the IHTMLDOMAttribute does not apply to the element and is specified, then the IHTMLDOMAttribute with the specified name is returned.
