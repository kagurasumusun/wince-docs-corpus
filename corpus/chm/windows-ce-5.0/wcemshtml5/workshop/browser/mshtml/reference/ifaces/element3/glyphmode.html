IHTMLElement3::glyphMode Property

Retrieves whether the glyph represents the object and whether it represents the start tag, the end tag, or both.

Syntax

HRESULT IHTMLElement3::get_glyphMode(LONG *p);

Parameters

p
Pointer to a variable of type LONG that receives one of the values listed in Possible Values.

Possible Values

NoneGlyph does not represent the object.
BeginGlyph represents the start tag.
EndGlyph represents the end tag.
BothGlyph represents both the start and end tags.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

Glyphs are images or icons that are used to represent HTML tags in a document while in edit mode.
