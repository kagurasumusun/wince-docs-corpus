IHTMLElement4::setAttributeNode Method

Sets an IHTMLDOMAttribute2 interface node as part of the object.

Syntax

HRESULT setAttributeNode(      
    IHTMLDOMAttribute *pattr,
    IHTMLDOMAttribute **ppretAttribute
);

Parameters

pattr
[in] Pointer to the IHTMLDOMAttribute2 interface to be assigned.
ppretAttribute
[out, retval] Address of a pointer variable that receives the assigned IHTMLDOMAttribute2 pointer.

Return Value

Returns S_OK if successful. Returns WRONG_DOCUMENT_ERR if pattr was created from a different document than the calling element's parent document. Returns NO_MODIFICATION_ALLOWED_ERR if a read only attribute already exists with the same IHTMLDOMAttribute2::name as pattr. Returns INUSE_ATTRIBUTE_ERR if pattr is already assigned to an element object.
