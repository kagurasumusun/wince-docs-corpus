IHTMLPopup::show Method

Displays the pop-up window on the screen.

Syntax

HRESULT show(      
    long x,
    long y,
    long w,
    long h,
    VARIANT *pElement
);

Parameters

x
[in] Long integer that specifies the x-coordinate of the pop-up window, in pixels.
y
[in] Long integer that specifies the y-coordinate of the pop-up window, in pixels.
w
[in] Long integer that specifies the width of the pop-up window, in pixels.
h
[in] Long integer that specifies the height of the pop-up window, in pixels.
pElement
[in] Pointer to a VARIANT that specifies the element to which the x,y coordinates are relative. If none is given, the x,y coordinates are relative to the desktop, where (0,0) is the upper left corner.

Return Value

Returns S_OK if successful, or an error value otherwise.

Example

The following example shows how to use the IHTMLPopup::show method to create and display a pop-up window.

<html>
<head>
<SCRIPT LANGUAGE="JScript">
var oPopup = window.createPopup();
function window_onload() {
    var oPopupBody = oPopup.document.body;
	oPopupBody.style.backgroundColor = "lightyellow";
	oPopupBody.style.border = "solid black 1px";    
    oPopupBody.innerHTML = "Display some <B>HTML</B> here.";
    oPopup.show(100, 100, 200, 50, document.body);}
</SCRIPT>
</head>
<body onload="window_onload();">
</body>
</html>
