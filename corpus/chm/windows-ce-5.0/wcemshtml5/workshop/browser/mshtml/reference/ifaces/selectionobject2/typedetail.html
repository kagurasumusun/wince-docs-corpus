IHTMLSelectionObject2::typeDetail Property

Retrieves the name of the selection type.

Syntax

HRESULT IHTMLSelectionObject2::get_typeDetail(BSTR *p);

Parameters

p
Pointer to a variable of type BSTR that receives the name of the selection type.

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

The default implementation of this property returns a value of undefined.

Host applications can provide a custom selection mechanism and can provide a value for this property that indicates the selection type.

MSHTML requests the selection type from the host application by calling ISelectionServicesListener::GetTypeDetail.
