IHTMLChangeSink::Notify Method

Called by MSHTML when a change occurs in the contents of the markup container with which it is associated.

Syntax

HRESULT Notify(VOID);

Return Value

Returns S_OK if successful, or an error value otherwise.

Remarks

A call to this method signals that there is a new change record available in the change log for a markup container. Implement this method to provide whatever processing is necessary for your application when changes occur in a markup container.

See Also
