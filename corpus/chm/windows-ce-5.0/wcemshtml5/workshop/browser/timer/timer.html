Timer API Reference

The Timer application programming interface (API) provides essential timer services for Microsoft® ActiveX® Controls, supports external reference clocks, and enables synchronization between controls and scripts.

Interfaces

ITimer

This interface implements timer functions.

ITimerService

This interface creates, retrieves, and sets timer objects.

ITimerSink

This interface implements a method that is called by the timer service for a scheduled event.

Methods

ITimer::Advise

Schedules single or periodic notifications.

ITimerService::CreateTimer

Creates a timer object.

ITimer::Freeze

Halts the timer temporarily.

ITimerService::GetNamedTimer

Retrieves the named timer.

ITimer::GetTime

Retrieves the current time of the timer.

ITimerSink::OnTimer

Called by the timer service for a scheduled event.

ITimerService::SetNamedTimerReference

Replaces the named timer's reference timer with a new reference timer.

ITimer::Unadvise

Cancels an event request.
