ITimerService::CreateTimer Method

Creates a timer object.

Syntax

HRESULT CreateTimer(      
    ITimer *pReferenceTimer,
    ITimer **ppNewTimer
);

Parameters

pReferenceTimer
[in] Address of the reference timer for the new timer.
ppNewTimer
[out] Address of the pointer to the new timer object.

Return Value

Returns one of the following values: 

S_OKThe method was called successfully.
E_POINTERA pointer is invalid.
E_OUTOFMEMORYThe system is out of memory.

Remarks

If pReferenceTimer is NULL, the base or default reference timer is used to create the new timer.
