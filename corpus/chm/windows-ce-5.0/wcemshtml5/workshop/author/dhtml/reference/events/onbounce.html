onbounce Event

Fires when the behavior property of the marquee object is set to "alternate" and the contents of the marquee reach one side of the window.

Syntax

Inline HTML<MARQUEE onbounce = "handler" ... > All platforms
Event propertyMARQUEE.onbounce = handlerJScript only
MARQUEE.onbounce = GetRef("handler")Visual Basic Scripting Edition (VBScript) 5.0 or later only
Named script <SCRIPT FOR = MARQUEE EVENT = onbounce> Internet Explorer only

Event Information

BubblesNo
CancelsYes
To invoke Cause the marquee contents to loop.
Default action The marquee contents begin to scroll in the opposite direction.

Event Object Properties

Although event handlers in the DHTML Object Model do not receive parameters directly, a handler can query an event object for data.

Example

This example shows how to display an alert each time the onbounce event occurs.

<BODY>
<MARQUEE ID=mqBounce BEHAVIOR=alternate
    onbounce="alert('onbounce fired')" LOOP=3 
		WIDTH=200>Marquee text
</MARQUEE>
</BODY>
