href Property

Sets or retrieves the URL of the linked style sheet.

Syntax

styleSheet.href [ = sURL ]

Possible Values

sURLString that specifies or receives the URL.

The property is read/write. The property has no default value.

Expressions can be used in place of the preceding value(s), as of Microsoft® Internet Explorer 5. For more information, see About Dynamic Properties.

Remarks

The property returns the URL if the style sheet is a link. If the style sheet is a style, the property returns null.

Standards Information

This property is defined in World Wide Web Consortium (W3C) Document Object Model (DOM) Level 1 .

Applies To

styleSheet
