DATA Attribute | data Property

Sets or retrieves the URL that references the data of the object.

What's New for Microsoft® Internet Explorer 6

This property now applies to the comment object.

Syntax

HTML<ELEMENT DATA = sURL... >
Scriptingobject.data(v) [ = sURL ]

Possible Values

sURLString that specifies or receives the URL of the data.

The property is read/write. The property has no default value.

Expressions can be used in place of the preceding value(s), as of Microsoft® Internet Explorer 5. For more information, see About Dynamic Properties.

Standards Information

This property is defined in HTML 4.0  and is defined in World Wide Web Consortium (W3C) Document Object Model (DOM) Level 1 .

Applies To

COMMENT, OBJECT
