CH Attribute | ch Property

Sets or retrieves a value that you can use to implement your own ch functionality for the object.

Syntax

HTML<ELEMENT CH = sChar... >
Scriptingobject.ch(v) [ = sChar ]

Possible Values

sCharString that specifies or receives the value of the ch property.

The property is read/write. The property has no default value.

Expressions can be used in place of the preceding value(s), as of Microsoft® Internet Explorer 5. For more information, see About Dynamic Properties.

Remarks

The functionality specified by the HTML 4.0 standard for this property is not implemented.

There is no functionality implemented for this property unless defined by the author.

Standards Information

This property is defined in HTML 4.0  and is defined in World Wide Web Consortium (W3C) Document Object Model (DOM) Level 1 .

Applies To

TR, TD, TH, COL, TBODY, THEAD, TFOOT
