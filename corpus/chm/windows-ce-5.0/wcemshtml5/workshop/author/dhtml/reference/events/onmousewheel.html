onmousewheel Event

Fires when the wheel button is rotated.

Syntax

Inline HTML<ELEMENT onmousewheel = "handler" ... > All platforms
Event propertyobject.onmousewheel = handlerJScript only
object.onmousewheel = GetRef("handler")Visual Basic Scripting Edition (VBScript) 5.0 or later only
Named script <SCRIPT FOR = object EVENT = onmousewheel> Internet Explorer only

Event Information

BubblesYes
CancelsYes
To invoke Rotate the wheel button.
Default action Scrolls the page up or down.

Event Object Properties

Although event handlers in the DHTML Object Model do not receive parameters directly, a handler can query an event object for data.

Remarks

The onmousewheel event is the only event that exposes the wheelDelta property. This property indicates the distance that the wheel button has rotated, expressed in multiples of 120. A positive value indicates that the wheel button has rotated away from the user. A negative value indicates that the wheel button has rotated toward the user. See the example below.

Example

The following example shows how to use the onmousewheel event and the wheelDelta parameter to expand and contract a picture in response to the wheel button being moved.

<HTML>
<HEAD>
<SCRIPT>
var count = 10;
function Picture()
{
	count = Counting(count);
	Resize(count);
	return false;
}
function Counting(count){   
    if (event.wheelDelta >= 120)
        count++;
    else if (event.wheelDelta <= -120)
        count--;   
    return count; 
}
function Resize(count){    
    oImage.style.zoom = count + '0%';    
}
</SCRIPT>
</HEAD>
<BODY>
<img id="oImage" src="Sample.jpg" onmousewheel="Picture()" width="283"
height="212" >
</BODY>
</HTML>
