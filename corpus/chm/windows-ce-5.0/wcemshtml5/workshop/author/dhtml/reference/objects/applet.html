Remarks

To use executable content specified by the applet element, a user's computer must have the Microsoft virtual machine (Microsoft VM) installed. See Microsoft Virtual Machine Overview  for more information.

This element is available in HTML as of Internet Explorer 3.0, and in script as of Internet Explorer 4.0.

This element is an inline element.

This element requires a closing tag.

Standards Information

This object is deprecated in HTML  and is defined in World Wide Web Consortium (W3C) Document Object Model (DOM) Level 1 .
