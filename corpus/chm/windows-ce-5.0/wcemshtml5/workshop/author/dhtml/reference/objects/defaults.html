defaults Object

Programmatically sets default properties on an element behavior.

The following table lists the members exposed by the defaults object. Click a tab on the left to choose the type of member you want to view.

Remarks

The PUBLIC:DEFAULTS element is the declarative form of the defaults object.

This object is available in script as of Internet Explorer 5.5.

Standards Information

There is no public standard that applies to this object.
