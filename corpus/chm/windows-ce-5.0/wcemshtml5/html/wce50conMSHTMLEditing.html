MSHTML Editing

In addition to its HTML rendering and parsing capabilities, MSHTML exposes a minimal set of HTML editing functionalities. Applications hosting MSHTML can use these editing functionalities to enable editing of HTML content in a manner similar to text editing in word processors.

MSHTML editing in Windows CE provides the following functionality to the user:

  • Standard editing functionality such as caret positioning, keyboard navigation, drag-and-drop, and content selection.
  • Copy, cut, delete, and paste operations.
  • Multi-level undo and redo.

Hosting applications can exploit the MSHTML Editor as a means to generate proper and consistent HTML and XML code. The MSHTML Editor generates standard HTML, allowing third-party applications to quickly adapt the latest Microsoft browser technology.
