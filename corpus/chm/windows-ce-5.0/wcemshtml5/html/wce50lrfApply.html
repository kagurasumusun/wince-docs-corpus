Platform Builder for Microsoft Windows CE 5.0  

apply (Internet Explorer)

This method captures the initial display of an object's content for a transition.

object.filters.item("DXImageTransform.Microsoft.<Filter Name>").stop();

Return Values

None.

Remarks

Applies to Fade, Pixelate, RandomBars, and RandomDissolve transitions.
