CEL_SYSTEM_PAGE

This structure identifies that a page fault occurred in the system.

typedef __CEL_SYSTEM_PAGE {
  DWORD dwAddress;
  DWORD fReadWrite:1;
  DWORD dwReserved:31;
} CEL_SYSTEM_PAGE, *PCEL_SYSTEM_PAGE;

Members

dwAddress
The address where the page fault occurred.
fReadWrite
The low bit of the DWORD is used to indicate whether the page is writeable. If set to 0, this is a read-only page; otherwise, it is a writeable page.
dwReserved
The remaining 31 bits are reserved for future use.

Remarks

The fReadWrite and dwReserved parameters are different fields of the same DWORD.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Celog.h.
