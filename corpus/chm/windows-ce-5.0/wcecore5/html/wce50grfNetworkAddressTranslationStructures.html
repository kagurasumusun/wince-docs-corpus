Network Address Translation Structures

The following table shows the network address translation structures.

Programming element Description
IP_NAT_DIRECTION This enumeration defines values that specify whether editor is interested in inbound or outbound sessions.
IP_NAT_REGISTER_EDITOR This structure allows the editor to register itself with the network address translation (NAT), and to obtain the entry points of helper functions provided by the NAT.
IP_NAT_SESSION_MAPPING_STATISTICS This structure holds statistics for a single-session mapping.
IPRcvBuf This structure represents one buffer in a chain of buffers that corresponds to an IP packet.
