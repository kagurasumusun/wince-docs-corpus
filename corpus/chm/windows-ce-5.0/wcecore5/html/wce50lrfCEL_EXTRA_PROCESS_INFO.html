CEL_EXTRA_PROCESS_INFO

This structure stores additional information about a process.

typedef struct __CEL_EXTRA_PROCESS_INFO {
  HANDLE hProcess;
  DWORD dwVMLen;
  DWORD dwOID;
  WCHAR szFullPath[0];
} CEL_EXTRA_PROCESS_INFO, *PCEL_EXTRA_PROCESS_INFO;

Members

hProcess
Handle to the process.
dwVMLen
Lenth of the executable code, which starts at the dwVMBase address from the CEL_PROCESS_CREATE structure.
dwOID
A nonzero value for a valid file OID. Zero value, if the file is not in the RAM or ROM file system.
szFullPath
Full path to the executable if the file is not in the RAM/ROM file system.

The length is derived from the entry length.

Remarks

If the OID is nonzero, the full path will not be provided. Use the OID and the CREATE_SYSTEMGUID macro to call CeOidGetInfoEx2 to obtain the full path and other information about the file.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Celog.h.
