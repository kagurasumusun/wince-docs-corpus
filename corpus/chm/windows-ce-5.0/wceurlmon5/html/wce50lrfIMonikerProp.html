IMonikerProp

This interface provides access to the properties of a moniker.

Method Description
PutProperty Sets the value of a property on a moniker.

Remarks

This interface is implemented by persistent monikers, such as a MIME handler, to retrieve properties about the moniker being handled.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
