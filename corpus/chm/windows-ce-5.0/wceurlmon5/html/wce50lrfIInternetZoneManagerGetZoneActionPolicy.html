IInternetZoneManager::GetZoneActionPolicy

This method retrieves the policy associated with the specified URL action. 

HRESULT GetZoneActionPolicy( 
  DWORD dwZone,
  DWORD dwAction,
  BYTE* pPolicy,
  DWORD cbPolicy,
  URLZONEREG urlZoneReg
);

Parameters

dwZone
[in] Unsigned long integer value of the zone.
dwAction
[in] Unsigned long integer value of the action.
pPolicy
[out] Address of the buffer to store the policy information.
cbPolicy
[in] Unsigned long integer value that specifies the size of the buffer.
urlZoneReg
[in] URLZONEREG value that specifies the section in the registry to search.

Return Values

Returns S_OK if successful or an error value otherwise.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
