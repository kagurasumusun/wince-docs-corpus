URL Moniker Services Samples

The samples included with Microsoft® Windows® CE provide a starting point for adding functionality to your browser.

Note   These samples have not been tested and are not intended for production use.

The implementation file, Zones.cpp implements the Security tab of the Internet Options dialog box. The source code is located in the %WINCEROOT%\PUBLIC\IE\OAK\INETCPL directory. For more information about Security Zones, see URL Security Zones.
