URL Moniker Services Migration

The following list shows migration considerations for URL Moniker Services:

  • The security zone, My Computer, has been deprecated.
  • The security zone for temporary Internet files has been modified. Cookie files are stored in the restricted zone and cache files are stored in the Internet zone.

For general migration information about Windows CE, see Migrating from an Earlier Version of Windows CE.
