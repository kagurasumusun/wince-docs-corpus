Internet Security Manager

The Internet Security Manager is an object that manages security settings.

Creation/Access Functions

CoCreateInstance

Call CoCreateInstance with the CLSID parameter set to CLSID_InternetSecurityManager.

Interfaces Implemented

IInternetSecurityManager

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.dll.
