SnmpMibEntry Array

This is the primary MIB structure definition array. It defines the SNMP types for every variable that is used in the MIB of the extension agent, as well as the relative position for the buffer variable in the buffer structure that is generated by the extension-agent framework. You should lay out the SnmpMibEntry table in exactly the same order as the ASN.1 MIB definitions for the extension agent. All of the entries in this table are generated by macro statements. There are three basic entity types that are generated by the four types of macros:

  • Variable declaration macros
  • Table declarations macro
  • Table entry declaration macro
  • MIB-entry array end macro

The following code example shows the definition for the MibEntry array.

SnmpMibEntry mib_snmpTest[] = 
{
  MIB_Integer(snmpErrNumber),
  MIB_TABLE_ROOT(snmpErrTable),
  MIB_TABLE_ENTRY(snmpErrEntry),
  MIB_Integer(snmpErrCode),
  MIB_Integer_RW(snmpTriggerTrap),
  MIB_END()
};

gb_X

The following code example shows how to use the variable declaration macros in a sample MIB.

typedef struct
{
  AsnAny  snmpErrNumber;
  AsnAny  snmpErrCode;
  AsnAny  snmpTriggerTrap;
} SNMPTEST_VARS;

UINT fnSnmpErrNumber (
  UINT actionId,
  AsnAny *objectArray,
  UINT *errorIndex
);

UINT fnSnmpErrCode (
  UINT actionId,
  AsnAny *objectArray,
  UINT *errorIndex
);

UINT fnSnmpTriggerTrap (
  UINT actionId,
  AsnAny *objectArray,
  UINT *errorIndex
);

#define gf_snmpErrNumber          fnSnmpErrNumber
#define gb_snmpErrNumber          SNMPTEST_VARS
#define gf_snmpErrCode            fnSnmpErrCode
#define gb_snmpErrCode            SNMPTEST_VARS
#define gf_snmpTriggerTrap        fnSnmpTriggerTrap
#define gb_snmpTriggerTrap        SNMPTEST_VARS
#define sf_snmpTriggerTrap        fnSnmpTriggerTrap
#define sb_snmpTriggerTrap        SNMPTEST_VARS

// The following variable definitions that are defined in Mibentry.c also are used:
static UINT ids_snmpErrNumber[]   = {1,0};
static UINT ids_snmpErrCode[]     = {2,1,1};
static UINT ids_snmpTriggerTrap[] = {3,0};

Table Declaration Macro

The table declaration macro is as follows.

MIB_TABLE_ROOT( X )

This macro defines the beginning of a MIB table. It requires that the OID of the table be defined prior to its occurrence in the .C file. For example:

ids_X - define the OID of the table.

You also need to define an array element of type SnmpMibTable. The name of the table is generated from the base name that is passed to the MIB_TABLE_ROOT macro. For each MIB_TABLE_ROOT macro that is defined in the SnmpMibEntry array, there must be a corresponding MIB_TABLE macro that is defined in a SnmpMibTable array.

Entry Declaration Macro

The entry declaration macro is as follows.

MIB_TABLE_ENTRY(X)

This macro defines the beginning of the table entry definition, corresponding to the ASN.1 x ::= SEQUENCE { ...} statement. It also requires that an OID be defined for the entry.

MIB-Entry Array End Macro

The MIB-Entry Array End macro is as follows.

MIB_END()

This macro is mandatory and must be the final entry in an SnmpMibEntry table. It terminates the table.
