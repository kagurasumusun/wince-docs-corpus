Host Resources Installed Software Group

The Host Resources Installed Software group contains information on the software that is installed on the host computer. The following table shows the variables of the Host Resources Installed Software Group and their properties.

Name Type Access Description
hrSWInstalledLastChange TimeTicks R/O Last time that the hrSWInstalledTable entry was added or deleted
hrSWInstalledLastUpdateTime TimeTicks R/O Last time that the hrSWInstalledTable entry was updated completely
hrSWInstalledTable     Table of software that is installed on the host
hrSWInstalledIndex Integer R/O Table index of software that is installed
