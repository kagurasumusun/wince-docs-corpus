SnmpUtilVarBindFree

This function frees the memory allocated for an SnmpVarBind structure.

VOID SnmpUtilVarBindFree(
  SnmpVarBind* pVb 
);

Parameters

pVb
[in, out] Pointer to an SnmpVarBind structure whose memory should be freed.

Return Values

This function has no return values.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Snmp.h.
Link Library: Snmpapi.lib.
