Network Bridging Object Identifiers

The Network Driver Interface Specification (NDIS) defines a list of object identifiers that can be used to set or obtain the operational characteristics of NIC drivers. Because the Windows CE–based MAC bridge appears as a single NIC to upper-layer protocols, it must respond appropriately to each query for a specific characteristic.
