TUI IP Phone Functionality

The TUI supports a wide range of standard phone functionality as well as enhanced features.

This topic summarizes TUI functionality from a user perspective.

For more information about using the TUI application, see the template IP phone Quick Start guide.

For more information about template IP phone user documentation, including the location of the documentation, see Creating End User Documentation for an IP Phone.

For more information about how the TUI application operates, see TUI Architecture and Examining the TUI Implementation.

The following phone functionality is enabled in the TUI:

  • Dial and answer calls
  • Caller ID
  • DTMF and progress tones
  • Call holding: simple hold, hold and call, hold multiple calls
  • Call forwarding: automatic forwarding, forward on no answer, forward a ringing call
  • Call transfer
  • Exchange integration: contacts, global address list, free/busy information
  • Local call conferencing
  • Call blocking
  • Call waiting
  • Incoming call screening
  • Custom ring tones
  • Missed call notifications
  • Persistent call logging storage for incoming, outgoing, and missed calls
  • Speed dial
  • Volume change and microphone mute
  • Lock/unlock functionality with PIN codes and PC integration
  • Presence integration
  • Voice mail integration
