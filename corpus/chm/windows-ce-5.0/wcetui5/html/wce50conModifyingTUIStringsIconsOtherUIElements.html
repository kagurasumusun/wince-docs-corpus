Modifying TUI Strings, Icons, and Other UI Elements

Although you can modify the TUI application any way you want by changing the source, there are a number of ways you can change how the application appears without making significant source code modifications.

The following table shows the files you can modify to change how the TUI appears. These files are in the %_WINCEROOT%\Public\VoIP\OAK\Phone\TUI directory.

Subdirectory and file UI elements controlled
App\Voipui.rc Fonts used by different parts of the UI.

Strings for user interface elements and context-sensitive help text.

File path pointers to bitmap images (the pointer can be modified or the referenced image can be changed).

App\Res\* Bitmap images referenced by Voipui.rc.
Inc\MetricsAndColors.h Text, rectangle, and line colors.

Dimensions of user interface elements.
