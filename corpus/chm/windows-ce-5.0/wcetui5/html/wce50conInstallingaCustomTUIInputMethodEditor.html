Installing a Custom TUI Input Method Editor

The TUI sends keyboard messages to the edit controls, which in turn use the installed IME to actually output the desired text.

By default, the TUI uses the Phone IME Catalog item to provide "triple-tap" functionality. For information about how the TUI uses the Phone IME, see Using the Phone IME from the TUI.

You can replace by the Phone IME with a different IME by connecting your new IME to the Windows CE Input Method Manager (IMM). For more information about using the IMM, see Input Method Manager (IMM).

If your custom IME uses CE Shell support, you can disable the existing popup menus by modifying code in the Desktop.cpp file in %_WINCEROOT%\Public\VoIP\Oak\Phone\TUI\Controls.
