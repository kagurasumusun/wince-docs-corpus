Internet Explorer TV-Style Navigation Interfaces

The following table shows the Internet Explorer television-style navigation interfaces with a description of the purpose of each.

Programming element Description
IOleControlNavigation2 This interface provides methods that support television-style (five-key) navigation in a browser-based application.
IOleControlNavigation2AdviseSink The browser implements this interface to allow the navigation control to notify the browser of changes in the control that relate to navigation.
