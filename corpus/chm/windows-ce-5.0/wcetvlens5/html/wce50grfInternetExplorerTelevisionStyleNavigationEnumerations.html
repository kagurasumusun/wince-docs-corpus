Internet Explorer TV-Style Navigation Enumerations

The following table shows the Internet Explorer television-style navigation enumerations with a description of the purpose of each.

Programming element Description
NVFOCUS_DIRECTION This enumeration contains values that specify the direction in which to shift the focus inside the rectangle, or the direction in which to exit the rectangle.
