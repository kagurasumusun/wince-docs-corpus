ISpEventSink::GetEventInterest

This method gets the event interest for the voice.

HRESULT GetEventInterest(
  ULONGLONG* pullEventInterest
);

Parameters

pullEventInterest
[out] Flags of type SPEVENTENUM defining the event interest.

Return Values

The following table shows the possible return values.

Value Description
S_OK Function completed successfully.
E_INVALIDARG pEventArray is bad or invalid
FAILED(hr) Appropriate error message.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapi.h, Sapi.idl.
Link Library: Sapilib.lib.
