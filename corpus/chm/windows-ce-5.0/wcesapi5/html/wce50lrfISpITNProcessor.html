ISpITNProcessor

This interface performs inverse text normalization (ITN) for an ITN grammar. It is implemented by SAPI.

Methods

The following table lists the methods for the ISpITNProcessor interface.

Method Description
ITNPhrase Parses an inverse text normalization phrase.
LoadITNGrammar Loads an inverse text normalization grammar.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapiddk.h, Sapiddk.idl.
Link Library: Sapilib.lib.
