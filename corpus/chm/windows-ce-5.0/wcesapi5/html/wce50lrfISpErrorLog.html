ISpErrorLog

This interface prepares a log file of compilation error messages. An object implementing the interface can be supplied to ISpGrammarCompiler::CompileStream.

Methods

The following table lists the methods for the ISpErrorLog interface.

Method Description
AddError Writes a compilation error message to the log file.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapiddk.h, Sapiddk.idl.
Link Library: Sapilib.lib.
