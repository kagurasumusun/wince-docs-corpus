ISpSREngineSite::ParseFromTransitions

This method parses a phrase from a list of CFG transitions. The resulting phrase can be used to send CFG results back to SAPI.

HRESULT ParseFromTransitions(
  const SPPARSEINFO* pParseInfo,
  ISpPhraseBuilder** ppPhrase
);

Parameters

pParseInfo
[in] Pointer to an SPPARSEINFO structure containing transition information.
ppPhrase
[out] Address of a pointer to an ISpPhraseBuilder interface representing the phrase containing CFG results.

Return Values

The following table shows the possible return values.

Value Description
S_OK Function completed successfully.
FAILED(hr) Appropriate error message.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapiddk.h, Sapiddk.idl.
Link Library: Sapilib.lib.
