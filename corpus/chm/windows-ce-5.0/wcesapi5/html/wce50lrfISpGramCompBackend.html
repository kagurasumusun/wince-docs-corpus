ISpGramCompBackend

This interface represents the grammar compiler back end that works with a binary grammar. The interface inherits from the ISpGrammarBuilder interface.

Methods

The following table lists the methods for the ISpGramCompBackend interface.

Method Description
InitFromBinaryGrammar Initializes a grammar from binary data.
SetSaveObjects Sets the storage location of the binary grammar.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapiddk.h, Sapiddk.idl.
Link Library: Sapilib.lib.
