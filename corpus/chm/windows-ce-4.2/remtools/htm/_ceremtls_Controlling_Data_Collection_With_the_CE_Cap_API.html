Collecting Data with the Remote Call Profiler API

By default, the Remote Call Profiler logger begins writing data to a .icp file when an instrumented module starts, and continues logging until the last instrumented process unloads. This section describes how you can use Remote Call Profiler API Functions to start and stop data collection during a profiling run.

To collect data with the Remote Call Profiler API

  1. In the [ProcessName] section of the Icecap.ini file, set Profile=ON to begin profiling when the application starts.

    - or -

    Set Profile=OFF to control the start of profiling with API functions.

  2. Add Remote Call Profiler API prototypes and constants to the files for your application.
  3. Add a #include <cecap.h> statement to those files.
