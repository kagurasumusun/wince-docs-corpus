Output Window

The Remote Call Profiler Output window displays messages, warnings, and errors from the .icp file and the Remote Call Profiler viewer.

In the event of an error, Remote Call Profiler displays an error message in a dialog box. To display information about an error message, type the numeric code associated with the message in the Help index. For example, for the error message topic Error 2001: File Open Failed, type 2001 in the Type in the keyword to find box. To view the entire list of error messages associated with the Output Window, from the Help View menu, choose Locate Topic in Contents.
