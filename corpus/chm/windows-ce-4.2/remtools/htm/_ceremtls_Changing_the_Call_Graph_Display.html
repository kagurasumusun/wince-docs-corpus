Filtering Data in the Call Graph View

  1. In the Call Graph pane, choose Sort By Application to sort nodes of the tree by the total application inclusive time or counter value of each function.

    - or -

    In the Call Graph pane, choose Sort By Elapsed to sort nodes by elapsed inclusive time or counter value.

  2. Choose Counter: Time to display CPU cycles.

    - or -

    Choose the name of a user-defined counter.

  3. Select the Show Only Top check box to display a limited number of functions.

    - or -

    Clear the Show Only Top check box to display all functions.

  4. In the Functions box, type the maximum number of functions to display.
  5. In the Hide Functions Below box, type a percentage to display only those functions that consumed more than the specified percentage of the total time or counter value.
  6. Choose the ! button.
