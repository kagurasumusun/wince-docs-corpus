ISubscriber::Notify

This method notifies a subscriber of events. The Publish/Subscribe Manager calls this method. For more information about the Publish/Subscribe Manager, see Publisher Characteristics.

HRESULT Notify(
  DWORD dwEventCode,
  DWORD dwFlags 
);

Parameters

dwEventCode
[in] Code for the event.
dwFlags
[in] Flags associated with the event.

Return Values

The following table shows the return values for this method.

Value Description
S_OK The call was successfully completed.
E_FAIL Unable to complete the call.

Remarks

The publisher may call this method to notify subscribers of publisher-defined events.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: CEPubSub.h (for desktop), CEPubSubPS.h (for device), CePubSub.idl.
