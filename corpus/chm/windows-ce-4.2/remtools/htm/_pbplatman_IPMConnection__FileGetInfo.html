IPMConnection::FileGetInfo

This method obtains the attributes of a file.

HRESULT FileGetInfo(
  BSTR bstrRemotePath,
  long* pdwFileAttributes,
  long* pdwFileSize,
  VARIANT* pvtCreationTime 
);

Parameters

bstrRemotePath
[in] Path and name of the file.
pdwFileAttributes
[out] Attributes of the file.
pdwFileSize
[out] Size of the file.
pvtCreationTime
[out] Time when the file was created.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Connection.h, Cemgr.idl.
