Introduction to Data Collection Control

Remote Call Profiler automatically collects profiling information when you run an instrumented application. To control the amount of data collected, you can use the Remote Call Profiler Collection Control window to set the initial profiling state and then use the Remote Call Profiler Collection Control window or Remote Call Profiler data collection control functions to turn profiling on and off.

With the Remote Call Profiler Collection Control window, you can interactively control data collection during a profiling run, and you can launch an application on the target device. You can also start or stop the collection of data from the target device.
