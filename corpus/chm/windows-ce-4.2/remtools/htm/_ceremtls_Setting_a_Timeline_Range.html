Setting a Range for the Timeline

When you set a range for a timeline, the range of data displayed in a view window updates to match selected range in the Timeline window. For more information about view windows, see Remote Call Profiler View Windows.

To set a range for the timeline

  1. On the timeline, select a location for the beginning of the range.
  2. From the Action menu, choose Set Begin Range.
  3. Select a location for the end of the range.
  4. From the Action menu, choose Set End Range.
