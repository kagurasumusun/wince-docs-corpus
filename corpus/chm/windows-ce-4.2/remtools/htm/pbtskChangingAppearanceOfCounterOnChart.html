Changing the Appearance of a Counter on a Chart

  1. In the legend, select a counter.
  2. From the Edit menu, choose Edit Chart Line.
  3. In the Color area, select a color for the line.
  4. In the Scale area, select a vertical scale for plotting the line.
  5. In the Width area, select the width of the line.
  6. In the Style area, select a solid line or a dashed-line pattern.
  7. Choose OK when you have finished making selections.

    From the File menu, choose Save Chart Settings if you want to update your chart selections in a settings file.
