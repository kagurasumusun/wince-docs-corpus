IPMOS::MajorVersion

This method obtains or sets the major version of the OS object.

To obtain the major version of the OS object use the following syntax.

HRESULT MajorVersion(
  int* pwMajor 
);

To set the major version of the OS object use the following syntax.

HRESULT MajorVersion(
  int wMajor 
);

Parameters

pwMajor
[out] Pointer to the major version of the OS object.
wMajor
[in] Major version of the OS object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Os.h, Cemgr.idl.
