Adding an Object, Counter, and Instance to an Alert Log

  1. From the Edit menu, choose Add To Alert.
  2. From the Object area, select an object to monitor.
  3. From the Counter area, select one or more counters.

    Choose Explain to display a definition of the selected counter.

  4. From the Instance area, select one or more instances.
  5. From the Alert If area, select Over or Under.
  6. From the Run Program On Alert area, select First Time or Every Time.
  7. Enter the path and file name for the application or macro that you want to run when the specified alert occurs, and then choose Add.
  8. Repeat the previous six steps to add an additional object or device, and then choose Done.
