Adding an Object, Counter, and Instance to a Report

  1. From the Edit menu, choose Add To Report.
  2. In the Object window, select an object to monitor from the list.
  3. In the Counter window, select one or more counters.
  4. Choose Explain to see a definition of the selected counter.
  5. If applicable, in the Instance box, select one or more instances.
  6. Choose Add.
  7. Repeat the previous five steps for any additional objects or devices that you want to monitor, and then choose Done.
