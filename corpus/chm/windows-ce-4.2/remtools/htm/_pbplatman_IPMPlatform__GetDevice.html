IPMPlatform::GetDevice

This method obtains a remote device object for a specified bstrDeviceIdOrName element.

HRESULT GetDevice(
  BSTR bstrDeviceIdOrName,
  IPMRemoteDevice** ppiRemoteDevice 
);

Parameters

bstrDeviceIdOrName
[in] GUID or name of the remote device object to be retrieved.
ppiRemoteDevice
[out] Pointer to a pointer to the IPMRemoteDevice interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Platform.h, Cemgr.idl.
