Kernel Transport Selection

A kernel transport provides the means to establish a kernel-level connection to an OS image running on a target device. A kernel transport, in addition to implementing the IPMService interface, also implements the IKITL interface that is defined in the Kitl.idl file in the Sdk\Wce420\Platman\Include directory in the top-level Platman directory of Platform Manager.

Platform Manager provides the following kernel transports by default:

  • Emulator Kernel Transport
  • Ethernet Kernel Transport
  • Serial Kernel Transport
