Starting Remote Kernel Tracker in Limited Buffer Mode

  1. From the Tools menu, choose Remote Kernel Tracker.
  2. In the Remote Kernel Tracker window, from the File menu, choose Limited Buffer Mode.
  3. Type or select a limit for the amount of data to collect.

    The limit can range from 1 megabyte (MB) to 100 MB.

  4. Choose OK.
