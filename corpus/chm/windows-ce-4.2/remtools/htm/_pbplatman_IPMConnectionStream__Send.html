IPMConnectionStream::Send

This method sends a byte array over the connection stream.

HRESULT Send(
  long dwSize,
  VARIANT vtArray,
  long* pdwSizeSent 
);

Parameters

dwSize
[in] Size of the array to be sent.
vtArray
[in] Byte array to be sent.
pdwSizeSent
[out] Pointer to the number of bytes sent.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Connectionstream.h, Cemgr.idl.
