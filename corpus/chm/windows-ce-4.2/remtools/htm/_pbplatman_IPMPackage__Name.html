IPMPackage::Name

This method obtains the name of the package object.

HRESULT Name(
  BSTR* pbstrPackageName 
);

Parameters

pbstrPackageName
[out] Pointer to the name of the package object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Package.h, Cemgr.idl.
