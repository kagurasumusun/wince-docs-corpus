IPublisherManagement

This interface provides the means for the Publish/Subscribe Manager to obtain buffering settings from the publisher. For more information about the Publish/Subscribe Manager, see Publisher Characteristics. The publisher implements this interface.

The IPublisherManagement interface passes a pointer to the ISubscriber interface. The publisher requires a pointer to the ISubscriber interface to send data to the subscriber.

The IPublisherManagement interface provides a means for the Publish/Subscribe Manager to obtain buffering settings from the publisher. This interface also provides a means for the Publish/Subscribe Manager to indicate when it is ready to receive data and to indicate when data should not be published.

The following table shows this interface's methods.

Method Description
IPublisherManagement::Initialize Passes a pointer to the ISubscriber interface. Called by the Publish/Subscribe Manager.
IPublisherManagement::StartPublishing Indicates that the Publish/Subscribe Manager is ready to receive data. Called by the Publish/Subscribe Manager.
IPublisherManagement::StopPublishing Indicates that the Publish/Subscribe Manager does not want to receive data. Called by the Publish/Subscribe Manager.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: CEPubSub.h (for desktop), CEPubSubPS.h (for device), CePubSub.idl.
