IPMPlatform::GetPackage

This method obtains the package object for a specified bstrPackageIdOrName element.

HRESULT GetPackage(
  BSTR bstrPackageIdOrName,
  IPMPackage** ppiPackage 
);

Parameters

bstrPackageIdOrName
[in] GUID or name of the package object to be retrieved.
ppiPackage
[out] Pointer to a pointer to the IPMPackage interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Platform.h, Cemgr.idl.
