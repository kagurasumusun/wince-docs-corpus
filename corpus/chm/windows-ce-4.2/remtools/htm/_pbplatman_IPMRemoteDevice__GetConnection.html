IPMRemoteDevice::GetConnection

This method returns the connection object for the remote device.

HRESULT GetConnection(
  BSTR bstrConnectId,
  IPMConnection** ppiConnection 
);

Parameters

bstrConnectId
[in] GUID of the connection object to be retrieved.
ppiConnection
[out] Pointer to a pointer to the IPMConnection interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Device.h, Cemgr.idl.
