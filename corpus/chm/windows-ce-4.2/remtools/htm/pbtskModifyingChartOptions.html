Modifying Chart Options

  1. From the Options menu, choose Chart.
  2. In the Chart Options dialog box, select the items that you want to display in the chart.
  3. In the Vertical Maximum box, type the maximum value to which the vertical axis should extend.
  4. Under Update Time, choose Manual Update or Periodic Update, and then type a number in the Interval box to specify the time, in seconds, between chart updates.
  5. Under Gallery, select Graph or Histogram as the format for the display.
