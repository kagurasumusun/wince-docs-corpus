IPMPlatformManager::AddBootableDevice

This method adds a bootable device object to the IPMPlatformManager interface of type bstrBootableDeviceName.

HRESULT AddBootableDevice(
  BSTR bstrBootableDeviceName,
  BSTR bstrBootableDeviceId,
  IPMBootableDevice** ppiBootableDevice 
);

Parameters

bstrBootableDeviceName
[in] Name of the bootable device object to be added.
bstrBootableDeviceId
[in] Optional; GUID of the bootable device object to be added. If this parameter is not specified, Platform Manager creates a GUID for the bootable device object.
ppiBootableDevice
[out] Pointer to a pointer to the IPMBootableDevice interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Platman.h, Cemgr.idl.
