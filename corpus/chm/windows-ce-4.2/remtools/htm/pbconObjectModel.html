Platform Manager Object Model

Platform Manager stores information about a platform and how to establish a connection between a development workstation and the target device running the platform. Platform Manager stores information in a collection of objects that are arranged in a defined hierarchical structure. You can view the Platform Manager hierarchy in the registry under the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Tools\Platform Manager key.

The following illustration shows the object model for Platform Manager.

When you create a software development kit (SDK), the information required to develop applications for your platform is associated with a platform object. The objects associated with your platform are registered with the root-level Platform Manager object.
