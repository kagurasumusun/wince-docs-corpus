Remote Call Profiler Quick Start

The following table shows topics that are designed to get you up and running with Remote Call Profiler. To work through these topics and familiarize yourself with Remote Call Profiler, you can use the instrumented applications in the Hello directory in the Sdk\Wce420\Platman\Samples directory of the top-level Platman directory for Platform Manager. For more information about the Hello sample, view the Readme.txt file in the Hello directory.

Topic Description
Downloading and Launching an Instrumented Module Download an instrumented application to a target device and launch the application on the target device.
Introduction to Data Collection Control Control data collection by using the Remote Call Profiler Collection Control window or the data collection control functions.
Data Viewing in Remote Call Profiler Select a time segment, set data filters, and then display profiling data in Top X View, Call Graph View, Butterfly View, Call Tree View, Module Summary View, or Call Trace and Function Trace Views.
