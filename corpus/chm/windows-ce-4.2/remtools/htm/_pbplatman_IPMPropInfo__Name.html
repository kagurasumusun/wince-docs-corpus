IPMPropInfo::Name

This method obtains or sets the name of the property information object.

To obtain the name of the property information object use the following syntax.

HRESULT Name(
  BSTR* pbstrName 
);

To set the name of the property information object use the following syntax.

HRESULT Name(
  BSTR bstrName 
);

Parameters

pbstrName
[out] Pointer to the name of the property information object.
bstrName
[in] Name of the property information object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Propinfo.h, Cemgr.idl.
