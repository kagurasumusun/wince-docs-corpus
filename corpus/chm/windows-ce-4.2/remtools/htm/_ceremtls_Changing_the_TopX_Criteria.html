Filtering Data in the Top X View

In the Top X view, to filter the data that Remote Call Profiler displays, you can display only a percentage of or a specific number of the functions in the data range. You can also display all functions within the data range.

To filter data in a Top X view

  1. In the Top X pane, choose TopX% to display a percentage of the available functions.

    - or -

    In the Top X pane, choose TopX# to display a specific number of functions.

    - or -

    In the Top X pane, choose Function Summary to specify all functions in the given data range.

  2. From the Top X box, type or select the percentage or number of functions to display.

    If you chose Function Summary, do not choose a value from the Top X box.

  3. In the By box, choose # Calls to display the total number of calls to each function.

    - or -

    In the By box, choose Time to display the CPU cycles spent in each function.

    - or -

    In the By box, choose User Counter to display the user-defined counter value for each function.

  4. In the box to the right of the By box, choose Application Exclusive, Application Inclusive, Elapsed Exclusive, or Elapsed Inclusive time.

    If you chose Time, do not choose a value from the box to the right of the By box.

  5. Choose the ! button.
