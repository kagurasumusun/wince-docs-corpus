IPublisher::Control

This method sends control information from a subscriber to the publisher.

HRESULT Control(
  DWORD dwControl,
  DWORD dwBufSize,
  BYTE* pbData 
);

Parameters

dwControl
[in] Control code defined by the publisher.
dwBufSize
[in] Size of the data buffer in bytes.
pbData
[in] Pointer to the data buffer.

Return Values

The following table shows the return values for this method.

Value Description
S_OK The call was successfully completed.
E_FAIL Unable to complete the call.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: CEPubSub.h (for desktop), CEPubSubPS.h (for device), CePubSub.idl.
