IPMService::IsServiceReleaseable

This method returns a value that shows whether the service can be released.

HRESULT IsServiceReleaseable(
  VARIANT_BOOL* pBool 
);

Parameters

pBool
[in] Pointer to a flag that indicates if there are any locks for the service object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Service.h, Cemgr.idl.
