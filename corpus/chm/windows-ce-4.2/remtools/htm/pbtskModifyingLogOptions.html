Modifying Log Options

  1. From the Options menu, choose Log.
  2. In the File Name box, type a name for the log file that you want to create.
  3. In the Update Time area, choose Manual Update or Periodic Update.

    If you choose Periodic Update, in the Interval box enter a number that specifies the time, in seconds, between updates of the log.

  4. Choose OK.
