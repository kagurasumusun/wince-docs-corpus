Support for Automation Clients

Each object interface for Platform Manager is derived from the IDispatch interface, and as such, each object interface supports Automation. The Platform Manager API supports Automation clients developed in the Microsoft Visual Basic® programming language, the Microsoft Visual Basic Scripting Edition (VBScript) programming language, or Microsoft JScript®.

The code libraries for Platform Manager show examples of appropriate syntax for Automation clients using the Platform Manager API.
