KITLUnloadTransportLib

This function unloads a KITL transport library.

BOOL KITLUnloadTransportLib(
  KITLTRANLIB klib 
);

Parameters

klib
[in] Transport library to unload.

Return Values

This function returns TRUE if the call is successful.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Kitl.h.
