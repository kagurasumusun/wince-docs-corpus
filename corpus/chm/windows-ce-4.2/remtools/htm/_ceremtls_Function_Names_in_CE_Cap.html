Function Names in Remote Call Profiler

The following example shows the syntax that Remote Call Profiler uses to represent the name of a function.

[Namespace::][ClassName::]FunctionName

In this example, Namespace is the declared name space to which the function belongs. If you define a function within a name space, Remote Call Profiler includes the name space and the scope operator (::) in the representation of the function name.

ClassName is the class in which the function is declared. If you define a function within a class, Remote Call Profiler includes the class name and the scope operator in the representation of the function name.
