Data Collection Control

Remote Call Profiler provides a number of ways of controlling the amount and type of data that you collect during a profiling run. You can use the Remote Call Profiler Collection Control window to collect data interactively during a profiling run and add Remote Call Profiler API functions to your code to collect data. You can mark sections of the logging stream and name processes and threads for easier identification in Remote Call Profiler views and in the Remote Call Profiler Collection Control window.
