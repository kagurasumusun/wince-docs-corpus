Serial Download Service

The serial download service downloads an OS image to a target device over a serial port connection using the boot loader for Windows CE.

For the serial download service, you cannot configure the device-side settings at run time. You must configure the device-side settings by modifying the code in the OS image and then recompiling the code. You can change the baud rate in the code. At the #define DEF_BAUD_DIVISOR line in the Halserkitl.c file in %_WINCEROOT%\Platform\Cepc\Kernel\Hal, change the value of DEF_BAUD_DIVISOR. To determine the baud rate, divide a rate of 115,200 bits per second by the DEF_BAUD_DIVISOR constant. For example, to set a baud rate of 38,400 bits per second, set DEF_BAUD_DIVISOR to 3.
