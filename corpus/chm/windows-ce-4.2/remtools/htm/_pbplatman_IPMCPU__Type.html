IPMCPU::Type

This method obtains or sets the type of the microprocessor.

To obtain the type of the microprocessor use the following syntax.

HRESULT Type(
  long* pdwType 
);

To set the type of the microprocessor use the following syntax.

HRESULT Type(
  long dwType 
);

Parameters

pdwType
[out] Pointer to the type of the microprocessor.
dwType
[in] Type of the microprocessor.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Cpu.h, Cemgr.idl.
