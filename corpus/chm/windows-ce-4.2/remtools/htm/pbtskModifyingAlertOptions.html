Modifying Alert Options

  1. From the Options menu, choose Alert.
  2. Select or clear the Switch To Alert View and the Log Event In Application Log check boxes.
  3. Select or clear the Send network message check box.

    If you select the Send network message check box, in the Net Name box type the network name of the alert recipient's device, without backslashes (\\).

  4. In the Update Time area, choose Manual Update or Periodic Update.

    If you choose Periodic Update, in the Interval box type a number to specify the time, in seconds, between updates.
