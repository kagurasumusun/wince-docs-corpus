Placing or Removing a Marker

To place a marker

  1. In the ruler bar, right-click the location at which you want to place a marker.
  2. Choose Set Time Marker 1 or Set Time Marker 2.

To place a marker at the current location of the cursor

  1. In the system pane, right-click at any location.
  2. Choose Set Time Marker 1 or Set Time Marker 2.

To remove a marker

  • In the ruler bar, right-click, and then choose Delete Time Marker 1 or Delete Time Marker 2.
