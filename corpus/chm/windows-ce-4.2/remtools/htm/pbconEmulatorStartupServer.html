Emulator Startup Server

As an application developer working with a tool, such as eMbedded Visual C++, you can launch a platform on the Emulator startup server. When an OEM creates an SDK for a platform, the OEM has the option to include support for the Emulator in the SDK.

You can configure the Emulator startup server by choosing from options that are defined by selections made when the OEM created the SDK for the platform. If you have installed Platform Builder on your development workstation, you can, as an alternative, use the settings that Platform Builder uses to connect to the Emulator.
