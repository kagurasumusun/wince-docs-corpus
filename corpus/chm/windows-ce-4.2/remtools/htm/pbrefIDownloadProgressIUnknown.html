_IDownloadProgress:IUnknown

This interface provides information about progress of a download of an OS image to a target device.

The following table shows this interface's methods.

Method Description
_IDownloadProgress::OnProgressNotify Provides information about the status of a download of an OS image to a target device.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Download.h, Download.idl.
