IPublisherManagement::StartPublishing

This method indicates that the Publish/Subscribe Manager is ready to receive data. The Publish/Subscribe Manager calls this method. For more information about the Publish/Subscribe Manager, see Publisher Characteristics.

HRESULT StartPublishing();

Parameters

None.

Return Values

The following table shows the return values for this method.

Value Description
S_OK The call was successfully completed.
E_FAIL Unable to complete the call.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: CEPubSub.h (for desktop), CEPubSubPS.h (for device), CePubSub.idl.
