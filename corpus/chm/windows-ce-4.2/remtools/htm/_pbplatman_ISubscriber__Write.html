ISubscriber::Write

This method sends data from a publisher to each registered subscriber of that publisher. A publisher calls this method. The Publish/Subscribe Manager handles the call from the publisher by calling the ISubscriber::Write method for each registered subscriber. For more information about the Publish/Subscribe Manager, see Publisher Characteristics.

HRESULT Write(
  DWORD dwBufSize,
  BYTE* pbData 
);

Parameters

dwBufSize
[in] Size of the buffer in bytes.
pbData
[in] Pointer to the data buffer.

Return Values

The following table shows the return values for this method.

Value Description
S_OK The call was successfully completed.
E_FAIL Unable to complete the call.

Remarks

To improve performance, a subscriber should not process data in this call but should instead make a local copy of the data and return immediately.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: CEPubSub.h (for desktop), CEPubSubPS.h (for device), CePubSub.idl.
