Device Details

In the TickStats sample, the TickStatsCE.cpp file is for the target device. The TickStatsCE.cpp file is composed of the following parts:

  • Functionality that loads Platform Manager and creates a connection stream.
  • A loop that reads bytes from the development workstation and either sends back the tick count or causes itself to exit.
  • A function that closes the connection stream.
