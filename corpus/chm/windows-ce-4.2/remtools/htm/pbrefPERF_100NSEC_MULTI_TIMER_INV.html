PERF_100NSEC_MULTI_TIMER_INV

This is the inverse of the timer for multiple but similar items. The following table shows the values used when the objects are not in use.

Element Value
X CounterData
Y 100NsTime
Time base 100Ns
Data Size 8 Bytes
Display Suffix %
Calculation 100* (B1- ((X1-X0)/(Y1-Y0)))/B1
