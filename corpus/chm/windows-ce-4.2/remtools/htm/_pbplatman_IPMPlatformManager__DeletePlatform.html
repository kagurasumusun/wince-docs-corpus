IPMPlatformManager::DeletePlatform

This method deletes a specified platform object registered with Platform Manager.

HRESULT DeletePlatform(
  BSTR bstrPlatformIdOrName 
);

Parameters

bstrPlatformIdOrName
[in] GUID or name of the specified platform object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Remarks

If you specify a name in the bstrPlatformIdOrName parameter and there is more than one platform with that name in the collection, the IPMPlatformManager::DeletePlatform method deletes the first platform with that name.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
