IPMOS::TypeId

This method obtains or sets the type GUID of the OS object.

To obtain the type GUID of the OS object use the following syntax.

HRESULT TypeId(
  BSTR* pbstrTypeId 
);

To set the type GUID of the OS object use the following syntax.

HRESULT TypeId(
  BSTR bstrTypeId 
);

Parameters

pbstrTypeId
[out] Pointer to the type GUID of the OS object.
bstrTypeId
[in] Type GUID of the OS object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Os.h, Cemgr.idl.
