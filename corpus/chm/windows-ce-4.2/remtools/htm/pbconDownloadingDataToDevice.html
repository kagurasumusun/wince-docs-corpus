Packages

A package object contains one of more files that you want to download to a target device to extend the functionality of a remote utility. For example, you can use a package object to associate additional tools and ActiveX controls with the software development kit (SDK) for a platform. When a remote utility requests that Platform Manager download a package, Platform Manager loads the files that match the target device to which it is connected.

The Platform Manager API exposes an IPMPackage interface for a package. You can associate each file in a package with a specific operating system (OS) version and CPU. You can register a package with a particular platform or with Platform Manager. However, if you register a package with Platform Manager, then the package is available to all platforms. To see how to create packages and register them with Platform Manager, see the Samplesreg.vbs file in Sdk\Wce420\Samples\Bin in the top-level Platman directory for Platform Manager.

A simple distributed tool can download its device-side part to a target device using packages. For more information, see the TimeViewer sample in Sdk\Wce420\Samples\Timeviewer in the top-level Platman directory for Platform Manager.
