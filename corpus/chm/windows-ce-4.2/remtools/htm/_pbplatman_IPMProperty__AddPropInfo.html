IPMProperty::AddPropInfo

This method adds a property information object to the IPMProperty interface.

HRESULT AddPropInfo(
  BSTR bstrPropInfoName,
  long dwPropInfoType,
  BSTR bstrPropInfoValue, 
  IPMPropInfo** ppiPropInfo 
);

Parameters

bstrPropInfoName
[in] Name of the property information object.
dwPropInfoType
[in] Type of the property information object.
bstrPropInfoValue
[in] Value of the property information object.
ppiPropInfo
[out] Pointer to a pointer to the IPMPropInfo interface. This pointer is returned if the property information object has been successfully added.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Property.h, Cemgr.idl.
