Creating Custom Transport Files

As the first step of creating a custom transport for Platform Manager, you must create files for the transport. The following procedure shows how to create these files. For more information about creating a custom transport, see Custom Transport Creation.

To create custom transport files

  1. From the File menu, choose New Project or File.
  2. Choose the Projects tab.
  3. Choose WCE Transport Layer.
  4. In the Project Name box, enter a name for the project.
  5. Choose OK.
  6. Choose Finish.

For information about building the custom transport files, see Building the Desktop-Side and the Device-Side File.
