IPMCPU:IDispatch

This interface provides the ability to access and change a specified microprocessor object. The microprocessor object is returned as a collection by the IPMPlatformManager::EnumCPUs and IPMPlatform::EnumCPUs methods. The microprocessor object is returned as a single object by the IPMPlatformManager::GetCPU and IPMPlatform::GetCPU methods.

The following code sample shows one technique for accessing a microprocessor object from an Automation client.

Dim tCPU as Object
Set tCPU = tPlatman.GetCPU( <GUID or name of CPU> )

The following table shows this interface's methods.

Method Description
IPMCPU::Id Obtains the GUID associated with the microprocessor object.
IPMCPU::Name Obtains or sets the name of the microprocessor object.
IPMCPU::Architecture Obtains or sets the architecture of the microprocessor.
IPMCPU::Type Obtains or sets the type of the microprocessor.
IPMCPU::PageSize Obtains or sets the page size of the microprocessor.
IPMCPU::Level Obtains or sets the level of the microprocessor.
IPMCPU::DefaultValue Obtains or sets the default value for the microprocessor.
IPMCPU::CpuNum Obtains or sets the numerical value by which Platform Manager identifies the CPU.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Cpu.h, Cemgr.idl.
