CESH Service

The CESH service is a protocol for communicating over the PPFS Service. In the release directory on the development workstation, there is a Shell.exe file that serves as command interpreter. The Shell.exe process executes on the target device because it is loaded onto the target device by the PPFS service. Shell.exe periodically polls the FSAUXIN file in the release directory and executes any commands in it.

The development workstation writes commands to the FSAUXIN file, and the Shell.exe process on the target device executes the commands. Shell.exe sends the output of commands over a KITL stream named CESH.
