Error 2002: Bad .ICP File Version

Bad file version number ICPVersion

Remote Call Profiler cannot open an .icp file created with the version of the Remote Call Profiler DLL listed in the .icp file.

The version of the Remote Call Profiler DLL on the development workstation that created the .icp file must be compatible with the version of the msic.exe file on the analysis development workstation.
