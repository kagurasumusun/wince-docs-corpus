Process Profiling Level

The process profiling level permits or blocks data collection for all threads in a specified process. You can use the process profiling level when you want to control data collection for all threads in a single process application with multiple threads. You can also use the process profiling level to control data collection for a specific process in a cross-process application.

The Remote Call Profiler API functions StartProfile, StopProfile, SuspendProfile, ResumeProfile when passed the PROFILE_PROCESSLEVEL constant, control data collection for a specific process.
