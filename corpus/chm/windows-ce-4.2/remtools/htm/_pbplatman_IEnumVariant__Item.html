IEnumVariant::Item

This method obtains the member of a collection of objects corresponding to a specified index.

HRESULT Item(
  long Index,
  VARIANT* pVariant 
)

Parameters

Index
[in] Index of the member.
pVariant
[out] Pointer to the member of the collection.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Enumvariant.h, Cemgr.idl.
