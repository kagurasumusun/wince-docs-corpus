Obtaining the Path of the Release Directory for a Platform

The release directory is a directory on the development workstation that a target device can access as if the contents of the directory were on the target device. Platform Builder creates a different release directory for each platform. The following procedure shows how to find the location of the release directory for the workspace that is currently opened by Platform Builder.

To obtain the path of the release directory for a platform

  1. Open your platform.
  2. From the Platform menu, choose Settings.
  3. Choose the General tab.
  4. View the Release Directory box.

    The Release Directory box shows the path of the release directory for your platform.
