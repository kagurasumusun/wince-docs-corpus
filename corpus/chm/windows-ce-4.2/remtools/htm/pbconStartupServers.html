Startup Server Selection

A startup server is a mechanism that enables you to download the files for the device-side part of Platform Manager to a target device and launch the files on the target device. A startup server provides the ability to download a file to a target device without adding the file to the OS image when you build a platform.

There are two primary methods for putting the device-side part of Platform Manager on a target device. The first method is through Platform Builder. With this method, you integrate the device-side part of Platform Manager into the operating system (OS) when you build a platform.

Alternatively, you can load the device-side part of Platform Manager on demand with a startup server. Before you can establish a connection to a target device through a Platform Manager transport, you must download the device-side part of the transport to the target device and start the device-side part on the target device. With a startup server, you can load the files for the device-side part of the transport and launch the files. This practice is an efficient use of memory resources on the target device. For more information about transports, see Transport Selection.

Platform Manager provides the following startup servers:

  • ActiveSync Startup Server
  • CESH Startup Server
  • Emulator Startup Server
  • Manual Startup Server
