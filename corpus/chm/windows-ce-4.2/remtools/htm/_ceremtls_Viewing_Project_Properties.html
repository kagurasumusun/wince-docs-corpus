Displaying the Properties of a Project Item

  1. In the Timeline window, from the project list, select a project item whose properties you want to display.
  2. From the View menu, choose Properties Window.
  3. Choose the User tab to display a user-defined subset of the properties of the project item.

    - or -

    Choose the All tab to view all properties of the project item.
