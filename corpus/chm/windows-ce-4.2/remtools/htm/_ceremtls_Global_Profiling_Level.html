Global Profiling Level

We recommend that you use the global profiling level only for cross-process applications if you want to control data collection for all the threads in all processes. To control data collection in a single-process, multithreaded application, we recommend you use the process and thread levels. For a single-threaded application, we recommend that you use the thread profiling level.

The Remote Call Profiler API functions StartProfile, StopProfile, SuspendProfile, ResumeProfile when passed the PROFILE_GLOBALLEVEL constant, control data collection for a specific process.
