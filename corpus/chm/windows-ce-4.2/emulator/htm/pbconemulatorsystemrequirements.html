Emulator System Requirements

The development workstation must meet the following requirements in order to run one instance of the Emulator configured to use 64 megabytes (MB) of memory:

  • 450-MHz CPU.
  • 192 MB of system memory. Microsoft suggests that the development workstation have at least 256 MB of system memory for a larger Windows CE OS image.
  • 50 MB of space free on hard drive.

Microsoft recommends that the development workstation meet the following requirements to run one instance of the Emulator configured to use 64 MB of memory:

  • 1-GHz CPU.
  • 384 MB of system memory.
  • 500 MB of space free on hard drive.

Each additional instance of the Emulator requires an additional 32 MB of system memory plus an amount of system memory equal to the amount the Emulator is configured to use.

To run the Emulator, you must set the input language for the development workstation to English.
