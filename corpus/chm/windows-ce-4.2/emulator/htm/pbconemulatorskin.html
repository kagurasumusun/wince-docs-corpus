Emulator Skin

An Emulator skin controls the appearance and functionality of the graphical user interface (GUI) for the Emulator. With an Emulator skin, you can give the Emulator the look and behavior of a specific hardware platform. Platform Manager provides a collection of Emulator skins that you can use to customize the appearance of the Emulator. For more information, see Emulator Skin Samples.

You can also customize an Emulator skin. For more information, see Emulator Skin Development.

You can choose to run the Emulator with or without an Emulator skin. If you run the Emulator with an Emulator skin, the Emulator skin affects the appearance of the Emulator window. The Emulator skin overrides the video display setting for the Emulator.
