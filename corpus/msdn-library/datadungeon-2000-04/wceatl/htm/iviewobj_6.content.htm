IViewObjectExImpl::GetExtent

This method retrieves the control's display size in HIMETRIC units (0.01 millimeter per unit) from the m_sizeExtent data member.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation
