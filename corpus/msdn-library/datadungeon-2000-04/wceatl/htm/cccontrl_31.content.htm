CComControl::GetZoomInfo

This method retrieves the x and y values of the numerator and denominator of the zoom factor for a control activated for in-place editing.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

void GetZoomInfo( ATL_DRAWINFO& di );
