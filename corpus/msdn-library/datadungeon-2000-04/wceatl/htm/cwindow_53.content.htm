CWindow::MapWindowPoints

This method converts a set of points from the window’s coordinate space to the coordinate space of another window. The second of this method allows you to convert the coordinates of a RECT structure.

At a Glance

Header file: Atlwin.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

int MapWindowPoints( HWND hWndTo, LPPOINT lpPoint, UINT nCount ) const;

int MapWindowPoints( HWND hWndTo, LPRECT lpRect ) const;
