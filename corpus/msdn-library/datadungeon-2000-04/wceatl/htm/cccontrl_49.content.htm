CComControl::m_bDrawFromNatural

This data member is a flag that indicates that IDataObjectImpl::GetData should set the control size from m_sizeNatural rather than from m_sizeExtent.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

unsigned m_bDrawFromNatural:1;

See Also

IDataObjectImpl::GetData, CComControl::m_sizeNatural, CComControl::m_sizeExtent
