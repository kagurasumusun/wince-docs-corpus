IDataObjectImpl::GetData

This method transfers data from the data object to the client. The pformatetcIn parameter must specify a storage medium type of TYMED_MFPICT.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

HRESULT GetData( FORMATETC* pformatetcIn, STGMEDIUM* pmedium );
