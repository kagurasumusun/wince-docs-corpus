Unsupported ATL Classes

ATL for Windows CE currently does not support all classes in the standard ATL.

The current version of Windows CE does not support asynchronous monikers, snap-in objects, safety maps, apartment threading, or out-of-process servers. Because of these differences, ATL for Windows CE does not support the following classes:

  • CBindStatusCallback

  • CSnapInItemImpl

  • CSnapInPropertyPageImpl

  • IObjectSafetyImpl

  • IServiceProviderInfo

Some classes in ATL for Windows CE do not support all the methods they support in the standard Active Template Library. For more information about these classes, see Modified ATL Classes.
