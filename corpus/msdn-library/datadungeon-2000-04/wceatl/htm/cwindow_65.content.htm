CWindow::SendMessage

This method sends a message to the window and does not return until the window procedure has processed the message.

At a Glance

Header file: Atlwin.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

LRESULT SendMessage( UINT message, WPARAM wParam = 0,
LPARAM lParam = 0 );

See Also

CWindow::PostMessage, CWindow::SendNotifyMessage
