Welcome to the Active Template Library for Windows CE

The Active Template Library for Windows CE Version 2.10 contains all the classes, macros, and global functions you need to develop small, fast Microsoft® ActiveX® controls for platforms that run Windows CE.

The Active Template Library for Windows CE supports almost all of the classes, macros, and global functions supported by the standard Active Template Library.

The ATL for Windows CE documentation is HTML-based. You can start reading now by clicking on one of the categories you see at the right.

For the latest information about developing for Windows CE, visit the Microsoft Windows CE World Wide Web site, http://www.microsoft.com/ windowsce/developer.
