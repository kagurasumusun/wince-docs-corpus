DECLARE_REGISTRY_RESOURCE

This macro gets the named resource containing the registry file and runs the script to either enter objects into the system registry or remove them from the system registry.

At a Glance

Header file: Atlcom.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

DECLARE_REGISTRY_RESOURCE( x )
