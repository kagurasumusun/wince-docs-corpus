IDataObjectImpl

This class implements the IDataObject interface, which provides methods to support Uniform Data Transfer and manages connections to advise sinks to handle data change notifications.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

template< class T >
class IdataObjectImpl

Remarks

Windows CE does not support the DAdvise, DUnadvise, or EnumDAdvise methods of the IDataObjectImpl class, or the IDataObjectImpl::m_spDataAdviseHolder data member.
