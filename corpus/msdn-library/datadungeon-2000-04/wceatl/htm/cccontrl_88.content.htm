CComControl::m_sizeExtent

This data member stores the extent of the control in HIMETRIC units (each unit is 0.01 millimeters) for a particular display.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

SIZE m_sizeExtent;

See Also

CComControl::m_sizeNatural, CComControl::m_rcPos
