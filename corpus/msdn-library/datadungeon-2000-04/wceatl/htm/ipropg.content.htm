IPropertyPageImpl

This class implements the IPropertyPage interface, which allows an object to manage a particular property page within a property sheet.

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

template< class T >
class IPropertyPageImpl

Remarks

ATL for Windows CE does not support the Help or OnStyleChange methods of the IPropertyPageImpl class.
