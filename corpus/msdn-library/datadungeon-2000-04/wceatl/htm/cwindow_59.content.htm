CWindow::PostMessage

This method places a message in the message queue associated with the thread that created the window and returns without waiting for the thread to process the message.

At a Glance

Header file: Atlwin.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL PostMessage( UINT message, WPARAM wParam = 0,
LPARAM lParam = 0 );

See Also

CWindow::SendMessage, CWindow::SendNotifyMessage
