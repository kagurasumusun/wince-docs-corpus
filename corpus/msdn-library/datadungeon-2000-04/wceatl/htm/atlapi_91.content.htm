NOTIFY_ID_HANDLER

This macro is similar to NOTIFY_HANDLER, but maps a WM_NOTIFY message based only on the control identifier.

At a Glance

Header file: Atlwin.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

NOTIFY_ID_HANDLER( id, func )
