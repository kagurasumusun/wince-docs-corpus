CComControl::DoesVerbActivate

This method checks that the iVerb parameter used by IOleObjectImpl::DoVerb either activates the control’s user interface (iVerb equals OLEIVERB_UIACTIVATE), defines the action taken when the user double-clicks the control (iVerb equals OLEIVERB_PRIMARY), displays the control (iVerb equals OLEIVERB_SHOW), or activates the control (iVerb equals OLEIVERB_INPLACEACTIVATE).

At a Glance

Header file: Atlctl.h
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL DoesVerbActivate( LONG iVerb );
