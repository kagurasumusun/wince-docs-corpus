Soltr Sample Help File

The Soltr sample Help file demonstrates the unique tags and structure of a Help for Windows CE file. This file is based on the help file for Solitaire, the bundled application found on many Palm-size PCs. Soltr explains how to play Solitaire, set Solitaire options for the Palm-size PC, and keep track of the score.

Soltr is built using HTML 3.0, with certain limitations and additional tags. After setting up the standard header tags, Soltr uses the <!-- PegHelp --> tag to begin and separate help topics. The images in the help file are stored as .2bp files, and are loaded using the <IMG SRC > tag. Because all Help for Windows CE files are saved with the .htm extension, all references must use this extension as well.

The Soltr sample help file uses the following tags:

<A HREF, NAME>…</A>
<B>…</B>
<BR CLEAR>
<TITLE>…</TITLE>
<BODY BGCOLOR, TEXT>…</BODY>
<!DOCTYPE HTML PUBLIC>
<HEAD>…</HEAD>
<HR>
<HTML>…</HTML>
<IMG SRC>
<LI>
<META HTTP-EQUIV, CONTENT>
<OL>…</OL>
<P>…</P>
<!-- PEGHELP -->
TITLE
<UL>…<\UL>
