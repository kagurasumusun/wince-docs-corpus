Choosing Menus and Controls

Palm-size PC applications can use all of the standard menus and controls available in Windows CE. However, some controls optimize screen space better than others. The following screen shots show a dialog box on a Handheld PC (H/PC) and a dialog box on a Palm-size PC.

Although both dialog boxes contain the same information, they present information differently. Palm-size PC software uses separator bars instead of frames to visually group related controls. Drop-down list boxes replace radio buttons, and check boxes are displayed vertically instead of horizontally. These space-saving techniques allow a Palm-size PC dialog box to appear as spacious and uncluttered as their H/PC and desktop PC counterparts.
