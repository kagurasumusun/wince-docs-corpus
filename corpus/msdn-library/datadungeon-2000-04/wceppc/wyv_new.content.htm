What's New for Palm-size PC Version 1.2

Windows CE for the Palm-size PC version 1.2 provides a world-wide update to the Palm-size PC device line. Targeted originally for the Japanese personal digital assistant (PDA) market, Palm-size PC version 1.2 expands on the capabilities of the original Palm-size PC with additional support for color and localization capabilities. This section describes the new features and API available on the Palm-size PC version 1.2.

New Features for Palm-size PC Version 1.2

The following list describes the new features of the Palm-size PC Version 1.2.

  • Windows CE 2.11

    Palm-size PC version 1.2 is based on Windows CE 2.10. This version of Windows CE contains a number of additional features to the core operating system. For more information, see the Windows CE Programmer's Guide.

  • Color

    Palm-size PC version 1.2 supports color displays. For more information, see Working with Graphics.

  • True Type fonts

    Palm-size PC version 1.2 supports TrueType (TTF) fonts . Palm-size PC version 1.2 includes Tahoma and Courier New fonts, while the Japanese localized version adds MS PGothic for displaying Japanese characters. For more information, see Working with Graphics.

  • Windows CE ROM size

    As an operating system, Windows CE for the Palm-size PC version 1.2 requires 16 MB of ROM for Japanese support, while the minimum world-wide English (WWE) version requires 8 MB. Depending on the device, some Windows CE components may be compressed.

  • Processor support

    Palm-size PC version 1.2 supports both the MIPS and SH3 CPUs. The following table describes the processors that have been successfully tested on the localized versions of Palm-size PC version 1.2

  • Language Support

    In addition to Japanese, Palm-size PC version 1.2 supports world-wide English (WWE), German, French, Italian, Spanish, and Brazilian Portuguese,. Palm-size PC version 1.2 also includes national language support (NLS) for displaying date, currency, and other locale-dependent information. (and the Euro currency)

  • OLE

    Palm-size PC version 1.2 ships with full Windows CE OLE32 support in ROM. For more information, see COM and ActiveX Object Services in the Win32 SDK.

  • HTML Control

    The HTML control has been updated in order to display Asian characters. For information on programming the HTML control, see Creating an HTML Control for Palm-size PC.

  • Input panel and IMM/IME support

    Due to increased language support, Palm-size PC version 1.2 supports the input method manager (IMM) and input method editor (IME) API. In addition to a unique API set, Palm-size PC version 1.2 supports the standard Windows CE 2.10 SIP and IMM/IME API. For more information, see Receiving User Input and Using the Input Panel to Communicate With the Input Method Editor.
