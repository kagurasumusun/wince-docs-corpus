Optional Navigation Controls

An OEM can provide optional navigation controls. The following list describes some options an OEM may choose to implement:

  • Start
  • Tab/BackTab
  • Alt
  • Right arrow and left arrow
  • Volume up and volume down
  • Mute
  • Space
  • Shift
  • Additional VK_* messages
  • Additional program controls

These options can be implemented in several ways, including adding extra buttons and button chording. As with other navigation controls, the OEM is responsible for the supporting drivers for additional options.
