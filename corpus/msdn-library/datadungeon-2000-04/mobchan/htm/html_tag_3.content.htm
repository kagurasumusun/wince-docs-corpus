MIME Formats

Mobile Channels support for Multiple Internet Mail Extensions (MIME) formats is described in the following table.

MIME format Palm-size PC H/PC (2.0)
text/plain Yes Yes
text/html Yes Yes
image/bmp Yes Yes
image/gif Yes Yes
image/jpeg Yes Yes
image/tiff No No
image/x-xbitmap No Yes
audio/wav Yes Yes
audio/basic No No
audio/aiff No No
video/avi No No
video/mpeg No No
