Valid HTML Tags and Attributes

Mobile Channels does not support all Internet Explorer HTML tags and attributes. Such differences in support of common layout attributes include the following:

  • The ALIGN attribute in the IMAGE tag is not supported. For example, <IMG SRC=MyPic.gif ALIGN=RIGHT> is ignored.

  • Consecutive BR tags and P tags are not supported.

    A Channel Browser attempts to collapse excess vertical white space. This allows pages formatted for desktop displays to fit more easily on the screens of smaller Windows CE-based devices. Therefore, techniques such as multiple line break tags do not yield the expected results. Use the non-breaking space “&nbsp;” to prevent the browser from collapsing lines breaks between tags. For example, <BR><BR><BR> results in the same vertical spacing as <BR>. To achieve the desired result, use <BR>&nbsp;<BR>&nbsp;<BR>.

  • The FRAMESET tag is not supported. For example, <FRAMESET ROWS=”10,*,20”> is invalid.

  • The LEFTMARGIN and TOPMARGIN attributes of the BODY tag are not supported. For example, <BODY TOPMARGIN=0 LEFTMARGIN=0> is ignored.

  • Named anchors are not supported. For example, <A HREF=”#HERE”> is invalid.

  • The WIDTH and HEIGHT attributes in a table tag are not supported. For example, <TABLE WIDTH=220> is invalid. Table cell width is supported, but only if every table cell width is defined.

    Note   Use table cell width to achieve table spacing.

  • Dimensions given in percentages are not supported. For example, <TABLE WIDTH=100%> is invalid.

For more information on supported HTML tags, see Mobile Channels HTML Reference.
