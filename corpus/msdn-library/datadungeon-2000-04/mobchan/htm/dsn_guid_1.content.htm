Display Capabilities

The screen size of a Palm-size PC is 240 x 320 pixels, which includes right and left margins of approximately 6 pixels and a scroll bar of approximately 16 pixels.

Note   Create the entire page layout in a 210 pixel-wide table. This allows accurate rendering of a Palm-size PC display when working or viewing on a standard monitor, and avoids scaling problems.

The Palm-size PC displays only the following grayscale colors:

  • White: 255, 255, 255

  • Light gray: 192, 192, 192

  • Dark gray: 128, 128, 128

  • Black: 0, 0, 0

While the Palm-size PC supports only a grayscale display, it is possible for users to view your site on a desktop computer as well. Therefore, you can include some color in your display; restrict images to 16 colors in order to conserve storage space.
