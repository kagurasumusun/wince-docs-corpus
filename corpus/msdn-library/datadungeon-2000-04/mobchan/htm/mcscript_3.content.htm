Keywords

The following keywords are reserved and may not be used as variable names:

  • If, Then, Else, ElseIf, End If

  • FOR, Next, Do While, Loop, Exit FOR, Exit While

  • SET, Response, Request, MobileChannels

  • Now, LocDate, Len, Mid, Split, Asc, Chr, StrComp, Random

If you attempt to use these keywords as variable names, you will receive a syntax error from your interpreter.

Note   If you use Next or LocDate, which are reserved keywords, as variable names, you do not receive a syntax error. However, you do receive unexpected results.
