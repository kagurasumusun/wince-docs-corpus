Welcome to the Mobile Channels Development Kit

Mobile Channels is a technology for downloading and viewing HTML-based content on a Windows CE-based device. The Mobile Channels Development Kit for Microsoft® Windows® CE (MCDK) is designed to provide Web content developers with tools and information needed to create mobile channels for the Palm-size PC and other Windows CE-based mobile devices.

The guide includes the following parts:

  • An overview of mobile channels and how they are used

  • A design guide

  • References for HTML tags, Channel Definition Format (CDF) files, and scripted channels

To view either the sample mobile channels, or the ones you create, you need Internet Explorer 4.0 or later and Windows CE Services 2.1. You can install these programs from the compact disc packaged with your device, or from the following Web sites:

  • Microsoft Internet Explorer Download at http://www.microsoft.com/ie/download
