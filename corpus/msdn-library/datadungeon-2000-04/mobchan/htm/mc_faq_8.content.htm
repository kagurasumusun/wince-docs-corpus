Subscribing to Similar Channels

A subscribed channel appears on the Internet Explorer 4.0 channel bar, but does not appear on the mobile device or in the Channel Items area of the desktop computer. Alternately, subscribing to a mobile channel removes a different mobile channel.

Cause

The ID tag in the channel CDF file is not unique. When two mobile channels have the same ID tag, the most-recently subscribed channel replaces the older channel on the desktop and mobile device.

Resolution

Use an ID tag unique to your mobile channel. Avoid using tags such as “index”, “main”, “sports”, or “mobile”; these tags are often used by other developers.
