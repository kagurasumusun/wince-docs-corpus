Title

This method attempts to retrieve the title of a specified element by the following means:

  • If an explicit TITLE tag exists, its associated value is returned.

  • If the element is an .mcd data item with an ITEMFORMAT specifying a TITLE field, the data item is opened and the title extracted.

  • If an ID element is provided, its value is returned.

  • If anything else, NULL is returned.

Syntax

MC.Title(ElemString)

Example

titleString = MC.Title(ElemString)

Remarks

This method does not mark a data item as “Read” as it retrieves the title. When using the Navigate method to get the title, the item is marked as “Read,” even if the user has not actually looked at it.
