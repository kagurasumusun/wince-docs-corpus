Preface

The Microsoft® Windows® CE Toolkit for Visual Basic® 6.0 enables you to develop Windows CE-based applications using a integrated development environment (IDE) that is very similar to the IDE used to develop other Visual Basic applications. The toolkit contains Windows CE-specific versions of many of the standard development tools you use to create, test, and refine your applications. In addition, the toolkit includes tools, wizards, and other features unique to Windows CE that will help you develop new software.

With the Microsoft Windows CE Toolkit for Visual Basic 6.0, you can create applications for a Handheld PC (H/PC), including an HP/C running the Microsoft® Windows® CE, Handheld PC Professional Edition software. You also can design custom platforms created with the Microsoft® Windows® CE Platform Builder Version 2.11. Furthermore, you can simultaneously develop applications for a variety of processors. The following table shows the processors the toolkit supports.

Processor Family
Processor
ARM ARM720, SA1100
MIPS MIPS3900, MIPS4100, MIPS4300
Hitachi SH3, SH4
PowerPC PPC, PPC821
X86 X86 (DX/SX), X86 Emulation

The toolkit supports versions 2.0, 2.10, and 2.11 of the Microsoft® Windows® CE operating system. While the toolkit is primarily designed to run on Microsoft® Windows NT® Workstation 4.0, it also runs on Microsoft® Windows® 95 and Microsoft® Windows® 98. However, because the Windows NT architecture differs slightly from the Windows 95/98 architecture, some toolkit features, such as emulation, will not work on Windows 95/98.
