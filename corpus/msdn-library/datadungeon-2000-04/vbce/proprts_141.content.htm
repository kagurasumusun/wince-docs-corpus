Item

This property returns a specific member of a Collection object either by position or by key.

Syntax

object.Item(index)

Parameters

object
Object expression that evaluates to a collection.
index
Expression that specifies the position of a member of the collection. If a numeric expression, index must be a number from 1 to the value of the collection's Count property. If a string expression, index must correspond to the key parameter specified when the member was added to the collection.

Remarks

If the value provided as index does not match any existing member of the collection, an error occurs.

Item is the default property for a collection.
