Supported Features

ADOCE supports the following objects:

  • Recordset object
  • Field object
  • Fields collection

ADOCE does not support the features in the following list:

  • Connection object

    There is a fixed connection to the ADOCE database engine.

  • Command object

    All commands are sent using the Open method.

  • Error object and errors collection

    All errors are returned in the Visual Basic Err object.

  • Property object and properties collection

    The ADOCE provider supplies no additional properties.
