Installation and System Requirements

To install the ADOCE control, you need the following:

  • Microsoft® Windows® CE Services 2.1
  • Microsoft® Windows NT® Workstation 4.0, Microsoft® Windows® 95, Microsoft® Windows® 98
  • Microsoft® Windows® CE Platform SDK, Handheld P/C Edition, version 2.0
  • Microsoft® Visual Basic®, Professional Edition 6.0 or Microsoft® Visual Basic®, Enterprise Edition 6.0, and the Microsoft® Windows® CE Toolkit for Visual Basic® 6.0

    – Or –

    Microsoft® Visual C++®, Professional Edition 6.0 or Microsoft® Visual C++®, Enterprise Edition 6.0, and the Microsoft® Windows® CE Toolkit for Visual C++ 6.0

    To install ADOCE 2.0

  1. Download the ADOCE setup application.
  2. Connect the H/PC to the desktop computer.
  3. Run Setup.exe.

The ADOCE 2.0 SDK is installed in \Windows CE Platform SDK\ADOCE. You can use the programming samples provided only if you have one of the toolkits that are described earlier installed on your computer.

The ADOCE 2.0 emulator files are installed in \Windows CE Platform SDK\Wce\Emul\Hpc\Windows and are copied into your emulator object store Hpc.obs using the command empfile -s.

The setup application attempts to download H/PC files to the device. If the device is not connected at that time, Windows CE Services downloads the files when you next connect.
