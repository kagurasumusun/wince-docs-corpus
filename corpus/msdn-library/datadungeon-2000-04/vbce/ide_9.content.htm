Tools Menu

Use the Tools menu to start the Menu Editor or to change the behavior of IDE features. The Tools menu in the toolkit does not include the Add Procedure command because the toolkit does not support Property procedures, Event procedures, or the Static keyword. The Menu Editor and Options commands are identical to the commands in Visual Basic 6.0.

The following table shows the Tools menu commands contained in the toolkit.

Command
Description
Procedure Attributes Displays the Procedure Attributes dialog box, which enables you to set the attributes for each property and method specified for an item.
Menu Editor Displays the Menu Editor dialog box, which enables you to create custom menus for an application.
Options Displays the Options dialog box, which enables you to set IDE attributes.
