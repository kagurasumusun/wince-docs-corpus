Establishing a Remote Connection

Before you can use a remote tool, you must establish a connection between the desktop computer and the device. To assist you in configuring various connections to Windows CE-based devices, each remote tool contains a Windows CE Platform Manager, an add-in that manages all communication between a remote device and a tool. Because the Platform Manager is an add-in, all commands are built into the menus and dialog boxes of the tools; thus, you implicitly use the Platform Manager every time you connect or disconnect a tool from a device.

The Spy, Zoom, Process Viewer, and Heap Walker tools enable you to automatically connect to a device upon startup. The first time you start one of these tools, the Platform Manager displays the Select a Windows CE Device dialog box. After you select a device, simply choose OK. The Platform Manager connects the tool to the specified device. The next time you activate the tool, the Platform Manager automatically connects to the last device selected.

You also can connect to a device manually by choosing Connect to Device from the Spy menu on the Spy tool or from the File menu on the Zoom, Process Viewer, or Heap Walker tools. To disconnect from a device, choose the Disconnect from Device command on the same menus to terminate the connection to the device.

The Spy, Zoom, Process Viewer, and Heap Walker tools do not support emulation and can be used on only one Windows CE-based device at a time.

If the remote connection to your tool fails, run Repllog.exe from the device, as shown in the following procedure.

    To run Repllog.exe from your remote device

  1. Choose Start on the remote device, and then choose Run.
  2. Type Repllog.exe in the Open field.
  3. Choose OK.
