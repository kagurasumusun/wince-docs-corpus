Windows CE Menu

The Windows CE menu contains commands used to access tools specific to Windows CE. These tools enable you to create, manage, and debug your applications. Some tools require a connected device in order to operate properly. For more information about Windows CE tools, see Using Remote Tools.

The following table shows the Windows CE menu commands contained in the toolkit.

Command
Description
Application Install Wizard Creates a setup program for your application.
Download Runtime Files Copies the run-time files to a connected device or emulator.
Control Manager Installs and uninstalls ActiveX controls on a connected device or emulator.
Heap Walker Analyzes memory use on a Windows CE-based device.
Process Viewer Analyzes process and module use on a Windows CE-based device.
Registry Editor Edits registry entries on a local computer or on a connected device or emulator.
Spy Analyzes the messages your application sends to its windows while running on a Windows CE-based device.
Zoom Captures full-screen images of applications running on a Windows CE-based device.
