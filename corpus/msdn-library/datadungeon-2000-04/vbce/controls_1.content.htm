ActiveX Controls

ActiveX controls are components you can add to your project that perform specialized tasks. Each ActiveX control supplies objects you can control with your application. In addition, each ActiveX control supplies constants with predefined values to make controlling the objects easier. ActiveX controls are created from an external DLL, and each ActiveX DLL contains libraries that hold ActiveX controls, along with enumerations and other objects.

The following ActiveX controls are available in the Windows CE Toolkit for Visual Basic 6.0.

Comm Control Grid Control TabStrip Control
CommandBar Control Image Control TreeView Control
CommonDialog Control ImageList Control Winsock Control
File System Controls ListView Control
