Add-Ins Menu

Use the Add-Ins menu to load add-ins, such as the API Viewer, into the IDE. The Add-Ins menu in the toolkit does not include the Visual Data Manager command, which was written to showcase the data access features in Visual Basic 5.0. These data access features are not applicable to Windows CE, which uses the ADOCE control to access data.

The following table shows the Add-Ins menu command contained in the toolkit.

Command
Description
Add-In Manager Displays the Add-In Manager dialog box, which enables you to load and unload add-ins that extend the IDE.
