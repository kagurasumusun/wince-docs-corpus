Using Spy

Spy is a tool for displaying messages received by an application window running on a remote device. When you start Spy (pspy.exe), the remote device downloads a dialog box containing a list of the windows that are open on the device. The following screen shot shows the Spy window.

To view information about the messages in a window’s message queue, select a window and choose Messages on the File menu.

The Remote Spy is a read-only utility that will not alter the functionality of any application, but it may slow system performance on low memory devices.
