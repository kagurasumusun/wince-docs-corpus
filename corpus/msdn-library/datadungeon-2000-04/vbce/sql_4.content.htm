Data Manipulation Language Statements

Using the Data Manipulation Language (DML) elements of SQL, you can retrieve information from, and store information in, a database. However, DML does not enable you to change the structure of the database.

The following statements make up the DML portion of SQL for ADOCE:

  • Variations on the SELECT statement
    • SELECT – Simple
    • SELECT – Order By
    • SELECT – Restricted
    • SELECT – Projection
    • SELECT – Join
  • DELETE
  • INSERT
