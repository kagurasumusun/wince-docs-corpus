Finance Control

This control provides access to financial functions by creating a Finance object.

Library Name

PVBFINANCELib

DLL Name

Finance.dll

The Finance control supports the following methods:

DDB PMT
FV PPMT
IPmt PV
IRR Rate
MIRR SLN
NPer SYD
NPV  

Remarks

The Finance object is a non-visual object. It cannot be placed on a form. To use the Finance object, use the CreateObject statement to create the object.
