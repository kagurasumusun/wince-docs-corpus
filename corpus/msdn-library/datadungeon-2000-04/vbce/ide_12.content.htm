Help Menu

The Help menu provides access to the Windows CE Toolkit Help command and to the About the Windows CE Toolkit command, which provides version and product identification information.

The following table shows the Help menu commands contained in the toolkit.

Command
Description
Contents Runs Microsoft® Developer Network (MSDN) Library for Microsoft® Visual Studio™ and displays the Contents tab.
Index Runs MSDN Library for Visual Studio and displays the Index tab.
Search Runs MSDN Library for Visual Studio and displays the Search tab.
Windows CE Toolkit Help Runs Help for the toolkit.
Technical Support Displays information about obtaining technical support from Microsoft.
Microsoft on the Web Displays a menu with Internet sites.
About Microsoft Visual Basic Displays the About Microsoft Visual Basic dialog box, which provides the version number and product identifier for Visual Basic.
About the Windows CE Toolkit Displays the About the Windows CE Toolkit for Visual Basic dialog box, which provides a version number and product identifier for the toolkit.
