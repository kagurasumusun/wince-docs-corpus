Welcome to the Microsoft Windows CE Toolkit for Visual Basic 6.0

With the Microsoft® Windows® CE Toolkit for Visual Basic® 6.0, you can apply your knowledge of Visual Basic to building applications that target Windows CE-based mobile and embedded devices. The toolkit uses the same Visual Basic code editor, form editor, and property pane, with new Windows CE-specific functionality exposed. The Windows CE emulation environment and remote tools, built into the familiar Visual Basic development environment, can help you port existing applications or develop entirely new ones for a wide range of devices that run Windows CE.

The documentation included with the toolkit contains both a Programmer's Guide and a Programmer's Reference. The Programmer's Guide contains step by step information on using remote tools, writing code, and debugging applications. The Programmer's Reference provides detailed information on all Windows CE for Visual Basic language features.

The Windows CE Toolkit for Visual Basic 6.0 is a member of the Windows CE family of development products. These products include the following additional toolkits:

Microsoft Windows CE Toolkit for Visual C++

Microsoft Windows CE Toolkit for Visual J++

For the latest information about developing for Windows CE, visit the Microsoft Windows CE World Wide Web site, http://www.microsoft.com/ windowsce/developer.
