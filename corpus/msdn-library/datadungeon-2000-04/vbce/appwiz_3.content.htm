Installing and Registering a Control

You can install and register a control to an emulator or a device. The following procedure shows how to install a control using the Control Manager.

    To install and register a specified control

  1. Choose Control Manager from the toolkit Windows CE menu.
  2. Highlight a control from the list of controls.
  3. Choose a project type from the left pane of the Control Manager window.
  4. Choose Install to Target from the Control menu. The control is installed and registered to the target device. A dialog box confirms that the installation is successful.

In addition, you can install and register a control that is not listed in the Control Manager.

    To install and register a control not listed in the Control Manager

  1. Choose a project type from the left pane of the Control Manager window.
  2. Choose Add New Control from the Control menu.
  3. Select the .dll containing the control.

    The .dll file will be copied, then registered.
