Database Conversion

ADOCE 2.0 not only enables you to create new databases, but it also provides a Windows CE file filter for databases. The file filter is a conversion utility that enables you to import Microsoft Access database tables from a desktop computer to an H/PC and export ADOCE databases to Microsoft Access databases on a desktop computer. The ADOCE setup application adds the following commands to the Mobile Devices Tools menu to give users manual control over the Windows CE file filter.

  • Import Database Tables
  • Export Database Tables

You can specify an open database connectivity (ODBC) data source instead of a Microsoft Access file. ADOCE supports Access and SQL Server ODBC sources.

For more information about the conversion process, see Database Conversion Specifics.

For information about controlling the conversion process programmatically, see Programming Interface.

Note ADOCE 2.0 supports only database conversion, not synchronization.
