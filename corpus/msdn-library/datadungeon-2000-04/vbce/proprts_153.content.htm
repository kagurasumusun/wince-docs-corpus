LegalTradeMarks

This property returns and sets a string value containing legal trademark information about the running application.

Syntax

object.LegalTrademarks [= string]

Parameters

object
Object expression that evaluates to an App object.
string
String expression that specifies legal trademark information.

Remarks

The LegalTrademarks property is read-only at run time.

You can set this property at design time in the Type box in the Make tab of the Project Properties dialog box.
