Getting Technical Support

You can find late-breaking updates and technical information in the Readme file included with your product disks or CD.

If you still have a question, Microsoft offers technical support and services ranging from self-help tools to direct assistance with a Microsoft technical engineer.

    To get information about Microsoft support options and resources

  • Choose Technical Support on the Visual Studio Help menu.

There also is specific technical support information available for the Windows CE toolkits. In addition to the Windows CE Toolkit for Visual Basic 6.0, the toolkits include the Microsoft® Windows® CE Toolkit for Visual J++™ and the Microsoft® Windows® CE Toolkit for Visual C++®.

    To get technical support information for the Windows CE toolkits

  1. Access the following Web site: http://support.microsoft.com/support/supportnet/default.asp.
  2. Complete your online profile on the Support Web page. Choose the Next button to move to the next page. Choose the Finish button when your profile is complete.
  3. Choose Windows CE Toolkit for Visual Basic 6.0 on the Phone Numbers and Support Options page. Then choose the Go button. The support page for the toolkit opens.

The Phone Numbers and Support Options page contains the current rate and coverage information for the following technical support options:
