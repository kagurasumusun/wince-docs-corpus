FilterIndex

This property returns and sets a default filter for an Open or Save As dialog box.

Syntax

object.FilterIndex [= number]

Parameters

object
Object expression that evaluates to a CommonDialog control.
number
Numeric expression that specifies a default filter.

Remarks

This property specifies the default filter when you use the Filter property to specify filters for an Open or Save As dialog box.

The index for the first defined filter is 1.
