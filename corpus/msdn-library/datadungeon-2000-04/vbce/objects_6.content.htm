CommandBarComboBox Object

This object represents a combo box.

Syntax

CommandBarComboBox

The CommandBarComboBox object supports the following properties:

Caption Enabled
Index ItemData
Key NewIndex
List ListCount
ListIndex Sorted
Style Tag
Text Type
Visible Width

The CommandBarComboBox object supports the following properties:

  • AddItem
  • Clear (Clipboard, ComboBox, ListBox)
  • RemoveItem

Remarks

Combo boxes appear only when the CommandBarControl object's Type property is set to cbrComboBox.
