Database Conversion Specifics

Windows CE Services uses file filters to automatically handle conversions between desktop computer file formats and device file formats. ADOCE provides the file filter Adofiltr.dll to handle the .mdb to ADOCE conversion process. The file format on the H/PC is listed as .cdb, but the .mdb tables are simply stored as database tables in the Databases directory of the H/PC. This section covers the following topics:

  • Importing into the Device
  • Exporting from the Device
