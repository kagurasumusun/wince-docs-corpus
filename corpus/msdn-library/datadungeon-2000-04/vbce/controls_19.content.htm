Frame Control

This control provides an identifiable grouping for other controls. For example, you can use a frame control to separate a group of option button controls.

Syntax

Frame

The Frame control supports the following properties:

Appearance FontBold Left
BackColor, ForeColor FontItalic Name
BorderStyle FontStrikethru Parent
Caption FontUnderline TabIndex
ClipControls FontName Tag
Container FontSize Top
Enabled Height Visible
Font HWnd Width

The Frame control supports the following methods:

  • Move
  • Refresh
  • ZOrder

The Frame control supports the following events:

  • Click
  • DblClick
  • MouseDown
  • MouseMove
  • MouseUp

Remarks

When using the Frame control to group other controls, first draw the frame control, and then draw the controls inside it. This enables you to move the frame and the controls it contains together.

To select multiple controls in a frame, hold down the CTRL key while using the mouse to draw a box around the controls.
