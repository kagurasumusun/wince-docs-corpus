Starting a Remote Tool

You can start a remote tool from Visual Basic or from the Windows Start button.

    To start a remote tool from Visual Basic

  1. Choose Windows CE Remote Tools from the Visual Basic Tools menu.
  2. Choose a tool from the Remote Tools menu.

    To start a remote tool from the Start button

  1. Choose the Start button.
  2. Choose Programs, then Microsoft Visual Basic 6.0, then Windows CE Tools. Choose a tool from the Windows CE Tools window.

Note You can run multiple instances of Zoom, but only single instances of other remote tools.
