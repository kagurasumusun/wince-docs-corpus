Run Menu

The Run menu contains the Start command, which you can use to compile and run an application. Because you cannot stop or pause an application from the IDE, Windows CE-based applications are always compiled completely before they are run. For this reason, the toolkit does not include a Start With Full Compile option. To compile an application without running it, use the Make button on the toolbar.

The following table shows the Run menu command contained in the toolkit.

Command
Description
Start Compiles and runs the application.
