Properties

The ADOCE control supports the following Recordset Object properties.

  • AbsolutePage
  • AbsolutePosition
  • ActiveConnection
  • BOF
  • Bookmark
  • CacheSize
  • CursorType
  • EditMode
  • EOF
  • LockType
  • PageCount
  • PageSize
  • RecordCount
  • Source

The ADOCE control supports the following Field Object properties.

  • ActualSize
  • Attributes
  • DefinedSize
  • Name
  • Type
  • UnderlyingValue
  • Value

The ADOCE control supports the following Fields Collection property.

  • Count
