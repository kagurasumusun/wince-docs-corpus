Using the Control Manager and Application Wizard

The Windows CE Toolkit for Visual Basic 6.0 includes two tools that help you distribute your applications: the Control Manager and the Application Install Wizard. The Control Manager installs and registers ActiveX controls onto a Windows CE-based device and the Application Install Wizard creates a setup program that installs your application onto a device.

The following sections describe how to use the Control Manager to install and register a control and the Application Install Wizard to create a setup program.
