Error

This event occurs whenever an error occurs in background processing in a Winsock control, such as a failure to connect or a failure to send or receive in the background.

Syntax

Private Sub winsock_Error(number, description)

Parameters

winsock
Object expression that evaluates to a Winsock control.
number
Contains the error number.

Remarks

The Winsock control uses the Error event to notify your application that a network error has occurred. An error message does not automatically display. Unlike Visual Basic 6.0, the Windows CE for Visual Basic 6.0 toolkit does not include a CancelDisplay parameter.
