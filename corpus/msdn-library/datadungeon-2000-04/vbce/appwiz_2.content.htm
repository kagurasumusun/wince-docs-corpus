Exploring Control Manager Menu Commands

The Control Manager contains several commands you can use to install and uninstall controls. The following table shows the menu commands available in the Control Manager.

Menu
Command
Description
File Exit Quits the Control Manager.
Control Install To Target Copies an ActiveX control to a device and registers it.
  UnInstall From Target Removes an ActiveX control from a device and deregisters it.
  Add New Control Adds a desktop control to a Windows CE enabled controls list, enabling you to add the control to the Toolbox and place it on a form. However, this does not automatically include the control with your project. You must manually copy the control to the device and register it.
View ToolBar Shows or hides the toolbar.
  Status Bar Shows or hides the status bar.
  Refresh Refreshes the display.
Help About Shows the About box.
