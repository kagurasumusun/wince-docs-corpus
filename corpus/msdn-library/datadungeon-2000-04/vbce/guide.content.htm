Programmer’s Guide

With ADOCE 2.0, you can move databases to and from your Handheld PC (H/PC), and you can create and access databases on an H/PC and an emulator on a desktop computer.

This documentation contains information to help you get started quickly using ADOCE in your applications. It covers the following topics:

  • Moving Databases Between the Desktop and Device
  • Listing All ADOCE Tables
  • Creating a Table
  • Storing and Retrieving Information
  • Sorting a Table
  • Distributing ADOCE Applications
  • System Table Definitions

For more information about using the ADOCE control, see Welcome to ADO for Windows CE, or see the following references:

  • SQL Reference
  • ADO Reference
