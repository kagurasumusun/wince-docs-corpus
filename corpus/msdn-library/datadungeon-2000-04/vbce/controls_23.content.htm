Menu Control

This control displays a custom menu for your application.

Syntax

Menu

The Menu control supports the following properties:

  • Caption
  • Checked
  • Enabled
  • Name
  • Parent
  • Visible

The Menu control supports the following event:

  • Click

Remarks

A menu can include commands, submenus, and separator bars. Each menu you create can have up to four levels of submenus. To create a separator bar, enter a single hyphen (-) in the Caption field. To display a check mark to the left of a menu item, select the check box.
