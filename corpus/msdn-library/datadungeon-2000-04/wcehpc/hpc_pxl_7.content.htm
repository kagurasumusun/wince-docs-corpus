COLINFO: Column Formatting Information (7Dh) [PXL 2.0]

The COLINFO record describes the column formatting for a column.

Record Data

Offset
Name
Size
Contents
0 colfirst 2 First Column this applies to
2 colLast 2 Last Column this applies to
4 coldx 2 Column width in 1/255s of a character
6 ixfe 2 Index to format to apply to columns
8 grbit 1 Option flags

Parameters

grbit
The grbit member is structured as follows:
Bit
Size
Name
Contents
0 1 fHidden Set if the column had been hidden or set to zero width
1 1 fUserSet Set if the column width has been set by the user (as opposed to AutoFormat)
2 3 iOutLevel Unused by Pocket Excel
5 3 fCollapsed Unused by Pocket Excel
8 2 Unused Unused by Pocket Excel
