Microsoft Pocket Excel File Format

The file format in which Microsoft Pocket Excel workbooks are saved is an abbreviated form of the binary interchange file format (BIFF). For details on the BIFF file format, developers should refer to the Excel Developer’s Kit, available from Microsoft Press. This document details differences between the Desktop BIFF file format and that used by Pocket Excel. From this point forward, “BIFF” refers to the Pocket Excel file format.
