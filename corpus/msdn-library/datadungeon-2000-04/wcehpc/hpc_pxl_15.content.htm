LABEL: Cell Value, String Constant (04h)

A LABEL record describes a cell that contains a string constant.

Record Data

Offset
Name
Size
Contents
0 rw 2 Row
2 col 1 Column
3 ixfe 2 Index to XF record
5 cch 2 Length of the string, in characters
7 rgch Variable The string

Parameters

rw
The zero-based row number
col
The zero-based column number
cch
String length. Must be between 0000h and 00FFh (0-255)
