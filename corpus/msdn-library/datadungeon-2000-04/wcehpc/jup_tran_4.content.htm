TransportCountEx

This function, an extension of TransportCount, determines the number of messages in the mailbox or any other message folder, and returns this count in the lpNumMsgs parameter.

At a Glance

Header file: Msgstor2.h
Platforms: H/PC 3.0
Windows CE versions: 2.10 and later

Syntax

BOOL TransportCountEx(HANDLE hService, LPWSTR szFolderID,
WORD *pwNumMsg);

Parameters

hService
[in] Handle to a private SERVICE structure.
szFolderID
[in] Null-terminated string that contains the identifier of the folder to search.
pwNumMsg
[in] Pointer to the number of messages in the folder specified by szFolderID.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call the function TransportError or TransportErrorMsg.

Remarks

The transport service provider must implement this function in a DLL registered as a mail service. The Inbox application can then load this DLL and call this function.
