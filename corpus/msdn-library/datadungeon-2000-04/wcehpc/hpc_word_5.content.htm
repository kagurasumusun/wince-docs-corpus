Paragraph Formatting Properties

The tokens described in the following table apply to paragraphs that are not contained inside tables. Most paragraph properties are not supported by Microsoft Pocket Word 2.0 inside table cells.

Token
Description
fi Indent first
li Line indent
pard Paragraph default
qc Center justify
ql Left justify (default, so not saved with document)
qr Right Justify
ri Right indent
s Style
sa Space after
sb Space before
sl Line spacing
Slmult Line spacing multiplier
