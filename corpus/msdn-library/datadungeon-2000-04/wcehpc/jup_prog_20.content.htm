Windows CE Toolkits

A toolkit is a set of Help files, programming tools, samples, and other routines designed to help you write applications in a specific programming language. Microsoft toolkits for Windows CE are integrated into the Microsoft® Visual Studio™ . You can access a toolkit through the integrated development environment (IDE). Portions of the toolkit may also be accessed separately through the Start menu. The following table shows the toolkits that are currently available for programming an application for an H/PC.

Toolkit
OS supported
