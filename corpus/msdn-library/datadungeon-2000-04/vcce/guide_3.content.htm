Connecting to a Device

The toolkit uses the Windows CE Platform Manager to connect to Windows CE-based devices and tools. The Platform Manager enables you to use any communication protocol, such as TCP/IP or Windows CE Services, to connect to a device or tool. The communication protocol also is known as the transport component.

In addition to facilitating communication between the toolkit and its associated devices and tools, the Platform Manager registers new software development kits (SDKs) and toolkits in the Windows Registry.

    To configure the transport component of a device

  1. Choose Configure Platform Manager on the Visual Studio Tools menu.
  2. Choose the platform your device uses in the Windows CE Platform Manager Configuration dialog box. The following screen shot shows the dialog box.

  1. If your device is not on the displayed list, choose Add Device.
  2. Choose your device, and then choose the Property button.
  3. Choose a transport component in the Device Property dialog box.
  4. Choose Test to test the connection, OK to close the dialog box with the changes you have made, Cancel to close the dialog box without making any changes, or Advanced to select a server component.
