Uninstalling the Windows CE Toolkit for Visual C++ 6.0

You can uninstall the Windows CE Toolkit for Visual C++ 6.0 without removing Visual C++ 6.0.

    To uninstall the Windows CE Toolkit for Visual C++

  1. Choose the Start button on the Taskbar.
  2. Choose Settings, then choose Control Panel.
  3. Select the Add/Remove Programs icon. A dialog box appears with a list of removable applications.
  4. Highlight Microsoft Windows CE Toolkit for Visual C++, 6.0. Choose the Add/Remove button.
  5. Follow the prompts on the screen.
