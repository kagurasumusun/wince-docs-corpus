Windows CE Remote File Viewer

The Windows CE Remote File Viewer (Osviewer.exe) utility enables you to accomplish the following actions:

  • View the object store on the remote device.
  • Browse the emulation file system and object store.
  • Browse the remote device file system and object store.
  • Browse the root directory, which contains Windows NT, of the desktop computer hard drive.
  • Delete, copy, and move files, folders, and databases.
  • Move files in and out of the emulation object store (Wceobstr.dat).
  • View a file’s properties.

The following screen shot shows the File Viewer window.

You can change the display format of the files by changing your display section on the View menu. The following table shows the View menu options.

Option Description
Small Icons Displays the small icon associated with the item
Large Icons Displays the large icon associated with the item
List Displays objects in list form
Details Displays name, size, type, last modified date and attribute information
Refresh Refreshes the File Viewer window

Drag the splitter bar to resize the window. Double-click a folder to display its contents. Double-click a file to view its properties.
