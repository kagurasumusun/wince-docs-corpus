Windows CE Technical Support Resources

You can find late-breaking updates and technical information in the Readme file that came with your product disks or compact disc.

If you still have a question, Microsoft offers technical support and services ranging from self-help tools to direct assistance with a Microsoft technical engineer.

    To get information about Microsoft support options and resources

  1. Choose Options on the Visual Studio Tools menu.
  2. Select the Help System tab in the Options dialog box.
  3. Select the most current MSDN library in the Preferred Collection text box, then select OK.
  4. Choose Technical Support on the Visual Studio Help menu. This opens a help page entitled Getting Help from Microsoft Technical Support, which contains links to a variety of technical support topics.

There also is specific technical support information available for the Windows CE Toolkit for Visual C++.

    To get answers to technical questions online

  1. Access the following Web site: http://support.microsoft.com/support
  2. Complete your online profile on the Support Web page.
  3. On the Support Online search page, enter Windows CE Toolkit for Visual C++ in the My question is dialog box. Specify your search options, and choose the Find button. Support Online searches all the information resources on the site and displays the results of your selection.

    To view technical support options for the toolkit

  1. Access the following Web site: http://support.microsoft.com/support/supportnet/default.asp
  2. Complete your online profile on the Support Web page.
  3. On the Phone Numbers and Support Options page, select Windows CE Toolkit for Visual C++ in the Select Your Product dialog box. Choose the Go button. The support page for the toolkit opens.
