Establishing a Remote Connection

Before you can use a remote tool on a device, there must be a connection between the tool and the device. The Windows CE Platform Manager manages all communication between the remote devices and tools. The Platform Manager commands are built into the menus and dialog boxes of the tools; you implicitly use the Platform Manager every time you connect or disconnect a tool from a device.

The first time you start the Spy++, Zoomin, Process Viewer, or Heap Walker tools, the Select a Windows CE Device dialog box appears. When you select a Windows CE-based device from the list and choose OK, the Platform Manager connects the tool to the specified device. The next time you activate the tool, the Platform Manager automatically connects it to the last device you selected. You also can connect to a device manually.

    To manually connect the Remote Spy++, Zoomin, Process Viewer, or Heap Walker tools to a device

  1. Chose Connect to Device from the Spy menu on the Spy++ tool or from the File menu on the Zoomin, Process Viewer, or Heap Walker tool.
  2. Choose the Disconnect from Device command on the same menus to terminate the connection to the device.

The Spy++, Zoomin, Process Viewer, and Heap Walker tools do not support emulation and can be used on only one Windows CE-based device at a time. The Registry Editor and File Viewer support emulation and can be used on multiple devices simultaneously. You can use the Registry Editor and File Viewer to add or remove connections to a device.

    To add or remove a device from the Registry Editor or File Viewer

  1. Choose the File menu on the File Viewer or the Registry menu on the Registry Editor.
  2. Choose Add Device to connect the tool to a device or choose Remove Device to disconnect the tool from a device.

Along with adding and removing connections to devices, you can use Platform Manager to configure a device from the Registry Editor and File Viewer.

    To configure a device from the Registry Editor or File Viewer

  1. Choose Configure Windows CE Platform Manager from the tool’s Help menu.
  2. Choose the platform your device uses in the Windows CE Platform Manager Configuration dialog box.
  3. If your device is not on the displayed list, choose Add Device to add your device.
  4. Choose your device, and then choose the Property button.
  5. Choose a transport component in the Device Property dialog box.
  6. Choose Test to test the connection, OK to close the dialog box with the changes you have made, Cancel to close the dialog box without making any changes, or Advanced to choose a server component.

For more information about the Platform Manager, see Connecting to a Device.

If the remote connection to your tool fails, run Repllog.exe from the device, as shown in the following procedure.

    To run Repllog.exe from your remote device

  1. Choose Start on the remote device, and then choose Run.
  2. Type Repllog.exe in the Open field.
  3. Choose OK.
