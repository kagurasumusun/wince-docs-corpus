Starting a Remote Tool

You can start a remote tool from the command line, from the Windows Start button, or from Visual Studio.

    To start a remote tool from Visual Studio

  1. Choose Windows CE Remote Tools from the Visual Studio Tools menu.
  2. Choose a tool from the Remote Tools menu.

You can run multiple instances of Remote Zoomin, but only single instances of other remote tools.

    To start a remote tool from the command line

  • Type C:\Windows CE Tools\WCE*\BIN[filename] from the command prompt on your windows desktop computer, where * is the version of the Windows CE operating system you are using, and filename is the name and extension of a Windows CE tool.

    To start a remote tool from the Start button

  1. Choose the Start button.
  2. Choose Run from the Start menu. Enter the name of a tool in the Open field of the Run dialog box, and then choose OK.

    – Or –

    Choose Programs, then Microsoft Visual C++ 6.0, then Windows CE Tools. Choose a tool from the Windows CE Tools window.
