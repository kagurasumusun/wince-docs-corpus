C Runtime Library Functions

The Microsoft Windows CE Toolkit for Visual C++ 6.0 supports a subset of the C Runtime Library functions supported in Visual C++.

Note Windows CE supports only Unicode implementations of such functions as wsprintf.

The following table shows all supported C Runtime Library functions.
