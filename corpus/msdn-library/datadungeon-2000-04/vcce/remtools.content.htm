Remote Tools

The Windows CE Toolkit for Visual C++ 6.0 adds several remote tools to the standard Visual Studio tools. The remote tools enable you to use your desktop computer to perform a variety of programming tasks on a Windows CE-based device.

The following table shows each of the remote tools.

Windows CE Tool Description
Windows CE Remote Spy++ Displays a graphical view on the desktop computer of windows and window messages running on the remote device.
Windows CE Remote Registry Editor Manages remote device registry entries from the desktop computer.
Windows CE Remote Zoomin Captures an image from the remote device and displays it on the desktop computer.
Windows CE Remote Process Viewer Displays a graphical view on the desktop computer of Windows CE processes and thread characteristics. The Process Viewer enables you to view memory use and search for memory leaks.
Windows CE Remote Heap Walker Displays information about heap identifiers and flags for processes that are running on a remote device.
Windows CE Remote File Viewer Displays a hierarchical view on the desktop computer of the Windows CE object store. The File Viewer enables you to transfer objects between the emulation object store and the device.
