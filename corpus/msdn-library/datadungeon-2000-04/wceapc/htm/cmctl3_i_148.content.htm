IASVVI

This interface provides methods to manage a visual volume indicator (VVI) control.

Method
Description
IASVVI::get_Inverted Retrieves whether the control is inverted or normal.
IASVVI::get_Mirrored Retrieves whether or not the control is mirrored.
IASVVI::put_Inverted Sets whether the control is inverted or normal.
IASVVI::put_Mirrored Sets whether or not the control is mirrored.

Remarks

The IASVVI interface, which has a global unique identifier (GUID) equal to IID_ASVVI, extends the IASProgressBar interface. The visual volume indicator control has a programmatic identifier equal to APC_Vvi.
