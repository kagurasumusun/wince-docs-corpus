Bundled Applications

Windows CE for the Auto PC includes the following bundled applications:

  • Address Book

    Address Book records and manages contact information. It enables users to reference or access other applications.

  • Audio

    Audio adjusts audio output. It enables users to control balance, fade, bass, treble, center channel, subwoofer, surround sound, crossover filters, and equalizer settings.

  • AM/FM Tuner

    AM/FM Tuner enables the user to listen to AM and FM radio stations. It supports both manual and speech commands.

  • CD Player

    CD Player controls output and the user interface functions of the compact disc player and changer. It supports both manual and speech commands.

  • Directions

    Directions calculates routes using the current GPS location or an address as the starting point, and an address or point of interest as the destination.

  • Messages

    Messages enables the user to receive and review messages. It displays different types of wireless information, such as e-mail, news, and traffic information.
