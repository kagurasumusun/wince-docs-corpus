IASCrossHairs::put_CrossHairHiliteColor

This method sets the color of the cross hair axes when the axes are highlighted.

Syntax

HRESULT put_CrossHairHiliteColor( OLE_COLOR clr );

Parameters

clr
[in] Color of the cross hair axes when the axes are highlighted.

Return Values

NOERROR indicates success. If an error occurs, the appropriate HRESULT value is returned.

Remarks

Use the RGB macro to set the components of clr before passing clr to the method.
