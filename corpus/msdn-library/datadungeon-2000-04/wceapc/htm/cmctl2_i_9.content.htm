IASPlayList::get_InactiveForeColor

This method gets the inactive foreground color.

Syntax

HRESULT get_InactiveForeColor( OLE_COLOR *pclr );

Parameters

pclr
Pointer to the inactive foreground color.

Return Values

NOERROR indicates success. E_INVALIDARG indicates that an invalid argument has been entered.

Remarks

Use the GetRValue, GetGValue, and GetBValue macros to get the color components of pclr.

See Also

IASPlayList::put_InactiveForeColor, GetRValue, GetGValue, GetBValue
