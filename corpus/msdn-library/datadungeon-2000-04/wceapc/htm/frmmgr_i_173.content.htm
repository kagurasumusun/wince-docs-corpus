IfmSystem

This interface is exposed by the Forms Manager and provides some system-level methods.

Method
Description
IfmSystem::CreateFMCompatibleBitMap Creates a compatible bitmap.
IfmSystem::CreateFMCompatibleDC Creates a compatible device context (DC).
IfmSystem::GetFMSystemFont Retrieves one of the two system fonts.
IfmSystem::GetFormDisplayCaps Retrieves the display capabilities.

Remarks

The IfmSystem interface extends the IDispatch interface.
