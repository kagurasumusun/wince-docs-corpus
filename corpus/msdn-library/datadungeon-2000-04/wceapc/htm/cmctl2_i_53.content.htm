IASSlider::get_HiliteColor

This method gets the highlight color.

Syntax

HRESULT get_HiliteColor( OLE_COLOR *pclr );

Parameters

pclr
Pointer to the highlight color.

Return Values

NOERROR indicates success. E_INVALIDARG indicates that an invalid argument has been entered.

Remarks

Use the GetRValue, GetGValue, and GetBValue macros to get the color components of pclr.

See Also

IASSlider::put_HiliteColor, GetRValue, GetGValue, GetBValue
