Testing your Installation

Once you’ve created an installation application, you should test the installation to ensure it runs smoothly and your application functions as expected.

The following procedures outline how to test that your installation is stable and will install reliably on an Auto PC.

To install and debug your application

  1. Build a CEI file containing all application files using CEIBuild.
  2. Create a CD or CompactFlash card that contains the CEI file and a corresponding Autorun.inf file.
  3. Turn on the Auto PC.
  4. Insert the CD or CompactFlash card into an Auto PC.
  5. Follow the instructions that appear on the screen of the Auto PC to install your application.
  6. Use the Windows CE Remote File Viewer to verify the construction of directories and the placement of files.
  7. Use the Windows CE Remote Registry Editor to verify that the installation program updated the registry settings properly.
