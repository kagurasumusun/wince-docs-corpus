IASPlayList::put_ActiveForeColor

This method sets the active foreground color.

Syntax

HRESULT put_ActiveForeColor( OLE_COLOR clr );

Parameters

clr
Active foreground color.

Return Values

NOERROR indicates success. E_INVALIDARG indicates that an invalid argument has been entered.

Remarks

Use the RGB macro to set the components of clr before passing clr to the method.

See Also

IASPlayList::get_ActiveForeColor, RGB
