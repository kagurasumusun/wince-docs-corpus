Working with Controls

Microsoft® Windows® CE for the Auto PC supports a set of standard ActiveX® controls for use by application developers. These controls provide basic user interface (UI) elements from which you can develop forms. The controls are displayed in an Auto PC form and managed by the Forms Manager.

Windows CE for the Auto PC has UI elements developed specifically for the automobile environment. If none of these standard controls are sufficient, you can define custom controls by adhering to guidelines provided in the following sections.
