IASShellMenu::get_LabelHeight

This method gets the label height.

Syntax

HRESULT get_LabelHeight( long *plHeight );

Parameters

plHeight
Pointer to a long integer that contains the height of the label.

Return Values

NOERROR indicates success. If an error occurs, the appropriate HRESULT value is returned.
