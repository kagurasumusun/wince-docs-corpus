IASClassMsgSink::HandleDraw

This method enables a control to notify its sink when drawing takes place.

Syntax

HRESULT HandleDraw( IDispatch *pdispControl, OLE_HANDLE hDC );

Parameters

pdispControl
Pointer to the control that is calling the method.
hDC
Handle to a device context (DC).

Return Values

NOERROR indicates that the sink handled the message. S_FALSE indicates that the sink did not handle the message. If an error occurs, the appropriate HRESULT value is returned.

Remarks

A control invokes this method when its own IASControl::Draw method is invoked.
