IAPCSpeech

This interface is a high level Auto PC simple speech interface.

Implement the IAPCSpeech interface in one of the following ways:

  • Call the IfmManage::get_Speech method of the Forms Manager if you want the speech notification to come through the regular class message sink or event sink.
  • Call the CreateAPCSpeech function to get the IAPCSpeech interface only if your application wants the speech notifications to be sent to the application thread directly.

Description

IAPCSpeech::Train Trains the application to recognize a user command, and deals with only one command at a time.
IAPCSpeech::VoiceHelpStart Called by the shell to start voice Help.
