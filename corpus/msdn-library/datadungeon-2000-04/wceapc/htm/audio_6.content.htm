WAV-in and WAV-out APIs

The WAV-in and WAV-out APIs enable you to control foreground audio sources, such as .wav file output and TTS output. These APIs are compatible with Win32® WAV APIs and communicate directly with the WAV-out device driver. Before playing or recording sound, you must access an audio device and query its capabilities. You must also coordinate the various devices in the system by using device handles and device identifiers. For more information about the WAV-in and WAV-out APIs, see the Microsoft® Windows® CE Software Developer’s Kit documentation.
