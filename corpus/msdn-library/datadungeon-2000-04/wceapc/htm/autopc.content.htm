Welcome to Windows CE Platform Software Developer's Kit, Auto PC Edition

Auto PC is an in-vehicle information and entertainment system that runs the Microsoft® Windows® CE operating system. An Auto PC provides a single, integrated platform that supports entertainment and information management. Microsoft® Windows® CE for the Auto PC includes extensions that support features specific to an Auto PC, such as positioning and navigation.

This start page helps you navigate the documentation describing the Microsoft® Windows® CE Platform Software Developer's Kit (SDK), Auto PC Edition.
