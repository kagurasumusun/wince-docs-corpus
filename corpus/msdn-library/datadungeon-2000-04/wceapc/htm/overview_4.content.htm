Development Tools

To create an application for an Auto PC, you must install the Microsoft® Visual C++® version 6.0 development system, the Microsoft® Windows NT® Workstation 4.0 operating system, the Windows CE Platform SDK for Auto PCs, and the Microsoft® Windows® CE Toolkit for Visual C++® 6.0 installed on your computer.

Microsoft Windows CE for the Auto PC does not support Microsoft Foundation Classes (MFC), Active Template Libraries (ATL), or Microsoft® Visual Basic®.
