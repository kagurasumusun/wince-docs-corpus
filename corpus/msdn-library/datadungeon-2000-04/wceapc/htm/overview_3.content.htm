Software

Windows CE for the Auto PC includes APIs adapted from Microsoft® Win32® APIs. For example, Windows CE for the Auto PC adapts the Win32 Speech API (SAPI) by adding the IAPSpeech interface. It adapts the navigation API by modifying the functions to work with COM objects.

The following table shows some of the APIs that Windows CE for the Auto PC supports.

API
Description
Address Book Enables access to the Contacts database
Audio manager Controls the audio system
Forms Manager Manages forms that comprise an Auto PC application
Positioning and Navigation Device interface for positioning, navigation, and GPS
Power Management Supports power management
Speech (SAPI) Controls speech and text to speech
Tuner Supports the AM/FM tuner
WAV-in Handles audio sources
WAV-out Handles audio destinations
Win32 Interface to the operating system
