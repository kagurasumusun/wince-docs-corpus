IVTxtAttributes

This interface allows an application to control various aspects of the operation of a voice text object.

Method
Description
IVTxtAttributes::EnabledGet Retrieves whether voice text is enabled for a voice text site.
IVTxtAttributes::EnabledSet Sets whether voice text is enabled for a voice text site.
IVTxtAttributes::IsSpeaking Indicates whether text is currently being spoken by a voice text site.
IVTxtAttributes::SpeedGet Retrieves the current average talking speed for a voice text site, in words per minute.
IVTxtAttributes::SpeedSet Sets the average talking speed for a voice text site, in words per minute.
IVTxtAttributes::TTSModeGet Retrieves the globally unique identifier (GUID) of the current text-to-speech (TTS) mode for a voice text site.
IVTxtAttributes::TTSModeSet Sets the globally unique identifier (GUID) of the current text-to-speech (TTS) mode for a voice text site.
