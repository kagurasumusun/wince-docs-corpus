IASClassMsgSink::HandleGotFocus

This method enables a control to notify its sink when the control gains focus.

Syntax

HRESULT HandleGotFocus( IDispatch *pdispControl );

Parameters

pdispControl
Pointer to the control that is calling the method.

Return Values

NOERROR indicates that the sink handled the message. S_FALSE indicates that the sink did not handle the message. If an error occurs, the appropriate HRESULT value is returned.

Remarks

A control invokes this method when its own IASControl::GotFocus method is invoked.

See Also

IASControl::GotFocus, IASClassMsgSink::HandleLostFocus
