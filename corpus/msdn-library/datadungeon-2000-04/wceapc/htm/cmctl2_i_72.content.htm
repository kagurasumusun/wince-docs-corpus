IASTimer::put_TimerEnabled

This method sets whether or not the timer is enabled.

Syntax

HRESULT put_TimerEnabled( BOOLfEnabled );

Parameters

fEnabled
Boolean that is set to TRUE if a timer is enabled, or to FALSE if not.

Return Values

E_OUTOFMEMORY
This value is returned if the system is out of memory.
