IVIO_EnumDiagnosticItems::Next

This method retrieves the specified number of items in the enumeration sequence.

Syntax

HRESULT IVIO_EnumDiagnosticItems::Next ( ULONG cItems, IVIO_EnumDiagnosticEntry **rgItemsArray, ULONG *pcItemsFetched);

Parameters

cItems
[in] Number of items to retrieve.
rgItemsArray
[out] Array of IVIO_EnumDiagnosticEntry pointers where retrieved diagnostic entry items are stored.
pcItemsFetched
[out] Pointer to a ULONG that contains the number of elements actually returned. If cItems is 1, this parameter can be NULL. If cItems is greater than 1, this parameter must be a valid pointer.

Return Values

One of the values described in the following table is returned.

Value
Description
S_OK The application successfully retrieved the number of IVIO_EnumDiagnosticEntry interfaces specified in cItems. The value referenced by pcItemsFetched is set to cItems.
S_FALSE The application returned fewer IVIO_EnumDiagnosticEntry interfaces than specified in Items. The value referenced by pcItemsFetched is set to the number of interfaces returned. The members of rgItemsArray that were not set are set to NULL.
E_OUTOFMEMORY The application is out of memory.
E_UNEXPECTED An unexpected error occurred.
E_INVALIDARG The value of cItems is invalid, or pcItemsFetched is NULL and cItems is greater than 1.
E_POINTER Either the rgItemsArray pointer is invalid or the pcItemsFetched pointer is invalid.

Remarks

The application must release the interfaces returned in rgItemsArray when it is done with them.
