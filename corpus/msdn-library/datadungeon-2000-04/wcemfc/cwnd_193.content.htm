CWnd::SetScrollRange

This method sets minimum and maximum position values for the specified scroll bar. It can also be used to hide or show standard scroll bars.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void SetScrollRange( int nBar, int nMinPos, int nMaxPos, BOOL bRedraw = TRUE );

See Also

CWnd::SetScrollPos, CWnd::GetScrollRange
