CStatusBar::Create

This method creates a status bar (a child window) and associates it with the CStatusBar object. It also sets the initial font and sets the status bar’s height to a default value.

At a Glance

Header file: Afxext.h
Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL Create( CWnd* pParentWnd, DWORD dwStyle = WS_CHILD | WS_VISIBLE | CBRS_BOTTOM, UINT nID = AFX_IDW_STATUS_BAR );
