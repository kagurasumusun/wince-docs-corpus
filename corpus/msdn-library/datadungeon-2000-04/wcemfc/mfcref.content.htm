MFC for Windows CE Reference

Windows CE supports many of the standard Microsoft Foundation Class library classes. Because Windows CE runs on platforms that are very different from the Windows-based desktop platforms, it has some different requirements. In order to meet these requirements, the designers of Windows CE have made changes to some of the classes in the library.

The MFC for Windows CE Reference contains documentation for all Microsoft Foundation Classes supported in the following released versions of Windows CE:

  • Windows CE version 1.0
  • Windows CE version 1.01
  • Windows CE version 2.0
  • Windows CE version 2.01
  • Windows CE version 2.10

Unless otherwise noted, all documented API elements are present in version 2.10. The version of MFC included in the Windows CE Toolkit for Visual C++ 6.0 supports the following Windows CE platforms:

  • Palm-size PC, version 2.01
  • Handheld PC (H/PC), version 2.0.
  • H/PC running H/PC Pro Edition software

Note Not all classes and class members are supported on all platforms. For information about which Windows CE platforms support a particular class, see the reference entry for that class.

Each reference topic includes an At a Glance table containing the following information.

At a Glance

Header file: Header file in which the class is defined.
Platforms: Targeted platforms.
Windows CE versions: Windows CE versions that include this API element.
Complete documentation: Link to the complete documentation as originally published. Usually, this is a link to the Visual C++ documentation.

When there is a link to original documentation, comments in the Remarks section are specific to Windows CE.
