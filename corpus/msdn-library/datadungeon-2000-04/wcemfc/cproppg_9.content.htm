CPropertyPage::OnQueryCancel

This method is called by the framework when the user clicks the Cancel button and before the cancel action has taken place. Override this method to specify an action the program takes when the user clicks the Cancel button.

At a Glance

Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
