CMenu::DeleteTempMap

This method is called automatically by the CWinApp idle-time handler, DeleteTempMap deletes any temporary CMenu objects created by the FromHandle method.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

static void PASCAL DeleteTempMap( );
