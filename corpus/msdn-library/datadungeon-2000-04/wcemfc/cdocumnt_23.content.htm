CDocument::SetModifiedFlag

This method is called after any modifications are made to the document. By calling this method consistently, you ensure that the framework prompts the user to save changes before closing a document.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void SetModifiedFlag( BOOL bModified = TRUE );
