CMemFile::Free

This method is called by CMemFile methods. Override this method to implement custom memory deallocation. If you override this method, you will probably also want to override Alloc and Realloc.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.0 and later
Complete documentation Visual C++ documentation

Syntax

void Free( BYTE * lpMem );

See Also

CMemFile::Alloc, CMemFile::Realloc
