CDWordArray

This class supports arrays of 32-bit DWORDs.

Because the methods of CDWordArray are similar to the methods of the CObArray class, use the CObArray reference documentation for method specifics.

Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
