CObArray::SetSize

This method establishes the size of an empty or existing array; allocating memory if necessary. If the new size is smaller than the old size, then the array is truncated and all unused memory is released. For efficiency, call SetSize to set the size of the array before using it. This prevents the need to reallocate and copy the array each time an item is added.
