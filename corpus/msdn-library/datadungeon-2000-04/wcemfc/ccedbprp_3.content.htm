CCeDBProp::GetBlob

This method retrieves the value of a property, when the property's data type is a binary large object (CEBLOB).

At a Glance

Header file: Wcedb.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.0 and later

Syntax

CEBLOB GetBlob( ) const;

Return Values

A pointer to the string represented by the property.

Remarks

You can only call GetBlob on a property of the type CeDBProp::Type_Blob.

See Also

CCeDBProp::SetBlob, CEBLOB
