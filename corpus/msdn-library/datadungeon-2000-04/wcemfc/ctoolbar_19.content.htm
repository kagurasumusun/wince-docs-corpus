CToolBar::SetHeight

This method sets the toolbar's height to the value, in pixels, specified in cyHeight.

After calling SetSizes, use this method to override the standard toolbar height. If the height is too small, the buttons will be clipped at the bottom.

At a Glance

Header file: Afxext.h
Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation

Syntax
