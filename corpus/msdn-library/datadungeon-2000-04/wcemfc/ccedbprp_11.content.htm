CCeDBProp::GetULong

This method retrieves the value of a property, when the property's data type is an unsigned long integer.

At a Glance

Header file: Wcedb.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.0 and later

Syntax

ULONG GetULong( ) const;

Return Values

The value of the property.

Remarks

You can only call GetULong on a property of the type CeDBProp::Type_ULong.
