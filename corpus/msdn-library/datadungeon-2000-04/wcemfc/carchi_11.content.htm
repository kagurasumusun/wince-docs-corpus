CArchive::MapObject

This method places an object in the map that is not actually serialized to the file, but that is available for subobjects to reference.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void MapObject( const CObject* pOb );

See Also

CArchive::ReadObject, CArchive::WriteObject
