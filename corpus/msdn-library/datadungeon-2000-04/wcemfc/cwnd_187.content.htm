CWnd::SetOwner

This method sets the current window’s owner to the specified window object. This owner can then receive command messages from the current window object.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void SetOwner( CWnd* pOwnerWnd );
