COleCurrency::GetStatus

This method retrieves the status (validity) of a specified COleCurrency object. The return value is defined by the COleCurrency::CurrencyStatus enumerated type.

At a Glance

Header file: Afxdisp.h
Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation
