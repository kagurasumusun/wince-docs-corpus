Windows CE Database Classes

MFC for Windows CE introduces the following unique database support classes.

CCeDBDatabase represents a Windows CE object store database.

CCeDBProp encapsulates the attributes and functionality of a database property.

  • CCeDBEnum is an object store database enumerator.
  • CCeDBRecord represents a Windows CE database record.

For information about where these Windows CE database classes fit into the Windows CE class hierarchy, see Classes Derived from CObject.
