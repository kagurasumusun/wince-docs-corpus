CArray::RemoveAt

This method removes one or more elements starting at a specified index in an array. In the process, it shifts down all the elements above the removed element(s).

At a Glance

Header file: Afxtempl.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void RemoveAt( int nIndex, int nCount = 1 );
