CListCtrl::GetItemData

This method retrieves the 32-bit application-specific value associated with the item specified by nItem. This value is the lParam member of the LV_ITEM structure; for more information about this structure, see GetItem.

At a Glance

Header file: Afxcmn.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

DWORD GetItemData( int nItem ) const;
