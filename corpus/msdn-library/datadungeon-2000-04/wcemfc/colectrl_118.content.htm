COleControl::OnSetObjectRects

This method is called by the framework to implement a call to IOleInPlaceObject::SetObjectRects. The default implementation automatically handles the repositioning and resizing of the control window and returns TRUE.

At a Glance

Header file: Afxctl.h
Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.0 and later
