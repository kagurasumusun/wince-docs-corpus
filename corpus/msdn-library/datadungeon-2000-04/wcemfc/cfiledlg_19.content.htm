CFileDialog::m_ofn

This data member is an OPENFILENAME structure. Use this structure to initialize the appearance of a File Open or File Save As dialog box after it is constructed but before it is displayed with the DoModal method.

At a Glance

Header file: Afxdlgs.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

OPENFILENAME m_ofn;
