CCeDBDatabase::m_hHandle

This data member contains the handle to an open database.

At a Glance

Header file: Wcedb.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.0 and later

Syntax

HANDLE m_hHandle;

Remarks

When you call the Open method, it sets the m_hHandle data member to a non-NULL value.
