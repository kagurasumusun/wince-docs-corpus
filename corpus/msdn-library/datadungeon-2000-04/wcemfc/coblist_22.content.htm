CObList::SetAt

This method writes the CObject pointer to the specified position in the list. A variable of type POSITION is a key for the list. It is not the same as an index, and you cannot operate on a POSITION value yourself.

You must ensure that your POSITION value represents a valid position in the list. If it is invalid, then the Debug version of the MFC for Windows CE asserts.
