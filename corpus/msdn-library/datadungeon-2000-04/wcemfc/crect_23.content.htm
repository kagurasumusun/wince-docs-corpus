CRect::operator LPCRECT

This operator converts a CRect object to an LPCRECT. When you use this method, you do not need the address-of (&) operator. This operator will be automatically used when you pass a CRect object to a method that expects an LPCRECT.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
