CWnd::OnPaint

This method is called by the framework when Windows CE or an application makes a request to repaint a portion of an application’s window.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

afx_msg void OnPaint( );

See Also

CWnd::BeginPaint, CWnd::EndPaint, CWnd::RedrawWindow, CPaintDC, CView::OnDraw
