CToolBar::SetSizes

This method sets the toolbar's buttons to the size, in pixels, specified in sizeButton. The sizeImage parameter must contain the size, in pixels, of the images in the toolbar's bitmap.

At a Glance

Header file: Afxext.h
Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation

Syntax

void SetSizes( SIZE sizeButton, SIZE sizeImage );
