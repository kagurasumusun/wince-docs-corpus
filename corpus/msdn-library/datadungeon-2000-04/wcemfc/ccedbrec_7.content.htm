CCeDBRecord::GetNumProps

This method retrieves the number of properties to which the record holds pointers.

At a Glance

Header file: Wcedb.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.0 and later

Syntax

int GetNumProps( ) const;

Return Values

The number of properties belonging to the record.
