CDocument::DeleteContents

This method is called by the framework to delete the document’s data without destroying the document object itself. The default implementation of this method does nothing. Override this method to delete the data in your document.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation
