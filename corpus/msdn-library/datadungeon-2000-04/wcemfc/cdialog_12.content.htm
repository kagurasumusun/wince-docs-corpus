CDialog::OnCancel

This method is called by the framework when the user clicks the Cancel button or presses the ESC key in a modal or modeless dialog box.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual void OnCancel( );
