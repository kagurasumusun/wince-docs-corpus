CToolBar::LoadBitmap

This method loads the bitmap specified by lpszResourceName or nIDResource. The bitmap should contain one image for each toolbar button. If the images are not of the standard size (16 pixels wide and 15 pixels high), call SetSizes to set the button sizes and their images.
