CDialog::OnOK

This method is called by the framework when the user clicks the OK button (the button with an identifier of IDOK).

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual void OnOK( );
