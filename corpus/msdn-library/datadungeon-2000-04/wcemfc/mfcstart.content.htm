Welcome to the Microsoft Foundation Classes for Windows CE.

The Microsoft Foundation Class Library for Windows CE Version 2.10 contains all the classes and global functions you need to develop applications for platforms that run Windows CE.

The Microsoft Foundation Class Library for Windows CE includes new classes and member functions for Windows CE version 2.10. MFC for Window CE now includes support for color, printing, and the Internet.

The MFC for Windows CE documentation is HTML-based. You can start reading now by clicking on one of the categories you see at the right.

For the latest information about developing for Windows CE, visit the Microsoft Windows CE World Wide Web site, http://www.microsoft.com/ windowsce/developer.


MFC for Windows CE Programmer's Guide
Describes the new classes that are unique to Windows CE and explains the differences between MFC for Windows CE and the standard MFC library.

MFC for Windows CE Sample Code
Describes the sample applications provided with MFC for Windows CE 2.10. These samples illustrate various aspects of developing applications for Windows CE-based platforms using MFC.

MFC for Windows CE Reference
Includes reference documentation for all the classes in the MFC for Windows CE library.
