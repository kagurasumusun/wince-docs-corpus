Classes Derived from CObject

Most of the classes in the Microsoft Foundation Class library are derived from the root class, CObject. These classes can be divided into the following categories:

Application Architecture Classes List Classes
Exception Classes Map Classes
File Service Classes Internet Services Classes
Graphical Drawing Classes Window Class Categories
Control Support Classes Frame Windows and Splitter Windows
Graphical Drawing Object Classes Control Bar Classes
Menu Classes Property Sheets
Windows CE Database Classes Dialog Box Classes
Synchronization Classes View Classes
Windows Sockets Classes Control Bar Classes
Array Classes
