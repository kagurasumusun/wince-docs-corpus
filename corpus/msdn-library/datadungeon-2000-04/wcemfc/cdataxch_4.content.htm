CDataExchange::PrepareEditCtrl

This method is called by the framework to prepare the specified edit control for dialog data exchange (DDX) and validation (DDV).

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

HWND PrepareEditCtrl( int nIDC ); throw( CNotSupportedException );
