CDocument::SetTitle

This method specifies the document’s title (the string displayed in the title bar of a frame window). Calling this method updates the titles of all frame windows that display the document.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual void SetTitle( LPCTSTR lpszTitle );
