CArray::GetData

This method gains direct access to the elements in an array. If no elements are available, GetData returns a null value.

At a Glance

Header file: Afxtempl.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation
