CHttpConnection::CHttpConnection

This constructor constructs a CHttpConnection object. You never create a CHttpConnection directly. Rather, you create an object by calling CInternetSession::GetHttpConnection.

At a Glance

Header file: Afxinet.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later.
