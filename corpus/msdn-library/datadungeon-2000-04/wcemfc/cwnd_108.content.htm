CWnd::OnCopyData

This method copies data from one application to another. This method is called by the framework to allow your application to handle a Windows message.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL OnCopyData( CWnd* pWnd, COPYDATASTRUCT* pCopyDataStruct );
