Graphical Drawing Object Classes

MFC for Windows CE supports all the graphical drawing object classes that standard MFC does, but because Windows CE does not support polygonal regions, the class implementations are somewhat different.

For information about the MFC for Windows CE graphical drawing object classes, see the following topics:

  • CBitmap
  • CBrush
  • CFont
  • CGdiObject
  • CPalette
  • CPen
  • CRgn

For information about where the graphical drawing object classes fit into the Windows CE class hierarchy, see Classes Derived from CObject.
