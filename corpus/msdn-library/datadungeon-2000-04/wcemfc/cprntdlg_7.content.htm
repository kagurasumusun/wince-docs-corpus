CPrintDialog::GetMargins

This method retrieves the margins of the printer device driver.

At a Glance

Header file: Afxdlgs.h
Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.10 and later

Syntax

void GetMargins(LPRECT lpRectMargins, LPRECT lpRectMinMargins)
const;

Parameters

lpRectMargins
Long pointer to a RECT structure or CRect object that describes (in 1/1000 inches or 1/100 mm) the print margins for the currently selected printer. Pass NULL for this parameter if you are not interested in this rectangle.
lpRectMinMargins
Long pointer to a RECT structure or CRect object that describes (in 1/1000 inches or 1/100 mm) the minimum print margins for the currently selected printer. Pass NULL for this parameter if you are not interested in this rectangle.

Return Values

None.

Remarks

GetMargins serves the same role as the CPageSetupDialog::GetMargins method does in Windows-based desktop platforms.
