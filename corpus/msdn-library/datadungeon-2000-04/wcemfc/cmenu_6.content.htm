CMenu::CheckMenuRadioItem

This method checks a specified menu item and make it a radio item. At the same time, the method unchecks all other menu items in the associated group and clears the radio-item type flag for those items.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL CheckMenuRadioItem( UINT nIDFirst, UINT nIDLast,
UINT nIDItem, UINT nFlags );
