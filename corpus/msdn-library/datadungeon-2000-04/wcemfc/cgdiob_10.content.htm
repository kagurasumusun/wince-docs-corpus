CGdiObject::GetObjectType

This method retrieves the type of the specified object.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

UINT GetObjectType ( ) const;

Remarks

Windows CE 1.0 does not support the following return values:

  • OBJ_ENHMETADC
  • OBJ_ENHMETAFILE
  • OBJ_EXTPEN
  • OBJ_METADC
  • OBJ_METAFILE
  • OBJ_PAL
