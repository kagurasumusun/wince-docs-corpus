CFileException

A CFileException object represents a file-related exception condition.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Remarks

MFC for Windows CE does not support the following methods of the CFileException class:

  • ClassName::ErrnoToException
  • ClassName::ThrowErrno
