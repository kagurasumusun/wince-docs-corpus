CConnectionPoint

This class defines a special type of interface used to communicate with other OLE objects, called a "connection point." Unlike normal OLE interfaces, which are used to implement and expose the functionality of an OLE control, a connection point implements an outgoing interface that is able to initiate actions on other objects, such as firing events and change notifications.
