CRect::IsRectNull

This method determines whether the top, left, bottom, and right values of CRect are all equal to zero. This method differs from IsRectEmpty, which determines whether the rectangle is empty.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax
