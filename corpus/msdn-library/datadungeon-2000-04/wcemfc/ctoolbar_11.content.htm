CToolBar::GetToolBarCtrl

This method allows direct access to the underlying common control.

Use GetToolBarCtrl to take advantage of the functionality of the Windows CE toolbar common control, and to take advantage of the support CToolBarCtrl provides for toolbar customization.

At a Glance

Header file: Afxext.h
Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation
