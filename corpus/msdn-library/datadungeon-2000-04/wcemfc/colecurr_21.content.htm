COleCurrency::CurrencyStatus

This enumeration specifies the values that can be used in the COleCurrency::m_status data member to indicate whether the COleCurrency::m_cur data member contains a valid value. This enumeration is used with the COleCurrency::GetStatus and COleCurrency::SetStatus methods.

At a Glance

Header file: Afxdisp.h
Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.0 and later

Syntax

enum CurrencyStatus{ valid = 0, invalid = 1, null = 2, };
