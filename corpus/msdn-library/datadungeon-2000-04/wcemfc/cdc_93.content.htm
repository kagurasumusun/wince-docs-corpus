CDC::m_hAttribDC

This data member contains the attribute device context for this CDC object. By default, this device context is equal to m_hDC.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

HDC m_hAttribDC;

See Also

CDC::m_hDC, CDC::SetAttribDC, CDC::ReleaseAttribDC
