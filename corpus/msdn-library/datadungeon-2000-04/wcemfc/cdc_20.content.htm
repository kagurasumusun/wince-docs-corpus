CDC::EndPage

This method informs the device that the application has finished writing to a page. This method is typically used to direct the device driver to advance to a new page.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation

Syntax

int EndPage( );
