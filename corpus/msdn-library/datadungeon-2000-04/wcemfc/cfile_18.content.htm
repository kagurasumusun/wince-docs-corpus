CFile::SeekToBegin

This method sets the value of the file pointer to the beginning of the file. SeekToBegin is equivalent to Seek( 0L, CFile::begin ).

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax
