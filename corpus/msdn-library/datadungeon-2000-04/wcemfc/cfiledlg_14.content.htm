CFileDialog::OnInitDone

Override this method to handle the CDN_INITDONE notification message. The notification message is sent when the system has finished arranging controls in the Open or Save As dialog box to make room for the controls of the child dialog box.

At a Glance

Header file: Afxdlgs.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
