CWinApp::ProcessMessageFilter

This method does not do anything in Windows CE. MFC for Windows CE supports this method solely for compatibility with existing code.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual BOOL ProcessMessageFilter ( int code, LPMSG lpMsg );

Remarks

Windows CE does not support hooking messages because the extra processing required by hooks could seriously degrade the performance of Windows CE-based devices. MFC for Windows CE supports the CWinApp::ProcessMessageFilter method for compatibility with existing code, but this method does not do anything. It just returns FALSE.
