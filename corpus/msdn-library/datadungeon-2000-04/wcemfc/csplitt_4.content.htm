CSplitterWnd::CanActivateNext

This method is called by the framework to determine whether it is currently possible to invoke the Next Pane or Previous Pane command.

At a Glance

Header file: Afxext.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual BOOL CanActivateNext( BOOL bPrev = FALSE );

See Also

CSplitterWnd::ActivateNext, CSplitterWnd::SetActivePane
