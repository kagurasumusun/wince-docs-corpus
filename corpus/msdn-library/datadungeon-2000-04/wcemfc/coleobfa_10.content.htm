COleObjectFactory::UpdateRegistryAll

This method registers all of the application's object factories with the system registry. This method is usually called by CWinApp::InitInstance when the application is launched.

Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.0 and later
