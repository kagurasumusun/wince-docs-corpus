CCtrlView

This class and its derivatives, CEditView, CListView, and CTreeView, adapt the document-view architecture to the common controls supported by Windows CE.

At a Glance

Header file: Afxext.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation
