CRect::UnionRect

This method makes the dimensions of a CRect object equal to the union of the two source rectangles. The union is the smallest rectangle that contains both source rectangles.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL UnionRect( LPCRECT lpRect1, LPCRECT lpRect2 );
