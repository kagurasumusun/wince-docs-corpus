CString::ReverseFind

This method searches this CString object for the last match of a substring. The method is similar to the strrchr run-time function.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

int ReverseFind( TCHAR ch ) const;

See Also

CString::Find, CString::FindOneOf
