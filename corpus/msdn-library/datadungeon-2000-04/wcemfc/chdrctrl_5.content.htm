CHeaderCtrl::DrawItem

This method is called by the framework when a visual aspect of an owner-draw header control changes. The itemAction member of the DRAWITEMSTRUCT structure defines the drawing action that is to be performed.

At a Glance

Header file: Afxcmn.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax
