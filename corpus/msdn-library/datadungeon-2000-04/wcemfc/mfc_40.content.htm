Unique MFC Classes for Windows CE

The following classes are unique to Windows CE. The CCeDB* classes provide support for creating and accessing Windows CE databases in the object store. The CCeSocket class provides asynchronous notification for certain socket events. The CCeCommandBar class encapsulates a Windows CE command bar.

  • CCeDBDatabase
  • CCeDBEnum
  • CCeDBProp
