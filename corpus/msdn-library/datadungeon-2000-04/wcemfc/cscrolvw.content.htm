CScrollView

This class is a CView with scrolling capabilities.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Remarks

Because MFC for Windows CE only supports the MM_TEXT map mode, it supports the following methods of the CScrollView class differently than standard MFC:

  • CScrollView::SetScaleToFitSize
  • CScrollView::SetScrollSizes
  • CScrollView::GetDeviceScrollSizes
