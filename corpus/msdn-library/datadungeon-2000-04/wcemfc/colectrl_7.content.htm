COleControl::AmbientLocaleID

This method returns the container’s locale identifier.

At a Glance

Header file: Afxctl.h
Platforms: H/PC 2.0, H/PC Pro
Windows CE versions: 2.0 and later
Complete documentation: Visual C++ documentation

Syntax

LCID AmbientLocaleID( );

Remarks

MFC for Windows CE only supports the AmbientLocaleID method if the OLEAMBIENTTHEREADLOCALE flag is not defined.
