CWindowDC

This class is derived from CDC. It calls the Windows CE GetWindowDC function at construction time and ReleaseDC function at destruction time.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation
