MFC Global Functions

MFC for Windows CE supports a global function called AfxGetCeSocketWindow. Use this function to retrieve a window handle to which you can send socket notifications.

Because MFC for Windows CE does not support Gopher or FTP Internet protocol, it supports the AfxParseURL global function differently than the standard MFC library does.
