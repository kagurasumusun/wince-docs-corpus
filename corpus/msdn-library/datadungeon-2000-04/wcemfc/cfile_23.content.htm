CFile::Write

This method writes data from a buffer to the file associated with the CFile object.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual void Write( const void* lpBuf, UINT nCount ); throw( CFileException );

Remarks

You can use the Cfile::Open method to write to files in the Windows CE object store.
