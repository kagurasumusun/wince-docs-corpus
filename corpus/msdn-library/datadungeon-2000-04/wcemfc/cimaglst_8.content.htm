CImageList::Detach

This method detaches an image list object from a CImageList object. This method returns a handle to the image list object.

At a Glance

Header file: Afxcmn.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

HIMAGELIST Detach( );

See Also

CImageList::Attach, CImageList::DeleteImageList
