CWinThread::ExitInstance

This method is called by the framework to exit this instance of the thread. It is called either from within the rarely overridden Run method, or if a call to InitInstance fails.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual int ExitInstance( );
