COleDateTimeSpan::DateTimeSpanStatus

This enumeration specifies the values that can be used in the COleDateTimeSpan::m_status data member to indicate whether the COleDateTimeSpan::m_span data member contains a valid value. This enumeration is used with the COleDateTimeSpan::GetStatus and COleDateTimeSpan::SetStatus methods.
