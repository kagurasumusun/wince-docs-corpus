CListBox::SetItemHeight

This method sets the height of all items in the list box.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

int SetItemHeight ( int nIndex, UINT cyItemHeight );

Remarks

Because Windows CE does not support owner-drawn list boxes, there is no reason to specify an item index in the nIndex parameter. Always set the index parameter to zero.
