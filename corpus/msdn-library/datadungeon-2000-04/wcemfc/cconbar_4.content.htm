CControlBar::EnableDocking

This method enables a control bar to be docked. The sides specified must match one of the sides enabled for docking in the destination frame window, or the control bar cannot be docked to that frame window.

At a Glance

Header file: Afxext.h
Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation

Syntax

void EnableDocking( DWORD dwStyle );
