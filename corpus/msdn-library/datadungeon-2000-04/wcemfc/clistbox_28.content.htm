CListBox::InitStorage

This method allocates memory for storing list-box items.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

int InitStorage ( int nItems, UINT nBytes )

Remarks

Windows CE calculates the amount of memory to allocate. The nBytes parameter is not used. Set the nBytes parameter to zero.
