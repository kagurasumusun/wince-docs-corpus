CWnd::OnSysKeyUp

This method is called by the framework, if the CWnd object has the input focus, when the user releases a key that was pressed while the ALT key was held down. If no window currently has the input focus, the active window’s OnSysKeyUp method is called. The CWnd object that receives the call can distinguish between these two contexts by checking the context code in nFlags.
