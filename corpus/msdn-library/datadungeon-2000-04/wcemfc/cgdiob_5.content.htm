CGdiObject::DeleteObject

This method deletes the GDI object by freeing all system storage associated with it.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL DeleteObject ( );

Remarks

In Windows CE, if the GDI object is currently selected into a device context, this method returns FALSE.
