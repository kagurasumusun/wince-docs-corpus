CWnd::GetParentFrame

This method retrieves the parent frame window. The method searches up the parent chain until a CFrameWnd (or derived class) object is found.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

CFrameWnd* GetParentFrame( ) const;
