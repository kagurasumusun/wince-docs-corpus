CTimeSpan::GetSeconds

This method retrieves the number of seconds in the current minute represented by this CTimeSpan object. The range is –59 through 59.

At a Glance

Header file: Afx.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation
