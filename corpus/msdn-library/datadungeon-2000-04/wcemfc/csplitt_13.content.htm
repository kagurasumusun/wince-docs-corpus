CSplitterWnd::DoScroll

This method is called by the framework to perform synchronized scrolling of split windows when the view receives a scroll message.

At a Glance

Header file: Afxext.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

virtual BOOL DoScroll( CView* pViewFrom, UINT nScrollCode,
BOOL bDoScroll = TRUE );
