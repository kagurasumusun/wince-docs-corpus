CRgn::SetRectRgn

This method creates a rectangular region. The CRgn object must already have been initialized before calling SetRectRgn.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void SetRectRgn ( int x1, int y1, int x2, int y2 );

void SetRectRgn( LPCRECT lpRect );

Remarks

The CRgn::SetRectRgn method is included for compatibility with existing code. The CRgn::SetRectRgn method in Windows CE just calls CRgn::CreateRectRgn; you do not save a memory allocation by using this method.
