CRect::operator !=

This operator determines whether rect is not equal to the CRect object by comparing the coordinates of their upper-left and lower-right corners.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

BOOL operator !=( const RECT& rect ) const;
