CStatusBarCtrl::SetText

This method set the text in the specified part of a status bar control. The message invalidates the portion of the control that has changed, causing it to display the new text when the control next receives the WM_PAINT message.

At a Glance

Platforms: Palm-size PC, H/PC Pro
Windows CE versions: 2.10 and later
Complete documentation: Visual C++ documentation
