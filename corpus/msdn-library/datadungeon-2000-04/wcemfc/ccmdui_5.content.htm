CCmdUI::SetCheck

This method sets the user-interface item for this command to the appropriate check state. This method works for menu items and toolbar buttons. The indeterminate state applies only to toolbar buttons.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax
