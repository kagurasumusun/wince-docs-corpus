CEdit

This class encapsulates the functionality of a Windows CE edit control, which is a rectangular child window in which a user can enter text.

At a Glance

Header file: Afxwin.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

See Also

CWnd, CButton, CComboBox, CListBox, CScrollBar, CStatic, CDialog, Control Classes

Remarks

MFC for Windows CE does not support the following methods of the standard MFC ClassName class:

  • CEdit::GetHandle
  • CEdit::SetHandle
