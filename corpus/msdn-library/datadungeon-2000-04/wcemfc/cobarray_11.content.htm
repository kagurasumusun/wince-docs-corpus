CObArray::GetUpperBound

This method retrieves the current upper bound of this array. Because array indexes are zero-based, this method returns a value 1 less than GetSize.

At a Glance

Header file: Afxcoll.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
