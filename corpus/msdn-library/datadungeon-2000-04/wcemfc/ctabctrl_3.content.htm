CTabCtrl::AdjustRect

This method calculates a tab control’s display area given a window rectangle, or to calculate the window rectangle that would correspond to a specified display area.

At a Glance

Header file: Afxcoll.h
Platforms: H/PC 2.0, Palm-size PC, H/PC Pro
Windows CE versions: 1.0 and later
Complete documentation: Visual C++ documentation

Syntax

void AdjustRect( BOOL bLarger, LPRECT lpRect );
