Samples

The following samples are provided to demonstrate how to use the ADO for Windows® CE control:

  • ADODemo.vbp

    This is a one-form sample that demonstrates how ADOCE is implemented in an application. The application allows you to open and modify tables and send SQL statements to a recordset.

  • EmulDB.vbp

    This sample application converts a desktop database in .mdb format to .cdb format and installs the .cdb file in the object store of the desktop emulator.

These samples run on the H/PC 2.0 platform and will run in the H/PC 2.0 emulator. Both samples can be easily ported to other Windows CE platforms. The samples are located in the \Program Files\Microsoft Visual Studio\Common\ADOCE\Samples\VB directory.
