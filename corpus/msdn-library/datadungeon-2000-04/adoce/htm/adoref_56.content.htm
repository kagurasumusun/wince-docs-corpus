CREATE DATABASE

This statement is used to create a database on the device

Syntax

CREATE DATABASE 'database_name.cdb'

Parameters

database_name.cdb

Specifies the name of the database to be created. This name must be in single quotes and have the .cdb file extension.

Remarks

An ADO database is created in the object store with the name database_name.cdb.

This statement is available on the following platforms: H/PC Pro, P/PC 1.2, and Platform Builder 2.12.

Example

Dim rs, i, L1
Set rs = CreateObject("adoce.recordset")
rs.Open "create database 'myDatabase.cdb'"
rs.Close
Set rs = Nothing
