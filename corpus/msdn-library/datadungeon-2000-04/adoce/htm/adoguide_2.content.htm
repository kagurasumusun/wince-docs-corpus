Data Conversion

When a database is moved between the desktop computer and a Windows CE–based device, the data must be converted from one database format to another. Data exported to the desktop computer is converted into Microsoft Access database format with an .mdb file extension. Data imported to the device is converted into a proprietary database format with a .cdb file extension. The two database file formats are not compatible with each other. For more information on issues that arise when converting databases between the desktop computer and a device, see the following topics:

  • Converting Data to the Device

  • Converting Data to the Desktop

  • The Conversion Log and Error Notification

For procedures describing how to export and import a database between the desktop computer and device, see Exporting and Importing a Database.
