H/PC Remote Tools

A remote tool is an application that allows you to access a remote computer as though it were an H/PC device. Although they are included in the Windows CE toolkits, the remote tools are considered to be separate applications. The following table shows the remote tools.

Remote tool
Description
Remote CE Heap Walker Enables you to view detailed information about heap identifiers and flags for processes that are running on a remote platform. The Windows CE Heap Walker is a useful tool to determine if an application has memory leaks.
Remote CE Object Viewer Displays a hierarchical view, on the desktop computer, of the Windows CE object store. The Remote Object Viewer enables you to transfer objects between the emulation object store and the remote platform.
Remote CE Process Viewer Displays a graphical view of Windows CE process and thread characteristics. The Process Viewer enables you to view memory usage and search for memory leaks.
Remote CE RegEdit Manages remote platform registry entries from the desktop computer.
Remote CE Spy Displays a graphical view, on the desktop computer, of Windows CE system processes, threads, windows, and window messages running on the remote platform.
Remote CE Zoom Captures an image from the remote platform and displays it on the desktop computer.

For more information, see the Windows CE Toolkits H/PC Emulator.

The Microsoft ®Windows® CE Platform SDK, Handheld PD Edition, Version 2.0 includes an emulator. The emulator acts as a virtual H/PC on your desktop computer. Like the remote tools, you can use the emulator through the IDE, or you can access it through the Start menu. The Emulator comes with a virtual registry editor.
