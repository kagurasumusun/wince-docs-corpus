DEFCOLWIDTH: Default Column Width (55h) [PXL 2.0]

The DEFCOLWIDTH record contains the default column width.

Record Data

Offset
Name
Size
Contents
0 grbit 2 Flags
2 coldx 2 Column width, in characters
4 ixfe 2 Format index

Parameters

grbit
The grbit parameter is structured as follows:
Bit
Size
Name
Contents
0 1 fHidden Set if column is hidden
1 1 fUserSet Set if the column width had been set by the user
