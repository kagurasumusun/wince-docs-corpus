Replaced Tokens

When Microsoft Pocket Word 2.0 opens a document, it will treat some tokens as other recognized tokens. When saving the document, the original token will not be written to the file, and another token will be written in its place.

Example

Section Default \sectd is replaced with Paragraph Default \pard

Microsoft Pocket Word 2.0 does not support Sections in documents. So any Section Default tokens found when opening a document will be saved later as Paragraph Default tokens.
