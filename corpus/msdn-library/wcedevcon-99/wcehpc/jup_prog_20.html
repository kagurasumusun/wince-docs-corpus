Converting Rich Ink Data

The Rich Ink control stores data in an internal .PWI file format.

    To convert .PWI data to a RTF or text file format

  1. Load the RichInk .dll

    2.Create a RichInk control

  2. Send an EM_STREAMIN message with the SendMessage function to stream the RichInk data in from a memory block
  3. Send an EM_STREAMOUT message with SendMessage to determine the size of the converted text.
  4. Allocate memory for the converted text
  5. Steam the converted text to the memory you allocated
