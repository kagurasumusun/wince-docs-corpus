Developer’s Tools

An H/PC supports a wide variety of programming tools for different languages. Currently, Microsoft provides toolkits, remote tools, and emulators.

Windows CE Toolkits for the H/PC

A toolkit is a set of Help files, programming tools, samples, and other routines designed to help you write applications in a specific programming language. Microsoft toolkits for Windows CE are integrated into the Microsoft® Visual Studio™ . You can access a toolkit through the integrated development environment (IDE). Portions of the toolkit may also be accessed separately through the Start menu. The following table shows the toolkits currently available for programming an application for an H/PC.
