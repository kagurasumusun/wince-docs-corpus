TransportCopy

This function copies a message to a folder on a mail server.

At a Glance

Header file: Msgstor2.h
Platforms: H/PC Pro
Windows CE versions: 2.10 and later

Syntax

BOOL TransportCopy(HANDLE hService, MailMsg *MsgPtr,
LPWSTR szDestFolderID);

Parameters

hService
[in] Handle to a private SERVICE structure.
MsgPtr
[in] Pointer to the MailMsg structure. The szSvcID member of MailMsg specifies the service identifier of the message to be copied.
szDestFolderID
[in] Null-terminated string that contains the identifier of the destination folder.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call the function TransportError or TransportErrorMsg.

Remarks

The transport service provider must implement this function in a DLL registered as a mail service. The Inbox application can then load this DLL and call this function.
