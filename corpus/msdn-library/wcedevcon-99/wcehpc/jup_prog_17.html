Programming H/PC Controls

Windows CE 2.10 contains two unique controls: the Rich Ink control and the HTML control. The following section discusses how to create and use these controls.

Programming a Rich Ink Control

A Rich Ink control enables a user to write and draw on the touch-sensitive screen of an H/PC with a stylus or other pointing device. A Rich Ink control provides a convenient means for applications to accept input from a user without using a keyboard. For a user, taking notes or drawing sketches with a Rich Ink control is very much like writing or drawing on paper.

In addition to capturing images, a Rich Ink control provides powerful editing and formatting capabilities. For example, when a user deletes a word from handwritten notes on the screen, the control automatically closes the resulting word gap. An application can use a Rich Ink control in the following ways:

  • An electronic form application can accept a user’s handwritten signature.
  • A calendar application with an embedded Rich Ink control can allow a user to jot down a “To Do” list for a selected date.

Once a user has added data using a Rich Ink control, you can translate that data into an RTF or text file.
