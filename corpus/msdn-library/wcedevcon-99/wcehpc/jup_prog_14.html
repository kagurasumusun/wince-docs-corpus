Registry Settings

Windows CE 2.10 comes with a variety of options for mail transport services. These options include the following registry settings.

  • HKEY_LOCAL_MACHINE\PMail\ServiceLibs\[ServiceType]
    \NewHierarchy

    If an application or user sets this DWORD key as a nonzero value, every service of this type is allocated a separate folder hierarchy in the message store. These folder hierarchies have the same name as the corresponding mail service name. If this key is 0, services of this type use the Mailbox hierarchy. The OS writes this registry key as 0 by default.

  • HKEY_LOCAL_MACHINE\PMail\ServiceInfo\[ServiceName]
    \InboxOnly

    If an application or user sets this DWORD key as a nonzero value, the client operates only on the Inbox folder subtree of the specified service. If this key is 0, the client operates on the whole folder hierarchy. The system writes this registry key as 0 by default. A Service DLL that allows a user to specify this option must implement the TransportGetInboxId function.

Note Windows CE 2.10 ignores the GrabRead registry option. When Windows CE 2.10 reads a message from a service, the message body is always placed in the local store.
