Using A Rich Ink Control

After initialization, a Rich Ink control communicates with the calling application using the standard Windows CE messaging system. Specifically, the control performs the following tasks:

  • Sends the IM_SHOWCMDBAR message to the Rich Ink control to show or hide the command bar.
  • Sends the IM_GETDATALEN, IM_GETDATA, and IM_SETDATA messages between the Rich Iink control and the application to transmit inking data, such as notes or a sketch.
  • Sends the IM_REINIT message to the Rich Ink control to erase all the content from the control.
  • Sends the standard EM_GETMODIFY and EM_SETMODIFY messages to the Rich Ink control to determine if the Rich Ink content has been modified and to set the modification flag in the control, respectively.
