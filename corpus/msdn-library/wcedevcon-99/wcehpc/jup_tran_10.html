TransportFreeFolderID

This function frees storage allocated by TransportGetFolderId or TransportPutFolder.

At a Glance

Header file: Msgstor2.h
Platforms: H/PC Pro
Windows CE versions: 2.10 and later

Syntax

BOOL TransportFreeFolderID(HANDLE hService, LPWSTR szFolderID);

Parameters

hService
[in] Handle to a private SERVICE structure.
szFolderID
[in] Null-terminated string that contains the identifier of a folder for which storage was allocated by the function TransportGetFolderId or TransportPutFolder.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call the function TransportError or TransportErrorMsg.

Remarks

The transport service provider must implement this function in a DLL registered as a mail service. The Inbox application can then load this DLL and call this function.
