Running Media Player from an MS-DOS prompt or command line

To run Media Player from an MS-DOS prompt or command line

Type mplayer2. The player window opens.

To start playing a specific media file as soon as the player window opens, type the path or URL to the media file after the command mplayer2. For example:

mplayer2 http://webserver/directory/file name

mplayer2 drive:\directory\file name
