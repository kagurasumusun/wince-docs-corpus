Introducing Windows Media Player

Microsoft Windows Media Player is a universal tool you can use to receive audio, video, and mixed-media files in most popular formats. As you play a file, Media Player's controls work like those of a CD player.

· To close the player, right-click in the player window, and then click Close.

· This is a custom version of Media Player. To use the standard Windows Media Player, click the Start button, click Run, and then type mplayer2.exe.
