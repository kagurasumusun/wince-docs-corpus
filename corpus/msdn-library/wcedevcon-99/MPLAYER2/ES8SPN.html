Using the Seek bar

To use the Seek bar

The Seek bar appears above the controls in the player window, if it is included in the current view and media file. The Seek bar indicates the progress of the current clip.

To select a place in the clip to start playing, drag the progress indicator on the Seek bar. You can move backward or forward in a clip.

Note

· The Seek bar is unavailable in some media files and if media content is live.
