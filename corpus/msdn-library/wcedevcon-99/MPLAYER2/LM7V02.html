Navigating to marked sections in a media file

To navigate to marked sections in a media file

Sometimes media files will contain markers, which are like tracks on a compact disc. When you select a marker from a list, Media Player begins playing the section of the media file associated with that marker.

1 On the Play menu, click Go To.

2 Double-click the marker indicating the section you want to begin playing.

Tip

· If the Go To bar appears in the player window, you can open the list of markers by clicking the arrow in the Go To bar.
