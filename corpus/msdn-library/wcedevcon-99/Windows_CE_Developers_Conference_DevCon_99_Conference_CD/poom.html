Pocket Outlook Object Model (POOM) SDK 

The POOM SDK integrates seamlessly into Microsoft Windows CE Toolkits for Visual Basic or Visual C++ and provides innovative Pocket Outlook features for streamlining business and personal information management applications running on Windows CE devices.

Installation Requirements

The following are required to install and run the POOM SDK:

  • Windows 95/98 or Windows NT
  • Microsoft Visual C++ 6.0 or Visual Basic 6.0
  • Windows CE Toolkit for Visual C++ 6.0 or Visual Basic 6.0
  • A Windows CE Palm-size PC, Handheld PC or Handheld PC (Professional)
    (The POOM SDK does not support Windows CE emulation.)
  • PC with 486/66 MHz or higher processor
  • 24 MB RAM (32 MB recommended)
  • 40 MB Hard-Disk space
  • CD-ROM drive compatible with multimedia PC specifications
  • Microsoft Mouse or equivalent pointing device
  • VGA or higher-resolution monitor (Super VGA recommended).

Installation and Setup

The POOM SDK is shipped as a self-extracting, executable file. To install, simply run the file from the link below. When prompted, specify a directory for extracted content, then follow the instructions accompanying the README.TXT file.
