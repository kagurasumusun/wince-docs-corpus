Kingston CompactFlash™ Card Selected for Windows CE Promotion

Limited time offer allows customers of Windows CE s to receive
8MB of free Kingston® CompactFlash memory

Fountain Valley, CA – April 5, 1999 - Kingston® Technology Company today announced Microsoft Corp.® has selected Kingston’s CompactFlash as a featured product for their national Spring Promotion and print campaign.

Now running, Microsoft Windows CE Special Spring Promotion, grants any customer who purchases a Handheld PC powered by the Windows CE operating system the opportunity to receive an 8MB Kingston CompactFlash memory card with a Type II PC Card Adapter (Part#: CF/8ADP) and Microsoft Expedia Streets and Trips 2000. The customer must fill out a coupon and submit it with proof of purchase from their Windows CE-based device in order to claim their prize. The promotion will last through June 30, 1999. For more information visit the Windows CE web site at http://www.microsoft.com/windowsce/products/

"CompactFlash cards provide a great way for customers to expand their Windows CE-based information appliances," said Shawn McMichael, group product manager, information appliances division, Microsoft Corp. "They enable users to store additional digital images, play music and load extra third-party applications which add versatility and power to these smart devices."

"Flash memory plays a vital role in devices such as Handheld PCs and electronic notebooks, not only by enhancing the performance, but also by providing additional storage capabilities for the device," noted Chris Wong, product manager, peripherals division, Kingston. "Kingston’s CompactFlash memory is put through the same rigorous testing procedures as its memory for standard systems and demonstrates quality equal to all memory under the Kingston brand."

About Kingston’s CompactFlash Memory

As with all of Kingston’s flash memory products, CompactFlash memory cards are optimized to provide fast digital image and data-write performance. At one-third the size of a full-size PC Card, CompactFlash cards paired with the PC Card Type II adapter simplify data transfer from a handheld PC to a desktop. The cards’ plug and play capability instantly adds memory and increased performance to devices such as Handheld PCs, personal digital assistants, electronic notebooks, digital cameras and cellular telephones. Kingston’s Flash products support the latest operating systems, including Windows 95, Windows 98, Windows NT, Macintosh OS and OS/2® Warp. For more information on Kingston’s flash memory products, visit the Kingston web site at www.kingston.com/flash.
