Kingston Announces Microsoft-Certified Plug-and-Play
Ethernet Adapter Line Featuring Easiest Windows 95 Installation Available

Fountain Valley, CA— (Feb. 1, 1996), Kingston Technology Corporation, the leading manufacturer of memory products and growing networking hardware manufacturer, today announced the introduction of a new line of Microsoft-Certified Plug-n-Play Ethernet adapters. The Kingston EtheRx PnP Ethernet adapters are fully compliant with current Plug-and-Play standard 1.0A and feature the easiest Windows 95 installation available.

To make installation as easy as possible, Plug-n-Play operating systems like Windows 95 are already shipping with built in driver support for the EtheRx PnP adapters. This allows the Kingston Adapter to be dynamically configured by the Operating System with no user intervention -- a sharp contrast to many competitors whose product requires the user to insert a driver diskette provided by the manufacturer. In close cooperation with Microsoft, Kingston has certified EtheRx PnP adapters with the Microsoft Compatibility Labs (MCL). This ensures absolute compatibility with Windows 95. A unique automedia detection feature introduced by Kingston allows the EtheRx PnP adapter to select the network media interface dynamically.

"Automedia detection eliminates the common requirement of restarting the computer in MS-DOS mode, running manufacturer-supplied setup software to change the connector type, and rebooting the computer," explained Jason Jacobi, Product Marketing Manager for the Kingston Technology Networking Business Unit. "The EtheRx PnP and Windows 95 combination is a perfect solution for users who are searching for a true Plug-n-Play configuration," Jacobi added.

For users with non-PnP operating systems, Kingston offers QStart, a unique configuration and diagnostic program with a PnP disable feature that allows the adapter to be installed in Standard NE2000 mode. This feature allows the EtheRx PnP adapter the flexibility to be installed in both PnP and non-PnP environments. The product is available in both a 10BASE-T only and a dual interface 10BASE-T and 10BASE2 version. With EtheRx PnP, one adapter will meet a variety of Ethernet adapter requirements, thus allowing system administrators to reduce and simplify adapter inventory. The multiple features built into the EtheRx PnP adapter makes it an Ethernet solution ideal for all types of PnP and non-PnP environments.

With sales of $1.3 billion for 1995, Kingston Technology Corporation is the recognized industry leader in memory upgrades for PC’s workstations and laser printers world-wide. The recent formation of the Kingston Networking Units marks the manufacturer’s successful entry into the Ethernet market. The firm markets its product through a worldwide network of distributors, major reseller chains and independent dealers. As a continuing demonstration of its commitment to service and quality on a global level, Kingston Technology Corporation became ISO 9001 certified in 1994.
