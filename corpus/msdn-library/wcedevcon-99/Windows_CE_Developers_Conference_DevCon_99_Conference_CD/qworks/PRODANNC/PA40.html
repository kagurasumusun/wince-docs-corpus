EtheRx PCI Ethernet Adapters

Release date: September, 1995
 

EtheRx PCI from Kingston Technology is a family of PCI bus low-cost Ethernet adapters. Available in a 10BASE-T and a dual-interface 10BASE-T and 10BASE2 interface version, each EtheRx PCI comes complete with ODI, NDIS2, NDIS3, SCO and Packet drivers for compatibility with all popular Network Operating Systems. EtheRx PCI features QStartTM an easy-to-use installation and diagnostic program that picks up where PCI leaves off. With just a few keystrokes or mouse clicks, QStart runs a four-step diagnostic program and loads the right driver for more than 30 Network Operating Systems. Each EtheRx PCI is individually tested and backed by a lifetime warranty.
