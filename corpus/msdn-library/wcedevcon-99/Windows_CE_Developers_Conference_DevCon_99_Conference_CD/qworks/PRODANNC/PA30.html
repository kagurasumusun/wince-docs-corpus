EtheRx Client PCI Ethernet Adapters

Release date: April, 1997
 

EtheRx Client PCI from Kingston Technology is a family of programmed I/O, PCI bus low-cost Ethernet adapters. Available in a 10Base-T and a dual-interface 10Base-T and 10Base2 interface version, each EtheRx Client PCI adapter comes complete with ODI, NDIS2, NDIS3, SCO and Packet drivers for compatibility with all popular Network Operating Systems. EtheRx Client PCI features Qstart, an easy-to-use installation and diagnostic program that picks up where PCI leaves off. With just a few keystrokes or mouse clicks, Qstart runs a four-step diagnostic program and loads the right driver for more than 30 Network Operating Systems. Each EtheRx Client PCI adapter is individually tested and backed by a lifetime warranty.
