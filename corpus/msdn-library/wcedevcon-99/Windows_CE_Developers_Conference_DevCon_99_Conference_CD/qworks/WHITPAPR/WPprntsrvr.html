Overview

Highlights

The Kingston Fast EtheRx 10/100TX Print Servers are: KNP101X and KNP103X. The KNP101X supports a UTP (Unshielded Twisted-Pair) connection designed for 10BASE-T or 100BASE-TX networks with one parallel port for a printer connection. The KNP103X supports a UTP (Unshielded Twisted-Pair) connection designed for 10BASE-T or 100BASE-TX networks with three parallel ports for up to three printer connections. Both models conform to IEEE 802.3u 100BASE-TX, IEEE802.3i 10BASE-T, and IEEE 802.3 Ethernet Standards.

The Fast EtheRx Print Servers offer auto negotiating for ease of installation. The UTP port can also be manually configured for 100 Mbps, 10 Mbps, half or full duplex operation.

What is a Print Server?

The Print Server is designed to provide simple and efficient printer sharing. All users on the LAN, regardless of operating system or network protocol, will be able to use the printer(s) connected to the Print Servers. By connecting your printers to a Print Server instead of a file server or workstation, you will off load system resources, increase printing performance and allow different network protocols to be used simultaneously.

Advantages of a Print Server

Printing is a fundamental function of any network. Users want to be able to print quickly and easily. Generally, users are connected to a printer via a networked PC or server. The following diagrams are examples of possible printing environments and the advantages and limitations of each.

 

Network is connected to the printer via a file server.

 

 

Advantage – This environment does not require any additional hardware to connect the printer to the network.

Limitation – The printer location is limited to the server room making it inconvenient to retrieve print jobs and/or perform trouble-shooting tasks. There is also additional workload being place on the file server thereby decreasing its performance and speed.

 

 

 

 

Network is connected to the printer via a PC dedicated print server

 

 

Advantage – The printer can be placed anywhere within 100 meters of the hub allowing for more flexibility. And, since the PC is used solely for the purpose of acting as a print server, the network is not bogged down with additional workload.

Limitation – There is the added cost of having to purchase and maintain a PC strictly for the purpose of acting as a print server. This requires finding room for the PC and leaving it running at all times. Should the PC go down, it needs to be replaced and reconfigured before users are able to print again.

 

 

 

Network is connected to the printer via a workstation on the network

 

Advantage – No additional hardware is required in this environment.

Limitation – The performance of the workstation is crippled due to the additional task of acting as a print server. The workstation has to be powered on at all times to provide printing to the rest of the network.

Choosing the print server environment

By utilizing a print server there is no need to spend additional money on a PC or extra energy leaving the PC running. Its small, lightweight form factor makes it easily mobile and able to fit anywhere. The printer can be placed within 100 meters of the hub offering even more flexibility. Since the print server takes on the total workload of the printing tasks, the network is free to operate at its maximum performance level. Incoming print jobs are handled concurrently preventing network bottlenecks. A print server also has the added advantage of remote manageability.

 

Kingston’s Fast EtheRx 10/100TX Print Servers

The Kingston Fast EtheRx 10/100TX Print Servers are available with either one or three parallel ports for up to three network printer connections. Both models support a UTP connection designed for 10BASE-T or 100BASE-TX networks. Dip-switches allow manual configuration of UTP port for 10Mbps, 100Mbps, half duplex, full duplex or auto-negotiation.

Kingston’s Print Servers have the unique feature of Internet Printing. This allows remote or offsite users to print to a desired site through Internet E-mail. Internet Printing eliminates low-resolution faxes that are difficult to read and do not produce clear copies. Also, users can produce hard copies quickly without having to spend extra money shipping them overnight. Or, work at home and send your work to the office with the click of a button.

Allowing for added flexibility, Kingston’s print servers include SNMP support for TCP/IP users with BiAdmin or WebAdmin management tools. SNMP or Simple Network Management Protocol allows users to monitor information or statistics of a network-connected device from a remote site. Using the SNMP feature with Kingston’s print servers allows management of such functions as configuration, reset, status (whether a port is online or offline) and statistics such as the number of packets the print server has sent/received.
