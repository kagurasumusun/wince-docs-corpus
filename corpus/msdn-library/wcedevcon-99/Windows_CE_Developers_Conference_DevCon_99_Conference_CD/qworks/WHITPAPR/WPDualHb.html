Overview
KND800TX, KND810TX, KND1610TX, KND2410TX

The Kingston EtheRx dual-speed Fast Ethernet stackable and workgroup hubs are Class compliant repeaters ideal for the small-office / home-office environment. The dual-speed 10/100BASE-TX hubs conform to IEEE802.3u 100BASE-TX, IEEE802.3i 10BASE-T, and IEEE802.3 CSMA/CD standards and are stackable up to a maximum of four (4) hubs. The KND800TX (workgroup form factor), KND810TX (Stackable), KND1610TX (Stackable) and KND2410TX (Stackable) offer eight (8), sixteen (16) or twenty four (24)  10/100Mbps UTP ports that auto-negotiate 10BASE-T and 100BASE-TX operation. The last port has an additional uplink port to support both crossover and straight-through cable wiring. Ideal for inter-connecting 10BASE-T Ethernet networks with 100BASE-TX Fast Ethernet networks, all models can also be used as simple 10BASE-T or 100BASE-TX repeaters. For easy trouble-shooting, the front panel includes a variety of LEDs, including Power, Collision, 100TX, Link, and Activity. Compact in size, the EtheRx dual-speed hubs are easy to install and require no additional hardware configuration.

Migrating to Fast Ethernet

As networks expand, there is an increased need for additional bandwidth at both workgroup and backbone locations. Companies are migrating to Fast Ethernet to help alleviate data bottlenecks. Fast Ethernet can be deployed into a new or existing network in a variety of ways depending on the bandwidth requirements of network users. If a network has enough bandwidth to justify creating multiple segments or has multiple source nodes sending information to different destinations, then a switch may be implemented as a viable solution. A low utilization network or one containing only one server may choose a more cost-effective alternative such as a dual speed hub. A dual speed hub allows for both Fast Ethernet and Ethernet or any combination of the two to exist on a single hub.

One implementation of Fast Ethernet, in a larger office environment, is the construction of high-speed network backbones (see Figure 1). In this example, Fast Ethernet connects the three file servers together in a high-speed backbone. This high-speed segment is then connected to the rest of the network via a bridge. The bridge is then connected to a standard Ethernet hub, which in turn connects the various nodes on the segment.

Dual Speed Hubs

Alternatively, by utilizing dual speed hubs the same network can be set up using only one hub in place of the Fast Ethernet hub, switch and Ethernet hub (see Figure 2). This is not only more cost effective, but simpler to implement and provides flexibility for future growth.

The 10/100 auto-sensing capability on every port allows for any combination of 10Mbps and 100Mbps to coexist on one network without affecting response time. When used in conjunction with auto-negotiating adapters, the auto-negotiating feature of Kingston’s dual speed hubs assures that each node runs at the maximum possible speed.

An added advantage to utilizing dual speed hubs are that they are easy to trouble shoot. Fewer links in the network mean that the administrator doesn’t have far to look to detect where a problem lies. Kingston’s hubs make trouble shooting a step easier with 100TX LEDs for 100Mbps speed detection, Link and Activity status LEDs, a Power LED, and individual collision LEDs for both 10Mbps and 100Mbps collision detection.

Conclusion

Dual speed hubs allow for both Ethernet and Fast Ethernet or any combination of the two to exist within a single hub. This provides a low cost solution to Fast Ethernet migration that is easy to implement for a company of any size.
