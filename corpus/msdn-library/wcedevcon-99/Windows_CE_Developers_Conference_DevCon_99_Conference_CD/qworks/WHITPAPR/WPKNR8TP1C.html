KNR8TP1C - EtheRx Internet Access Router

Overview

The KNR8TP1C is a multi-port Internet access router that supports up to eight (8) UTP ports for 10BASE-T network connections and one (1) 9-pin serial port for an external modem or ISDN terminal adapter connection. The KNR8TP1C conforms to IEEE802.3i 10BASE-T and IEEE802.3 CSMA/CD standards.

The EtheRx Internet Access Router allows you to connect multiple workstations to the Internet simultaneously using only one Internet account. As many as 250 private and secure e-mail addresses can be created from an e-mail address. For easy troubleshooting, the front panel includes a variety of diagnostic LEDs such as Power, Collision, Utilization, Diagnostic, Link, Activity and Partition Status. An LCD displays Internet configuration, Internet Connection status, and system status information for easy viewing. Router configuration, user management, and e-mail setup are simply done through a web browser.

Introduction

Many small businesses today want to make the Internet available to their employees but balk at the time, expense and headache associated with providing access to each desktop. Internet access devices eliminate most, if not all, of those problems by providing a gateway to the Internet in a single easily installed and configured device.

Access to the Internet and all of the functionality that comes along with it can no longer be considered a luxury. E-mail, file transfer, www.anycompany.com access and other types of Internet-based communication are becoming more important for all types and sizes of businesses. The Internet provides companies with the opportunity to utilize a truly global network without the expense of building their own private wide area network.

 

One of the many possible configuration options available with the KNR8TP1C

 

Recognizing the need for a low-cost, dependable, easily installed and configured Internet access tool, Kingston introduces the KNR8TP1C. The EtheRx Internet Access Router is designed for the small company and home office environment. It is a solution that every network manager can love.

Fast, Easy Connection

Connecting to the Internet is as easy as if the user had a dedicated line. Kingston's EtheRx Internet Access Router allows up to 250 users to simultaneously connect to the Internet using only one Internet Service Provider (ISP) account. The KNR8TP1C dials up the ISP whenever any user requests a web site connection. When the connection is established all users can simultaneously access any other resource on the Internet. When the Internet Access Router detects no activity for a period of 5 minutes (user programmable) it drops the ISP connection until another user attempts to access an Internet based resource.

Simple Installation

With its eight RJ-45 ports Kingston's EtheRx Internet Access Router can be quickly and easily added to an existing Ethernet network or it can serve as the central hub in a small network. With its built in 9-pin serial port the KNR8TP1C can establish a connection to an ISP via a 56k external modem or a high-speed 128k ISDN terminal adapter.

Built-in E-mail

In addition to providing a simple way to connect to the Internet the KNR8TP1C provides up to 250 secure e-mail addresses. Users can send and receive private encrypted e-mail across the Internet or within an Intranet. The EtheRx Internet Access Router provides security for the Virtual Mailboxes by acting as a Firewall to prohibit remote e-mail retrieval.

Simple TCP/IP Configuration

The KNR8TP1C simplifies the TCP/IP protocol configuration task on the workstations by acting as a BOOTP/DHCP server. It can dynamically assign and manage IP addresses within the local network. This valuable feature relieves the network administrator from the arduous task of managing static IP addresses for up to 250 users. If static IP addresses are required they can easily be excluded from the DHCP range using the built-in HTML-based configuration utility.

Low Cost Solution

The EtheRx Internet Access Router is an inexpensive solution to a small organization's Internet access challenge. All that's required is one KNR8TP1C, one ISP account and one phone connection. No longer is there a need to install and configure modems and run phone lines to each workstation. The customer saves money on the modem hardware and on the installation charges for the individual phone lines. The fees associated with monthly line maintenance are also eliminated. With a suggested retail price of US$479.00, networking professionals can realize the performance, ease of use and feature advantages of the Kingston KNR8TP1C EtheRx Internet Access Router without the high price premium placed on competing products.
