SWITCHING Overview

Switches are hardware devices designed to segment local area networks (LANs), connect LANs of different speeds, maximize the bandwidth of a network, or segment a single collision domain1 into multiple domains. Unlike a repeater, where nodes contend for access to transmission media (or cable), a switch provides each node with dedicated service and exclusive access to the total available bandwidth. This process, more commonly referred to as concurrent access2, allows multiple data streams to pass though a switch simultaneously without affecting one another. This dramatically improves network performance by allowing multiple nodes to successfully transmit at the same time.

SWITCHING FUNCTION

  • Switches send packets only to those clients who need them. This means that other clients, or nodes on the network, remain free to exchange additional information.
  • All nodes can be active at the same time. Switches can receive, process, and forward packets on all ports independently. Unlike a repeater, switches have the ability to transmit data out to multiple destination ports at once, while still receiving packets from non-destination ports.
  • The use of memory provides for buffering data and storing MAC addresses for routing. Memory helps prevent congestion in situations where many devices are transmitting to the same receiver (for instance, clients to a server). Packets may be stored in memory and then sent out to the destination address.
  • Switches can segment a single collision domain into multiple collision domains, thus reducing the number of nodes per collision domain and increasing network performance.
  • In a shared environment, the total available bandwidth decreases as devices are added to the network. In a switched environment there are fewer collisions, thus the total available bandwidth does not decrease as quickly with the addition of more attached devices.

DEPLOYMENT

Whether used to connect individual power users, segment workgroups or deploy hybrid environments, switches can meet the demands of any size networks. Because Kingston’s EtheRx switches support both 10Mbps and 100Mbps Ethernet networks, or a combination of both, they are the perfect solution for users looking for a way to cost-effectively migrate to Fast Ethernet.

Kingston's EtheRx Switches have a mixture of switched 10Mbps UTP ports and 100Mbps UTP ports. This allows the Kingston's EtheRx switches to enable standard 10Mbps Ethernet networks to communicate with 100Mbps Fast Ethernet networks. This gives the file server 100Mbps of dedicated bandwidth to connect and service nodes running at 10Mbps. On the client side, power users may keep their existing 10Mbps 10BASE-T adapters and still receive the significant boost in performance that comes from 10Mbps of dedicated bandwidth and minimized retransmission due to collision. EtheRx Switches give you the flexibility to provide more bandwidth where it is necessary. A server can transmit at 100Mbps, and the switch will fan out the data to the many nodes. In the reverse direction, many nodes can transmit data at 10Mbps, and the switch will aggregate their traffic onto the 100Mbps-server link. 10/100Mbps switches are also ideal for networks in the process of upgrading or migrating to 100Mbps because there is no immediate requirement to replace all of the existing hardware at one time.

On a LAN, there are typically congested points or where data must pass though some slower device, causing delays and pathway constraints. These areas are referred to as bottlenecks. On a network, bottlenecks may result from multiple nodes continually requesting services from a single server, numerous collisions within a single collision domain, or from heavily populated repeater segments. To resolve these bottlenecks, each node must have dedicated service and exclusive access to the network. Not only does a switch address both of these needs, but it also creates a unique collision domain for each connected device, and because Kingston’s EtheRx Ethernet Switches support full-duplex operation, dedicated channels are also established for bi-directional transmission of data. This enhances network performance by allowing connected nodes to send and receive data simultaneously.
