PCMCIA Systems

With the increasing popularity of portable computing, the need for integrated expandability led to the creation of the Personal Computer Memory Card International Association (PCMCIA). This organization of industry companies has led the development of PC Card interoperability standards. Due to the compact size of notebooks, PC Cards are designed to be about the size and shape of credit cards with varying thickness depending on their function.

Today, the proliferation of notebooks and hand-held computer systems, together with the search for smaller, lighter, and more portable tools for information processing, are generating innovative developments in many areas of the portable computer market. These innovations include advances in display, memory, power management, and overall computer design and size. PC Cards are a key component for expanding memory, storage, and I/O capabilities to portable computer systems.

Type I PCMCIA Card

PCMCIA standards define three types of cards. A Type I PC Card (3.3mm thick) may be used for various types of memory enhancements, including RAM, Flash memory, One-Time-Programmable (OTP) memory, and Electronically Erasable Programmable Read-Only-Memory (EEPROM).

2 Type II PCMCIA Cards

A Type II PC Card (5.0mm thick) may be used for memory enhancements and/or for I/O features such as LAN, modem, SCSI interface, sound card, Global Positioning System (GPS), RS232 interface and host communications.

1 Type III PCMCIA Cards

A Type III PC Card (10.5mm thick) is primarily used for Winchester drives. New applications are added to these cards, making them an attractive alternative for both portable computer and desktop users.

Support for Card and Socket Services

As the primary software specification of PCMCIA, Card and Socket Services (CS/SS) is a set of device drivers which control the recognition and compatibility of PC Card devices. Socket Services is a BIOS level software interface that recognizes and monitors when a PC Card has been inserted or removed. Card Services is a software management interface that allows for automatic allocation of system resources such as memory, COM ports, and IRQs, once a card has been inserted.

The combination of PC Card adapter hardware and CS/SS extends "Plug-and-Play" and "Hot Swapping" capability to portable computing environments where Windows 95 is not being used. The "Hot Swapping" feature allows for the removal of one card and the insertion of another without having to reset or turn off the computer. Once a card is removed, Socket Services instructs Card Services to re-allocate system resources for other needs. This is especially useful for portable users with limited PCMCIA slots.

Unique Hardware Enabler

Despite the advantages of using Socket and Card Services there are instances when it is preferable to dedicate a PCMCIA slot to the use of a specific card. In multiple application environments or environments where large driver files are used, for instance, use of the EtheRx IC PC Card’s Hardware Enabler frees up conventional memory allowing more efficient use of system resources. In addition, the large amount of conventional memory, up to 71Kb, used by Socket and Card Services often restricts the loading of custom applications which require the use of conventional memory to operate properly. "Power users" in particular will appreciate the ability to open more applications and files without running into "Insufficient Memory" errors.

Glossary

10BASE-T - An implementation of the IEEE 802.3 Ethernet standard on 22 to 26 gauge unshielded twisted-pair wiring. 10BASE-T compliant adapters require an RJ-45 media interface.

10BASE2 - An implementation of the IEEE 802.3 Ethernet standard on RG-58 thin coaxial cabling. 10BASE2 compliant adapters require a BNC media interface.

802.3 - Defined by the IEEE, these standards govern the use of the CSMA/CD (Carrier Sense Multiple Access/Collision Detection) network access method used by Ethernet networks.

BNC - Biconic Connector. This type of interface used on 10BASE2 compliant Ethernet adapters allowing for connection to RG-58 thin coaxial cabling.

Bus - The path upon which data is transferred through a computer system.

Enabler - A Controller specific driver which reserves system IRQ and I/O port resources for a specific PC Card product.

Plug-and-Play - (PnP) A specification developed by Intel and Microsoft that allows full auto-configuration of PC adapters.

Promiscuous Mode - An Ethernet mode that allows an adapter to receive all types of data packets on the network. It is often used for network diagnostics.

Thin Coaxial - RG-58 cabling. The type of cable (media) used in 10BASE2 Ethernet networks that connects to an adapter with BNC interface.

Socket and Card Services -Device drivers which control recognition and compatibility of PC Card devices.

Hot Swapping - Support for the removal, reinsertion and operation of different PC Card products without rebooting the system.
