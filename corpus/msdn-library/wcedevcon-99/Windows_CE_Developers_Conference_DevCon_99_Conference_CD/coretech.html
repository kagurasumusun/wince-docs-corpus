Leveraging Core Technologies and Components

Windows® CE-based Technologies Overview
This talk discusses the technologies that are key to building intelligent appliances that solve customer problems. The talk is balanced between what can be done with today's technologies and what is coming in the near future. Topics covered include graphical user interface and multimedia, global solutions, connectivity and interoperability, security, browsers and applications, open and expandable platforms and real-time performance.

Networking & Communications
Networking and communication features are key components of the Windows® CE operating system. These capabilities are extensively expanded upon in Windows CE 3.0 (aka "Cedar") enabling the vision of computing everywhere, connecting everything. This session will primarily focus on the Cedar features with discussions ranging from home networking, network management of Windows CE-based devices, mobility and connectivity, telephony and more.

Universal Plug and Play (UPnP)
UPnP is the cornerstone of computing everywhere - and communicating with everything. This session introduces UPnP as it applies to the Windows CE world. We’ll explore UPnP’s open standards-based communication methods, which enable seamless connections between PCs, appliances and services in an IP network.

Message Queuing
Microsoft Message Queuing (MSMQ) on Windows CE delivers the core functionality you need to write reliable, distributed MSMQ applications for disconnected environments. We’ll explore the many aspects of MSMQ, including Windows CE-specific features and limitations. We’ll also present a technical review of a real-world MSMQ/Windows CE-based application.

DirectX® Foundation
DirectX® foundation technologies are a set of low-level APIs that provide fast and efficient hardware acceleration in a device-independent way. In this highly technical session, we’ll explore DirectX® APIs and study device driver interfaces, complete with a comparison of the desktop to Windows CE-based implementations. This session also focuses on DirectDraw® and DirectSound®, the foundations of all 2D video and audio acceleration.

DirectX® Media
DirectX® media technologies build on the DirectX® foundation technologies to provide a rich API and feature set for multimedia playback. You’ll learn how these technologies, particularly DirectShow™ and the Windows Media™ Player Control, are integrated into the Internet Explorer browser to produce the best browsing experience available in an embedded system.

Windows® CE Security
This session covers the different security features available in Windows® CE. Learn about Cryptography 1.0 APIs, NTLM and Schannel authentication modules, secured sockets, HTTPS support, 128bit security modules, and DUB authentication and other kernel authentication hooks. New security features available in “Cedar” (aka Windows® CE 3.0) will also be discussed such as Smart Card PC/SC support, Cryptography 2.0 APIs, and the ability for OEMs to secure the registry.

Internationalization Features
Right from the start, the Windows® CE operating system has been designed to support multiple languages and multiple countries. In this session, we’ll provide a technical overview of the international languages supported. We’ll also introduce how Windows® CE can greatly simplify the development of applications for international markets.

Testing Windows® CE
Reliability. Use for critical applications. Performance under stress. Windows® CE has a quality assurance team dedicated to making sure that your embedded device will have high stability and low failure rates. Learn about Microsoft's commitment to testing and what tools we provide our customers to ensure that your platforms are rock solid. This talk will touch on how we test the OS internally, what special tools and tests we ship in the Platform Builder, and how to leverage those tools and tests. If you are a manager or a front-line engineer this talk will be an eye opener and will help you deploy high quality products.

Connecting Wirelessly to your Digital Nervous System with Windows® CE
When customers deploy mobile Windows® CE-based devices in an organization, they want to provide quick and immediate access to information -- requiring use of wireless connectivity. Windows® CE enables strong support for wireless solutions and there are partners with solutions ready today. This session will highlight several wireless solutions available today; considerations for application developers who need to integrate with wireless transports, and how you may ensure you choose the right option to fit with Microsoft® platforms and technology
