The Microsoft beta version of the Auto PC software development kit (Auto PC SDK) helps build in-car computing applications for controlling high-end digital audio systems, voice-activated navigation, hands-free voice/data telephony and more. The device’s open Windows CE platform also expands the Auto PC’s functionality to include a global positioning satellite system or a wireless transmitter/receiver.

Download the software development kit (Palm-size PC SDK 1.2SP) for the Windows CE-based Palm-size PC 1.2 and start writing applications that capitalize on this new device’s capabilities, such as a full-color screen display, Visual Basic runtime and powerful database support.

Use the software development kit (Jupiter SDK) for the Windows CE-based Handheld PC (Professional) 3.0 and start writing applications that capitalize on this new mobile device’s capabilities, such as larger keyboard, full-color screen display and powerful database support.

The POOM SDK integrates seamlessly into Microsoft Windows CE Toolkits for Visual Basic or Visual C++ and provides innovative Pocket Outlook features for streamlining business and personal information management applications running on Windows CE devices.
