Developing Custom Devices, Intelligent Appliances, and Peripherals

Introduction to Creating Windows® CE-based Intelligent Appliances
This session covers the design considerations for intelligent appliances (IA), the future of embedded devices. We'll discuss what makes an appliance intelligent, and explain how to select and configure the OS. You'll learn the steps involved in creating an AI using Windows CE, including targeting, testing and debugging.

Real Time in Windows® CE 3.0
Windows® CE 3.0, the next generation of Windows® CE, will feature improved real time capabilities that provide a dramatic improvement in OS responsiveness. This presentation includes a performance demonstration of CE handling hard real time. We’ll also review the host of new tools that OEMs can use to measure OS performance.

Platform Builder
Platform Builder 2.12 features an exciting new Integrated Development Environment that makes configuring and building your custom Windows® CE much easier. In this session, you’ll learn how to use the new kernel debugger and a full range of other new features.

Device Driver Features in Windows® CE 2.12 and beyond
oin us for an in-depth look into the exciting device driver features coming to Windows CE 2.12, and hear our plans for Windows CE 3.0 ("Cedar") and beyond. We'll introduce a full range of features, including enhanced USB and NDIS support, IEEE/1394 ("Firewire"), CD-ROM/DVD-ROM support, enhanced boot loader features, and more. You'll learn how all these new drivers fit into the Windows CE driver model, and discover how to write and port certain drivers for Windows CE.

Flash Memory Support
Flash memory is an excellent storage alternative to Winchester disks, especially for embedded devices that need to withstand a rugged environment. In this session you’ll learn all about Resident Flash Array, the exciting new technology supported in Windows® by our partners M-Systems and Intel.

Digital Imaging with Windows® CE
This important technical session is for anyone interested in the upcoming digital imaging architecture of Windows® CE. We’ll discuss the future of imaging functionality, from Palm-size PCs and H/PCs to camera designs with Windows® CE-compatible CPUs and touch screens. You’ll learn about a wide range of topics, including imaging pipeline, capture, and imaging-aware applications.

Implementing a Successful Windows® CE Project
Learn the steps involved in a custom hardware project, from the decision to use Windows CE right up to the first customer shipment. We'll show you how to identify prototyping opportunities for your platform, how to successfully organize the design and architecture, even how to train your team. We'll study the Windows CE licensing and development model, and discuss planning, testing, integrating modules and much more.

Debugging Custom Devices Using CodeTest
In this session, we'll review the issues and challenges associated with developing a custom Windows CE-based embedded platform, and introduce compelling tools to tackle these issues. Learn how advanced embedded development tools from Applied Microsystems can help speed your development time and result in a higher quality Windows CE-based product. We'll discuss enhanced target communications, advanced debugging of device drivers and applications, performance analysis and software testing, plus much more.

Boot Loaders, the Forgotten Element of Windows® CE Development
The lowly boot loader is often lost in the excitement of receiving a demo board with a running Windows CE kernel. This small piece of code is a great place to learn how your hardware actually works, and how to debug many low-level routines used by the OAL. This session will cover how to quickly construct a boot loader for almost any platform using various parts of the Platform Builder sample code.

File System Drivers Exposed
Windows CE exposes an API to allow OEMs to develop their own file system drivers. Through the use of actual code and demonstrations of a working file system driver, you'll learn how to write fully functional file system drivers - the low-level block driver, which provides the interface to the physical media, as well as the high-level file system DLL, which provides the file system management.

Writing and Debugging Device Drivers
Attend this session to learn the fundamentals of writing Windows CE device drivers. We'll provide an overview of Windows CE 2.X architecture, including protection modes, address space, native and stream interfaces, how to access the device's physical resources, and more. We'll also explore the device driver mode, the device manager, device driver registration and installation, and how to build and debug the device driver from the Visual C++ IDE.

Video Driver Exposed
At first glance, one of the most daunting tasks of porting Windows CE is writing a video driver. Fortunately, Windows CE uses a simple, flexible model that can easily be ported. In this session, you'll learn the various steps involved in writing a Windows CE video driver - everything from the DDI interface to the simple "DirtyRect" video driver - with a special emphasis on the GPE class driver. We'll also cover techniques for video acceleration that will speed up your Windows CE-based device dramatically.

Hardware Reference Platform (HARP)
From the outset, Windows CE has been designed to support multiple CPU architectures. Developing standardized hardware for testing these CPUs has always been a challenge, and getting that hardware into the hands of non-Microsoft developers has been an even greater task. In this session, we'll discuss HARP, Microsoft's proposal for an industry-standard, CPU-independent development platform. HARP has been well-received in the silicon vendor community, and is poised to expand beyond Windows CE OS validation in the next 12 months.

Debugging a Windows® CE Project
In this session, we'll discuss Windows CE-specific strategies for debugging and point out pitfalls to avoid. You'll learn how to use the new features of Visual C 6.0 for Windows CE, plus how to take advantage of new Handheld PC Pro and PSPC features that allow you to utilize the WinDbg kernel debugger.

Access to Corporate Resources from a Custom Appliance: Active Gateway
Attend this session to learn about Active Gateway, a development platform that enables real-time applications to communicate with corporate resources. It is composed of client components that can exchange information synchronously or asynchronously. Any Windows CE-based device can access applications running on the server or remote clients, and we'll learn how embedded applications can insert, delete, modify or retrieve data stocked in SQL-relational databases. We'll also discuss other services including a remote-management service, a software delivery service, and a push/broadcast service.

Getting Auto PC Software to Run on your Auto PC Hardware
Windows CE is a great platform for developing custom devices; Auto PC is no exception. This session covers the various steps involved in creating custom devices. We'll discuss Hardware Abstraction Layer (HAL) issues, power management, targeting different processors, tools support, and more. We'll also explore developing third-party drivers for the Auto PC.

Windows® CE: Where does it best fit?
This marketing presentation explores possible uses for Windows CE, both today and in the future. You'll hear Microsoft's vision for Windows CE, including how this powerful tool can change the world. Lean which vertical market segments are being targeted today, and what Windows CE can do for them. Join us as we attempt to answer the question, "Where are we winning and losing today - and why?"

Jump-start Windows® CE Development
This session demonstrates the different solutions offered by the myriad of Windows® CE partners who are building solutions to help to expedite building a Windows® CE-based device. Each solution will cover different microprocessors and the various technologies needed to implement the solution.

Real-world Applications of Windows® CE
The myriad of hardware solutions that are powered by Windows® CE is reshaping the industry of "Intelligent Appliances". This session will demonstrate the challenges and the success of several Windows® CE-based devices from around the world. We will demonstrate Windows CE-based kiosks, a racing car using Windows® CE as its main on-board computer, an instant-replay video device and a on-board truck application. Look forward to having your view of Windows® CE radically adjusted!

Power Management Capabilities of Intel Architecture Platforms Running Windows® CE
In embedded applications - the Auto PC included - power management is of paramount importance to OEMs; and thus it also concerns hardware and software vendors. This session will detail the power management capabilities of Intel Architecture platforms running Windows® CE. The session covers the power management API's developed by Intel as well as the HW and SW architectures that supports the power management capabilities. A detailed example scenario will be presented. The example will include a demo of an Intel Architecture-based Auto PC system.

Visual Basic® for Intelligent Appliances
Visual Basic® is now available for your custom devices with full support in Platform Builder. Visual Basic® supports headless and visual devices. This session takes you through the process of adding the Visual Basic® runtime components to your Windows® CE OS configuration, creating a Platform SDK that includes Visual Basic® support, installing that Platform SDK into the Windows® CE Toolkit for Visual Basic® 6.0, writing Visual Basic® programs, and downloading and debugging on your device. Come see how easy it is to offer the most popular programming language in the world to your own custom device.
