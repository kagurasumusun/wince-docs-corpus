Interactive Hands-on Laboratory

Real-Time Capabilities of Windows® CE
Observe the real-time improvement between the current release of Windows® CE and the future release of Windows® CE, code-named Cedar. By using several software examples at your disposition, you will gain a clear idea of how the Windows® CE operating system functions in real time. By using a high precision timer (70 ns), you will measure the ISR/IST cycles under three different types of load: operating the kernel only, multi-treads and processes and network access.

How to Create a Web Browser with Windows® CE 2.12
Windows® CE 2.12 introduces a number of new controls and applications. The most exciting of these controls is the new HTML control. This lab will show you how to create a complete Web browser using this new control. During the session, you will be able to build an OS image with a custom made application. You will then flash it in memory and you will able to verify that Windows® CE can let you easily build one of the most powerful Web browsers in the embedded world.

Code Analysis Using CodeTest from Applied Microsystems Corp.
Tracing and debugging device drivers and applications in a multi-process and multi-thread environment can be extremely challenging. Applied Microsystems Corp. has designed a suite of tools called "CodeTest" which permits a much easier way of tracing the execution of exactly what is happening. This session will allow you to familiarize yourself with CodeTest and you will be able to experiment with various aspects of software debugging.

How to Write a Bootloader
Its one thing to listen to how easy it is to write a boot loader. Its another to bootstrap yourself in the Platform Builder and start building code. This lab will take you from booting up your development PC to downloading working code to a target machine. In this hands-on lab, you will write a boot loader from scratch, compile it and download it to the target all using the tools and sample code from the Platform Builder. After the lab, you will be ready to tackle your own custom hardware and the larger tasks of porting the operating system itself.

Platform Builder 2.12
This new release of Platform Builder introduces numerous exciting new features. In this lab, you will learn how to configure and how to create a new Windows® CE operating system for an embedded device. You will also be able to explore some of the new features of Platform Builder such as the built-in embedded kernel debugger. At the conclusion of the session, you will have a good understanding of which tools to use when building a Windodws® CE operating system.

Using Visual Basic® in an Embedded System
Visual Basic® offers a very compeling alternative to complex development on C or C++. It is a simple and powerful language to use, even in the embedded world. During this lab, you will be able to build an OS image including the Visual Basic® runtime. You will also write some Visual Basic®-based applications and see how to download code on a target device and how to debug the Visual Basic®-based application.
