How Quantum Micro Systems® Upgraded a Hand-Held Terminal using a MIPS®RISC Processor and Windows® CE Operating Systems

by Vahé Manugian, Ph.D.

The challenge was considerable - upgrade a warehouse data collection system based on a CP/M and 8-bit microcontroller with the following specifications:

  • Upgrade the microcontroller since the current one would no longer be available.
  • Upgrade the operating system while maintaining compatibility with the current system.
  • Provide an easy development path for future system versions.
  • Make the user-interface, scanners, modem, and connectivity backward compatible with the existing system.
  • Create a rugged, low-power, low-cost, and secure (high data integrity) device.
To meet these requirements, Quantum Micro Systems selected the Philips PR31700 with a MIPS R3000 core and the Windows CE operating system. The MIPS core provided excellent performance, specifically a 10x reduction in data search time over the previous system. The combination of the MIPS core, Windows CE operating system and Quantum Microsystems' custom hardware and software achieved power consumption values of 500 micro-amps in suspend mode and 21 milli-amps in idle mode. As part of the power management system, battery level indicators were implemented into both hardware and software.

To provide compatibility with the previous system, the customer requested the use of the existing packaging, keyboard, displays and peripherals. A custom keyboard driver implemented an 8x8 scanning keyboard. The display was a 128x64-pixel RAM-based display driven through memory-mapped I/O and implemented as a non-DIB driver. A custom I/O driver was also developed to interface with the external peripherals, which included a laser scanner, bar code scanner, printer and modem. To provide user-interface compatibility, a layer was provided on top of the Windows CE OS that allowed the customer to provide the exact same user-interface as the old version, but with far superior performance. The Windows CE operating system was configured to fit into 2MB of Flash memory while still providing capability to have almost full Windows graphics features for future versions. In addition, this allowed for full connectivity with Windows NT through TCP/IP and PPP.

Three senior Quantum Micro System engineers were able to complete this project in four months. Without the Philips PR31700 MIPS RISC processor and the Windows CE operating system, the development would not have been possible in such a short period of time. The Microsoft Windows CE toolkit for the Visual C++ development system enabled applications to be developed on an emulator and simultaneously downloaded to the new system as soon as it was available. The applications were up and running immediately!

The goal was realized - replacement of an existing system with a low-cost version using the latest technology. The result provided many more features than the old system, including connectivity with Windows NT.

The Philips PR 31700 32-bit MIPS RISC microprocessor provides a viable replacement to existing 8-bit microcontroller based products. This is especially true in hand-held applications where the design constraints for low-cost and low power are severe. Philips developed this new class of processor utilizing System-On-Chip technology to squeeze the MIPS core and peripherals onto a single device. This high level of integration with on-board power management is key for low-power operation and low cost.
