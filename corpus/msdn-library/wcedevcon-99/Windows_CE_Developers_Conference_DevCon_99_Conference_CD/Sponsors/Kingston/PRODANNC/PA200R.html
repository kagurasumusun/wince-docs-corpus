EtheRx Pro Series Ethernet Switch

Release date: January, 1998
 

For use in both standard desktop and 19" rack-mount installations, the KNS200/R is a high-performance 2-port 10/100Mbps switch ideal for the small-to-medium sized business. The EtheRx KNS200/R provides automatic switching between 10Mbps and 100Mbps operation, thus allowing standard 10Mbps Ethernet networks to communicate with Fast Ethernet networks. Compact in size, the KNS200/R is easy to install and requires no hardware configuration.
