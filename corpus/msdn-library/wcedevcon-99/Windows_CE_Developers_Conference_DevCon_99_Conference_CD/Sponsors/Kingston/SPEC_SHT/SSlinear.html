Linear Flash Cards

 

Kingston manufactures two +5.0 volt only Linear Flash PC Cards: LINEAR/8 (8MB) and LINEAR/20 (20MB). These cards are compatible with the 68-pin PCMCIA.JEIDA international standard. Each card is based on 16Mbit +5.0 Volt only Flash memory. Each card uses a separate EEPROM memory device to control the attribute memory space where the Card Information Structure (CIS) resides. Each card can be read in either a byte-wide or word-wide mode that allows for flexible integration into various system platforms.
