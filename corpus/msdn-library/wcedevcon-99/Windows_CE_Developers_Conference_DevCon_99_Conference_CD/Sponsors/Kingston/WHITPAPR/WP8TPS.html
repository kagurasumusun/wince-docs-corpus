Product Positioning

Hubs or concentrators are hardware devices that provide a central point for the network devices, including servers, workstations etc. The hubs' function is to repeat and broadcast the outgoing packets to network nodes. It is up to the node to ignore all packets except the ones that match its destination addresses.

Historically (for the last 8 years), thin coaxial was the preferred method of cabling for small workgroup setups. Coaxial cabling was relatively cheaper since it does not need a hub to connect the PCs together. All that it needs are cables, T-connectors and 50 Ohm terminators. Typically, 10Base-T was for larger installations when hubs were sitting in wiring closets. Further more, the price per port for the required 10Base-T hubs made it impractical for smaller installations.

A major benefit using 10Base-T is that it is a low-cost cabling alternative. Unshielded twisted-pair wiring (UTP), better known as telephone wire, can be used for transmitting Ethernet data signals. In fact, they have already been installed in most office buildings.

Another 10Base-T feature that network administrators look for is connecting Ethernet workgroups in a star topology that focuses all network cabling in a single hub. It makes network management and trouble shooting so much easier with the link/activity status indicator lights. Instead of inspecting the entire coaxial cable segment that may go up to 185 meters, the technician can troubleshoot a problem network node by checking only the cable going from the node to the hub.

10Base-T's popularity spreads over two thirds of the total Ethernet installations world- wide. With 10Base-T Ethernet NIC prices dropping below $100.00 retail, more and more small to mid-size companies or individual departments within large organizations realized that they can save time and money by connecting their systems together to allow data and resource sharing, like printers and modems. These changes have and will continue to enhance PC connectivity.

Since the KNE-8TP/WG 8-port Hubs' price is only slightly more than $31 per port, the cost will be offset by the 10Base-T NICs that cost $20 dollars less than 10Base-2 NICs. It would further maximize the use of all eight UTP ports when multiple hubs are stacked. More and more new installation sites are switching from the bulky coaxial cables to the clean RJ-45 cabling solution. Even if there are existing workstations installed with coaxial cabling, they can still be connected to the new 10Base-T workstations via the BNC port that the 8 port hubs provide.

To further enhance this product, Kingston has included the stackable feature to allow flexible installations. When hubs are stacked together, all the devices that are connected to these hubs are looked at as if they were all connected to a single hub. Four hubs can be stacked together and form a 32-port single logical hub unit. This way, up to 1024 ports can be connected together for a more flexible growth path.

For the smaller network setups, no ports are wasted when connecting hubs together. The "stack in" and "stack out" ports provide the connections to connect up to four hubs together, and form a single logical hub unit. Kingston's complete packaging includes a 9" stacking cable so that nothing else is needed.

Features and Benefits

Feature: Compact Design - 1.1"x6.5"x6.1" (28mmx165mmx155mm)

Benefit: These units are designed for the widest installation applications. They are compact enough for putting on desktops, stacked up in wiring closets or wall-mounting.

 

Feature: UTP Ports

Benefit: 8 Unshielded twisted-pair ports that allow 8 workstations or hubs to connect together in one segment.

 

Feature: BNC Port

Benefit: 1 RG58 thinnet coaxial port that allows 1 coaxial segment to be connected to the rest of the 10Base-T ports or connect the hub to a coaxial backbone.

 

Feature: Stackability

Benefit: Up to four KNE-8TP/S hubs can be stacked together via the special ports to form up to a single 32 port logical unit. This will increase the number of ports, without using up the existing RJ-45 ports that cascading would need. It makes network expansion more flexible and cost effective.

 

Feature: Power LED Light

Benefit: The green LED indicates the power status. The LED will be lit when the Hub powers on.

 

Feature: Collision LED Light

Benefit: The amber LED displays the collision status. If a collision is detected on the network, the amber LED will flash. For the Ethernet CSMA/CD network, collisions can be quite common. A collision occurs when two or more stations try to transmit data simultaneously.

 

Feature: Link / Activity LED Lights

Benefit: The green LEDs display the link and activity status for the 8 RJ-45 twisted-pair ports. If a good link is established on any given port, the green LED will stay lit, indicating a valid network connection between the network node and the Hub. When data is transmitted, the LED will flash.

 

Feature: External AC Power Transformer

Benefit: The external 110 VAC power transformers allow the hubs to be compact and uniquely designed. A 220 VAC version of the external power transformer is available for users outside North America.

 

Glossary

10Base-T - An implementation of the IEEE 802.3 Ethernet standard on 26 to 22-gauge unshielded twisted-pair wiring, a Baseband medium, at 10 megabits per second.

802.3 - Defined by the IEEE, these standards govern the use of the CSMA/CD network access method used by Ethernet networks. Although CSMA/CD and Ethernet are used interchangeably, there are technical differences.

Automatic Partitioning/Reconnection - If any of the ports on the EtheRx hub experience excessive collisions, duration collisions, or faulty conditions, that particular port can be partitioned. Once partitioned, the hub will continue to monitor that port. If the error conditions have been corrected the hub will automatically reconnect that port to the network.

Backbone - Cable on which 2 or more stations or networks may be attached.

BNC port - A standardized biconic connector used with thinnet and coaxial cable.

Carrier Sense Multiple Access/Collision Detection (CSMA/CD) - Network access method in which nodes contend for the right to send data. If two or more nodes attempt to transmit at the same time, they abort their transmission until a random time period of microseconds has transpired and then attempt to retransmit.

Cascading Star - Topology in which a centralized multiport repeater serves as the focal point for many other multiport repeaters.

Crossover Cable - A cable connecting or cascading between two hubs or connecting 2 stations without a hub. The transmit and receive pins on these cables are crossed.

Hub - A hub or repeater in a star-topology network to which the nodes are connected. Also, a wiring hub or repeater that brings together the connections from multiple network nodes.

Jabber Lock-up Protection - The EtheRx hub implements a built-in jabber protection scheme to ensure that the network is not disabled due to transmission of excessively long data packets. This protection scheme will automatically interrupt excessively long transmissions to prevent jabber lock-up.

Link Test - The EtheRx hub implements the link test function as specified in the IEEE 802.3 10Base-T standard. The hub will transmit link test pulses to any RJ-45 twisted-pair port. These pulses are sent to confirm that a valid connection exists between each twisted-pair port on the hub and its attached device.

RG-58 - A type of shielded coaxial cable used for "thin" Ethernet transmission (thinnet). Like all Ethernet cable, RG-58 has a 50-ohm characteristic impedance.

RJ-45 - A modular eight-wire connector used to terminate twisted-pair telephone cable. It is used for starLAN networks and some telephone systems.

Repeater - If any single port senses the start of a valid packet on its receiving line, the EtheRx hub will re-transmit the received data to all other ports on the network. The re-transmission of packet complies to the IEEE 802.3 specification in terms of preamble structures, voltage amplitude, and timing characteristics. These timing regeneration prevent cumulative loss of signal, jitters, and distortion caused by the network cabling, enabling the EtheRx hub to be cascaded to other EtheRx hubs.

Stackable hub - Connecting multiple hubs to form a single logical unit. This way all the ports in the units that are stacked together are looked at as if they were all connected in one hub. This allows for greater flexibility when growing your network because stacking allows a greater number of hubs to be installed per segment.

 

Questions and Answers

Question: What is the difference between hubs and concentrators?

Answer: None! they have the same meaning

.

Question: Why is the AUI port being replaced by the BNC port?

Answer: The targeted customers for this product are small to medium sized workgroups. By having the BNC connector, a coaxial segment can be connected to the BNC port directly. The AUI port would require an additional $30 transceiver to convert to a BNC port. Offices that have thick Ethernet cabling that require the AUI connectors normally are for much larger installations that need more ports per Hub.The BNC ports are actually a more expensive option to implement comparing with the AUI ports.

 

Question: What is the maximum distance can one stack his/her hubs together?

Answer: The units were designed to utilize the stacking cables which are 9" shielded twisted pair cables. Using after market cables are not recommended because they may create reflection due to impedance mismatch. Also, characteristics of certain cables may attenuate more than others and that may cause problems.

 

Question: Can these hubs still be cascaded?

Answer: Yes, 5 segments can be connected in series using 4 Hubs. A crossover cable is needed to cascade hubs together via one of the 8 UTP ports.

 

Question: Does it come with an SNMP (Simple Network Management Protocol) Agent?

Answer: No, this is a product that addresses to the small to medium sized workgroup environments that do not require management software. Manageable hubs usually support more ports for larger installations. A new line of manageable hubs from Kingston are going to be available in the future to address these needs.
