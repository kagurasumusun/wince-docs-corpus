Product Overview

Kingston’s TurboChip 233 is the ideal processor upgrade solution designed for Pentium® 75MHz and up desktop and mini-tower computer systems. The TurboChip 233, part number TCMMX/233 incorporates the Intel 233MHz Pentium processor with MMX to combine the power of high performance Pentium processing performance with industry standard multimedia extension instructions to equip your system with the necessary tools for today’s exciting media-intensive graphic, sound, and video software applications. In addition, TurboChip 233 features a robust 32KB of level-1 cache and is the most convenient upgrade solution to increase a computer’s processing performance an estimated 250% over its existing processing speed.

TurboChip 233 is a chip-for-chip replacement processor upgrade which easily installs into the existing processor socket with support for either a Socket 5 or Socket 7 pin layouts. All of these computer systems use ZIF (zero-insertion-force) sockets with a lever handle to make removing the CPU chip quick and easy. To ensure years of reliable performance, TurboChip 233 incorporates an integrated cooling unit including which includes both heat sink and fan to control the operating temperature of the CPU.

Question: What if the system doesn’t boot up after TurboChip 233 is installed?
Answer: Most likely, TurboChip 233 is not compatible with this particular system. Determining compatibility is black and white. If the system boots and the monitor has a visual on the screen, then TurboChip is compatible with this particular system. If the system doesn’t boot and the monitor has no visual, then TurboChip is probably NOT compatible with this particular system. Your next step is to simply un-install TurboChip 233 and re-insert the original CPU. TurboChip 233 was tested to be compatible with many popular Pentium-based 75MHz and up desktop systems, both branded and non-branded.

Question: What is MMX technology?
Answer: MMX technology is an Intel architecture designed to accelerate multimedia and communications software applications. Intel was able to design new data types and 57 new instructions to accelerate calculations common in audio, 2D and 3D graphics, video, speech synthesis and recognition, and data communications algorithms. Processors enabled with MMX technology will deliver enough performance to execute processor-intensive communication and multimedia tasks with headroom left to run other tasks or applications. Eventually, all software applications will be designed with MMX and computers will be able to show complex visual effects with no loss of frame rate, smoother video, high quality audio and high color resolution. (Source: Intel Corporation web page, www.intel.com)
