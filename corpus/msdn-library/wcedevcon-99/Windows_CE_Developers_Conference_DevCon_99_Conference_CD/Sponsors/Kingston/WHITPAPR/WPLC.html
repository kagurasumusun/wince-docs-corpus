Product Description

The Kingston EtheRx LC ISA Ethernet Adapters are a series of NE2000 compatible adapters that combine low cost with the QStartTM auto configuration installation program. The EtheRx LC adapters are available as a combo version that supports 10Base-T and Coaxial cabling as well as a 10Base-T only version. The Adapters support 8 IRQ’s and 7 I/O Base addresses to avoid conflicts in even the most populated systems. A remote boot ROM is available as an option for diskless workstations.

EtheRx LC comes complete with QStartTM a comprehensive GUI installation utility designed to provide for the easiest possible Ethernet adapter installation with mouse support. Upon execution of the QStart utility, the host system is interrogated for available system resources like IRQs and I/O addresses. QStartTM then allocates open addresses to the Kingston adapter. QStartTM then prompts the installer for the Network Operating System the adapter will be interfacing. Upon selection, the appropriate LAN driver will then be automatically configured to the adapter. The installer can then run the diagnostics program built into QStartTM for assurance that the adapter is configured properly. Complete installation and configuration has never been easier!

With 100% quality control and lifetime warranty, the EtheRx LC adapters are the preferred choice for their reliability. At list prices less than $50, they are the only adapters on the market that provide such price/features.

The Significance Of NE2000 Compatibility

Since the mid 1980’s, Ethernet has gained tremendous acceptance. Novell NE2000 compatible adapters have long been the preferred choice for small and medium size companies to network their offices. For years, Novell’s NE2000 adapters have dominated the Ethernet market. With the popularity of the NE2000 adapters, Networking operating systems (NOS) developers have to make sure that their software work with the NE2000 adapters. Very much like the IBM Token Ring adapters, built-in drivers for the NE2000 adapters are included with every NOS to ensure easy adapter installation.

On the other hand, chipset manufacturers see the opportunity to design a chipset that can have instant market acceptance by cloning the NE2000 chipset. Today, around 50% of the Ethernet adapters installed worldwide are either NE2000 or NE2100 compatible.

For resellers and network administrators, NE2000 spells relief, because by using the built-in drivers, they do not need to manage an additional network driver diskette. NE2000 compatible adapters are readily available and they are very cost effective.
