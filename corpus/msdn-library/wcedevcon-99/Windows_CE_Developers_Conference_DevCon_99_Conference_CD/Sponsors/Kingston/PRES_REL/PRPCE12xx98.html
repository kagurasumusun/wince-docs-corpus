KINGSTON INTRODUCES LINE OF NOR LINEAR FLASH MEMORY

Linear PC Card Storage Solutions Up to 64MB Capacity Now Available

Fountain Valley, CA -- (December XX, 1998), Kingston Technology Company today announced a new line of NOR Flash memory based linear PC Card storage solutions, up to 64MB in capacity. The new linear flash cards are lightweight, rugged and low-powered PC Card storage solutions for today’s rapidly expanding mobile and telecommunications environments.

Kingston’s new line of linear flash memory cards increase the data storage capacity for many mobile applications, effectively increasing the functionality of the equipment and its applications. These include hand held computers, palmtop PCs, digital cell phones, voice recorders and digital cameras. Linear flash memory is also used when a computer receives data in blocks, the linear data must first be translated to blocks of data. This is done by Flash File (FFS) or Flash Translation Layer (FTL) software. (These last 2 sentences need more explanation).

"Kingston Technology is committed to the non-volatile memory market," said Raymond Wang, PC Enhancement Product Manager, Kingston. "We are the first in the industry to offer a 64MB card solution, while also providing our customers a low cost alternative to OEM accessories. Complementing the new linear flash line, Kingston also offers a comprehensive array of flash memory based storage solutions including, CompactFlash, ATA Flash and SSFDC/Smart Media solutions," added Wang.

In telecommunications applications, linear flash cards are primarily used for execution code storage for industrial internetworking types of equipment made by companies such as Bay Networks, Cisco and Ascend. The linear flash cards store the executable codes necessary to run the operating systems of the equipment. Linear flash storage solutions can also benefit existing equipment when utilized as upgrades with higher capacity cards increasing the functionality of the network.

Kingston will incorporate Intel’s StrataFlash and AMD’s flash memory technology in its new line of linear flash memory cards. The Kingston linear cards are available in capacities ranging from 4MB to 64MB and are guaranteed compatible with Cisco, Bay Networks and Ascend networking systems.
