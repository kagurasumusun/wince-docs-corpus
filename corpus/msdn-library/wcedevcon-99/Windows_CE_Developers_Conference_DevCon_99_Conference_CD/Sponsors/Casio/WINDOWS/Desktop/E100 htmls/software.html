Software included with the Cassiopeia E-100:

Compact Flash Backup in ROM
Allows you to backup your data onto a CF card either manually or daily at a preset time.

Casio Menu
Have a lot of important files or applications? Not a problem, we include Casio Menu, an application launcher in ROM on the E-100. Assign applications and files to 12 buttons on your screen. Access to them is just a tap away. You can also assign sub menus to the buttons. Tap a button assigned a sub menu and you open to 6 additional buttons that can have applications or files assigned to them. Quick, easy organized access to your data.

Image Viewer
This powerful electronic image viewing tool for your Windows CE device supports the most popular and widely used graphic image formats, including .bmp, .jpg and Windows CE .2bp file format. Image Viewer also works with CASIO’s exclusive .cam image file format and includes a special Comments Editor for use only with the CASIO QV Digital Camera .cam image files.
