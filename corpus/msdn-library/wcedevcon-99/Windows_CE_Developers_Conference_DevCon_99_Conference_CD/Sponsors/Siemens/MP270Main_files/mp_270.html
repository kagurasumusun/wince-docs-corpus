SIMATIC Multi Panel MP270
The first representative of the new category

The MP270 SIMATIC multi panel is the first representative of a new product category called the "mul-tifunction platform." Under Windows CE, the multi panels are deterministic. This is a basic prerequi-site for ensuring reliable control close to the machine. The short time required for booting the operat-ing system reduces unnecessary standstill time

Since Windows CE is also a diskless operating system which makes it particularly suited to use in rugged industrial environments, an MP270 can also be used to control and monitor machines in applications in which the vibration resistance required and the presence of great amounts of dust previously restricted the use of a PC. HMI functionality is primarily that of the PC version ProTool/Pro.

Highlights

   
  • Multifunctional platform for automation tasks
    • Visualization with ProTool
    • Soft PLC WinLC as option with Windows® CE 3.0
  • Future-oriented due to Microsoft's Windows CE standard operating system
  • Robust due to diskless operation and IP65 front
  • Low mounting depth of 50 mm (mounting cutout same as OP35/37)
  • Convenient process representation with pixel and vector graphics with up to 256 colors
  • Process presentations via dynamic attributes (e.g., motion)
  • Integrated message system with message output which can be configured as desired
  • Archivation of messages and measured values on PC card possible
  • Up to 2048 power tags (process connections) and 2000 alarms and events each
     
   

Available coupling

   

The MP270 offers connections to various controllers via already integrated interfaces.

  • SIMATIC S7/M7 via MPI or PROFIBUS-DP (except S7-210/212)
  • Serial SIMATIC S5 via AS511 or PROFIBUS-DP
  • Serial SIMATIC 505 via NITP or PROFIBUS-DP
  • Allen Bradley SLC 500 and serial PLC-5 via DF1
     
   

Harmonious integration into the ProTool product familyaft

   

The MP270 multi panel is ideal for on-site control and monitoring of machines. It fits smoothly into the family of proven SIMATIC operator panels - from the OP3 to the PC platforms. The MP270 is config-ured with the configuration software SIMATIC ProTool® V5.1 or ProTool/Pro ® V5.1 under Windows 95/98/NT. The configuration data are transferred serially from the configuration station to the MP270.

   

 

   
   

 

The ProTool family permits transparent concepts ranging from visualization with SIMATIC operator and touch panels close to the machine to the multifunctional platform and PC-based solutions. Trans-parency of configuration means, for example, that parts of projects ranging from operator panels to Windows CE platforms to a PC platform can be borrowed and vice versa when the target hardware permits (e.g., color depth, screen resolution, archiving medium and functionality). Screens, message texts and variables can be taken from a ProTool/Pro project for a PC application and also used for an MP270 project, for example. Identical methods of use with the same look and feel reduce costs for configuration, training and familiarization, and maintenance.
