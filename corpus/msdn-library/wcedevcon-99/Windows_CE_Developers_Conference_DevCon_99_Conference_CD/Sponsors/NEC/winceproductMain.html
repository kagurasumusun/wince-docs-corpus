VR4121 User's Manual

VR41xx Power Management

The highly integrated 131-MHz VR4111 uses the ultra-low-power-consuming VR4120™ CPU core and SDRAM/EDO DRAM memory controller. The processor offers excellent power consumption and performance rates in a highly integrated, low-cost system on a chip. The VR4120 CPU has an optimized five-stage pipeline, 16 KB instruction cache, 8 KB data cache, multiply-and-accumulate (MAC) unit, and SDRAM/EDO DRAM memory management unit that delivers high performance in a compact, low-cost chip. The integrated peripherals include a power management unit, DMA unit, interrupt control unit, timers, real-time clock, serial interface, IrDA® interface, keyboard interface, touch-panel interface, host signal processing unit (software modem), A/D converter and D/A converter.

  

 

VR4111 Product Brief

VR4111 User's Manual

  

Utilizing the popular MIPS® RISC architecture, the 90-MHz VR4111 microprocessor offers excellent power consumption and performance rates in a highly integrated, low-cost system on a chip. The ultra-low power consuming VR4110™ CPU core has an optimized five-stage pipeline, 16 KB instruction cache, 8 KB data cache, multiply-and-accumulate (MAC) unit, and memory management unit that enable high system performance. The integrated peripherals include a power management unit, DMA unit, interrupt control unit, timers,real-time clock, serial interface, IrDA® interface, keyboard interface, touch-panel interface, host signal processing unit (software modem), A/D converter and D/A converter.

VRC4171 User Manual

 

  

The VRC4171 companion chip has been specifically designed for the VR4102 and VR4111microprocessors. The VRC4171 incorporates a color/monochrome LCD graphics display controller, two PC Card™/Compact Flash™/Miniature Card™ controllers, and several general-purpose I/O pins. The combination of the VR4102 and VR4111 with the VRC4171 is an excellent performance/cost solution for the next generation of Windows CE-based applications.

  
       

VRC4373 Product Brief

  

The VRC4373 is a single-chip device providing a glueless, high performance interface for the VR43XX, VR54xx microprocessors, a DRAM memory system and a standard PCI bus. The device also provides a 66MHz bus interface and 33MHz PCI bus interface. It also includes 4 DMA channels and 16550 UART. The interface control logic is highly configurable by software and requires minimal hardware configuration for many different systems.

The cost-optimized VR4305 microprocessor expands the VR4300 family of processors into price-sensitive, high-volume consumer applications such as set-top boxes, low-end printers, network computers and consumer electronics. Delivering a clock rate of 80 MHz and 105 Dhrystone MIPS, the VR4305 microprocessor is ideal for use in embedded systems where low cost and 64-bit performance with scalability are desired.

  
   

 

  

VR4300/4305/4310 Datasheet

VR4300/4305/4310 Product Brochure

VR4300/4305/4310 User Manual

  

The VR4310 microprocessor is the pin-compatible successor of the VR4300. Taking advantage of NEC's advanced 0.28-micron (drawn) process technology, the VR4310 versions use almost 50% of the power that the VR4300 uses at the same frequency. The device has an internal operating frequency of either 100, 133, or 167 MHz running at 3.3 volts. The VR4310 has an optimized five-stage pipeline, 16 KB instruction cache, 8 KB data cache, memory management unit, floating-point arithmetic unit (FPU), and clock generator, and is compatible with MIPS I, II, and III instruction sets.
