Utilizing Internet Technologies

Overview of Internet Explorer for Windows® CE
Windows CE now comes with award-winning Microsoft Internet Explorer technology. Boasting the best compatibility of any embedded browser, Internet Explorer for Windows CE provides an Internet SDK that lets you utilize reusable components to build Internet-enabled applications. In this presentation, we'll provide an architectural overview of Internet Explorer for Windows CE, and introduce other browser-related technologies, including JavaScript and Windows Media technologies.

Windows CE® Internet Programming
By coupling Windows CE with the Internet, you can easily deploy small, mobile devices that are well-connected to the world. Attend this session for an in-depth look at the many elements of Internet programming, starting with the basics of sockets and WinInet support. We'll review available browser support, including the Pocket Internet Explorer and the channel browser, and discuss the recently introduced Internet Explorer for Windows CE. You'll leave this session ready to connect your Windows CE devices to the Internet.

Microsoft® Microbrowser Technology
Microsoft Microbrowser technology is designed for low-end Internet appliances, such as cell phones and pagers. Microbrowser Version 1, which has a footprint of less than 100k, supports HTML 3.2 and HTTP 1.0, and renders on small screen displays. In this session, you'll learn how the powerful Wireless Product Adaptation Kit (WPAK) can help OEMs port the browser to low-end devices, as well as author for various low-end devices. We'll demo the browser on a real cell phone and on Windows NT through a phone emulator.

Building Web Pages With Windows® CE In Mind
Windows® CE can now display web pages containing dynamic HTML, Cascading Stylesheets, and other fourth generation browser features. In this session, we'll explore the differences between Internet Explorer 4.0 on the desktop and on Windows CE, and discuss HTML, Document Object Model, JavaScript®, and other Internet-related features.

Internet-enabling Your Windows® CE Applications with WinInet
The Microsoft® Win32® Internet (WinInet) API provides stand-alone applications with easy access to standard Internet protocols, such as FTP and HTTP - and it abstracts the protocols into a high-level interface that is familiar to Win32® developers. In this session, we'll contrast the current WinInet API vs. previous versions and the desktop implementation. We'll also provide source code samples to illustrate how APIs enable you to accomplish common tasks like establishing an Internet connection, managing Uniform Resource Locators (URLs), HTTP and FTP sessions, and more.

Put the Web in your Product: Hosting the Internet Explorer WebBrowser Control
Hosting the Internet Explorer WebBrowser ActiveX® control is the best way to enable Internet technologies in your product. Whether you want to host the control to provide simple Web browsing right in your product, or to make your product's entire user interface HTML-based, this informative session is a must. We'll provide source code for a sample host application, and discuss the interfaces and methods needed to host the control. You'll also learn which methods are available to drive the control, which events are fired by the control, and how to handle these specific events.

An Introduction to the Windows® CE Web Telephone
This session will provide an overview of the key characteristics of the latest Windows® CE information appliance - the Web Telephone. Learn about the market, the product, the hardware and software, the users, and how to target services and solutions at this category of device. See a live demonstration and come prepared to be blown away by one of the coolest new Windows® CE powered products!

Delivering Handheld Applications over the Internet Using AvantGo Technology
AvantGo.com enables developers to offer applications and content to Windows® CE users over the Internet. In this session, Marty Kacin, director of professional services for AvantGo, will discuss and demonstrate a range of applications that make it is possible to deliver to handheld devices through AvantGo.com. He will cover the HTML design principles of optimizing for a variety of handhelds, and he will talk about how to offer an application using the subscription model.
