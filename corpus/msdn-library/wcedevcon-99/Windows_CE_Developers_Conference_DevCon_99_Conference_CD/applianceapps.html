Designing Applications for Information Appliances

Developing Great Applications for the Palm-size PC
The lightweight, Palm-size PC is positioned to be a very hot device for both business and consumer productivity. If you want to extend the reach of your existing Windows® or Handheld PC application to the consumer's palm, catch this informative session. You'll hear straight from the development team how to write Windows® CE-based applications targeted for this platform. Hear real-world, hard-core code examples involving the unique hardware functionality APIs enable for features like voice, digital ink, handwriting recognition and soft keyboard input.

Developing Great ActiveSync™ Plug-ins
Want to learn how to quickly and easily develop an ActiveSync™ service provider? This session starts with the fundamentals, then dissects a sample sync service provider to show you how to easily build one of your own. We’ll cover both desktop and device-side components.

Plugging Into Pocket Outlook®
This workshop provides an overview of the Pocket Outlook® object model, and highlights some of its differences from Outlook’s desktop version. The Pocket Outlook® object model, which allows developers to access and manipulate appointments, tasks, contacts and cities, uses a COM-based API set modeled after the desktop version, usable in both C++ and Visual Basic®. It works on the handheld PC version 2.0 and higher, and on all versions of the palm-size PC.

Targeting A Single Source to Multiple Windows® CE Platforms
One of the great strengths of Windows® CE is its highly adaptable configuration, which enables the software engineer to build on the common subset of the Win32® API supported by multiple devices. Attend this session to learn tips on targeting the Handheld PC Pro, Palm-size PC, and Auto PC devices.

Developing Great Applications for the Handheld PC
The latest generation of handheld PCs has many new features that you can exploit with your applications, including larger screens, new input types, and an improved object store. In this session, the Windows® CE development team will explain how to extend the reach of your programming expertise and existing Win32®-bit application to capture market opportunities. You’ll learn tips, techniques and programming samples for the handheld PC, covering a variety of topics such as the expanded GDI, diverse communications options and APIs.

Secrets of Application Installation
It’s no secret that a well-written, friendly setup application is one of the easiest ways to make a great first impression with the user. In this session, you’ll go undercover with the setup gurus of Windows® CE Services, probing the hidden depths of AppInstall. You’ll also learn the technical details of writing and registering a file converter.

Working with Microsoft® Marketing - PC Companions
Got a cool product for a Windows® CE-based device and aren’t sure how to get your message out? Looking for customers who purchase mobile devices in computer superstores to evaluate for their workplace? Not sure if selling your product on the Internet is giving you enough exposure to corporate customers? Come learn how Microsoft’s Windows® CE marketing team is helping bring exposure to this platform and the hundreds of new products being created around it. Get tips on what enterprise customers are looking for and how to reach them effectively. Learn how Microsoft® is working with major resellers to create special areas devoted to handheld devices and accessories. Find out what programs are available for third parties to participate in to reach end-users. This track is applicable to all those interested in learning how to market software and accessories for PC Companion devices running Windows® CE.

Enabling Mobile Enterprise Solutions for the Palm-size PC
The recently released Windows® CE for Palm-size PC enabled several important features for corporate or solution developers, such as color display, ADO for Windows CE, MFC and VB runtime. This session will provide specific detail about the Palm-size PC software and hardware features added in the Wyvern release, as well as an overview of the software development kit for the Palm-size PC. This includes a demonstration of the device, and a demo of a model ISV application using the Palm-size PC.

Auto PC Features Overview
In this session, you will learn how to develop great applications for the Auto PC using the forms-based application development environment. Other topics include adding your application to the Auto PC shell, enabling speech recognition, using the Text to Speech Interface, using the Shell services, and more. OEM customizations issues such as multiple screen regions, softkeys, etc. will also be covered.

The Auto PC Forms Manager User Interface
The Auto PC Forms Manager User Interface offers a rich set of controls to support a wide variety of applications. Come learn what controls are available for application development. You will also learn how to deal with OEM customization issues regarding User Interface and Shell. Audio Interfaces will also be covered in detail.

Porting Desktop Visual Basic® Applications to Windows® CE
The purpose of this session would be to orient the experienced Visual Basic® developer to the differences between the desktop PC and the H/PC device. Specifically, the focus will be on how to go about porting existing desktop applications to Windows® CE. Developing applications for the H/PC requires the developer to rethink both their interface and data handling techniques. Here we will look at how a developer can adjust their programming style to meet the needs of the Windows® CE environment.

Data Access Technologies Featuring ADO
With the familiarity of ADO on the desktop/laptop, ADO for Windows® CE is a great way to extend access to corporate databases in SQL Server and Access. This session will discuss how you can extend DNA applications with the version of ADO included in Windows CE 2.11, part of the new Handheld PC Professional Edition. We will discuss out-of-the box capabilities with ADO for Windows CE and also valuable third party tools to enhance access to corporate database & server applications from Windows® CE PC Companion devices.

Developing PC Companion Applications Using the Microsoft® Windows® CE Toolkit for Visual C++® 6.0
The Windows® CE Toolkit for Visual C++® makes it easy for developers familiar with Visual C++® to apply their existing 32-bit Windows development experience to create new Windows® CE-based applications targeted toward PC Companions. Leverage the Microsoft® Windows® CE development team to gain real world experience in using MFC for Windows® CE 2.11 and beyond, MFC AppWizard and ClassWizard for Windows® CE. See the new features which will make targeting and creating applications for multiple platforms easier to handle. Learn how to use emulation to expedite development of new applications, see how it allows you to test and debug your Windows® CE applications. Hear tips, view code samples and learn how to use Visual C++® to code new Windows® CE functionality like color displays and mixed CPU code generation.

Building Wireless Enterprise Applications for Windows® CE
This session will focus on the proper design and development of robust, transactional mobile applications for Windows® CE-based devices, using the Windows® CE Toolkits. This practical session will outline the important considerations necessary for developing high-performance reliable applications that extend the reach of your enterprise. Topics will include: universal data access, asynchronous communication, low-bandwidth channels, out-of-range conditions, online vs. occasionally connected operation, network file & print services, and utilizing middle-tier business logic components.

Developing Custom Applications for Windows® CE in the Enterprise (Case Study)
When enterprise customers want to extend access to information using Windows® CE-based PC Companion devices, they are most often interested in custom line of business solutions. Although the development environment is similar to standard Win32®, there are some important considerations and steps to keep in mind for Windows® CE. This session will include an in depth technical discussion of the end-to-end process for developing custom applications to take advantage of Windows® CE features and most effectively integrate with Windows NT® and BackOffice® products. This will be presented in a case study format by two top-tier Windows® CE solution providers that developed solutions for customers in the insurance industry.
