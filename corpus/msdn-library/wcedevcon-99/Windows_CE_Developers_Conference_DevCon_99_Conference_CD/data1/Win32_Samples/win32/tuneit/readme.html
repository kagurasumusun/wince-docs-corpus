AutoPC Tuneit Sample Application

This application shows how to use the tuner and audio manager functions to control the radio tuner and audio parameters.

To Build

From within the Visual Studio integrated development environment, open Tuneit's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build tuneit.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.
