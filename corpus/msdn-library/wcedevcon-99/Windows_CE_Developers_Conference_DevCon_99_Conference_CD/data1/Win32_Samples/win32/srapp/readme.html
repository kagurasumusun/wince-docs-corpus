AutoPC SRAPP Sample Application

This application demonstrates how to use speech recognition in your applications.

To Build

From within the Visual Studio integrated development environment, open SRApp's project (.dsp) file. Select the proper platform (Emulation or SH3 based device), and select "Build srapp.exe" from the build menu.

To Use

This sample shows how to create voice menus and how to train speaker dependent voice templates. While in the "Listen for Numbers" or "Listen for Colors" forms, you must press either the push to talk button, or say the wakeup word before the sample will recognize your voice.
