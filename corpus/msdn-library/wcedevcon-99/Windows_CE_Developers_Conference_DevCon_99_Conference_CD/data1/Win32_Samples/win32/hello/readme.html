AutoPC Hello World! Sample Application

This application demonstrates the most basic operations and steps required for an AutoPC application to create a form and have itself shown on the panel. The application creates a form with one control, a power list box (menu). Then it populates the PLB with a single entry of type ASFC_PWRLB_TYPE_COMMAND called Exit. When this menu/PLB option is selected, a WM_COMMAND message goes to the event sink which exits the application.

To Build

From within the Visual Studio integrated development environment, open Hello's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build hello.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

Pressing the enter button on the faceplate will quit the application. No other buttons have any functionality.
