AutoPC SimpleClock Sample Application

This application demonstrates an extremely simple application that implements a IASClassMsgSink so we can catch key presses.

To Build

From within the Visual Studio integrated development environment, open SimpleClock's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build SimpleClock.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

When the sample comes up there is only a clock control and a label. Press Any key on the keypad to exit.
