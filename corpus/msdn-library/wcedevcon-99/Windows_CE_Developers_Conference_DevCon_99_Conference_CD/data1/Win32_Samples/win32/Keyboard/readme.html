AutoPC Keyboard Sample Application

This sample demonstrates the receiving of keyboard messages from the AutoPC Faceplate. It also demonstrates simple reception of other system messages.

To Build

From within the Visual Studio integrated development environment, open Keyboard's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build keybaord.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

Press the faceplate buttons, and description text will appear on the faceplate. Press escape to exit the application.
