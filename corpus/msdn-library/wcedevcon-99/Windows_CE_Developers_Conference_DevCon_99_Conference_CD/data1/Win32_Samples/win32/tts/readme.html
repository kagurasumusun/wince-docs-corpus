AutoPC TTS Sample Application

This application demonstrates simple text-to-speech in an application.

To Build

From within the Visual Studio integrated development environment, open TTS's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build tts.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

 To Use

The application shows a power list box with multiple entries. Two of the entries (Hello world and Welcome to the Auto PC) just simply speak their text names. The Read Form selection tells the form and the control to Speak themselves. The Read Menu Items speaks each menu item and advances the menu using bookmarks in the speak function. Exit will say "Exit" and quit the application.
