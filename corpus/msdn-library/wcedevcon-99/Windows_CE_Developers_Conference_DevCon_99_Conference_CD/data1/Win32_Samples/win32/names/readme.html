AutoPC Names Sample Application

This application demonstrates how to use the Address book API and a message box. The address book is brought up with the abDialog function, after filling out an ABDIALOGINFO structure to indicate which features the user should have access to. Then whatever fields we are interested in can be retrieved with the abRead function.

To Build

From within the Visual Studio integrated development environment, open Names's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build Names.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

Select the "Select a contact" entry in the power list box and find a person's name in the address book. Press enter while you're in that contact's card to select that person's name, and the application will tell you what that person's name means.
