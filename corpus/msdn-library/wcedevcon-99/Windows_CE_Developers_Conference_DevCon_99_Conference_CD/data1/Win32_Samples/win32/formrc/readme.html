AutoPC FormRC Sample Application

This application creates a single form using a constraint based resource script.

To Build

From within the Visual Studio integrated development environment, open FormRC's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build formrc.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

Move up and down the menu, changing the options. Select done when finished to exit.
