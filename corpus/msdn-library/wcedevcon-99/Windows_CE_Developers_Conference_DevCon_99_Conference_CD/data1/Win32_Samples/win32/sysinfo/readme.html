Auto PC SysInfo Sample Control Panel Applet

This applet shows how to create a control panel applet for the Auto PC v 1.0. The applet is a DLL renamed to a .CPL file, and placed in the \Windows directory of the object store.

To Build

From within the Visual Studio integrated development environment, open SysInfo's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build sysinfo" from the build menu.

To Use

Use empfile or the remote file viewer to copy the .cpl file to the object store's (Emulator or device) \Windows directory and run the control panel application. This will load and run the applet. To debug the CPL, you must set a hard-coded break point and have the debugger attached to the ctlpnl.exe process on the emulator or debugger.
