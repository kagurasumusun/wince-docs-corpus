AutoPC MultForm Sample Application

This application demonstrates how to create and manage two different forms and use a menu to switch between the two.

To Build

From within the Visual Studio integrated development environment, open MultForm's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build MultForm.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

When the application starts you will see a simple form displaying hello world. Select the menu button and you will be presented with a menu of two forms selections and an exit. Select the clock menu item and you will see a form with a clock on it. Select the exit item on the menu and you will close the application.
