AutoPC Multi_RC Sample Application

This application is a version of MultiForm which uses a resource script instead of programmatically creating controls. It demonstrates how to use the IASActiveForms interface to switch between multiple forms.

To Build

From within the Visual Studio integrated development environment, open Multi_RC's project (.dsp) file. Select the proper platform (Emulation/SH3 based device), and select "Build Multi_rc.exe" from the build menu. To execute, start up and power up the Auto PC emulator and select execute from the build menu.

To Use

Press the menu key and select which form you want to be brought into the foreground. Select the Exit option from the menu to quit the application.
