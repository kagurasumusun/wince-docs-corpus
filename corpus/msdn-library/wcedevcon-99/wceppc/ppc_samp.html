Sample Code for a Palm-size PC

The Windows CE SDK provides sample code that illustrates the Palm-size PC development environment. The sample code is described in the following table.

Sample code
Demonstrates
EReceipt Sample Application Using the Rich Ink control
Generic Sample Application Basic graphics and windowing techniques
Hello Sample Application Basic windowing techniques
InkControl Sample Application Basic Rich Ink Control techniques
Soltr Sample Help File The unique tags and structure of a Help for Windows CE file

Note Some of the sample applications for a Palm-size PC have the same names as sample applications for an H/PC. Assume that the applications discussed in this chapter are samples for a Palm-size PC, unless otherwise noted.
