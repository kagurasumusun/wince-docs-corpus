Building the Sample Applications

You can build the sample applications for a variety of devices using the SH3 CPU, the MIPS CPU, or the x86 Windows CE emulator running on a desktop computer. However, not all of these options are available for each application. In addition, you can compile the sample applications in either debug or release mode. The following step-by-step instructions demonstrate how to build the Generic sample application for the X86 emulator in debug mode. The process is analogous for the other applications and build configurations.

    To compile the Generic sample for the X86 emulator in debug mode

  1. Select Open Workspace on the File menu.
  2. Navigate to the directory that contains the sample code.
  3. Select Generic.dsw, and then click Open.
  4. Select Set Active Configuration on the Build menu.

    The Select Active Configuration dialog box displays the configurations available for this sample.

  5. Select Generic-Win32 (WCE x86em) debug, and then click OK.
  6. Select Always Download on the Build menu.

    This puts a check mark on Always Download.

  7. Select Rebuild All on the Build menu.

    To run the Generic sample for the X86 emulator in debug mode

  • Select Execute Generic.exe on the Build menu when compiling finishes.

    To terminate the emulator

  1. Click the Start button on the emulator.
  2. Select Exit Apps.
