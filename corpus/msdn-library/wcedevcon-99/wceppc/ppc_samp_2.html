EReceipt Sample Application

The EReceipt sample application demonstrates how to use the Rich Ink control to design an electronic receipt. The application includes fields for a consumer’s name, phone number, and credit card number It also includes a field for the amount charged. A user can sign at the bottom of the form, save his or her signature, or load a previously-saved signature. However, EReceipt does not read or save any consumer information other than a signature.

To build the EReceipt sample application, follow the procedure described in Building the Sample Applications. In the procedure, select one of the following project configurations:

  • Windows CE emulation
  • Windows CE chipset (MIPS or SH3)

EReceipt initializes and loads the Rich Ink control in InitInstance using InitCommonControls and InitInkX. Then, the application calls WinMainProc. The main purpose of WinMainProc is to respond to IDC_SAVE, IDC_OPEN, and IDC_CLEAR messages. WinMainProc demonstrates how to use IM_CLEARALL, IM_GETDATA, IM_GETDATALEN and IM_SETDATA messages to clear, save, and display the content of the Rich Ink control in a dialog box.

For another example of using the Rich Ink control, see InkControl Sample Application. The Note Taker application on a Palm-size PC is also an example of a Rich Ink control.
