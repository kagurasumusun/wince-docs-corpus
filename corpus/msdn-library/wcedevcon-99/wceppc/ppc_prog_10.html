Using the Built-In Infrared Serial Port on a Palm-size PC

Palm-size PC applications can transmit data, such as records or files, from one Palm-size PC to another through the built-in IrDA port. Because Palm-size PC software does not support Windows CE Explorer, it is your responsibility to implement transmission capabilities using the IrDA port. You can implement this with the Windows Sockets (WinSock) and Infrared Sockets (IrSock) interfaces. For more information about WinSock and IrSock, see the Core Services section of the Programmer's Guide.
