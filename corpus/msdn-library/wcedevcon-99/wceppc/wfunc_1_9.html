SHInitExtraControls

This function initializes parameters for the CAPEDIT and Palm-size PC ToolTips controls.

At a Glance

Header file: Aygshell.h
Windows CE Versions: 2.01 and later

Syntax

BOOL SHInitExtraControls(void);

Return Values

None.

Remarks

ShInitExtraControls operates in the same manner as InitCommonControls. Only use ShInitExtraControls to initialize controls unique to the Palm-size PC, such as the CAPEDIT control and certain ToolTips controls.
