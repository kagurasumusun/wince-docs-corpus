Using the Input Panel to Communicate with the Input Method Editor

The input panel was ported from the original Palm-size PC shell into Windows CE 2.10. The input panel architecture was then generalized and made into a selectable component in the operating system. To accommodate an ever-wider range of capabilities, the COM interfaces between the input panel and the input method editor (IME) have been extended. The following section discusses the new interfaces between the input panel and the IME available on a Palm-size PC version 1.2.
