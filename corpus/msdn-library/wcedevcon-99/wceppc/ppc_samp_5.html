InkControl Sample Application

The InkControl sample application demonstrates how to create and use a Rich Ink control. A user can enter handwritten notes on the touch screen, save work, and access previously-saved files.

To build the InkControl sample application, follow the procedure described in “Building the Sample Applications” earlier in this chapter. To build the InkControl sample application, follow the procedure described in Building the Sample Applications. In the procedure, select one of the following project configurations:

  • Windows CE emulation
  • Windows CE platform (MIPS or SH3)

The InkControl sample application loads and initializes the Rich Ink control in InitInstance using the InitCommonControls and InitInkX functions. InitInstance also uses the developer-defined GetInkCtrlMenu function to find the Rich Ink built-in menu handle. Finally, InitInstance subclasses the Rich Ink control and adds the Open and Save As menu items. Then, the application calls InkProc. The main purpose of InkProc is to open and save files.

For another example of using the Rich Ink control, see EReceipt Sample Application. The Note Taker application on a Palm-size PC is also an example of a Rich Ink control.
