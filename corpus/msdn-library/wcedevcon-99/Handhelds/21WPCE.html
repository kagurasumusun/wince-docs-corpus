WINDOWS CE ENVIRONMENT

Compaq Computer Corporation

Windows CE devices like the Compaq Aero 2100 represent the fastest growing segment of the palm-size PC market. There are many good reasons for this turn of events. As an operating system, Microsoft Windows CE represents a smooth migration path for users already trained on Windows 95/98 or Windows NT. It uses the same familiar Microsoft Windows interface and programs as those found in Windows 95/98/NT and even includes condensed versions of common office applications like Microsoft Outlook. For the busy professional, this means a quick start with no extensive training required.

The Practical Side of Windows CE

Windows CE is fast becoming a platform for a wide array of mobile devices, ranging from palm-size PCs to handheld devices and from automotive computers to household appliances. In each case, Microsoft has created a version of Windows CE uniquely suited to the individual device type/form factor, yet still compatible with all the other manifestations of Windows, ranging all the way up to the server level.

This means that Windows CE not only offers a well-known user interface, but also brings seamless data integration and synchronization features to palm-size devices. Many products offer subsets of the functionality found in Windows CE, but none combine them into a single package like Windows CE.

 

The Business Case for Windows CE

Windows CE devices allow mobile users to connect directly to a corporate LAN using TCP/IP and communicate with other devices that are either running MS Windows or that communicate via TCP/IP - including UNIX, PC or Mac desktops and portables, web servers, database servers, application servers, and most types of advanced client-server systems. Special-purpose clients can be programmed in Windows CE to communicate directly with these information repositories across an intranet, an extranet, or the Internet.

Thousands of developers around the world are already familiar with Windows, and have already created scores of applications for the Windows CE platform. This number will continue to grow and expand, as Windows CE become more widespread in both the business and consumer worlds. Microsoft has improved developer support by offering software programming toolkits for Visual C/C++ and Visual Basic. This empowers corporate developers and independent software vendors to use palm-size PC "thin clients" for increasingly sophisticated mobile user applications. Meanwhile, many new Windows CE enhancements are constantly making their way to market, including low-power modem/network cards, display cards, and high performance batteries.

 

Windows CE Features

The Windows CE version for palm-sized PCs provides a familiar set of software features that have proven indispensable to the mobile professional. In particular, a miniature version of the Microsoft Outlook program called Pocket Outlook helps mobile professionals keep track of key information using the following applications:

  • Calendar function helps users schedule appointments, meetings, and events that can be synchronized with the desktop version of Microsoft Outlook.

  • Contact List lets users maintain important information such as phone numbers, street and e-mail addresses, and more for their friends, family, and business associates. Based on their preferences, user can customize the type and amount of information that appears under a contact name.
  • Task Tracker helps users keep track of pending and completed action items. Priority and reminder functions help keep track of multiple tasks associated with managing complex projects.
  • Note Taker allows users to write ideas, draw sketches, and make diagrams the way they would on paper.
  • Voice Recorder is an even quicker way to take notes, with one-button operation that turns the Compaq Aero 2100 into an instant recording device — even when the unit is off. The low memory demands of voice notes allows users to store hundreds of recordings. Recordings use 3KB of memory for every 10 seconds of recorded messages, depending on the level of fidelity chosen.
  • Calculator provides all standard calculator functions including add, subtract, multiply, divide, square root, and memory store/recall.

For any of these applications that require user input, Windows CE has provided a built-in Jot Character Recognizer that translates scribbled notes into neatly typed information. It also provides a tiny "virtual keyboard" that can be used to directly type in notes, answer queries or messages, and fill-in dialog boxes, all by simply tapping the stylus on the keyboard.

 

Other Important Features

Windows CE functionality extends far beyond these simple software applications to provide benefits and features that extend the value provided to mobile professionals:

  • Active Desktop™ feature allows users to select what information is displayed on the opening screen when the unit is turned on. Important and frequently accessed information, such as the day's appointments and active tasks, can be accessed instantly by a tap of the stylus.

  • Customizable interface allows users to change palm-size PC settings to match their work habits. Users can:
    • set a security password restricting access to the unit;
    • associate specific programs with the front panel buttons;
    • adjust memory allocation between storage and program memory;
    • turn sound on/off for certain functions to personalize usage or conserve battery life;
    • select background "wallpaper" for the Windows CE desktop;
    • select alarms and types of sounds;
    • control the type, organization, and detail level of items listed on the Start Menu.
  • Automatic synchronization ensures that both the desktop and palm-size PC share the latest calendar, contacts, tasks, and inbox (e-mail messages) information. Windows CE's special ActiveSync feature is initiated automatically each time the user docks the device in its special docking cradle.
  • Channel feature downloads web information from an inter/intranet website to the Compaq Aero 2100 for offline viewing. A Channel is a Web site or Web-formatted content that is automatically downloaded to the palm-size PC from the desktop via the synchronization process.
  • Remote connectivity allows users to stay connected even when they are travelling away from the office. Using an appropriate CompactFlash modem card, connections can be made to an Internet Service Provider (ISP), to a corporate network through Remote Access Services (RAS), or to the desktop PC via a direct dial-up connection. Windows CE also supports wireless cards seamlessly.
  • Backup and restore features allow users to back up data created on the palm-size PC by copying it from the Compaq Aero 2100 onto removable CompactFlash memory cards.
  • Programmability and back-end integration. A full set of developer tools like Visual Basic and Visual C/C++ make Windows CE a complete application development platform for enterprise solutions. Backend integration with corporate servers allows enterprise solutions including "thin client" (Exchange, Citrix, database, etc.) and vertical applications (data collection, barcode forms, etc.).
  • Easy upgrades. Upgrading the Windows CE operating system is quick and easy. The system resides on a chipset that can be easily upgraded by removing the back cover of the device and replacing the existing O/S chipset card with the new one. RAM and ROM are included on the same chipset, so that upgrading one will necessarily affect the other.
