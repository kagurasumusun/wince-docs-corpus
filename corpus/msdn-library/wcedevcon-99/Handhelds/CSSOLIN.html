INTRODUCING THE COMPAQ C-SERIES
The Need for a Handheld PC

Mobile professionals in all industries have similar information-access needs. They are often out of their offices for extended periods and sometimes travel great distances. While away, they need a highly mobile, easy-to-use, and low-cost device to check e-mail and make remote connections to their office PC, LAN, or corporate networks. They need instant access to critical data and personal information at any time wherever they are. Furthermore, easy-to-use remote fax and Internet connections are essential. Finally, easy and instant synchronization with the PC/Network to manage the information represents another core need.

As companies expand into global marketplaces, professionals are asked to be more productive while they are away from their offices. Whether they are in a meeting across the hall or with a customer on the other side of the world, they must have fast and easy access to complete personal and company information.


Key Advantages of the Handheld PC

The C-Series handheld PC meets the needs of mobile professionals where other mobile PC technologies seem too complex, feature rich, or expensive, or not robust enough. While a notebook PC is the best tool for having a complete and full-functional PC with you, the handheld PC excels in providing the essential productivity features, information access and data synchronization capabilities in the smallest possible form factor. Other main advantages of a handheld PC are its instant-on feature, support for Pen input, and low total cost of ownership.


Windows CE Functionality

Aside from RAS, e-mail and Internet access, other requirements of mobile professionals include the ability to review documents, write memos or a letter, prepare and edit spreadsheets, manage the contact database, and handle busy agendas. Some mobile professionals must access customer files and display PowerPoint presentations. All of these cases require seamless information flow and real-time data synchronization between the handheld PC and the desktop PC. The Windows CE operating system meets these requirements by providing easy-to-use "Pocket" versions of Microsoft Word, Excel, Outlook, Explorer and PowerPoint. Windows CE also has the capability of synchronizing data and files between the handheld PC and the desktop.


Compaq C-Series: Handheld PC with Windows CE 2.0

Recognizing the need for a handheld PC in the mobile professional market, and acknowledging that Windows CE is the preferred environment, Compaq specifically designed the C-Series to meet these needs. Windows CE Environment

Microsoft Windows CE is the logical choice for mobile professionals who want robust connectivity and functionality without sacrificing compatibility.

If you can use Windows, you already know how to use Windows CE. It uses the same familiar Microsoft Windows interface and programs as those found in Windows 95 and in Microsoft Office applications like Word and Excel. For the busy professional, this commonality saves the time that it would take to learn a new interface or program.

In addition to being easy to learn, Windows CE devices are highly mobile. Each weighing a pound, the monochrome and the color C-Series devices can fit into a purse or coat pocket.

Windows CE not only offers a well-known user interface, but also brings the most seamless integration and data/information synchronization capabilities with PCs to handheld devices. Many devices offer subsets of the Windows CE functionality, but none combine them into one product like Windows CE.

For example, most handheld devices allow you to store your contact and/or calendar information, but few combine that functionality with an e-mail program (included with Windows CE). Even fewer handheld devices handle e-mail attachments, and enable full functional Web browsing using a Pocket version of Internet Explorer — other capabilities of Microsoft Windows CE.

Windows CE devices also include versions of the most popular productivity applications available — those found in Microsoft Office. These Microsoft applications include Word, Excel, PowerPoint, Internet Explorer, and Outlook. Other non-Windows CE devices running their own proprietary operating systems cannot offer native versions of these Microsoft Office applications and documents.

Few non-Windows CE handheld PC devices enable printing directly from the device or transferring data from or to another device or printer using an infrared or serial connection. Windows CE devices let you directly connect to a corporate LAN using TCP/IP. Windows CE offers a powerful highly portable solution that combines standard MS Outlook contact and time management functions with connectivity and productivity applications like Word and Excel. It helps users keep information up-to-date, even while out of the office. It keeps important information readily on hand where it is needed. Best of all, it helps users to stay in touch with people while away from the office.

Seamless Windows compatibility is another key advantage of the Windows CE environment. Data synchronization with desktop applications is seamless, and thanks to ActiveSync, happens completely automatically - you don't even have to push a button. Thousands of developers around the world are already familiar with Windows. Dozens of applications are already available for the Windows CE platform alone. This number will continue to grow and expand as more devices get into the hands of users.

Microsoft has extended this developer reach by offering toolkits for Visual C/C++ and Visual Basic. This empowers corporate developers - enabling handheld PC service to their users.

Numerous independent hardware vendors (IHVs) are bringing dozens of Windows CE products to market, including low power modem and network cards, display cards, and high performance batteries, etc.

Reducing the Total Cost of Ownership

The decision to implement mobile computing systems is mainly driven by the expected productivity gains that result from mobile data access and availability of information to the professionals.

The reason to equip professionals with highly mobile device like the Compaq C-Series is based on the productivity gains that can be expected.

As an example let's take a professional that earns around $60K p.a. Let's assume he can — only — increase his productivity by adding around 1 hour of productivity time during a day. Examples are:

  • Reviewing documents or answering email during idle time while travelling;
  • Send and Receive email in Hotels;
  • Taking notes or action items unobtrusively in meetings;
  • Checking the agenda of a busy day avoiding conflicts or delays;
  • Setting appointments or looking up contact information while away from the desk;
  • Present a sales or product presentation at the clients office;
  • Responding with a well calculated offering to a customer request on the spot; and
  • Checking stock levels immediately — using wireless technologies — and being able to make the best offer to the customer immediately.

Assuming a professional works an average 240 days a year. With a 1 hour daily productivity gain he adds around 240 hours of productivity. This results into 4-5 extra working weeks which results around $5000 direct benefit - not taking into account the potentially increased business opportunities and improved customer satisfaction.

In scenarios where a more specific application is required and tied to a dedicated task (mobile data collection and data entry, forms based applications etc.), the productivity gains can be significantly higher. Mobile solutions cannot also contribute to the productivity by eliminating steps in the data entry process and by reducing the cycle times needed.

As studies have shown the cost of the actual mobile computing device is only a small part of the real cost of implementing such solutions. The overall cost of implementing such a solution — often referred to as Total Cost of Ownership (TCO) — is a critical factor to decide the return on such a project. TCO is the summary of all costs of a system including Hardware, accessories, training, service and support etc.

Compaq has developed key technologies to reduce TCO and implemented these throughout their different product lines.

Traditionally mobile computing devices have a higher TCO than desktop computers as a result of higher system cost, more requirements for LAN and remote infrastructure, and higher failure.

The Compaq C-Series is the first handheld PC that was developed to encompass enablers towards the reduction in TCO for highly mobile devices.

Hardware cost:

  • The C-Series offers a compelling price/performance ratio.
  • All systems have a single Type II PC card slot to take advantage of many existing PC cards (e.g. Ethernet connections).
  • All systems come with an AC adapter.
  • Most systems come with NiMH rechargeable batteries that can be recharged in the system.
  • The 20 MB color system comes with the Convenience cradle bundled.
  • The Compaq C-Series models share most of the accessories and options. This greatly facilitates the effort involved in ensuring accessories/options are available and allows to share accessories across different handheld PCs.
  • The C-Series is equipped with an integrated low power 33.6kbps softmodem that eliminates the need for an expensive PC card modem but also reduces power consumption significantly.
  • To provide enough performance for today and tomorrows applications, the C-Series is equipped with a high performance MIPS-based RISC processor that delivers an "instant computing" experience.
  • In combination with the Cradle, the C-Series can be locked in place using a "Kensington Lock" compatible locking cable. When the unit is in an unattended office or displayed in a public area this prevents theft.
  • Compaq product quality and dedication to customer satisfaction will add to the overall reduction.

Software cost:

  • All C-Series come with 16MB ROM based OS and applications.
  • The ROM includes the complete Windows CE Operating system including VB runtime and Microsoft Foundation Class (MFC).
  • The ROM includes a complete Package of Microsoft Pocket Office (Pocket Excel, Pocket Word, Pocket PowerPoint, Pocket Outlook, Pocket Internet Explorer and even Pocket Solitaire).
  • Built-in Desktop/LAN connectivity software and data synchronization applications.
  • With these applications being standard on all C-Series products — and being stored in ROM — the network/system administrator can be sure to have a standardized set of applications on all devices.
  • A number of Compaq developed utilities and bundled productivity applications add value and features to the user. These applications can be downloaded to the system at the administrator's or user's discretion.

Upgradeability/Expandability:

  • The Compaq C-Series uses an Industry standard Type II PC card slot (a.k.a. PCMCIA) to support a variety of expansion cards including network adapter, VGA-out, storage, wireless communication, etc.
  • The system memory can be upgraded to a total of 32 MB EDO RAM internally. By choosing to use a full 32 Bit EDO architecture, the memory access is very fast with improved system performance.
  • The System ROM that stores the Windows CE OS and the Pocket Office suite can be easily upgraded with a new version simply by plugging in the newer ROM module.
  • For corporate users, the C-Series allows users to replace the standard Mask ROM with a Flash ROM module. This solution allows for an easy upgrade to newer OS versions, simply by downloading the software from a PC via the supplied serial cable.

Using Industry Standard Windows OS Environment:

  • By using Microsoft Windows CE 2.0 that has the same familiar user interface as Windows 95 and Pocket Versions of the familiar Microsoft Office suite training cost can reduced to an absolute minimum. This results in improved productivity gains and reduces the support requirements.
  • The seamless compatibility with PCs, based on Microsoft Windows 95 or later versions facilitates a smooth and easy integration into existing infrastructures. The Windows CE services application to communicate with the PC comes with the handheld PC to provide a complete solution.
  • With an optional low power Ethernet card and a Compaq unique Ethernet utility, the C-series becomes a client in an Ethernet LAN, allowing to browse and access network resources.
  • Windows CE uses a subset of the Win32 API and supports the existing and familiar development tools used for Windows 95. This allows for rapid porting of specific or custom Windows applications. This means that there is a very small learning curve for Windows developers to develop for Windows CE, resulting in a fast growing number of 3rd party software titles and a growing variety of third party solution.
  • Windows CE works with standard printers via IR, or serial connections.
  • Synchronization and configuration utilities make setting up the unit much easier.

Service, Support, Management:

  • The C-Series comes with a comprehensive online help and a detailed manual in the rare case when a user needs assistance in using the system.
  • The Compaq C-Series is the only handheld PC to offer a variety of password enhancements to ensure integrity of the users data and discourage theft.
    • The C-Series offers an encrypted password capability of up to 40 characters long.
    • The password is stored in Flash memory and cannot be erased by unauthorized persons.
    • There are multiple password layers available, including an administrator password .
    • The C-Series can be programmed to completely lockup after unauthorized attempts to bypass the password, thereby preventing any unauthorized access to handheld PC and the stored data. While this cannot prevent theft in general, it can reduce the number of cases where units are stolen, as it becomes known that the devices may not be used by unauthorized individuals.
    • To make the use of a password easier and more convenient the C-Series allows the user to delay the request for a password for a selected length of time after last using the product.
    • In case the user forgets his password, a "secret hint" can be entered to remind the user of his/her password.
  • Since there are no moving parts in a handheld PC (no hard disk or CD-ROM drive), the device is much more robust than regular Notebooks. This reduces the risk of damage to the product components, thereby resulting in lower service cost.
  • The PC remote access software Carbon Copy (bundled with each C-Series in many countries) or the optional Hydra/Citrix client software to access and launch applications on an NT server make the C-Series a capable mobile client and allow centralized applications to be used remotely.
  • The C-Series is the only handheld PC that integrates an Asset management application. Whenever the unit is connected (serial, modem, LAN) to a PC or server, this software broadcasts important information about itself and its configuration. This makes the support and management of these devices on a network much easier and helps to reduce overall support cost.
  • Windows CE is built around a very powerful synchronization technology that ensures that the user's primary data (on the network server, mailserver or PC) and the data on the mobile device are kept up-to-date. While it is very convenient for the user it also reduces the likeliness of data loss to a minimum since there is always a copy of the users data on the PC/Server.
  • The C-Series also offers a Backup/restore application that can be set to automatically backup parts or all of the users information onto non-volatile Flash Memory. The unique integrated Flash memory in the C-Series allows to backup/Restore PIM data without the use of any additional storage/memory card.
