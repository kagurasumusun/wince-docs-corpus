COMPAQ-UNIQUE DESIGN
Internal Features
Internet Setup Utility

Included is the Compaq exclusive, Internet setup utility, designed to copy Internet Service Provider (ISP) settings from a user's PC to the C-Series. This utility makes setup easy and consistent with the user's desktop. It functions automatically, providing opportunities for the user to pick from a list or to get help for manual setup.


Internet Favorites Synchronizer

The Internet favorites synchronizer included with the C-Series synchronizes favorite Internet sites between the users desktop and the C-Series. This synchronizer works with both Internet Explorer and Netscape Navigator.




Internal Recharging Batteries

The C-Series offers built-in charging for use with optional (standard on color units) NiMH rechargeable batteries.


Application Launch Keys

Easy access application launch keys let users start programs directly from the keyboard without having to access the touch screen functions.


Pocket Carbon Copy (Exclusive)

A remote control application through which users can access and remotely manipulate PCs configured as dial-up hosts using this application. In addition, corporate customers can use Pocket Carbon Copy to troubleshoot Compaq servers with Remote Insight boards installed.


Display Features

  • Full width display: The Compaq C-Series provides a half-height full-width VGA (640x240) display on both mono and color units. This lets users review spreadsheet and word files with minimal horizontal scrolling.
  • Dual brightness backlight: The C-Series screen provides dual-brightness backlight settings, which allows users the flexibility of viewing the screen in many different light conditions. Selecting the low brightness setting extends battery life.
  • Touch screen: The touch-screen design eliminates the need for a mouse or other pointing device. It also allows the user to take hand-written notes, make freehand drawings, annotate documents and obtain signatures.


Ergonomic Design Features

  • Top mounted external speaker: The speaker on the C-Series is on top of the unit, so appointment alarms can be easily heard, even if the case is closed.
  • LEDs: There are two LEDs: one for a silent appointment alarm, and one to notify the user that the battery is being recharged. The LEDs are visible when the unit is opened or closed.
  • Voice Recording Microphone: The C-Series has a microphone with a quick-access button and voice recording software. This allows users to record a quick note without opening the unit.
  • Easy open design: The C-Series also offers a "latchless" design, easily opened by right-handed or left-handed users.
  • Infrared Port: The Infrared port provides wireless connectivity with another C-Series, PC, or printer.
  • Cradle: The optional cradle provides an easy connection to a serial PC port while also connecting to an external power supply. PC Card, infrared port, voice and alarm buttons are all accessible while the unit is docked. The cradle is Kensington-lock compatible for secure lock-down.


Compaq-Only Security and Management

Compaq-only security and management features protect users and their information. The Compaq C-Series has powerful unique security and management features that truly differentiate it from all other competing handheld PCs in the marketplace. These features allow the C-Series to meet Compaq's goal of providing mobile professionals with data that is safe from the dangers of unauthorized usage and technology failure. Increased security is provided by authentication procedures when a corporate network is accessed, file level security, and a Secure Socket Layer (SSL) to provide a safer environment for accessing Web-based applications.


Integrated Flash Memory

This semi-permanent memory retains the user's most critical information (password, calendar, contacts, and appointments) even when batteries are drained or removed. The C-Series can be set for automatic internal backup to ensure vital information is always updated and safe.


Non-Erasable, Encrypted Password

Compaq's unique password enhancements allow very tight control over access to the C-Series. A non-erasable, encrypted password is stored in the integrated flash memory. This protects the password even when batteries are removed.


Password Reminder

The C-Series uses a one-of-a-kind password reminder system. If a user forgets the password, the password reminder feature gives hints to remind him or her of a special, second password. Once into the system, the user can change the old password.


Password Delay Feature

The password delay feature allows users to deactivate passwords for up to eight hours. This feature is helpful when users anticipate frequently turning their units off and on and they do not want to re-enter their passwords each time.


Backup and Restore to Flash PC Cards

The "backup and restore to flash memory" feature copies all the data from the C-Series to removable PC flash Cards. This unique feature allows users to backup data while away from their desks.


Pocket Asset Management

With the Pocket Asset Management feature, Compaq provides information specific to the handheld PC, such as model number, serial number, and memory size. This information is useful when making a technical support phone call.

Pocket Asset Management also gives system administrators the data needed to track their C-Series inventory. Pocket Asset Management saves time and guarantees integrity by tracking C-Series electronically and remotely without the need for physical inspection or user interaction. When the unit is connected to a PC or network, it automatically and transparently transfers its information to the PC, allowing easy tracking by administrators.

Many of the Pocket Asset Manager parameters supported by the C-Series are stored in Flash memory, but some are stored in the System ROM and a few only exist as calculated values stored in system RAM.


High Performance CPU

The unit offers a high performance MIPs-based RISC processor. Its speed and the ROM based OS and Applications translate into no waiting for boot-up and there is no waiting when loading applications or switching between applications. Users get fast calculations in Excel, and smooth scrolling, cutting and pasting in Word documents.


Integrated Low-Power Software Modem

The C-Series includes an integrated 33.6Kbps software modem in many countries-the fastest modem in the handheld market. This provides high-speed access for desktop PC synchronization, e-mail retrieval, and Internet access. This design frees the PC card slot for other uses. The internal modem consumes very little power, preserving battery life. Users simply have to plug a standard RJ-11 connector into the telephone jack and they are ready to dial in using the internal modem. In addition to being very convenient, this feature reduces power consumption while on line.


RAM Expandable to 32MB

The C-Series offers exceptional expandability for investment protection and product enhancement. All models come standard with high performance EDO RAM, which is expandable to 32 MB. The 32-bit design of the memory allows increased system performance and storage capacity. The RAM modules are user installable, which leaves the PC card slot available for other devices. This design is faster and cheaper compared to Compact Flash card or Mini Flash Card implementation used in many other handheld PC devices.


Type II PC Card Slot

Industry-standard Type II PC card slot provides compatibility with many memory, modem, network, VGA, wireless radio, and serial PC Cards.


16MB ROM with OS and Application Software

16 MB of ROM (Read Only Memory) contains all components of the Windows CE operating system and all primary applications on a single module. The ROM is user-replaceable for upgrades.


Flash ROM (Optional)

Corporate customers can use the Flash ROM option to distribute operating system and application software updates as mentioned earlier (see Expandability within the C-Series Standard Features section). Mask ROM is standard, but you can upgrade to Flash ROM which allows companies to manage the information unique to your handheld PC.

  • Inbox: A part of the Microsoft Pocket Outlook suite that provides e-mail services for the C-Series. It uses standard SMTP (simple mail transfer protocol) and POP3 (post office) protocols that works with appropriately configured TCP/IP networks, including the Internet and company Intranets.
  • Pocket Internet Explorer®: Integrates with Windows CE Explorer for seamless browsing of local and remote files and access to Internet web pages.
  • Pocket Word®: Incorporates many features of Microsoft Word for Windows including normal and outline view, recently used file list, retention of font style information transferred to and from the C-Series, zooming, printing, spelling check, and more.

Using the included serial cable and software, presentations can be projected from the C-Series in full 640 x 480-resolution color with an optional PCMCIA VGA PC card and appropriate driver. The order of the slides can be changed, slides can be hidden, and the title slide can be changed for last minute adjustments. Users can also view speaker notes on the C-Series display while projecting the slides.

Microsoft® Windows® CE

The Microsoft Windows CE operating system provides the interface, connectivity, synchronization, and functionality that mobile professionals need.


Microsoft Windows User Interface

Windows CE closely replicates the popular Windows 95 and Windows NT operating systems. This confirms to the users that they are using an extension of their desktop PC.


Windows CE Services

Windows CE provides Windows CE Services featuring ActiveSync, which manages the C-Series from the user's desktop PC. Once the software is installed, the user's desktop PC becomes "handheld PC aware" and provides automated services without user intervention. The Auto Connect feature automatically detects C-Series connections and initiates communication. ActiveSync provides continuous automatic replication and synchronization of calendar, contacts, tasks, e-mail, and other data files between the Desktop PC and the C-Series. Windows CE Services also provides the following:

  • Built in TCP/IP, SLIP, POP3/SMTP and PPP protocols;
  • Network connectivity support, Ethernet NDIS driver (Optional Network card required);
  • PC card support;
  • IrDA-standard infrared support;
  • Printer support;
  • Multi-handheld partnerships;
  • Connectivity to Desktop PC via serial cable;
  • Cell phone connectivity support (optional); and
  • SMB redirector for file sharing.
