Security and Management

Passwords

The C-Series surpasses all other handheld PCs in security and in preserving data integrity. For maximum security, three different kinds of encrypted passwords can be set on the C-Series within a non-erasable memory that is integrated into the system. These include administrator, system, and reminder passwords.

Standard Windows CE (v1.0 and v2.0) supports a system password of up to 8 characters in length. This password is defined using the password control panel applet. Also in the password applet, the user can enable power-on security, in which case the user has to enter the correct system password each time they turn on the H/PC. If the user forgets the system password, all they have to do is remove the batteries, to perform a full reset. This erases the password, as well as all user files.

The standard security method in Windows CE is not considered to be a strong security implementation since it can be easily bypassed. To meet the needs of the target customer Compaq has replaced Windows CE security with one of its own design.

User-Level Security

On the C-Series, a system password of up to 40 characters in length is supported. This password is defined using the password control panel applet. This password applet was completely re-implemented by Compaq, to achieve the new user-level security functionality. The user can enable power on security by checking a box in the password applet.

When defining a password, the longer the password the harder it is to breach. Hence, the 40- character security offered by the C-Series, is stronger than Windows CE's 8-character limit. Because of the difficulty in remembering long passwords, people often choose a simple password to reduce the chances of forgetting it. This is counter to the need for strong security.

C-Series adds a significant security feature called "Password Reminder Security." This feature can be thought of as a secure, personal back-door that comes into play in the event the user forgets his/her password. When the user chooses a system password, she/he also defines a personal challenge phrase, and its associated response. The challenge phrase can be a question or some other kind of memory jogger. The personal challenge phrase should ideally trigger a response that only the user knows. The challenge phrase is referred to as "personal," since it is most likely that the question will relate to a personal event/memory that is unique to the user. The user should choose a phrase and response that she/he is unlikely to forget. The response that the user defines is strongly encrypted and can be up to 40 characters long. The challenge phrase can be up to 80 characters long.

If the user defines a system password and enables power-on security, the password must be entered to gain access to the system. The login screen gives the user up to 5 attempts to enter the correct system password. If the user consumes all 5 attempts, then the system enters the Password Reminder security mode (if a challenge/response has been defined). In Password Reminder mode, the user gets an additional 5 attempts to enter the correct response to their personal challenge phrase. If the user consumes all 5 attempts, then the system will enter the user-level security lockout mode. The device will be rendered unusable until the user's password is cleared either by an administrator (if an administrator password has been defined), or the device is unlocked. Entering a valid Compaq Unlock Key (purchased separately) clears all passwords, without erasing the data.

The IMPORTANT point to note about this security implementation is that the user cannot simply remove all batteries to erase the content of memory, thinking that the password will also be erased. The C-Series stores all passwords and security phrases in a Flash memory that retains its contents, even in the event of a total loss of power.

When the user is setting up the password security, a choice is offered to either erase all data or enter security lockout mode (as previously described) once the maximum number of attempts have been made.

Whenever a system password has been defined, even if power-on security has not been enabled, the user must enter that password before they are allowed to change the settings in the password control panel applet. So, like other password systems, the user must know the current password in order to change the password to another value. TheSystem, Reminder, or Administrator Password can be used to gain access to the password control panel.

C-Series Administrator Security

Since the C-Series is targeted at the corporate market, Compaq also designed an Administrator password feature. A designated Administrator can gain access to a C-Series handheld PC using the Administrator password.

The Administrator password can be entered instead of the user's system password, in response to the login screen, and in the password control panel applet. In the event that a user is locked out of the system, the Administrator can gain access to the system, and reset the user's system password in the password control panel applet. All of this applies only if an Administrator password has been defined in advance.

In order to block an attempt at cracking the Administrator password there is a limit on the number of invalid Administrator passwords that can be entered before the system enters administrator security lockout mode (in this mode an unlock key is required to regain access to the handheld PC). All of the security modes are illustrated in the following figure.

The Administrator password is also required to change the Administrator controlled Pocket Asset data, such as the Asset Tag #. The Administrator password is changed in the Flash Manager control panel applet.

In the system password security mode, the system will only accept the user's system password or the Administrator password (if one has been defined).

In the challenge/response security mode, the system will accept the original system password, the user's response phrase or the Administrator password (if one has been defined). This mode is skipped if the user has not defined a challenge and a response phrase.

In the user lockout security mode, the system will only accept the Administrator password (if one has been defined) or an unlock key.

In the administrator lockout security mode, the system will only accept an unlock key.

Compaq Unlock Key

If the security system enters Administrator lockout mode, or if it enters User lockout mode and no Administrator password is defined, then the system will be unusable until a valid unlock key is entered.

When in either user lockout mode, or administrator lockout mode, the login screen will display 3 pieces of information:

  1. Serial #

  2. Owner name
  3. Random #

These 3 pieces of information are by the unlock application used to generate a unique unlock key. This unlock application is located on the Compaq Software CD or the internet (www.compaq.com/products/handhelds). The application that generates unlock keys, is an application with the decryption algorithm located within a secure sales wrapper. The requestor can only submit the 3 pieces of information communicated to them by the C-Series. The decryption algorithm will generate an unlock key, which can then be used to unlock the handheld PC.

Unlock keys are time dependent, which means an unlock key can be used only once. If you do not have access to the unlock application please contact Compaq Technical support to purchase your unlock key.

Password Delay

Since Windows CE devices are instant ON, users will be turning these devices ON and OFF many times during a day. It would be very inconvenient to enter their password every time they turn ON the unit (this is the behavior of Windows CE today). Compaq has defined a feature called Password Delay that temporarily disables the power on password for a specified time period. The time is an elapsed time from the time the last successful logon occurred.

Example:

If the user configures the Password Delay time (in the Password control panel applet) to 1 hour then the following are true:

  • User must enter the power-on password the first time to gain access to the system. The time of this access is recorded.

  • If the user turns the unit OFF then ON again within 1 hour, he/she will not see the logon screen, it will be bypassed.
  • If the user turns the unit OFF then ON again more than 1 hour after the first access above, the logon screen will appear and the user will need to enter his/her password to gain access to the system.
  • Password Delay remains active until it is turned "OFF" using the password control panel.

Compaq Backup and Restore

The C-Series provides several ways to protect against data loss. With the C-Series, users can do the following:

  • Back up data to the desktop computer using Microsoft Backup/Restore Windows CE services.

  • Back up data to an ATA Flash RAM PC Card.
  • Back up data to flash memory located in the C-Series.

For comprehensive and secured backup protection, the Microsoft Backup/Restore Windows CE Services utility can be used to periodically back up all handheld PC data onto a desktop computer's hard drive (such as a Compaq Deskpro). Users can also manually back up data or set this utility to back up automatically each time they connect to a handheld PC.

For comprehensive and convenient backup protection, the C-Series comes preinstalled with a Compaq Backup and Restore utility that can back up and restore the entire handheld PC memory contents to an ATA Flash RAM PC Card, provided an appropriately sized card is used. This feature enables the professional to carry a PC Card-based copy of their data with them at all times for quick retrieval. These applications can be accessed from the C-Series Start Menu.

A dual backup option within Compaq Backup and Restore creates two top-level folders on the PC Card: \BackupA and \BackupB. It toggles between these folders each time it copies data, thus retaining copies of the last two backups that you have made. A single backup option copies only to \BackupA and always overwrites the last backup.

In addition to these backup utilities, the C-Series can also back up the Contacts, Tasks, Calendar, Appointments, and select system data directly to flash memory built into the C-Series. Flash memory is an area in the device that securely stores saved information even if there is a power loss. This information can be easily retrieved in case of a power failure or other disturbance to the system. This backup utility can be configured to run every few days (using the Flash Manager control Panel applet) or run manually from the Icon tray.

Connectivity & Remote Access

SoftModem

Mobile professionals and entrepreneurs must be in touch constantly with their mission-critical information. This means that they need easy connections to e-mail, faxes, and the Internet. They also need to create, edit, review, present and print documents while on the road. Nevertheless, many handheld PCs in the market today do not have an integrated modem. PC Card modems and other PC Card devices use large amounts of power to operate and can quickly drain the batteries in handheld PCs.

The integrated 33.6 kbps modem on the C-Series addresses this issue, and provides an elegant communications solution for professionals.. The ultra-low power integrated design leverages the high performance of the main processor, eliminating the need for a separate PC Card modem.

This integrated design frees up the PC Card slot for other services such as network, VGA, wireless radio and serial PC Cards.

The modem is implemented using a convenient, integrated RJ-11 connector compatible with most phone systems.

The soft modem is planned to be approved for use by the local telephone companies in the United States, Latin America, the United Kingdom, the Netherlands, France, Germany, Norway, and Japan. Other geographies are under investigation. Country specific phone jack cables will be shipped within the respective unit configured packaging.

Expandability

EDO RAM

The Compaq C-Series is expandable up to 32-MB on selected models. Expansion can be accomplished using an easy to install memory expansion module in the base of the unit.

The industry standard, high speed design of the C-Series memory increases system performance, enables running many applications at once and provides instant access to vast storage capabilities. With this capacity, users can store thousands of contacts, years of calendar entries, and many large files.

The 32-bit design of the fast EDO RAM in the C-Series maintains the high performance of the CPU after upgrading, unlike memory upgrades for most other handheld PCs in the market that are based on a 16-bit design, which can reduce CPU performance.

The design also frees up the PC Card slot for other services such as communications or storage.

User Upgradeable ROM

The Windows CE operating system and Compaq software are stored in a 16-MB ROM card in the expansion compartment of the unit. The pin-free design of this compartment enables easy upgrade by users. Simply loosen the compartment screw, remove the cover and pull the two card tabs simultaneously to release the ROM. An upgrade ROM (and RAM) can be seated back into the unit in a way similar to installing SIMMs in a desktop PC.

Flash ROM Option

In addition to standard ROM upgrades, the C-Series has a Flash ROM option for businesses, enabling flexible and frequent changes to the operating system and applications without taking apart the C-Series.

Flash ROM is a memory chip that holds its content without power. Unlike DRAM and SRAM memory chips, in which a single byte can be written, flash memory must be erased and written in fixed blocks, typically ranging from 512 bytes up to 256KB. Compaq has written software for the purpose of downloading ROM images from the PC to the C-Series, easing the administrative burden involved in manually upgrading the software on each handheld PC.

Since it is stored in Flash ROM, any operating system changes are stored without the need for a battery to retain the contents. Information is protected even if batteries run out.

Type II PC Card Slot

The full Type II PC Card slot in the C-Series provides investment security and increased functionality through compatibility with many memory, modem, network, VGA, wireless radio and serial PC Cards.

Ease of Use

The C-Series design and available options were made with ease-of-use and service for the professional in mind.

Each unit ships with a universal 110-240V AC adapter as standard equipment. This C-Series AC adapter also serves to charge the NiMH rechargeable batteries that are standard equipment with the color C-Series. NiMH rechargeable batteries are available as an option for monochrome units.

Each unit was designed with application launch keys for the standard software applications. When pressed at the same time as the function key (Fn) application software will instantly load into memory. For instance, holding the "Fn" key and pressing the 6 key will launch the contacts list. Holding Fn+2 will launch Microsoft Pocket Word.

A .5-watt speaker is integrated in the lid of the C-Series, unlike other handheld PCs where the speaker can be found under the lid, or in the base of the unit. The lid-mounted design offers the best position for the speaker with sound volume maximized when unit is opened or closed. It is less likely that users of the C-Series will miss important reminders for appointments or tasks.

The built-in microphone works with the lid open or closed for convenient recording of voice memos. This handy feature enables one-handed voice memo recording. This way voice recording can be easily and conveniently used without requiring the user to open the lid of the unit to record messages.

The C-Series offers a rich, viewing experience with a half-height VGA display (640 x 240 Pixel) with a 6.1" by 2.3" viewable area (6.5" diagonal). Users can view a complete page at full width without having to scroll horizontally.

The dual brightness backlight button on the C-Series provides the user with two levels of backlighting (the light that illuminates the screen). Operating the backlight uses more battery power. To conserve battery power, users can set the backlight to the lowest setting that is comfortable for them.

The C-Series comes with a high performance MIPs-based RISC processor enabling what is called "instant computing." The CPU performance is among the fastest available for handheld PCs which increases user productivity by decreasing the time during loading or switching between applications, booting-up, or activating the unit from a power-saver mode. This CPU also offers fast calculations and smooth scrolling through documents.

These APIs enable corporate developers to connect C-Series devices to backend databases like Microsoft SQL Server and Lotus Notes.

Corporate Connection simplifies the programming task and provides a full range of communications and data base access services to dial-up, wired and wireless LAN users running Windows CE.
