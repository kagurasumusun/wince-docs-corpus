THE MOBILE COMPUTING MARKET

The Compaq Aero 8000® H/PC Pro is designed for enterprises with mobile workforces, such as field sales/service and healthcare. It is also ideal for the business professional with a desktop PC who travels occasionally, needs access to e-mail and Windows documents, and delivers PowerPoint presentations.

THE NEED FOR PERSONAL PRODUCTIVITY

Traditionally, mobile computing devices have been used to help employees gain access to their own data and applications whenever they are away from their PC or company network. They must be able to review documents, write letters and memos, prepare and edit spreadsheets, manage the contact database, and handle busy agendas. Some mobile professionals must have access to copies of customer files and be able to display PowerPoint presentations.

Such personal productivity applications typically required seamless information flow and real-time data synchronization between the H/PC Pro and the desktop PC. The Windows CE operating system meets these requirements by providing easy-to-use "Pocket" versions of Microsoft Word, Excel, Outlook, Explorer, and PowerPoint. The ActiveSync™ feature in Windows CE helps synchronize data and files between the H/PC Pro and desktop PCs.

Recognizing the need for H/PC Pro in the mobile professional market, and acknowledging that Windows CE is the preferred environment, Compaq designed the Aero 8000® specifically for these needs. Compared to a notebook computer, the Compaq Aero 8000® offers basic functionality, but improved mobility and lower cost. The Compaq Aero 8000® is designed as a mobile extension to a PC rather than a replacement for a notebook PC. It can perform many of the essential functions of a PC, including the ability to run special versions of common software that have been designed for easy use on these extremely small devices.

THE NEED FOR NETWORK CONNECTIVITY

Whereas personal productivity software typically works offline, using synchronization to desktop PCs, there is a growing need for mobile computers that remain connected to the business, either through wireless networking, dial-in access (RAS), or the Internet. Besides syncing to the desktop, these computers must be capable in many instances of syncing directly with network-based databases and application servers. Some of the areas in which H/PC Pros are being evaluated and purchased for these purposes include healthcare, sales-force automation, and field-service automation.

Some applications require mobile data collection, remote access to server databases, and remote control of host systems for failure analysis. The special vertical applications often needed for these markets can be ported relatively easily to the Windows CE platform since it uses the same developer tools as Windows 95.

Compaq conducts ongoing market research to understand and meet these customer needs, and is committed to becoming a leader in the H/PC Pro market. The same skills and resources that have helped Compaq expand the Deskpro, server, and solutions market will help create an optimal H/PC Pro solution.

COMPARISON TO NOTEBOOKS: THE DIFFERENCES

The standard reaction to H/PC Pro devices such as the Compaq Aero 8000® is to compare them to notebooks, which they closely resemble. In fact, the Compaq Aero 8000® looks, feels, and functions much like a notebook. Rather than replacing notebooks, however, this new class of devices will supplement the existing arsenal of computing devices in special applications and


The Compaq Aero® 8000

niche markets. For this reason, it is important to understand the key differences between H/PC Pros and notebooks, and the situations in which H/PC Pros will provide a special advantage:

  • Lower cost: At less than $1,000, the Compaq Aero 8000® presents a significant cost advantage over more elaborate notebook models, especially for applications in which all the features of a notebook (such as disk drives and CD drive) are not needed.

  • Convenient size/weight: The unit's lighter weight (2.9 pounds) and slimmer profile (8.5 by 11 by 1 inches) make it easier for employees to carry it on trips around the office, around the warehouse, or around the world.
  • Longer battery life: The scaled-down power requirements of the Compaq Aero 8000® (no hard drive, floppy drive, or CD) result in significantly longer battery life &mdash; 6 to 12 hours, which is much greater than the 2 to 4 hour battery life of a comparable notebook computer. A single charge of the removable lithium-ion battery can support several days of work. The ability to go so long without a recharge increases mobility even more, because workers are not tethered to a power cord.
  • Instant on/off: The operating system software and key applications are stored in read-only memory (ROM), which provides a quick on/off capability not available in notebooks. This helps eliminate "dead time" for employees working in a dynamic, fast-paced environment. The computer is ready to go when the user needs it &mdash; making it possible to take notes, record contact information, or review/edit crucial data on the spot, without delay.
  • Synchronized data: All work performed on the Compaq Aero 8000® automatically synchronizes with desktop or notebook PCs using Microsoft's ActiveSync™ technology. Synchronized data includes the employee's personal calendar, contact list, to-do list, e-mail messages, and other important files and databases.
  • Durability: The Compaq Aero 8000 has fewer moving parts than a notebook or desktop PC &mdash; no hard drive, floppy disk drive, or CD drive. That means it can take more punishment in mobile environments without crashing. In fact, this unit is twice as rugged as a standard notebook and is designed to pass the PC Computing Torture Test.
  • Windows CE platform: Windows CE contains pocket versions of popular Windows productivity software such as Word, Excel, PowerPoint, Outlook, and Access. Additional software provided by third-party vendors extends this platform significantly, as discussed later in this document.

COMPARISON TO NOTEBOOKS: THE SIMILARITIES

As important as understanding the differences is the need to understand the similarities between devices such as the Compaq Aero 8000® and notebook computers. As the following list shows, the Compaq Aero 8000® is similar in many ways, which makes it considerably more flexible and easy-to-use when compared to a palm-size PC.

  • Full-size screen. With 800x600 pixels and 256-color resolution on a 10-inch monitor, the screen is much more comparable to a notebook than to other Windows CE devices, such as the Compaq C-Series (handheld), the Compaq Aero 2100 (palm-size).

  • High performance. The 64-bit 128-Mhz Hitachi SH4 processor in the Compaq Aero 8000® makes it comparable to notebooks in speed and performance. The 16MB of SDRAM (upgradable to 32 or 64 MB) is more comparable to a notebook or desktop PC than to most handheld PCs. Onboard 256K SPI flash memory stores password and asset data.
  • Keyboard. The Compaq Aero 8000® also comes with a 95-percent keyboard for easy typing, in notable contrast to regular handheld PCs, which have tiny keyboards, or the palm-size PC, which has no keyboard. Key spacing of 18mm provides comfortable touch typing.
  • Touchpad mouse. The Compaq Aero 8000® comes with its own built-in touchpad, and supports a mouse or other pointing device. A palm-size PC, by comparison, requires a stylus or touch screen to operate.
  • Built-in modem. The built-in 56K V.90 modem provides instant connectivity via dial-up access to remote networks (RAS), the Internet, extranets, and intranets.
  • Extensive I/O options. The unit includes a PCMCIA Type II port, CompactFlash Type II serial port, VGA out, fast I/R, PS/2 port (external mouse/keyboard through one cable), and a built-in two-way microphone/speaker with voice recording/playback capabilities.
  • Enhanced security. A built-in Smart Card reader/writer and full Microsoft Windows NT security make it possible to create highly secure applications for this device.

For all these reasons, interest in H/PC Pros is broadening and companies are increasingly willing to consider CE devices for mobile applications. Notebook and laptop PCs are still valuable as replacements for desktop computers in situations where the mobile worker must run many large-scale applications. But handheld computers are the obvious choice when mobility, ease-of-use, and price are key considerations.

 

UNDERSTANDING THE WINDOWS CE PLATFORM

Microsoft Windows CE (WinCE) is the enabling technology that makes H/PC Pros possible. WinCE is the logical choice for mobile professionals who want robust connectivity and functionality without sacrificing compatibility. Windows CE offers a powerful, highly portable solution that combines Outlook-style contact- and time-management features with productivity applications such as Word and Excel.

  • Familiar interface requires no training. People who use Microsoft Windows 95/98/NT can use Windows CE without retraining. It uses the same familiar Windows interface.

  • Mobility. Windows CE is designed specifically for small mobile devices. Weighing just under three pounds, the color Compaq Aero® 8000 fits much more easily into a briefcase or tote bag than does a notebook computer.
  • Synchronization. A major benefit of Windows CE is its ability to seamlessly integrate and synchronize data and information between H/PC Pros and host PCs such as notebooks and desktops. Users can easily transfer files to the Compaq Aero 8000®, edit them, and have the updated file automatically copied back to the desktop or notebook via the AutoSync feature in Windows CE.
  • Integrated e-mail and PIM tools. Most handheld devices allow users to store their contact and calendar information, but few combine that functionality with the Pocket Outlook e-mail program included with Windows CE. Even fewer handheld devices can handle e-mail attachments like Windows CE does.
  • Internet browsing. The Compaq Aero 8000® makes it easy to connect to Internet, intranet, and extranet sites and use the Pocket Internet Explorer to browse websites, or use customized web applications developed specifically for mobile workers. The Compaq Aero 8000 includes a full-featured Pocket version of Internet Explorer made specifically for this purpose.
  • Productivity tools. The WinCE package includes versions of the most popular productivity applications available &mdash; those found in Microsoft Office, including Word, Excel, PowerPoint, and Outlook. Non-Windows CE devices, running their own proprietary operating systems, cannot offer native versions of these Microsoft Office applications and documents.
  • Connectivity. Windows CE for the H/PC Pro allows printing directly from the device or transferring data from or to another device or printer using an infrared or serial connection. It is also possible to connect directly to a corporate LAN using TCP/IP.
  • Seamless Windows compatibility. Data synchronization with desktop applications is seamless, and thanks to ActiveSync, happens automatically &mdash; without pushing a button.
  • Application portability. Thousands of developers around the world are already familiar with Windows. Dozens of applications are already available for the Windows CE platform alone. Microsoft makes development easier by offering toolkits for Visual C/C++ and Visual Basic. This empowers corporate developers to offer H/PC Pro services to their users.
  • Enhancements. Numerous independent hardware vendors (IHVs) are bringing dozens of Windows CE products to market, including low-power modem and network cards, display cards, high-performance batteries, and so on.

For more information about Microsoft Windows CE, visit the Microsoft website for the Windows CE operating system at www.microsoft.com/windowsCE.

 

NEW FEATURES IN VERSION 2.11

In November 1998, Microsoft released the latest version of its Windows CE platform. Previously code-named Jupiter, the new Windows CE 2.11 operating system adds important features not available in previous versions, including enhanced software offerings such as:

  • Enhanced e-mail. An enhanced Pocket Outlook e-mail tool with support for IMAP4, lightweight directory access protocol (LDAP), and Transport Neutral Encoding Format (TNEF). IMAP4 lets users synchronize directly with Microsoft Exchange Server and other IMAP4 servers, and it supports offline changes in the hierarchical folder structure. LDAP allows users to resolve e-mail addresses against the server address directory. TNEF allows users to send and accept meeting requests. Rich content support for inbox e-mail messages allows users to jump directly to web links embedded in e-mail messages and add names and addresses to the Contacts database with a single command.

  • Convertibility. Built-in converters for Pocket Excel and Pocket Word so that desktop Excel and Word files can be transferred directly to the H/PC Pro without being converted previously on the desktop or notebook PC where they originated.
  • Presentation support. Enhanced Pocket PowerPoint provides the ability to edit presentation notes inside the H/PC Pro. Other editing capabilities can be added through third-party software.
  • Database features. New Pocket Access software allows users to drag and drop Access 97 database files to the handheld unit, and supports synchronization with the desktop through ActiveSync, as well as synchronization with enterprise databases running under Microsoft SQL Server 7.0.
  • Enhanced browsing. The built-in Pocket Internet Explorer allows enhanced browsing, including the ability to connect to shared folders on a network. Security is enhanced through support for CryptoAPI 1.0, Security Support Interface (SSPI), and 128-bit encryption (where allowed by law). The new version also provides support for the Jscript web application scripting language, and improves compatibility with HTML 3.2.
  • Quick notes. New Microsoft InkWriter allows the user to capture typed notes, handwritten notes, and drawings.

The new edition of Windows CE made possible devices such as the Compaq Aero 8000® by providing support for new hardware features such as 800 x 600 color displays, printing, and CompactFlash cards &mdash; all prominent features of the Compaq Aero 8000® H/PC Pro. The enhanced display capabilities give the user a viewing experience that compares favorably with notebook computers and makes it easier to support enhanced document creation, editing, and presentation applications. Built-in support for network-based e-mail, directory, and database services enhances the product's ability to integrate with the enterprise.
