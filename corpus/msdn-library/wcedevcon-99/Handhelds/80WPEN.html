COMPAQ AERO® IN THE ENTERPRISE

The main advantage that the Compaq Aero 8000® H/PC Pro has over its competitors &mdash; in addition to its superior display, power, and mobility &mdash; is the way it has been designed to fit exactly the needs of enterprise application planners deploying mobile solutions. Many companies today have a significant investment in business computers, ranging from mainframe to client-server systems. The Compaq Aero 8000® is designed to help leverage existing investments by providing a ready solution for specialized applications within a corporate environment.

 

THE NEEDS OF INFORMATION MANAGEMENT (IM)

In designing the Compaq Aero 8000® H/PC Pro, a major concern was the needs of information management (IM) &mdash; the primary deployers of corporate enterprise solutions. The Compaq Aero 8000 H/PC Pro provides for IM needs in several ways:

  • Enhanced security and user authentication (Smart Cards). In addition to basic password and encryption features found in other handheld devices such as the Compaq C-Series, the Compaq Aero 8000® comes equipped with a built-in Smart Card reader that can limit use to persons who have the appropriate card and password combination. Importantly, the Smart Card Reader is also a writing device, so IM can load the card with passwords for login or special data to interface with applications.

  • Network connectivity. One of the primary needs of IM is to link users together in local area networks (LANs) and wide area networks (WANs), as well as the increasingly common intranets and extranets. Network connectivity gives users access to remote databases, web content, and a wide variety of other networked client-server applications, including messaging and collaborative applications such as Microsoft Outlook/Exchange and Lotus Notes/Domino. The PCMCIA slot on the unit supports wired and wireless network cards for easy connectivity and access to network resources.
  • Flexible data storage options. Compact Flash Type II cards provide for 20/40/64 MB flash modules that plug in, either internally or through an external slot. The internal version is a configure-to-order option that supports loading of corporate data on the internal drive. Other important storage options include:
    • IBM Microdrive, a 340 MB hard drive that provides large-scale storage in a Type II PC card form factor.
    • Iomega Clik! drive, a PCMCIA II plug in module with 40 MB removable storage cartridges.
    • 120 MB floppy SuperDisk™, connected to the Compaq Aero 8000® as an external drive using a PCMCIA card slot.
  • Mobile access. The built-in 56K V.90 modem allows remote access outside of the standard corporate network, including dial-up access via Remote Access Services (RAS) on Windows NT servers, standard Internet access through ISP connections, or secure Internet access through a virtual private network (VPN).
  • Rapid application development. The Windows CE operating system provides a ready-made industry-standard operating system compatible with existing Windows applications, yet it also supports customized application development for H/PC Pros using the same programming languages, development tools, and APIs as standard 32-bit Windows (Win32) applications. Existing development staff can create new applications or port existing applications without having to retrain extensively in new programming languages or development paradigms. A wide range of development tools facilitates this process, such as the Synchrologic software discussed later in this document.
  • Compatibility with existing databases. Applications developed for Windows CE will have the same ease of access to existing databases, such as Oracle or Sybase, that all Windows applications enjoy.
  • Procurement cost savings. The Compaq Aero 8000® can help lower procurement costs by providing a mobile solution with just the right combination of power and computing features at a significantly lower price point than comparable notebook or desktop devices.
  • Total cost of ownership (TCO). Large-scale investments in equipment can be significantly increased or reduced by a number of issues related to the way they are deployed, used, and maintained. The Compaq Aero® 8000 lowers not only raw equipment costs but lowers the long-term costs associated with maintenance and administration. Because there are fewer moving parts in the Compaq Aero® 8000, there is less chance of equipment failure. In addition, since users cannot easily load their own applications onto the device, support calls are reduced substantially. Finally, the proven quality and dependability of the Compaq brand ensures lower repair and maintenance costs during the product life cycle as well as reduced system downtime.

EXTENDING THE PLATFORM THROUGH PARTNERSHIPS

To provide the ideal enterprise solution platform, Compaq has partnered with major industry players to extend the basic Windows CE platform with additional software that will make the Compaq Aero 8000 an ideal fit for a wide range of applications:

  • Smart Card applications (Schlumberger, Aliroo)

  • Mobile thin clients running full Windows applications (Citrix)
  • Mainframe terminal emulation (FutureSoft)
  • Enterprise client-server / database connectivity (Oracle, Sybase, @hand, Synchrologic)
  • Mobile Internet applications (Intertop)
  • Wireless connectivity (Proxim, Sierra Wireless, GoAmerica, Infowave)
  • Synchronization of multiple applications and databases (River Run)
  • Access to legacy e-mail systems (River Run)
