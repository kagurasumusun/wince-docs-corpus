IASMemorySlider

This interface is used to manage a memory slider.

Method
Description
IASMemorySlider::put_StoreUsed Sets the amount of the object store currently being used.
IASMemorySlider::put_RamUsed Sets the amount of RAM currently being used.

Remarks

The IASMemorySlider interface, which has a global unique identifier (GUID) equal to IID_ASMEMORYSLIDER, extends the IASSlider interface. The memory slider has a programmatic identifier equal to APC_MemSlider.
