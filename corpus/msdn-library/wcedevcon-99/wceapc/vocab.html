Auto PC Speech Recognition Vocabulary

These vocabulary words are recognized by the speech recognition engine. In most cases, the vocabulary directly maps to the name of the command started when the word or words is said aloud. For example, a user says, “Cancel” to choose the Cancel command.

The result of the vocabulary word or phrase depends on the currently active grammar, as shown in the following tables.

Note Many of the words—but not all—in the global grammar are used in bundled applications. Because the complete global grammar is installed in Auto PC device ROM, you have a wider variety of words to include in your applications, but do not have to train the engine to recognize a word.

Action

Audio Go to Audio..
Auto PC Wake up Auto PC speech recognition.

Clock Display the clock.

Directions Go to Directions.
Disc Select the next disc.
E-mail Go to e-mail list in Messages.
End Terminates the speech recognition timer.
FM Set the radio frequency band to FM.
Go Initiates the calculation of a route. Used in Directions.
Help List help for words the Auto PC device is listening for.
List Read a list.
Locate Instructs balloon grammar to listen for user-defined voice tags and custom commands.
Loud After “Volume,” set audio volume to Loud preset.
Messages Go to Messages.
Mute Mute the audio output.
News Go to news list in Messages.
Next Go to the next item in a list, or the next turn in Directions.
No Select the “No” option in a system message box.
Normal After “Volume,” set audio volume to Normal preset.
OK Select the “OK” option in a system message box.
Pause Pause CD playback.
Play Start CD playback.
Preset (followed by a number or custom speech command) Go to the preset value associated with a number key or custom speech command (such as a radio station preset)..
Previous Go to the previous item in a list, or the previous turn in Directions.
Quiet After “Volume,” set audio volume to Quiet preset.
Radio Go to Radio.
Random Play CD tracks in random order.
Read Read an item.
Retry Try an action again. Used with a system message box.
Select Choose an item.
Setup Go to Setup.
Start Reserved for future versions. Do not use.
Traffic Go to traffic list in Messages.
Volume Specify audio volume preset. Used with “Loud,” “Normal,” and “Quiet.”
What can I say? Read a list of the words Auto PC is listening for.
What time is it? Read the current time.
Yes Select the “Yes” option in a system message box.

Radio Grammar

Word or phrase
Action
0 through 9 After “Preset,” go to a numbered preset.
AM or FM Change the radio frequency band.
Next or Previous Seek for a radio station.
Preset (followed by a number or custom speech command) Go to the preset value associated with a number key or custom speech command (such as a radio station preset)..
Read Read the station number and frequency.

CD Player Grammar

Word or phrase
Action
Delete Remove the current song from the play list.
Disc Go to a different disc.
Next or Previous Go to a different track.
Play or Pause Start or stop playing.
Random Play tracks in random order.
Read Read the disc and track number.
Stop Stop playing.

Address Book Grammar

Word or phrase
Action
Back Go up one level.
Dial Call the selected number, or the preferred number for the selected contact.
Locate (and the custom speech command) Instructs balloon grammar to listen for user-defined voice tags and custom commands.
List Read the contact list.
Next or Previous Go to a different contact.
Select Choose a contact.
Read Read contact information.

Directions Grammar

Word or phrase
Action
Go Initiates the calculation of a route.
List List all remaining turns.
Next or Previous Go to a different turn.
Read Read the current turn.

Messages Grammar

Word or phrase
Action
Back Return to the message list.
Delete Delete the current message.
E-mail Go to e-mail.
List List messages.
News Go to news.
Next or Previous Go to a different message.
Read Reads the message information, including the sender of the message, the date that the message was sent, and the subject of the message.
Select Open the selected message and reads the content of the message.
Traffic Go to traffic.
