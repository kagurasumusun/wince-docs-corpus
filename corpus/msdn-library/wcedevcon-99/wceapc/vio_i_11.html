IVIO_EnumMetrics::Set

This method sets the value of the current item referenced by the enumerator.

Syntax

HRESULT IVIO_EnumMetrics::Set ( LPVARIANT pValue);

Parameters

pValue
[in] Pointer to the VARIANT that contains the new value.

Use a VT_BSTR to set the following three values. A VT_BSTR is a 32-bit character string.

VIOVEHICLEMETRIC_MAKE
Specifies the make of the vehicle.
VIOVEHICLEMETRIC_MODEL
Specifies the model of the vehicle.
VIOVEHICLEMETRIC_VIN
Specifies the vehicle identification number (VIN) number.

Use a VT_UI4 to set the following values. A VT_UI4 is an unsigned long integer.

VIOVEHICLEMETRIC_YEAR
Specifies the year of the vehicle.

Specifies the displacement of the engine in 0.1 liter increments.

Value

VIOVEHICLEMETRIC_TRANSMISSION_GEARS
Transmission gear count. If the high bit (0x80000000) is set it means that an overdrive gear is available.

Return Values

One of the values described in the following table is returned.

Value
Description
S_OK The value of the item currently referenced by the enumerator was set successfully.
S_FALSE The enumerator is not positioned on a valid item.
E_OUTOFMEMORY The application is out of memory.
E_POINTER The pointer referenced by pValue is invalid.
