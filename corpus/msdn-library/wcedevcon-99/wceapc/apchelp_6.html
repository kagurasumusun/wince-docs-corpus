Authoring and Coding Voice Help

The WAV file names for short voice Help and strings for long voice Help are included in the resource file where you specify the speech commands supported by your application.

Note Short voice Help is disabled if you do not provide a prerecorded speech WAV file for a word, or if you have added speech commands that do not have a speaker-independent template, and if these words have not been trained by the user. For more information on speaker-dependent speech commands, see Voice Help for Speaker-dependent Speech Commands.
