WM_APCCOMM_DIALSTATECHANGED

This message is sent internally to notify address book forms that the dialing state changed.

Parameters

wParam
Specifies the new dialing state
lParam
Specifies the result obtained from the previous dialing state.

Remarks

This message is broadcast through the application sink to forms managed by the address book application programming interface (ABAPI) by the internal telephony API (TAPI) thread.
