Bitmaps

Visual Help uses inline bitmaps and full-screen bitmaps. The following table shows the characteristics of these bitmaps.

Bitmap
Size (width by height)
Description
Inline 40 x 11 pixels maximum Includes text. Bitmap is placed on a black background.
Full-screen 223 x 44 pixels exactly Does not include text. The bitmap uses the entire screen for the topic.

All bitmaps must use the eight-color palette supported by an Auto PC display. However, they must be saved as 16-color bitmaps; this includes monochrome (black and white) bitmaps. The following table shows the supported colors and their common uses.

Color
Use
White Editable text
Black Background
Cyan Non-editable text and unselected items
Magenta Not used
Red Alerts and warnings
Green ENTER key and enabled items
Yellow Selected items
Blue Unavailable or unselected items

All bitmaps must be installed in the same directory as your application executable file.
