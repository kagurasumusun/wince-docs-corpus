PNAccess_t

Enumerates permissions the Positioning and Navigation device supplies to the application

Syntax

typedef enum ePNAccess_t{
PN_AS_READWRITE = MIN_PNACCESS_T,
PN_AS_READ = MAX_PNACCESS_T
}PNAccess_t;

Members

PN_AS_READWRITE
Device has full permissions.
PN_AS_READ
Device has partial permissions, which enables the user to only receive data from the Positioning and Navigation device.
