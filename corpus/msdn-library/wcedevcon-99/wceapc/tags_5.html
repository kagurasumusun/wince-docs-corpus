Pit

This tag changes the average pitch of the text-to-speech (TTS) voice.

Syntax

\Pit=new_pitch\

Parameters

new_pitch
Specifies the pitch, in hertz.

Example

“\Pit=40\This sentence starts low \Pit=400\ and finishes high.”

Remarks

The actual pitch fluctuates as the string is pronounced, but this tag sets a new average.
