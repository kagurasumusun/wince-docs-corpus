Accessing Settings in Regional Setup

Regional Setup enables the user to specify regional settings. The following table shows the Regional Setup options available to a user.

Option
Description
Currency U.S. dollars or Canadian dollars. U.S. dollars is the default setting
Date style Short date format or long date format
Distance Miles or kilometers. Miles is the default setting.
Time format 12-hour or 24-hour
Time style h:mm:ss tt, hh:mm:ss tt, h:mm:ss, or hh:mm:ss
Volume or fuel Gallons or liters. Gallons is the default setting.

The regional settings information is stored in the registry. Your application can retrieve the settings for currency and volume.

    To retrieve the currency or volume information

  • Access the following registry keys:
    Currency:
    HKEY_CURRENT_USER\SYSTEM\RegionalSettings\Currency

    The value is 0 for Dollars (U.S.), or 1 for Dollars (CAN).

    Volume (Fuel Measurement):
    HKEY_CURRENT_USER\SYSTEM\RegionalSettings\Fuel

    The value is 0 for Gallons (U.S.), or 1 for Liters.
