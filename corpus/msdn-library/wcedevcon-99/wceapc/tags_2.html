Ctx

This tag sets the context for the text that follows. The context determines how symbols are spoken.

Syntax

\Ctx=string\

Parameters

string
This parameter can be one of the following context strings:
“Address”
Used for changing the pronunciation of numbers.
“Normal”
Normal or default speech mode.

Example

\ctx=“Address”\

Remarks

After you use the \ctx=“Address”\ tag to speak the address, add the \ctx=“Normal”\ tag at the end so that you go back to normal default, for example, \ctx=“Address”\106.9\ctx=“Normal”\.
