PNAVSETTINGS

This structure indicates valid and invalid PNSETTINGS elements.

Syntax

typedef struct tagPNAVSETTINGS{
DWORD dwStructureSize;
DWORD dwAv1;
DWORD dwPNReserved;
} PNAVSETTINGS;

Members

dwStructureSize
Specifies the size, in bytes, of the PNAVSETTINGS structure
dwAv1
Specifies bit flags, one for each element in the corresponding PNSETTINGS structure, that indicate if an element is available. The bit flags defined for the PNAVSETTINGS structure are described in the following table.
