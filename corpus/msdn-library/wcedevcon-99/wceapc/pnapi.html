Using Positioning and Navigation

An Auto PC provides the driver positioning and navigation assistance by using a Global Positioning System (GPS) receiver. A GPS receiver determines vehicle location by measuring the vehicle distance and angle from multiple GPS satellites that orbit Earth. Your application can use position data to find a detour from a vehicle’s current position to a specific destination when the vehicle’s route is impassable.

Applications written for an Auto PC can use the positioning and navigation API (PNAPI) to enable communication between an application and a GPS device. PNAPI is implemented as a COM object. The methods available for handling GPS devices are exposed through the IPosNav interface. These methods enable an application to perform the following:

  • Communicate with a GPS device
  • Retrieve data from a PNAPI data structure
  • Send data to a GPS device
  • Format data using conversion utilities
