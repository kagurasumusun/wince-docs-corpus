Introduction to the Auto PC

Auto PC is an in-vehicle information and entertainment system that runs the Microsoft® Windows® CE operating system. It provides a single, integrated platform that supports entertainment and information management. Microsoft® Windows® CE for the Auto PC includes extensions that support features specific to an Auto PC, such as positioning and navigation.

Windows CE has the following features:

  • The kernel supports basic services, such as process and thread handling and memory management.
  • The file system supports persistent storage of information with RAM or Compact Flash cards.
  • The Graphics, Windowing, and Events Subsystem (GWES) controls graphics and event handling.
  • Several communication interfaces support the exchange of information with other devices.

For information about the features of the Windows CE operating system, see the Microsoft Windows CE Programmer’s Guide.

Be sure to read the release notes located in the Apcreadme.htm file for important information about issues related to the use of the Microsoft® Windows® CE Platform Software Development Kit (SDK), Auto PC Edition, including the Auto PC emulator.
