Tabber Control

A tabber control enables a user to tab left or right and to choose a position in a list. It displays as a single row of tabs.

A tabber control is used to manipulate other controls. For example, in the application, Address Book, a tabber control displays letters of the alphabet on tabs. The IASTabber interface contains methods to manage this control.
