Creating the Help File

To create Help for a Windows CE platform, first create the appropriate files. Use an HTML editor, such as NotePad or Microsoft FrontPage®, a web site creationto do so. The following table shows what extensions to use for your Help files.

Help for Windows CE version number
File extension

Note Other than the file extension, .htp and .htm files are identical.
