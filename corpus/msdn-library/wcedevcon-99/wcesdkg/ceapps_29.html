Spelling Dictionaries

The SplInit function loads one main dictionary, creates three internal user dictionaries, and loads as many external user dictionaries as an application specifies for the spelling checker session.

SplInit loads a read-only main dictionary for each spelling checker session. Currently, Windows CE does not support replacing this main dictionary with a dictionary supplied by an application, but it can specify additional dictionaries to load when it calls the spelling checker.

In addition to loading the main dictionary, SplInit creates three internal user dictionaries for each spelling checker session. These dictionaries are empty when a spelling checker session is initialized. During a spelling checker session, an application can add to and modify these internal user dictionaries. When an application ends a spelling checker session with a call to SplQuit, the internal user dictionaries are not saved. The following table describes the internal user dictionaries:

Internal user dictionary
Description
SPL_IGNORE_LEX Contains words that the spelling checker finds, but that the user does not want to change. The spelling checker ignores words in this list for the remainder of the spelling checker session.
SPL_CHANGE_ALWAYS_LEX Contains words that the spelling checker finds, paired with words that replace subsequent occurrences of the found words.
SPL_CHANGE_ONCE Contains words that the spelling checker finds and the user changes. The spelling checker continues to find subsequent occurrences of the words.

An application can specify external user dictionaries for SplInit to load at the beginning of a spelling checker session. The ppwsz parameter is a pointer to a list of external user dictionaries consisting of a path and a file name for each dictionary. During a spelling checker session, an application can modify external user dictionaries. When the spelling checker session ends, the spelling checker writes external user dictionaries using the specified path and file name.

The internal and external user dictionaries are lists of NULL-terminated words. Two NULL characters indicates the end of a dictionary. In the SPL_CHANGE_ALWAYS_LEX and SPL_CHANGE_ONCE internal dictionaries, the words are listed with the incorrect word first and the correct word second. For example:

…thier\0their\0wierd\0weird\0\0

The functions that an application can use during a spelling checker session to modify internal and external user dictionaries are described in the following table:

Function
Description
SplAddUserDict Adds a single word or word pair to the specified dictionary
SplRemUserDict Deletes a single word or word pair from the specified dictionary
SplClrUserDict Clears all entries from the specified dictionary

The SplEnumUserDictionary function enumerates the contents of a specified internal or external user dictionary. The function writes the dictionary contents to the output buffer specified in the SPLBUFFER structure. One use of enumeration is to provide dictionary entries to an application, which displays the entries for a user to edit.
