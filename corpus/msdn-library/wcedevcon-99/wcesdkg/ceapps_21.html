IME Status Window

The status window provides information on the status of the IME (whether active or inactive) and allows the user to set the IME conversion mode.

To quickly change the conversion mode of the IME or to switch to another IME, users can use hot keys. To retrieve or set the value of an IME hot key, an application can call the ImmGetHotKey or ImmSetHotKey functions.

An application cannot add hot keys to the system however, it can initiate the same action as a hot key by using the ImmSimulateHotKey function.
