File System Drivers

An FSD is a DLL that exports file system entry points that map to standard Windows CE file system APIs, such as CreateFile and CreateDirectory. When an application calls a file system API function, and the function is referencing a file on a volume registered by the FSD, FSDMGR maps the call to the FSD.

Windows CE provides a template for functions that you need to develop for a file system. Typically, an FSD exports a full range of functions, but you also have the option of not exporting an entry point for a particular file system API function if you do not want that function to be available. For example, to prevent applications from creating or destroying directories inside volumes belonging to your FSD, do not include CreateDirectory and RemoveDirectory in your FSD. FSDMGR automatically supplies stub functions for any functions that you choose not to supply for your file system. These stub functions return ERROR_NOT_SUPPORTED. As a result, if an application tries to create or remove a directory on a volume that belongs to your FSD, the call fails.

In addition to exporting entry points for the file system API functions, an FSD must also export entry points for FSD_MountDisk and FSD_UnmountDisk. Device Manager calls FSD_MountDisk when a device for which that FSD has been registered is inserted or removed. The FSD_MountDisk and FSD_UnmountDisk entry points are passed double-words that uniquely identify the disk being mounted. These double words are in turn passed back to FSDMGR services that query, read, and write to that disk.
