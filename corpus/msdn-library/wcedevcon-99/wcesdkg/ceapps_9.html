Software Tools for Creating a Help System

A Help system for Windows CE consists of HTML files and graphics. Windows CE Help version 2.10 includes support for an All Topics list, using link (.lnk) files. You can also create an index. The following list describes the tools you should have to create a Help system:

  • An HTML editor, such as NotePad or FrontPage.
  • A remote screenshot program, such as CE Zoom.

    CE Zoom is a remote tool shipped with the Windows CE Toolkits. CE Zoom lets you take a screenshot from a connected Windows CE device.

  • An HTML and link validator.
