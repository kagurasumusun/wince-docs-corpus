Introduction to User Interface Services on Windows CE

Windows CE combines the Microsoft® Win32® User Interface (UI) and Graphics Device Interface (GDI) libraries into the Graphics, Windowing, and Events Subsystem module (Gwes.exe). GWES is the interface between the user, your application, and the operating system.

GWES supports all the windows, dialog boxes, controls, menus, and resources that make up the Windows CE user interface. This interface enables users to control applications. GWES also provides information to the user in the form of bitmaps, carets, cursors, text, and icons.

Even Windows CE-based platforms that lack a graphical user interface use GWES basic windowing and messaging capabilities and power management functions.
