Creating Context-Sensitive Help

The most common way to call help in Windows CE Help versions 2.0 and 2.10 is from the ? button in the upper right-hand corner of the application screen or dialog box. The user accesses Help on version 2.01 by choosing Help in the Start menu. The following code example shows how to call Help from an application, using the CreateProcess function. 

CreateProcess(TEXT,"peghelp.exe", TEXT("file:inkwrite.htm#font_and_ink"), NULL, NULL, FALSE, 0, NULL, NULL, NULL, NULL;

Pass the “peghelp.exe” string in as the first parameter, using the TEXT macro first to convert the string to Unicode. Use TEXT on the second argument, this time passing a string containing the file name of the contents or specific Help topic you want to display. Set all other parameters to NULL, FALSE, or 0, respectively.
