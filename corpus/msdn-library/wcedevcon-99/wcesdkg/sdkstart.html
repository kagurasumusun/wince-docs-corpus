Windows CE Platform SDK

The Microsoft Windows CE operating system is the portable, real-time, modular operating system for embedded and dedicated systems. The Platform SDK contains the tools and information you need to develop applications for Windows CE-based platforms.

For the latest information about developing for Windows CE, visit the Microsoft Windows CE World Wide Web site, http://www.microsoft.com/ windowsce/developer.
