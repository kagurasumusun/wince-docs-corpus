IME User Interface

The IME user interface consists of the status, composition, and candidate windows. By default, the system automatically creates and manages these windows for all windows that require text input. For many applications, this default processing is sufficient. An application that relies entirely on the system for IME support is considered IME-unaware because it is unaware of the many system tasks associated with managing IME windows.

In contrast, an IME-aware application participates in the creation and management of IME windows. Such an application controls the operation, position, and appearance of the default windows by sending, intercepting, and processing messages intended for IME windows. In some cases, an application can create and customize its own IME windows and provide complete processing for these windows.
