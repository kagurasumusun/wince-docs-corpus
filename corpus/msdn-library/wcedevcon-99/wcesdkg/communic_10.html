Accessing an FTP Server

Applications use WinInet to perform the following tasks on an FTP server:

  • Navigating between directories
  • Enumerating, creating, removing, and renaming directories
  • Renaming, uploading, downloading, and deleting files

    To access an FTP server with WinInet

  1. Call InternetOpen to initialize an Internet handle.
  2. Call InternetConnect to create an FTP session.

    InternetConnect returns a handle that subsequent functions can use, such as FtpFindFirstFile or FtpGetFile.

  3. Call InternetCloseHandle to terminate the FTP session.
  4. Call InternetCloseHandle again to terminate Internet operations.

The following table shows additional WinInet functions you can use on an FTP server.

Function
Description
FtpGetCurrentDirectory Determines which directory the application is in
FtpSetCurrentDirectory Allows the application to change to a different directory
FtpCreateDirectory Creates a new directory
FtpFindFirstFile Searches for a specific file
InternetFindNextFile Finds the next file using the handle returned from FtpFindFirstFile
FtpRenameFile Renames a file or directory
FtpDeleteFile Deletes a file
FtpPutFile Uploads a file to an FTP server
FtpGetFile Downloads a file from an FTP server

Note Applications must specify a directory name relative to the current directory or include the full directory path.
