Ending Spelling Sessions

Calling the SplQuit function ends a spelling checker session by doing the following tasks:

  • Invalidating the spelling checker session handle created when an application called the SplInit function to initialize the spelling checker session.
  • Freeing all resources that the SplInit function allocated.
  • Deleting internal user dictionaries.
  • Saving external user dictionaries to the files specified with the SplInit function.
