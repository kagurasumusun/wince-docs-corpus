Cryptography

Cryptography provides a way to distribute files and messages in secret code, or cipher, so they can only be read by intended recipients. Cryptography maintains secrecy and ensures data integrity to achieve secure communications in your applications, even with nonsecure transmission media, such as the Internet.

This chapter will cover the following aspects of cryptography:

  • Encryption and decryption
  • The Windows CE implementation of the Microsoft cryptographic system
  • How to use the Microsoft cryptographic application programming interface (CryptoAPI)
