IME Window Class

The IME window class is a predefined global system class that defines the appearance and behavior of the standard IME windows. This class is similar to common control classes with which you use the CreateWindowEx function to create a window. Like static controls, an IME window does not respond to user input by itself but, rather, notifies the IME of user input actions. To carry out a response to user action, an IME window processes messages sent by the IME or the application.

IME-aware applications can create their own IME windows using the IME window class. By using the IME window class, applications can take advantage of the default processing of the IME window while retaining control of the window's positioning.
