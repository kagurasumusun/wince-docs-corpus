Encryption and Decryption

Encryption is the process of transforming data into a form unreadable by anyone without a secret key. Decryption is the reverse process in which the encrypted data is converted back to its original form. When a user encrypts a sensitive file, an intruder cannot read the file without the proper key to decrypt it. Adding a digital signature , a form of arithmetical thumbprinting,ensures that the original message has not been tampered with.

Data that has not been encrypted is known as plaintext. To encrypt plaintext, an encryption key is used to impose an encryption algorithm onto the data. The resulting encrypted message is known as ciphertext. To return the ciphertext to plaintext, a user must possess the appropriate decryption key. A decryption key consists of random numbers, approximately 40 to 2000 bits in length, The key imposes a decryption algorithm onto the data. This decryption algorithm reverses the encryption algorithm that was previously imposed, thus returning the data to its original form. The longer the key, the more difficult it is to decrypt ciphertext without possessing the key. For a key size of just 40 bits, there are 240 possible keys, or just over one trillion.

There are two primary encryption approaches: symmetric and public-key. Symmetric encryption is the most common type of encryption and uses the same key for encryption as decryption. This key is known as a session key. Public-key encryption uses two different keys, a public key and a private key, where one key encrypts the message and the other decrypts it.The public key is widely distributed while the private key is kept secret.

Aside from key length and the encryption approach, many other factors and variables have an impact on the success of cryptographic systems. For instance, different cipher modes can be used to vary the encryption along with initialization vectors and salt values. Cipher modes define the method in which data is encrypted. The stream cipher mode encrypts data one bit at a time. The block cipher mode encrypts data one block at a time. Although they tend to execute more slowly than stream ciphers, block ciphers are generally more secure. Within block ciphers, there are four modes of encryption: electronic cookbook (ECB), cipher block chaining (CBC), cipher feedback mode (CFB), and output feedback mode (OFB). For information on these modes, see Encrypting and Decrypting Data.

Initialization vectors are random numbers used as starting points when encrypting data. Usually, initialization vectors have the same number of bits as the block size and do not require encryption. With initialization vectors, two identical plaintext messages can be encrypted with the same key and result in two completely different ciphertext messages. This variation is done by encrypting each plaintext message with a different initialization vector.

Salt values consist of random numbers and can be transmitted in plaintext form. Two identical packets of plaintext can be encrypted into two completely different packets of ciphertext, if the salt value is changed with each packet sent.

In addition to encrypting the data, a user can digitally sign data to allow another user to verify that the data has not been changed since it was signed. The identity of the user that signed the data can also be verified. This digital signature consists of a small amount of binary data, typically less than 256 bytes. A digital signature can be bundled with signed messages or stored separately; depending on the application.
