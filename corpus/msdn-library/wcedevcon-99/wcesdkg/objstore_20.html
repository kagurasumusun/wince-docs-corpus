Getting Information About a Database

Each database in the object store or a mounted database volume contains information about that database as a whole, including its name, type identifier, and sort order specifications. This information is defined in the CEDBASEINFO structure through the CeCreateDatabaseEx and CeSetDatabaseInfoEx functions. As discussed earlier, this information can be accessed using CeOidGetInfoEx.

The database name is a null-terminated string that contains up to 32 characters. The type identifier is a double-word value that can be used for any application-defined purpose, typically to differentiate one type of database from another while enumerating them. The sort order specification determines the order in which the database seek functions examine the records in a database.

The CENOTIFICATION structure contains information about the object store or a mounted database volume. The structure is sent to the application to notify it when a database record is created, modified, or deleted. Use the CeFreeNotification function to free the notification structure.
