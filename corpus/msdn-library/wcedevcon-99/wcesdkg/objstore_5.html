Creating and Opening Files

You can use the CreateFile function to create a new file or to open an existing file.

When an application uses CreateFile, it must specify whether it will read from the file, write to the file, or both. The application must also specify what action to take if the file already exists. For example, an application can specify that CreateFile is always used to create the file. The function then creates the file if it does not exist or else overwrites the file if it does exist.

CreateFile also enables an application to specify whether it wants to share the file for reading or writing. When an application opens a file and does not specify that the file may be shared, the file cannot be opened again until the application that originally opened the file closes it. This restriction also applies to the original application that opened the file.

The OS assigns a unique identifier, called a file handle, to each file opened or created. An application can use the file handle in functions that read from, write to, or describe the file. The file handle remains valid until the file is closed. For more information about processes, see Working with Processes and Threads.

    To create or open a file with the CreateFile function

  1. Specify the file name.
  2. Specify preferred access information.
  3. Specify the share mode.
  4. Specify any creation instructions.
  5. Specify any attributes you want associated with the file.

In the following code example shows how CreateFile opens an existing file for reading. 

HANDLE hFile; 
 
hFile = CreateFile(TEXT("MYFILE.TXT"),     // Open MYFILE.TXT
                GENERIC_READ,              // Open for reading
                FILE_SHARE_READ,           // Share for reading
                NULL,                      // No security
                OPEN_EXISTING,             // Existing file only
                FILE_ATTRIBUTE_NORMAL,     // Normal file
                NULL);                     // No template file
 
if (hFile == INVALID_HANDLE_VALUE) 
{ 
    // Process error ...
    return;
}

In the preceding code example, CreateFile succeeds only if a file named MYFILE.TXT already exists in the root directory. Check the return value of CreateFile before attempting to use the handle to access the file. If an error occurs, use the GetLastError function to get extended error information and respond accordingly.
