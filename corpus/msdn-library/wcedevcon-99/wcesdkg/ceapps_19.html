Working with the Input Method Editor

Similar to a spelling checker or handwriting recognition engine, an Input Method Editor (IME) in Windows CE simplifies the process of providing input for users. As a user enters keystrokes, an IME monitors the keystrokes, anticipates which character the user intends to compose, and presents a list of candidate characters. From this list, a user can select the intended character while the IME converts the user's keystrokes into this final selected character. This method of input saves users the burden of having to compose the entire character.

IMEs are particularly useful in Asian languages where each language is typically comprised of thousands of characters and it is difficult to display every character on a keyboard. In addition, characters in Asian languages are often composed of multiple strokes and are very time-consuming to enter.

An IME provides windows through which users can enter keystrokes, view candidates, and select characters. Windows CE applications can use the functions and messages of the input method manager (IMM) to create and manage their own IME windows.
