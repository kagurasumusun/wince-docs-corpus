Closing and Deleting Files

To use OS resources efficiently, an application should use CloseHandle to close files that it no longer needs. If a file is open when an application terminates, the system closes the file automatically.

To delete a file, call DeleteFile with the name of the file passed as its parameter.

A file must be closed before it can be deleted. The following code example shows how to close and delete Myfile.txt.

CloseHandle(hFile); 
DeleteFile(TEXT("MYFILE.TXT"));
