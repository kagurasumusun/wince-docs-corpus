Loading FSDs

FSDs are loaded automatically when a storage device that is registered for an FSD is inserted into a Windows CE device.

When a PC card, such as a storage card, is inserted in a device, the card’s device driver reads the PC Card driver registry entry, which defines the name of the FSD to use for the card. The PC Card driver calls LoadFSD, passing the installable FSD name. Device Manager loads the installable FSD that is passed in with the LoadFSD call. Device Manager checks in MyFSD for the FSD_MountDisk entry point, which is the generic exported entry point for MyFSD_MountDisk. If it is found, Device Manager loads Fsdmgr.dll. Device Manager calls Fsdmgr.dll, passing information about MyFSD.

FSDMGR then calls MyFSD_MountDisk, which is exported from MyFSD.dll. MyFSD_MountDisk locates all volumes on the device and registers them with FSDMGR by calling FSDMGR_RegisterVolume. FSDMGR then displays them as directories in the built-in file system and makes them accessible to applications by means of the file system APIs.
