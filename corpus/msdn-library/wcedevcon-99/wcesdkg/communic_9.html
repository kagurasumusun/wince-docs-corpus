Accessing the HTTP Protocol

Applications must interact with the HTTP protocol to access resources on the Internet. You can use the HTTP functions provided by WinInet to access the HTTP protocol, or you can use the InternetOpenUrl function to access a Uniform Resource Locator (URL) directly.

    To use the HTTP functions provided by WinInet

  1. Call InternetOpen to initialize an Internet handle.
  2. Call InternetConnect to create an HTTP session.
  3. Call HttpOpenRequest to create an HTTP request handle.
  4. Call HttpSendRequest to send an HTTP request.

    You can use the same HTTP request handle generated in the previous step in multiple calls to HttpSendRequest, but the application must read all data returned from the previous call before calling the function again.

  5. Call InternetReadFile to download information.

    – Or –

    Call InternetQueryDataAvailable to query how much data is available to be read by a subsequent call to InternetReadFile.

  6. Call InternetCloseHandle to terminate Internet operations.

Use the InternetOpenUrl function to parse the URL string, establish an Internet connection, and prepare for data download. This is practical for applications that are not concerned with protocol details, but are interested in retrieving only data that relates to a specific URL.

    To use InternetOpenUrl to access a URL

  1. Call InternetOpen to initialize an Internet handle.
  2. Call InternetOpenUrl to open a connection to the URL using the handle created by InternetOpen.

    InternetOpenUrl returns a handle that subsequent functions can use, such as InternetReadFile or InternetSetFilePointer. You do not need to call InternetConnect when you use InternetOpenUrl.

  3. Call InternetReadFile to download information.

    – Or –

    Call InternetFindNextFile to navigate between directories.

    InternetQueryDataAvailable can use the handle returned by InternetOpenUrl to query how much data is available to be read by a subsequent call to InternetReadFile.

  4. Call InternetCloseHandle to close the handle created by InternetOpenUrl.
  5. Call InternetCloseHandle again to terminate Internet operations.
