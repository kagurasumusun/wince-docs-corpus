IME Candidate Window

The candidate window contains a list of candidate characters for the selected character in the composition window. Users can scroll through this list and select the desired character before composition of the character is completed in the composition window. The user can compose the desired text in this manner until the composition string is finalized and the candidate window is closed.

Once the desired character has been determined, the IME sends this character to the application in the form of WM_IME_CHAR or WM_IME_COMPOSITION/GCS_RESULT messages. If the application does not process these messages, the DefWindowProc function translates them into one or more WM_CHAR messages.

The characters in the candidate list are arranged in an array of strings in the CANDIDATELIST structure. Use the ImmGetCandidateList function to retrieve a candidate list and copy the list to a buffer. Use the ImmGetCandidateListCount function to retrieve the total size, in bytes, of all the candidate lists. To get or set information about the candidate list window in the CANDIDATEFORM structure, use the ImmGetCandidateWindow and ImmSetCandidateWindow functions.
