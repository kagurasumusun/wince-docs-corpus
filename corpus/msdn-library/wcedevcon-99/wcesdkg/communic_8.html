Establishing an Internet Connection

WinInet handles are maintained in a hierarchy in which you must call a higher-level function before you call a dependent function. Handles returned by the WinInet functions in Windows CE control only Internet functions. They are not native system handles. Therefore, only an Internet function works with its corresponding Internet handle. Win32 routines, such as ReadFile or CloseHandle, fail.

    To establish an Internet connection with WinInet

  1. Call InternetOpen.

    This function initializes an Internet handle that is used by all subsequent functions.

  2. Call InternetConnect.

    This function uses the handle returned by InternetOpen to create an HTTP or FTP session.

  3. Call any of the other WinInet functions, such as HttpOpenRequest or FtpFindFirstFile.
  4. Call InternetCloseHandle to terminate Internet operations.

    This function closes the Internet handle and frees any resources associated with it. InternetCloseHandle terminates existing activity on the handle and discards remaining data. If InternetCloseHandle closes a parent handle, all of the parent’s child handles are also closed. If an operation requires more than one Internet handle, you may need to make multiple calls to InternetCloseHandle.
