The Database GUID Macros

You use a Windows CE GUID (CEGUID) to identify the mounted database volumes. Four macros are used to create or check CEGUIDs.

Use the CREATE_SYSTEMGUID macro to generate a CEGUID that identifies the object store on the Windows CE device. When you need to check if the CEGUID returned from a function call is the object store, use the CHECK_SYSTEMGUID macro.

Some database functions can be called with an invalid CEGUID or they can return one. For example, if you want to use the CeEnumDBVolumes function to enumerate all available databases, you can pass it an invalid CEGUID the first time you call it. This causes the function to begin returning database information from the first database on the system. Use the CREATE_INVALIDGUID macro to create the invalid CEGUID. Likewise, call the CHECK_INVALIDGUID macro to check if a CEGUID is an invalid CEGUID.

If you pass CREATE_SYSTEMGUID to the Ex functions, then access is directed to the object store.
