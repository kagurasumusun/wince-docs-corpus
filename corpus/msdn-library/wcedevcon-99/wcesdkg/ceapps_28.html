Initializing a Spelling Session

An application calls the SplInit function to initialize a spelling checker session. SplInit does the following tasks:

  • Creates a handle for a spelling checker session
  • Loads the main dictionary
  • Creates internal user dictionaries
  • Loads external user dictionaries

Each call that an application makes to the spelling checker specifies a pointer to the handle of the spelling checker session. The handle associates a call to a particular spelling checker session.
