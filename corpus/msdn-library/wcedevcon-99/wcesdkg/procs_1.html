Creating and Terminating a Process

When you initiate an application from within a running application, the application calls the CreateProcess function to load the new application into memory and to create a new process with at least one new thread.

    To create and terminate a process

  1. Call the CreateProcess function to create a process.

    The lpApplicationName parameter must specify the name of the module to execute. Windows CE does not support passing NULL for lpApplicationName.

  2. Call the TerminateProcess function to terminate a process.

    Windows CE processes do not have exit codes and cannot terminate themselves. You cannot use TerminateProcess to terminate a Protected Server Library (PSL) for processes contained therein.

The intent of creating threads in an application is to make use of as much of the CPUs time as possible. To aid in measuring this performance for your application, use the GetThreadTimes function. GetThreadTimes returns the total time that a given process has taken to perform an assigned task.
