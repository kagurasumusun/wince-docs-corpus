Remote Debugging and Testing

In addition to desktop emulation, Windows CE contains several tools that enable you to examine your application as it runs. The following table shows these remote tools.

Tool
Purpose
Remote Process Viewer Displays a graphical view, on the desktop computer, of Windows CE processes and thread characteristics. The Process Viewer enables you to view memory usage and search for memory leaks.
Remote File Viewer Displays a hierarchical view, on the desktop computer, of the Windows CE object store. The File Viewer enables you to transfer objects between the emulation object store and the device.
Remote Zoomin Captures an image from the remote device and displays it on the desktop computer.
Remote Registry Editor Manages remote device registry entries from the desktop computer.
Remote Heap Walker Displays information about heap identifiers and flags for processes that are running on a remote device. The Heap Walker is a useful tool to determine if an application has memory leaks.
Remote Spy++ Displays a graphical view, on the desktop computer, of window messages running on the remote device.

In order to use the remote tools, you must connect your desktop computer to your remote device with a standard serial cable connection. For information on how to physically connect your desktop computer and a remote device, see the user’s guide that came with your device.
