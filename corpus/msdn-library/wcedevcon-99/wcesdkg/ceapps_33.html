Getting Suggestions

Call the SplSuggest function to receive suggestions for alternatives to misspelled words from the spelling checker. To get suggestion scores, an application must call the SplOptionSet function and set the SPL_SCORE_SUGGESTIONS flag.

A call to SplSuggest causes the spelling checker to return up to eight alternative words to the output buffer specified in the SPLBUFFER structure. The aspl member of SPLBUFFER is an array of SPLSUGGEST structures, one structure for each word. The first member of this structure points to a word in the output buffer, and the second member specifies a score for the suggested alternative. The score indicates the extent to which the spelling checker changed the misspelled word to produce the suggested replacement for the word. An application can use suggestion scores to exclude some words from the list of alternatives that it displays to a user.
