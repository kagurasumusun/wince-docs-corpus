Creating a Help system

Introduction: Windows CE Help is an application that lets you display HTML-based Help files. The first part of this section is a general overview of Windows CE Help. It discusses how the user accesses Help files on a Windows CE mobile platform and how Windows CE Help interacts with the rest of Windows CE. The second part discusses how to create a Help system for Windows CE. The third part contains a full example of a Windows CE help file.
