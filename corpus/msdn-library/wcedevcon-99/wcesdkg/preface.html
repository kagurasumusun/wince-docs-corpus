Preface

The Microsoft Windows CE User Interface Services Programmer’s Guide in conjunction with the Windows CE Programmer’s Guide, the Windows CE Communications Guide, and the Windows CE SDK Library provides all the information you need to write applications for devices based on the Microsoft Windows CE operating system.

The Windows CE User Interface Services Guide contains the following chapters:

Introduction to User Interface Services on Windows CE

This chapter provides an overview of the Graphics, Windowing, and Events Subsystem (GWES) module, and specifically, Windows CE User Interface Services. It explains the specific components included in GWES and how those components work together to provide window management and event handling, power management features, control, menu, GDI, dialog box, resource, and user input support.

Working with Windows and Messages

This chapter discusses Windows CE windowing and messaging features. Emphasis is placed on creating, sizing, positioning, and destroying windows as well as sending and responding to messages.

Using Resources

This chapter provides information about resources such as dialog and message boxes, menus, icons, carats, bitmaps, and timers.

Creating Controls

This chapter explains how to add standard controls to a user interface.

Working with Graphics

This chapter provides an overview of the Windows CE Graphics Device Interface (GDI). It also explains how to work with graphics objects such as pens, brushes, shapes, fonts, and lines.

Receiving User Input

This chapter discusses various user input methods supported by Windows CE, such as keyboard, mouse, handwriting, and speech API (SAPI). It also describes how to use virtual keys.

Designing a User Interface for Windows CE

This chapter provides a general overview of user interface design concepts and presents specific suggestions for working with windows and dialog boxes, adding controls, creating icons, using color, and layout.

Appendix A: Window and Control Styles

This appendix lists window and control styles supported by Windows CE.
