Finding Spelling Mistakes

To use the spelling checker, an application fills a SPLBUFFER structure with the information the spelling checker needs. This information includes the location of the beginning of the input buffer, which contains the text to be processed, and the location of the output buffer where the speller checker returns suggestions for misspelled words.

After initializing a spelling checker session, an application calls the SplCheck function. With this call, the spelling checker processes the text in the input buffer. When the spelling checker finds an error, it identifies the location of the error relative to the beginning of the buffer and sets an error flag that indicates what the error is. The spelling checker updates the SPLBUFFER structure with this information. An application updates SPLBUFFER by adjusting the beginning of the input buffer and setting a processing mode flag that indicates how the spelling checker proceeds.
