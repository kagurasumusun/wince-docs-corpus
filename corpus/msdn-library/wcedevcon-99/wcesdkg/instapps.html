Installing and Managing Applications

This chapter is going to discuss how to use one application to increase the capabilities of another application. First, we'll talk about how applications run on a Windows CE device. Then, we'll talk about how to install your own applications using the Windows CE CAB files and the Application Manager. Then, we'll talk about how to use two of the applications that are common to many Windows CE Devices: the Help system, the spell checker, and (maybe) Pocket Outlook.
