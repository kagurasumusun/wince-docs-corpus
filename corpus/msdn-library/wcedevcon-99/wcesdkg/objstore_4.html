File System API

The Windows CE file system API enables applications to create, open, modify, and delete files and directories. It also enables applications to retrieve data from files and retrieve system information about files. The following table shows the functions in the file system API that Windows CE supports.

CopyFile GetFileInformationByHandle
CreateDirectory GetFileSize
CreateFile GetTempPath
DeleteFile MoveFile
DeviceIoControl ReadFile
FindClose RemoveDirectory
FindFirstFile SetEndOfFile
FindNextFile SetFileAttribute
FlushFileBuffers SetFilePointer
GetDiskFreeSpaceEx WriteFile
GetFileAttributes  

The file system API functions that create, open, and delete files and directories take a string identifying the path and file name as a parameter.

The file system API provides functions used to obtain information about a file or file system. The GetFileInformationByHandle function retrieves information about a file and stores it in a structure of the type BY_HANDLE_FILE_INFORMATION. This information includes creation time, file size, and file attributes, such as whether the file is hidden or is a directory. For more information about file attributes, see Microsoft Visual C++ for Windows CE Programmer’s Reference, Microsoft Press, 1998.

An application can use the GetFileAttributes function to retrieve the file attributes. The CreateFile and SetFileAttributes functions can set most file attributes. However, some attributes can only be set by the OS or by the device manufacturer. The GetFileSize function returns the size of a file. The GetDiskFreeSpaceEx function retrieves organizational information about a file system partition, including the number of bytes per sector, the number of sectors per cluster, the number of free clusters, and the total number of clusters.
