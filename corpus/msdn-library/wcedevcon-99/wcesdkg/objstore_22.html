Working with Database Records

Several functions allow you to create, modify, and delete database records and their properties.

You can create new records or modify existing records using the CeWriteRecordProps function. The function parameters include the handle to the database and the CEOID of the record to add. If the CEOID is zero, CeWriteRecordProps creates a new record. On a mounted database volume, all write operations are cached. The database subsystem will periodically request a cache flush after a series of operations. If memory is low, the cache is flushed to permanent storage. Unlike the file system that can choose to flush only part of the cache, on a database flush, all blocks are flushed.

    To write properties to a record

  1. Create an array of CEPROPVAL structures.
  2. Call the CeWriteRecordProps function.
  3. Pass the handle of the database in the function’s HANDLE parameter.
  4. Pass the CEOID of the record in the function’s CEOID parameter.

    If the passed CEOID is zero, a new record will be created.

  5. Pass the number of properties being set in the function’s property-count parameter.
  6. Pass the address of the array of property values in the function’s CEPROPVAL parameter.

    You must pass at least one property value. You can delete a property by setting the CEDB_PROPDELETE flag for a particular property. CeWriteRecordProps returns the CEOID of the record to indicate success, or zero to indicate failure.

Use the CeDeleteRecord function to delete a record from a database, supplying the CEOID of the record and the handle to the open database that contains the record.

The following code example shows how to create and write four properties: a 16-bit signed integer, a 32-bit signed integer, a null-terminated string, and a binary large object (BLOB) to the new record. 

TCHAR szError[50];            // String for displaying an error message
HANDLE hDataBase;            // Database handle returned by CeOpenDatabase            
CEOID CeOid;                    // Object identifier of the written record
CEPROPVAL NewRecProps[4];    // New property to be written to a record
LPBYTE lpBlob;                // Pointer to the BLOB data
LPWSTR lpwStr;                // Pointer to a null-terminated Unicode 
                            // character string 

// Assign values to the properties to be written.

// A 16-bit signed integer
NewRecProps[0].propid = CEVT_I2;
NewRecProps[0].wLenData = 0;
NewRecProps[0].wFlags = 0;
NewRecProps[0].val.iVal = –1;

// A 32-bit signed integer
NewRecProps[1].propid = CEVT_I4;
NewRecProps[1].wLenData = 0;
NewRecProps[1].wFlags = 0;
NewRecProps[1].val.lVal = 0xffffffff;

// A null-terminated string
lpwStr = (LPWSTR) LocalAlloc (LMEM_FIXED, 50 * sizeof(TCHAR));
if ( lpwStr )
    _tcscpy(lpwStr, TEXT("This is a string property"));

NewRecProps[2].propid = CEVT_LPWSTR;
NewRecProps[2].wLenData = 0;
NewRecProps[2].wFlags = 0;
NewRecProps[2].val.lpwstr = lpwStr;

// A CEBLOB structure
lpBlob = (LPBYTE) LocalAlloc(LMEM_FIXED, 50  * sizeof(TCHAR));
if ( lpBlob )
    _tcscpy((LPWSTR) lpBlob, TEXT("This is a blob property"));

NewRecProps[3].propid = CEVT_BLOB;
NewRecProps[3].wLenData = 0;
NewRecProps[3].wFlags = 0;
NewRecProps[3].val.blob.dwCount = 50  * sizeof(TCHAR);
NewRecProps[3].val.blob.lpb  = lpBlob;

// Call function CeOpenDatabaseEx to open the database 
// hDataBase = CeOpenDatabaseEx {...}

// Write the properties to a new record.
if (!(CeOid = CeWriteRecordProps(
            hDataBase,        // Handle of the database
            0,                // Write a new record.
            4,                // Four properties
            NewRecProps        // Pointer to the new properties
            )))
{
    wsprintf(szError, TEXT("ERR: CeWriteRecordProps failed (%ld)"),
            GetLastError());
}

// Free local memory lpBlob 
if( lpBlob )
    LocalFree(lpBlob);

// Free local memory lpwStr 
if( lpwStr )
    LocalFree(lpwStr);

// Close database handle
CloseHandle(hDataBase);
