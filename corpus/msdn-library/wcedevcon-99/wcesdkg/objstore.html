Accessing Persistent Storage

The persistent storage that Windows CE uses to support applications is called the object store. This part of memory is not used for the operating system (OS), but rather for registry entries, a file system, and Windows CE databases. Windows CE also supports storage on mounted file systems, such as PC Card storage devices. Windows CE also supports using DLLs to add your own installable file system drivers.

To create, access, or store a data object, you need to use the appropriate application programming interface (API) for the type of data object with which you are working.

Windows CE persistent storage consists of the following APIs:

  • Object identifier APIs, which allow manipulation of databases in the object store and mounted file systems.
  • File system APIs, which allow manipulation of files and directories in the object store and mounted file systems.
  • Registry APIs, which allow registry manipulation in the object store and external locations.
