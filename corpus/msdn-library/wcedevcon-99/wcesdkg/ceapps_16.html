Adding to the All Topics List

The All Topics is a list of HTML links to all the available Help files on a Windows CE platform. The All Topics list for Windows CE Help versions 2.0 and 2.01 is a separate HTML file listing links to all the Help files on the platform. The manufacturer creates this file; do not alter it. Version 2.1 creates an All Topics list dynamically by selecting the name of the first topic in each Help file and a corresponding link (.lnk) file.

    To add a topic to the All Topics list for version 2.10

  1. Name the first topic in each Help file Main_Contents.

    Place this name only in files you want to include in the table of contents.

  2. Include “Main_Contents” in the <META> tag for each of these files.

    The following code example shows how to include a topic in the dynamic table of contents. 

    <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">
<HTML>
<HEAD>
<META HTTP-EQUIV="Htm-Help" CONTENT="soltr.htm#Main_Contents">
<TITLE>Solitaire Help</TITLE>
</HEAD>
<BODY BGCOLOR="#FFFFFF" TEXT="#000000">
<!-- PegHelp -->
<P><A NAME="Main_Contents"></A><B>Solitaire Help</B></P>
<A HREF="soltr.htm#playing_the_game">Playing the Game</A><BR>
<A HREF="soltr.htm#setting_solitaire_options">Setting Solitaire Options</A><BR>
<A HREF="soltr.htm#solitaire_scoring_systems">Solitaire Scoring Systems</A><BR>
<BR CLEAR=ALL>
<!-- PegHelp --><HR>
<!-- ************************Topic Break************************* -->
  3. Create a link file for each Help file in the table of contents.

    Create a link file with NotePad or another ASCII editor. Name the link file as you want Help to display the link in the table of contents. For example, the Solitaire Help file is Soltr.htm and the link file is Solitaire.lnk. The link in the table of contents is Solitaire. You can place spaces in the link file name. For example, the link file for Pocket Word is Pocket Word.lnk.

    The text in the link file tells Windows CE Help where to aim the link in the table of contents. The following code example is one entry in the Solitaire.lnk file. 

    18#\windows\soltr.htm

    The number 18 in this example represents the number of characters in \Windows\Soltr.htm

    During program installation, install your link file in the \Windows\Help directory. You can install the Help file anywhere on the platform.
