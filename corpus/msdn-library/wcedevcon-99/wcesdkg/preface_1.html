About the Code Samples Included in this Guide

The Windows CE User Interface Services Programmer’s Guide includes code samples developed with Microsoft® Visual C++® version 6.0 and the Microsoft® Windows® CE Toolkit for Visual C++® version 6.0. Concepts presented in sample applications are ported for a Handheld PC (H/PC) and for an H/PC running Microsoft® Windows® CE, Handheld PC Professional Edition software, but apply to all Windows CE-based platforms.
