Communicating over the Internet

As previously mentioned, Windows CE supports WinInet, the Windows CE Internet API. WinInet is used by applications that use HTTP and FTP Internet protocols. The WinInet.dll module exports the WinInet functions, which you can use to develop Internet client applications, such as Web browsers and file-transfer applications.

Although you can use Winsock connections to access HTTP and FTP, applications that use WinInet do not have to identify the underlying protocols. The functions remain constant even when Internet protocols change.

On Windows CE-based platforms, most WinInet callback functions operate synchronously and support Unicode input by default. Only InternetReadFile and InternetQueryDataAvailable operate in both synchronous and asynchronous modes. To request asynchronous operation on these two functions, an application sets the INTERNET_FLAG_ASYNC flag when it calls InternetOpen, which is the initial function required to establish an Internet connection.

WinInet allows multithreaded applications to make concurrent calls to WinInet functions from different threads. Although the functions in WinInet complete any necessary synchronization, they do not validate parameters.
