Providing User Feedback

In addition to receiving user input, a user interface provides feedback by displaying messages. Messages are communications to the user displayed on the screen. They inform the user of system status, or prompt the user to complete some action. Effective messages are clear and concise.

When you include an identification number in message text, place it at the end of the message text and not in the title bar or at the beginning of the text where it may decrease the user’s ability to quickly read the message.
