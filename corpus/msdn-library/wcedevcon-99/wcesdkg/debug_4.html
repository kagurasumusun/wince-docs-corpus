Windows CE Emulation

The Microsoft® Windows® CE emulation environment provides a Microsoft® Windows® NT desktop version of Windows CE. This environment allows you to run your applications on a simulated version of your targeted Windows CE platform. The emulation environment supports Windows CE common controls and the Windows CE object store file system.

The object store is managed by a file called FILESYS.EXE and contains the Windows CE registry, databases, and other files. The tree structure is identical to the tree structure of the object store on the remote device. Most of the Windows CE functionality is retained, including desktop shortcuts, object store browsing, drag-and-drop operations, context-sensitive menus, and support for all shell APIs.

To run emulation on your desktop PC, you must first have Microsoft® Windows NT® 4.0, Microsoft® Visual C++® 6.0, and the Microsoft® Windows® CE Toolkit for Visual C++® 6.0 installed. Each Windows CE platform has slightly different emulation procedures. To learn the emulation procedures for your targeted Windows CE platform, see the emulation section in the platform SDK documentation.
