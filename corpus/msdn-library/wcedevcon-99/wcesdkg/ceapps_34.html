Automatic Spell Checking

An application can implement an automatic spelling checker that corrects words as a user types. A single call to the SplReplace function checks a word and if it is wrong, returns to the SPLBUFFER structure a suggested replacement for the word. However, SplReplace returns a suggestion only if the error tolerance of the suggestion is within the limit set by an application with a call to the SplLimitSet function.
