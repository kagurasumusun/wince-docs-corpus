TouchPanelReadCalibrationAbort

This function aborts the currently active call to the TouchPanelCalibrateAPoint function.

Syntax

VOID TouchPanelReadCalibrationAbort(void);

Return Values

TRUE indicates success. FALSE indicates that there is no active TouchPanelCalibrateAPoint call in progress.

Remarks

This function is declared in the Tchddi.h header file and is available in Windows CE version 1.0 and later.
