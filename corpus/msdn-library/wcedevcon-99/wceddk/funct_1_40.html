CardResetFunction

This function resets a specified card function in a specified socket.

Syntax

STATUS CardResetFunction(CARD_CLIENT_HANDLE hCardClient CARD_SOCKET_HANDLE hSock);

Parameters

hCardClient
Handle obtained from the CardRegisterClient function.
hSock
Handle to a socket and function pair.

Return Values

CERR_SUCCESS indicates success. One of the following values indicates failure.

CERR_BAD_HANDLE
Indicates that the driver handle specified for hCardClient is invalid.
CERR_BAD_SOCKET
Indicates that the socket identifier specified for hSock is invalid.
CERR_IN_USE
Indicates that another driver owns the configuration for the requested socket.
CERR_NO_CARD
Indicates that no PC Card is inserted in the specified socket.

Remarks

If there are no conflicts, Card Services resets the socket and function pair before this function returns.

Driver Name

PCMCIA
