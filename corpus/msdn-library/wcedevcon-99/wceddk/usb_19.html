Testing USB Device Drivers

There is no extensive USB test suite for Windows CE at this time. The sample USB mouse and HID drivers, the USB CD-Changer device driver for the Auto PC, and the USB 8x930Ax peripheral kit and evaluation board from Intel Corporation can be used to assist in testing USB scenarios. These are the methods used at Microsoft to test the USB system software for Windows CE 2.10. Further details on testing a USB system and the device drivers on an OEM platform are available in the Platform Builder.
