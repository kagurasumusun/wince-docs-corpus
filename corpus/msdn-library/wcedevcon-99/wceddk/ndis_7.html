Testing NDIS Miniport Drivers

The Windows CE Device Driver Test Kit for Windows CE versions 2.1 and 2.11 includes a tool called Ndistest to assist in testing NDIS Ethernet miniport drivers. The Test Kit does not include any tools for testing IrDA miniport drivers. The Ndistest tool is a special protocol driver that provides functionality and stress testing. Ndistest for Windows CE is based on the test tool for Windows NT, with the difference that the Windows CE test tool does not include a Graphics User Interface to configure and run the tests. Rather, Ndistest for Windows CE requires that a user manually edit configuration files and start the tests using a command line. Dual-computer testing for Windows CE runs against an Ndistest server running Windows NT.

Although the Device Driver Test Kit is part of the Windows CE Platform Builder, it was not present for Windows CE version 2.10. The Device Driver Test Kit for Windows CE version 2.10 is available on the Windows CE Web site at http://www.microsoft.com/windowsce/downloads/embedded/default.asp. The Ndistest tool from the Device Driver Test Kit for Windows CE version 2.1 works on both Windows CE versions 2.1 and 2.11.
