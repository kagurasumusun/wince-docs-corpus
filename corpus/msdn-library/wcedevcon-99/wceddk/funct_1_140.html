IsListEmpty

This function indicates whether or not a doubly-linked, driver-maintained list is empty.

At a Glance

Header file: Ntcompat.h
Windows CE versions: 2.0 and later

Syntax

BOOLEAN IsListEmpty(IN PLIST_ENTRY ListHead);

Parameters

ListHead
Pointer to the driver-allocated storage for the head of the list.

When this parameter is of type LIST_ENTRY, it is doubly linked.

Return Values

Returns TRUE if there are currently no entries in the list.

Remarks

A driver that calls this function can be running at IRQL >= DISPATCH_LEVEL only if the caller-allocated storage for ListHead is resident and only if pointers to every list entry remain valid at IRQL >= DISPATCH_LEVEL as well.
