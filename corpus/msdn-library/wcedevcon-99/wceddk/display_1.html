Display Driver Interface

In Windows CE, display drivers are native drivers because there is a custom interface between them and the Graphics, Windowing, and Events subsystem (GWES). They are loaded and called directly by their parent process, which can be either the GWES module or the Device Manager. Windows CE display drivers are most commonly written using a layered architecture. The GPE library provided by Microsoft handles all the default drawing, acting as the display driver’s model device driver (MDD) layer. OEMs or independent hardware vendors (IHVs) write the hardware-specific code that corresponds to the display driver’s platform-dependent driver (PDD) layer. Display driver writers can minimize the amount of time and effort needed to create a display driver by customizing one of the sample drivers provided in the Platform Builder. The display drivers in the Platform Builder represent a variety of display hardware devices. All of the sample drivers take advantage of the GPE to provide default drawing with hardware-specific issues addressed in the driver samples.
