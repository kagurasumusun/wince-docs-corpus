IOCTL_HID_ACQUIRE

This control code unsubscribes an event handle from receiving notifications about HID class device events.

Parameters

hDevice
Handle to the HID class device.
dwIoControlCode
Specifies this code.
lpInBuffer
Pointer to an input buffer containing a SHiddiAcquire structure.
nInBufferSize
Specifies the length of the input buffer.
lpOutBuffer
NULL.
nOutBufferSize
Not used.
lpBytesReturned
Specifies the total number of bytes returned.
lpOverlapped
NULL.

Remarks

The input buffer contains a SHiddiAcquire structure that indicates a device ID and whether to acquire or unacquire the device. Since acquiring the device is now performed through the IOCTL_HID_SET_FORMAT control code, this control code should only be used to unacquire a device. The HID class driver should return an INVALID_PARAMETER error if this code is used to attempt to acquire a device.
