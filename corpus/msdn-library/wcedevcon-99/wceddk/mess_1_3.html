ACMDM_DRIVER_NOTIFY

This message notifies an ACM driver of changes to other ACM drivers.

Parameters

dwDriverID
Specifies a driver instance identifier. The driver returns this value in response to the ACM_Open function.
hDriver
Handle to a driver.
uMsg
Specifies this message.
lParam1
Not used.
lParam2
Not used.

Return Values

MMSYSERR_NOERROR indicates success. Otherwise, the driver returns one of the MMSYSERR error values declared in the Mmsystem.h header file or one of the ACMERR error values declared in the Msacm.h header file.

Remarks

Each time a client calls the acmDriverAdd, acmDriverRemove, or acmDriverPriority functions, the ACM (Waveapi.dll) sends this message by calling the ACM driver’s ACM_IOControl entry point through the DeviceIoControl function. For more information about these functions, see the Windows CE Platform SDK.

ACM driver support for this message is optional. If the driver supports this message, it can call ACM functions, such as acmEnumDrivers and acmMetrics, to determine which drivers have been added, removed, enabled, disabled, or changed in priority. However, Windows CE versions 2.12 and earlier do not issue this message because ACM drivers cannot be dynamically added or removed, and their priorities are fixed.
