Using 2-Bits per Pixel

The 2-bpp format typically is used for four-level grayscale displays, although any four-entry palette works. The following table shows the bits for the associated gray levels.

Bit 1
Bit 0
Gray level
0 0 Black
0 1 Dark gray
1 0 Light gray
1 1 White
