NdisRawWritePortUlong

This function writes a ULONG value to an I/O port on the NIC.

At a Glance

Header file: Ndis.h
Windows CE versions: 2.0 and later

Syntax

VOID NdisRawWritePortUlong(IN ULONG Port, IN ULONG Data);

Parameters

Port
Specifies the I/O port. This address falls in a range that was mapped during initialization with the NdisMRegisterIoPortRange function.
Data
Specifies the ULONG to be written.

Remarks

This function runs faster than the NdisImmediateWritePortUlong function because it need not map a bus-relative I/O port address onto a host-dependent logical port address at every call.

A driver that calls this function can run at any IRQL.
