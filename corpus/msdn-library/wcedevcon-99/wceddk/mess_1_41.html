WODM_RESTART

This message is used in an MMDRV_MESSAGE_PARAMS structure passed to the WAV_IOControl function to request a waveform output driver to continue playback of a waveform after playback has been paused with WODM_PAUSE.

Parameters

uDeviceId
Device identifier—0, 1, 2, and so on—for the target device.
uMsg
Specifies this message.
dwUser
Specifies a device instance identifier.
dwParam1
Not used.
dwParam2
Not used.

Return Values

MMSYSERR_NOERROR indicates success. Otherwise, the driver returns one of the MMSYSERR or WAVEERR error values declared in the Mmsystem.h header file.

Remarks

The ACM sends this message by calling the audio driver’s WAV_IOControl entry point through the DeviceIoControl function.

Data output resumes from the position that was saved when the WODM_PAUSE message was received.

If the driver receives this message and output is not in a paused state, the driver does nothing except return MMSYSERR_NOERROR.
