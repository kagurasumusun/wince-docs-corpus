IOCTL_SERIAL_GET_WAIT_MASK

This code retrieves the value of the wait mask.

Parameters

dwOpenData
Handle returned from a call to the COM_Open function.
dwCode
Specifies this code.
pBufIn
Ignored.
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Ignored.
pdwActualOut
Ignored.

Remarks

This control code is declared in the Pegdser.h header file and defined in the Mdd.c file.
