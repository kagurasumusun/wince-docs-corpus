ASSERT

This macro evaluates the specified condition in a debug build. If the resulting evaluations is FALSE, it calls the DbgAssert function to handle the assertion failure.

At a Glance

Header file: Ndis.h
Windows CE versions: 2.0 and later

Syntax

ASSERT(Expression);

Parameters

Expression
Boolean that defines the condition to evaluate.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

If you use this macro, DbgAssert might display a message box. If this is not acceptable in your environment, use KASSERT instead.
