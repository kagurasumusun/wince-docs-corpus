HWClose

This function closes the device initialized by the HWInit function.

Syntax

ULONG HWClose(PVOID pContext);

Parameters

pContext
Pointer to a context structure returned by HWInit that contains implementation-specific data describing the hardware device.

Return Values

Zero indicates success.

Remarks

This function supports the implementation of the PDDs of serial port drivers. This function is decared in the Serhw.h header file and is available in Windows CE version 1.0 and later.
