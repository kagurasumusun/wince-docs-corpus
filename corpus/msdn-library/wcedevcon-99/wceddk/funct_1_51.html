COM_PowerUp

This function indicates to the serial port driver that the platform is resuming from suspend mode.

Syntax

BOOL COM_PowerUp(HANDLE pContext);

Parameters

pContext
Pointer to a handle to the device.

Return Values

Zero indicates success. A value of 1 indicates failure.

Remarks

This function is exported to users. As with all power-up handlers, this function cannot call functions in other DLLs, memory allocators, debugging output functions, or do anything that could cause a page fault.

This function is defined in the Mdd.c file.
