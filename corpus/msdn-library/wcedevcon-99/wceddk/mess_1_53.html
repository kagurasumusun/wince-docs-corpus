WPDM_PAUSE

This message is passed to the PDD_WaveProc function to instruct the audio PDD to pause playback.

Parameters

apidir
Output only; one of the following values:
WAPI_IN
Not used.
WAPI_OUT
Support required for output.
dwParam1
Not used.
dwParam2
Not used.

Remarks

This message is declared in the Waveddsi.h header file.
