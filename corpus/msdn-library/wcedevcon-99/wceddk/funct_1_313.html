OhcdPdd_PowerUp

This function is the OHCD power-up handler.

Syntax

void OhcdPdd_PowerUp(DWORD dwDeviceContext);

Parameters

dwDeviceContext
[IN] Specifies a pointer to the device context returned from the OhcdPdd_Init function.

Remarks

This function is called when the system turned on. This function must call the OhcdMdd_PowerUp function to enable the MDD to restore state information. The OHC interface memory area, as passed to the OhcdMdd_CreateOhcdObject function, must be preserved across a power cycle. No system calls may be made from within this function.

This function is declared in the Ohcdddsi.h header file.
