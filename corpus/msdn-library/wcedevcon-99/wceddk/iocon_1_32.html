IOCTL_SERIAL_SET_RTS

This code sets the Ready to Send (RTS) signal to high.

Parameters

dwOpenData
Handle returned from a call to the COM_Open function.
dwCode
Specifies this code.
pBufIn
Ignored.
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Ignored.
pdwActualOut
Ignored.

Remarks

This control code is declared in the Pegdser.h header file and defined in the Mdd.c file.

See Also

IOCTL_SERIAL_CLR_RTS, COM_IOControl, COM_Open
