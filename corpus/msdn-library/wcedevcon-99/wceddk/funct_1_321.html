PDCardGetWindow

This function reports the current state of a memory or an I/O window.

Syntax

STATUS PDCardGetWindow(UINT32 uWindow, PPDCARD_WINDOW_STATE pWindowState);

Parameters

uWindow
Specifies the number indicating the window. The first window is 0.
pWindowState
Pointer to a PDCARD_WINDOW_STATE structure.

Return Values

Returns one of the CERR_* error values in the Cardserv.h header file.
