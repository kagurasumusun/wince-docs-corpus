HWPowerOn

This function is called by the model device driver to notify the platform-dependent driver that the platform is resuming from suspend mode.

Syntax

BOOL HWPowerOn(PVOID pContext);

Parameters

pContext
Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function is called when the device enters a power-up state. Since this call is without standard process/thread context, take care in writing this function. No DLLs or system calls, such as Sleep, can be used. This function restores its state from local storage, and then returns.

This function supports the implementation of the PDDs of serial port drivers. This function is declared in the Serhw.h header file and is available in Windows CE version 1.0 and later.
