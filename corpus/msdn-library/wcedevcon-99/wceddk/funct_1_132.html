HWSetDTR

This function sets the Data Terminal Ready (DTR) signal.

Syntax

VOID HWSetDTR(PVOID pContext);

Parameters

pContext
Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.

Return Values

None.

Remarks

This function sets the DTR signal. This function supports the implementation of the Serial Port Drivers PDD. This function is declared in the Serhw.h header file and is available in Windows CE version 1.0 and later.

See Also

HWInit, HWClearDTR
