PDCARD_POWER_ENTRY

This structure indicates the voltage levels that a socket controller can produce.

Syntax

typedef struct {
UINT8 uPowerLevel;
UINT8 fSupply;
} PDCARD_POWER_ENTRY;

Members

uPowerLevel
Specifies the voltage in 0.1 volt increments.
fSupply
Specifies the voltage source: Vcc, Vpp1, or Vpp2.

Remarks

This structure is declared in the Sockserv.h header file. It supports the implementation of the driver described in the sample PC Card socket driver.
