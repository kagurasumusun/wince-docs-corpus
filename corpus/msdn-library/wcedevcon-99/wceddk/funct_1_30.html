CardReleaseConfiguration

This function places the selected socket and card into a memory-only interface, which is the default mode.

Syntax

STATUS CardReleaseConfiguration(CARD_CLIENT_HANDLE hCardClient CARD_SOCKET_HANDLE hSock);

Parameters

hCardClient
Handle obtained from the CardRegisterClient function.
hSock
Handle to a socket and function pair.

Return Values

CERR_SUCCESS indicates success. One of the following values indicates failure:

CERR_BAD_HANDLE
Indicates that the driver handle specified for hCardClient is invalid.
CERR_BAD_SOCKET
Indicates that the socket identifier specified for hSock is invalid or that a PC Card is not inserted.
CERR_IN_USE
Indicates that the configuration is owned by another driver.
CERR_WRITE_FAILURE
Indicates that this function is unable to write configuration registers.

Remarks

Card Services removes power if no other drivers are using the card.

Driver Name

PCMCIA
