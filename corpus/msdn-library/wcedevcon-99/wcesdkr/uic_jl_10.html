ListView_GetCallbackMask

This macro retrieves the callback mask for a list view control. You can use this macro or send the LVM_GETCALLBACKMASK message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_GETCALLBACKMASK

Syntax

UINT ListView_GetCallbackMask( HWND hwnd );

Parameters

hwnd
Handle to the list view control.

Return Values

Returns the callback mask.
