TabCtrl_AdjustRect

This macro calculates a tab control’s display area Nonzero indicates success. Zero indicates otherwise. a window rectangle, or calculates the window rectangle that would correspond to a specified display area. You can use this macro or send the TCM_ADJUSTRECT message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message:
TCM_ADJUSTRECT

Syntax

void TabCtrl_AdjustRect( HWND hwnd, BOOL fLarger, RECT FAR *prc);

Parameters

hwnd
Handle to the tab control.
fLarger
Boolean value that specifies the operation to perform. If set to TRUE, prc specifies a display rectangle and receives the corresponding window rectangle. If set to FALSE, prc specifies a window rectangle and receives the corresponding display area.
prc
Pointer to a RECT structure that specifies the Nonzero indicates success. Zero indicates otherwise. rectangle and receives the calculated rectangle.

Return Values

None.
