MAKELONG

This macro creates an unsigned 32-bit value by concatenating two specified 16-bit values.

At a Glance

Header file: Windef.h
Windows CE versions: 1.0 and later

Syntax

DWORD MAKELONG( WORD wLow, WORD wHigh );

Parameters

wLow
Specifies the low-order word of the new long value.
wHigh
Specifies the high-order word of the new long value.

Return Values

The return value is an unsigned 32-bit value.

Remarks

The MAKELONG macro is defined as follows: 

#define MAKELONG(a, b) \ 
    ((LONG) (((WORD) (a)) | ((DWORD) ((WORD) (b))) << 16))
