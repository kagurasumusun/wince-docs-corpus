MailOpenNotify

This function attempts to open the mail database and specify a window handle to receive DB_CEOID_* notifications of changes made to the database by different handles.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

BOOL MailOpenNotify (HANDLE * phMail, BOOL fAllowCreate,
HWND hwndNotify);

Parameters

phMail
Out parameter to receive the mail handle. This handle is set even if the function fails, so that the MailError function can be called against the returned handle to obtain the specific error message.
fAllowCreate
If this Boolean is TRUE, the database is created if it does not already exist. If this Boolean is FALSE, the call fails when the specified database cannot be opened.
hwndNotify
Handle to the window that receives DB_CEOID_* notifications when the database is modified by handles other than the one used to open it.

Return Values

TRUE indicates success. FALSE indicates failure.
