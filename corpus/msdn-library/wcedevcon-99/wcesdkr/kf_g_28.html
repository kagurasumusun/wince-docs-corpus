GetProcessHeap

This function obtains a handle to the heap of the calling process. This handle can then be used in calls to the HeapAlloc, HeapReAlloc, HeapFree, and HeapSize functions.

At a Glance

Header file: Winbase.h
Windows CE versions: 1.0 and later

Syntax

HANDLE GetProcessHeap(VOID)

Return Values

A handle to the calling process’s heap indicates success. NULL indicates failure. To get extended error information, call GetLastError.

Remarks

The GetProcessHeap function allows you to allocate memory from the process heap without having to first create a heap with the HeapCreate function, as shown in this example: 

HeapAlloc(GetProcessHeap(), 0, dwBytes);

Note The handle obtained by calling this function should not be used in calls to the HeapDestroy function.
