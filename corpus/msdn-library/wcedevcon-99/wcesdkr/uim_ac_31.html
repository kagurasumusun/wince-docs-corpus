CB_RESETCONTENT

This message is sent by an application to remove all items from the list box and edit control of a combo box.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

CB_RESETCONTENT wParam = 0; lParam = 0;

Return Values

This message always returns CB_OKAY.

Remarks

The Microsoft Platform SDK documentation says this message always returns CB_OKAY (0). This is inaccurate. This message always returns TRUE.

If you create the combo box with an owner-drawn style but without the CBS_HASSTRINGS style, the owner of the combo box receives a WM_DELETEITEM message for each item in the combo box.
