Header_GetItemRect

This macro retrieves the bounding rectangle for a specified item in a header control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related message: HDM_GETITEMRECT

Syntax

BOOL Header_GetItemRect(HWND hwndHD, int iIndex,
LPRECT lpItemRect);

Parameters

hwndHD
Handle to a header control.
iIndex
Zero-based index of the header control item for which to retrieve the bounding rectangle.
lpItemRect
Long pointer to a RECT structure that receives the bounding rectangle information.

Return Values

Nonzero indicates success. Zero indicates otherwise.
