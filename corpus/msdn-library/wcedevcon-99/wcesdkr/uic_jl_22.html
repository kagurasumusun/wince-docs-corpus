ListView_GetItemCount

This macro retrieves the number of items in a list view control. You can use this macro or send the LVM_GETITEMCOUNT message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_GETITEMCOUNT

Syntax

int ListView_GetItemCount( HWND hwnd );

Parameters

hwnd
Handle to the list view control.

Return Values

Returns the number of items.
