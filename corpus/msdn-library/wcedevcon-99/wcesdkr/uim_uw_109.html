WM_WINDOWPOSCHANGED

This message is sent to a window whose size, position, or place in the z-order has changed as a result of a call to the SetWindowPos function or another window-management function.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

WM_WINDOWPOSCHANGED lpwp = (LPWINDOWPOS) lParam;

Parameters

lpwp
Long pointer to a WINDOWPOS structure that contains information about the window’s new size and position.

Return Values

An application should return zero if it processes this message.

Default Action

The DefWindowProc function sends the WM_SIZE and WM_MOVE messages to the window.

Remarks

The WM_SIZE and WM_MOVE messages are not sent if an application handles the WM_WINDOWPOSCHANGED message without calling DefWindowProc. It is more efficient to perform any move or size change processing during the WM_WINDOWPOSCHANGED message without calling DefWindowProc.
