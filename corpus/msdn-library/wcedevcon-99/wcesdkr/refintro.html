Introduction to the Windows CE Reference

The Windows CE Reference contains documentation for all interfaces, functions, structures, messages, and other application programming interface (API) elements for the following released versions of Windows CE:

  • Windows CE version 1.0
  • Windows CE version 1.01
  • Windows CE version 2.0
  • Windows CE version 2.10
  • Windows CE version 2.11
  • Windows CE version 2.12

Unless otherwise noted, all documented API elements are present in version 2.12.

This document contains Release Notes for Windows CE SDK Version 2.11.

Each reference topic includes a table containing the following information:

At a Glance

Header file: Header file where the API element is defined.
Component: Windows CE component that includes this API element.
Platforms: Targeted platforms.
Windows CE versions: Windows CE versions that include this API element.

When there is a link to original documentation, comments in the Remarks section are specific to Windows CE.
