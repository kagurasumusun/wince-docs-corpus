ICreateTypeInfo::SetVarHelpContext

This method sets the Help context identifier for a variable.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

HRESULT SetVarHelpContext( unsigned int index,
unsigned long dwHelpContext );

Parameters

index
Index of the variable described by the type description.
dwHelpContext
Specifies the handle to the Help context identifier for the Help topic on the variable.

Return Values

One of the values described in the following table is returned.

Value
Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_ACCESSDENIED Cannot write to the destination.
TYPE_E_ELEMENTNOTFOUND The element cannot be found.
