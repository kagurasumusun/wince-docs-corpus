ITypeInfo2::GetFuncIndexOfMemId

This method binds to a specific member based on a known dispatch identifier (DISPID)

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

HRESULT GetFuncIndexOfMemId(MEMBERID memid,
INVOKEKIND invKind, unsigned int *pFuncIndex );

Parameters

memid
Member identifier.
invKind
Invoke kind.
pFuncIndex
Returns a pointer to the index to the function.

Return Values

One of the values described in the following table is returned.

Value
Description
S_OK Success.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.

Example

ITypeInfo2::GetFuncIndexOfMemId(
MEMID memid, 
INVOKEKIND invKind, 
UINT * pfuncIndex)
