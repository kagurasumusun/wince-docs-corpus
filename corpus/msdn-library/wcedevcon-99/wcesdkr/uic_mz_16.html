MonthCal_SetMaxSelCount

This macro sets the maximum number of days that can be selected in a month calendar control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related message: MCM_SETMAXSELCOUNT

Syntax

BOOL MonthCal_SetMaxSelCount(HWND hwndMC, UINT iMax);

Parameters

hwndMC
Handle to a month calendar control.
iMax
INT value that will be set to represent the maximum number of selectable days.

Return Values

Nonzero indicates success. Zero indicates otherwise. This macro will fail if applied to a month calendar control that does not use the MCS_MULTISELECT style.
