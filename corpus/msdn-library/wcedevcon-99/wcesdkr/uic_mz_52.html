TabCtrl_HitTest

This macro determines which tab, if any, is at a specified screen position. You can use this macro or send the TCM_HITTEST message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TCM_HITTEST

Syntax

int TabCtrl_HitTest( HWND hwnd, TC_HITTESTINFO FAR *pinfo);

Parameters

hwnd
Handle to the tab control.
pinfo
Pointer to a TCHITTESTINFO structure that specifies the screen position to test.

Return Values

The index of the tab indicates success. –1 indicates that no tab is at the specified position.
