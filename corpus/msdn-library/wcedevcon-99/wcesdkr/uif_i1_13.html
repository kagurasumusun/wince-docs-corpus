ImageList_Duplicate

This function creates a duplicate of an existing image list.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

HIMAGELIST ImageList_Duplicate(HIMAGELIST himl);

Parameters

himl
[in] Handle to the image list to be duplicated. All information contained in the original image list is copied to the new image list.

Return Values

The handle to the new duplicate image list indicates success. NULL indicates failure.

Remarks

The ImageList_Duplicate function is not supported for emulation.
