TreeView_GetFirstVisible

This macro retrieves the first visible item in a tree-view control. You can use this macro, or you can explicitly send the TVM_GETNEXTITEM message with the TVGN_FIRSTVISIBLE flag.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TVM_GETNEXTITEM

Syntax

HTREEITEM TreeView_GetFirstVisible( hwnd);

Parameters

hwndTV
Handle to the tree view control.

Return Values

The handle to the item indicates success. NULL indicates failure.

See Also

TreeView_GetNextVisible, TreeView_GetPrevVisible, TVM_GETITEMRECT
