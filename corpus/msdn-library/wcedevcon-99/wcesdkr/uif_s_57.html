StartDoc

This function starts a print job.

At a Glance

Header file: Wingdi.h
Windows CE versions: 2.0 and later

Syntax

int StartDoc( HDC hdc, CONST DOCINFO * lpdi);

Parameters

hdc
[in] Handle to the device context (DC) for the print job.
lpdi
[in] Long pointer to a DOCINFO structure that contains the name of the document file and the name of the output file.

Return Values

A value greater than zero indicates success. This value is the print job identifier for the document. A value less than or equal to zero indicates failure. To get extended error information, call GetLastError.

Remarks

Applications should call the StartDoc function immediately before beginning a print job. Using this function ensures that multipage documents are not interspersed with other print jobs.

Windows CE does not support printing to files. It ignores the lpszOutput member of the DOCINFO structure.
