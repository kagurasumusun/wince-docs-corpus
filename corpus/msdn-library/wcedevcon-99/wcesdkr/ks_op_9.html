PARAMDESC

This structure is used for holding information for transferring a structure element, parameter, or function return value between processes.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

typedef struct FARSTRUCT tagPARAMDESC {
unsigned long lpVarValue;
unsigned short wParamFlags;
};
} PARAMDESC;

The lpVarValue member contains a pointer to a VARIANT that describes the default value for this parameter, if the PARAMFLAG_FOPT and PARAMFLAG_FHASDEFAULT bit of wParamFlags is set.l.
