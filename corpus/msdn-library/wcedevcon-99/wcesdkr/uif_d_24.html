DrawMenuBar

This function redraws the menu bar part of the command bar the specified window’s command bar. If the menu bar changes after Windows CE has created the window, this function must be called to draw the changed menu bar.

At a Glance

Header file: Winuser.h
Windows CE versions: 2.0 and later

Syntax

BOOL DrawMenuBar( HWND hWnd);

Parameters

hWnd
[in] Handle to the window whose menu bar needs redrawing.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.
