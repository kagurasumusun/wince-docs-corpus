STORE_INFORMATION

This structure contains the size of the object store and the amount of free space currently in the object store.

At a Glance

Header file: Winbase.h
Windows CE versions: 1.0 and later

Syntax

typedef struct STORE_INFORMATION {
DWORD dwStoreSize;
DWORD dwFreeSize;
} STORE_INFORMATION, *LPSTORE_INFORMATION;

Members

dwStoreSize
Specifies the size, in bytes, of the object store.
dwFreeSize

Specifies the amount of free space, in bytes, in the object store.
