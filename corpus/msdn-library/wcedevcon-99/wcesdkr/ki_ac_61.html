ICreateTypeInfo2::SetName

This method sets the name of the typeinfo.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

HRESULT SetName( OLECHAR FAR* szName );

Parameters

szName
NULL-terminated string that contains the name to be assigned to the typeinfo.

Return Values

One of the values described in the following table is returned.

Value
Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.
TYPE_E_INVALIDSTATE The state of the typeinfo is not valid for this operation.
