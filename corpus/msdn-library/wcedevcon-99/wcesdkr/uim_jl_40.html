LBN_SELCANCEL

This notification message is sent by an application when the user cancels the selection in a list box. The parent window of the list box receives this notification message through the WM_COMMAND message.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

LBN_SELCANCEL idListBox = (int)LOWORD(wParam);
hwndListBox = (HWND) lParam;

Parameters

idListBox
Identifier of the list box.
hwndListBox
Handle to the list box.

Remarks

This notification message applies only to list boxes of the LBS_NOTIFY style.

See Also

LBN_DBLCLK, LBN_SELCHANGE, LB_SETCURSEL, WM_COMMAND
