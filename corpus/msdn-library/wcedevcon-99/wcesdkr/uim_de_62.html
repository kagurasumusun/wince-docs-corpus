EN_HSCROLL

This notification message is sent when the user clicks an edit control’s horizontal scroll bar. The parent window of the edit control receives this notification message through the WM_COMMAND message. The parent window is notified before the screen is updated.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

EN_HSCROLL idEditCtrl = (int) LOWORD (wParam);
hwndEditCtrl = (HWND) lParam;

Parameters

idEditCtrl
Identifier of the edit control.
hwndEditCtrl
Handle to the edit control.

See Also

EN_VSCROLL, WM_COMMAND
