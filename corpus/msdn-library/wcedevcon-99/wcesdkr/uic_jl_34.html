ListView_GetTextBkColor

This macro retrieves the text background color of a list view control. You can use this macro or send the LVM_GETTEXTBKCOLOR message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_GETTEXTBKCOLOR

Syntax

COLORREF ListView_GetTextBkColor( HWND hwnd );

Parameters

hwnd
Handle to the list view control.

Return Values

Returns the background color of the text.
