ListView_GetSelectedCount

This macro determines the number of selected items in a list view control. You can use this macro or send the LVM_GETSELECTEDCOUNT message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_GETSELECTEDCOUNT

Syntax

UINT ListView_GetSelectedCount( HWND hwnd );

Parameters

hwnd
Handle to the list view control.

Return Values

Returns the number of selected items.
