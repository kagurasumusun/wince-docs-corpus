TabCtrl_SetExtendedStyle

This macro sets the extended styles that the tab control will use.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related message: TCM_SETEXTENDEDSTYLE

Syntax

DWORD TabCtrl_SetExtendedStyle(WND hwndTab, DWORD dwExStyle);

Parameters

hwndTab
Handle to the tab control.
dwExStyle
Contains the new tab control extended styles. It is a combination of tab control extended styles.

Return Values

DWORD that contains the previous tab control extended styles.
