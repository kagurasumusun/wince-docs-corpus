IMN_SETSENTENCEMODE

This message is sent when the sentence mode of the input context is updated. The application receives this notification message through the WM_IME_NOTIFY message.

At a Glance

Header file: Imm.h
Windows CE versions: 2.1 and later (Japanese version 1.0 and later)

Return Values

None

Remarks

The application can get data about the sentence mode by using the ImmGetConversionStatus function.

See Also

ImmGetConversionStatus, WM_IME_NOTIFY
