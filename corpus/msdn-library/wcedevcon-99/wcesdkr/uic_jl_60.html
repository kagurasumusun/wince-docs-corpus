ListView_SetTextColor

This macro sets the text color of a list view control. You can use this macro or send the LVM_SETTEXTCOLOR message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_SETTEXTCOLOR

Syntax

BOOL ListView_SetTextColor( HWND hwnd, COLORREF clrText );

Parameters

hwnd
Handle to the list view control.
clrText
New text color.

Return Values

TRUE indicates success. FALSE indicates failure.
