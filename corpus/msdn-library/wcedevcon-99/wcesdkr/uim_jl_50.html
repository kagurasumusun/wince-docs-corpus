LVM_ENSUREVISIBLE

This message ensures that a list view item is entirely or at least partially visible, scrolling the list view control if necessary. You can send this message explicitly or by using the ListView_EnsureVisible macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: ListView_EnsureVisible

Syntax

LVM_ENSUREVISIBLE wParam = (WPARAM)(int) iItem;
lParam = (LPARAM)(BOOL) fPartialOk;

Parameters

i
Index of the list view item.
fPartialOK
Boolean that specifies whether the item must be entirely visible. If set to TRUE, no scrolling occurs if the item is at least partially visible.

Return Values

TRUE indicates success. FALSE indicates failure.
