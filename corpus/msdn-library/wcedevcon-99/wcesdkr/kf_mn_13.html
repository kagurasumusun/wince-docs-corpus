MailGetSvcId

This function retrieves the object identifier of a mail entry from the message store based on the value of the service identifier.

At a Glance

Header file: Msgstore.h
Windows CE versions: 1.0 and later

Syntax

BOOL MailGetSvcId (HANDLE hMail, MailMsg* pmm);

Parameters

hMail
Handle to the mail context. This handle is created by the MailOpen function.
pmm
Pointer to the MailMsg structure that contains the service name and identifier being passed in when calling MailGetSvcId. After calling MailGetSvcId, the object identifier (the oid member) and associated flags (the dwFlags member) are passed back in this structure when MailGetSvcId completes successfully.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call MailError or MailErrorMsg.
