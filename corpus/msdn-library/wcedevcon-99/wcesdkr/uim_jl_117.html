LVN_KEYDOWN

This notification message notifies a list view control parent window that a key has been pressed. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

LVN_KEYDOWN pnkd = (LV_KEYDOWN FAR *) lParam;

Parameters

pnkd
Pointer to an NMLVKEYDOWN structure.

Return Values

None

See Also

LV_KEYDOWN, WM_KEYDOWN, WM_KEYUP
