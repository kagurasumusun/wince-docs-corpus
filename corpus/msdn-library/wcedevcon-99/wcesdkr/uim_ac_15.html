CB_GETCURSEL

This message is sent by an application to retrieve the index of the currently selected item, if any, in the list box of a combo box.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

CB_GETCURSEL wParam = 0; lParam = 0;

Return Values

The zero-based index of the currently selected item indicates success. CB_ERR indicates that no item is selected.

See Also

CB_SELECTSTRING, CB_SETCURSEL
