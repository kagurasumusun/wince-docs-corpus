CB_GETLBTEXT

This message is sent by an application to retrieve a string from the list of a combo box.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

CB_GETLBTEXT wParam = (WPARAM) index;
lParam = (LPARAM)(LPCSTR) lpszBuffer;

Parameters

index
Specifies the zero-based index of the string to retrieve.
lpszBuffer
Long pointer to the buffer that receives the string. The buffer must have sufficient space for the string and a terminating null character. You can send a CB_GETLBTEXTLEN message prior to the CB_GETLBTEXT message to retrieve the length, in bytes, of the string.

Return Values

The length of the string, in bytes and excluding the terminating null character, indicates success. CB_ERR indicates that the index parameter does not specify a valid index.

Remarks

If you create the combo box with an owner-drawn style but without the CBS_HASSTRINGS style, the buffer pointed to by the lpszBuffer parameter of the message receives the 32-bit value associated with the item (the item data).
