UpdateWindow

This function updates the client area of the specified window by sending a WM_PAINT message to the window if the window’s update region is not empty. UpdateWindow sends a WM_PAINT message directly to the window procedure of the specified window, bypassing the application queue. If the update region is empty, no message is sent.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

BOOL UpdateWindow( HWND hWnd);

Parameters

hWnd
Handle to the window to be updated.

Return Values

Nonzero indicates success. Zero indicates failure.

Windows NT: To get extended error information, call GetLastError.
