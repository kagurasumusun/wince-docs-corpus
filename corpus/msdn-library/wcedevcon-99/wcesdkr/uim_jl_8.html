LB_GETHORIZONTALEXTENT

This message is sent by an application to retrieve from a list box the width, in pixels, by which the list box can be scrolled horizontally—the scrollable width—if the list box has a horizontal scroll bar.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

LB_GETHORIZONTALEXTENT wParam = 0; lParam = 0;

Return Values

The scrollable width, in pixels, of the list box indicates success.

Remarks

To respond to the LB_GETHORIZONTALEXTENT message, the list box must have been defined with the WS_HSCROLL style.
