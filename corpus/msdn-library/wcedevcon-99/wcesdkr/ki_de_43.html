IErrorInfo::GetHelpFile

This method returns the path of the Help file that describes the error.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

HRESULT GetHelpFile( BSTR *pBstrHelpFile );

Parameters

pBstrHelpFile
Pointer to a Unicode string that contains the fully qualified path of the Help file.

Return Values

S_OK indicates success.

Comments

IErrorInfo::GetHelpFile returns the fully qualified path of the Help file that describes the current error. IErrorInfo::GetHelpContext should be used to find the Help context identifier for the error in the Help file.
