DTM_SETMCFONT

This message sets the font to be used by the date and time picker (DTP) control’s child month calendar control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related macro: DateTime_SetMonthCalFont

Syntax

DTM_SETMCFONT wParam = (WPARAM)(HFONT) hFont;
lParam = (LPARAM) MAKELONG(fRedraw, 0);

Parameters

hFont
Handle to the font to be set.
fRedraw
Boolean that specifies whether the control should be redrawn immediately upon setting the font. Setting this parameter to TRUE causes the control to redraw itself.

Return Values

The return value for this message is not used.
