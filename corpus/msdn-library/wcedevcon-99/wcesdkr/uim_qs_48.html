STN_CLICKED

This notification message is sent when the user clicks a static control that has the SS_NOTIFY style. The parent window of the control receives this notification message through the WM_COMMAND message.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

STN_CLICKED idStatic = (int) LOWORD(wParam);
hwndStatic = (HWND) LOWORD(lParam);

Parameters

idStatic
Identifier of the static control.
hwndStatic
Handle to the static control.
