CONTEXT

This structure contains processor-specific register data. Currently there are CONTEXT structures defined for Intel, MIPS, Alpha, SHx, ARM, and PowerPC processors. Refer to the WinNT.h header file for definitions of these structures.

At a Glance

Header file: Winbase.h
Windows CE versions: 2.0 and later

Remarks

Windows CE defines an additional CONTEXT structure for SHx and ARM processors which is also found in the WinNT.h header file.
