PSM_RESTARTWINDOWS

This message indicates that Windows needs to be restarted for the changes to take effect. An application should send this message only in response to the PSN_APPLY or PSN_KILLACTIVE notification message. You can send the PSM_RESTARTWINDOWS message explicitly or by using the PropSheet_RestartWindows macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: PropSheet_RestartWindows

Syntax

PSM_RESTARTWINDOWS wParam = 0; lParam = 0;

Return Values

None.

See Also

PSM_REBOOTSYSTEM, PSN_APPLY, PSN_KILLACTIVE, PropertySheet
