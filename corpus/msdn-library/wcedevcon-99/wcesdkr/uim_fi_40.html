IMC_SETSENTENCEMODE

This message is sent by an application to an IME window to set the current sentence mode.

At a Glance

Header file: Imm.h
Windows CE versions: 2.1 and later

Syntax

msg = (UINT) WM_IME_CONTROL;
wParam = (WPARAM) IMC_SETSENTENCEMODE;
lParam = 0;

Parameters

lParam
IME sentence mode value.

Return Values

Zero indicates success. Nonzero indicates failure.
