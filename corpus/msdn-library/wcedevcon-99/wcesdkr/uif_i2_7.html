ImmDisableIME

This function disables the input method editor (IME) for a thread or all threads in a process.

At a Glance

Header file: Imm.h
Windows CE versions: 2.10 and later

Syntax

BOOL ImmDisableIME( DWORD idThread );

Parameters

idThread
[in] Identifier of the thread for which the IME is disabled. If idThread is zero, the IME for the current thread is disabled. If idThread is –1, the IME is disabled for all threads in the current process. For Windows CE versions 2.10 and later, passing a –1 value for the idThread parameter is not supported.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

The application must call this function before the first top-level window in the thread receives the WM_CREATE message. This means the application must call this function before calling CreateWindow to create the first top-level window.
