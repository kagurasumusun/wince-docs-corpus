SetViewportOrgEx

This function sets the viewpoint origin of a device context to the specified coordinates.

At a Glance

Header file: Wingdi.h
Windows CE versions: 1.0 and later

Syntax

SetViewportOrgEx(HDC hdc, int X, int Y, LPPOINT lpPoint);

Parameters

hdc
[in] Handle to the device context.
X
[in] Specifies the x-coordinate, in device units, of the new viewport origin.
Y
[in] Specifies the y-coordinate, in device units, of the new viewport origin.
lpPoint
[in] Long pointer to a POINT structure. The previous viewport origin (in device coordinates) is placed in this structure. If lpPoint is NULL, nothing is returned.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.
