Workarounds

Determining the Buffer Size for Receiving a Phone Book Entry Using the RasGetEntryProperties Function

The RasGetEntryProperties function fails with a return value of ERROR_BUFFER_TOO_SMALL when the application sets the lpdwDeviceInfoSize and lpbDeviceInfo parameters to NULL to determine the required buffer size. This is the documented behavior.

To determine the required buffer size, call RasGetEntryProperties with lpbDeviceInfo set to NULL and lpdwDeviceInfoSize set to zero. The function returns the required buffer size in lpdwDeviceInfoSize.

The correct required buffer size is returned if lpDeviceInfo points to a big enough buffer. Unimodem currently requires 128 bytes.

Specifying the Default Install Directory of an Application

The device-side default install directory for an application is specified in the Cab Wizard Win32 Setup information (.inf) file. If the path to the default install directory contains more than one subdirectory from an existing directory, then the intermediate subdirectories are stripped out of the install directory.

For example, given the following existing directory and default install directory, Cab Wizard installs an application in the \Program Files\MyApp directory.

Existing directory: \Program Files
Default install directory: \Program Files\Microsoft\MyApp
Directory displayed to user: \Program Files\MyApp

To avoid this problem, do not include intermediate subdirectories, in this case \Microsoft, when specifying the device-side default install directory.
