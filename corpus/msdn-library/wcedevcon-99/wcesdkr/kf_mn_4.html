MailErrorMsg

This function retrieves the last occurrence of a mail error condition, fills a text string with a description of the error, and sets a pointer to the line number where the error occurred.

At a Glance

Header file: Msgstore.h
Windows CE versions: 1.0 and later

Syntax

int MailErrorMsg (HANDLE hMail , LPWSTR szBuffer, int iBuffLen,
int* piSrcLine);

Parameters

hMail
Handle to the mail context. This handle is created by the MailOpen function.
szBuffer
Pointer to a wide character string array that contains a description of the error condition issued by the last called mail function.
iBufferLen
Length, in characters, of the string array receiving the error description.
piSrcLine
Pointer to an integer that contains the line number where the error occurred. If no errors are encountered, the value pointed to by this parameter is set to NULL.

Return Values

The value of the last error code as an integer indicates success.

Remarks

The MailErrorMsg function operates with the same behavior as the MailError function with the exception of the additional information it provides.
