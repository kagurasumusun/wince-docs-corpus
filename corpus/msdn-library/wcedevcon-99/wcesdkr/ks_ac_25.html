CONTROLINFO

This structure contains parameters that describe a control’s keyboard mnemonics and keyboard behavior.

At a Glance

Header file: Ocidl.h
Windows CE versions: 2.0 and later

Syntax

typedef struct tagCONTROLINFO
{
ULONG cb;
HACCEL hAccel;
USHORT cAccel;
DWORD dwFlags;
} CONTROLINFO;

Members

cb
Size of the CONTROLINFO structure.
hAccel
Handle to an array of Windows ACCEL structures, each structure describing a keyboard mnemonic. The array is allocated with the GlobalAlloc function. The control always maintains the memory for this array; the caller of IOleControl::GetControlInfo should not attempt to free the memory.
cAccel
Number of mnemonics described in the hAccel member. This value can be zero to indicate no mnemonics.
dwFlags
Specifies the keyboard behavior of the control. It is one of the following values:
Value
Description
CTRLINFO_EATS_RETURN When the control has the focus, it will process the RETURN key.
CTRLINFO_EATS_ESCAPE When the control has the focus, it will process the ESCAPE key.
  When the control has the focus, the dialog box containing the control cannot use the RETURN or ESCAPE keys as mnemonics for the default and cancel buttons.
