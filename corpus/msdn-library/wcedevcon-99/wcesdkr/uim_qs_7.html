RB_GETRECT

This message retrieves the bounding rectangle for a specified band in a rebar control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

RB_GETRECT wParam = (WPARAM)(INT) iBand;
lParam = (LPARAM)(LPRECT) lprc;

Parameters

iBand
Zero-based index of a band in the rebar control.
lprc
Long pointer to a RECT structure that receives the bounds of the rebar band.

Return Values

Nonzero indicates success. Zero indicates otherwise.
