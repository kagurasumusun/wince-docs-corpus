TVM_ENSUREVISIBLE

This message ensures that a tree view item is visible, expanding the parent item or scrolling the tree view control, if necessary. You can send this message explicitly or by using the TreeView_EnsureVisible macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: TreeView_EnsureVisible

Syntax

TVM_ENSUREVISIBLE wParam = 0;
lParam = (LPARAM)(HTREEITEM) hitem;

Parameters

hitem
Handle to the item.

Return Values

Nonzero indicates that the system scrolled the items in the tree view control and no items were expanded. Zero indicates otherwise.

See Also

TVN_ITEMEXPANDED, TVN_ITEMEXPANDING
