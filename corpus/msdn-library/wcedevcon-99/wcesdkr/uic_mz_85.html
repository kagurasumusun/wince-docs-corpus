TreeView_GetPrevSibling

This macro retrieves the previous sibling item of a specified item in a tree-view control. You can use this macro, or you can explicitly send the TVM_GETNEXTITEM message with the TVGN_PREVIOUS flag.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TVM_GETNEXTITEM

Syntax

HTREEITEM TreeView_GetPrevSibling( hwnd, hitem);

Parameters

hwndTV
Handle to the tree view control.
hitem
Handle to an item.

Return Values

The handle to the item indicates success. NULL indicates failure.
