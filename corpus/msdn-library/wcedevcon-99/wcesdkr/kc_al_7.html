GetRValue

This macro retrieves an intensity value for the red component of a 32-bit red, green, blue (RGB) value.

At a Glance

Header file: Wingdi.h
Windows CE versions: 1.0 and later

Syntax

BYTE GetRValue( DWORD rgb );

Parameters

rgb
Specifies an RGB color value.

Return Values

The return value is the intensity of the red component of the specified RGB color.

Remarks

The intensity value is in the range 0 through 255.

The GetRValue macro is defined as follows: 

#define GetRValue(rgb)   ((BYTE) (rgb))
