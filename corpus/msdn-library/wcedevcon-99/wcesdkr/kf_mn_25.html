MailUpdate

This function replaces an entry in the message store with updated information.

At a Glance

Header file: Msgstore.h
Windows CE versions: 1.0 and later

Syntax

BOOL MailUpdate (HANDLE hMail, MailMsg* pmm, BOOL fDoAll);

Parameters

hMail
Handle to the mail context. This handle is created by the MailOpen function.
pmm
Pointer to the MailMsg structure that contains the mail entry with the updated information.
fDoAll
If this Boolean is TRUE, all members of the MailMsg structure are updated. If this Boolean is set to FALSE, only the flags are changed—that is, the dwFlags member in the MailMsg structure pointed to by pmm.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call MailError or MailErrorMsg.

Remarks

The entry being updated is based on the oid member of the MailMsg structure. If the entry does not exist in the database, the MailUpdate function fails.
