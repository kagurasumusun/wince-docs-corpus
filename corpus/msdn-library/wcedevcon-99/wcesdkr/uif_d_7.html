DestroyAcceleratorTable

This function destroys an accelerator table. Before an application closes, it must use this function to destroy each accelerator table that it created by using the CreateAcceleratorTable function.

At a Glance

Header file: Winuser.h
Versions: 1.0 and later

Syntax

BOOL DestroyAcceleratorTable(HACCEL hAccel);

Parameters

hAccel
Handle to the accelerator table to destroy. This handle must have been created by a call to the CreateAcceleratorTable function.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.
