TCN_KEYDOWN

This notification message notifies a tab control’s parent window that a key has been pressed. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

TCN_KEYDOWN pnm = (TC_KEYDOWN FAR *) lParam;

Parameters

pnm
Pointer to an NMTCKEYDOWN structure.

Return Value

None.

See Also

TC_KEYDOWN, WM_NOTIFY
