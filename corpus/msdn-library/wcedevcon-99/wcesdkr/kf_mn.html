MailClose

This function releases the handle to the current mail context.

At a Glance

Header file: Msgstore.h
Windows CE versions: 1.0 and later

Syntax

BOOL MailClose (HANDLE hMail);

Parameters

hMail
Handle to the mail context to be released. This handle is created by the MailOpen function.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call MailError or MailErrorMsg.
