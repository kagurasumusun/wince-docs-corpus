PSM_REBOOTSYSTEM

This message indicates that system needs to be restarted for the changes to take effect. An application should send this message only in response to the PSN_APPLY or PSN_KILLACTIVE notification message. You can send the PSM_REBOOTSYSTEM message explicitly or by using the PropSheet_RebootSystem macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: PropSheet_RebootSystem

Syntax

PSM_REBOOTSYSTEM wParam = 0; lParam = 0;

Return Values

None.

Remarks

This message causes the PropertySheet function to return the ID_PSREBOOTSYSTEM value, but only if the user clicks the OK button to close the property sheet.
