MailAtt

This structure is used to describe a single attachment to a mail message.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

typedef struct MailAtt_s {
UINT uiAttachmentNumber;
DWORD dwFlags;
ULONG ulCharacterPosition;
ULONG ulSize;
LPWSTR szOriginalName;
LPWSTR szLocalName;
} MailAtt, *lpMailAtt;

Members

uiAttachmentNumber
Number, counting from 1, to indicate which attachment is specified.
dwFlags
This member has three bit-masks to categorize three groups of the mail attachment flags: *_ALL_*, *_THIS_*, and *_NUMBER_*.
Value
Description
ATT_ALL_FLAGS_MASK For flags that apply to all attachments to the message. Currently, no such flags are defined in this category.
ATT_THIS_FLAGS_MASK For flags that apply only to a specified attachment. The following table shows the two flags that are currently defined in the category.
ATT_DISP_RETRIEVE User has requested to download the non-local attachment to the message. Set only if ATT_DOWNLOADABLE is set.
ATT_DOWNLOADABLE The originating transport is capable of downloading the attachment independently.
ATT_NUMBER_MASK For number masks used to mark the number of attachment files (or headers) to the mail message. Currently, no number mask is defined.

ulCharacterPosition
Character position of the attachment in the text portion of the message. Not currently supported.
ulSize
Size of the attached file. For MailPutAttachment it must be specified for a non-local attachment when szLocalName is NULL. For MailgetAttachment it is assigned to the size of the attached file for either a local or a non-local attachment.
szOriginalName
Null-terminated string that contains the name of the original file of attached to the message, without path information.
szLocalName
Null-terminated string that contains the path name of the attached file on a Windows CE device. It must be set to NULL for a nonlocal attachment.

Remarks

From the user point of view, an attachment is the file (szOriginalName) attached to the message. For an application developer, however, the attachment may be conveniently viewed as consisting of a header and the attached file. The header is the MailAtt data structure itself. The original file name does not contain path information.

An application developer may want to work with either local or non-local attachments. A local attachment has a header and a copy (szLocalName) of the original file (szOriginalName) stored on a Windows CE device. A nonlocal attachment does not store the attached file locally and is simply a place-holder for the original file. For a non-local attachment, szLocalName must be set NULL and ulSize specified.

Nonlocal attachments are possible only when a message is linked to a service. For some services, an attachment header can be used to make the file local on demand.
