TBM_GETPAGESIZE

This message retrieves the size of the page for a trackbar. The page size affects how much the slider moves for the TB_PAGEUP and TB_PAGEDOWN notification messages.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

TBM_GETPAGESIZE wParam = 0; lParam = 0;

Return Values

Returns a 32-bit value that specifies the page size for the trackbar.

Remarks

The trackbar also sends the TB_PAGEUP and TB_PAGEDOWN notification messages to its parent window when it receives keyboard or mouse input that scrolls the page.
