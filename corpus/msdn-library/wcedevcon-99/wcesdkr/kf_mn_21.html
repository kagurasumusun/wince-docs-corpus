MailPutFolder

This function is used to add, delete, or rename mail folders.

At a Glance

Header file: Msgstore.h
Windows CE versions: 1.0 and later

Syntax

BOOL MailPutFolder (HANDLE hMail, BYTE bId, LPWSTR szName);

Parameters

hMail
Handle to the mail context. This handle is created by the MailOpen function.
bId
Unique integer from zero to 255 that identifies the mail folder. Since a system folder cannot be modified or deleted, this cannot be one of the following identifiers: MAIL_FOLDER_INBOX; MAIL_FOLDER_OUTBOX; MAIL_FOLDER_SENT.
szName
Pointer to a buffer that contains a null-terminated string that identifies the name of the mail folder. If this parameter is NULL, then the folder identified by bId is deleted.

Return Values

TRUE indicates success. FALSE indicates failure. To get extended error information, call MailError or MailErrorMsg.

Remarks

If the bId parameter identifies a folder that already exists in the message store the MailPutFolder function renames the folder to the szName string. If the folder exists and szName is NULL the folder is deleted. If the bId identifier is not found in the database, a folder is created with the name pointed to by the szName parameter.

MailGetFolderName, MailGetFolderId
