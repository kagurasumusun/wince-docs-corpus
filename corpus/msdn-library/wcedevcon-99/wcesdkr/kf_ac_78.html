CeRegDeleteValue (RAPI)

This function removes a named value from the specified registry key. CeRegDeleteValue is a remote application interface, which enables an application running on a desktop computer to make function calls on a Windows CE–based device.

At a Glance

Header file: Rapi.h
Windows CE versions: 2.0 and later

Syntax

LONG CeRegDeleteValue( HKEY hKey, LPCWSTR lpszValueName );

Parameters

hKey
[in] Handle to a currently open key or any of the following predefined reserved handle values:
  • HKEY_CLASSES_ROOT
  • HKEY_CURRENT_USER
  • HKEY_LOCAL_MACHINE
  • HKEY_USERS
lpValueName
[in] Pointer to a null-terminated string that names the value to remove. If this parameter is NULL or points to an empty string, the default value of the key is removed. A default value is create by calling CeRegCreateValueEx with a NULL or empty string value name.

Return Values

ERROR_SUCCESS indicates success. A nonzero error code defined in Winerror.h indicates failure. To get a generic description of the error, call FormatMessage with the FORMAT_MESSAGE_FROM_SYSTEM flag set.

Remarks

The key identified by the hKey parameter must have been opened with KEY_SET_VALUE access (KEY_WRITE access includes KEY_SET_VALUE access).
