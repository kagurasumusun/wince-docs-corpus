TBM_SETTHUMBLENGTH

This message sets the length of the slider in a trackbar. This message is ignored if the trackbar does not have the TBS_FIXEDLENGTH style.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

TBM_SETTHUMBLENGTH wParam = (WPARAM)(UINT) iLength;
lParam = 0;

Parameters

iLength
Length, in pixels, of the slider.

Return Values

None.
