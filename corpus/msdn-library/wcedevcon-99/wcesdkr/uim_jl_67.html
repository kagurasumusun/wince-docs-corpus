LVM_GETITEMSPACING

This message determines the spacing between items in a list view control. You can send this message explicitly or by using the ListView_GetItemSpacing macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: ListView_GetItemSpacing

Syntax

LVM_GETITEMSPACING wParam = (WPARAM)(BOOL) fSmall;
lParam = 0;

Parameters

fSmall
Boolean that specifies the view for which to retrieve the item spacing. Set to TRUE for small icon view, or to FALSE for icon view.

Return Values

Returns the amount of spacing between items. The horizontal spacing is contained in the low-order word and the vertical spacing is contained in the high-order word.
