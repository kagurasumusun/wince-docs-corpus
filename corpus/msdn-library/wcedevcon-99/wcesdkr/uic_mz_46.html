TabCtrl_GetImageList

This macro retrieves the image list associated with a tab control. You can use this macro or send the TCM_GETIMAGELIST message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TCM_GETIMAGELIST

Syntax

HIMAGELIST TabCtrl_GetImageList( HWND hwnd );

Parameters

hwnd
Handle to the tab control.

Return Values

The handle to the image list indicates success. NULL indicates failure.
