RB_SETPARENT

This message sets a rebar control’s parent window.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

RB_SETPARENT wParam = (WPARAM)(HWND) hwndParent; lParam = 0;

Parameters

hwndParent
Handle to the parent window to be set.

Return Values

Returns the handle to the previous parent window, or NULL if there is no previous parent.

Remarks

The rebar control sends notification messages to the window you specify with this message. This message does not change the actual parent that was set when the control was created.
