IMC_CLOSESTATUSWINDOW

This message is sent by an application to the input method editor (IME) window to hide the status window.

At a Glance

Header file: Imm.h
Windows CE versions: 2.1 and later

Syntax

msg = (UINT) WM_IME_CONTROL;
wParam = (WPARAM) IMC_CLOSESTATUSWINDOW;
lParam = (LPARAM) 0;

Return Values

Zero indicates success. Nonzero indicates failure.

Remarks

When the status window of IME is hidden, this message does nothing. Although an application may send this message to the IME window, the application does not receive the corresponding IMN_CLOSESTATUSWINDOW message.
