UDM_SETBASE

This message sets the radix base for an up-down control. The base value determines whether the buddy window displays numbers in decimal or hexadecimal digits. Hexadecimal numbers are always unsigned, and decimal numbers are signed.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

UDM_SETBASE wParam = (WPARAM) nBase; lParam = 0;

Parameters

nBase
New base value for the control. This parameter can be 10 for decimal or 16 for hexadecimal.

Return Values

The previous base value indicates success. Zero indicates that an invalid base was given.
