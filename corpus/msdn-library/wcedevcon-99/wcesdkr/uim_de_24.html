DTN_FORMAT

This notification message is sent by a date and time picker (DTP) control to request text to be displayed in a callback field. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

DTN_FORMAT lpNMFormat = (LPNMDATETIMEFORMAT) lParam;

Parameters

lpNMFormat
Long pointer to an NMDATETIMEFORMAT structure that contains information regarding this instance of the notification message. The structure contains the substring that defines the callback field and receives the formatted string that the control will display.

Remarks

Handling this message allows the owner of the control to provide a custom string that the control will display. For additional information about callback fields, see Callback Fields.

Return Values

The owner of the control must return zero.
