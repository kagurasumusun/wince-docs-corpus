EXIT_PROCESS_DEBUG_INFO

Windows CE versions: 2.0 and later

Syntax

typedef struct _EXIT_PROCESS_DEBUG_INFO {
DWORD dwExitCode;
} EXIT_PROCESS_DEBUG_INFO;
