MailNonIpmInfo

This structure is used internally by transports to describe non-Interpersonal Message (IPM) data on a message.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

typedef struct MailNonIpmInfo_s {
LPWSTR szMessageClass;
UINT uiPropcount;
CEPROPVAL propArray[];
} MailNonIpmInfo, *lpMailNonIpmInfo;

Members

szMessageClass
Null-terminated string that contains the header “Type” of the non-IPM message.
uiPropCount
Count of non-IPM properties in the following propArray.
propArray
Array of CEPROPVAL structures. The uiPropCount member specifies the number of the elements in the array.
