MailAttArray

This structure is used to describe a series of mail attachments.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

typedef struct MailAttArray_s {
DWORD dwFlags;
UINT uiAttCount;
lpMailAtt AttArray[];
} MailAttArray, *lpMailAttArray;

Members

dwFlags
Specifies a bitmask of flags that apply to all of the attachments. Flags not in the ATT_ALL_FALGS_MASK area are ignored. Currently, no valid flags are supported.
uiAttCount
Count of attachments in the following AttArray.
AttArray
Array of MailAtt structures. The uiAttCount member specifies the number of the elements in the array.
