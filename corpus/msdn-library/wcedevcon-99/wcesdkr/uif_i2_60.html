IsChild

This function tests whether a window is a child window or descendant window of a specified parent window. A child window is the direct descendant of a specified parent window if that parent window is in the chain of parent windows; the chain of parent windows leads from the original overlapped or pop-up window to the child window.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

BOOL IsChild( HWND hWndParent, HWND hWnd);

Parameters

hWndParent
Handle to the parent window.
hWnd
Handle to the window to be tested.

Return Values

Nonzero indicates that the window is a child or descendant window of the specified parent window. Zero indicates that the window is not a child or descendant window of the specified parent window.
