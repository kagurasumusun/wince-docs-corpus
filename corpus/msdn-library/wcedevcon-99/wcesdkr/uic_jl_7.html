ListView_EnsureVisible

This macro ensures that a list view item is either entirely or partially visible, scrolling the list view control if necessary. You can use this macro or send the LVM_ENSUREVISIBLE message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_ENSUREVISIBLE

Syntax

BOOL ListView_EnsureVisible( HWND hwnd, int i, BOOL fPartialOK );

Parameters

hwnd
Handle to the list view control.
i
Index of the list view item.
fPartialOK
Boolean value that specifies whether the item must be entirely visible. If set to TRUE, no scrolling occurs if the item is at least partially visible.

Return Values

TRUE indicates success. FALSE indicates failure.
