TreeView_EditLabel

This macro begins in-place editing of the specified item’s text, replacing the text of the item with a single-line edit control containing the text. This macro implicitly selects and focuses the specified item. You can use this macro or send the TVM_EDITLABEL message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TVM_EDITLABEL

Syntax

HWND TreeView_EditLabel( hwnd, hitem);

Parameters

hwndTV
Handle to the tree view control.
hitem
Handle to the item to edit.

Return Values

The handle to the edit control used to edit the item text indicates success. NULL indicates failure.

Remarks

This macro sends a TVN_BEGINLABELEDIT notification message to the parent of the tree view control.

When the user completes or cancels editing, the edit control is destroyed and the handle is no longer valid. You can safely subclass the edit control, but do not destroy it.

The control must have the focus before you call this macro. Focus can be set using the SetFocus function.
