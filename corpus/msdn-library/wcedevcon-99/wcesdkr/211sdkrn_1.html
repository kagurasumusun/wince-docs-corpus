Known Issues

Long Device Names for PCMCIA Modems

The dwDeviceName field in the RASENTRY and RASCONNSTATUS structures is limited to 32 characters plus a trailing null character. However, the friendly names of several PCMCIA modems are longer than 32 characters. This could potentially cause problems if a modem was swapped for a different one by the same manufacturer with a similar name.

The WM_GETFONT Message Fails for Some Dialog Boxes

The WM_GETFONT message does not return the font handle used by dialog boxes that are created with one of the following functions:

DialogBox CreateDialog
DialogBoxParam CreateDialogParam
DialogBoxIndirectParam CreateDialogIndirectParam

Remote Access Server (RAS) Callback Functions

After calling the RasDial function, a call is dialed and eventually connects. However, progress notification messages are not received by the window that the lpvNotifier parameter points to.
