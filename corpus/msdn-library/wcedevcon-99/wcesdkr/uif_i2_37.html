ImmLockIMCC

This function enables an input method editor (IME) to get a pointer to an input method context (IMC) component that can be a member of the IMC. ImmLockIMC increases the lock count for the IMC.

At a Glance

Header file: Imm.h
Windows CE versions: 2.10 and later

Syntax

LPVOID WINAPI ImmLockIMCC( HIMCC hIMCC );

Parameters

hIMCC
[in] Handle to IMC component

Return Values

Pointer to the IMC component indicates success. NULL indicates failure.

Remarks

Windows CE does not use the lock count.
