waveOutReset

This function stops playback on a specified waveform output device and resets the current position to 0. All pending playback buffers are marked as done and returned to the application.

At a Glance

Header file: Mmsystem.h
Windows CE versions: 2.0 and later

Syntax

MMRESULT waveOutReset(HWAVEOUT hWaveOut);

Parameters

hwo
Handle to the waveform-audio output device.

Return Values

One of the values described in the following table is returned.

Value
Description
MMSYSERR_NOERROR Success.
MMSYSERR_INVALHANDLE Specified device handle is invalid.
MMSYSERR_NODRIVER No device driver is present.
MMSYSERR_NOMEM Unable to allocate or lock memory.
MMSYSERR_NOTSUPPORTED Function is not supported.
