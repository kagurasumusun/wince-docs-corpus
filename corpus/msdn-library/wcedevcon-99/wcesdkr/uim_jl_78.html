LVM_GETTOPINDEX

This message retrieves the index of the topmost visible item when in list or report view. You can send this message explicitly or by using the ListView_GetTopIndex macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: ListView_GetTopIndex

Syntax

LVM_GETTOPINDEX wParam = 0; lParam = 0;

Return Values

The index of the item indicates success. Zero indicates the list view control is in icon or small icon view.
