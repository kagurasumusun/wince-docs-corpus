GetSubMenu

This function retrieves the handle to the pop-up menu activated by the specified menu item.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

HMENU GetSubMenu(HMENU hMenu, int nPos);

Parameters

hMenu
[in] Handle to the menu.
nPos
[in] Specifies the zero-based relative position in the given menu of an item that activates a drop-down menu or submenu.

Return Values

The handle to the drop-down menu or submenu activated by the menu item indicates success. NULL indicates that the menu item does not activate a drop-down menu or submenu.
