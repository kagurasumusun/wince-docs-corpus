PropSheet_RemovePage

This macro removes a page from a property sheet. You can use this macro or send the PSM_REMOVEPAGE message explicitly.

At a Glance

Header file: Prsht.h
Windows CE versions: 1.0 and later
Related message: PSM_REMOVEPAGE

Syntax

void PropSheet_RemovePage( hPropSheetDlg, index, hpage );

Parameters

hPropSheetDlg
Handle to the property sheet.
index
Zero-based index of the page to remove.
hpage
Handle to the page to remove.

Return Values

None.

Remarks

An application can specify the index or the handle, or both. If both are specified, hpage takes precedence.
