ListView_GetColumn

This macro retrieves the attributes of a list view control’s column. You can use this macro or send the LVM_GETCOLUMN message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_GETCOLUMN

Syntax

BOOL ListView_GetColumn( HWND hwnd, int iCol,
LV_COLUMN FAR* pcol );

Parameters

hwnd
Handle to the list view control.
iCol
Index of the column.
pcol
Pointer to an LVCOLUMN structure that specifies the information to retrieve and receives information about the column. The mask member specifies which column attributes to retrieve.

If the mask member specifies the LVCF_TEXT value, the pszText member must contain the address of the buffer that receives the item text, and the cchTextMax member must specify the size of the buffer.

Return Values

TRUE indicates success. FALSE indicates failure.
