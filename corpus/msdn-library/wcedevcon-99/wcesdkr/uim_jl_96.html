LVM_SETITEMPOSITION32

This message moves an item to a specified position in a list view control, which must be in icon or small icon view. This message differs from the LVM_SETITEMPOSITION message in that it uses 32-bit coordinates. You can send this message explicitly or by using the ListView_SetItemPosition32 macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: ListView_SetItemPosition32

Syntax

LVM_SETITEMPOSITION32 wParam = (WPARAM)(int) iItem;
lParam = (LPARAM)(LPPOINT) lpptNewPos;

Parameters

iItem
Index of the list view item for which to set the position
lpptNewPos
Long pointer a POINT structure that contains the new position of the item, in list view coordinates

Return Values

None
