MAILSORTINFO

This structure is used to describe the order in which messages are sorted for a particular mail handle.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

typedef struct _MAILSORTINFO {
MAILSORTFIELD iSort;
BOOL fAscending;
int cMsgs;
} MAILSORTINFO, *PMAILSORTINFO;

Members

iSort
Specifies the member by which the database is sorted for the specified mail handle. See the MAILSORTFIELD enumeration.
fAscending
Boolean that is set to TRUE if the records are sorted in ascending order on the specified key, or to FALSE if the records are sorted in descending order.
cMsgs
Specifies the number of messages currently in the store.
