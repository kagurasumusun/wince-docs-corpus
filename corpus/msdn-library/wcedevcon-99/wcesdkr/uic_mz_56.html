TabCtrl_SetCurSel

This macro selects a tab in a tab control. You can use this macro or send the TCM_SETCURSEL message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: TCM_SETCURSEL

Syntax

int TabCtrl_SetCurSel( HWND hwnd, int iItem);

Parameters

hwnd
Handle to the tab control.
iItem
Index of the tab to select.

Return Values

The index of the previously selected tab indicates success. –1 indicates failure.

Remarks

A tab control does not send a TCN_SELCHANGING or TCN_SELCHANGE notification message when a tab is selected using the TCM_SETCUSEL message.
