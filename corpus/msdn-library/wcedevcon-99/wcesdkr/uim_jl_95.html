LVM_SETITEMPOSITION

This message moves an item to a specified position in a list view control, which must be in icon or small icon view. You can send this message explicitly or by using the ListView_SetItemPosition macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: ListView_SetItemPosition

Syntax

LVM_SETITEMPOSITION wParam = (LPARAM)(int) i;
lParam = MAKELPARAM((int) x, (int) y);

Parameters

i
Index of the list view item
x and y
Specifies the new position of the item’s upper-left corner, in view coordinates

Return Values

TRUE indicates success. FALSE indicates failure.
