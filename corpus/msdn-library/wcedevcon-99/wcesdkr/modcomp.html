Windows CE Modules and Components

Because minimizing memory use is a major design goal, Windows CE is built from modules. You can control the size of the system software by selecting only the modules that you need. Several modules are also further divided into components. By selecting the minimum set of needed modules and components, you can minimize the memory needed for your Windows CE operating system.

A module or a component supports a group of related API functions. All defined modules and components are listed here in alphabetical order. The first list contains only the modules. Additional lists show the components for those modules that are divided into components.

These lists are followed by alphabetical reference entries for all modules. For each module that has components, its component entries follow immediately after the module entry. The reference entries include lists of functions that make up the modules and components.
