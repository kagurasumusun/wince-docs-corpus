CBN_DBLCLK

This notification message is sent when the user double-clicks a string in the list box of a combo box. The parent window of the combo box receives this notification message through the WM_COMMAND message.

At a Glance

Header file: Winuser.h
Windows CE versions: 2.0 and later

Syntax

CBN_DBLCLK idComboBox = (int) LOWORD(wParam);
hwndComboBox = (HWND) lParam;

Parameters

idComboBox
Identifier of the combo box.
hwndComboBox
Handle to the combo box.

Remarks

This notification message occurs only for a combo box with the CBS_SIMPLE style. In a combo box with the CBS_DROPDOWN or CBS_DROPDOWNLIST style, a double-click cannot occur because a single click closes the list box.

See Also
