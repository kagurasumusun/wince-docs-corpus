Module32Next

This function retrieves information about the next module associated with a process or thread.

At a Glance

Header file: Tlhelp32.h
Windows CE versions: 2.0 and later

Syntax

BOOL WINAPI Module32Next( HANDLE hSnapshot, LPMODULEENTRY32 lpme);

Parameters

hSnapshot
Handle to the snapshot returned from a previous call to the CreateToolhelp32Snapshot function.
lpme
Pointer to a MODULEENTRY32 structure.

Return Value

TRUE indicates the next entry of the module list has been copied to the buffer. FALSE indicates failure. The ERROR_NO_MORE_FILES error value, returned by GetLastError, indicates that no more modules exist.

Remarks

To retrieve information about first module associated with a process, use the Module32First function.
