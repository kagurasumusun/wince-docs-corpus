LB_GETITEMRECT

This message is sent by an application to retrieve the dimensions of the rectangle that bounds a list box item as it is currently displayed in the list box.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

LB_GETITEMRECT wParam = (WPARAM) index;
lParam = (LPARAM)(RECT FAR*) lprc;

Parameters

index
Zero-based index of the item.

Windows 95 and Windows 98: The wParam parameter is limited to 16-bit values. This means list boxes cannot contain more than 32,767 items. Although the number of items is restricted, the total size in bytes of the items in a list box is limited only by available memory.

lprc
Long pointer to a RECT structure to receive the client coordinates for the item in the list box.

Return Values

LB_ERR indicates that an error has occurred.
