BN_PAINT

This notification message is sent when a button should be painted. The parent window of the button receives this notification message through the WM_COMMAND message.

At a Glance

Header file: Winuser.h
Windows CE versions: 2.0 and later

Syntax

BN_PAINT

Remarks

This notification message is provided for compatibility with applications written for 16-bit versions of Windows earlier than version 3.0. Win32-based applications should use the BS_OWNERDRAW button style and the DRAWITEMSTRUCT structure for this task.
