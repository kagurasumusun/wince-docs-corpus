SetTextColor

This function sets the text color of the specified device context to the specified color.

At a Glance

Header file: Wingdi.h
Windows CE versions: 1.0 and later

Syntax

COLORREF SetTextColor(HDC hdc, COLORREF crColor);

Parameters

hdc
[in] Handle to the device context.
crColor
[in] Specifies the color of the text.

Return Values

A color reference for the previous text color indicates success. CLR_INVALID indicates failure. To get extended error information, call GetLastError.

Remarks

The text color is used to draw the face of each character written by the ExtTextOut function. The text color is also used in converting bitmaps from color to monochrome and vice versa.
