MailGetSort

This function retrieves the information about the current sort order for the specified mail handle.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

BOOL MailSetSort (HANDLE hMail, PMAILSORTINFO pInfo);

Parameters

hMail
Handle to the open mail context as returned by the MailOpen function.
pInfo
Receives the sort information.

Return Values

TRUE indicates success. FALSE indicates that the mail handle is invalid.

Remarks

Before calling the MailGetSort function, call MailFirst to update the number of applicable messages. To get extended error information, call MailError or MailErrorMsg.
