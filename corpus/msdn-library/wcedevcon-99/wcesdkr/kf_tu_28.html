UnmapViewOfFile

This function unmaps a mapped view of a file from the calling process’s address space.

At a Glance

Header file: Winbase.h
Windows CE versions: 1.01 and later

Syntax

BOOL UnmapViewOfFile( LPCVOID lpBaseAddress);

Parameters

lpBaseAddress
Pointer to the base address of the mapped view of a file that is to be unmapped. This value must be identical to the value returned by a previous call to the MapViewOfFile function.

Return Values

Nonzero indicates success. All dirty pages within the specified range are written “lazily” to disk. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

Although an application may close the file handle used to create a file mapping object, the system holds the corresponding file open until the last view of the file is unmapped.
