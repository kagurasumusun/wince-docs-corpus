MAILSORTFIELD

The MAILSORTFIELD enumeration specifies the fields by which mail messages may be sorted.

At a Glance

Header file: Msgstore.h
Windows CE versions: 2.0 and later

Syntax

typedef enum {
MAIL_SORT_FROM,
MAIL_SORT_SUBJ,
MAIL_SORT_DATE,
MAIL_SORT_SIZE
} MAILSORTFIELD;

Elements

MAIL_SORT_FROM
Sort message by senders.
MAIL_SORT_SUBJ
Sort messages by subject.
MAIL_SORT_DATE
Sort messages by date.
MAIL_SORT_SIZE
Sort messages by size.
