TCM_GETITEMRECT

This message retrieves the bounding rectangle for a tab in a tab control. You can send this message explicitly or by using the TabCtrl_GetItemRect macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: TabCtrl_GetItemRect

Syntax

TCM_GETITEMRECT wParam = (WPARAM)(int) iItem;
lParam = (LPARAM)(RECT FAR *) prc;

Parameters

iItem
Index of the tab.
prc
Pointer to a RECT structure that receives the bounding rectangle of the tab, in viewport coordinates.

Return Values

TRUE indicates success. FALSE indicates failure.
