CB_DELETESTRING

This message is sent by an application to delete a string in the list box of a combo box.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

CB_DELETESTRING wParam = (WPARAM) index, lParam = 0

Parameters

index
Specifies the zero-based index of the string to delete.

Return Values

A count of the strings remaining in the list indicates success. CB_ERR indicates that the index parameter specifies an index greater than the number of items in the list.

Remarks

If you create the combo box with an owner-drawn style but without the CBS_HASSTRINGS style, the system sends a WM_DELETEITEM message to the owner of the combo box so the application can free any additional data associated with the item.
