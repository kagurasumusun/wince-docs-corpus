ListView_GetSelectionMark

This macro retrieves the selection mark from a list view control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related message: LVM_GETSELECTIONMARK

Syntax

INT ListView_GetSelectionMark(HWND hwndLV);

Parameters

hwndLV
Handle to a list view control.

Return Values

Returns the zero-based selection mark, or -1 if there is no selection mark.

Remarks

The selection mark is the item index from which a multiple selection starts.
