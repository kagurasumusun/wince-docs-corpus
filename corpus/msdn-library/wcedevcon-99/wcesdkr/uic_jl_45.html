ListView_SetColumn

This macro sets the attributes of a list view column. You can use this macro or send the LVM_SETCOLUMN message explicitly.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related message: LVM_SETCOLUMN

Syntax

BOOL ListView_SetColumn( HWND hwnd, int iCol,
LV_COLUMN FAR* pcol );

Parameters

hwnd
Handle to the list view control.
iCol
Index of the column.
pcol
Pointer to an LVCOLUMN structure that contains the new column attributes. The mask member specifies which column attributes to set.

If the mask member specifies the LVCF_TEXT value, the pszText member is the address of a null-terminated string and the cchTextMax member is ignored.

Return Values

TRUE indicates success. FALSE indicates failure.
