VARDESC

This structure describes a variable, constant, or data member.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

typedef struct FARSTRUCT tagVARDESC {
MEMBERID memid;
OLECHAR FAR *lpstrSchema;
union {

} UNION_NAME(u);
ELEMDESC elemdescVar;

} VARDESC
