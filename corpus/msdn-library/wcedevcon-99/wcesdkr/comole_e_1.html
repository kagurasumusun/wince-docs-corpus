DESCKIND

The DESCKIND enumeration identifies the type description being bound to.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

typedef enum tagDESCKIND {
DESCKIND_NONE,
DESCKIND_FUNCDESC,
DESCKIND_VARDESC,
DESCKIND_TYPECOMP,
DESCKIND_IMPLICITAPPOBJ
} DESCKIND;

Elements

DESCKIND_NONE
No match was found.
DESCKIND_FUNCDESC
A FUNCDESC was returned.
DESCKIND_VARDESC
A VARDESC was returned.
DESCKIND_TYPECOMP
A TYPECOMP was returned.
DESCKIND_IMPLICITAPPOBJ
An IMPLICITAPPOBJ was returned.
