LVN_BEGINDRAG

This notification message notifies a list view control parent window that a drag and drop operation is being initiated. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later

Syntax

LVN_BEGINDRAG pnmv = (NM_LISTVIEW FAR *) lParam;

Parameters

pnmv
Pointer to an NMLISTVIEW structure. The iItem member identifies the item being dragged, and the other members are zero.

Return Values

None

See Also

NM_LISTVIEW, WM_NOTIFY
