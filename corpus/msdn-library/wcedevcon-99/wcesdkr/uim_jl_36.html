LB_SETTOPINDEX

This message is sent by an application to ensure that a particular item in a list box is visible.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

LB_SETTOPINDEX wParam = (WPARAM) index; lParam = 0;

Parameters

index
Zero-based index of the item in the list box.

Windows 95 and Windows 98: The wParam parameter is limited to 16-bit values. This means list boxes cannot contain more than 32,767 items. Although the number of items is restricted, the total size in bytes of the items in a list box is limited only by available memory.

Return Values

LB_ERR indicates that an error has occurred.

Remarks

The system scrolls the list box contents so that either the specified item appears at the top of the list box or the maximum scroll range has been reached.
