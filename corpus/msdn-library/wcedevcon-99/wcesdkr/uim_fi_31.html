IMC_GETOPENSTATUS

This message is sent by an application to an IME window to determine whether the IME is open.

At a Glance

Header file: Imm.h
Windows CE versions: 2.1 and later

Syntax

msg = (UINT) WM_IME_CONTROL;
wParam = (WPARAM) IMC_GETOPENSTATUS;
lParam = 0;

Return Values

Nonzero indicates that the current IME is open. Zero indicates the current IME is closed.
