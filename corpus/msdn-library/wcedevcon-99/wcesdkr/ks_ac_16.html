CEVALUNION

This union contains a value for a property.

At a Glance

Header file: Winbase.h
Windows CE versions: 1.01 and later

Syntax

typedef union _CEVALUNION {
short iVal;
USHORT uiVal;
long lVal;
ULONG ulVal;
FILETIME filetime;
LPWSTR lpwstr;
CEBLOB blob;
BOOL boolVal
 double dblVal
} CEVALUNION;

Members

iVal
Specifies an integer.
uiVal
Specifies an unsigned integer.
lVal
Specifies a long integer.
ulVal
Specifies an unsigned long integer.
filetime
Specifies a FILETIME structure.
lpwstr
Pointer to a null-terminated string.
blob
Specifies a CEBLOB structure.
boolVal
Specifies a BOOL type.
dblVal
Specifies a signed double.

See Also

CEBLOB, FILETIME
