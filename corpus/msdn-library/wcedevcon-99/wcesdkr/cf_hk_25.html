InternetLockRequestFile

This function allows the user to place a lock on the file that is being used.

At a Glance

Header file: Wininet.h
Windows CE versions: 2.12 and later

Syntax

BOOL InternetLockRequestFile (HINTERNET hInternet,
HANDLE *lphLockRequestInfo );

Parameters

hInternet
[in] HINTERNET handle returned by FtpOpenFile, HttpOpenRequest, or InternetOpenUrl.
lphLockRequestInfo
[out] Address of a handle to store the lock request handle.

Return Values

Returns TRUE if successful, or FALSE otherwise.

Remarks

If the HINTERNET handle passed to hInternet was created using INTERNET_FLAG_NO_CACHE_WRITE or INTERNET_FLAG_DONT_CACHE, the function creates a temporary file with the extension .tmp, unless it is an HTTPS resource. If the handle was created using INTERNET_FLAG_NO_CACHE_WRITE or INTERNET_FLAG_DONT_CACHE and it is accessing an HTTPS resource, InternetLockRequestFile fails.
