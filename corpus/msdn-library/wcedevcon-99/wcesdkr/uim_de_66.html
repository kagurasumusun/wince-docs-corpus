EN_UPDATE

This notification message is sent when an edit control is about to display altered text. This notification is sent after the control has formatted the text but before it displays the text. This makes it possible to resize the edit control window, if necessary. The parent window of the edit control receives this notification message through the WM_COMMAND message.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

EN_UPDATE idEditCtrl = (int) LOWORD (wParam);
hwndEditCtrl = (HWND) lParam;

Parameters

idEditCtrl
Identifier of the edit control.
hwndEditCtrl
Handle to the edit control.

See Also

EN_CHANGE, WM_COMMAND
