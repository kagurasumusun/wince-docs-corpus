WM_ENABLE

This message is sent when an application changes the enabled state of a window. It is sent to the window whose enabled state is changing. This message is sent before the EnableWindow function returns, but after the enabled state—the WS_DISABLED style bit—of the window has changed.

At a Glance

Header file: Winuser.h
Windows CE versions: 1.0 and later

Syntax

WM_ENABLE fEnabled = (BOOL) wParam;

Parameters

fEnabled
Boolean value that specifies whether the window has been enabled or disabled. Set to TRUE if the window has been enabled, or to FALSE if the window has been disabled.

Return Values

An application should return zero if it processes this message.
