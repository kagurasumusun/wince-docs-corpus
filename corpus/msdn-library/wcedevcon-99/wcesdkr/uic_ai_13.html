DateTime_SetMonthCalFont

This macro sets the font to be used by the date and time picker (DTP) control’s child month calendar control.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related message: DTM_SETMCFONT

Syntax

void DateTime_SetMonthCalFont(HWND hwndDP, HFONT hFont, LPARAM MAKELONG(hRedraw, 0));

Parameters

hwndDP
Handle to a DTP control.
hFont
Handle to the font that will be set.
fRedraw
Value that specifies whether the control should be redrawn immediately upon setting the font. If set to TRUE, the control redraws itself.
