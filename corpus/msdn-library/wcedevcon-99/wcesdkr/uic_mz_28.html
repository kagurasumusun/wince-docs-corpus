PropSheet_PressButton

This macro simulates the choice of a property sheet button. You can use this macro or send the PSM_PRESSBUTTON message explicitly.

At a Glance

Header file: Prsht.h
Windows CE versions: 1.0 and later
Related message: PSM_PRESSBUTTON

Syntax

BOOL PropSheet_PressButton( hPropSheetDlg, iButton );

Parameters

hPropSheetDlg
Handle to the property sheet.
iButton
Index of the button to select. It is one of the following values:
Value
Description
PSBTN_APPLYNOW Selects the Apply Now button.
PSBTN_BACK Selects the Back button.
PSBTN_CANCEL Selects the Cancel button.
PSBTN_FINISH Selects the Finish button.
PSBTN_HELP Selects the Help button.
PSBTN_NEXT Selects the Next button.
PSBTN_OK Selects the OK button.

Return Values

None.
