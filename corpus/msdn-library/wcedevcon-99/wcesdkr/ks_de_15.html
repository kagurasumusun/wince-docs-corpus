EXIT_THREAD_DEBUG_INFO

Windows CE versions: 2.0 and later

Syntax

typedef struct _EXIT_THREAD_DEBUG_INFO {
DWORD dwExitCode;
} EXIT_THREAD_DEBUG_INFO;
