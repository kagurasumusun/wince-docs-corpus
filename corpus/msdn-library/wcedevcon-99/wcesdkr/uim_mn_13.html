MCM_SETCURSEL

This message sets the currently selected date for a month calendar control. If the specified date is not in view, the control updates the display to bring it into view.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later
Related macro: MonthCal_SetCurSel

Syntax

MCM_SETCURSEL wParam = 0;
lParam = (LPARAM)(LPSYSTEMTIME) lpSysTime;

Parameters

lpSysTime
Long pointer to a SYSTEMTIME structure that contains the date to be set as the current selection. The time members of this structure are ignored.

Return Values

Nonzero indicates success. Zero indicates otherwise. This message fails if applied to a month calendar control that uses the MCS_MULTISELECT style.
