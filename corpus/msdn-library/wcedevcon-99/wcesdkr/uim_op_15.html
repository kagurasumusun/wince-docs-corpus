PSM_PRESSBUTTON

This message simulates the choice of a property sheet button. You can send this message explicitly or by using the PropSheet_PressButton macro.

At a Glance

Header file: Commctrl.h
Windows CE versions: 1.0 and later
Related macro: PropSheet_PressButton

Syntax

PSM_PRESSBUTTON wParam = (WPARAM)(int) iButton; lParam = 0;

Parameters

iButton
Index of the button to select. It is one of the following values:
Value
Description
PSBTN_APPLYNOW Selects the Apply Now button.
PSBTN_BACK Selects the Back button.
PSBTN_CANCEL Selects the Cancel button.
PSBTN_FINISH Selects the Finish button.
PSBTN_HELP Selects the Help button.
PSBTN_NEXT Selects the Next button.
PSBTN_OK Selects the OK button.

Return Values

None.
