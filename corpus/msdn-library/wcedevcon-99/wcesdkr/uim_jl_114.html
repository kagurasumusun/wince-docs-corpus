LVN_ITEMACTIVATE

This notification message is sent by a list view control when the user activates an item. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

LVN_ITEMACTIVATE lpnmlv = (LPNMLISTVIEW)lParam;

Parameters

lpnmlv
Long pointer to an NMLISTVIEW structure that contains notification data. The iItem, iSubItem and ptAction members contain data about the activated item. If the item was activated from the keyboard, the ptAction member will contain –1 in its x and y members.

Return Values

The application receiving this notification must return zero.
