RBN_ENDDRAG

This message is sent by a rebar control when the user stops dragging a band. It is sent in the form of a WM_NOTIFY message.

At a Glance

Header file: Commctrl.h
Windows CE versions: 2.0 and later

Syntax

RBN_ENDDRAG lpnmrb = (LPNMREBAR)lParam;

Parameters

lpnmrb
Long pointer to a NMREBAR structure that contains information about the notification.

Return Values

The return value for this notification is not used.
