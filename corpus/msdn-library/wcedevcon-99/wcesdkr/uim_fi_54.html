IMN_SETSTATUSWINDOWPOS

This message is sent when the status window position in the input context is updated. The application receives this notification message through the WM_IME_NOTIFY message.

At a Glance

Header file: Imm.h
Windows CE versions: 2.1 and later

Return Values

None

Remarks

The application can get data about the status window position by using the IMC_GETSTATUSWINDOWPOS message.
