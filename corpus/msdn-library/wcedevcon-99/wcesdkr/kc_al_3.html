CREATE_SYSTEMGUID

This macro creates a CEGUID that identifies the object store database volume.

At a Glance

Header file: Windbase.h
Windows CE versions: 2.10 and later

Syntax

VOID CREATE_SYSTEMGUID( PCEGUID pceguid);

Parameters

pceguid
Pointer to a CEGUID identifier that receives the CEGUID identifier of the database volume in the object store.

Remarks

Use this macro to generate the CEGUID identifier of the object store volume.
