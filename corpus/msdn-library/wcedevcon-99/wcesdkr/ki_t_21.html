ITypeInfo::ReleaseTypeAttr

This method releases a TYPEATTR previously returned by GetTypeAttr.

At a Glance

Header file: Oaidl.h
Windows CE versions: 2.0 and later

Syntax

HRESULT ReleaseTypeAttr( TYPEATTR FAR* pTypeAttr );

Parameter

pTypeAttr
Pointer to the TYPEATTR to be freed.

Remarks

The function ReleaseTypeAttr releases a TYPEATTR that was returned through ITypeInfo::GetTypeAttr.
