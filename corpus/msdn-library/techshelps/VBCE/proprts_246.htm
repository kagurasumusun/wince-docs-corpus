TwipsPerPixelY

Return the number of twips per pixel for an object measured horizontally (TwipsPerPixelX) or vertically (TwipsPerPixelY).

Syntax

object.TwipsPerPixelX

object.TwipsPerPixelY

The object placeholder represents an object expression that evaluates to an object.

Remarks

You can use these properties to convert measurements quickly without changing an object's ScaleMode property setting.
