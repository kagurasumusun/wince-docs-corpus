Optimizing Performance

If you've used the standard installation option during Setup, you can optimize the performance of the Pegasus DDK Books Online by copying the files listed below from the Pegasus DDK Books Online disc to the Pegasus DDK Books Online installation directory on your computer. Each file affects the performance of a specific Library component, listed on the left.

To optimize the performance of:Copy file:
Pegasus DDK Books Online startupSTARTUP.DAT
Keywords listKEYWORD.MSD
Source list navigation, Sync buttonSOURCE.MSD
Search engineSRCHTITL.DAT
The full installation option automatically copies the files listed above to your system to optimize performance. To recover disk space, you may delete one or more of these files to turn optimization off for specific components. Please note that this optimization procedure cannot be used with the minimal installation option.
