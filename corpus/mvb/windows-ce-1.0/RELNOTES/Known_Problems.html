Known Problems

This section describes the known problems and limitations in the Pegasus DDK Books Online software. If you encounter any other problems using the software, please notify us through the CompuServe Microsoft Developer Network Forum (GO MSDNLIB).

Installation and setup

If you run the Setup program while an existing version of the Pegasus DDK Books Online is running on your system, you may have problems with the installation. Please close the Pegasus DDK Books Online before running Setup.

Do not remove the Pegasus DDK Books Online disc from the CD-ROM drive while the Pegasus DDK Books Online software is running. (If you wish to access the contents of earlier Library discs, close the Library software before switching discs.) If the Library software cannot access the disc, it causes a general protection fault. If you encounter this problem, close the message box and restart Windows.

If your Windows installation directory is on a read-only drive, the Setup program displays the message "Error opening file: Windows-path\MVIEWER2.EXE." If you encounter this problem, make sure that you have access to your Windows installation directory.

The Pegasus DDK Books Online displays an "Undefined Dynalink" error message if it finds a different version of CTL3D.DLL on your machine. If you encounter this message, delete the CTL3D.DLL file from your Windows directory and re-install the Pegasus DDK Books Online.

The Pegasus DDK Books Online uses the Microsoft Multimedia Viewer version 2.0 software. If you wish to run a Viewer version 1.0 application concurrently with the Pegasus DDK Books Online, start the Library software first. Otherwise, you will encounter an "Unable to find Dynalink" error message.

If you have problems installing the Pegasus DDK Books Online using the Setup program, see the MANSETUP.TXT file on the disc for manual installation instructions.

If the Setup program and your manual installation efforts fail, check the netware loadable modules (NLMs) on your system. Unload the NLMs and reload them in the following order:

Running the debugging version of Windows
If you are running the debugging version of Windows, you will encounter warning messages with fatal exit codes 0x4000, 0x4800, and 0x5000 during and immediately after running the Setup program. You will also encounter warning messages with fatal exit code 0x4800 whenever you change topics in the Viewer window. Please ignore these messages. They do not occur in the retail version of Windows.
Searching
During a search, if you encounter the error message "Out of memory" or "An internal error occurred while searching: 1," you may be out of temporary disk space. Check the TEMP variable setting in AUTOEXEC.BAT. Make sure that it is pointing to a directory located on your hard drive (not to a RAM disk). Use File Manager to check the available space in your TEMP directory. Depending on the Pegasus DDK Books Online features and queries you are using, you may need 4 MB (or more) of free temporary space.
These two error messages may also be caused by low memory conditions. From the Program Manager Help menu, choose the About Program Manager command to check available memory.
Highlights and hyperlinks
Search hits are automatically highlighted in topic text. In some cases (for example, if a search hit appears in a table), highlighting may be off by one character.
Keywords (function, structure, and message names) appearing in topic text are hyperlinked to their descriptions in the reference material automatically. The utility we use to generate these hyperlinks is not context sensitive. For this reason, we’ve disabled hyperlinks for common words such as system, time, and exit; these words are not hyperlinked even if they appear as keywords in a topic.
Formatting
In some topics, you may encounter formatting problems such as table columns that do not line up, overwritten text, or truncated lines in the Viewer window. If you encounter these problems, resize or maximize the Viewer window.
In some topics, you may see lists with extraneous characters, double bullets, or double numbers. We are working on fixing these problems.
Scrolling
When scrolling line by line through a topic that contains graphics, the scroll box sometimes moves erratically.
In the Contents window, the position of the scroll box within the scroll bar may not accurately reflect the position of the highlighted topic in the Source or Keywords list.
Printing
If you print a topic that contains an ampersand (&) in its title, the Print Topic message box displays the title text without the ampersand, but underlines the character after the ampersand. For example, if you print the topic entitled "MS-DOS Q&A," the Print Topic box displays "Printing MS-DOS QA." The topic is printed correctly.
If you encounter a general protection fault when you print a topic, check your printer driver. Switch to a more current version of the driver, if one is available. If the problem persists, one of the following procedures may solve the problem:
In Control Panel, double-click the Fonts icon. Click the TrueType button in the Fonts dialog box, and turn off the Enable TrueType Fonts option.
Open Control Panel, choose Setup and Options for your printer, turn off the Color option, and restart Windows.
If you are using an HP LaserJet printer, make sure that you have the most current printer driver and that your printer resolution is 300 dpi (graphics may not print properly at 600 dpi).
If you are getting partial printouts of topics, check your printer driver. Switch to a more current version of the driver, if one is available. If the problem persists, use Control Panel to route the printout to a file. Either (a) assign the printer to the FILE: port, or (b) switch to the Generic / Text Only driver.
A topic that exceeds 32K will also produce a partial printout. To print topics over 32K, display the topic in the Viewer window and press CTRL + INS to copy it to the Clipboard. You can then paste the text into a word-processing program (such as Windows Write or Word for Windows) and use the printing facilities of that program.
