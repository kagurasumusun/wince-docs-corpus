Notes and Recommendations

This section provides recommendations for using the Pegasus DDK Books Online. For detailed instructions on using the Library, please refer to the online Help system.

System requirements

The Pegasus DDK Books Online requires 4 megabytes of RAM (6-8 MB recommended). The program will not install properly on systems that have less memory.

The Pegasus DDK Books Online has the following disk space requirements: 80K for minimal installation, 2 MB for standard installation, and 15 MB for full installation. These numbers are based on a system that has 512 bytes per sector. The actual disk space may vary if you have a very large hard disk with a different sector size.

The Pegasus DDK Books Online requires Microsoft Windows version 3.1 or Windows for Workgroups version 3.1. The Library software is also compatible with the Windows subsystem of the Windows NT operating system. If you encounter any problems using the Library on Windows NT, please access the WINNT forum, Section 4, on CompuServe (GO WINNT). We have no plans for providing compatibility with Windows version 3.0.

If you have multiple CD-ROM drives (local or networked) and change the drive or share for the Pegasus DDK Books Online after installation, double-clicking the Pegasus DDK Books Online icon will display error messages from the Multimedia Viewer. When you see the message "<drive> must contain Pegasus DDK Books Online CD," click the Cancel button. The Multimedia Viewer window will be displayed with the message "Cannot find Viewer file. Make sure the correct disk and directory are specified." Click OK to close the message box, choose the File Open command from the Multimedia Viewer window, and select MSDNWDT1.MVB from the correct drive or share.

If you receive an "Unable to read drive" or "CD is not in drive" message when you run the Pegasus DDK Books Online, please check your disc caddy for any problems accessing the CD. (Switch to another CD to test the caddy.) If the problems persist with the Pegasus DDK Books Online CD, please call (206) 635-7033 to request another CD.

Library contents

Embedded graphics are missing from some topics. If a graphic is missing, you will see a picture of Dr. GUI with the message "Sorry, this illustration is not available" in the topic. Please do not report this as a bug; we are aware of all missing graphics and will continue to add these in future releases of the Library.

On some displays, graphics in topics may appear stretched or otherwise distorted; this is caused by the difference between preparing art for the printed page vs. the display screen. If all graphics appear distorted on your system, use the Windows Setup program to change your display driver to either (a) the standard VGA (640x480) driver included with Windows or (b) the Super VGA driver, if your system supports it. If changing the driver improves the graphics display, we recommend that you contact your display card vendor about possible updates to your original display driver.

The product documentation included in the Pegasus DDK Books Online is not edited by the Microsoft Developer Network team. You may encounter documentation errors, references to page numbers, and formatting problems. We will communicate any errors you report to the appropriate product documentation groups.

Addresses, phone numbers, and other contact information appearing in the Pegasus DDK Books Online may have changed since the time of publication. To avoid any inconvenience, we have removed pricing and contact information from the Microsoft Developer Network News topics appearing in the Library, but other topics may contain obsolete data.

The Pegasus DDK Books Online includes the 1993 issues of the Microsoft Systems Journal (MSJ) and associated sample code. All MSJ samples are provided as is; they have not been modified or tested for the Pegasus DDK Books Online.

This release of the Pegasus DDK Books Online contains the November 17, 1993 version of the Microsoft Developer Knowledge Base.

The Pegasus DDK Books Online contains Help files, which are represented in the Contents window by a single topic marked with the icon. This topic represents the table of contents for the Help file, which is included in the Pegasus DDK Books Online in its original format. You can click the colored, underlined text in this topic or use the << and >> keys to navigate through the Help file. (The <Contents and Contents> keys will lead you out of the Help file, to the next or previous topic listed in the Contents window.)

We've preserved the original hyperlinks in each Help file. Keywords (function, structure, and message names) appearing in Help topics are not hyperlinked to reference material in the Pegasus DDK Books Online.

Searching
The search engine ignores punctuation marks such as the period (.), comma (,), semicolon (;), and colon (:) appearing in a query. Refer to online Help for more information on search syntax.
By default, the Pegasus DDK Books Online displays the top 2000 search results for each query. If your query results in a large number of hits, you can narrow your search by typing a new query and selecting the Refine Search check box. The second query will search the topics in your existing list.
The search engine does not save the Title Text Only setting when you close the Search window. If you wish to search topic titles only, you must reselect this check box.
Annotations and bookmarks
The Pegasus DDK Books Online lets you define a maximum of 98 bookmarks. You can create any number of annotations (limited only by disk space). Each annotation is limited to 2048 bytes.
Copying and printing
The text you can copy with the Edit menu Copy command is limited to 32K. A topic that exceeds this limit will not appear in its entirety in the Copy dialog box. To copy topics over 32K, display the topic in the Viewer window and press CTRL + INS. These shortcut keys bypass the Copy dialog box and copy the entire topic directly to the Clipboard.
The text you can print with the File menu Print Topic command is also limited to 32K. A topic that exceeds this limit will produce a partial printout. To print topics over 32K, display the topic in the Viewer window and press CTRL + INS to copy it to the Clipboard. You can then paste the text into a word-processing program (such as Windows Write or Word for Windows) and use the printing facilities of that program.
The Pegasus DDK Books Online software allows you to print the topic currently being displayed in the Viewer window. In some cases, the current topic may be part of a chapter. To print the entire chapter, you must view and print each topic in the chapter separately.
