Implementing a Dummy File Filter

You can modify the file filter registry (discussed in the topic “File Filter Registry Entries”) simply for the purpse of giving the appearance that files of a certain type are being converted, without actually performing a filter conversion.

Modify the desktop PC registry key HKLM\Software\Microsoft\Pegasus\Filters by adding a subkey that is the name of the file extension for the type of files that should be converted using the “null” file conversion. For example, if you are converting files with extionsion “.abc”, then you must add a subkey .abc.

Under the .abc subkey, create a string value named DefaultImport that is set to “Binary Copy”. This identifies the conversion for files with extension .abc that are imported from the desktop PC to the Handheld PC (HPC).

Under the .abc subkey, create a string value named DefaultExport that is set to “Binary Copy”. This identifies the conversion for files with extension .abc that are exported from HPC to the desktop PC.

So, when a file with extension .abc is copied between the desktop PC and the HPC, it will appear as though a conversion process is taking place (that is, you will not see a message from HPC Explorer stating that a conversion filter was not found). However, no filter actually is being used, since an InstalledFilters subkey has not been added under the .abc key.
