ntohs

The Windows Sockets ntohs function converts a u_short from network byte order to host byte order.

u_short ntohs (// winsock.h
u_short netshort// 16-bit number in network byte order
);
Parameters
netshort
A 16-bit number in network byte order.
Return Values
ntohs returns the value in host byte order.
Remarks
This function takes a 16-bit number in network byte order and returns a 16-bit number in host byte order.
