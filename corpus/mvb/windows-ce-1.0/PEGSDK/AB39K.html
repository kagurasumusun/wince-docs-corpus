MailGetFolderId

The MailGetFolderId function retrieves the identification number of a mail folder from the message store.

BOOL MailGetFolderId (// msgstore.h
HANDLE hService,// Handle to mail context.
BYTE* bId,// Folder ID.
LPWSTR szName// Folder name.
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
bId
If the folder name pointed to by szName exists in the message store, the value of this parameter contains the identification number associated with the name.
szName
Points to the string containing the name of the mail folder being searched for.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
