Programming Applications for Efficient Power Management

Power management is transparent to most applications. The programming techniques for efficient power management amount to the following guidelines:

· Return control to the operating system when possible to let it determine when the system is inactive.

· Do not use idle loops.

While most applications are not affected, the following suspend mode operating characteristics might affect others:

· The Sleep timer is inactive during suspend mode.

· The user can turn the computer off to enter the suspend mode.

Applications can use the following functions to obtain power information, reset the activity timer, or set timers and events that can switch the computer to the on mode.

FunctionDescription
GetSystemPowerStatusExUse to obtain information about the system power status.
PegRunAppAtTimeUse to set timer or run application at specified time.
WaitCommEventWait for an event to occur for a communications device. (Serial, IrDA, or PC Card devices can return EV_POWER when the device resumes operation. )
