Mail Message ID Numbers

Each mail message has three distinct and unique identification numbers:

· Message ID (dwMsgId). This ID is used by the Mail API to manipulate messages at the message store level. In most cases this ID number should not be changed or used by applications.

· Service ID (szSvcId). This ID is used by the service to uniquely identify messages. This value should be changed only by the service library.

· Object ID (oid). This ID is set by the operating system to uniquely identify the message as a record in the object store. Your application can use this ID number to directly access messages.
