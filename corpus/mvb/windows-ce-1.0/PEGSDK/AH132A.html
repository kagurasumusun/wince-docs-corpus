PDATA Format

The Microsoft object module format for SH-3 specifies a data structure to aid in stack walking at run-time. It is used mainly in debugging and exception processing.

In most cases this data structure occupies only eight bytes per function. For functions which have an exception handler an additional eight bytes are needed. Another eight bytes are needed in the rare cases where the prolog extends more than 255 instructions (510 bytes) beyond the beginning of a function, or the total function length is greater than 8,388,607 instructions (just under 16 Megabytes).

The PDATA record contains the following information:

struct PDATA {-

unsigned int FuncStart : 32;

unsigned int PrologLen : 8;

unsigned int FuncLen : 23;

unsigned int ExceptionFlag : 1;

};

FuncStart indicates the address of the first instruction in the function. It is the function’s entry address.

PrologLen indicates the length of the prolog in instructions. A prolog with ten instructions would have a PrologLen of 10.

FuncLen indicates the total function length in instructions. A function with two hundred instructions would have a FuncLen of 200.

ExceptionFlag indicates that the function has an associated exception handler or handler data. When its value is one then the PDATA_EH is present in the .text section (as described below). When the ExceptionFlag is zero then no PDATA_EH is present.

In the event that the ExceptionFlag is set, or the FuncLen is set to zero, then there is additional PDATA information that precedes the function in the .text section. The data record containing this information appears in the .text section, immediately preceding the function, if and only if the ExceptionFlag bit is set. This record is used whenever the function has an associated exception handler or handler data. The structure of this record is as follows:

struct PDATA_EH {-

unsigned int * pHandler;

unsigned int * pHandlerData;

};

pHandler contains the address of the exception handler for the function.

pHandlerData contains the address of the exception handler data record for the function.

The prolog and function length record appears in the .text section, immediately preceding the exception handling data record if it exists (otherwise immediately preceding the function itself), if and only if the FuncLen field is zero. (Note that if the FuncLen field is zero, the PrologLen field should also be zero.) This record is generated when the prolog extends more than 255 instructions (510 bytes) beyond the beginning of a function, or the total function length is greater than 8,388,607 instructions (just under 16 Megabytes).

The structure of this record is as follows:

struct PDATA_PNFLEN

{-

unsigned int PrologLen;

unsigned int FuncLen;

};

PrologLen: as in the PDATA structure, this field indicates the total prolog length in instructions.

FuncLen: as in the PDATA structure, this field indicates the total function length in instructions.

Note that the exception handling data record and the prolog and function length record are both guaranteed to be 4-byte aligned. This implies that any function that has either or both of these records associated with it will be 4-byte aligned.
