GetSystemPowerStatusEx

Retrieves the power status of the system.

BOOL GetSystemPowerStatusEx(// winbase.h
PSYSTEM_POWER_STATUS_EX pstatus,// pointer to the buffer to be filled
BOOL fUpdate//
);
Parameters
pstatus
Points to the buffer to be filled in.
fUpdate
If TRUE, the function gets the latest information from the device driver, as opposed to cached information that may be out-of-date by several seconds.
