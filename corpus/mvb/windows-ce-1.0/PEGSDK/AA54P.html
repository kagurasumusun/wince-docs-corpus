<LI>

Denotes one item of a list. The same tag is use for OL, UL, MENU and DIR. Look at the ‘list stack’ and generate a list item of the appropriate type. A Directory List element is used to present a list of items containing up to 20 characters each. Items in a directory list may be arranged in columns, typically 24 characters wide. If the HTML user agent can optimize the column width as function of the widths of individual elements, so much the better. A directory list must begin with the <DIR> element which is immediately followed by a <LI> (list item) element.

TYPE

Same as the type option on the tag starting the list. It simply overrides the default for this list.

VALUE

Sets the current list to the value specified. (This has to be updated in the list stack.)

The list consists of bullets left justified to the left margin. The corresponding list item is indented from the bullet 8 pixels. The default bullet is rendered as a Symbol 9pt font = · (alt 0183).

A <p> paragraph space is inserted after each LI (default = 12 pixels).
