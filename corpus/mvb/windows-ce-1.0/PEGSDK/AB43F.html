FreeAddressCard

The FreeAddressCard function frees memory that the system allocated for address card data as a result of a call to the OpenAddressCard or GetAddressCardProperties function.

void FreeAddressCard(// addrstor.h
AddressCard *pac// address of structure with address card data
);
Parameters
pac
Points to the AddressCard structure that was filled by a previous call to OpenAddressCard or GetAddressCardProperties.
Return Values
No return value.
