Inline Assembly for MIPS Target Devices

In each MIPS C++ compilation unit that uses assembler statements, you are responsible for including function prototypes to declare each assembler statement that you will be using in that module. In addition, you must also include a #pragma intrinsic statement declaring _ _asm. For example, the following C++ code can be used to accomplish this definition:

extern “C” {-

void __asm(char*, . . . );

};

#pragma intrinsic (__asm)

Note It is not necessary to perform these declarations in C source modules.

As can be inferred from the declaration above, MIPS assembler statements have function call semantics:

The first argument (argument 0) is the body of the function and is a literal string containing the inline assembler code. See below for a description of the syntax within this string.

Subsequent arguments are processed and evaluated exactly as C function call arguments.

The result is taken from the return register.
