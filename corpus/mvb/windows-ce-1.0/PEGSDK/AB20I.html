ImageList_Create

The ImageList_Create function creates a new image list.

HIMAGELIST WINAPI ImageList_Create(// commctrl.h
int cx,// dimension of each image in pixels
int cy,// dimension of each image in pixels
UINT flags,// flag specifying the type of image to create
int cInitial,// number of images that the list contains
int cGrow// number of images by which the list can grow
);
Parameters
cx
Dimensions of each image, in pixels.
cy
Dimensions of each image, in pixels.
flags
Flags specifying the type of image list to create. This parameter can be a combination of these values.
Value		Meaning
ILC_COLORUse the default behavior if none of the other ILC_COLOR* flags is specified. The default image list bitmap is a 2bpp DIB.
ILC_COLOR4Uses 4-bit device-independent bitmap (DIB) sections.
ILC_COLOR8Uses 8-bit DIB sections.
ILC_COLOR16Uses 16-bit DIB sections.
ILC_COLOR24Uses 24-bit DIB sections.
ILC_COLOR32Uses 32-bit DIB sections.
ILC_COLORDDBUses device-dependent bitmaps.
ILC_MASKUses a mask. The image list contains two bitmaps, one of which is a monochrome bitmap used as a mask. If this value is not included, the image list contains only one bitmap.
ILC_PALETTEUses a color palette with the image list.
cInitial
Number of images that the image list initially contains.
cGrow
Number of images by which the image list can grow when the system needs to resize the list to make room for new images. This parameter represents the number of new images that the resized image list can contain.
Return Values
Returns the handle of the image list if successful or NULL otherwise.
