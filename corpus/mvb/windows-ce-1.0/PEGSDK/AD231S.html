WM_SETTINGCHANGE

The WM_SETTINGCHANGE message is sent to all windows when an application changes a systemwide setting by using the SystemParametersInfo function.

wParam = wFlag; // system-wide parameter flag

lParam = (LPARAM)(LPCTSTR) pszMetrics; // metrics name

Parameters

wFlag

Value of wParam. Specifies the systemwide parameter that has changed. For a list of values, see the SystemParametersInfo function.

pszMetrics

Points to a buffer that contains the string "WindowMetrics" if wFlag specifies any of the following systemwide parameters. This parameter is NULL otherwise:

· SPI_SETANIMATION

· SPI_SETNONCLIENTMETRICS

· SPI_SETICONMETRICS

· SPI_SETMINIMIZEDMETRICS

Return Values

An application should return zero if it processes this message.
