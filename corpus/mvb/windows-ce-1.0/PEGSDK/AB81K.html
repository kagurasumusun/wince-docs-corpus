MailUpdate

The MailUpdate function replaces an entry in the message store with updated information.

BOOL MailUpdate (// msgstore.h
HANDLE hService,// Handle to mail context.
MailMsg* pmm,// Item information.
BOOL fDoAll// Update flags only or all fields
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
pmm
Points to the MailMsg structure containing the mail entry with the updated information.
fDoAll
If this parameter is TRUE, all members of the MailMsg structure are updated; if FALSE, only the flags are changed.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
Remarks
The entry being updated is based on the oid member of the MailMsg structure. If the entry does not exist in the database, this function fails.
