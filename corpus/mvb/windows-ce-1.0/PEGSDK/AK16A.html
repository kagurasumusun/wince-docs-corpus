Remote Spy

The Remote Spy (Pspy.exe) user interface is similar to the standard Windows Spy, except that you select windows to be spied upon on the HPC using the finder toggle switch. When the finder is on, you select an HPC window to spy upon by either touching a window on the HPC with the stylus or selecting it from the Pspy client listbox.

Using Remote Spy

To begin spying on a window, click the Spy On Window button, and then toggle the finder switch OFF. The Spy On Window button spawns a new MDI child window for each HPC window spied upon, but the spy function is active only when the finder switch is OFF.
