Limit use of temporary files.

Many programs make use of temporary files that are deleted when the program terminates. While it may be convenient, such files represent a load on memory resources that you may wish to limit or eliminate. There are a number of strategies for using temporary files that you may wish to consider.

An obvious one is elimination. While you may pay a price in terms of speed, simplicity, or perhaps robustness (with such features as automatic backups to protect against program or machine failure), the increase in memory efficiency may be sufficient to offset the liabilities. If possible, design your application so that it is sensitive to available memory and can modify its usage of temporary files accordingly.
