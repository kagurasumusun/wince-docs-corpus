PegRegDeleteValue

The PegRegDeleteValue function is the RAPI version of the RegDeleteValue function. For more information about using RAPI functions, please see the Remote API Functions overview

LONG PegRegDeleteValue(// rapi.h
HKEY IN hKey,// handle of key
LPCWSTR IN lpszValueName// address of value name
);
Parameters
hKey
Identifies a currently open key or any of the following predefined reserved handle values:
· HKEY_CLASSES_ROOT
· HKEY_CURRENT_USER
· HKEY_LOCAL_MACHINE
· HKEY_USERS
lpValueName
Points to a null-terminated string that names the value to remove. If this parameter is NULL or points to an empty string, the value set by the PegRegSetValueEx function is removed.
Return Values
If the function succeeds, the return value is ERROR_SUCCESS. If the function fails, the return value is an error value.
Remarks
The key identified by the hKey parameter must have been opened with KEY_SET_VALUE access (KEY_WRITE access includes KEY_SET_VALUE access).
