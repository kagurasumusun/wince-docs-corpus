htonl

The Windows Sockets htonl function converts a u_long from host byte order to network byte order.

This function takes a 32-bit number in host byte order and returns a 32-bit number in network byte order.

u_long htonl (// winsock.h
u_long hostlong// 32-bit number in host byte order
);
Parameters
hostlong
A 32-bit number in host byte order.
Return Values
The htonl function returns the value in network byte order.
