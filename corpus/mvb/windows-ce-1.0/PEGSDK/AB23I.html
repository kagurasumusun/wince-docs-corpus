ImageList_Destroy

The ImageList_Destroy function destroys an image list.

BOOL WINAPI ImageList_Destroy(// commctrl.h
HIMAGELIST himl// handle of the image list to destroy
);
Parameters
himl
Handle of the image list to destroy.
Return Values
Returns TRUE if successful or FALSE otherwise.
