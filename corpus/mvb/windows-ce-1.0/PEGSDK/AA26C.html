User Feedback

Provide feedback to your users when appropriate so that they can manage memory efficiently. It is better not to wait until something fails. Provide them ample warning so that they can, if necessary, delete unneeded data and applications to make more room. If your application involves downloading of data (e-mail or stock quotations, for example) that may require more memory than is available, provide a way for your user to make more memory available without interfering with the download.
