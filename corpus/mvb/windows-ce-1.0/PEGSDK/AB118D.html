DrawIconEx

The DrawIconEx function draws an icon or cursor in the client area of the window of the specified device context, performing the raster operations as specified.

Windows CE Notes The following parameter settings must be used:

· diFlags must one of DI_NORMAL, DI_IMAGE, or DI_MASK.

· cxWidth and cyHeight must be zero or the native dimensions of the icon.

· hbrFlickerFreeDraw must be NULL.

· iStepIfAniCur must be zero. Animated icons are not supported.

Stretching and compressing are not supported.

hIcon cannot identify an animated cursor.

Mapping modes are not supported.

BOOL DrawIconEx(// winuser.h
HDC hdc,// handle to device context
int xLeft,// x-coordinate of upper left corner
int yTop,// y-coordinate of upper left corner
HICON hIcon,// handle to icon to draw
int cxWidth,// width of the icon
int cyHeight,// height of the icon
UINT istepIfAniCur,// must be zero
HBRUSH hbrFlickerFreeDraw,// must be NULL
UINT diFlags// icon-drawing flags
);
Parameters
hdc
Identifies the device context for a window.
xLeft
Specifies the logical x-coordinate of the upper-left corner of the icon or cursor.
yTop
Specifies the logical y-coordinate of the upper-left corner of the icon or cursor.
hIcon
Identifies the icon or cursor to be drawn.
cxWidth
Specifies the logical width of the icon or cursor. This value must be zero or the native dimensions of the icon.
cyHeight
Specifies the logical height of the icon or cursor. This value must be zero or the native dimensions of the icon.
istepIfAniCur
Must be zero. Specifies the index of the frame to draw.
hbrFlickerFreeDraw
Must be NULL. Identifies a brush that the system uses for flicker-free drawing. In Windows CE, the system draws the icon or cursor directly into the device context.
diFlags
Specifies the drawing flags. This parameter can be one of the following values.
Value		Meaning
DI_IMAGEPerforms the raster operation specified by ropImage.
DI_MASKPerforms the raster operation specified by ropMask.
DI_NORMALCombination of DI_IMAGE and DI_MASK.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE. To get extended error information, call GetLastError.
Remarks
DrawIconEx places the icon's upper-left corner at the location specified by the xLeft and yTop parameters.
