Working with Windows CE API

Although the Windows CE API contains most of the commonly used Win32 API functions, many have been modified to accommodate the needs of the Windows CE platform. This section discusses how you will need to change your programs to conform to the Windows CE API.

The complete Peg/OS API, and how it differs from Win32, can be found in the Windows CE SDK reference. What we will focus on here are those functions that are most commonly used in Windows programming.
