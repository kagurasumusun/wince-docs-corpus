IPegasusFileFilter::NextConvertFile

When the user selects a conversion type from HPC Explorer's conversion selection dialog box, HPC Explorer calls the IPegasusFileFilter::NextConvertFile function of the file filter that supports the selected conversion.

STDMETHODIMP IPegasusFileFilter::NextConvertFile(

int nConversion,

PFF_CONVERTINFO* pci,

PFF_SOURCEFILE* psf,

PFF_DESTINATIONFILE* pdf,

volatile BOOL *pbCancel

PR_ERROR *perr

);

Parameters

nConversion

A counter for converting a single source file into multiple destination files. This parameter will be zero the first time this function is called and will be incremented for each successive call. A simple filter should return HRESULT_FROM_WIN32(ERROR_NO_MORE_ITEMS) if this parameter is not zero.

pci

Points to a PFF_CONVERTINFO structure that contains a pointer to an IPegasusFileFilterSite object. A file filter uses this interface to create an IStream or IStorage object to read the contents of the source file or to write to the destination file. Any files opened in this way should be closed using the corresponding CloseSourceFile or CloseDestinationFile methods.

psf

Points to a PFF_SOURCEFILE structure that contains information about the source file.

pdf

Points to a PFF_DESTINATIONFILE structure that contains information about the destination file.

pbCancel

Points to a variable that receives TRUE if the user cancels the file conversion before it is completed. Otherwise, the variable is set to FALSE. Because this variable is updated asynchronously by another thread, its contents can change at any time. A file filter must check this variable regularly during the conversion process, and return ERROR_CANCELLED (after cleaning up) if it is ever set to TRUE.

perr

Address of a filter-defined error code that may be passed to the IPegasusFileFilter::FormatMessage member function. This error code will be ignored unless the return value from this function is E_FAIL.

Return Value

The return value can be one of the following values.

ValueMeaning
NOERRORThe subconversion was successful; proceed to the next subconversion.
HRESULT_FROM_WIN32 (ERROR_CANCELLED)The user canceled the conversion.
HRESULT_FROM_WIN32 (ERROR_NO_MORE_ITEMS)The conversion (or last subconversion) was successful. End calls to IPegasusFileFilter::NextConvertFile.
E_FAILperr was filled with an error code that should be passed to IpegasusFileFilter::FormatMessage
Remarks
HPC Explorer calls this function repeatedly, incrementing the nConversion parameter, until the return value is ERROR_NO_MORE_ITEMS. A simple filter should return NOERROR the first time this method is called, and return HRESULT_FROM_WIN32(ERROR_NO_MORE_ITEMS) thereafter. Alternatively, a file filter can return E_FAIL and specify a filter-defined error code in the variable pointed to by perr. For more information about filter-defined error codes, see "Filter Defined Error Values" in this chapter.
As a file conversion progresses, a file filter should periodically call IPegasusFileFilterSite::ReportProgress to report its progress. HPC Explorer uses the progress information to update a progress bar that shows the user how the much of the conversion has been completed.
If any important data is intentionally discarded by a file filter during the conversion process, the filter should call IPegasusFileFilterSite::ReportLoss to report the loss. When calling this function, the filter specifies a message that explains the data loss, and HPC Explorer formats and displays the message in a message box when the file conversion has completed.
