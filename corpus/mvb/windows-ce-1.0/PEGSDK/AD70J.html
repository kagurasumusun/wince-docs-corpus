LVM_GETITEMSPACING

Determines the spacing between items in a list view control. You can send this message explicitly or by using the ListView_GetItemSpacing macro.

wParam = (WPARAM)(BOOL) fSmall;

lParam = 0;

// Corresponding macro

DWORD ListView_GetItemSpacing(

HWND hwnd,

BOOL fSmall

);

Parameters

hwnd

Handle of the list view control.

fSmall

View to retrieve the item spacing for. This parameter is TRUE for small icon view or FALSE for icon view.

Return Values

Returns the amount of spacing between items.
