PEGDIRINFO

The PEGDIRINFO structure contains information about a directory object.

typedef struct _PEGDIRINFO {-  // pegdi

DWORD dwAttributes;

PEGOID oidParent;

WCHAR szDirName[MAX_PATH];

} PEGDIRINFO;

Members

dwAttributes

Specifies the attributes of the directory.

oidParent

Specifies the object identifier of the parent directory.

szDirName

Specifies a null-terminated string that contains the name and path of the directory.
