lineShutdown

The lineShutdown function shuts down the application's usage of the line abstraction of API.

LONG lineShutdown(// tapi.h
HLINEAPP hLineApp// application's usage handle for the line API
);
Parameters
hLineApp
Specifies the application's usage handle for the line API.
Return Values
Returns zero if the request is successful or a negative error number if an error has occurred. Possible return values are:
· LINEERR_INVALAPPHANDLE
· LINEERR_RESOURCEUNAVAIL
· LINEERR_NOMEM
· LINEERR_UNINITIALIZED
Remarks
If this function is called when the application has lines open or calls active, the call handles are deleted and Tapi.dll automatically performs the equivalent of a lineClose on each open line. However, it is recommended that applications explicitly close all open lines before invoking lineShutdown. If shutdown is performed while asynchronous requests are outstanding, those requests will be cancelled.
