RegisterClipboardFormat

The RegisterClipboardFormat function registers a new clipboard format. This format can then be used as a valid clipboard format.

Windows CE Notes Supports only the Unicode version of RegisterClipboardFormat.

UINT RegisterClipboardFormat(// winuser.h
LPCTSTR lpszFormat// address of name string
);
Parameters
lpszFormat
Points to a null-terminated string that names the new format.
Return Values
If the function succeeds, the return value identifies the registered clipboard format. If the function fails, the return value is zero. To get extended error information, call GetLastError.
Remarks
If a registered format with the specified name already exists, a new format is not registered and the return value identifies the existing format. This enables more than one application to copy and paste data using the same registered clipboard format.
Registered clipboard formats are identified by values in the range 0xC000 through 0xFFFF.
