Modifying Address Card Properties

Before modifying an address card's properties, an application must first open the address card and retrieve its current properties. The Contacts API contains two functions for this purpose, OpenAddressCard and GetAddressCardProperties. Both functions fill an AddressCard structure with a given card's properties. OpenAddressCard retrieves all of the card's properties. GetAddressCardProperties retrieves only a specified set of properties. Because the GetAddressCardProperties function allocates less memory, you should use this function whenever possible.

The process of modifying an address card's properties is similar to adding an address card. First, an application modifies members of the AddressCard structure retrieved by OpenAddressCard and GetAddressCardProperties. Next, the application calls the SetMask function once for each property to be modified. Finally, the application passes the AddressCard structure to the ModifyAddressCard function.

When an application finishes modifying address card properties, the FreeAddressCard function should be called to free memory that the system allocated for the address card. For every call to OpenAddressCard and GetAddressCardProperties, there must be a corresponding call to FreeAddressCard.
