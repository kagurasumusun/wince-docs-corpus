LB_GETANCHORINDEX

An application sends an LB_GETANCHORINDEX message to retrieve the index of the anchor item. This message has no parameters.

wParam = 0; // not used, must be zero

lParam = 0; // not used, must be zero

Return Values

The return value is the index of the current anchor item—that is, the item most recently selected by the user pressing a mouse button.

Remarks

In a multiple-selection list box, the anchor item is the first or last item in a block of contiguous selected items.
