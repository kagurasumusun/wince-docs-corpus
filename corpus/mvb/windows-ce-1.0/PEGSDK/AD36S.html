WM_COPY

An application sends the WM_COPY message to an edit control or combo box to copy the current selection to the clipboard in CF_UNICODETEXT format.

wParam = 0; // not used; must be zero

lParam = 0; // not used; must be zero

Return Values

This message does not return a value.

Remarks

When sent to a combo box, the WM_COPY message is handled by its edit control.

This message has no effect when sent to a combo box with the CBS_DROPDOWNLIST style.

See Also
