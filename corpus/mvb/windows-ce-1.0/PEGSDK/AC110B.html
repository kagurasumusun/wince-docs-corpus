NEWCPLINFO

The NEWCPLINFO structure contains resource information and a user-defined value for a dialog box supported by a Control Panel application.

Windows CE Notes For ldata, applications should retrun the icon resource ID for the control panel (same as hIcon, but the resource ID instead of the icon handle.)

typedef struct tagNEWCPLINFO {-  // ncpli

DWORD dwSize;

DWORD dwFlags;

DWORD dwHelpContext;

LONG lData;

HICON hIcon;

TCHAR szName[32];

TCHAR szInfo[64];

TCHAR szHelpFile[128];

} NEWCPLINFO;

Members

dwSize

Specifies the length of the structure, in bytes.

dwFlags

Specifies Control Panel flags.

dwHelpContext

Specifies the context number of a topic in a Help (.hlp) file. This topic is intended to be displayed when the user selects help for the dialog box.

lData

Specifies data defined by the application. Windows CE, applications should return the icon resource ID for the control panel (same as hIcon, but the resources ID instead of the icon handle.)

hIcon

Identifies the icon that represents the dialog box. This icon is intended to be displayed by the application that controls the Control Panel application.

szName

Specifies a null-terminated string that contains the dialog box name. The name is intended to be displayed below the icon.

szInfo

Specifies a null-terminated string containing the dialog box description. The description is intended to be displayed when the icon for the dialog box is selected.

szHelpFile

Specifies a null-terminated string that contains the path of the Help file, if any, for the application.
