Menus and Toolboxes

Menus and toolboxes are combined in a single command bar, found at the top of the window. There are a number of Windows CE-specific functions for dealing with the command bar (see chapter 5, "Command Bars," for more details). You should also refer to the Programmers Reference for a detailed description of these functions (look under CommandBar_*).

In general, menus work much the same as with Windows 95, with the exception that they can be only one level deep. Cascading menus are not supported. If you want the functionality of submenus, you should have your command bring up a dialog box with the appropriate set of choices. Toolbar buttons that include bitmaps must use the 2-bits per pixel (.2bp) format but are otherwise similar to their Windows 95 equivalents.
