PSM_PRESSBUTTON

Simulates the choice of a property sheet button.

wParam = (WPARAM)(int) iButton;

lParam = 0;

// Corresponding macro

BOOL PropSheet_PressButton(

hPropSheetDlg,

iButton

);

Parameters

hPropSheetDlg

Handle of the property sheet.

iButton

Index of button to choose. This parameter can be one of the following values.

ValueMeaning
PSBTN_APPLYNOWChooses the Apply Now button.
PSBTN_BACKChooses the Back button.
PSBTN_CANCELChooses the Cancel button.
PSBTN_FINISHChooses the Finish button.
PSBTN_HELPChooses the Help button.
PSBTN_NEXTChooses the Next button.
PSBTN_OKChooses the OK button.
Return Values
No return value.
