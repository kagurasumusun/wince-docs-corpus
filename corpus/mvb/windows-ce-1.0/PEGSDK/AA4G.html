User Notification States

User notifications exist in either a registered or an active state. From the time an application calls PegSetUserNotification until the time the user is notified, the notification is registered. From the time the user is notified until the user handles the event, the notification is active.

You may think of a registered notification as seen by the system but not yet seen by the user. An active notification is seen by the user but no longer seen by the system. After a notification is handled, it no longer exists.
