PegSHGetShortcutTarget

The PegSHGetShortcutTarget function is the RAPI version of the SHGetShortcutTarget function. For more information about using RAPI functions, please see the Remote API Functions overview.

BOOL PegSHGetShortcutTarget(// rapi.h
LPWSTR IN lpszShortcut,// address of shortcut name
LPWSTR OUT lpszTarget,// address of buffer that receives target pathname
INT IN Arg3
);
Parameters
szShortcut
Pointer to a buffer that contains the name of the shortcut to create.
szTarget
Pointer to a buffer that gets the target path of the shortcut.
cbMax
count in characters to copy
