DB_PEGOID_CHANGED

The DB_PEGOID_CHANGED message is sent when an object in the object store has been modified.

DB_PEGOID_ CHANGED

oidChanged = (PEGOID) wParam; // identifier of modified object

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidChanged

Value of wParam. Identifies the object that was modified.

oidParent

Value of lParam. Identifies the parent object of the modified object.
