MailPut

The MailPut function creates a new mail entry in the message store.

BOOL MailPut (// msgstore.h
HANDLE hService,// Handle to mail context.
MailMsg*pmm// Item information.
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
pmm
Points to the MailMsg structure containing the information for the new entry. The dwMsgID member of the MailMsg structure is ignored by this function.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
Remarks
If this function is successful, the oid member of the MailMsg structure is set with a unique identification number for this mail entry. The oid can be used by other mail functions to reference this entry.
This function is for adding new entries to the message store. To change existing entries, use the MailUpdate function.
