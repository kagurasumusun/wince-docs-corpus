Notes on Running the Windows CE Remote Tools

Basic Procedure

1. On your NT desktop machine, start Remote Access. It should display a small status box indicating that it is waiting for a connection. You will need a null modem cable between the HPC and the selected serial port (user authentication will fail if your cable does not simulate DCD). You need not ever worry about stopping and restarting Direct Cable Connect every time you run a remote application or you reboot the HPC; it automatically goes back to “Waiting....” when disconnected. Direct Cable Connect can be put in your start folder once configured. If you do not have HPC Explorer installled on the desktop PC, read the file Remote.txt, located on the SDK in the \Msdev\Peg directory.

2. On your HPC, start Repllog.exe. Make sure the direct donnection is established and that the HPC confirms that your remote connection to the host PC is authenticated.

Note On the NT desktop machine, make sure that dialin permission is granted for the user that you desire to login as from the HPC.

3. On the NT desktop machine, run the client program (for example, Remote Zoomin, Remote Spy, Remote Registry Editor, and so on). You may start as many Remote Zoomin windows as you like. Only one Remote Spy client can be run at a time, but the Remote Spy client can spawn as many spy windows as needed. If you attempt to bring up an additional Remote Spy client, the current client will simply be restored and activated. The Remote Registry Editor and the Remote Memory Viewer are restricted to one instance in the same way.
