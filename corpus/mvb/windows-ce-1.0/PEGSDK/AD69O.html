TBM_SETRANGE

Sets the range (minimum and maximum positions) for the slider in a trackbar.

wParam = (WPARAM)(BOOL) fRedraw;

lParam = (LPARAM)MAKELONG(lMinimum,lMaximum);

Parameters

fRedraw

Redraw flag. If this parameter is TRUE, the slider is redrawn after the range is set.

lMinimum

Minimum position for the slider.

lMaximum

Maximum position for the slider.

Return Values

No return value.

See Also

TBM_SETRANGEMAX, TBM_SETRANGEMIN
