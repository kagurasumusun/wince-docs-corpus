RasGetEntryProperties

The RasGetEntryProperties function retrieves the properties of a phone book entry.

DWORD RasGetEntryProperties(// // afdfunc.h
LPTSTR lpszPhonebook,// full path and file name of the phone book file
LPTSTR szEntry,// existing entry name
LPBYTE lpbEntry,// receives the connection data associated with the entry
LPDWORD lpdwEntrySize,// size, in bytes, of the buffer specified by lpEntryInfo
LPBYTE lpb,// receives device-specific configuration information
LPDWORD lpdwSize// variable containing the size of the buffer specified by lpb
);
Parameters
lpszPhonebook
Points to a null-terminated string that specifies the full path and file name of the phone book file. This parameter can be NULL, in which case the default phone book file is used. This parameter should always be NULL for Windows 95 and Windows CE since the phone book entries are stored in the registry.
szEntry
Points to a null-terminated string containing an existing entry name. If a "" entry name is specified, structures containing default values are returned.
lpbEntry
Points to a RASENTRY structure that receives the connection data associated with the phone book entry specified by the lpszEntry member followed by any additional bytes needed for the alternate phone number list, if any. On entry, the dwSize member of this structure must specify the size of the structure.
lpdwEntrySize
Points to a variable that contains the size, in bytes, of the buffer specified by lpEntryInfo. On return, the function sets this variable to the number of bytes required. This parameter can be NULL if the information is not required. The recommended method for determining the required buffer size is to call RasGetEntryProperties with lpbEntryInfo set to NULL and the DWORD pointed to by lpdwEntryInfoSize set to zero. The function will return the required buffer size in the DWORD.
lpb
Points to buffer to receive device-specific configuration information. This parameter may be NULL if the data is not required. The recommended method for determining the required buffer size is to call RasGetEntryProperties with lpbDeviceInfo set to NULL and the DWORD pointed to by lpdwDeviceInfoSize set to zero. The function will return the required buffer size in the DWORD.
lpdwSize
Points to a variable that contains the size, in bytes, of the buffer specified by lpb. On return, the function sets this variable to the number of bytes required. This parameter can be NULL if the information is not required.
Return Values
If the function succeeds, the return value is zero. If the function fails, the return value can be one of the following error codes.
Error Code		Description
ERROR_INVALID_PARAMETERThe function is called with an invalid parameter.
ERROR_BUFFER_INVALIDThe address or buffer specified by lpbEntryInfo is invalid.
ERROR_BUFFER_TOO_SMALLThe buffer size indicated in lpdwEntryInfoSize is too small.
ERROR_CANNOT_OPEN_PHONEBOOKThe phone book is corrupted or missing components.
ERROR_CANNOT_FIND_PHONEBOOK_ENTRYThe phone book entry does not exist.
