DestroyPropertySheetPage

The DestroyPropertySheetPage function destroys a property sheet page for the handle returned from CreatePropertySheetPage. An application must call this function for pages that have not been passed to the PropertySheet function.

BOOL DestroyPropertySheetPage(// prsht.h
HPROPSHEETPAGE hPSPage// handle of the property sheet page to delete
);
Parameters
hPSPage
Handle of the property sheet page to delete.
Return Values
Returns TRUE if success or FALSE otherwise.
