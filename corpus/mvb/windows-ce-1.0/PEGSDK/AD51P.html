TCM_SETIMAGELIST

The TCM_SETIMAGELIST message assigns an image list to a tab control. You can send this message explicitly or by using the TabCtrl_SetImageList macro.

wParam = 0; // not used; must be zero

lParam = (LPARAM)(HIMAGELIST) himl; // handle of image list to assign

// to tab control

// Corresponding macro

BOOL TabCtrl_SetImageList(

HWND hwnd,

HIMAGELIST himl

);

Parameters

hwnd

Handle to the tab control.

himl

Handle of the image list to assign to the tab control.

Return Values

Returns the handle to the previous image list or NULL if there is no previous image list.
