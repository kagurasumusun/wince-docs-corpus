Memory Management

Memory Pages

The Windows CE operating system has virtual memory, which means that memory is always allocated at the granularity of a page. The size of a page varies from architecture to architecture, and can be anywhere from 1K to 4K bytes. Because an average of a half page is likely to be wasted in any independent memory section, a larger page size implies more wasted space than a smaller page size. A smaller page size requires more operating system overhead in order to keep track of pages. It also decreases the amount of memory that can be addressed from the translation lookaside buffer (TLB)-potentially reducing its effectiveness.

Since RAM usage is our biggest concern, we are currently trying to bring the page size down as close to 1K as possible. In general, you should assume a 1K page size when making memory allocation decisions.
