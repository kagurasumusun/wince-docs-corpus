DTM_ENABLESHRINK

An application sends a DTM_ENABLESHRINK message to command the HTML control to toggle the image shrink enable mode. If shrink is enabled, the HTML control will shrink images as required to make the page fit the window.

wParam = 0, // not used, must be zero

lParam = (LPARAM)(BOOL) bEnableShrink; // enables the shrink enable

Parameters

bEnableShrink

Indicates whether to enable shrink. If bEnableShrink is TRUE, shrink is enabled. If bEnableShrink is FALSE, shrink is not enabled.

Return Values

This message does not return a value.
