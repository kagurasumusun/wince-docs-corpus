RasGetConnectStatus

Get connection status.

DWORD RasGetConnectStatus(//afdfunc.h
HRASCONN hRasConn,// handle of RAS connection
LPRASCONNSTATE pRasConnStatus// connection status information
);
Parameters
hRasConn
Handle of RAS connection.
pRasConnStatus
Pointer to a structure in which to return connection status information.
Return Values
If the function succeeds the return value is zero; else an error from Raserror.h is returned.
Error Code		Description
ERROR_INVALID_PARAMETERInvalid hRasConn or pRasConnStatus parameter.
