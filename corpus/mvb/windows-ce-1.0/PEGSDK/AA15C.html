Low Memory Manifestations

A low memory condition can manifest itself to the application in the following ways:

· A call to the VirtualAlloc function can fail.

· The LocalAlloc or HeapAlloc function may attempt to grow its heap, but fail to do so.

· The stack might need to grow, but may not be able to.

The first two manifestations cause failures to be returned in an orderly fashion. They can occur as a result of a direct call by the application, or indirectly as a result of a call to a function such as CreateWindow. The third manifestation is more severe, and will cause the process to wait for a free page.
