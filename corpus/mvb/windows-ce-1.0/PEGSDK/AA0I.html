Serial Communication

Windows CE Serial Communication API

The folllowing serial devices are available on the Handheld PC (HPC):

· Built-in serial port

· Built-in infrared (IR) port

· Serial device PC Card

HPC serial devices are accessed using file system functions such as those listed below.

FunctionDevice Application
CreateFileOpen (get a handle to) a device.
CloseHandleClose (the handle to) a device.
ReadFileRead data from the device.
WriteFileWrite data to the device.
SetFilePointerAn application calls this function to move the data pointer in the PCMCIA serial device (that is, does a data “seek”)
DeviceIoControlAn application calls this function to specify an I/O control operation to be performed.
The operating system loads a serial driver that supports the built-in serial and built-in IR devices. If a serial (modem-type) device PC Card is inserted into the PCMCIA slot, the operating system will load the serial driver for the PC Card. The HPC serial devices are referenced as shown in the table below.
Device Name		Physical Device
COM1:Built-in serial device
COM2:PC Card slot
COM3:Built-in infrared (IR) device
Note To use the IR device, you must call CreateFile using “COM1:” and then call EscapeCommFunction with dwFunc set to SETIR. See the topic “Using the Built-In IR Port.”
