LVM_SETIMAGELIST

Assigns a new image list to a list view control. You can send this message explicitly or by using the ListView_SetImageList macro.

wParam = (WPARAM)(int) iImageList;

lParam = (LPARAM)(HIMAGELIST) himl;

// Corresponding macro

HIMAGELIST ListView_SetImageList(

HWND hwnd,

HIMAGELIST himl,

int iImageList

);

Parameters

hwnd

Handle of the list view control.

himl

Handle of the image list to assign.

iImageList

Type of image list. This parameter can be one of the following values.

ValueMeaning
LVSIL_NORMALImage list with large icons
LVSIL_SMALLImage list with small icons
LVSIL_STATEImage list with state images
LVSIL_HEADERImage list for use with report view header
Return Values
Returns the handle of the previous image list, or NULL if the list view control has no image list.
