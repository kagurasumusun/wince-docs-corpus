ERRORMSG

Output an error message.

BOOL ERRORMSG(
BOOL cond,
(printf_exp)
);
Parameters
cond
The condition under which the message is printed.
(printf_exp)
A printf-style expression to be output. Must be enclosed in parentheses. This is passed in to the NKDbgPrintf function.
Remarks
Very similar to RETAILMSG except that this will prefix the message with a big bold ERROR and also give the file name and line number of the error.
Example
ERRORMSG(x==y, (L"Sample: Problem. x==y = %d\r\n", x==y));
See Also
DEBUGMSG, RETAILMSG, NKDbgPrintf
