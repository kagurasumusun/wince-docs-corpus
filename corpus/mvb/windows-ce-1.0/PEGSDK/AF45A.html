INDEXTOOVERLAYMASK

Prepares the index of an overlay mask so that the ImageList_Draw or ImageList_DrawEx function can use it.

UINT INDEXTOOVERLAYMASK(
UINT iOverlay
);
Parameters
iOverlay
Index of an overlay mask.
Remarks
The INDEXTOOVERLAYMASK macro is defined as follows:
#define INDEXTOOVERLAYMASK(i) ((i) << 8)
See Also
ImageList_Draw, ImageList_DrawEx, ImageList_SetOverlayImage
