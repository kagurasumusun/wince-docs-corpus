RecountCards

The RecountCards function causes the system to recount the number of address cards in the Contacts database.

void RecountCards( );// addstor.h
Parameters
This function has no parameters
Return Values
This function has no return value.
Remarks
Your application must call this function if another application modifies the Contacts database while your application has it open. The system notifies your application of such a modification by sending the DB_PEGOID_CHANGED, DB_PEGOID_CREATED, or DB_PEGOID_RECORD_DELETED message to the window specified in the OpenAddressBook function.
