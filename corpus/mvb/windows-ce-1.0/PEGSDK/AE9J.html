TVN_BEGINRDRAG

Notifies a tree view control's parent window about the initiation of a drag and drop operation involving the right mouse button. This notification message is sent in the form of a WM_NOTIFY message.

pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv

Address of an NM_TREEVIEW structure. The itemNew member is a TV_ITEM structure that contains valid information in the hItem, state, and lParam members about the item to be dragged. The ptDrag member specifies the current screen coordinates of the mouse.

Return Values

No return value.
