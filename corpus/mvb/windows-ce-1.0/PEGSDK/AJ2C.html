What's New in Visual C++ 4.0 for Windows CE

Overview: What is Visual C++ for Windows CE?

Microsoft Visual C++ 4.0 for Windows CE is:

· A special edition of the Microsoft Developer Studio, customized for Windows CE project development

· Visual C++ version 4.0, enhanced with packages for simultaneous cross-development onto multiple Windows CE platforms

· A new Integrated Cross-Development Environment for embedded programming

You can now develop embedded programs for Handheld PCs (HPC) while working within the same integrated environment that supports development of Win32 applications.
