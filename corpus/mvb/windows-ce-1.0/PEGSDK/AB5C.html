CharLowerBuff

The CharLowerBuff function converts uppercase characters in a buffer to lowercase characters. The function converts the characters in place.

Windows CE Notes Supports only the Unicode version of this function.

DWORD CharLowerBuff(// winbase.h
LPTSTR lpsz,// pointer to buffer containing characters to process
DWORD cchLength// number of bytes or characters to process
);
Parameters
lpsz
Pointer to a buffer containing one or more characters to process.
cchLength
Specifies the size, in characters, of the buffer pointed to by lpsz.
The function examines each character, and converts uppercase characters to lowercase characters. The function examines the number of characters indicated by cchLength, even if one or more characters are null characters.
Return Values
If the function succeeds, the return value is the number of characters processed. For example, if CharLowerBuff("Acme of Operating Systems", 10) succeeds, the return value is 10.
