mkdir

mkdir dir

The mkdir statement creates a directory in the HPC file system.

Parameters

dir

Specifies the name of the directory to create.

Remarks

The new directory is created within the directory specified by the loaddir command-line argument of the Load function, unless the dir parameter begins with a backslash (\).

The directory is added to the unload script. When the user runs the unload script, the directories in the unload script are removed from the HPC.
