TimerProc

The TimerProc function is an application-defined callback function that processes WM_TIMER messages.

void CALLBACK TimerProc(// winuser.h
HWND hwnd,// handle of window for timer messages
UINT uMsg,// WM_TIMER message
UINT idEvent,// timer identifier
DWORD dwTime// current system time
);
Parameters
hwnd
Identifies the window associated with the timer.
uMsg
Specifies the WM_TIMER message.
idEvent
Specifies the timer's identifier.
dwTime
Specifies the system time, in Coordinated Universal Time (UTC) format.
Return Values
This function does not return a value.
Remarks
TimerProc is a placeholder for the application-defined function name.
See Also
KillTimer, SetTimer, WM_TIMER
