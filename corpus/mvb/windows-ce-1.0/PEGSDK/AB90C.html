CommandBar_AddToolTips

The CommandBar_AddToolTips function adds tooltip strings to a command bar. A tooltip control is a small pop-up window that displays a line of descriptive text giving the purpose of a button in a command bar. Only command-bar buttons can have tooltip strings; menus and combo boxes cannot.

BOOL CommandBar_AddToolTips(// commctrl.h
HWND hwndCB,// handle of command bar
UINT uNumToolTips,// number of tooltip strings to add
LPTSTR lpToolTips// pointer to array of tooltip strings
);
Parameters
hwndCB
Handle identifying the command bar. This handle is returned when the command bar is created by the CommandBar_Create function.
uNumToolTips
Specifies the number of tooltip strings in the array specified by the lpToolTips parameter.
lpToolTips
Points to an array of strings to be shown when the tooltip control is active. The array must contain the same number of elements as specified by the uNumToolTips parameter.
Return Values
If the function succeeds, the return value is TRUE; otherwise, it is FALSE.
