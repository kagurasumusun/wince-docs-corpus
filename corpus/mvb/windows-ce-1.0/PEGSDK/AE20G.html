PSN_QUERYCANCEL

Indicates that the user chose the Cancel button. This notification message is sent in the form of a WM_NOTIFY message.

lpnmhdr = (NMHDR FAR *) lParam;

Parameters

lpnmhdr

Address of an NMHDR structure. The hwndFrom member is the handle of the property sheet, and the hwndTo member is the handle of the page.

Return Values

Returns TRUE to prevent the cancel operation or FALSE to allow it.

Remarks

A property sheet page can use this notification message to ask the user to verify the cancel operation.
