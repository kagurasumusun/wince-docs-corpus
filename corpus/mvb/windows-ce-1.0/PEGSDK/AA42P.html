<FORM>

Create a form object used to delimit a data input form. Forms can not be nested.

ACTION

The URL to submit the form. This will be included in the form structure. If the action value is missing, then assume the URL of the document itself.

METHOD

The METHOD attribute selects variations in the protocol.

GET or POST. The default is GET. This will be a flag in the form structure, which will be passed to the application if the form is ever submitted.

ENCTYPE (Ignored in V1.0)

A mime type for the encoding of the form data. This attribute specifies the format of the submitted data in case the protocol does not impose a format itself.
