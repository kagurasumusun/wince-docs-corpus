CommandBar_Height

The CommandBar_Height function retrieves the number of visible pixels in height of a command bar.

int CommandBar_Height(// commctrl.h
HWND hwndCB// handle of command bar
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
Return Values
The return value is the visible height, in pixels, of the of the command bar.
Remarks
Because the command bar occupies part of the client area of an application's main window, it is necessary to call this function to determine the true top of the client area.
