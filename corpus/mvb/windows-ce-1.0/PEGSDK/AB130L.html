PegGetStoreInformation

The PegGetStoreInformation is the RAPI version of GetStoreInformation. For more information about using RAPI functions, please see the Remote API Functions overview.

BOOL PegGetStoreInformation(// rapi.h
LPSTORE_INFORMATION OUT lpsi// pointer to STORE_INFORMATION structure to be filled
);
Parameters
lpsi
Points the a STORE_INFORMATION structure to be filled in by this function.
Return Values
