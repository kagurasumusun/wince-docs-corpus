How to Set Up Remote Access Service

How to Set Up RAS

1. From the Start button in NT4.0 choose Settings, then Control Panel

2. Double-click on "Network"

3. Select the "Services" tab

4. If "Remote Access Service" is not listed:

· Press "Add"

· In the listbox, select "Remote Access Service"

· Press "OK"

· The "Windows NT Setup" dialog will appear, asking the location to the drive and directory where your NT disks/CD-ROM are located

· Your NT disks/CD-ROM will be required here, as RAS will now be installed

5. In the "Network Services" listbox, select "Remote Access Service" and press "Properties"

6. If the COM port you wish to use is displayed in the listbox, you will need to remove it. Select the COM port, press "Remove", and then "Yes" to confirm

7. In the "Remote Access Setup" dialog, press "Add"

8. Press "Install Modem", and set the "don't detect my modem; I will select it from a list" checkbox to TRUE, and press "Next". This may take a while, since a list of all supported modems is loaded

9. In the "Manufacturers" list select "Standard modem types" and in the "Models" list, select "Dial-Up Networking Serial Cable between 2 PCs", and press "Next"

10. Select the "Selected ports" radio button, and select the COM port you will use (eg. COM1 or COM2) to connect to the device, and press "Next"

11. Take note of any warning or informational messages that may pop up

12. If a "Location information" dialog pops up, type any 3-digit number in the "area code" (eg. 206), and press "Next"

13. Continue by pressing "Finish", and then affirmatively exiting all the dialog boxes, until you reach the "Add RAS Device" dialog

14. The dropdown list should now contain the port that we have just configured. Select the port, and press "OK". On some builds of NT, the dropdown list may not display the port that was just added. If it does not, repeat steps 8-14. Eventually, NT will detect the modem.

15. In the "Remote Access Setup" dialog, select the port that we have just configured, and press "Configure"

16. Select "Receive calls only" radio button, and press "OK"

17. In the "Remote Access Setup" dialog, press "Network"

18. In the "Server Settings" group, set the "TCP/IP" checkbox to TRUE. If you have no other modem previously 8) installed, then make sure the other checkboxes are cleared. Otherwise, leave the other checkboxes as they were

19. Press the "Configure" button for "TCP/IP"

20. Select the "This computer only" radio button

21. Select the "Use static address pool" radio button, and for "Begin", enter "192.100.1.99" for "End", enter "192.100.1.205"

22. Make sure the "Allow remote clients to request a predetermined IP address" is cleared

23. Continue by affirmatively exiting all the dialog boxes, and press "Close" when you reach the "Network" dialog.

24. If a "Microsoft TCP/IP Properties" dialog pops up, press "OK"

25. When a message box pops up asking to restart your computer, select "No", because HPC Explorer Setup must still configure RAS further. Go back to HPC Explorer Setup, and press "Next"
