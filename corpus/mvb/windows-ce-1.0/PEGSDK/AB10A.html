AddAddressCard

The AddAddressCard function adds an address card to the Contacts database. Before calling this function, an application must call the SetMask function once for each property in the new address card.

BOOL AddAddressCard(// addstor.h
AddressCard *pac,// address of structure with card information
PEGOID *poidCard,// address of variable for object identifier
int *pindex// address of variable for position index
);
Parameters
pac
Points to the AddressCard structure that contains the address card information to be added.
poidCard
Points to a variable that receives the object identifier of the new address card.
pindex
Points to a variable that receives the position index of the new address card. The index is relative to the beginning of the database and is based on the current sort order.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
The Contacts database must have been opened by a previous call to the OpenAddressBook function.
