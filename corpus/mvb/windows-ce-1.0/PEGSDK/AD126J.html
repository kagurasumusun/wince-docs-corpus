LVM_SCROLL

Scrolls the content of a list view control. You can send this message explicitly or by using the ListView_Scroll macro.

wParam = 0;

lParam = MAKELPARAM((int) dx, (int) dy);

// Corresponding macro

BOOL ListView_Scroll(

HWND hwnd,

int dx,

int dy

);

Parameters

hwnd

Handle of the list view control.

dx and dy

Amount of horizontal and vertical scrolling, in pixels. If the current view is report view, dx must be zero and dy is the number of lines to scroll.

Return Values

Returns TRUE if successful or FALSE otherwise.
