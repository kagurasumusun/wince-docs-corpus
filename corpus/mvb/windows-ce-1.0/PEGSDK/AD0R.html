UDM_GETACCEL

Retrieves acceleration information for an up-down control.

wParam = (WPARAM) cAccels;

lParam = (LPARAM)(LPUDACCEL) paAccels;

Parameters

cAccels

Number of elements in the array specified by paAccels.

paAccels

Address of an array of UDACCEL structures that receives acceleration information.

Return Values

Returns the number of accelerator structures retrieved.

See Also

UDACCEL, UDM_SETACCEL
