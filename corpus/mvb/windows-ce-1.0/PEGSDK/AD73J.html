LVM_GETITEMSTATE

Retrieves the state of a list view item. You can send this message explicitly or by using the ListView_GetItemState macro.

wParam = (WPARAM)(int) i;

lParam = (LPARAM)(UINT) mask;

// Corresponding macro

UINT WINAPI ListView_GetItemState(

HWND hwnd,

int i,

UINT mask

);

Parameters

hwnd and i

Handle of the list view control, and the index of the list view item.

mask

Mask that specifies which of the item's state flags to return.

Return Values

Returns the item's state flags.
