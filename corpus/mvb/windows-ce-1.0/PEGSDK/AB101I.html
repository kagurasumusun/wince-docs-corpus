ImageList_ReplaceIcon

The ImageList_ReplaceIcon function replaces an image with an icon or cursor.

int WINAPI ImageList_ReplaceIcon(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iReplace,// index of the image to replace
HICON hicon// handle containing the bitmap and mask for the new image
);
Parameters
himl
Handle of the image list
iReplace
The index of the image to replace. If iReplace is set to –1, hicon is appended to himl.
hicon
Handle of the icon or cursor that contains the bitmap and mask for the new image.
Return Values
Returns the index of the image if successful or –1 otherwise.
Remarks
You do not need to destroy hicon if it was loaded by the LoadIcon function; the system automatically frees an icon resource when it is no longer needed.
