Overview of Windows CE Programming for Hand-Held PCs

This book is designed for programmers familiar with the C programming language and the Microsoft® Windows® 95 programming model. While this book provides an overview of the concepts used in Windows-based programming, it assumes some expertise on the part of the reader. For a more comprehensive look at Windows 95 and Windows 95 programming we suggest you read Charles Petzold, Programming Windows 95, Redmond, Wash.: Microsoft Press, 1996.
