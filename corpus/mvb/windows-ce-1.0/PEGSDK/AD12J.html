LVM_DELETEITEM

Removes an item from a list view control. You can send this message explicitly or by using the ListView_DeleteItem macro.

wParam = (WPARAM)(int) iItem;

lParam = 0;

// Corresponding macro

BOOL ListView_DeleteItem(

HWND hwnd,

int iItem

);

Parameters

hwnd and iItem

Handle of the list view control, and the index of the list view item to delete.

Return Values

Returns TRUE if successful or FALSE otherwise.
