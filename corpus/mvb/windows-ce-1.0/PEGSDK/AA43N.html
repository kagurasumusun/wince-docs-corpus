TransportInit

BOOL TransportInit (
HANDLE *NewService,// New Service handle
LPWSTR szCommonKey,// Top-level registry key
LPWSTR szTransportKey,// Registry key for this transport
);
The TransportInit function takes a pointer to a service handle and initializes internal data for the service.
Parameters
NewService
A service handle that is returned by TransportInit.
szCommonKey
Top level registry key (for example, HLM\PMail\ServiceLibs).
szTransportKey
Registry key for this transport (for example, HLM\PMail\ServiceLibs\SAMPLE).
Return Value
Value		Description
FALSEThe initialization failed. For example, NewService was not a valid pointer, or the heap allocation of the SERVICE structure failed.
TRUESuccess.
