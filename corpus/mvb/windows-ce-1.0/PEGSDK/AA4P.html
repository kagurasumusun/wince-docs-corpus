Components

When you create Help for a Windows CE-based program, two kinds of files are needed: a contents or .hpc file (one for each application) that contains jumps to all the topics files or .htp’s that contain the help information.

Things to know before you begin:

· Contents topic files have an .htc extension.

· Each topic is a separate file with an .htp extension.

· All .htc files should be in the Windows folder.

· All .htp files and .2bp files may be in the Windows folder.

If .htp files are in another folder, the full path must be specified in the <file> attribute and in the <title>, <a>, and <img src> tags. The examples in this document assume that all files are stored in the Windows folder.

Topics are authored in HTML. Pocket Help supports a subset of HTML tags. This section will cover a few of the standard tags that you will use in each file. For a complete list of supported tags please see the Pocket Help HTML Reference.
