copy

copy sourceDir destinationDir file

The copy statement copies a file from the desktop PC to the HPC.

Parameters

sourceDir

Specifies the directory on the desktop PC that contains the files to be copied. The specified directory is relative to the install directory. This argument can be a period (.) to indicate that the source files are to be copied from the install directory on the desktop PC.

destinationDir

Specifies the directory on the HPC that receives the files being copied. This parameter can specify an absolute or relative path.

To specify an absolute path this parameter must start with a backslash (\) to indicate the root directory followed by the complete path. This command will fail if the specified directory does not already exist on the HPC.

To specify a relative path this parameter can be a period (.). This indicates the source files are to be copied to the load directory on the HPC. The load directory is specified by the install_directory argument of the Load function’s command line parameter.

file

Specifies the name of the file to copy.

Remarks

If a destination file already exists, this statement displays a message box asking whether to overwrite the file.

The copied file is added to the unload script. When the user runs the unload script, the files in the unload script are removed from the HPC.
