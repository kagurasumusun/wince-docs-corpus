ImageList_SetIconSize

The ImageList_ SetIconSize function sets the dimensions of images in an image list and removes all images from the list.

BOOL WINAPI ImageList_SetIconSize(// commctrl.h
HIMAGELIST himl,// handle of the image list
int cx,// width of the images in the image list
int cy// height of the images in the image list
);
Parameters
himl
Handle of the image list.
cx and cy
Width and height, in pixels, of the images in the image list. All images in an image list have the same dimensions.
Return Values
Returns TRUE if successful or FALSE otherwise.
