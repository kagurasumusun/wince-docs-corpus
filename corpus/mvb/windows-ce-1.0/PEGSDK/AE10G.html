PSN_HELP

Notifies a page that the user has chosen the Help button. This notification message is sent in the form of a WM_NOTIFY message.

lpnmhdr = (NMHDR FAR *) lParam;

Parameters

lpnmhdr

Address of an NMHDR structure. The hwndFrom member is the handle of the property sheet, and the hwndTo member is the handle of the page.

Return Values

No return value.

Remarks

An application should display help information for the page.
