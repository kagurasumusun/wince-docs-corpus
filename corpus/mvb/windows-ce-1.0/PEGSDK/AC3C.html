PEGBLOB

The PEGBLOB structure contains information about a BLOB of data in the object store.

typedef struct _PEGBLOB {-  // pegblob

DWORD dwCount;

LPBYTE lpb;

} PEGBLOB;

Members

dwCount

Specifies the size, in bytes, of the BLOB.

lpb

Points to the beginning of the BLOB.
