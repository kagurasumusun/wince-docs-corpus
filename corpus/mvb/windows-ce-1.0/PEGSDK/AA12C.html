Map Files

The map file is useful for analyzing the static sections. At the top of the map file you will find the length of each section. The R/W data section is composed of two subsections: .data, which consists of all initialized global data, and .bss, which consists of uninitialized data (initialized to zero by the loader). You should also look at the read-only section, .rdata.

Make sure you understand what data is using your module's memory. Note the section number (typically 2 for R/W). You can then look in the symbols part of the map file to see exactly what is in this section and how much space each item uses. To calculate, for instance, the total amount of memory that will be taken up by R/W, add the amount needed by .data and .bss and round up the next multiple of the page size.
