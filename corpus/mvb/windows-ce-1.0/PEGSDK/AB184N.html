SetMask

The SetMask function tells the system which properties are present in an address card, enabling the system to save the property in the object store. Before calling the AddAddressCard or ModifyAddressCard function, an application must call SetMask once for each property in the new or modified address card.

void SetMask(// addrstor.h
AddressCard *pac,
// address of structure with address card data
HHPRTAG hhProp// property tag
);
Parameters
pac
Points to an AddressCard structure that contains information about an address card.
hhProp
Specifies the property tag of a property in the address card. Refer to Properties and Property Tags in the Contacts Database guide chapter for a list of these tags. Property tags begin with the HHPR_ prefix. If this parameter is zero, the function marks all properties as present.
