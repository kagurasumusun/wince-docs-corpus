INLINEIMAGEINFO

The INLINEIMAGEINFO structure is sent in the DTM_SETIMAGE message from the application to the HTML control.

typedef struct tagINLINEIMAGEINFO {-
DWORD   dwCookie;       // Cookie value from NM_INLINE_IMAGE message

int iOrigHeight; // The original height of the image

int iOrigWidth; // The original width of the image

HBITMAP hbm; // Handle to the Bitmap of the image

BOOL bOwnBitmap; // Flag to indicates whether the HTML

// control should destroy the bitmap.

} INLINEIMAGEINFO, *LPINLINEIMAGEINFO;

Members

dwCookie

Cookie value passed in the dwCookie field of the NM_HTMLVIEW structure when an NM_INLINE_IMAGE notification message is received from the HTML control.

iOrigHeight

Original height of the image.

iOrigWidth

Original width of the image.

hbm

Handle to the bitmap of the image..

bOwnBitmap

If bOwnBitmap is set to TRUE, the HTML Control will destroy the bitmap when the page is destroyed. If bOwnBitmap is set to FALSE, the HTML control will not destroy the bitmap.
