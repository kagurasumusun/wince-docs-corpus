HDN_TRACK

Notifies a header control's parent window that the user is dragging a divider in the header control. This notification message is sent in the form of a WM_NOTIFY message.

phdr = (HD_NOTIFY FAR *) lParam;

Parameters

phdr

Address of an HD_NOTIFY structure that contains information about the header control and the item whose divider is being dragged.

Return Values

Returns FALSE to continue tracking the divider or TRUE to end tracking.

See Also

HD_NOTIFY, HDN_BEGINTRACK, HDN_ENDTRACK, WM_NOTIFY
