GetAddressCardOid

The GetAddressCardOid function retrieves the object identifier of an address card in the Contacts database.

PEGOID GetAddressCardOid(// addrstor.h
int nCard// index of address card
);
Parameters
nCard
Specifies the position index of the address card. The index is relative to the beginning of the database and is based on the current sort order.
Return Values
Returns the object identifier of the address card, or zero if the card was not found.
Remarks
The function starts at the beginning of the database and seeks until finding the record at the position specified by nCard.
The Contacts database must have been opened by a previous call to the OpenAddressBook function. This function fails if no sort order was specified when the address book was opened.
