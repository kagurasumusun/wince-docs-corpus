TAPI

Introduction to TAPI for Windows CE

The Win32 telephony application programming interface (TAPI), provides a means for applications to take advantage of a wide range of sophisticated communications features and telephone services, while making their specific technologies transparent. Win32 TAPI consists of a set of constant definitions, data structures, functions, messages, and callback procedures. Due to the nature of the device, functions used for controlling and monitoring phone devices are not needed for Windows CE and are therefore unsupported. The Windows CE operating system implements TAPI, version 1.5. It provides only the basic tools applications need for simple outbound dialing and address translation.

Windows CE TAPI is implemented and managed by two dynamic-link libraries, Tapi.dll and Unimodem.dll. These libraries provide a device-independent interface for carrying out telephony tasks. When an application calls a TAPI function the library processes the call and routes the request to the appropriate telephony service provider (TSP). To receive requests from the TAPI dynamic-link library, the TSP must implement the telephony service provider interface (TSPI). The TSPI is beyond the scope of this book. For general information about service providers and TSPI, see the Microsoft Win32 Telephony Service Providers Reference.
