CommandBar_AddBitmap

The CommandBar_AddBitmap function adds a bitmap that contains button images to a command bar. The dimensions of each button image should be 16 ´16 pixels.

int CommandBar_AddBitmap(// commctrl.h
HWND hwndCB,// handle of command bar window
HINSTANCE hInst,// handle of module instance with bitmap
int idBitmap,// identifier of bitmap resource
int iNumImages,// number of images in bitmap
int iReserved,// reserved
int iReserved// reserved
);
Parameters
hwndCB
Handle identifying the command bar. This handle is returned when the command bar is created by the CommandBar_Create function.
hInst
Identifies the module instance with the executable file that contains a bitmap resource. You can add the system-defined button bitmaps by specifying HINST_COMMCTRL as the hInst parameter and one of the following values as the idBitmap parameter.
Value		Meaning
IDB_STD_SMALL_COLORAdds small, color standard bitmaps.
IDB_VIEW_SMALL_COLORAdds small, color view bitmaps.
idBitmap
Specifies the identifier of the bitmap resource that contains the button images. If hInst is NULL, this parameter must be the handle to a bitmap that contains the button images.
iNumImages
Specifies the number of button images in the bitmap.
Return Values
If the function succeeds, the return value is the index of the first new image. If the function fails, the return value is –1.
