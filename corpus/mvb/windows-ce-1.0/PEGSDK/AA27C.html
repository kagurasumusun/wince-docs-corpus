The Recycle Bin and Backup Files

The Recycle Bin is a useful way to allow users to change their mind about deleting files. However, placing a file in the Recycle Bin does not change memory usage until the bin is emptied by the user. Use the Recycle Bin sparingly. You may wish to provide your users with the option of placing in the Recycle Bin or deleting entirely, if memory resources are becoming tight.

Automatically creating backup files also provides a way to protect your users against unintentional data loss. They do take up extra space however. Whether or not backup files are automatically generated is generally part of the application's configuration, and must be changed manually by the user (by going to the Tools/Options menu, for instance). You may wish to prompt your users if memory is becoming tight, and offer the option of turning off automatic backups.
