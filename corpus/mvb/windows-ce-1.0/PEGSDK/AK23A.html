Remote Connection Server

The Remote Connection Server (Rsdkmon.exe) is used to start a connection with the HPC. It will start Dccman.exe, which will start the desktop PC Remote Access Service (RAS) connection. The remote connection server also keeps Dccman from disconnecting. The remote connection server essentially acts as a communication placeholder that acts just like any other of the remote client tools. That is, it basically is just an empty remote client “template”.

To kill the remote connection, click the icon located in the task bar tray. (The icon is a small, green symbol next to the clock in the task bar tray.)
