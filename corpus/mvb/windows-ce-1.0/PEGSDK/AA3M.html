Mail Folders

The message store is divided into folders for organizing messages. The folders are arranged in a flat hierarchy; sub-folders are not supported. There are built-in folders including inbox, outbox, and sent-items folders, as well as user-defined local folders. The built-in folders cannot be renamed or deleted and are used for specific functions. The following is a short description of each folder type:

· Inbox. The inbox is used to store all incoming messages regardless of the delivery service.

· Outbox. The outbox stores messages set to be sent, until the service is connected and the messages are actually sent.

· Sent-Items. The sent-items folder stores a copy of sent messages.

· User-Defined. Users can create up to 21 other folders for storing messages on the device. These folders can use up to 31 characters for their name.

Microsoft Inbox also gives the appearance of having a folder for deleted messages. This is actually done by setting a flag. Messages marked as deleted remain in their respective folders, but are hidden from the user. The pseudo-folder for deleted items displays messages from all folders that have the deleted flag set. One advantage to using this technique is that if a message is undeleted it shows up back in the proper folder.
