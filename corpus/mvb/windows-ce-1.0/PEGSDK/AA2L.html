Sample Conversions

File formats used by the Windows CE operating system and Windows CE-based applications are generally different than those of the corresponding Windows-based applications. For example, Pocket Word does not support OLE compound files. HPC Explorer automatically adjusts file formats as files are transferred between the PC and the HPC. Some of the common filters provided with HPC Explorer include:

· Windows bitmap (.bmp) to Windows CE monochrome bitmap (.2bp)

· Windows icon (.ico) to Windows CE monochrome icon (.ic2)

· Pocket Excel (.pxl) to Excel 5.0 (.xls)

· Excel 5.0 (.xls) to Pocket Excel (.pxl)
