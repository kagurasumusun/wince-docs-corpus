HTML Viewer Control

About HTML Viewer Control for Windows CE

The Hypertext Markup Language (HTML) Viewer Control interface for Windows CE provides, for example, the capabilities needed to implement the Windows CE Pocket Internet Explorer and the Help engine. It also provides Independent Software Vendors (ISVs) the ability to implement additional viewers, based on the HTML Viewer control.

For example, the Pocket Internet Explorer application, the HTML Viewer Control, and system support consist of an application (Webview.exe) and a dynamic link library (Htmlview.dll). Webview.exe provides the user interface and the interpretation and data retrieval of Uniform Resource Locators (URLs). It also determines the type of data to be presented. The HTML viewer provides a viewer for the data in the case where the data is of type HTML. If a type other than HTML is determined, other viewers may be invoked. An individual URL may result in many viewers being invoked. For example, an HTML source may include a reference to data of other types, thus invoking an alternative viewer.

This chapter discusses the interface between the HTML Viewer Control DLL and another viewer application. The Windows CE HTML Viewer Control interface consists of the following basic components:

· An initialization function (InitHTMLControl) implemented in the HTML Control library Htmlview.dll. This registers the DISPLAYCLASS window class.HTML Control Functions Summary

Windows CE HTML Viewer Control is implemented in the dynamic-link library Htmlview.dll. This library provides the interface that allows an application to view HTML files; this interface is defined by the header file Htmlctrl.h, located on the SDK in the directory \Msdev\Peg\Include. An application loads the HTML Viewer library, initializes the HTML Control, and creates a window based on the HTML Viewer window class named DISPLAYCLASS. In order to perform the various viewer functions, the application sends messages to the callback function registered in the HTML Viewer window class.
Note that the HTML Control interface is not implemented using COM interfaces.
