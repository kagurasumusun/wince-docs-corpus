LB_GETTOPINDEX

An application sends an LB_GETTOPINDEX message to retrieve the index of the first visible item in a list box. Initially the item with index zero is at the top of the list box, but if the list box contents have been scrolled another item may be at the top. This message has no parameters.

wParam = 0; // not used, must be zero

lParam = 0; // not used, must be zero

Return Values

The return value is the index of the first visible item in the list box.
