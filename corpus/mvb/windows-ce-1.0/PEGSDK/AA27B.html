Floating Point Underflow

The underflow exception is raised in all IEEE specified cases. Denormal numbers are fully supported. Flushing denormal results to zero is not supported (thus, _EM_DENORMAL is not supported).

Tininess is detected after rounding. This has the effect of slightly reducing the number of underflow exceptions. Loss-of-accuracy is defined to be the same as inexact result. This removes the need for an additional check for denormalization loss, since inexact result is already required to support the corresponding status flag.
