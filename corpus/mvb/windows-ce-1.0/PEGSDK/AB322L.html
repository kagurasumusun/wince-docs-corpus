PropSheetProc

Specifies an application-defined callback function that the system calls when the property sheet is being initialized.

void CALLBACK PropSheetProc(
HWND hwndDlg,// handle of the property sheet dialog box
UINT uMsg,// action flag
LPARAM lParam// always zero
);
Parameters
hwndDlg
Handle of the property sheet dialog box.
uMsg
Action flag. Currently, the only defined value is PSCB_INITIALIZED, which indicates that the property sheet is being initialized.
lParam
Always zero.
Return Values
No return value.
Remarks
An application must specify the address of this callback function in the pfnCallback member of a PROPSHEETHEADER structure before specifying the address of the structure in a call to the PropertySheet function.
