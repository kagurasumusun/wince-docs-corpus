TransportProps

BOOL TransportProps(
HWND hwndParent// Handle to parent window
LPWSTR szCommonKey// Top-level registry key
LPWSTR szTransportKey// Transport registry key
);
TransportProps is used to add or modify information for the user’s mail service. This function is not required to be implemented and can simply return TRUE. Note that a user interface is required to display the information.
Parameters
hwndParent
Handle to parent window.
szCommonKey
Top-level registry key. For Inbox, this is the HLM\PMail\ServiceInfo key.
szTransportKey
Transport registry key. This is the key that is associated with the user’s unique mail service. For the sample transport service, this is the HLM\PMail\ServiceInfo\MyMail key.
Return Value
Returns TRUE if the mail properties were successfully updated; returns FALSE otherwise.
Remarks
For example, under the ServiceInfo key (szCommonKey), a key named SAMPLE could exist. This registry key contains values that represent information such as the user’s settings and preferences. As part of this routine, such preferences as saving the user’s password may be set in the registry (see the sample registry in the topic).
