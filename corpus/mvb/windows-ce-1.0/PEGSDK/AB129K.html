ntohl

The Windows Sockets ntohl function converts a u_long from network byte order to host byte order.

u_long ntohl (// winsock.h
u_long netlong// 32-bit number in network byte order
);
Parameters
netlong
A 32-bit number in network byte order.
Return Values
ntohl returns the value in host byte order.
Remarks
This function takes a 32-bit number in network byte order and returns a 32-bit number in host byte order.
