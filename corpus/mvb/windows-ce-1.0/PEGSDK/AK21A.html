Remote Process Viewer

The Remote Process Viewer (Ppview.Exe ) displays process, thread and module information (similar to the Remote Memory Viewer). Double-clicking a process name brings up a dialog box showing detailed memory layout for that process. In addition, the user can reset thread priorities via a radio button display. The user also can use buttons to request the Windows CE operating system to kill orphaned modules and processes. An error message box is displayed if the server is unable to complete the user’s request.
