HPC Hardware

HPCs are available from several different hardware manufacturers. The hardware and software options available vary depending on the manufacturer, however, application developers can count on certain features being available for all HPCs. This section describes the hardware features that are supported by the current version of the Windows CE operating system.

Microprocessor and Timers

An HPC is a battery-powered, pocket-sized, mobile computer based on the MIPS R4000, Hitachi SH3, or Intel x86 microprocessor. The operating system is designed to run the processor at a pace that achieves an optimal balance between speed and power consumption. The microprocessor has three different modes of operation designed to maximize battery life by minimizing power consumption; full speed, standby, and suspend.

CPU Operating ModeDescription
Full SpeedUsed to execute applications
StandbyUsed during brief idle periods, standby mode uses less than one-tenth of full speed power;
SuspendUsed during long idle periods, suspend mode uses less than one-thousandth of full speed power..
The HPC has two hardware timers. A high-resolution interval timer provides scheduling interrupts and timer events, and a low-resolution real-time clock provides the current date and time.
Memory
An HPC has two kinds of memory, persistent memory (ROM) and volatile memory (RAM). It has a minimum of four megabytes of ROM and two megabytes of RAM.. The operating system and all bundled applications are stored in ROM; the RAM stores user data and downloaded applications, and provides a workspace for executing applications and the operating system.
While the Windows CE operating system does a great job of managing memory for you, the size of RAM and the absence of a disk drive on the HPC place a premium on conserving memory. A typically configured HPC will have less than 2 MB of RAM for storing files, running the shell, and executing applications.
A good example of efficient programming is the Contacts application included in the Windows CE software package. It takes up less than 100K of ROM and can run in under 20K of RAM, yet it provides users with a fully functional application that takes advantage of all the features Windows CE has to offer.
Some manufacturers provide optional RAM expansion devices that allow more storage for user data and downloaded applications or for increasing the work space available for processing applications. The Windows CE system software automatically detects the presence of the expansion device and begins using the additional memory that it provides.
Chapter 3, “Memory Management,” discusses memory conservation options and handling low memory situations, and offers some tips for minimizing your application's memory requirements.
The Object Store
The portion of RAM not reserved for use by the operating system is split between work space for executing applications, the user area, and space for storing data, the object store. The object store is used in place of conventional direct-access storage devices like disk and tape drives, to store the registry, downloaded applications, and the run-time data they need. The user determines the amounts of RAM available for the user area and the object store. For a detailed look at the object store, read Chapter 5, “The Object Store.”

Resetting Memory
There are two methods of rebooting an HPC and resetting its RAM.
· Pressing a hardware reset button, typically accessible through a pinhole somewhere on the HPC’s case performs a warm boot. The hardware reset button triggers a nonmaskable reset interrupt. A warm boot should be performed when the system stops responding or becomes unstable. A warm boot erases work currently in progress, however the contents of the object store remain intact.
· Removing the main batteries from the HPC performs a cold boot. Both batteries must be removed from the device for approximately one minute to insure the RAM gets reset. A cold boot erases all work currently in progress and all data from the object store.

User Input and Output Devices
The HPC has at minimum a 480 ´ 240–pixel liquid crystal display (LCD) arranged in a landscape orientation. The LCD is monochrome and maps the screen using two bits per pixel. This gives you only four colors to work with:
· Black
· White
· Light Gray
· Dark Gray
A continuous resistive touch panel overlies the LCD. The touch panel allows the user to directly manipulate the objects in the system's graphical user interface; it is the equivalent of a mouse in Windows 95. (HPCs do not support a mouse.)
The HPC has a "QWERTY"-style keyboard designed to be as similar as possible to a standard PC keyboard. The keyboard includes the standard "extra" keys such as CTRL, ALT, and two SHIFT keys. Infrequently used keys such as PRINT SCREEN and SCROLL LOCK and are not included. The keyboard supports separate key down and key up events.
An HPC has a light emitting diode (LED) on the outside of its case. Applications can use the LED to notify the user that an event has occurred. For example, a calendar application can cause the LED to blink when an appointment is about to happen. The user acknowledges the notification by pressing a button that is also located on the outer case. Pressing the button sends an acknowledgment to the corresponding application and causes the LED to stop blinking.
All HPCs have built-in audio output hardware. An application can use the audio hardware to associate sounds with notification events or to play wave (.wav) files. Current versions of the HPC do not contain audio input hardware.
Connectivity Hardware
The Windows CE operating system supports a number of standard and optional connectivity devices such as a serial port, infrared communications hardware, and a PC Card port. The following sections describe the connectivity hardware currently available to a Windows CE application.
Serial Port
All HPCs have a nine-pin serial port. Applications use the serial port for communication between the HPC and a desktop PC. The serial port is used to accomplish the following tasks;
· Install software
· Backup and restore user data
· Manually copy data
· Synchronize the user's PIM data
Software on the desktop PC provides the user interface for accomplishing these tasks. Connection to the desktop PC is either by way of a serial cable, or though an optional docking cradle (available from some HPC manufacturers) connected to the desktop PC. Some docking cradles also supply power to run the HPC and recharge its batteries.
HPCs also have a serial port for debugging. Depending on the device manufacturer, the debugging serial port may or may not have an external connector.
Some HPCs support data communications through a modem connected to the serial port.
Infrared Communications Hardware
The Windows CE operating system supports infrared communications hardware that conforms to the Infrared Data Association (IrDA) specifications. By using the infrared hardware, applications on two different HPCs can communicate with one another. HPC-to-PC communication and communication with other infrared-enabled devices is not supported in the current release.
Hardware Expansion Slot
While some HPCs have an internal modem and one-way pager built into the main hardware, most will utilize the PC Card slot for adding communication hardware. Because the Windows CE operating system supports only a portion of the PCMCIA standard, not all modems are supported. However, because the system supports installable device drivers, third-party software and hardware vendors can add support for additional devices by providing device drivers that are installed into the HPC RAM.
