LB_SETITEMHEIGHT

An application sends an LB_SETITEMHEIGHT message to set the height, in pixels, of items in a list box. Otherwise, this message sets the height of all items in the list box.

Windows CE Notes index must be set to zero.

wParam = (WPARAM) index; // item index

lParam = MAKELPARAM(cyItem, 0);	// item height

Parameters

index

Value of wParam. Must be zero.

cyItem

Value of lParam. Specifies the height, in pixels, of the item.

Return Values

If the index or height is invalid, the return value is LB_ERR.
