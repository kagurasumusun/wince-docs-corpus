<HR>

Horizontal rule. Create a new header specifying the size and type of rule. Does not mark end of a layout section.

SIZE

Height of the rule in pixels

WIDTH

Width of the rule in pixels or percentage of the currently available page width. This can be reduced by images down the right and left sides of the page.

ALIGN

left, right, center.

NOSHADE

Indicates that the rule should be drawn as a solid bar, not 3D. (just use a dark gray rect instead of DrawEdge)
