lineGetTranslateCaps

The lineGetTranslateCaps function returns address translation capabilities.

LONG lineGetTranslateCaps(// tapi.h
HLINEAPP hLineApp,// application handle returned by lineInitialize
DWORD dwAPIVersion,// version of TAPI
LPLINETRANSLATECAPS lpTranslateCaps// pointer to the location
);
Parameters
hLineApp
Specifies the application handle returned by lineInitialize.
dwAPIVersion
Indicates the version of TAPI negotiated by lineNegotiateAPIVersion.
lpTranslateCaps
Specifies a pointer to a location to which a LINETRANSLATECAPS structure will be loaded. Prior to calling lineGetTranslateCaps, the application should set the dwTotalSize field of this structure to indicate the amount of memory available to Tapi.dll for returning information.
Return Values
Returns zero if the request is successful or a negative error number if an error has occurred. Possible return values are:
· LINEERR_INCOMPATIBLEAPIVERSION
· LINEERR_NOMEM
· LINEERR_INIFILECORRUPT
· LINEERR_OPERATIONFAILED
· LINEERR_INVALAPPHANDLE
· LINEERR_RESOURCEUNAVAIL
· LINEERR_INVALPOINTER
· LINEERR_STRUCTURETOOSMALL
· LINEERR_NODRIVER
· LINEERR_UNINITIALIZED
Remarks
If an application has not yet called the lineInitialize function, it can set the hLineApp parameter to NULL when calling the lineGetTranslateCaps function.
