MailMsg

This structure is used by the Mail and Transport functions to store the contents of messages being sent and received.

typedef struct MailMsg {-

DWORD dwMsgId; // Message ID

DWORD dwFlags; // MAIL flags

DWORD dwMsgLen; // Length of complete body

WORD wBodyLen; // Local body length

FILETIME		ftDate;			// Time received

LPWSTR szSvcId; // Service defined ID

LPWSTR szSvcNam; // Service name

WCHAR* pwcHeaders; // Header fields

LPWSTR szBody; // Message body

PEGOID oid; // Database object ID

HANDLE hHeap // Heap for message storage

} MailMsg;

Members

dwMsgId

Specifies an internal identification number maintained by the system. This identification number is used by library routines to access messages in the message store. Applications should not attempt to change the value stored in this member.

dwFlags

Specify the folder containing the message, the status of the message, and how the message is handled. These mail flags are divided into three categories: folder flags, status flags, and message flags. The flags and a brief description of their meanings are listed below.

Folder flags determine which folder to locate or store the message in. Use only one of the following folder flags in combination with status and message flags.

Folder flagDescription
MAIL_FOLDER_ALLFolder flag mask
MAIL_FOLDER_FIRSTStart of user-defined folders
MAIL_FOLDER_LASTEnd of user-defined folders
MAIL_FOLDER_SENTCopy of sent mail
MAIL_FOLDER_OUTBOXLocal OUTBOX (last local folder)
MAIL_FOLDER_INBOXUniversal INBOX
MAIL_FOLDER_ANYSearch for any folder during “Get”
MAIL_FOLDER_TARGETTarget folder for MAIL_COPY
Status flags verify the status of the message being stored or retrieved. Status flags can be used to determine what type of messages to search for when calling MailFirst and MailNext functions. These flags can be any combination of the following values.
Status flag		Description
MAIL_STATUS_ALLStatus flag mask
MAIL_STATUS_FREEMessage deleted - free slot
MAIL_STATUS_DELETEMessage set to be deleted
MAIL_STATUS_COPYMessage set to be copied to local target
MAIL_STATUS_READMessage marked as having been read
MAIL_STATUS_SERVICEINBOX Message exists on a service
MAIL_STATUS_COMPOSEDComposed locally (To: address)
MAIL_STATUS_REMOTEINBOX body exists only on service
MAIL_STATUS_NOTLook for invert of status bits (GET)
MAIL_STATUS_ANY(MAIL_STATUS_NOT | MAIL_STATUS_FREE)
MAIL_STATUS_ALIVE(MAIL_STATUS_ANY | MAIL_STATUS_DELETE)
MAIL_STATUS_LOCAL(MAIL_STATUS_ALIVE | MAIL_STATUS_SERVICE)
MAIL_STATUS_BODY(MAIL_STATUS_ALIVE | MAIL_STATUS_REMOTE)
MAIL_STATUS_UNREAD(MAIL_STATUS_ALIVE | MAIL_STATUS_READ)
Message flags determine how the message will be handled and how much of the message is retrieved on a mail get. If none of the message flags are set, all fields but the body are retrieved. Use any combination of the first two flags with one of the remaining flags.

MAIL_GET_FLAGSGet only flags field (during a get)
MAIL_FULLGet full body when copying
dwMsgLen
Specifies the size, in bytes, of the entire message on the service.
wBodyLen
Specifies the size, in bytes, of the message as maintained in the message store.
ftDate
Specifies the date and time the message was received by the service.
szSvcId
Specifies a unique identification number assigned by the service. The service uses this identification number to access the desired message.
szSvcNam
Specifies the name of the service. Applications can use this name to link messages to a particular service.
pwcHeaders
Pointer to the header fields. The header consists of entries made up of two fields, a name and an associated value. The name fields are separated from the value fields by a NULL character, and the entries are separated from each other by a NULL character. The header string is terminated with two consecutive NULL characters.
szBody
Pointer to the body of the message.
oid
Specifies the object identifier. The object ID is assigned by the system and can be used as a key for storing and receiving messages. The object ID is set when the message is inserted in the message store using the MailPut function and returned in this field when the MailFirst or MailNext functions are called.
hHeap
Handle to the private heap used for all storage related to this message. Any storage allocated to this heap is freed when the MailFree function is called.
