NM_INLINE_IMAGE

The NM_INLINE_IMAGE notification message is sent by the HTML control to notify the application to load the image.

NM_HTMLVIEW *pnmHtmlView = (NM_HTMLVIEW *)lParam;
// points to NM_HTMLVIEW the structure

szSRCText = pnmHtmlView->szTarget; // contents of the SRC

// parameter of the IMG tag

dwCookieValue = pnmHtmlView->dwCookie; // cookie value passed

// in DTM_SETIMAGE

switch(pnmHtmlView->hdr.code) {- // check HTML notification message

case NM_INLINE_IMAGE:

};

Parameters

pnmHtmlView

Pointer to an NM_HTMLVIEW structure that contains information about the NM_INLINE_IMAGE notification message.

szSRCText

String that contains the text from the SRC parameter of the IMG tag in the HTML text.

dwCookieValue

Cookie value that must be passed in the DTM_SETIMAGE or DTM_IMAGEFAIL message, from the application to the HTML control.

Return Values

This message does not return a value.

DTM_SETIMAGE, DTM_IMAGEFAIL, NM_HTMLVIEW
