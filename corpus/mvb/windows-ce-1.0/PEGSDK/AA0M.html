Mail Interface

Inbox and the Mail API

Microsoft Inbox is an integral part of the personal information management software that comes bundled on the HPC with Windows CE. It provides users with access to electronic mail using Simple Mail Transport Protocol (SMTP) and Post Office Protocol 3 (POP3), which works with any TCP/IP network such as the Internet. Inbox was designed as a companion for Microsoft Exchange but it has an open application programming interface (API) providing an excellent opportunity for new mail transport and storage applications to be written.

Windows CE does not support Microsoft’s Messaging API (MAPI) standard. It does however, provide a new set of functions, structures, and messages common to mail applications. The Mail API allows applications to be aware of, and compatible with, Inbox. Mail messages can be sent and received from any application. Inbox also provides a method for automatically launching an application and passing it mail when a specified type of mail message is received.

This chapter takes a look at the layout of the mail database (the message store), and the API functions used to store, retrieve and manipulate messages.
