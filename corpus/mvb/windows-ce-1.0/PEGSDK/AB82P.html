WSAGetLastError

The Windows Sockets WSAGetLastError function gets the error status for the last operation that failed.

int WSAGetLastError(void);// winsock.h
Parameters
This function has no parameters.
Return Values
The return value indicates the error code for the last Windows Sockets function performed by this thread.
Notes for Windows Sockets Suppliers
The use of the WSAGetLastError function to retrieve the last error code, rather than relying on a global error variable (compare errno), is required in order to provide compatibility with future multithreaded environments.
WSAGetLastError will invoke GetLastError, which is used to retrieve the error status for all Win32 functions on a per-thread basis. For portability, an application should use WSAGetLastError immediately after the Windows Sockets function that failed.
Remarks
This function returns the last network error that occurred. When a particular Windows Sockets function indicates that an error has occurred, this function should be called to retrieve the appropriate error code.
