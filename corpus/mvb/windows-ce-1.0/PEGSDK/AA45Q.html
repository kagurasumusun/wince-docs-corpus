DTM_IMAGEFAIL

An application sends a DTM_IMAGEFAIL message to inform the HTML control that the image indicated by the cookie could not be loaded. Note that the cookie value is the value referenced by the dwCookie field of the INLINEIMAGEINFO structure that was sent with the DTM_SETIMAGE message.

wParam = 0, // not used, must be zero

lParam = (LPARAM)(DWORD) dwCookie; // identifies the load image

Parameters

dwCookie

Identifies the load image that could not be loaded. This value is passed in the dwCookie field of the NM_HTMLVIEW structure when an NM_INLINE_IMAGE notification message is received. Note that this is the same value that was passed in the dwCookie field of the INLINEIMAGEINFO structure when the DTM_SETIMAGE message was sent to the HTML control.

Return Values

This message does not return a value.

Remarks

The Image loading icon will be replaced with the broken image icon, and the Alt text will be displayed.

See Also

DTM_SETIMAGE, NM_INLINE_IMAGE
