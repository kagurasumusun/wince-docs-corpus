BM_SETCHECK

An application sends a BM_SETCHECK message to set the check state of a radio button or check box.

wParam = (WPARAM) fCheck, // check state

lParam = 0; // not used, must be zero

Parameters

fCheck

Value of wParam. Specifies the check state. This parameter can be one of the following values.

ValueMeaning
0Set the button state to unchecked.
1Set the button state to checked.
2Set the button state to grayed. This value can be used only if the button has the BS_3STATE or BS_AUTO3STATE style.
Return Values
This message always returns zero.
Remarks
The BM_SETCHECK message has no effect on push buttons.
See Also
BM_GETCHECK, BM_GETSTATE, BM_SETSTATE
