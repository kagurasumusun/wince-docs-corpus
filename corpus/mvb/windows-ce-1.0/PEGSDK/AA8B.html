Window Functionality

Creating and using windows works much the same way in Windows CE as it does in Windows 95. As with many other aspects of Windows CE though, only a subset of the Windows 95 functionality is available. Not all dwStyle flags, for instance, are supported, and the range of values the various members of the WNDCLASS structure can take is restricted. See Table 1, and the Developers Reference for details.

Windows can be moved (including partially off-screen), and may be dropped to the taskbar. However, Windows CE does not support maximize/minimize buttons or resize handles for windows. A window's size is fixed when the window is created and cannot be modified while in use. Windows CE also does not support "Topmost Window" functionality.
