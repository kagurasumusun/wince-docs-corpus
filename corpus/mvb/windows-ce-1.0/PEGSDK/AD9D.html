DB_PEGOID_DIRECTORY_DELETED

The DB_PEGOID_DIRECTORY_DELETED message is sent when a directory has been deleted from the object store.

oidDeletedDir = (PEGOID) wParam; // identifier of deleted directory

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidDeletedDir

Value of wParam. Identifies the directory that was deleted.

oidParent

Value of lParam. Identifies the parent object of the deleted directory.
