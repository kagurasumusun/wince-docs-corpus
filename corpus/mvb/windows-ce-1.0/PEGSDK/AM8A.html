Window Design

Basic window design conventions are similar to those in Windows; however, because of limited display space, Windows CE consolidates some of the common window design elements.

As in Windows, the visual difference between primary windows and secondary windows may be difficult to distinguish. Avoid thinking of the distinction as whether a window contains controls or not. While primary windows typically include only menus, a secondary window could include a menu button. Similarly, a primary window such as a form might include many of the same type of controls that are displayed in a secondary window.

By definition, a primary window is the primary window for an object. It typically displays a primary view of an object. It also appears in the taskbar. In contrast, a secondary window is an auxiliary, dependent window that typically provides a means of displaying or gathering additional user input. Secondary windows include property sheets, dialog boxes, and message boxes.

Similarly, you should avoid defining a window based on its implementation type. Users can’t determine what programming interface you use to create a window. A secondary window that looks like a message box is a message box to the user even if you used a dialog box instead of the message box API to create it. Users identify windows by their use and their consistency with other windows with which they interact.
