Windows CE Remote Tools

About Windows CE Remote Tools

After you are properly configured to run HPC Explorer, you will automatically be properly configured to run the Remote Tools. Remote Tools for Windows CE uses a standard serial cable connection between your HPC and your desktop via Windows CE Point-To-Point Protocol, using WinSock. For more information on how to configure your computer for use with these tools, see the HPC User’s Guide chapter “Connecting to Your Desktop Computer”.

The tools provided for use on the desktop PC client include:

· Remote Spy

· Remote Registry Editor

· Remote Zoomin

· Remote Memory Viewer

· Remote Process Viewer

· Remote Object Viewer

· Remote Connection Server

See also “Notes on Running the Remote Tools.”
