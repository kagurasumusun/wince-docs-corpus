gethostname

The Windows Sockets gethostname function returns the standard host name for the local computer.

int PASCAL FAR gethostname (// winsock.h
char FAR *name,// pointer to buffer
int namelen// length of the buffer
);
Parameters
name
A pointer to a buffer that will receive the host name.
namelen
The length of the buffer.
Return Values
If the function succeeds, gethostname returns zero. If the function fails, it returns SOCKET_ERROR. To get extended error information, call GetLastError.
Error code		Description
WSAEFAULTThe namelen parameter is too small.
WSANOTINITIALISEDA successful WSAStartup must occur before using this function.
WSAENETDOWNThe Windows Sockets implementation has detected that the network subsystem has failed.
WSAEINPROGRESSA blocking Windows Sockets operation is in progress.
Remarks
This function returns the name of the local host into the buffer specified by the name parameter. The host name is returned as a null-terminated string. The form of the host name is dependent on the Windows Sockets implementation—it may be a simple host name, or it may be a fully qualified domain name. However, it is guaranteed that the name returned will be successfully parsed by gethostbyname.
