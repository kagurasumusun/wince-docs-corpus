CommandBar_InsertButton

The CommandBar_InsertButton function inserts a button in a command bar.

BOOL CommandBar_InsertButton(// commctrl.h
HWND hwndCB,// handle of command bar
int iButton,// index of a button
LPTBBUTTON lpButton// structure with button data
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
iButton
Specifies the zero-based index of a button. The function inserts the new button to left of this button.
lpButton
Points to a TBBUTTON structure that contains information about the button to insert.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
