SHShowOutOfMemory

The SHShowOutOfMemory function displays a system-defined dialog box telling the user that memory is full.

int SHShowOutOfMemory(// shellapi.h
HWND hwndOwner,// handle of owner window
UINT grfFlags// reserved; must be zero
);
Parameters
hwndOwner
Identifies the window that owns the dialog box.
grfFlags
Reserved; must be zero.
Return Values
No return value.
