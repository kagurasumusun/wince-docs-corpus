CB_SETITEMDATA

An application sends a CB_SETITEMDATA message to set the 32-bit value associated with the specified item in a combo box.

Windows CE Notes Owner draw combo boxes are not supported.

wParam = (WPARAM) index; // item index

lParam = (LPARAM)(DWORD) dwData; // item data

Parameters

index

Value of wParam. Specifies the item's zero-based index.

dwData

Value of lParam. Specifies the new value to be associated with the item.

Return Values

If an error occurs, the return value is CB_ERR.

See Also

CB_ADDSTRING, CB_GETITEMDATA, CB_INSERTSTRING
