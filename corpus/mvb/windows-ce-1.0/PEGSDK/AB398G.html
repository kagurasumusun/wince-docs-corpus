GetStoreInformation

The GetStoreInformation function fills in a STORE_INFORMATION structure.

BOOL GetStoreInformation(// winbase.h
LPSTORE_INFORMATION lpsi// pointer to the STORE_INFORMATION structure
);
Parameters
lpsi
Points the a STORE_INFORMATION structure to be filled in by this function.
Return Values
Returns TRUE on success, else failure.
