TCM_DELETEITEM

The TCM_DELETEITEM message removes an item from a tab control. You can send this message explicitly or by using the TabCtrl_DeleteItem macro.

wParam = (WPARAM)(int) iItem; // index of the item to delete

lParam = 0; // not used; must be zero

// Corresponding macro

BOOL TabCtrl_DeleteItem(

HWND hwnd,

int iItem

);

Parameters

iItem

Index of the item to delete.

hwnd

Handle to the tab control.

Return Values

Returns TRUE if successful or FALSE otherwise.
