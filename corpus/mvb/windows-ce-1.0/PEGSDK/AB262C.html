CreatePopupMenu

The CreatePopupMenu function creates a pop-up menu. The menu is initially empty. You can fill it with menu items by using the InsertMenu and AppendMenu functions.

HMENU CreatePopupMenu(void);// winuser.h
Return Values
If the function succeeds, the return value is the handle to the newly created pop-up menu. If the function fails, the return value is NULL.
Remarks
The application can add the pop-up menu to an existing menu or pop-up menu, or it can display a floating pop-up menu by calling the TrackPopupMenu function.
An application must free system resources associated with the menu before closing. An application frees menu resources by calling the DestroyMenu function.
