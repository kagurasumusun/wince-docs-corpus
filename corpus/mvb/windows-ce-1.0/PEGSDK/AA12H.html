Button Tooltips

When you create a command bar, the system automatically creates an accompanying tooltip control. The tooltip control is a small pop-up window that contains a brief line of descriptive text about a button in a command bar. The tooltip appears when the user holds the stylus on a command bar button. Note that a tooltip does not appear for menus and combo boxes in a command bar. To add a tooltip for an application-defined button, use the CommandBar_AddToolTips function.
