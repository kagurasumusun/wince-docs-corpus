Conserving Memory with the Registry

In order to reduce memory requirements and decrease access times, the sizes of registry keys can be limited according to the following guidelines.

· Limit the length of each key name component.

· Limit the number of subkey levels under which a value is stored.

· Do not use the null (default) value name; this simply wastes the key above the value.

· Do not use many small registry values; use larger values (for example, multistrings, binary, and so on) rather than a number of individual strings, integers, and such.

· Keeping the above bullet in mind, do not use the Windows95 key-naming convention just for the sake of doing so. Although a remote registry tool is available with the SDK, the registry is not exposed to the end user. Therefore, registry keys do not need to follow a traditional convention.

· Keep the registry values to a reasonable size - do not add multi-kilobyte values.
