CommandBar_Destroy

The CommandBar_Destroy function destroys a command bar.

void CommandBar_Destroy(// commctrl.h
HWND hwndCB// handle of command bar
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
Return Values
No return value.
Remarks
This function calls the DestroyWindow function to destroy the command bar. If the command bar's parent window is being destroyed, it is not necessary to call CommandBar_Destroy.
