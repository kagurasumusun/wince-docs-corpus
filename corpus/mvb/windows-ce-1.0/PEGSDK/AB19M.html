RasEnumEntries

Lists all entry names in a remote access phone book.

DWORD RasEnumEntries(// afdfunc.h
LPTSTR reserved,// reserved
LPTSTR lpszPhoneBookPath,// path name of phone book
LPRASENTRYNAME lprasentryname,// buffer that receives array of RASENTRYNAME structs
LPDWORD lpcb,// size, in bytes, of the buffer specified by lprasentryname
LPDWORD lpcEntries// number of phone book entries written to the buffer
);
Parameters
reserved
Reserved.
lpszPhoneBookPath
Path name of phone book .
lprasentryname
Points to a buffer that receives an array of RASENTRYNAME structures, one for each phone book entry. Before calling the function, an application must set the dwSize member of the first RASENTRYNAME structure in the buffer to sizeof(RASENTRYNAME) in order to identify the version of the structure being passed.
lpcb
Points to a variable that contains the size, in bytes, of the buffer specified by lprasentryname. On return, the function sets this variable to the number of bytes required to successfully complete the call.
lpcEntries
Points to a variable that the function, if successful, sets to the number of phone book entries written to the buffer specified by lprasentryname.
Return Values
If the function succeeds the value is zero; else an error from Raserror.h is returned.
Error Code		Description
ERROR_UNKNOWNRequired reserved parameter is not NULL.
ERROR_CANNOT_OPEN_PHONEBOOKInvalid phone book path specified.
ERROR_INVALID_SIZEInvalid lpcb parameter.
