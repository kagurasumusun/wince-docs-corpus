MailErrorMsg

The MailErrorMsg function retrieves the last occurrence of a mail error condition, fills a text string with a description of the error, and sets a pointer to the line number where the error occurred.

int MailErrorMsg (// msgstore.h
HANDLE hMail ,// handle to mail context
LPWSTR szBuffer,// Buffer for error string
int iBuffLen ,// Length of buffer
int* piSrcLine// Line where error occurred
);
Parameters
hMail
Handle identifying the mail context. This handle is created by the MailOpen function.
szBuffer
Pointer to a wide character string array containing a description of the error condition issued by the last called mail function.
iBufferLen
The length, in characters, of the string array receiving the error description.
piSrcLine
Points to the line where the error occurred. If no errors are encountered, the value pointed to by this parameter is set to NULL.
Return Value
This function returns the value of the last error code as an integer.
Remarks
MailErrorMsg operates with the same behavior as the MailError function with the exception of the additional information it provides.
