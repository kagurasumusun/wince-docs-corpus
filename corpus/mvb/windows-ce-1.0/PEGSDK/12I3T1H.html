Preface

This manual describes the SH-3 COFF Assembler. The manual is based upon the SH Series Cross Assembler's Manual (version 2.0), and is organized as follows:

· Section 1: Gives an overview of the functions, limitations, and support tools of the assembler

· Sections 2-9: Describe the assembler language syntax and programming techniques

· Sections 10-11: Describe the use (invocation) of the assembler program itself

· Appendices A-D: Show further examples of notes, limitations, samples, and error messages

For further information on the SH microprocessor hardware, see the SH3 Hardware Manual.

For more information about the SH microprocessor executable instructions, see the SH3 Series Programming Manual.
