GetAddressCardProperties

The GetAddressCardProperties function opens an address card and retrieves specified properties from it.

BOOL GetAddressCardProperties(// addrstor.h
PEGOID oidCard,// object identifier of address card
AddressCard *pac,// address of structure for card properties
int numRequestedProps,// number of properties requested
HHPRTAG *rghhProp// array of properties to retrieve
);
Parameters
oidCard
Specifies the object identifier of an address card.
pac
Points to an AddressCard structure that receives the address card's properties.
numRequestedProps
Specifies the number of property tags in the array pointed to by the rghhProp parameter.
rghhProp
Points to an array of property tags that identify the address card properties to retrieve. Property tags begin with an HHPR_ prefix. Refer to Properties and Property Tags in the Contacts Database guide chapter for a list of these tags.
Return Values
Returns TRUE if the function succeeds, or FALSE otherwise.
Remarks
The system allocates memory for the address card's properties. After every call to this function, an application must free the memory by calling the FreeAddressCard function.
If only a few properties from the address card need to be displayed, you should use GetAddressCardProperties instead of the OpenAddressCard function. Using GetAddressCardProperties in this situation uses less memory than OpenAddressCard.
The Contacts database must have been opened by a previous call to the OpenAddressBook function.
