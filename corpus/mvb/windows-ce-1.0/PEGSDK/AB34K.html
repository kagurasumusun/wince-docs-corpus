MailGetField

The MailGetField function sets a pointer to a specified field in the header string.

LPWSTR MailGetField (// msgstore.h
MailMsg* pmm,// Message containing header string.
LPWSTR szName,// Name of field being retrieved
BOOL fGetName// Key position/Value switch
);
Parameters
pmm
Points to the mail message containing the header being searched.
szName
Points to a string containing the name field of the header entry being searched for. When looking for a match, this parameter can be any combination of uppercase and lowercase letters because the name field is not case-sensitive.
fGetName
This parameter determines which field of the entry is retrieved. It can be one of the following values.
Value		Description
TRUEPoints to the name field
FALSEPoints to the value field
Return Value
This function returns a pointer to the specified field.
Remarks
This function searches the header of the MailMsg structure in memory. Before calling this function, the message must be retrieved from the message store by calling MailGet, MailFirst, or MailNext.
The pwcHeaders member of the MailMsg structure points to the message’s header string. The header consists of entries made up of two fields, a name, and an associated value. The name fields are separated from the value fields by a NULL character, and the entries are separated from each other by a NULL character. The header string is terminated with two consecutive NULL characters.
