SHGetShortcutTarget

The SHGetShortcutTarget function retrieves the path which the shortcut points to.

BOOL SHGetShortcutTarget(// shellapi.h
LPTSTR szShortcut,// Pointer to a buffer containing the name of shortcut to create
LPTSTR szShortcut,
LPTSTR szTarget,// Pointer to a buffer that gets the target path of the shortcut
int cbMax// count in characters to copy
);
Parameters
szShortcut
Pointer to a buffer that contains the name of the shortcut to create.
szTarget
Pointer to a buffer that gets the target path of the shortcut.
cbMax
count in characters to copy
