Remote API Functions

About Remote API Functions

Windows CE supports a set of Remote API (RAPI) functions that give an application running on a desktop PC (the RAPI client) the ability to make function calls on the Windows CE PC (the RAPI server). The function calls are synchronous and behave as much as possible like the Win32 based functions provided by the Windows CE Operating System.

Most of the Windows CE RAPI functions have the same syntax, parameters, and return value as the corresponding Win32 based function. Any RAPI-specific differences are noted in the RAPI function descriptions.
