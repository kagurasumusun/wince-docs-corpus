API Functions

Since Windows CE will be stored on only 4 MB of flash ROM, it is much smaller and simpler than Windows 95. To reduce the footprint of the operating system, many of the Win32 API functions are not supported by Windows CE. These are largely functions that are not commonly used, whose functionality can be duplicated, or that are not relevant to Windows CE (multimedia-related functions, for instance).

While those functions that are supported still take the same arguments, many have had their capabilities reduced. In some cases, arguments will accept only a subset of the values supported under Win32. The functionality associated with others has been "turned off" (although you must still set the value to NULL when calling the function to avoid errors).

There are also some API functions that are specific to Windows CE, and support capabilities that are unique to Windows CE. Examples include functions to manage the command bar, event notification, and the object store (used for managing storage).
