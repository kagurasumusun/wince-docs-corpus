Pop-up Menus

Windows CE supports pop-up menus. However, because the interface does not support a right mouse button or function keys, users activate pop-up menus using ALT+tap or ALT+CTRL combinations. Guidelines for designing pop-up menus follow the Windows recommendations. However, note that using bold to indicate the default command for a pop-up menu is not currently supported in Windows CE.

Windows CE does not support the pop-up menu for the window (also known as the System or Control menu). As noted the relevant commands are provided through other interfaces.
