HDM_LAYOUT

Retrieves the size and position of a header control within a given rectangle. This message is used to determine the appropriate dimensions for a new header control that is to occupy the given rectangle.

wParam = 0;

lParam = (LPARAM)(HD_LAYOUT FAR*) playout;

// Corresponding macro

BOOL Header_Layout(

hwndHD,

playout

);

Parameters

hwndHD

Handle of the header control.

playout

Address of an HD_LAYOUT structure. The prc member specifies the coordinates of a rectangle, and the pwpos member receives the size and position for the header control within the rectangle.

Return Values

Returns TRUE if successful or FALSE otherwise.
