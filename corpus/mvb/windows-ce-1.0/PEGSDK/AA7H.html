Button Strings

Each command bar button can display a string in addition to, or instead of, an image. A command bar maintains an internal list that contains all of the strings available to buttons. You add strings to the internal list by using the TB_ADDSTRING message, specifying the address of the buffer that contains the strings to add. Each string must be null-terminated, and the last string must be terminated with two null characters.

Each string has a zero-based index. The first string added to the internal list of strings has an index of zero, the second string has an index of one. TB_ADDSTRING adds strings to the end of the list and returns the index of the first new string. Use the index of a string to associate the string with a button.
