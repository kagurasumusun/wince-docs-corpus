Filter Defined Error Values

Typically, a file filter function returns NOERROR if it succeeds or a Win32 error code if it fails (using the HRESULT_FROM_WIN32 macro). Alternatively, the NextConvertFile functions can return a filter-defined error code in the variable the perr parameter points to. The error code must be defined by using the PF_DECLARE_ERROR macro defined in the Replerr.h header file, and the filter DLL must include a message table that contains the error code and a corresponding message string. When the HPC Explorer receives the filter-defined error code, it uses the Win32 FormatMessage function to create the error string, checking the filter object first for the relevant string (using IPegasusFileFilter::FormatMessage). For more information about message tables, see the Win32 Programmer's Reference.
