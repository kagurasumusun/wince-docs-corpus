TVM_ENSUREVISIBLE

Ensures that a tree view item is visible, expanding the parent item or scrolling the tree view control, if necessary. You can send this message explicitly or by using the TreeView_EnsureVisible macro.

wParam = 0;

lParam = (LPARAM)(HTREEITEM) hitem;

// Corresponding macro

BOOL TreeView_EnsureVisible(

hwnd,

hitem

);

Parameters

hwnd and hitem

Handle of the tree view control, and the handle of the item.

Return Values

Returns TRUE if the control is scrolled or FALSE otherwise.

Remarks

If the message expands the parent item, the parent window receives the TVN_ITEMEXPANDING and TVN_ITEMEXPANDED notification messages.

See Also

TVN_ITEMEXPANDED, TVN_ITEMEXPANDING
