Button Bitmaps

Each button in a command bar can include a bitmapped image. A command bar stores the information needed to draw button images in an internal list. Initially, the list is empty. You add images to the list by calling the CommandBar_AddBitmap function. The function parameters include the handle of the module that contains the bitmap resource, the identifier of the bitmap resource, and the number of images in the bitmap. The dimensions of each image in the bitmap should be 16 (16 pixels. The system assumes that all of the images in the bitmap are the same size.

Each image has a zero-based index. The first image added to the internal list has an index of zero, the second image has an index of one. CommandBar_AddBitmap adds images to the end of the list and returns the index of the first new image which was added to the command bar. Use the index of an image to associate the image with a button.

The system includes a set of predefined button images that you can use with the buttons in your command bar. To use the predefined images, specify HINST_COMMCTRL as the module handle in the call to CommandBar_AddBitmap, and either IDB_STD_SMALL_COLOR or IDB_VIEW_SMALL_COLOR as the resource identifier, depending on which predefined images you want to use. The header files include constant values that you use as indices to the predefined images. For a list of these constant values, see the description of the CommandBar_AddBitmap function in the Windows CE Programmer's Reference.
