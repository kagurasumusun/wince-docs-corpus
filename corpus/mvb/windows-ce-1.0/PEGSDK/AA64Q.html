NM_TITLE

The NM_TITLE notification message is sent by the HTML control to notify the application and provide the title of the HTML document.

NM_HTMLVIEW *pnmHtmlView = (NM_HTMLVIEW *)lParam;
// points to NM_HTMLVIEW the structure

szTitle = pnmHtmlView->szTarget; // title of the HTML document

switch(pnmHtmlView->hdr.code) {- // check HTML notification message

case NM_TITLE:

};

Parameters

pnmHtmlView

Pointer to an NM_HTMLVIEW structure that contains information about the NM_TITLE notification message.

szTitle

String that contains the title of the HTML document.

Return Values

This message does not return a value.

Remarks

The HTML control does not send the NM_TITLE message if the TITLE tag is missing from the HTML document.
