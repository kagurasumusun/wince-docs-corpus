The Message Heap

Each message uses a private heap for dynamic storage of items in the message store. Heap-allocated storage includes the service ID and name, the header string, and the body of the message. The major advantage of using this private heap is that the entire heap can be released back to the system by calling the MailFree function. This keeps the global heap from becoming fragmented and wasting valuable memory.

Due to the memory constraints created by the form factor of the device, applications should allow only one message to be open at any one time. When the application is done with the message the heap should be freed.
