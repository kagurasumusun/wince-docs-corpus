Section Files (.htp)

Composition

Each topic must also start with the <html> tag, end with the </html> tag, and contain two parts: the head and the body.

The head section starts with the <head> tag and ends with the </head> tag. Like the contents file, this tag should include a <meta> tag that references the title of the .htc file associated with this topic. Use a naming convention that fits the needs of your project. If you have several components, you may want to use a two character abbreviation followed by a meaningful reference, for example, CD_new, where CD represents "calendar" and "new" the content of the topic.

Adding a Bitmap

To add a bitmap to a topic, use the anchor tag <IMG SRC> to specify the file name of a bitmap you want to include. Pocket Help files should use the .2bp extension.

The line, <IMG SRC="file:my_bitmap.2bp"> displays a graphic in the previous example.

Adding a Jump

To create a jump to another topic, use the anchor tag <a href> to specify the file name of the topic you want to jump to and the text that you want to be "hot."

For example:

<a href="file:my_topic1.htp">This is the text to be jumped</a>

In this example, Pocket Help displays "Creating a new appointment" as underlined text. When the user taps this text, the topic in the file Cal_new.htp is displayed.

Template

The following example provides an HTML code sample for a topic file and a screen shot of how it looks on the HPC:

<html>

<head>

<meta http-equiv=refer content="file:my_topic1.htc">

</head>

<body>

<H2>Second level heading</H2>

<p><b>This is for bold text</b>

<p>Here’s where to put normal text.

</body>

</html>
