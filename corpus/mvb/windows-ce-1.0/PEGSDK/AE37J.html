TVN_SELCHANGED

Notifies a tree view control's parent window that the selection has changed from one item to another. This notification message is sent in the form of a WM_NOTIFY message.

pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv

Address of an NM_TREEVIEW structure. The itemOld and itemNew members contain valid information about the previously selected item and the newly selected item. The action member indicates the type of action that caused the selection to change; it can be one of the following values.

ValueMeaning
TVC_BYKEYBOARDBy a key stroke
TVC_BYMOUSEBy a mouse click
TVC_UNKNOWNUnknown
Return Values
No return value.
