LVM_SETTEXTCOLOR

Sets the text color of a list view control. You can send this message explicitly or by using the ListView_SetTextColor macro.

wParam = 0;

lParam = (LPARAM)(COLORREF) clrText;

// Corresponding macro

BOOL ListView_SetTextColor(

HWND hwnd,

COLORREF clrText

);

Parameters

hwnd

Handle of the list view control.

clrText

New text color.

Return Values

Returns TRUE if successful or FALSE otherwise.
