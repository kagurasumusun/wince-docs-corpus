PSN_HASHELP

Queries a page to determine whether to show the Help button. This notification message is sent in the form of a WM_NOTIFY message.

lpnmhdr = (NMHDR FAR *) lParam;

Parameters

lpnmhdr

Address of an NMHDR structure. The hwndFrom member is the handle of the property sheet, and the hwndTo member is the handle of the page.

Return Values

Returns TRUE to show the Help button or FALSE otherwise.

Remarks

To set the return value, the dialog box procedure for the page must use the SetWindowLong function with the DWL_MSGRESULT value.

See Also

NMHDR, SetWindowLong
