PegEventHasOccurred

The PegEventHasOccurred function tells the shell that a system event has occurred. The shell starts any applications that have notifications registered for the given event.

BOOL PegEventHasOccurred(//
LONG lWhichEvent,// event identifier
TCHAR *pwszEndOfCommandLine// string to append to command line
);
Parameters
lWhichEvent
Specifies the event that has occurred. This parameter can be one of the following values:
· NOTIFICATION_EVENT_SYSTEM_BOOT
· NOTIFICATION_EVENT_SYNC_END
· NOTIFICATION_EVENT_NET_CONNECT
· NOTIFICATION_EVENT_NET_DISCONNECT
· NOTIFICATION_EVENT_DEVICE_CHANGE
· NOTIFICATION_EVENT_IR_DISCOVERED
pwszEndOfCommandLine
Points to a null-terminated command-line string. The system appends this string to the end of the command lines used to start the applications.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
Remarks
When a system event occurs, the code involved in the event should call this function so that applications that have registered notifications for that event can be run.
