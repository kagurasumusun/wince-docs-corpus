PEGFILEINFO

The PEGFILEINFO structure contains information about a file object.

typedef struct _PEGFILEINFO {-  // pegfi

DWORD dwAttributes;

PEGOID oidParent;

WCHAR szFileName[MAX_PATH];

FILETIME ftLastChanged;

DWORD dwLength;

} PEGFILEINFO;

Members

dwAttributes

Specifies the attributes of the file.

oidParent

Specifies the object identifier of the parent directory.

szFileName

Specifies a null-terminated string that contains the name and path of the file.

ftLastChanged

Specifies a time stamp indicating when the contents of the file were last changed.

dwLength

Specifies the length, in bytes, of the file.
