CreateUpDownControl

The CreateUpDownControl function creates an up-down control.

Windows CE Notes Up-down controls can only be buddies with edit controls.

HWND CreateUpDownControl(// commctrl.h
DWORD dwStyle,// window styles for the control
int x,// horizontal coordinate of the upper left corner of the control
int y,// vertical coordinate of the upper left corner of the control
int cx,// width, in pixels, of the up-down control
int cy,// height, in pixels, of the up-down control
HWND hwndParent,// handle of the parent window of the up-down control
int nID,// identifier for the up-down control
HINSTANCE hinst,// handle of the module instance of the app creating the control
HWND hwndBuddy,// handle of the window associated with the up-down control
int nUpper,// upper limit (range) of the up-down control
int nLower,// lower limit (range) of the up-down control
int nPos// position of the control
);
Parameters
dwStyle
Window styles for the control. This parameter should include the WS_CHILD, WS_BORDER, and WS_VISIBLE styles, and it may include any of the window styles specific to the up-down control.
x
Horizontal coordinate, in client coordinates, of the upper left corner of the control.
y
Vertical coordinate, in client coordinates, of the upper left corner of the control.
cx
Width, in pixels, of the up-down control.
cy
Height, in pixels, of the up-down control.
hwndParent
Handle of the parent window of the up-down control
nID
Identifier for the up-down control.
hinst
Handle of the module instance of the application creating the up-down control.
hwndBuddy
Handle of the window associated with the up-down control. If this parameter is NULL, the control has no buddy window. If it is not NULL, hwndBuddy must be an hwnd of an edit control.
nUpper
Upper limit (range) of the up-down control.
nLower
Lower limit (range) of the up-down control.
nPos
Position of the control.
Return Values
Returns the window handle of the up-down control if successful or NULL otherwise.
