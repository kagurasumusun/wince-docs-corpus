Close Button

You can add a close button to a command bar by using the CommandBar_AddAdornments function, specifying the handle of the command bar and the command identifier for the close button. When the user selects the close button, the system sends the given identifier to the command bar parent window in the context of a WM_CLOSE message.

The CommandBar_AddAdornments function positions the close button at the rightmost end of the command bar. You should call the CommandBar_AddAdornments function only after adding all other items to the command bar.
