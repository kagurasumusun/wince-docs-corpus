DeleteObject

The DeleteObject function deletes a logical pen, brush, font, bitmap, region, or palette, freeing all system resources associated with the object. After the object is deleted, the specified handle is no longer valid.

Windows CE Notes If the object is selected into a device context (using SelectObject), FALSE is returned.

BOOL DeleteObject(// wingdi.h
HGDIOBJ hObject// handle to graphic object
);
Parameters
hObject
Identifies a logical pen, brush, font, bitmap, region, or palette.
Return Values
If the function succeeds, the return value is TRUE. If the specified handle is not valid or is currently selected into a device context, the return value is FALSE.
Remarks
Do not delete a drawing object (pen or brush) while it is still selected into a device context.
When a pattern brush that was created using CreateDIBPatternBrushPt is deleted, the bitmap associated with the brush is not deleted. The memory associated with the bitmap must be freed independently.
