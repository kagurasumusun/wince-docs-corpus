Fonts

The default font for the Pocket Internet Explorer is Arial. HTML allows for 7 different sizes (1-7) to be specified. There are 6 sizes of the Arial font available in Pegasus ROM: 8, 9, 10, 12, 16, and 20. These correspond to pixel heights of: 15, 16, 18, 22, 24, and 32.

A mapping must occur between the 1-7 number and the font sizes available on the Pegasus. The goal of the font size determination algorithm is to:

Make good use of the Arial sizes available in the ROM of Pegasus, and

Allow additional fonts that are loaded on the system to be employed appropriately by the HTML control

Therefore, rather than a fixed mapping from a size (1-7) to a specific font size (Arial 8-20), the HTML control uses a linear mapping from the size (1-7) to the range of pixels between 15 and 32. The result is rounded down to the nearest available font.
