IsCharAlphaNumeric

The IsCharAlphaNumeric function determines whether a character is either an alphabetic or a numeric character. This determination is based on the semantics of the language selected by the user during setup or by using Control Panel.

Windows CE Notes Supports only the Unicode version of this function.

BOOL IsCharAlphaNumeric(// winbase.h
TCHAR ch// Unicode (wide) character to test
);
Parameters
ch
Specifies the Unicode (wide) character to be tested.
Return Values
If the character is alphanumeric, the return value is TRUE. If the character is not alphanumeric, the return value is FALSE. To get extended error information, use the GetLastError function.
