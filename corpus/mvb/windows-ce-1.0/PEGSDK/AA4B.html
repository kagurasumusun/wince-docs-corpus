Messaging for Windows CE

The Windows CE operating system supports most commonly used messages. However, many Win32 supported messages have been eliminated, particularly those associated with windows (WM_*) and edit boxes (EM_*). Some of those that are supported have been modified. Some of the more commonly used messages supported by Windows CE are listed in Table 3. You should refer to the Programmers Reference for a detailed list of which messages are and are not supported by Windows CE.
