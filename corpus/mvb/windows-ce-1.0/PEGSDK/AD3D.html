DB_PEGOID_CREATED

The DB_PEGOID_CREATED message is sent when a new object is created in the object store.

oidCreated = (PEGOID) wParam; // identifier of new object

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidCreated

Value of wParam. Identifies the newly created object.

oidParent

Value of lParam. Identifies the parent object of the newly created object.
