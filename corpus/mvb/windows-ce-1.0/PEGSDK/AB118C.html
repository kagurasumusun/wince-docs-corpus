CommandBar_InsertComboBox

The CommandBar_InsertComboBox function inserts a combo box into a command bar.

HWND CommandBar_InsertComboBox(// commctrl.h
HWND hwndCB,// handle of command bar
HINSTANCE hInst,// handle of application instance
int iWidth,// width of combo box
UINT dwStyle,// window styles
WORD idComboBox,// identifier of combo box
int iButton// index of a button
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
hInst
Identifies the instance of the application.
iWidth
Specifies the width, in pixels, of the combo box.
dwStyle
Specifies the window styles of the combo box. Currently, only the CBS_DROPDOWNLIST and WS_VSCROLL styles are supported. The WS_VISIBLE and WS_CHILD styles are included automatically.
idComboBox
Specifies the identifier of the combo box.
iButton
Specifies the zero-based index of a button. The function inserts the combo box to the left of this button.
Return Values
If the function succeeds, the return value is the window handle of the combo box. If the function fails, the return value is NULL.
