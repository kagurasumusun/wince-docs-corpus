Floating Point Exceptions

All five IEEE exceptions are detected. They are signaled by setting the appropriate status flags available through the _statusfp function. If the corresponding trap-enable masks available through the _controlfp function so indicate, and if the kernel provides a real, non-stubbed implementation of RaiseException, then the appropriate trap is taken. Traps are disabled by default.

The _statusfp function supports the status flags from <float.h>:

Table 6. Supported _statusfp Status Flags

STATUS FLAGMEANING
_SW_INEXACTInexact result
_SW_UNDERFLOWUnderflow
_SW_OVERFLOWOverflow
_SW_ZERODIVIDEDivide by zero
_SW_INVALIDInvalid operation
The _statusfp function does not support the invalid subconditions flags such as _SW_SQRTNEG in <float.h> Taking the square root of a negative number is reported as an invalid operation exception.
