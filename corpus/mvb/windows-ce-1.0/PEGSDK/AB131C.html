CommandBar_Show

The CommandBar_Show function shows or hides a command bar.

BOOL CommandBar_Show(// commctrl.h
HWND hwndCB,// handle of command bar
BOOL fShow// show state
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
fShow
Indicates whether to show or hide the command bar. Set this parameter to TRUE to show the command bar, or FALSE to hide it.
Return Values
Returns the previous show state of the command bar, TRUE if command bar was displayed, FALSE if it was hidden.
Remarks
Command bars are created with the show state set to TRUE. To hide the command bar before the window is displayed call this function before calling ShowWindow for the parent window.
