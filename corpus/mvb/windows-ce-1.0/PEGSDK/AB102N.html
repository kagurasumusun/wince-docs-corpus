SetColumnProperties

The SetColumnProperties function specifies the columns on which the Contacts database can be sorted.

BOOL SetColumnProperties(// addrstor.h
HHPRTAG *propList,// address of array of column property tags
int nColumns// number of property tags in array
);
Parameters
propList
Points to an array of up to four property tags that identify column properties on which the address cards can be sorted. Refer to Properties and Property Tags in the Contacts Database guide chapter for a list of these tags. Property tags begin with the HHPR_ prefix. If this parameter is NULL, the function uses the following property tags by default.
Value		Meaning
HHPR_SURNAMESort based on surnames.
HHPR_COMPANY_NAMESort based on company names.
HHPR_OFFICE_TELEPHONE_NUMBERSort based on the office telephone numbers.
HHPR_HOME_TELEPHONE_NUMBERSort based on home telephone numbers.
nColumns
Specifies the number of property tags in the propList array. If propList is NULL, this parameter is ignored.
Return Values
Returns TRUE if successful, or FALSE otherwise.
Remarks
The Contacts database must have been opened by a previous call to the OpenAddressBook function.
