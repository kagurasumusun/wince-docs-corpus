Shell_NotifyIcon

Sends a message to the system to add, modify, or delete an icon from the taskbar status area.

WINSHELLAPI BOOL WINAPI Shell_NotifyIcon(// shellapi.h
DWORD dwMessage,// message identifier
PNOTIFYICONDATA pnid// pointer to structure
);
Parameters
dwMessage
Identifier of the message to send. This parameter can be one of the following values.
Value		Meaning
NIM_ADDAdds an icon to the status area.
NIM_DELETEDeletes an icon from the status area.
NIM_MODIFYModifies an icon in the status area.
pnid
Pointer to a NOTIFYICONDATA structure. The content of the structure depends on the value of dwMessage.
Return Values
Returns TRUE if successful or FALSE otherwise.
