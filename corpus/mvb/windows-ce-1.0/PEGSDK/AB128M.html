RegOpenKeyEx

The RegOpenKeyEx function opens the specified key.

LONG RegOpenKeyEx(// winreg.h
HKEY hKey,// handle of open key
LPCWSTR lpszSubKey,// address of name of subkey to open
DWORD ulOptions,// reserved
REGSAM samDesired,// security access mask
PHKEY phkResult// address of handle of open key
);
Parameters
hKey
Identifies a currently open key or any of the following predefined reserved handle values:
· HKEY_CLASSES_ROOT
· HKEY_CURRENT_USER
· HKEY_LOCAL_MACHINE
· HKEY_USERS
lpszSubKey
Points to a null-terminated string containing the name of the subkey to open. If this parameter is NULL or a pointer to an empty string, the function will open a new handle of the key identified by the hKey parameter. In this case, the function will not close the handles previously opened. The string can be of the form TEXT("key1\key2\...\keyn"), where keyn is a subkey of key(n-1). Keyn is opened in this case. None of the other keys in the string need to be opened, and none are opened by RegOpenKeyEx.
ulOptions
Reserved; must be zero.
samDesired
Not used; can be any value. After a key is opened, any action valid on an open key may be performed.
phkResult
Points to a variable that receives the handle of the opened key.
Return Values
If the function succeeds, the return value is ERROR_SUCCESS. If the function fails, the return value is an error value.
Remarks
Unlike the RegCreateKeyEx function, the RegOpenKeyEx function does not create the specified key if the key does not exist in the registry. If one of the predefined keys is opened, no action is taken in the registry, and the hKey for the predefined key is returned.
