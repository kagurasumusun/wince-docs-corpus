Command Bar Buttons

You add buttons to a command bar by filling an array of TBBUTTON structures and calling the CommandBar_AddButtons function specifying the address of the array. Each TBBUTTON structure defines the attributes of a button. Button attributes include the image and string displayed in the button, the button state and styles, and the button command identifier. The CommandBar_InsertButton function lets you insert a button into a command bar. When calling the function, you specify the address of a single TBBUTTON structure, and the index of a button. The function inserts the new button to the left of the button with the specified index.
