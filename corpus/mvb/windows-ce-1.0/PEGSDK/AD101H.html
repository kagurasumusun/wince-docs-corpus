LB_SETANCHORINDEX

An application sends an LB_SETANCHORINDEX message to set the position of the anchor item.

wParam = (WPARAM) index; // index to set as anchor

lParam = 0; // not used, must be zero

Parameters

index

Value of wParam. Specifies the index of the list box item that will be the anchor.

Return Values

The return value is zero.

Remarks

This message sets the anchor by setting the internal value that represents the list box item most recently selected by the user pressing a mouse button. In a multiple-selection list box, the anchor item is the first or last item in a block of contiguous selected items.
