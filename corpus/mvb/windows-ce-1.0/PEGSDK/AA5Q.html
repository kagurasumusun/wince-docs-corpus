HTML Control Messages Summary

Following is a list of display messages defined by the HTML Control interface.

MessageDescription
DTM_ADDTEXTAdds text to the HTML Control.
DTM_ADDTEXTWUnicode version of DTM_ADDTEXT.
DTM_ANCHORTells the HTML control to jump to the indicated anchor.
DTM_ANCHORWUnicode version of DTM_ANCHORW.
DTM_ENABLESHRINKCauses HTML control to shrink images as required to make the page fit the window.
DTM_ENDOFSOURCEInforms the HTML Control that the document is complete.
DTM_IMAGEFAILInforms the HTML control that the load of the image indicated by the cookie could not be loaded.
DTM_SETIMAGEAssociates a bitmap with an image.
Following is a list of notification messages defined by the HTML Control interface.
Message		Description
NM_HOTSPOTSent if the user taps on a link or submits a form.
NM_INLINE_IMAGESent to notify the application to load the image.
NM_INLINE_SOUNDSent to notify the application to load the sound.
NM_METAContains the HTTP-EQUIV and CONTENT parameters of the META tag.
NM_TITLEContains the title of the HTML document.
