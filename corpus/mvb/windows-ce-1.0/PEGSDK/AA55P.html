<LINK>

The Link element indicates a relationship between the document and some other object. A document may have any number of Link elements. The Link element is empty (does not have a closing element), but takes the same attributes as the Anchor element. Typical uses are to indicate authorship, related indexes and glossaries, older or more recent versions, etc. Links can indicate a static tree structure in which the document was authored by pointing to a “parent” and “next” and “previous” document, for example. Servers may also allow links to be added by those who do not have the right to alter the body of a document.
