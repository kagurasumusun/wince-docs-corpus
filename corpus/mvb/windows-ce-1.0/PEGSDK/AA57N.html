TransportRelease

BOOL TransportRelease(
HANDLE hService// Service handle
);
The TransportRelease routine frees the memory heap and all resources allocated for this transport service (that is, by TransportInit). For the sample transport service, TransportRelease frees the heap allocated by TransportInit and also calls TransportDisconnect.
Parameters
hService
Handle to a SERVICE structure.
Return Value
Returns TRUE if successful or FALSE otherwise.
See Also
TransportInit, TransportDisconnect
