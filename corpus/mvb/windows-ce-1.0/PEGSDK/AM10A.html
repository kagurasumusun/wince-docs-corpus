Closing Windows

Windows should include Close buttons. Close is a command that applies to the window; removes the window. The impact of the Close command on user changes made within the window depends on context. If there are no changes or you automatically save changes, then the command should just remove the window. However, if your interface requires explicit user action to preserve changes, you should prompt the user if there are any unapplied changes in the window. This is the typical model when closing the primary window of an application or for property sheets. For other types of dialog boxes, you may use the button as an alias for Cancel; however, do so with caution. If there isn’t a Cancel action for the window or the Close action may be ambiguous, then it is better to avoid a Close button and only include buttons labeled for specific actions.
