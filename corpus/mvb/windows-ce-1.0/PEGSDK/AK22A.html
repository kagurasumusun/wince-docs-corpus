Remote Object Viewer

The Remote Object Viewer (Osview.exe) allows you to:

· Browse the Emulation file system and object store, the HPC file system and object store, and your local drive.

· Delete, move, and copy folders, files, and databases between the different object stores.

· View and change individual records within Windows CE and Emulation databases.

The first time you run the Remote Object Viewer, it will query you for an OK to add information to the desktop registry, to register the object viewer.
