MIPS Inline Assembler Syntax

As was previously described, _ _asm is treated as an extension to the C/C++ language. It could be viewed as having a prototype declaration as follows, with the string argument (char *) receiving special processing by the compiler:

void __asm(char *, ...);

In this syntax, the string argument is a null terminated character string consisting of one or more assembly language statements. Subsequent arguments are processed as if they were arguments to any C/C++ function call, but are passed as arguments to the assembly code described by the first string argument. For example, consider the following code:

__asm("mul %0, %1, %t0", 4, 5);

In this example, the reference to %0 refers to the first argument in the generated assembly code (with a value of 4) . In a similar fashion, %1 refers to the second argument to the generated assembly code (with a value of 5). See the arguments in the _ _asm statement for more details.

Within the string argument, an embedded semicolon (;) or newline (\n) is used to separate multiple assembly language statements. For example:

__asm(".set noat;"

"mult $1, $4 $5; "

".set at ");

Note that a semicolon is still required to separate statements, despite the fact that the strings are on separate physical lines in the source code.
