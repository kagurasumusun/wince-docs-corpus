CommandBar_Create

The CommandBar_Create function creates a command bar.

HWND CommandBar_Create(// commctrl.h
HINSTANCE hInst,// handle of application instance
HWND hwndParent,// handle of parent window
int idCmdBar// identifier of command bar
);
Parameters
hInst
Identifies the instance of the application in which the command bar is to be created.
hwndParent
Identifies the parent window for the command bar.
idCmdBar
Specifies the identifier of the command bar.
Return Values
If the function succeeds, the return value is the window handle of the command bar. If the function fails, the return value is NULL.
Remarks
This function creates an empty command bar.
