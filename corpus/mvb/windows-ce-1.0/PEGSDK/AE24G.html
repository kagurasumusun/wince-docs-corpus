PSN_RESET

Notifies a page that the user has chosen the Cancel button and the property sheet is about to be destroyed. All changes made since the user last chose the Apply Now button are canceled. This notification message is sent in the form of a WM_NOTIFY message.

lpnmhdr = (NMHDR FAR *) lParam;

Parameters

lpnmhdr

Address of an NMHDR structure. The hwndFrom member is the handle of the property sheet, and the hwndTo member is the handle of the page.

Return Values

No return value.

Remarks

An application can use this notification message as an opportunity to perform cleanup operations.

A page should not call the EndDialog function when processing this notification message.

See Also

EndDialog, NMHDR, SetWindowLong
