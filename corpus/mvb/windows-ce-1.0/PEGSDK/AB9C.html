CharUpperBuff

The CharUpperBuff function converts lowercase characters in a buffer to uppercase characters. The function converts the characters in place.

Windows CE Notes Supports only the Unicode version of this function.

DWORD CharUpperBuff(// winbase.h
LPTSTR lpsz,// pointer to buffer containing characters to process
DWORD cchLength// number of characters to process
);
Parameters
lpsz
Pointer to a buffer containing one or more characters to process.
cchLength
Specifies the size, in characters, of the buffer pointed to by lpsz.
The function examines each character, and converts lowercase characters to uppercase characters. The function examines the number of bytes or characters indicated by cchLength, even if one or more characters are null characters.
Return Values
If the function succeeds, the return value is the number characters. For example, if CharUpperBuff("Zenith of API Sets", 10) succeeds, the return value is 10.
