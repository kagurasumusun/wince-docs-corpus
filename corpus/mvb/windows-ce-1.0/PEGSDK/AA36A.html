Desktop Connectivity

Easy and powerful connectivity to desktop PCs running Windows 95 is a key feature of the HPC. The operating system supports functions for synchronizing data between machines, converting files, and installing applications.

Database Synchronization

The ability to synchronize databases on the device with a corresponding database on the desktop PC can add functionality to applications. The system automatically synchronizes the Schedule+ data on the desktop PC with the personal information manager applications on the device. You can write similar synchronization applications using the RAPI functions supported by Windows CE.

File Filters

Windows CE supports an API for converting files transferred between the desktop and the HPC. For example, not all of the features of Microsoft Word are incorporated into the pocket version running on the device. Before a Word document can be transferred for use on the device, items like unsupported fonts and OLE objects need to be converted or stripped from the file. Altering the files before they are transferred is accomplished with file filters.

A file filter is a DLL that controls the transfer between the desktop PC and the device. The HPC Explorer automatically adjusts file formats for some types of files and you can extend its file filtering capabilities by defining new application-specific filters of your own. See Chapter 12 “File Filters”, for more about existing filters and how to write new filters.

The Application Installation API

A distinct set of functions and load file commands are supported for installing applications on the HPC. These functions can be used to retrieve information about the device, load application files, update the registry, and create a script for unloading the file.
