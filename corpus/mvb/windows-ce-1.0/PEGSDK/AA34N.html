TransportErrorMsg

int TransportErrorMsg(
HANDLE hService// Service handle
LPWSTR szBuf// Buffer to hold error string
int iBufLen// length of szBuf, in chars
int *piSrcLine// Line where error occurred
);
TransportErrorMsg returns a string associated with an integer error number.
Parameters
hService
Handle to a SERVICE structure.
szBuf
Buffer to hold the error string.
iBufLen
Length of szBuff, in wide chars (that is, Unicode chars; not bytes).
piSrcLine
Line where the error occurred (retrieved from hService->iErrLine).
Return Value
A string describing the nature of the error is placed in szBuf, and the line number at which the error occurred is placed in piSrcLine.
Remarks
For example, the sample transport service returns one of the following error strings in szBuf.
Error String		String Resource Error Code
"No error"TRANS_ERR_NONE
"Service directory unavailable."TRANS_ERR_NO_SVC_DIR
"Could not allocate memory for service handle."TRANS_ERR_HANDLE_NOT_ALLOC
"Could not create message file."TRANS_ERR_CANT_OPEN
"Could not open mail message."TRANS_ERR_CANT_SEND
"Invalid message ID specified."TRANS_ERR_INV_MSG_ID
"Could not allocate message buffer."TRANS_ERR_NO_MSG_BUF
"There was an error reading the message."TRANS_ERR_READ
“Unknown Error”(String table containing error messages failed to load properly.)
