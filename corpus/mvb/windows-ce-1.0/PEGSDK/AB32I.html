ImageList_DragLeave

The ImageList_DragLeave function unlocks the given window and hides the drag image, allowing the window to be updated.

BOOL WINAPI ImageList_DragLeave(// commctrl.h
HWND hwndLock// handle of the window that owns the drag image
);
Parameters
hwndLock
Handle of the window that owns the drag image.
Return Values
Returns TRUE if successful or FALSE otherwise.
See Also
ImageList_DragEnter, ImageList_EndDrag
