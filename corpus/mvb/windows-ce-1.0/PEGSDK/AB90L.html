PegFindAllFiles

The PegFindAllFiles function retrieves information about all files in the given path of the Windows CE object store. The function copies information to an array of PEG_FIND_DATA structures. For more information about using RAPI functions, please see the Remote API Functions overview.

BOOL PegFindAllFiles(// rapi.h
LPCWSTR szPath,// address of pathname to search
DWORD dwFlags,// retrieval flags
LPDWORD lpdwFoundCount,// address of count of items
LPLPPEG_FIND_DATA ppFindDataArray// address of buffer for data
);
Parameters
szPath
Points to the name of the path in which to search for files.
dwFlags
Indicates the members of the PEG_FIND_DATA to be retrieved. This parameter can be one of the following values.
Value		Meaning
FAF_ATTRIBUTESRetrieve the file attributes and copy them to the dwFileAttributes member.
FAF_CREATION_TIMERetrieve the file creation time and copy it to the ftCreationTime member.
FAF_LASTACCESS_TIMERetrieve the time when the file was last accessed and copy it to the ftLastAccessTime member.
FAF_LASTWRITE_TIMERetrieve the time when the file was last written to and copy it to the ftLastWriteTime member.
FAF_SIZE_HIGHRetrieve the high-order DWORD value of the file size and copy it to the nFileSizeHigh member.
FAF_SIZE_LOWRetrieve the low-order DWORD value of the file size and copy it to the nFileSizeLow member.
FAF_OIDRetrieve the object identifier of the file and copy it to the dwOID member.
FAF_NAMERetrieve the filename and copy it to the cFileName member.
FAF_ATTRIB_CHILDRENIndicates that the given directory has child items.
lpdwFoundCount
Points to a variable that receives a count of the items found.
ppFindDataArray
Points to the address of an array of PEG_FIND_DATA structures that receive information about the found items. It is the application's responsibility to free the memory used by the array. To free the memory you must call RapiFreeBuffer.
Return Values
Returns TRUE if successful or FALSE if an error occurs.
