GetTickCount

The GetTickCount function retrieves the number of milliseconds that have elapsed since Windows was started.

DWORD GetTickCount(void);// winbase.h
Parameters
This function has no parameters.
Return Values
If the function succeeds, the return value is the number of milliseconds that have elapsed since Windows was started.
Remarks
The internal timer wraps around to zero if the system is run continuously for approximately 49.7 days.
