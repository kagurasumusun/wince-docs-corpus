RegDeleteKey

The RegDeleteKey function deletes a key and all its descendents.

LONG RegDeleteKey(// winreg.h
HKEY hKey,// handle of open key
LPCWSTR lpszSubKey// address of name of subkey to delete
);
Parameters
hKey
Identifies a currently open key or any of the following predefined reserved handle values:
· HKEY_CLASSES_ROOT
· HKEY_CURRENT_USER
· HKEY_LOCAL_MACHINE
· HKEY_USERS
The key specified by the lpszSubKey parameter must be a subkey of the key identified by hKey.
lpszSubKey
Points to a null-terminated string specifying the name of the key to delete. This parameter cannot be NULL, and the specified key must not have subkeys.
Return Values
If the function succeeds, the return value is ERROR_SUCCESS. If the function fails, the return value is an error value.
Remarks
If the function succeeds, RegDeleteKey removes the specified key from the registry. The entire key, including all of its values, is removed. Also note that if this key and/or any of its subkeys are open, it marks them as deleted in the open key list, but it does not remove them from that list (that is, this can only be performed by RegCloseKey.
To open the key, use the RegCreateKeyEx or RegOpenKeyEx function.
