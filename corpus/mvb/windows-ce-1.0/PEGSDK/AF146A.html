POINTSTOPOINT

The POINTSTOPOINT macro copies the contents of a POINTS structure into a POINT structure.

POINTSTOPOINT(
POINT pt,// POINT structure
POINTS pts// POINTS structure
);
Parameters
pt
Specifies the POINT structure to receive the contents of the POINTS structure. The POINT structure has the following form:
typedef struct tagPOINT {-// pt
LONG x;
LONG y;
} POINT;
pts
Specifies the POINTS structure to copy. The POINTS structure has the following form:
typedef struct tagPOINTS {-// pts
SHORT x;
SHORT y;
} POINTS;
Remarks
The POINTSTOPOINT macro is defined as follows:
#define POINTSTOPOINT(pt,pts) {-(pt).x = (SHORT)LOWORD(pts); \
(pt).y = (SHORT)HIWORD(pts);}
