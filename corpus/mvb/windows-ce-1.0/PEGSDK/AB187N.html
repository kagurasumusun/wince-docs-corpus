SetMenuItemInfo

Changes information about a menu item.

Windows CE Notes Only the following flags are valid for the MENUITEMINFO pmii->fMask:

· MIIM_DATA

· MIIM_ID

· MIIM_TYPE

If MIIM_TYPE is specified, then MENUITEMINFO pmii->fType must be the current type of the item, in other words, the type cannot be changed.

BOOL SetMenuItemInfo(// winuser.h
HMENU hmenu,
UINT uItem,
BOOL fByPosition,
LPCMENUITEMINFO pmii
);
Parameters
hmenu
Handle of menu .
uItem
Identifier or position of the menu item to change. The meaning of this parameter depends on the value of fByPosition.
fByPosition
If this parameter is FALSE, uItem is a menu item identifier. Otherwise, it is a menu item position.
pmii/
Constant pointer to a MENUITEMINFO structure.
