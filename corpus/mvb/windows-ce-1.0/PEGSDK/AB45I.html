ImageList_Draw

The ImageList_Draw function draws an image list item in the specified device context (DC).

BOOL WINAPI ImageList_Draw(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iDraw,// index of the image to draw
HDC hdcDst,// handle of the destination DC
int x,// location at which to draw within the specified DC
int y,// location at which to draw within the specified DC
UINT fStyle// flag specifying the drawing style
);
Parameters
himl
Handle of the image list.
iDraw
Index of the image to draw.
hdcDst
Handle of the destination DC.
x and y
Specify the x-coordinate and y-coordinate positions at which to draw within the specified DC.
fStyle
Flag specifying the drawing style. This parameter can be one or more of the following values.
Value		Meaning
ILD_BLENDSame as ILD_BLEND25.
ILD_BLEND25Draws the image, blending 25 percent with the system highlight color. This value has no effect if the image list does not contain a mask.
ILD_BLEND50Draws the image, blending 50 percent with the system highlight color. This value has no effect if the image list does not contain a mask.
ILD_FOCUSSame as ILD_BLEND25.
ILD_IMAGEDraws the image. Not recommended.
ILD_MASKDraws the mask. Not recommended.
ILD_NORMALDraws the image using the background color for the image list. If the background color is the CLR_NONE value, the image is drawn transparently using the mask.
ILD_OVERLAYMASKIsolates the one-based index of the overlay image to be drawn. Set the overlay image index using the INDEXTOOVERLAYMASK macro.
ILD_SELECTEDSame as ILD_BLEND50.
ILD_TRANSPARENTDraws the image transparently using the mask, regardless of the background color. This value has no effect if the image list does not contain a mask.
Return Values
Returns TRUE if successful or FALSE otherwise.
See Also
ImageList_DrawEx, INDEXTOOVERLAYMASK
