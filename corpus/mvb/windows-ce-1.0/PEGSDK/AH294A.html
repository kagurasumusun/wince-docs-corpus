11.1 Overview of Command Line Options

Command line options are detailed specifications of the assembly processing. Table 11.1 shows an overview of the command line options.

Table 11.1 Command Line Options

-NOOBJECT		Control output of an object module

-NOLIST		Control output of an assembler listing

Other specifications-wide[_listing]Shows up to 8 bytes of machine code or data per line in the assemble listing. Default is 4 bytes per line.
-nowide[_listing]Shows up to 4 bytes of machine code or data per line in the assemble listing. This is the default behavior.
-tab[_expand][=<number>]Expands tab characters in the assemble listing. The number, if specified, is the spacing of tab stops. Default is 8.
-Notab[_expand]Writes tab characters into the assemble listing unchanged. This is the default behavior.
-maxerr[ors]=<number>Aborts the assembly after <number> errors have been reported. Default is 100.
-Qsh<version>[r<revision>]Selects SH microprocessor version <version>, revision <revision> which controls the setting of the _M_SH and _M_SH_REV predefined symbols. Default is version 3, revision 6 (ie, -Qsh3r6).
-nologoInstructs not to print the logo banner (copyright notice) when it runs.
-help and -usage (currently identical)Output a detailed command line usage message and exit immediately.
-D<name>[=<number>]Predefines an equate; for example, -DFOO is equivalent to "FOO: .equ 1" in the source file; -DFOO=3 means "FOO: .equ 3".
The assembler listing is a listing to which the results of the assembly processing are output. See appendix C, Assembler Listing Example, for a detailed description of the assembler listing.
11.2 Command Line Option Reference
11.2.1 OBJECT/NOOBJECT: Object Module Output Control
11.2.2 DEBUG and NODEBUG: Debug Information Output Control
The assembler provides the following command line options concerned with object modules:
OBJECT/NOOBJECT: Command line options that control output of an object module
DEBUG/NODEBUG: Command line options that control output of debug information
11.2.1 OBJECT/NOOBJECT: Object Module Output Control
Syntax:
-OBJECT [= <object output file>] ; Abbreviated form: -O
-NOOBJECT ; Abbreviated form: -NOO
Description: The OBJECT option specifies output of an object module. The NOOBJECT option specifies no output of an object module. The object output file specifies the output destination for the object module. When the object output file parameter is omitted, the assembler takes the following actions:
· If the file format is omitted: The file format obj is supplied
· If the specification is completely omitted: The file format obj is appended to the name of the input source file (the first specified source file)
Do not specify the same file for the input source file and the output object file.
Relationship with Assembler Directives: The assembler gives priority to specifications made with command line options, as listed in Table 11.2.
Table 11.2 Command Line Option Specifications
Command Line Option		Assembler DirectiveResult

NOOBJECTRegardless of any specificationAn object module is not output
No specification.OUTPUT OBJAn object module is output
.OUTPUT NOOBJAn object module is not output

11.2.2 DEBUG and NODEBUG: Debug Information Output Control
Syntax:
-DEBUG ; Abbreviated form: -D
-NODEBUG ; Abbreviated form: -NOD
Description: The DEBUG option specifies output of debug information. The NODEBUG option specifies no output of debug information. The DEBUG and NODEBUG options are only valid in cases where an object module is being output.
See section 5.6.7, Object Module Assembler Directives, section 11.2.1, OBJECT/NOOBJECT: Object Module Output Control.
Relationship with Assembler Directives: The assembler gives priority to specifications made with command line options, as listed in Table 11.3.
Table 11.3 Command Line Option Priorities

Debug information is information required when debugging a program using the debugger or the emulator, and is part of the object module. Debug information includes information about source statement lines and information about symbols.

11.3.1 LIST/NOLIST: Assembler Listing Output Control
Syntax:
-LIST [ =<listing output file> ] ; Abbreviated form is -LIS
-NOLIST ; Abbreviated form is -NOLIS
Description: The LIST option specifies output of an assembler listing. The NOLIST option specifies no output of an assembler listing. The listing output file specifies the output destination file for the assembler listing. When the listing output file parameter is omitted, the assembler takes the following actions:
· If the file format is omitted, the file format lst is supplied
· If the specification is completely omitted, the file format lst is appended to the name of the input source file (the first specified source file)
Do not specify the same file for the input source file and the listing output file.

11.3.2 SHOW/NOSHOW: Source Program Listing Output Control
Syntax:
—SHOW [ = <output type> [, <output type>...]]
—NOSHOW [ = <output type> [, <output type>...]]
—SHOW [ = (<output type> [, <output type>...])]
—NOSHOW [ = (<output type> [, <output type>...])]
Output type: {-CONDITIONALS | DEFINITIONS | CALLS | EXPANSIONS | CODE}
Description: The SHOW option specifies output of preprocessor function source statements and object code lines in the source program listing. The NOSHOW option suppresses output of specified preprocessor function source statements and object code display lines in the source program listing. The items specified by output types will be output or suppressed depending on the option. When no output type is specified, all items will be output or suppressed:
· -SHOW: Output
· -NOSHOW: Not output (suppress)

11.3.3 LINES: Setting the Number of Lines in the Assembler Listing
Syntax:
—LINES=<line count> ; Abbreviated form is -LIN.
Description: LINES is the command line option that sets the number of lines on a single page of the assembler listing. The range of valid values for the line count is from 20 to 255.
The LINES specification is only valid in cases where an assembler listing is being output. See section 5.7.1, .PRINT: Assembler Listing Output Control, and section 11.3.1, LIST/NOLIST: Assembler Listing Output Control.
Relationship with Assembler Directives: The assembler gives priority to specifications made with command line options. Table 11.11 lists the results of the specifications.
