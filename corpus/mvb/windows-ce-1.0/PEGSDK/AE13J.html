TVN_DELETEITEM

Notifies a tree view control's parent window that an item has been deleted. This notification message is sent in the form of a WM_NOTIFY message.

pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv

Address of an NM_TREEVIEW structure. The itemOld member is a TV_ITEM structure containing valid information about the item that was deleted in the hItem and lParam members.

Return Values

No return value.

See Also
