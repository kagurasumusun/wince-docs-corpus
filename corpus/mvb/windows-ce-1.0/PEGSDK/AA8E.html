Records and Properties

A database consists of a set of records, each containing one or more data fields called properties. For example, a Contacts application would contain a database of address records, and the properties of each record might consist of a name, street address, city, state, zip code, and telephone number. The maximum size of a record is 128K. The maximum property size is 64K.

Each property in a record has an identifier that the system uses to sort database records and to locate properties to be read or modified. A property identifier is a two part, double word value of the type PEGPROPID. The high order word is an application-defined identifier, and the low order word is a predefined constant value that specifies the property's data type. The constants are defined in the Windows CE header files; they begin with the PEGVT_ prefix. An application can use the TypeFromPropID macro to extract the type from a property identifier.
