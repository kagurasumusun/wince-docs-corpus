EM_CANUNDO

An application sends an EM_CANUNDO message to determine whether an edit-control operation can be undone; that is, whether the control can respond to the EM_UNDO message. This message has no parameters.

wParam = 0;

lParam = 0;

Return Values

If the edit control can correctly process the EM_UNDO message, the return value is TRUE; otherwise, it is FALSE.
