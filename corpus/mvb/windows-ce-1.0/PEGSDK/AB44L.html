PegCopyFile

The PegCopyFile function is the RAPI version of the CopyFile function. See the CopyFile documentation for a description of the parameters and return values. . For more information about using RAPI functions, please see the Remote API Functions overview.

BOOL PegCopyFile(// rapi.h
LPCWSTR IN lpExistingFileName,// address of name of existing file
LPCWSTR IN lpNewFileName,// address of filename to copy to
BOOL IN bFailIfExists// flag for operation if file exists
);
Parameters
lpExistingFileName
Points to a null-terminated string that specifies the name of an existing file.
lpNewFileName
Points to a null-terminated string that specifies the name of the new file.
bFailIfExists
Specifies how this operation is to proceed if a file of the same name as that specified by lpNewFileName already exists. If this parameter is TRUE and the new file already exists, the function fails. If this parameter is FALSE and the new file already exists, the function overwrites the existing file and succeeds.
