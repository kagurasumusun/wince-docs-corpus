Message Headers

Each message has a header consisting of entries with two fields: a name and a value. The name fields are separated from the value fields by a NULL character, and the entries are separated from each other by a NULL character. The header string is terminated with two consecutive NULL characters.

For example a message header might contain the following fields.

Name FieldValue Field
Tobillg@microsoft.com
Fromgmarshall@cbs.com
ccdrather@cbs.com
SubjectMicrosoft Evening News
The fields in the header are wide character strings that can be accessed using the MailGetField and MailSetField functions. These functions use the name of the field to get a pointer to the string in the header; this way it can be used without allocating space for the string somewhere else. The names being located with MailGetField and MailSetField are not case-sensitive.
One special name field entry in the header is the “Type”. If the value field of this entry matches the name of a dynamic-link library registered with the system, the body of the message is given to that DLL for processing. The technique for launching an application when a particular type of message is received is discussed in more detail in the section describing the TransportView function in Chapter TBD “The Mail Transport Service.”
