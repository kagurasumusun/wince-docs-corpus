LoadIcon

The LoadIcon function loads the specified icon resource from the executable (.EXE) file associated with an application instance.

Windows CE Notes Predefined icons (IDI_*) are not supported.

The icon must be a two bit per pixel (.ic2) icon or a monochrome icon.

HICON LoadIcon(// winuser.h
HINSTANCE hInstance,// handle of application instance
LPCTSTR lpIconName// icon-name string or icon resource identifier
);
Parameters
hInstance
Identifies an instance of the module whose executable file contains the icon to be loaded.
lpIconName
Points to a null-terminated string that contains the name of the icon resource to be loaded. Alternatively, this parameter can contain the resource identifier in the low-order word and zero in the high-order word. Use the MAKEINTRESOURCE macro to create this value.
Return Values
If the function succeeds, the return value is the handle of the newly loaded icon. If the function fails, the return value is NULL. To get extended error information, call GetLastError.
Remarks
For Windows CE an icon loaded by LoadIcon will exist until the process which loaded the icon terminates. Each call to LoadIcon returns a new handle even if all the handles represent the same icon. Calling LoadIcon repeatedly on the same icon resource is inefficient. To conserve memory, call LoadIcon only once and save the return value for all subsequent uses.
