EM_GETLINECOUNT

An application sends an EM_GETLINECOUNT message to retrieve the number of lines in a multiline edit control. This message has no parameters.

wParam = 0;

lParam = 0;

Return Values

The return value is an integer specifying the number of lines in the multiline edit control. If no text is in the edit control, the return value is one (1).
