ImageList_Remove

The ImageList_Remove function removes an image from an image list.

BOOL WINAPI ImageList_Remove(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iRemove// index of the image to remove
);
// Related macro
BOOL ImageList_RemoveAll(
himl
// handle of the image list, and the index of the image to remove
);
Parameters
himl
Handle of the image list.
iRemove
Index of the image to remove. If the iRemove parameter is –1, the function removes all images.
Return Values
Returns TRUE if successful or FALSE otherwise.
