ImageList_Replace

The ImageList_Replace function replaces an image in an image list with a new image.

BOOL WINAPI ImageList_Replace(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iReplace,// index of the image to replace
HBITMAP hbmImage,// handle of the bitmap that contains the image
HBITMAP hbmMask// handle of the bitmap that contains the mask
);
Parameters
himl
Handle of the image list.
iReplace
Index of the image to replace.
hbmImage
Handle of the bitmap that contains the image.
hbmMask
Handle of the bitmap that contains the mask. If no mask is used with the image list, this parameter is ignored.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
This function copies the bitmap to an internal data structure. Be sure to use the DeleteObject function to delete hbmImage and hbmMask after the function returns.
