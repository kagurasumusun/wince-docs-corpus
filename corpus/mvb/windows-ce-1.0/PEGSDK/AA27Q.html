DTM_ENDOFSOURCE

An application sends a DTM_ENDOFSOURCE message to inform the HTML Control that the document is complete.

wParam = 0, // not used, must be zero

lParam = 0, // not used, must be zero

Parameters

This message uses no parameters..

Return Values

This message does not return a value.

Remarks

This implies that no more text will be added until the document is cleared. This allows the HTML Control to nicely clean up error conditions resulting from incomplete data or bad HTML text.
