Button States

Each button in a command bar has a current state. The command bar updates a button state to reflect user actions, such as tapping the button. The state indicates whether the button is currently pressed or not pressed, enabled or disabled, hidden or visible. An application sets a button initial state when adding the button to the command bar. The application can change and retrieve the state by sending messages to the command bar. An application can use the TB_GETSTATE and TB_SETSTATE messages to retrieve and set the state of a button. For a list of command bar button states, see the description of the TBBUTTON structure in the Windows CE Programmer's Reference.
