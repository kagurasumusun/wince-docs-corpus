ImageList_Merge

The ImageList_Merge function creates a new image by combining two existing images. The function also creates a new image list to store the image.

HIMAGELIST WINAPI ImageList_Merge(// commctrl.h
HIMAGELIST himl1,// handle of the first image list
int iImage1,// index of first image
HIMAGELIST himl2,// handle of the second image list
int iImage2,// index of second image
int dx,// x-offset of the second image relative to the first image
int dy// y-offset of the second image relative to the first image
);
Parameters
himl1
Handle of the first image list
iImage1
Index of the first existing image.
himl2
Handle of the second image list.
iImage2
Index of the second existing image.
dx
x-coordinate offset of the second image relative to the first image.
dy
y-coordinate offset of the second image relative to the first image.
Return Values
Returns the handle of the new image list if successful or NULL otherwise.
Remarks
The new image consists of the second existing image drawn transparently over the first. The mask for the new image is the result of performing a logical OR operation on the masks of the two existing images.
