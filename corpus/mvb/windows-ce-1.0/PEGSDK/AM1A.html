Introduction

Microsoft® Windows CE™ is a new platform designed for portable computing. It provides a substantial subset of the Windows operating system, providing users with familiarity and consistency between their desktop environment and handheld PC.

Windows CE runs on handheld PCs that support the specifications outlined by Microsoft for this operating system, which includes a display screen, keyboard, and stylus. The stylus supports interaction similar to a PC mouse for pointing, selection, and direct manipulation of elements in the interface. The interface includes most of the standard components found in Windows, including the desktop, taskbar, windows , icons, and controls.
