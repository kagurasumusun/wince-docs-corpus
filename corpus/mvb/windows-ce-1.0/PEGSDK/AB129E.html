ExtensionPropSheetPageProc

Specifies an application-defined callback function that receives the address of the AddPropSheetPageProc function, which resides in the module that creates a property sheet. A property sheet extension must export the ExtensionPropSheetPageProc function.

BOOL CALLBACK ExtensionPropSheetPageProc(
LPVOID lpv,// application defined value
LPFNADDPROPSHEETPAGE lpfnAddPropSheetPageProc,// address of AddPropSheetPage function
LPARAM lParam// application-defined 32-bit value
);
Parameters
lpv
Address of an application-defined value that describes an item for which a property sheet page is to be created. This parameter can be NULL.
lpfnAddPropSheetPageProc
Address of the AddPropSheetPageProc function. The extension dynamic-link library (DLL) calls this function to add a page to the property sheet.
lParam
Application-defined 32-bit value.
Return Values
Returns TRUE if success or FALSE otherwise.
