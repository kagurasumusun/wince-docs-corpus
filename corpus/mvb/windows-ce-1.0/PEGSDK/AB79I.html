ImageList_GetImageInfo

The ImageList_GetImageInfo function retrieves information about an image.

BOOL WINAPI ImageList_GetImageInfo(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iImage,// index of the image
IMAGEINFO FAR* pImageInfo// address of an IMAGEINFO structure
);
Parameters
himl
Handle of the image list
iImage
Index of the image.
pImageInfo
Address of an IMAGEINFO structure that receives information about the image. The information in this structure can be used to directly manipulate the bitmaps for the image.
Return Values
Returns TRUE if successful or FALSE otherwise.
