ImageList_ExtractIcon

Creates an icon or cursor based on an image and mask in an image list. ImageList_ExtractIcon is a macro that calls the ImageList_GetIcon function.

HICON WINAPI ImageList_ExtractIcon(
HINSTANCE hInst,
HIMAGELIST himl,
int iImage
);
Parameters
hInst
Ignored; set to zero.
himl and iImage
Handle of the image list, and the index of the image.
Return Values
Returns the handle of the icon or cursor if successful or NULL otherwise.
