ImageList_GetIconSize

The ImageList_GetIconSize function retrieves the dimensions of images in an image list.

BOOL WINAPI ImageList_GetIconSize(// commctrl.h
HIMAGELIST himl,// handle of the image list
int FAR *cx,// pixel width of each image
int FAR *cy// pixel height of each image
);
Parameters
himl
Handle of the image list.
cx
Address of integer variable that receives the width, in pixels, of each image.
cy
Address of integer variable that receives the height, in pixels, of each image.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
All images in an image list have the same dimensions.
See Also
ImageList_SetIconSize, ImageList_GetIcon
