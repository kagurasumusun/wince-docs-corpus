NM_TREEVIEW

Contains information about a tree view notification message.

typedef struct _NM_TREEVIEW {-  nmtv
NMHDR    hdr;

UINT action;

TV_ITEM  itemOld;
TV_ITEM  itemNew;
POINT    ptDrag;

} NM_TREEVIEW;

typedef NM_TREEVIEW FAR *LPNM_TREEVIEW;

Members

hdr

Required for all WM_NOTIFY messages.

action

Notification-specific action flag.

itemOld

itemNew

Addresses of TV_ITEM structures that contain information about the new and old item states. Both members are zero for notification messages that do not use them.

ptDrag

POINT structure that contains the client coordinates of the mouse at the time the event occurred that caused the notification message to be sent.

Remarks

The address of this structure is specified as the lParam parameter of the WM_NOTIFY message for several tree view notification messages.
