AppendMenu

The AppendMenu function appends a new item to the end of the specified menu. You can use this function to specify the content, appearance, and behavior of the menu item.

Windows CE Notes Cascading menus are not supported (in other words, inserting an MF_POPUP menu into another pop-up menu is not supported.)

The following flags are NOT supported for the fuFlags parameter;

· MF_BITMAP

· MF_BREAK

· MF_MENUBARBREAK

· MF_DISABLED

· MFS_GRAYED

Note MF_GRAYED can be used in place of MF_DISABLED and MFS_GRAYED.

BOOL AppendMenu(// winuser.h
HMENU hMenu,// handle to menu
UINT fuFlags,// menu item flags
UINT idNewItem,// menu item identifier or pop-up menu handle
LPCTSTR lpszNewItem// menu item content
);
Parameters
hMenu
Identifies the menu the new item is being added to.
fuFlags
Specifies flags to control the appearance and behavior of the new menu item. This parameter can be a combination the following values:
Value		Description
MF_CHECKEDPlaces a check mark next to the item.
MF_ENABLEDEnables the menu item so that it can be selected and restores it from its grayed state.
MF_GRAYEDDisables the menu item and grays it so it cannot be selected.
MF_POPUPSpecifies that the menu item is a pop-up item, that is, selecting it activates a pop-up menu. The idNewItem parameter specifies the handle to the pop-up menu. This flag is used to add a pop-up item to a menu bar.
MF_SEPARATORDraws a horizontal dividing line. This flag is only used in a pop-up menu. The line cannot be grayed, disabled, or highlighted. The lpszNewItem and idNewItem parameters are ignored.
MF_STRINGSpecifies that the menu item is a text string; the lpszNewItem parameter points to the string.
MF_UNCHECKEDDoes not place a check mark next to the item (default).
MF_OWNERDRAWContains a 32-bit value supplied by the application that can be used to maintain additional data related to the menu item. The value is in the itemData member of the structure pointed to by the lparam parameter of the WM_MEASURE or WM_DRAWITEM message sent when the menu is created or updated.
The following list shows groups of flags that cannot be used together:
· MF_ENABLED and MF_GRAYED
· MF_CHECKED and MF_UNCHECKED
· MF_STRING and MF_OWNERDRAW
idNewItem
Specifies either the identifier of the new menu item or, if the fuFlags parameter is set to MF_POPUP, the handle to the pop-up menu.
lpszNewItem
Specifies the address of a null-terminated string specifying the new menu item.
Return Values
Returns TRUE if successful or FALSE otherwise. To get extended error information, call GetLastError.
