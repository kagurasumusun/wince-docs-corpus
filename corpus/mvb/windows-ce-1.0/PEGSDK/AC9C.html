PEGDB_FIND_DATA

The PEGDB_FIND_DATA structure contains information about a database in the Windows CE object store. This structure is used by the PegFindAllDatabases function.

struct PEGDB_FIND_DATA {-

PEGOID OidDb;

PEGDBASEINFO DbInfo;

};

Members

OidDb

Specifies the object identifier of a database in the Windows CE object store.

DbInfo

Specifies a PEGDBASEINFO structure that contains information about a database.
