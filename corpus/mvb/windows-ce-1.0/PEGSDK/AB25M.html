RasGetEntryDevConfig

This function retrieves the device information saved by the last successful call to RasSetEntryDevConfig.

DWORD RasGetEntryDevConfig(// afdfunc.h
LPCTSTR lpszPhoneBook,// full path and file name of the phone book file
LPCTSTR szEntry,// existing entry name
LPDWORD pdwDeviceID,// Returns the saved device ID
LPDWORD pdwSize,// size of the structure pointed to by pDeviceConfig
LPVARSTRING pDeviceConfig// where the device configuration structure is returned
);
Parameters
lpszPhoneBook
Points to a null-terminated string that specifies the full path and file name of the phone book file. This parameter can be NULL, in which case the default phone book file is used. This parameter should always be NULL for Windows 95 and Windows CE since the phone book entries are stored in the registry.
szEntry
Points to a null-terminated string containing an existing entry name.
pdwDeviceID
Returns the saved device ID.
pdwSize
Points to the size of the structure pointed to by pDeviceConfig. This should be filled with the size required.
pDeviceConfig
Specifies a pointer to the memory location of the type VARSTRING where the device configuration structure is returned. If NULL then only the correct size is returned.
Return Values
If the function succeeds, the return value is zero. If the function fails, the return value will be set to an error code.
Error Code		Description
ERROR_CANNOT_OPEN_PHONEBOOKInvalid phone book.
ERROR_CANNOT_FIND_PHONEBOOK_ENTRYInvalid szEntry.
ERROR_INVALID_PARAMETERInvalid szEntry, pdwDeviceID or pdwSize parameter.
ERROR_BUFFER_TOO_SMALLSpecified buffer was too small.
Remarks
An example of how to use this function follows:
DWORD dwDeviceID;
LPVARSTRING pDeviceConfig;
DWORD dwSize;
dwSize = 0;
if (RasGetEntryDeviceConfig (NULL, EntryName, &dwDeviceID,
&dwSize, NULL)) {-
DEBUGMSG (1, (TEXT("Error getting device info size\r\n")));
return;
}
pDeviceConfig = LocalAlloc (LPTR, dwSize);
if (RasGetEntryDeviceConfig (NULL, EntryName, &dwDeviceID,
&dwSize, pdwDeviceConfig)) {-
DEBUGMSG (1, (TEXT("Error getting device info\r\n")));
return;
} else {-
DEBUGMSG (1, (TEXT("dwDeviceID=%d\r\n"), dwDeviceID));
if (pDeviceConfig) {-
DEBUGMSG (1, (TEXT("Have a device config @ 0x%X\r\n"),
pDeviceConfig));
LocalFree(pDeviceConfig);
}
