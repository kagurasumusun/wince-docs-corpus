SHAddToRecentDocs

Adds a document to the shell's list of recently used documents or clears all documents from the list. The user gains access to the list through the Start menu of the Windows taskbar.

WINSHELLAPI void WINAPI SHAddToRecentDocs(// shellapi.h
UINT uFlags,
LPCVOID pv
);
Parameters
uFlags
Flag that indicates the meaning of the pv parameter. This parameter can be one of the following values.
Value		Meaning
SHARD_PATHpv is the address of a path string.
SHARD_PIDLpv is the address of an item identifier list.
pv
Pointer to a buffer that contains the path and file name of the document, or the address of an ITEMIDLIST structure that contains an item identifier list uniquely identifying the document. If this parameter is NULL, the function clears all documents from the list.
Return Values
No return value.
