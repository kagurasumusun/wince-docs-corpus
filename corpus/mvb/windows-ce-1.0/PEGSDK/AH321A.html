Section 1 Features

The SH-3 has RISC-type instruction sets. Basic instructions are executed in one clock cycle, which dramatically improves instruction execution speed. The CPU also has an internal 32-bit architecture for enhanced data processing ability. Table 1.1 lists the SH-3 CPU features.

Table 1.1 SH-3 CPU Features
