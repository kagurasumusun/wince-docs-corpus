EM_UNDO

An application sends an EM_UNDO message to undo the last edit control operation. This message has no parameters.

wParam = 0;

lParam = 0;

Return Values

For a single-line edit control, the return value is always TRUE. For a multiple-line edit control, the return value is TRUE if the undo operation is successful, or FALSE if the undo operation fails.

Remarks

An undo operation can also be undone. For example, you can restore deleted text with the first EM_UNDO message, and remove the text again with a second EM_UNDO message as long as there is no intervening edit operation.
