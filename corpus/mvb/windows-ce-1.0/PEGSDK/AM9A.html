Sizing Windows

Because of limited display screen space, you should design your application’s primary window to always be full screen, unless your application may be used in context with another application, such as Windows CE Help application or Windows CE Calculator application, where the user benefits from seeing the window under the active application. In the latter situation, design your primary window to be a fixed size, because Windows CE provides no support for user sizing of windows. Maximize and Minimize buttons are also not supported. To minimize a primary window, a user taps the representative button in the taskbar. Restoring the window is supported in the same way. Secondary windows (dialog boxes, property sheets, and message boxes) can either be full screen or smaller.
