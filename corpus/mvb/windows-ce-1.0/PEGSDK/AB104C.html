CommandBar_GetMenu

The CommandBar_GetMenu function retrieves the menu handle for a button on the command bar.

HMENU CommandBar_GetMenu(// commctrl.h
HWND hwndCB,// handle of command bar
int iButton// index of button
);
Parameters
hwndCB
Handle identifying the command bar. This handle is returned when the command bar is created by the CommandBar_Create function.
iButton
Specifies the zero-based index of a button. This button is assumed to be a menu bar.
Return Values
If the function succeeds, the return value is the menu handle. If the function fails, the return value is NULL.
Remarks
If the iButton parameter does not identify a menu, this function will fail.
