Application Busy Feedback

Unlike Windows, Windows CE does not support a mouse pointer (sometimes called a cursor). However, the operating system does support a busy animation on the screen to indicate when an interface is processing and cannot accept user input. The Windows CE busy animation should be displayed when your application has been asked to execute a command that renders the current window, or the system as a whole, unresponsive to user input. When displayed only for the current window, the user may continue to interact with other windows, including the taskbar.
