Using the Application Loader

The following example shows the contents of a load file that could be used to load the HPC Explorer on the HPC. This load file performs the following tasks:

· It creates registry keys and values to associate files with an .htm extension with the application.

· It registers the icons for the application and associated files.

· It registers the version number of the application.

· It copies the program files to the device.

· It creates three shortcuts to the application.

// Create the registry keys that associate .htm files with HPC Explorer.

regKeyCreate HKEY_CLASSES_ROOT .htm 1

regKeyCreate HKEY_CLASSES_ROOT piefile 1

regKeyCreate HKEY_CLASSES_ROOT piefile\DefaultIcon 1

regString HKEY_CLASSES_ROOT .htm 1 Default "piefile"

regString HKEY_CLASSES_ROOT piefile 1 Default "Internet Document (HTML)"

regString HKEY_CLASSES_ROOT piefile\DefaultIcon 1 Default "%P\webview.exe,-2000"

regString ~ ~ 1 VersionNumber "1.0"

// Copy the files from the desktop PC to the HPC

// Usage: copy <source dir> <dest dir> <filename>

//        copyShared <source dir> <dest dir> <filename>

copyShared . \Windows htmlview.dll

copy . . webview.exe

copy . . readme.htm

copy . \Windows peghome.htm

copy . \Windows peg.gif

copy . \Windows "HPC Explorer Help.htc"

copy . \Windows ie_favor.htp

copy . \Windows ie_ops.htp

copy . \Windows ie_tips.htp

// Create the shortcuts.

// One on the desktop and one to replace the one in the Communcation

// folder that points to the old version.

createShortcut \Windows\Desktop "HPC IE.lnk" . webview.exe

createShortcut "\Program Files\Communication" "HPC IE.lnk" . webview.exe

createShortcut "\Windows\Programs\Communication" "HPC IE.lnk" . webview.exe

// Exit the script

exit
