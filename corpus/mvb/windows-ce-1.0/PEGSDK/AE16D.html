HDN_ITEMCHANGING

Notifies a header control's parent window that the attributes of a header item are about to change. This notification message is sent in the form of a WM_NOTIFY message.

phdr = (HD_NOTIFY FAR *) lParam;

Parameters

phdr

Address of an HD_NOTIFY structure that contains information about the header control and the header item, including the attributes that are about to change.

Return Values

Returns FALSE to allow the changes or TRUE to prevent them.

See Also

HD_NOTIFY, HDM_SETITEM, WM_NOTIFY
