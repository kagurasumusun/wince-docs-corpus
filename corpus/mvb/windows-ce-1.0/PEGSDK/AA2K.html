Initializing RAPI

Before any RAPI calls can be made, the system must be initialized by calling the PegRapiInit function. This sets up the communications link between the PC and the handheld PC (HPC) and performs other routine initialization. Upon completion of using RAPI, the PegRapiUninit function should be called to terminate the connection and cleanup. Creating and terminating connections are fairly expensive operations so it is recommended that you establish and terminate the link only once and not on a per-call basis.
