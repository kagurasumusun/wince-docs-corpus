Load_Exit

Stops the Remote Procedure Call (RPC) services initialized by Load_Init.

void Load_Exit(void);// ppcload.h
Parameters
This function has no parameters.
Return Value
None.
Remarks
This function requires a prior successful call to the Load_Init function.
This function is exported by Ppcload.dll, which runs on the desktop PC—it is intended to be called from a setup program.
