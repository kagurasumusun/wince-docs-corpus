HDM_HITTEST

Tests a point to determine which header item, if any, is at the specified point.

wParam = 0;

lParam = (LPARAM)(HD_HITTESTINFO FAR *) phdhti;

Parameters

phdhti

Address of an HD_HITTESTINFO structure that contains the position to test and receives information about the results of the test.

Return Values

Returns the index of the item at the specified position, if any, or –1 otherwise.
