ImageList_DragMove

The ImageList_DragMove function moves the image that is being dragged during a drag and drop operation. This function is typically called in response to a WM_MOUSEMOVE message.

BOOL WINAPI ImageList_DragMove(// commctrl.h
int x,// new drag position
int y// new drag position
);
Parameters
x and y
Specify the x-coordinate and y-coordinate for the new drag position.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
To begin a drag operation, use the ImageList_BeginDrag function.
See Also
ImageList_BeginDrag, WM_MOUSEMOVE
