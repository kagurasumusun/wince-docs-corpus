Opening the Contacts Database

Before an application can query or modify the Contacts database, the database must be opened using the OpenAddressBook function. The function fails with the ERROR_FILE_NOT_FOUND error if the Contacts database does not exist. In this case, the application can create the database by using the CreateAddressBook database function.

When calling CreateAddressBook, the application can identify up to four properties that can be used to sort the database. If the application does not specify any properties, the system uses the default properties surname, company name, office telephone number, and home telephone number. After creating the database, the application can call OpenAddressBook to open the database and specify the current sort order. The application must call the CloseAddressBook function when it finishes using the database.

The parameters of the OpenAddressBook function include the handle of a window that is to receive object store notification messages. The system sends notification messages to the window whenever another application modifies the Contacts database while your application has it open. These messages have the DB_PEGOID_ prefix and are defined in the Windbase.h header file. When an application receives a notification message, the RecountCards function can be used to recount the number of cards in the Contacts database.
