<FONT>

Used to set the current font.

SIZE

Size of current font can range from 1 to 7. A +N or -N is relative to the BASEFONT, while N provides an absolute setting of the current font. (Note that a FONT SIZE=-n, will always be relative to BASEFONT, while operations such as <SUB>, <SMALL>, and <BIG> will modify the current font size value.)

COLOR (Ignored in V1.0)

FACE

Sets the face or type of text, e.g. <FONT FACE=Arial>. A list of font names can be specified. If the first font is available on the system, it will be used, otherwise the second will be tried, and so on. If none is available, a default font will be used. The default font on the Pegasus is Arial.
