TBM_SETRANGEMIN

Sets the minimum position for the slider in a trackbar.

wParam = (WPARAM) fRedraw;

lParam = (LPARAM) lMinimum;

Parameters

fRedraw

Redraw flag. If this parameter is TRUE, the slider is redrawn after the range is set.

lMinimum

Minimum position for the slider.

Return Values

No return value.

See Also

TBM_GETRANGEMIN, TBM_SETRANGE, TBM_SETRANGEMAX
