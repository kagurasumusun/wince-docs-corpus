MailFree

The MailFree function returns storage space back to the system from a previous MailFirst, MailGet, or MailNext function call.

BOOL MailFree (// msgstore.h
MailMsg* pmm// Item information.
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
pmm
Points to the MailMsg structure being freed.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
Remarks
The message flags set before a call to retrieve a message from the message store determine whether the function needs to allocate memory. For more information about message flags, see the MailMsg structure in the structure section of this reference.
