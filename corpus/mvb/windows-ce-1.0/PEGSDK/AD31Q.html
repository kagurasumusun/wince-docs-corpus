TVM_GETEDITCONTROL

Retrieves the handle of the edit control being used to edit a tree view item's text. You can send this message explicitly or by using the TreeView_GetEditControl macro.

wParam = 0;

lParam = 0;

// Corresponding macro

HWND TreeView_GetEditControl(

hwnd

);

Parameters

hwnd

Handle of the tree view control.

Return Values

Returns the handle of the edit control if successful or NULL otherwise.
