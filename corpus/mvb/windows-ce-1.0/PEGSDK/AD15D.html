DB_PEGOID_RECORD_DELETED

The DB_PEGOID_RECORD_DELETED message is sent when a record has been deleted from the object store.

oidDeletedRec = (PEGOID) wParam; // identifier of deleted record

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidDeletedRec

Value of wParam. Identifies the record that was deleted.

oidParent

Value of lParam. Identifies the parent object of the deleted record.
