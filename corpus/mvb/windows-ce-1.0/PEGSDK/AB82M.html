RegCloseKey

The RegCloseKey function releases the handle of the specified key.

LONG RegCloseKey(// winreg.h
HKEY hKey// handle of key to close
);
Parameters
hKey
Identifies the open key to close.
Return Values
If the function succeeds, the return value is ERROR_SUCCESS. If the function fails, the return value is an error value.
Remarks
The handle for a specified key should not be used after it has been closed, because it will no longer be valid. Key handles should not be left open any longer than necessary.
The RegCloseKey function writes information to the registry before returning; therefore, there is no need to flush keys in the Windows CE registry.
