DB_PEGOID_FILE_DELETED

The DB_PEGOID_FILE_DELETED message is sent when a file has been deleted from the object store.

oidDeletedFile = (PEGOID) wParam; // identifier of deleted file

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidDeletedFile

Value of wParam. Identifies the file that was deleted.

oidParent

Value of lParam. Identifies the parent object of the deleted file.
