<OL>

The Ordered List element is used to present a numbered list of items, sorted by sequence or order of importance. Header not necessary for entire list, just add item to list stack, and each item should have the text of the “number” added to it’s text, in addition to the indent. See LI.

TYPE

A, a, I, i, 1 indicates list type.

START

Specifies what number to start at.
