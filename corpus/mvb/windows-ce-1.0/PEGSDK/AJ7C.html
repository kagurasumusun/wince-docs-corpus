Summary of What's New and Different

Standard Visual C++Visual C++ for Windows CE
Win32Win32 for Windows CE: essentially a subset
CRT FunctionsWindows CE CRT Functions: essentially a subset
CL native compilerCL used for native Emulation Environment
SHCL used for remote SH3 device (PegSH)
CLMIPS used for remote MIPS device (PegMIPS)
Common Development ToolsSame for Emulation Environment, plus remote versions of Spy, MemView, Zoomin and Regedit
MFC, OLE, EHMFC, OLE, and EH not supported
Versions 4.0, 4.1Version 4.0 only (version 4.1 is not supported in any way at this time)
Features new to this release include:
· All targets now use the integrated debugging tool; remote debugging no longer calls for WinDbg.
· All documentation is now provided within the integrated InfoViewer format; Windows CE information is no longer delivered in the WinHelp format.
