TAPI Line Device Messages

TAPI messages are used to notify the application of the occurrence of asynchronous events. When the status of the line device changes, a message is sent to the application that originated the request. The message provides a handle to the line device.

Following is a list of supported TAPI messages.

TAPI MessageMeaning
LINE_ADDRESSSTATESent when the status of an address changes on a line that is currently open by the application.
LINE_CALLINFOSent when the call information about the specified call has changed.
LINE_CALLSTATESent when the status of the specified call has changed.
LINE_CLOSESent when the specified line device has been forcibly closed.
LINE_DEVSPECIFICSent to notify the application about device-specific events occurring a line, address, or call.
LINE_DEVSTATESent when the state of a line device has changed.
LINE_REPLYSent to report the results of function calls that completed asynchronously.
LINE_REQUESTSent to report the results of function calls that completed asynchronously.
LINE_CREATESent to inform the application of the creation of a new line device.
LINE_REMOVESent to inform an application of the removal (deletion from the system) of a line device.
See the reference section of this document for a more complete description of the TAPI messages supported by the operating system.
