UDM_SETBUDDY

Sets the buddy window for an up-down control.

Windows CE Notes If hwndBuddy is not NULL, it must specify an edit control because up/down controls can only be buddied with edit controls.

wParam = (WPARAM)(HWND) hwndBuddy;

lParam = 0;

Parameters

hwndBuddy

Handle of the new buddy window. If this parameter is not NULL, an edit control must be specified.

Return Values

Returns the handle of the previous buddy window.
