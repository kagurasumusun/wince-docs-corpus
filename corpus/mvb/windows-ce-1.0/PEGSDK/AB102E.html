EnumWindowsProc

The EnumWindowsProc function is an application-defined callback function that receives top-level window handles as a result of a call to the EnumWindows function.

BOOL CALLBACK EnumWindowsProc(
HWND hwnd,// handle of parent window
LPARAM lParam// application-defined value
);
Parameters
hwnd
Identifies a top-level window.
lParam
Specifies the application-defined value given in EnumWindows.
Return Values
To continue enumeration, the callback function must return TRUE; to stop enumeration, it must return FALSE.
Remarks
The callback function can perform any desired task.
An application must register this callback function by passing its address to EnumWindows. EnumWindowsProc is a placeholder for the application-defined function name.
