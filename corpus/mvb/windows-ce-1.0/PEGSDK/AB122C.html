CommandBar_InsertMenubar

The CommandBar_InsertMenubar function inserts a menu bar into a command bar.

BOOL CommandBar_InsertMenubar(// commctrl.h
HWND hwndCB,// handle of command bar
HINSTANCE hInst,// handle of application instance
WORD idMenu,// resource identifier of menu
int iButton// index of a button
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
hInst
Identifies the instance of the application.
idMenu
Specifies the resource identifier of the menu to be inserted.
iButton
Specifies the zero-based index of a button. The function inserts the menu bar to the left of this button.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
Remarks
This function inserts an entire menu bar; it is the same type of menu as that used for the main menu of a Win32-based application.
