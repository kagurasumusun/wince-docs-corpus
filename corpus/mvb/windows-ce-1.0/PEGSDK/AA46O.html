remoteExec

remoteExec application [args]

The remoteExec statement causes Windows CE to begin executing an application.

Parameters

application

Specifies the path and file name of the executable module that contains the application. The path is relative to the directory specified by the loaddir command-line argument of the Load function. If this argument is NULL, the module name must be the first space-delimited token in the args string.

args

Specifies the command line arguments to pass to the application.
