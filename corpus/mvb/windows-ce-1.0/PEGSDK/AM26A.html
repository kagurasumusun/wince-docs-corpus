Power and Memory Management

Because Windows CE is used on portable handheld PCs, you need to take into consideration the limitations of such hardware in your design. For example, design for careful use and freeing of memory by supporting the Windows CE hibernation interface. In addition, after a user-configurable idle period, the system will automatically suspend (turn off). Any keyboard or touch input will restart the idle timer countdown. Most applications do not need to handle this situation. as their state will automatically be preserved. However, applications that want to use the modem, serial, or IrDA, can use system interfaces to reset the system timeout when appropriate.
