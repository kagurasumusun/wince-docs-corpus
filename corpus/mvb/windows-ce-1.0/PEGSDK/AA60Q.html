NM_INLINE_SOUND

The NM_INLINE_SOUND notification message is sent by the HTML control to notify the application to load the sound.

NM_HTMLVIEW *pnmHtmlView = (NM_HTMLVIEW *)lParam;
// points to NM_HTMLVIEW the structure

szSRCText = pnmHtmlView->szTarget; // contents of the SRC

// parameter of the BGSOUND tag

dwLoopCount = pnmHtmlView->dwCookie; // LOOP count value

switch(pnmHtmlView->hdr.code) {- // check HTML notification message

case NM_INLINE_SOUND:

};

Parameters

pnmHtmlView

Pointer to an NM_HTMLVIEW structure that contains information about the NM_INLINE_SOUND notification message.

szSRCText

String that contains the text from the SRC parameter of the BGSOUND tag in the HTML text.

dwLoopCount

Loop count value from the LOOP parameter of the BGSOUND tag.

Return Values

This message does not return a value.
