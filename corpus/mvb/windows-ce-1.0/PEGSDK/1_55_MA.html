SHCL Compiler Reference

The compiler-driver program SHCL.EXE is a 32-bit C/C++ compiler, which is used to compile and link 32-bit Hitachi SH3 C and C++ programs. The compiler produces Common Object File Format (COFF) object files. The linker produces executable files or dynamic-link libraries (DLLs).

SHCL will normally be configured and executed automatically from within Visual C in the Microsoft Developer Studio environment. This online reference to the command-line version of the compiler explains how SHCL functions behind the scenes when you choose a Win32p (PegSH) cross-development configuration.
