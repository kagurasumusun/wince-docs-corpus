ImageList_BeginDrag

The ImageList_BeginDrag function begins dragging an image.

BOOL WINAPI ImageList_BeginDrag(// commctrl.h
HIMAGELIST himlTrack,// handle of the image list
int iTrack,// index of the image to drag
int dxHotspot,// x-coordinate location of the drag position
int dyHotspot// y-coordinate location of the drag position
);
Parameters
himlTrack
Handle of the image list, obtained from ImageList_GetDragImage.
iTrack
Index of the image to drag.
dxHotspot
x-coordinate location of the drag position relative to the upper left corner of the image.
DyHotspot
x-coordinate location of the drag position relative to the upper left corner of the image.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
This function creates a temporary image list that is used for dragging. In response to subsequent WM_MOUSEMOVE messages, you can move the drag image by using the ImageList_DragMove function. To end the drag operation, you can use the ImageList_EndDrag function.
See Also
