TBM_GETTHUMBRECT

Retrieves the size and position of the bounding rectangle for the slider in a trackbar.

wParam = 0;

lParam = (LPARAM)(LPRECT) lprc;

Parameters

lprc

Address of a RECT structure that contains the bounding rectangle for the slider when the function returns.

Return Values

No return value.
