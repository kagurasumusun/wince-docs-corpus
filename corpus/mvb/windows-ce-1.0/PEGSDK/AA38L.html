IPegasusFileFilterSite::ReportLoss

The IPegasusFileFilterSite::ReportLoss member function is used by a file filter to report any information that it intentionally discarded during a file conversion. The file filter specifies a message that explains the data loss, and HPC Explorer formats and displays the message in a message box when the file conversion has completed. The file filter can specify either the identifier of a message table resource, or the address of a buffer that contains the message string.

STDMETHODIMP IPegasusFileFilterSite::ReportLoss(

DWORD dw, // Identifier of message

LPCTSTR psz, // Address of message string

va_list * Arguments // Address of array of message inserts

);

Parameters

dw

Specifies a 32-bit message identifier. The member function uses IPegasusFileFilter::FormatMessage to format the message. If the format fails (for example, the message identifier could not be recognized), then the system function FormatMessage is used.

psz

Points to the message string to display. This parameter should be NULL if the dw parameter is used.

Arguments

Points to an array of 32-bit values that are used as insert values in the formatted message. %1 in the format string indicates the first value in the Arguments array, %2 indicates the second argument, and so on.

Remarks

The interpretation of each 32-bit value depends on the formatting information associated with the insert in the message definition. The default is to treat each value as a pointer to a null-terminated string. By default, the Arguments parameter is of type va_list*, which is a language- and implementation-specific data type for describing a variable number of arguments.

Return Value

No return value.
