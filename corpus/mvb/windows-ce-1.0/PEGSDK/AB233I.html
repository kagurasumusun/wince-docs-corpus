IsRectEmpty

The IsRectEmpty function determines whether the specified rectangle is empty. An empty rectangle is one that has no area; that is, the coordinate of the right side is less than or equal to the coordinate of the left side, or the coordinate of the bottom side is less than or equal to the coordinate of the top side.

BOOL IsRectEmpty(// winuser.h
const RECT *lprc// address of structure with rectangle
);
Parameters
lprc
Points to a RECT structure that contains the logical coordinates of the rectangle.
Return Values
If the rectangle is empty, the return value is TRUE; otherwise, it is FALSE. To get extended error information, call GetLastError.
