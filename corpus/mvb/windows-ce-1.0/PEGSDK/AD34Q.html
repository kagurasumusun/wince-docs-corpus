TVM_GETIMAGELIST

Retrieves the handle of the normal or state image list associated with a tree view control. You can send this message explicitly or by using the TreeView_GetImageList macro.

wParam = (WPARAM) iImage;

lParam = 0;

// Corresponding macro

HIMAGELIST TreeView_GetImageList(

hwnd,

iImage

);

Parameters

hwnd

Handle of the image list.

iImage

Type of image list to retrieve. This parameter can be one of the following values.

ValueMeaning
TVSIL_NORMALRetrieves the normal image list, which contains the selected and nonselected images for the tree view item.
TVSIL_STATERetrieves the state image list, which contains the images for tree view items that are in a user-defined state.
LVSIL_HEADERImageList used for report view header.
Return Values
Returns the handle of the image list.
