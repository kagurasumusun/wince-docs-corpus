EndPaint

The EndPaint function marks the end of painting in the specified window. This function is required for each call to the BeginPaint function, but only after painting is complete.

BOOL EndPaint(// winuser.h
HWND hWnd,// handle to window
CONST PAINTSTRUCT *lpPaint// pointer to structure for paint data
);
Parameters
hWnd
Identifies the window that has been repainted.
lpPaint
Points to a PAINTSTRUCT structure that contains the painting information retrieved by BeginPaint.
Return Values
This function always returns TRUE.
Remarks
If the caret was hidden by BeginPaint, EndPaint restores the caret to the screen.
See Also
BeginPaint, PAINTSTRUCT
