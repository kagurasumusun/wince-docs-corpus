DTM_SETIMAGE

An application sends a DTM_SETIMAGE message to associate a bitmap with an image.

wParam = 0, // not used, must be zero

lParam = (LPARAM)(LPINLINEIMAGEINFO) lpInlineImageInfo;

// points to image information

Parameters

lpInlineImageInfo

Pointer to an INLINEIMAGEINFO structure that contains information about the bitmap image.

Return Values

This message does not return a value.

See Also

INLINEIMAGEINFO, NM_INLINE_IMAGE, DTM_IMAGEFAIL
