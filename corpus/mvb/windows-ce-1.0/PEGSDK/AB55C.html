CloseClipboard

The CloseClipboard function closes the clipboard.

BOOL CloseClipboard(void)// winuser.h
Parameters
This function has no parameters.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE. To get extended error information, call GetLastError.
Remarks
When the window has finished examining or changing the clipboard it must close the clipboard by calling CloseClipboard. This enables other windows to access the clipboard.
Do not place an object on the clipboard after calling CloseClipboard.
