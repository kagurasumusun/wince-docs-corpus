IPegasusFileFilter::FilterOptions

The IPegasusFileFilter::FilterOptions method displays a dialog box that lets the user select among the file filtering options supported by a file filter.

STDMETHODIMP IPegasusFileFilter::FilterOptions(

HWND hwndParent // Handle of parent window

);

Parameters

hwndParent

Specifies the handle of the parent window for the filtering options dialog box.

Return Value

If the creating the options dialog succeeds, the function should return NOERROR. If the function fails, the function should return an HRESULT error value.

Remarks

A file filter that includes user selectable conversion options should implement a IPegasusFileFilter::FilterOptions method. HPC Explorer will call the filter's IPegasusFileFilter::FilterOptions method when the user selects a supported conversion type from the conversion selection dialog box and pressed the Options button. The IPegasusFileFilter::FilterOptions function should display a dialog box that lets the user select among the conversion options supported by the file filter.
