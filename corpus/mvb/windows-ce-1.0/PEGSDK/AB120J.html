Load_PegFreeSpace

This function returns the amount of memory available for storing applications on the device.

DWORD Load_PegFreeSpace(void);// ppcload.h
Parameters
This function has no parameters.
Return Value
This function returns the number of bytes of unused memory remaining in the object store.
Remarks
This function requires a prior successful call to the Load_Init function.
This function is exported by Ppcload.dll, which runs on the desktop PC—it is intended to be called from a setup program.
