Command Bars

Windows CE integrates an application’s title bar, menu bar, and toolbar into a single interface area called a command bar. The command bar may include as its first elements a menu section that provides access to the application’s drop-down menus. The menu titles appear as bold text surrounded by a rectangular frame. A title bar icon is not included.

A command bar

Command bars support only the inclusion of menus, drop-down combo boxes, and toolbar button controls. Button controls follow the conventions of Windows toolbars; that is, they can be implemented to support either command or state setting interaction (such as check box and option button support). Therefore, you can use command bar controls for more than direct actions. For example, you can use them to enable users to toggle between different views, reducing the complexity or clutter of information shown in your window.

Access keys and shortcut keys may be assigned to command buttons. The buttons may also be part of the TAB and ARROW KEY input focus navigation order. The SPACEBAR and ENTER activate a command button after the user moves input focus to the button.

You can define tooltips for your command bar buttons. Typically, these include the name of the command, but you may include additional descriptive text as well as the shortcut keys that you assign to the commands. If you include shortcut keys, use the following conventions.

· Place the shortcut key text after the tip, in parentheses.

· Include two spaces before the first parenthesis.

· Use first letter capitalization for modifier keys (for example, Ctrl not CTRL).

· Use all uppercase for all single-character keys (for example, B not b)

· Use the PLUS SIGN (+), with no spaces, between each part of the shortcut (for example, Ctrl+B, not Ctrl + B).

While tootips allow you to provide textual descriptions for your command bar buttons, you may want to include text as part of the button label for buttons that are frequently accessed or difficult to distinguish, if you have sufficient space in your command bar. Note that command buttons only support graphics, so to include text, you must make the text a part of the graphic image you include for the button’s label.

Command bars are typically included only in primary windows, although you can include command buttons for OK, Cancel, and Help (the ? button) in the title bar of your secondary windows.
