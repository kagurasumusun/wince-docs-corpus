Load_AlreadyInstalled

Determines whether the application has already been installed on the Handheld PC

BOOL Load_AlreadyInstalled(// ppcload.h
LPSTRlpszAppName// pointer to a string
);
Parameters
lpszAppName
Pointer to string passed in to the function with the name of your application.
Return Value
This function returns one of the following values.
Value		Description
TRUEThe application is currently installed, or an error occurred.
FALSEThe application is not currently installed.
Remarks
This function requires a prior successful call to the Load_Init function.
This function is exported by Ppcload.dll, which runs on the desktop PC—it is intended to be called from a setup program.
If an error occurred during this function, it returns TRUE, so that the caller can prevent accidental overwriting.
The application must have been installed using the Application Loader before this function acknowledges that it has been installed. If the application was put on the device using the HPC Explorer drag and drop method, the Load_AlreadyInstalled function will not find the application.
