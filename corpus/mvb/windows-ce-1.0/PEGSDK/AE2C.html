EN_ERRSPACE

The EN_ERRSPACE notification message is sent when an edit control cannot allocate enough memory to meet a specific request. The parent window of the edit control receives this notification message through the WM_COMMAND message.

idEditCtrl = (int)LOWORD(wParam); // identifier of edit control

hwndEditCtrl = (HWND) lParam; // handle of edit control
