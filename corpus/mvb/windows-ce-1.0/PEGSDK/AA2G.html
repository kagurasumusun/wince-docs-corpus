Types of Notifications

The system can generate two main types of notifications, user and application.

A user notification is designed to alert the user about a timer event. The notification may require the user to perform some action to handle the notification or may generate a sound to alert the user. For example, the system may display a dialog box and play a sound before a scheduled appointment. The user would tap the dialog box OK button to acknowledge the appointment. User notifications are always associated with an application.

An application notification starts an application at a specified time or when a system event occurs. When an application starts as the result of a notification, the system specifies a command line parameter that identifies the event that has occurred.

The main difference between a user notification and an application notification is that a user notification is handled entirely by the operating system and an application notification starts application code. Also, a user notification alerts the user and an application notification may or may not alert the user.
