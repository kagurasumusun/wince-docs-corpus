Using the Built-In IR Port

Using the built-in IR port is similar to using the built-in serial port, except that communication must be “redirected” to the IR device using the EscapeCommFunction funtion:

1. Open the built-in serial port by performing CreateFile on device COM1.

2. Get the existing communication port settings by calling GetCommState.

3. Setup the communication port using the device-control block (a DCB structure) and calling SetCommState .

4. Call EscapeCommFunction (passing the handle returned from CreateFile) with dwFunc set to the value SETIR. This directs serial communication to the built-in IR port (referenced as COM3 on the HPC).

5. Perform ReadFile and WriteFile operations on the device handle returned from CreateFile. Open the built-in serial port by performing CreateFile on device COM1.
