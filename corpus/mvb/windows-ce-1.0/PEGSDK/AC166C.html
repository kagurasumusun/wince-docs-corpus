TV_KEYDOWN

Contains information about a keyboard event in a tree view control.

This structure is used with the TVN_KEYDOWN notification message.

typedef struct _TV_KEYDOWN {- tvkd
NMHDR hdr;

WORD wVKey;

UINT flags;

} TV_KEYDOWN;

Members

hdr

Required for all WM_NOTIFY messages.

wVKey

Virtual-key code.

flags

Always zero.

See Also

TVN_KEYDOWN, WM_NOTIFY
