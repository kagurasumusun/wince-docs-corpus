Paragraphs

Tags which Delineate Paragraphs

These tags are all mutually exclusive (with special attention to <p>). Each one delineates a paragraph, and with the exception of the <p> tag, they are not allowed within each other. The <p> tag can occur inside of some of these, as it is some times mistakenly used in place of a <BR>. If a <p> is found inside of a different kind of paragraph, it will be treated as a <BR>.

If we are not in any paragraph, and plain text is encountered, a missing <p> tag will be assumed.

Seeing any one of these tags inside another one (with the exception of <p>), will push a new paragraph type onto the stack. If a new paragraph is entered and the previous paragraph type was PARAGRAPH_TYPE_DEFAULT (<p>, <div>), then the previous paragraph will be ended. Note that the closing </p> tag is almost never seen, so this will keep the stack from growing too deep. (And since <p> is assumed if we’re not in a paragraph anyway, it doesn’t make any difference. )

<ADDRESS>, <BLOCKQUOTE>, <DD>, <DIV>, <DT>, <Hn>, <INPUT>, <LI>, <MARQUEE>, <OPTION>, <P>, <PRE>.

Paragraph Modifier Tags

These are tags which set flags, but do not break paragraphs.

<A>, <B>, <BIG>, <BLINK>, <BR>, <CENTER>, <CITE>, <CODE>, <EM>, <FONT>, <I>, <KBD>, <NOBR>, <S>, <SAMP>, <SMALL>, <STRIKE>, <STRONG>, <SUB>, <SUP>, <TT>, <U>, <VAR>, <WBR>.
