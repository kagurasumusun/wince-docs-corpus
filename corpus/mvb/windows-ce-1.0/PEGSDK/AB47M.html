RasSetEntryProperties

DWORD RasSetEntryProperties(// afdfunc.h
LPTSTR lpszPhonebook,// full path and file name of the phone book file
LPTSTR szEntry,// pointer to string containing existing entry name
LPBYTE lpbEntry,// pointer to RASENTRY structure
DWORD dwEntrySize,// pointer to buffer of device-specific configuration information
LPBYTE lpb,
DWORD dwSize
);
Parameters
lpszPhonebook
Points to a null-terminated string that specifies the full path and file name of the phone book file. This parameter can be NULL, in which case the default phone book file is used. This parameter should always be NULL for Windows 95 and Windows CE since the phone book entries are stored in the registry.
szEntry
Points to a null-terminated string containing an existing entry name. If a "" entry name is specified, structures containing default values are returned.
lpbEntry
Points to a RASENTRY structure that receives the connection data associated with the phonebook entry specified by the lpszEntry member followed by any additional bytes needed for the alternate phone number list if any. On entry, the dwSize member of this structure must specify the size of the structure.
dwEntrySize
The size, in bytes, of the buffer specified by lpEntryInfo. lpb Points to buffer of device-specific configuration information. This parameter may be NULL if the data is not required.
dwSize
Points to a variable that contains the size, in bytes, of the buffer specified by lpb.
Return Values
If the function succeeds, the return value is zero. If the function fails, the return value can be one of the following error codes:
Error Code		Description
ERROR_INVALID_PARAMETERThe function is called with an invalid parameter.
ERROR_BUFFER_INVALIDThe address or buffer specified by lpbEntryInfo is invalid.
ERROR_BUFFER_TOO_SMALLThe buffer size indicated in lpdwEntryInfoSize 897723654is too small.
ERROR_CANNOT_OPEN_PHONEBOOKThe phone book is corrupted or missing components.
