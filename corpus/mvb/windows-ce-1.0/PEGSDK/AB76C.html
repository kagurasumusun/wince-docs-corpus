CommandBar_AddAdornments

The CommandBar_AddAdornments function adds a close button and other standard buttons to a command bar.

BOOL CommandBar_AddAdornments(// commctrl.h
HWND hwndCB,// handle of command bar window
DWORD dwFlags,// optional buttons flag
DWORD dwReserved// reserved
);
Parameters
hwndCB
Handle identifying the command bar. This handle is returned when the command bar is created by the CommandBar_Create function.
dwFlags
Specifies optional buttons to be added to the command bar. This parameter can be a combination of the values listed below or zero if no additional buttons are needed. When the user selects the button, the message associated with the button is placed in the application’s message queue.
Value		MeaningMessage
CMDBAR_HELPHelp buttonWM_HELP
CMDBAR_OKOK buttonWM_COMMAND with IDOK as the message identifier
dwReserved
Reserved; must be zero.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
Remarks
When the user selects the close button a WM_CLOSE message is placed in the application’s message queue.
