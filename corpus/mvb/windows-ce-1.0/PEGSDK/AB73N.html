SetBrushOrgEx

The SetBrushOrgEx function sets the brush origin that GDI assigns to the next brush an application selects into the specified device context.

BOOL SetBrushOrgEx(// wingdi.h
HDC hdc,// handle of device context
int nXOrg,// x-coordinate of new origin
int nYOrg,// y-coordinate of new origin
LPPOINT lppt// points to previous brush origin
);
Parameters
hdc
Identifies the device context.
nXOrg
Specifies the x-coordinate, in device units, of the new brush origin. This value must be in the range zero through seven.
nYOrg
Specifies the y-coordinate, in device units, of the new brush origin. This value must be in the range zero through seven.
lppt
Points to a POINT structure that receives the previous brush origin.
This parameter can be NULL if the previous brush origin is not required.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE. To get extended error information, call GetLastError.
Remarks
A brush is a bitmap that the operating system uses to paint the interiors of filled shapes.
The brush origin is a pair of coordinates with values between zero and seven, specifying the location of one pixel in the bitmap. The default brush origin coordinates are (0,0). For horizontal coordinates, the value zero corresponds to the leftmost column of pixels; the value seven corresponds to the rightmost column. For vertical coordinates, the value zero corresponds to the uppermost row of pixels; the value seven corresponds to the lowermost row.
When the operating system positions the brush at the start of any painting operation, it maps the origin of the brush to the location on the window's client area specified by the brush origin. For example, if the brush origin is (2,3), the operating system maps the origin of the brush, (0,0), to the location (2,3) on the window's client area.
The operating system automatically tracks the origin of all window-managed device contexts and adjusts their brushes as necessary to maintain an alignment of patterns on the surface. The brush origin that is set with this call is relative to the upper-left corner of the client area.
Automatic tracking of the brush origin is not supported. Applications must use the SetBrushOrgEx and SelectObject functions to align the brush before using it.
