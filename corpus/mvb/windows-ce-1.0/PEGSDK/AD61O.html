TBM_SETPAGESIZE

Sets the size of the page for a trackbar. The page size affects how much the slider moves for the TB_PAGEUP and TB_PAGEDOWN notification messages.

wParam = 0;

lParam = (LONG) lPageSize;

Parameters

lPageSize

New page size.

Return Values

Returns a 32-bit value that specifies the previous page size.
