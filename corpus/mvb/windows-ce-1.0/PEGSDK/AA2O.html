The Load Function

The Load The Function

A setup program typically gathers setup-related information from the user, and then decompresses and installs application files into the user-specified directory on the PC's hard drive. After installing the application files on the desktop PC, the setup program calls the Load function provided by Ppcload.dll to load the files into the HPC.

The Load function not only loads application files, it also adds application information to the HPC registry and automatically creates an unload script for the application. It can also create a shortcut to the application anywhere in the Windows CE shell, and can automatically execute programs on the HPC before the load process completes.

Load Parameters

The parameters to the Load function include a window handle and the address of a buffer that contains a list of command-line arguments. The window handle identifies a window to be used as the parent for any windows created by the Load function. For example, the function displays a progress bar to indicate the progress of the load operation.

The Load function uses the list of command-line arguments to provide the information Ppcload.dll needs to load the application. The arguments must be separated by a space. If an argument must include a space, enclose the argument in quotation marks (""). The arguments include the following. If an argument enclosed in quotes includes a quotation mark, precede the quotation mark with a backslash (\).

ArgumentDescription
cpu_typeType of CPU on the HPC. Currently, SH3 and MIPS are the only valid CPU types.
application_nameApplication name.
install_directoryDirectory on the HPC where the application will be stored.
total_bytes_to_copyTotal number of bytes to be copied.
user_nameName of the person using the HPC.
user_companyName of the user’s organization.
load_fileName of the load file.
When this function is used to load .exe or .dll files, the file being loaded from the desktop PC must have the CPU type added to the file name as an extension. For example, if the cpu_type argument is “MIPS” and the application_name argument is “MyApp.exe”, the file being loaded should be named MyApp.exe.MIPS on the desktop PC. The CPU type should only be appended to .exe and .dll files, the Load function will look for all other file types without the CPU type extension.
The Load The File
The final command-line argument is the fully-qualified path name of a file (called a load file) that contains a list of statements for the Load function to process. You use load file statements to direct Ppcload.dll to create directories on the HPC, copy files into the directories, edit registry entries, execute programs on the HPC, and add items to the unload script.
You can include comments in a load file, but they must begin with a double slash (//), and they must start in column one. For information about each load file statement, see “Load File Statements” later in this chapter.
The Unload Script
The Remove Programs application in the HPC Control Panel uses the unload script, created when the Load function is called, to remove all traces of the application from the HPC, including all related files, registry entries, and shortcuts. In addition, the Load function automatically runs the unload script if the load operation fails or is canceled by the user before it has completed. Automatically running the unload script ensures that stray files are not left on the HPC.
To insure the Remove Programs application works correctly the file name specified by the application_name argument must match the file name specified by the load_file argument. For example, if the file specified by the application_name argument is “MyFile.exe” the file specified by the load_file argument should be “MyFile.load”.
