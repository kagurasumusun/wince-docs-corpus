CommandBar_AddButtons

The CommandBar_AddButtons function adds one or more buttons to a command bar.

BOOL CommandBar_AddButtons(// commctrl.h
HWND hwndCB,// handle of command bar
UINT uNumButtons,// number of buttons to add
LPTBBUTTON lpButtons// array of structures with button information
);
Parameters
hwndCB
Handle identifying the command bar. This handle is returned when the command bar is created by the CommandBar_Create function.
uNumButtons
Specifies the number of buttons to add.
lpButtons
Points to an array of TBBUTTON structures that contains information about the buttons to add. There must be the same number of elements in the array as buttons specified by uNumButtons.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
