Keyboard Input

Keyboard input conventions are similar to those for Windows. The hardware requirements for Windows CE define a basic keyboard layout that is as close to a standard PC keyboard as possible. However, some common keys are not supported, so you should avoid writing applications that rely on the following keys:

· insert

· scroll lock

· pause

· num lock

· print scrn

· Function keys

Note also that there is no delete key; SHIFT+BACKSPACE is the substitute for the DELETE key.

Include keyboard shortcuts for common or frequent actions. Support the common shortcut keys where they apply. For more information on assigning shortcut keys and common shortcut keys, see The Windows Interface Guidelines for Software Design. The Windows key is supported by the Windows CE system software; however, the Windows key may not be included on all handheld PCs supporting Windows CE.
