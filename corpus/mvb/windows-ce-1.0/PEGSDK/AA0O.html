HPC Application Loader

About the Application Loader

Microsoft provides a dynamic-link library called Ppcload.dll that a setup program can use to load a Windows CE application from a Windows-based personal computer (PC) to a Handheld personal computer (HPC). The DLL uses remote procedure call (RPC) functions and information provided in a setup script file to load an application's files. This chapter describes the services provided by Ppcload.dll and explains how to use them in a setup program.
