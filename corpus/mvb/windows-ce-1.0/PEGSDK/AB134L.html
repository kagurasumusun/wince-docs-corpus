PegGetSystemInfo

The PegGetSystemInfo function is the RAPI version of the GetSystemInfo function. For more information about using RAPI functions, please see the Remote API Functions overview. See the GetSystemInfo documentation for a description of the parameters and return values.

void PegGetSystemInfo(// rapi.h
LPSYSTEM_INFO OUT lpSystemInfo// address of system information structure
);
Parameters
lpSystemInfo
Points to a SYSTEM_INFO structure to be filled in by this function.
Return Values
This function does not return a value.
