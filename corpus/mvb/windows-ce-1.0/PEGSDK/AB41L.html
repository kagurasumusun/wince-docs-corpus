PegCloseHandle

The PegCloseHandle function is the remote API version of the CloseHandle function. For more information about using RAPI functions, see the Remote API Functions overview. See the CloseHandle documentation for a description of the parameters and return values.

BOOL PegCloseHandle(// rapi.h
HANDLE hObject// handle of object to close
);
Parameters
hObject
Identifies an open object handle.
