SB_GETTEXT

Retrieves the text from the given part of a status window.

wParam = (WPARAM) iPart;

lParam = (LPARAM)(LPSTR) szText;

Parameters

iPart

Zero-based index of the part from which to retrieve text.

szText

Address of the buffer that receives the text. This parameter is a null-terminated string.

Return Values

Returns a 32-bit value that consists of two 16-bit values. The low-order word specifies the length, in characters, of the text. The high-order word specifies the type of operation used to draw the text. The type can be one of the following values.

ValueMeaning
0The text is drawn with a border to appear lower than the plane of the window.
SBT_NOBORDERSThe text is drawn without borders.
SBT_POPOUTThe text is drawn with a border to appear higher than the plane of window.
If the text has the SBT_OWNERDRAW drawing type, this message returns the 32-bit value associated with the text instead of the length and operation type.
