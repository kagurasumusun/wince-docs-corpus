Help

Windows CE provides user access to Help through a command in the Start Menu as well as through a question mark Help button that you may include in the command bar of a primary or secondary window. This Help button looks similar to the What’s This? Button in Windows; however, it operates differently. Rather than putting the user into Help mode and allowing the user to select a particular field, this button brings up Help for the current window. ALT+H is the recommended shortcut key combination for accessing Help.

You author your application’s Help file in HTML. Each topic exists as a text file with an .htp extension. You author your content page list of topics similarly, but save the file with an .htc extension.
