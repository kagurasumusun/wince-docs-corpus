Contacts Database

About the Contacts Database

One of the Information Manager applications included with Windows CE is Contacts. It allows users to store and retrieve names, addresses and telephone numbers in the Contacts database. The Windows CE operating system includes a set of functions and structures that can be used in applications to query and manipulate the contents of the Contacts database. This chapter describes those functions and explains how to use them in an application. You should be familiar with the Windows CE object store and the object store API before reading this chapter.
