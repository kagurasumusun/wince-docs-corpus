CB_GETLBTEXTLEN

An application sends a CB_GETLBTEXTLEN message to retrieve the length, in characters, of a string in the list of a combo box.

wParam = (WPARAM) index; // item index

lParam = 0; // not used,must be zero

Parameters

index

Value of wParam. Specifies the zero-based index of the string.

Return Values

The return value is the length of the string, in characters, excluding the terminating null character. If the index parameter does not specify a valid index, the return value is CB_ERR.
