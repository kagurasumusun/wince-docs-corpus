Extension Keys

Each key under the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Pegasus\Filters key has as its name a file extension. These are the extension keys. Each extension key may have a DefaultImport named value and a DefaultExport named value, identifying the default file filter to use when importing or exporting files with the given extension. The filter is identified by use of a CLSID.

Under each extension key is the InstalledFilters subkey. This key has any number of named values, each of which has as its name a CLSID identifying a file filter object. The CLSID must identify an Object Linking and Embedding (OLE) Component Object Model (COM) object that is used for the file filter conversion.

Apartment model capabilities of each installed file filter are stored under each CLSID under the key HKEY_CLASSES_ROOT\CLSID. In addition to the DefaultIcon and InProcServer32 subkeys, each CLSID key must have a PegasusFilter subkey specifying Windows CE specific capabilities. This key may have the following named values:

Named ValueDescription
ImportIf this named value exists, the conversion type is for importing files to the HPC. Otherwise, the conversion type is for exporting files from the HPC.
HasOptionsIf this named value exists, the file filter supports the FilterOptions method of the IPegasusFileFilter interface.
DescriptionThis named value is a line of text that describes the conversion. HPC Explorer displays this text in the conversion selection dialog box.
NewExtensionThis named value is the extension of the file that will be created on the destination.
Sample File Filter Registry Entry
Below is a sample .reg file used to register the file filter:
REGEDIT4
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Pegasus\Filters\.bmp]
"DefaultImport"="{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}"
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Pegasus\Filters\.bmp\InstalledFilters]
"{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}"=""
[HKEY_CLASSES_ROOT\CLSID\{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}]
@="HPC Bitmap"
[HKEY_CLASSES_ROOT\CLSID\{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}\DefaultIcon]
@="2bp.dll,-1000"
[HKEY_CLASSES_ROOT\CLSID\{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}\InProcServer32]
@="2bp.dll"
"ThreadingModel"="Apartment"
[HKEY_CLASSES_ROOT\CLSID\{-DA01ED80-97E8-11cf-8011-00A0C90A8F78}\PegasusFilter]
"Import"=""
"Description"="Colors will be converted to grays."
"NewExtension"="2bp"
