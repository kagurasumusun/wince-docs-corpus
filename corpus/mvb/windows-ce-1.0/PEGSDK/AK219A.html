WinDbg from the Command Line

To run WinDbg on an SH3 target device:

windbg -g -k sh [com port] [baud rate] -f -y [peg release dir]

To run WinDbg on a MIPS target device::

windbg -g -k mips [com port] [baud rate] -y [peg release dir]

For further information on using WinDbg, see the Windows CE topics within that program’s Help file.
