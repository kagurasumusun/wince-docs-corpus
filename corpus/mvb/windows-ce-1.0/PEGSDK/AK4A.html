Building Applications for Emulation

From within the MSDev for Windows CE IDE, select either Win32 (x86em) Release or Win32 (x86em) Debug in the default project configuration. Click Build from the menu and select Build xxx.exe. After building and linking your executable file, you will see the dialog box shown below. Enter the destination location for your executable file and click OK.

Note If path that is entered for the Object Store path (in the above dialog) must exist in the object store. That is, you can not copy a file to a folder that does not already exist. For example, if you entered \Temp\Myapp.exe, but a Temp folder does not exist, an error would occur. You would first need to create the Temp folder by entering My Handheld and clicking file and selecting new folder .

On the initial build, the IDE will spawn Shell32.exe and execute your application within the emulation shell. To exit the emulation window, click the Start button and select Suspend.

Note If you rebuild your application, the above dialog will not be displayed. To copy the executable file to a different folder in the simulated file system, you can use the Remote Object Viewer. Another method is to click Build, Settings on the menu; under the Debug tab, you can change the Remote executable path and file name. Also, if you clear this field, then the above dialog will be displayed the next time you rebuild.
