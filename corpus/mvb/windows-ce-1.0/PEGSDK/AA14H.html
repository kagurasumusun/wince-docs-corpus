Menu Bars

The CommandBar_InsertMenubar function is used to insert a menu bar into a command bar. The parameters to this function include the handle of the module that contains the menu resource, the identifier of the menu resource, and the index of an element in the command bar. The function loads the menu resource and creates a menu bar inserted to the left of the specified element.

After inserting a menu bar, use the Win32 menu API to manage the menu. Many menu functions require you to specify the handle of a menu. To retrieve the handle of a menu bar in a command bar, use the CommandBar_GetMenu function.

For information about the Win32 menu API, see the Win32 Programmer's Reference.
