GetSystemDefaultLCID

The GetSystemDefaultLCID function retrieves the system default locale identifier.

LCID GetSystemDefaultLCID(void);// winbase.h
Parameters
This function has no parameters.
Return Values
If the function succeeds, the return value is the system default locale identifier.
Remarks
For more information about locale identifiers, see “Locales and Language Identifiers” in the Win32 Programmers Reference.
