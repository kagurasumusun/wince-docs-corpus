LoadResource

The LoadResource function loads the specified resource into global memory.

Windows CE Notes hModule must be non-NULL.

HGLOBAL LoadResource(// winbase.h
HMODULE hModule,// resource-module handle
HRSRC hResInfo// resource handle
);
Parameters
hModule
Identifies the module whose executable file contains the resource. Cannot be NULL.
hResInfo
Identifies the resource to be loaded. This handle must be created by using the FindResource function.
Return Values
If the function succeeds, the return value is a handle to the global memory block containing the data associated with the resource. If the function fails, the return value is NULL. To get extended error information, call GetLastError.
Remarks
The system automatically frees resources.
