htons

The Windows Sockets htons function converts a u_short from host byte order to network byte order.

u_short htons (// winsock.h
u_short hostshort// 16-bit number in host byte order
);
Parameters
hostshort
A 16-bit number in host byte order.
Return Values
The htons function returns the value in network byte order.
Remarks
This function takes a 16-bit number in host byte order and returns a 16-bit number in network byte order.
