LoadImage

The LoadImage function loads an icon, cursor, or bitmap.

Windows CE Notes cxDesired must be zero for IMAGE_BITMAP.

cyDesired must be zero for IMAGE_BITMAP.

Stretching/shrinking of icons is not supported.

fuLoad must be zero (==LR_DEFAULTCOLOR).

uType must be IMAGE_BITMAP or IMAGE_ICON.

SM_CXCURSOR and SM_CYCURSOR are not supported.

HANDLE LoadImage(// winuser.h
HINSTANCE hinst,// handle of the instance that contains the image
LPCTSTR lpszName,// name or identifier of image
UINT uType,// type of image
int cxDesired,// desired width
int cyDesired,// desired height
UINT fuLoad// must be zero
);
Parameters
hinst
Identifies an instance of the module that contains the image to be loaded.
lpszName
Identifies the image to load.
If the hinst parameter is non-NULL and the fuLoad parameter does not include LR_LOADFROMFILE, lpszName is a pointer to a null-terminated string that contains the name of the image resource in the hinst module.
uType
Specifies the type of image to be loaded. This parameter can be one of the following values.
Value		Meaning
IMAGE_BITMAPLoads a bitmap.
IMAGE_ICONLoads an icon.
cxDesired
Specifies the desired width, in pixels, of the icon or cursor. If this parameter is zero, the function uses the SM_CXICON system metric value to set the width.
cyDesired
Specifies the desired height, in pixels, of the icon or cursor. If this parameter is zero, the function uses the SM_CYICON system metric value to set the height.
fuLoad
Must be set to zero. Default value set as follows:.
Value		Meaning
LR_DEFAULTCOLORThe default flag; it does nothing.
Return Values
If the function succeeds, the return value is the handle of the newly loaded image. If the function fails, the return value is NULL.
Remarks
For Windows CE an image loaded by LoadImage will exist until the process which loaded the image terminates. Each call to LoadImage returns a new handle even if all the handles represent the same image. Calling LoadImage repeatedly on the same image resource is inefficient. To conserve memory, call LoadImage only once and save the return value for all subsequent uses.
