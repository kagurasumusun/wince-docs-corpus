Controls

In addition to the command bar, Windows CE supports a subset of the common Windows controls. Though the default size and appearance may differ slightly for some controls, the basic interaction is the same. For recommendations on using these controls, see The Windows Interface Guidelines for Software Design.

Command Buttons
You can include command buttons both in the command bar of the window and in the body of the window. Similarly, for secondary windows, buttons sometimes appear in either the title bar or the body of the window. Use the following conventions.
· When a window only includes the OK and/or Cancel (or Close) buttons, place them in the title bar. Under Windows CE the X button is used as a synonym for Close or Cancel functions.
· If you have multiple actions, place them as buttons in the body of the window, but keep the X button in the title bar if the window supports Cancel or Close. Remove the OK button from the title bar.
· When OK and X title bar buttons would perform the same function, remove or disable X and enable OK. Users will be more familiar with using OK to confirm than using X.
· OK should never appear both in the window and in the title bar, but Cancel may appear in both locations.
For example, a message box that supplies an OK and Cancel choice should use the OK and X button in the title bar. However, if the message box supports Yes, No, and Cancel actions, display these as buttons in the body of the window and include the X button in the title bar, but not the OK button.
Map ENTER and ESC keys to the OK and Cancel buttons following the recommended Windows conventions. For example, enter should press the OK or default button unless the user has moved the input focus to another button. Similarly, ENTER may apply to a control rather than to the window, if the control uses the key for its own interaction. For example, enter chooses the current selection and closes a drop-down list or drop-down combo box rather than closing the window. However, pressing enter commits a dialog box if the key no longer applies.
Text boxes
As the Windows guidelines suggest, you should provide a label for all controls. For text boxes you do this by including a static text field left or above the text box. In situations where you need to conserve space you may optionally consider including the label as the default text, enclosed between angle bracket characters (for example, <first name>); however, an external label is definitely preferable.
