Combo Boxes

The CommandBar_InsertComboBox function creates a combo box and inserts it into a command bar. The function parameters include the width, style, and identifier of the combo box, and the index of an element in the command bar. The combo box is inserted to the left of the element that has the given index.

By default, the CommandBar_InsertComboBox function creates a combo box that has the CBS_HASSTRINGS, WS_CHILD, and WS_VISIBLE styles. Optionally, an application can specify the CBS_DROPDOWNLIST style to give the combo box a drop-down list box, and the WS_VSCROLL style to add a vertical scroll bar to the list box. The current implementation of command bars does not support any other styles.

After creating a combo box, an application uses the Win32 combo box API to add items and manage the combo box. For information about the combo box API, see the Win32 Programmer's Reference.
