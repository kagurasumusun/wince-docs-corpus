ImageList_DragEnter

The ImageList_DragEnter function locks updates to the given window during a drag operation and displays the drag image at the specified position within the window.

BOOL WINAPI ImageList_DragEnter(// commctrl.h
HWND hwndLock,// handle of the window that owns the drag image
int x,// x-coordinate display position
int y// y-coordinate display position
);
Parameters
hwndLock
Handle of the window that owns the drag image.
x and y
Specify the x-coordinate and y-coordinate positions at which to display the drag image. The coordinates are relative to the upper left corner of the window, not the client area.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
To begin a drag operation, use the ImageList_BeginDrag function.
See Also
ImageList_BeginDrag, ImageList_DragLeave
