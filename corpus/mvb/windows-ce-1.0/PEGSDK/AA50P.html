<IMG>

The Image element is used to incorporate in-line graphics (typically icons or small graphics) into an HTML document. This element cannot be used for embedding other HTML text.

SRC

Specifies the URL of the image.

ALIGN

Specifies whether the text that is inline with this image is at the top, middle or bottom.

Left, right specify floating images. (see discussion in <BR CLEAR=x>). Basically, the image will float down the appropriate side of the page, so if we’re already in the middle of a line, insert a line break.

left (Version 2 feature, ignored in V1) - Aligns the image in the left margin. Subsequent text will wrap around the right hand side of the image.

right (Version 2 feature, ignored in V1) - Aligns the image to the right margin. Subsequent text will wrap around the left hand side of the image.

texttop - Aligns the image with the top of the tallest text in the line (usu. same as top attribute)

absmiddle - Aligns the middle of the image to the middle of the line of text.

baseline - Aligns the bottom of the image to the baseline of the line of text (same as bottom).

absbottom - Aligns the bottom of the image to the bottom of the line of text (including descender).

ALT

Alternate text. This should be put in place of the picture until the picture is available. Alternate text should be provided whenever the graphic is not rendered. Alternate text is mandatory for Level 0 documents.

ISMAP

Specifies that the picture is a map that has to be sent back to the sever for processing. Image maps are graphics in which certain regions are mapped to URLs. By clicking on different regions, different resources can be accessed from the same graphic.

VSPACE

Sets the vertical space above and below the image in pixels.

HSPACE

Sets the horizontal space to the left and right if an image in pixels.

WIDTH

Record this in the image header, and draw a rect of this size for now, until the image arrives. Both width and height should be adjusted by same algorithm inside the image decompressor, so that if the actual image is really this size, we will have the correct size rectangles drawn.

HEIGHT

Record this in the image header, and draw a rect of this size for now, until the image arrives. Both width and height should be adjusted by same algorithm inside the image decompressor, so that if the actual image is really this size, we will have the correct size rectangles drawn.

BORDER

Specifies the thickness of the border around the image in pixels. This is stored in the image header and is simply added to the dimensions of the picture for the purposes of determining rects. Default to 2 pixels black border (upon activation and selection, border turns dark gray) .

LOWSRC (Ignored in V1.0)

DYNSRC (Ignored in V1.0)

No support for animations.
