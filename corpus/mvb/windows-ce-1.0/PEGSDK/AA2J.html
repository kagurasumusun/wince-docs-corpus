TAPI Functions

TAPI functions are identified as “asynchronous” if they can return before making a call to the application’s callback function, otherwise they are considered “synchronous.” Following is a list of TAPI functions supported by Windows CE.

TAPI FunctionDescription
lineCloseCloses specified line device. Synchronous.
lineConfigDialogEditDisplays a dialog box allowing user to change line device configuration. Synchronous
lineDeallocateCallReleases the specified call handle. Synchronous.
lineDropDisconnects a call or abandons a call attempt in progress. Asynchronous.
lineGetDevCapsReturns the capabilities of a given line device. Synchronous.
lineGetDevConfigReturns the configuration of a media stream device. Synchronous.
lineGetIDRetrieves the device ID for a specified open line, address, or call. Synchronous.
lineGetTranslateCapsReturns address translation capabilities. Synchronous.
lineInitializeInitializes TAPI line abstraction. Synchronous.
lineMakeCallMakes an outbound call and returns a handle to tghe call. Asynchronous.
lineNegotiateAPIVersionAllows an application to negotiate which API version to use. Synchronous.
lineOpenOpens a specified line device for monitoring and/or controlling the line. Synchronous.
lineSetDevConfigSets the configuration of the specified media stream device. Synchronous.
lineSetStatusMessagesSpecifies status changes the application wants notification of. Synchronous.
lineShutdownShuts down the application’s use of the line TAPI. Synchronous.
lineTranslateAddressTranslates between canonical address format and dialable address format. Synchronous.
lineTranslateDialogDisplays a dialog box allowing user to change location. Synchronous.
