SetCapture

The SetCapture function sets the pen capture to the specified window belonging to the current thread. After a window has captured the pen, all pen input is directed to that window. Only one window at a time can capture the pen.

Windows CE Notes The Win32 API description states that if the mouse cursor is over a window created by another thread, the system will direct mouse input to the given window only if a mouse button is down. This behavior is not supported since it does not make sense for a touch-based system.

HWND SetCapture(// winuser.h
HWND hWnd// handle of window to receive pen capture
);
Parameters
hWnd
Identifies the window in the current thread that is to capture the pen.
Return Values
If the function succeeds, the return value is the handle of the window that had previously captured the pen. If there is no such window, the return value is NULL.
Remarks
Even if the foreground window has captured the pen, the user can still click another window, bringing it to the foreground.
When the window no longer requires all pen input, the thread that created the window should call the ReleaseCapture function to release the pen.
This function cannot be used to capture pen input meant for another thread.
