HeapDestroy

The HeapDestroy function destroys the specified heap object.

BOOL HeapDestroy(// winbase.h
HANDLE hHeap// handle of heap
);
Parameters
hHeap
Specifies the heap to be destroyed. This should be a heap handle returned by the HeapCreate function.
Return Values
If the function succeeds, the return value is TRUE; otherwise, it is FALSE.
Remarks
The HeapDestroy function decommits and releases all the pages of a private heap object, and invalidates the handle of the heap.
Processes can call HeapDestroy without first calling the HeapFree function to free memory allocated from the heap.
