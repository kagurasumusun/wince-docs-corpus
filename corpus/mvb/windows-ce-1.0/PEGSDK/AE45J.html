TVN_SETDISPINFO

Notifies a tree view control's parent window that it must update the information it maintains about an item. This notification message is sent in the form of a WM_NOTIFY message.

ptvdi = (TV_DISPINFO FAR *) lParam

Parameters

ptvdi

Address of a TV_DISPINFO structure. The item member is a TV_ITEM structure that contains valid information about the item in the hItem and lParam members.

Return Values

No return value.

See Also

TV_DISPINFO, TVN_GETDISPINFO, WM_NOTIFY
