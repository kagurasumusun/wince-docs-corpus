Floating Point Operations

All of the basic IEEE arithmetic operations are provided as shown in Table 4.

Table 4. Basic IEEE Arithmetic Operations

OPERATIONOPERANDCOMMENT
add, subtract, multiply, divide+, -, *, /Like operands are directly supported. Different operands supported in compiler by casting to double first.
floating-point remainderfmodNote 1.
copy without change of format=Not considered an IEEE operation, meaning it never causes an IEEE exception.
square rootsqrtNote 1.
round to floating-point integer_frndNote 1. Note 7. Undocumented.
convert between floating-point typescast-
convert floating-point to integercastNote 2.
convert integer to floating-pointcastNote 3.
comparison=, !=, <, <=, >, >=Note 4.
binary to decimal_ecvt, _fcvt, _gcvtNote 5. Note 6.
decimal to binarystrtodNote 6.
Notes:
1. Supported for double in the elementary function library. Supported for float in the compiler by casting to double first, calling the double version, then casting back to float.
2. Supported in the basic arithmetic operations for casting to signed and unsigned long and __int64. Supported in the compiler for shorter integer types by further casting. This means, for example, that converting 1000.0 to char does not cause an exception. Floating-point values too large for conversion return the right-most (least significant) bits of the exact result with the destination treated as a signed integer (even if it is declared unsigned). The correct IEEE invalid operation exception is still raised in this case.
3. Supported in the basic arithmetic operations for casting from signed and unsigned long and __int64. Supported in the compiler for shorter integer types by further casting.
4. Consistent with IEEE, = and != do not report invalid operation exceptions on unordered comparisons but the rest do. Like-typed operands are supported as basic arithmetic operations. Different-typed operands are supported in the compiler by casting to double first. The C comparison operators expect a predicate based comparison implementation but the Visual C/C++ SEH floating-point trap reporting model expects a condition code-based implementation. Both models are supported.
5. Exceptional values must be handled out-of-band.
6. Conversion between the ANSI and wide character sets is the programmer's responsibility.
7. _frnd supports all 4 IEEE rounding modes to support some of the routines in the VC++ elementary function library.
