PFF_DESTINATIONFILE Structure

The PFF_DESTINATIONFILE structure contains information about a destination file. A file filter uses the information to write the converted data to the file.

typedef struct tagPFF_DESTINATIONFILE

{-

TCHAR szFullpath[_MAX_PATH];

TCHAR szPath[_MAX_PATH];

TCHAR szFilename[_MAX_FNAME];

TCHAR szExtension[_MAX_EXT];

} PFF_DESTINATIONFILE;

Members

szFullpath

Specifies the full pathname to the destination file.

szPath

Specifies the pathname to the destination file.

szFilename

Specifies the name of the destination file as specified by the user.

szExtension

Specifies the filename extension of the destination file as specified by the user.
