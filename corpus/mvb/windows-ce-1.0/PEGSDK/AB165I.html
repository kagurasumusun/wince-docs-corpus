InterlockedTestExchange

The InterlockedTestExchange function is an interlocked function that performs a conditional setting of a variable.

DWORD InterlockedTestExchange(// winbase.h
LPLONG lpdata,// address of variable to check and set
LONG OldValue,// value to check against
LONG NewValue// value to set conditionally
);
Parameters
lpdata
Address of DWORD to check and set.
dwOldValue
Value to check against.
dwNewValue
Value to set to conditionally.
Return Values
Returns the value pointed to by lpData at the time of the call (that is, the old value).
Remarks
This function is an interlocked function—in other words, it can be considered atomic. It checks to see if the value pointed to by lpData is equal to dwOldValue. If so, it sets *lpData to be dwNewValue. Since the function returns the “old” value pointed to by lpData, if the return value is dwOldValue, then the function succeeded and set the value pointed to by lpData to dwNewValue. Otherwise, the function failed.
