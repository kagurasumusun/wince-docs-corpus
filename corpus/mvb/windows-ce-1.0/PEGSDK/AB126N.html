SetCursor

The SetCursor function establishes the cursor shape.

Windows CE Notes This function is significantly restricted from its Win32 form.

HCURSOR SetCursor(// winuser.h
HCURSOR hcur// handle of cursor
);
Parameters
hcur
Identifies the cursor. Only NULL and the wait cursor are supported.
Return Values
If hcur is non-NULL, the wait cursor is requested. If hcur is NULL, the wait cursor is not requested. No other cursors are supported.
Remarks
The wait cursor is controlled on a per thread basis. Each thread can perform its own SetCursor calls independent of other threads. The return value is the previous cursor for the calling thread. A thread cannot control the request state of another thread.
The wait cursor is only displayed on the screen if the foreground thread has requested it. If the foreground thread changes from a thread that has requested it to one that has not, the cursor is automatically hidden. Likewise, if the foreground thread changes from a thread that has not requested it to one that has, it is displayed. This behavior is handled by the system and does not require any application intervention. Changing the foreground thread usually occurs as a result of the user switching between applications.
