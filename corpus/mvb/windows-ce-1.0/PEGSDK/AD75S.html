WM_DRAWITEM

Sent to the owner window of an owner-drawn button or menu when a visual aspect of the button or menu has changed.

Windows CE Notes In the case of a menu item, the receiver of this message is responsible for erasing the background if necessary.

idCtl = (UINT) wParam;				// control identifier

lpdis = (LPDRAWITEMSTRUCT) lParam; // item-drawing information

Remarks

In the case of a menu item, the receiver of this message is responsible for erasing the background if necessary.
