MailError

The MailError function retrieves the error condition set by the last called mail function.

int MailError (// msgstore.h
HANDLE hMail// handle to mail context
);
Parameters
hMail
Handle identifying the mail context. This handle is created by the MailOpen function.
Return Value
This function returns the value of last error code as an integer.
Remarks
Each call to a mail function sets an error code. MailError retrieves the code and returns it as an integer. Negative values indicate warnings, positive values indicate errors, and zero indicates the function completed successfully. To insure the correct error value is captured, call MailError immediately after the transport function call.
