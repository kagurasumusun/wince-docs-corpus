Load_RegisterFileInfo

The Load_RegisterFileInfo function registers file information with the HPC Explorer.

LOADERROR Load_RegisterFileInfo(// ppcload.h
LPCSTRszFileName,// specifies the name of the application to be loaded
LPCSTRszIconFile,// specifies the file containing the icon
LPCSTRszFileType,// unused
intiIcon// specifies the index to the icon
);
Parameters
szFileName
This parameter specifies the name of the application to be loaded. It must be set prior to calling this function. The name should include the file extension but should not include the path.
szIconFile
This parameter specifies the file containing the icon associated with the application being loaded. It must be set prior to calling this function. The name should include the file extension and the directory path to the file.
szFileType
Currently unused.
iIcon
This parameter specifies the index to the icon associated with the file being loaded.
Return Value
This function returns one of the following error codes.
Error Code		Description
LOAD_SUCCESSLoad process completed successfully.
LOAD_INVALID_PARAMETERInvalid command line parameter.
LOAD_REG_ERRORCannot create registry entry.
Remarks
This function requires a prior successful call to the Load_Init function.
This function is exported by Ppcload.dll, which runs on the desktop PC—it is intended to be called from a setup program.
To insure consistency with other icons displayed by the HPC Explorer, icons should follow the two bit per pixel format and incorporate only the following colors; black, white, dark gray and light gray.
