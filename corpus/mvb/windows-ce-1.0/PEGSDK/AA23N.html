TransportDel

BOOL TransportDelete(
HANDLE hService// Service handle
MailMsg *MsgPtr// MailMsg structure with ID of message to delete
);
TransportDelete deletes a specific message located on the mail server.
For the sample service, TransportDelete removes the file specified in the MsgPtr structure.
Parameters
hService
Handle to a SERVICE structure.
MsgPtr
A pointer to the MailMsg structure. The message to be deleted is specified by MsgPtr®szSvcId. This field is compared with the message IDs stored in hService®Uids to identify the message to be deleted. The information maintained in hService is then used in support of deleting the message.
Return Value
Returns TRUE if successful or FALSE otherwise. To get extended error information, call TransportError or TransportErrorMsg. For example, if the message ID can not be found, hService®iErr is set to TRANS_ERR_INV_MSG_ID.
