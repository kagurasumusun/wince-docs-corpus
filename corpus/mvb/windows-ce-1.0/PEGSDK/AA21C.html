Hints and Tips for Efficient Memory Utilization

Calculations

Even when dealing with large data sets, many calculations are sequential and only involve two pieces of data at any one time. When you load your entire data set into one or more arrays, you are taking up memory resources to simply store a duplicate of the data that can also be found in the original data file. If you are using large data sets, consider loading in only the data that is immediately needed for a particular calculation, especially if it will not be modified in the process. When data is no longer needed, write it back to the file immediately. This practice basically trades speed for memory.
