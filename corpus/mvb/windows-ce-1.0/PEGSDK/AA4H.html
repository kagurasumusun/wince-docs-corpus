Command Bar Elements

A command bar can include four different types of elements:

· Buttons

· Combo boxes

· Menu bars

· Separators

A separator adds space between other items in a command bar and is typically used to divide items into groups.

Each element in a command bar has a zero-based index value that marks the position of the element within the command bar. The leftmost item occupies position zero, the next item to the right occupies position one. Several command bar functions use these index values to determine where to insert an element into a command bar. When calling one of these functions, an application must specify the index of an element. The function inserts the new element to the left of the specified element. To insert an element into the rightmost position of a command bar, specify an index one greater than the index of the current rightmost element.
