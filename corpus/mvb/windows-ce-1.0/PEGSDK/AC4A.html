AddressCard

The AddressCard structure contains information stored in an address card.

typedef struct _AddressCard {-

// Business view fields

TCHAR *pszBusinessFax;

TCHAR *pszCompany;

TCHAR *pszDepartment;

TCHAR *pszEmail;

TCHAR *pszMobilePhone;

TCHAR *pszOfficeLocation;

TCHAR *pszPager;

TCHAR *pszWorkPhone;

TCHAR *pszTitle;

// Personal view fields

TCHAR *pszHomePhone;

TCHAR *pszEmail2;

TCHAR *pszSpouse;

SYSTEMTIME stBirthday;
SYSTEMTIME stAnniversary;

// Notes view fields

TCHAR *pszNotes;

// Other fields the user can select

TCHAR *pszEmail3;

TCHAR *pszHomePhone2;

TCHAR *pszHomeFax;

TCHAR *pszCarPhone;

TCHAR *pszAssistant;

TCHAR *pszAssistantPhone;

TCHAR *pszChildren;

TCHAR *pszCategory;

TCHAR *pszWebPage;

TCHAR *pszWorkPhone2;

// Name fields

TCHAR *pszNamePrefix;

TCHAR *pszGivenName;

TCHAR *pszMiddleName;

TCHAR *pszSurname;

TCHAR *pszGeneration;

// Address Fields

TCHAR *pszHomeAddrStreet;

TCHAR *pszHomeAddrCity;

TCHAR *pszHomeAddrState;

TCHAR *pszHomeAddrPostalCode;

TCHAR *pszHomeAddrCountry;

TCHAR *pszOtherAddrStreet;

TCHAR *pszOtherAddrCity;

TCHAR *pszOtherAddrState;

TCHAR *pszOtherAddrPostalCode;

TCHAR *pszOtherAddrCountry;

TCHAR *pszOfficeAddrStreet;

TCHAR *pszOfficeAddrCity;

TCHAR *pszOfficeAddrState;

TCHAR *pszOfficeAddrPostalCode;

TCHAR *pszOfficeAddrCountry;

} AddressCard;

Members

pszBusinessFax

Points to the telephone number of the subject's business fax machine.

pszCompany

Points to the name of the company for which the subject works.

pszDepartment

Points to the name of the department in which the subject works.

pszEmail

Points to the subject's electronic mail alias.

pszMobilePhone

Points to the telephone number of the subject's mobile telephone.

pszOfficeLocation

Points to the location of the subject's business office.

pszPager

Points to the telephone number of the subject's pager.

pszWorkPhone

Points to the work telephone number of the subject.

pszTitle

Points to the subject's job title.

pszHomePhone

Points to the subject's home telephone number.

pszEmail2

Points to the subject's second email alias.

pszSpouse

Points to the name of the subject's spouse.

stBirthday

Specifies a SYSTEMTIME structure that contains the subject's date of birth.

stAnniversary

Specifies a SYSTEMTIME structure that contains the date of the subject's anniversary.

pszNotes

Points to notes about the subject.

pszEmail3

Points to the subject's third email alias.

pszHomePhone2

Points to the subject's second home telephone number.

pszHomeFax

Points to the telephone number of the subject's home fax machine.

pszCarPhone

Points to the telephone number of the subject's car telephone.

pszAssistant

Points to the name of the subject's assistant.

pszAssistantPhone

Points to the telephone number of the subject's assistant.

pszChildren

Points to the names of the subject's children.

pszCategory

Points to the name of the category to which the address card belongs. For example, a business card might belong to a "business" category.

pszWebPage

Points to the address of the subject's page on the world-wide web.

pszWorkPhone2

Points to the second work telephone number of the subject.

pszNamePrefix

Points to the subject's name prefix (for example, Mrs., Mr., Ms, and so on).

pszGivenName

Points to the subject's given name.

pszMiddleName

Points to the subject's middle name.

pszSurname

Points to the subject's surname.

pszGeneration

Points to the name of the subject's generation.

pszHomeAddrStreet

Points to the street address of the subject's home.

pszHomeAddrCity

Points to the city in which the subject lives.

pszHomeAddrState

Points to the state in which the subject lives.

pszHomeAddrPostalCode

Points to the postal code of the subject's home.

pszHomeAddrCountry

Points to the country in which the subject lives.

pszOtherAddrStreet

Points to the street address of the subject's second home

pszOtherAddrCity

Points to the city in which the subject's second home is located.

pszOtherAddrState

Points to the state in which the subject's second home is located.

pszOtherAddrPostalCode

Points to the postal code of the subject's second home.

pszOtherAddrCountry

Points to the country in which the subject's second home is located.

pszOfficeAddrStreet

Points to the street address of the subject's office.

pszOfficeAddrCity

Points to the city in which the subject's office is located.

pszOfficeAddrState

Points to the state in which the subject's office is located.

pszOfficeAddrPostalCode

Points to the postal code of the subject's office.

pszOfficeAddrCountry

Points to the country in which the subject's office is located.
