PSN_KILLACTIVE

Notifies a page that it is about to lose the activation either because another page is being activated or the user has chosen the OK button. This notification message is sent in the form of a WM_NOTIFY message.

lpnmhdr = (NMHDR FAR *) lParam;

Parameters

lpnmhdr

Address of an NMHDR structure. The hwndFrom member is the handle of the property sheet, and the hwndTo member is the handle of the page.

Return Values

Returns TRUE to prevent the page form losing the activation or FALSE to allow it.

Remarks

An application should validate the information that the user has entered.

To set the return value, the dialog box procedure for the page must use the SetWindowLong function with the DWL_MSGRESULT value, and the dialog box procedure must return TRUE.

If the dialog box procedure sets DWL_MSGRESULT to TRUE, it should display a message box to explain the problem to the user.
