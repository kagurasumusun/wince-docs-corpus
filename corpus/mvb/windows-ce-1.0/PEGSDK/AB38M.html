RasRenameEntry

The RasRenameEntry function changes the name of an entry in the phone book.

DWORD RasRenameEntry(// afdfunc.h
LPTSTR szPhonebook,// must be NULL
LPTSTR szOldEntry,// old entry name
LPTSTR szNewEntry// new entry name
);
Parameters
szPhonebook
Phone book name. Must be NULL.
szOldEntry
Old entry name.
szNewEntry
New entry name.
Return Values
If the function succeeds, the return value is zero. If the function fails, the return value is ERROR_INVALID_NAME, ERROR_ALREADY_EXISTS, or ERROR_CANNOT_FIND_PHONEBOOK_ENTRY.
