CreateMenu

The CreateMenu function creates a menu. The menu is initially empty, but it can be filled with menu items by using the AppendMenu and InsertMenu functions.

HMENU CreateMenu(void);// winuser.h
Return Values
If the function succeeds, the return value is the handle to the newly created menu. If the function fails, the return value is NULL.
Remarks
An application must free system resources associated with the menu before closing. An application frees menu resources by calling the DestroyMenu function.
