RapiFreeBuffer

RapiFreeBuffer frees the memory allocated by a Rapi call. For more information about using RAPI functions, please see the Remote API Functions overview.

STDAPI RapiFreeBuffer(// rapi.h
LPVOID Buffer// pointer to buffer to free
);
Parameters
Buffer
Pointer to buffer to free
Remarks
Any RAPI function that allocates memory on the users behalf must be freed by using RapiFreeBuffer.
