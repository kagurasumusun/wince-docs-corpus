RasDial

RAS dial-entry point.

Windows CE Notes The RasDial will not automatically display the login dialog. This is currently done thru the Remote Networking application. Applications are responsible for getting the information from the user.

Does not support the ERROR_CANNOT_FIND_PHONEBOOK_ENTRY return value.

DWORD RasDial(// afdfunc.h
LPRASDIALEXTENSIONS dialExtensions,// dial extensions
LPTSTR phoneBookPath,// phone book
LPRASDIALPARAMS rasDialParam,// dial parameters
DWORD NotifierType,// notifier type
LPVOID notifier,// pointer to notifier (or window handle)
LPHRASCONN pRasConn// pointer to RAS connection
);
Parameters
dialExtensions
The dial extensions.
phoneBookPath
The phone book.
rasDialParam
Dial parameters.
NotifierType
Notifier type.
notifier
Pointer to notifier (or window handle).
pRasConn
Returned pointer to RAS connection.
Return Values
Returns zero for success, otherwise one of the errors from Raserror.h.
Error Code		Description
ERROR_NOT_ENOUGH_MEMORYUnable to allocate memory.
ERROR_EVENT_INVALIDPPP Internal error.
ERROR_PORT_ALREADY_OPENPort already open.
ERROR_PPP_MACError initializing MAC layer.
ERROR_PPP_LCPError initializing LCP layer.
ERROR_PPP_AUTHError initializing AUTH layer.
ERROR_PPP_NCPError initializing NCP layer.
