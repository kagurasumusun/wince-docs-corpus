LB_GETSEL

An application sends an LB_GETSEL message to retrieve the selection state of an item.

wParam = (WPARAM) index; // item index

lParam = 0; // not used, must be zero

Parameters

index

Value of wParam. Specifies the zero-based index of the item.

Return Values

If an item is selected, the return value is greater than zero; otherwise, it is zero. If an error occurs, the return value is LB_ERR.
