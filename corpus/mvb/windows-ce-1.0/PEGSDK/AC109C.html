STORE_INFORMATION

The STORE_INFORMATION structure contains the size of the object store and the amount of free space currently in the object store.

typedef struct STORE_INFORMATION {-

DWORD dwStoreSize;

DWORD dwFreeSize;

} STORE_INFORMATION, *LPSTORE_INFORMATION;

Members

dwStoreSize

Specifies the size, in bytes, of the object store.

dwFreeSize

Specifies the amount of free space, in bytes, in the object store.
