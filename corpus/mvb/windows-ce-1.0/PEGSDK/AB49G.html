GetClassInfo

The GetClassInfo function retrieves information about a window class.

Windows CE Notes If lpClassName is an atom, it must be an atom returned from RegisterClass.

BOOL GetClassInfo(// winuser.h
HINSTANCE hInstance,// handle of application instance
LPCTSTR lpClassName,// address of class name string
LPWNDCLASS lpWndClass// address of structure for class data
);
Parameters
hInstance
Identifies the instance of the application that created the class. To retrieve information about classes defined by Windows (such as buttons or list boxes), set this parameter to NULL.
lpClassName
Points to a null-terminated string containing the class name. The name must be that of a preregistered class or a class registered by a previous call to the RegisterClass function.
lpWndClass
Points to a WNDCLASS structure that receives the information about the class.
Return Values
If the function finds a matching class and successfully copies the data, the return value is TRUE. If the function fails, the return value is FALSE. To get extended error information, call GetLastError.
