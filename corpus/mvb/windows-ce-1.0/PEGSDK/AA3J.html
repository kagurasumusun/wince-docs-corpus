TAPI Call Back Function

When Windows CE TAPI initializes use of the line abstraction, a callback function is specified. TAPI messages are delivered to the application through the callback procedure specified in the lineInitialize function.

Following is a description of the callback function. lineCallbackFunc is used as a placeholder for the name supplied by the application when the line is initialized for TAPI.

Syntax

void LineCallbackFunc (

DWORD hDevice,

DWORD dwMsg,

DWORD dwCallbackInstance,

DWORD dwParam1,

DWORD dwParam2,

DWORD dwParam3

);

Parameters

hDevice

Specifies a handle to the line device associated with the callback. The DWORD type should be used for this parameter; using the HANDLE type may generate an error.

dwMsg

Specifies the line device message.

dwCallbackInstance

Specifies the callback instance data passed back to the application in the callback.

dwParam1

Specifies a message parameter.

dwParam2

Specifies a message parameter.

dwParam3

Specifies a message parameter.
