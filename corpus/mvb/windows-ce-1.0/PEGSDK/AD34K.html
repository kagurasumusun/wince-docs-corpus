PSM_REMOVEPAGE

Removes a page from a property sheet.

wParam = (WPARAM)(int) index;

lParam = (LPARAM)(HPROPSHEETPAGE)hpage;

// Corresponding macro

void PropSheet_RemovePage(

hPropSheetDlg,

index,

hpage

);

Parameters

hPropSheetDlg

Handle of the property sheet.

hpage and index

Handle of the page to remove, and the zero-based index of the page to remove. An application can specify the handle or the index, or both. If both are specified, hpage takes precedence.

Return Values

No return value.
