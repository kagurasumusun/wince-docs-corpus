regValueDelete

regValueDelete key value

The regValueDelete statement deletes a named value from a key in the Windows CE registry. Most setup applications do not use this statement.

Parameters

key

Specifies the root key that contains the key to be deleted. This argument can one of the following values:

· HKEY_CLASSES_ROOT

· HKEY_CURRENT_USER

· HKEY_LOCAL_MACHINE

· HKEY_USERS

value

Specifies the name of the value to delete.
