Learning MIPS Assembly Language

The architecture of MIPS processors differs substantially from x86 architecture. You should read your MIPS documentation thoroughly before attempting to write any MIPS assembly-language code.

One source of learning MIPS assembly language is the MIPS Assembly Language Programmer’s Guide, published by Silicon Graphics, Inc. (October 1992). This document describes register-naming and other coding conventions accepted by both the inline and the stand-aone assembler provided in the MIPS edition of Visual C++. This chapter summarizes some of these conventions, but you should refer to the MIPS Assembly Language Programmer’s Guide for the complete rules of writing correct assembly-language code.
