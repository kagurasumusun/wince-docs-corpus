PSM_ADDPAGE

Adds a new page to the end of an existing property sheet.

wParam = 0;

lParam = (LPARAM)(HPROPSHEETPAGE)hpage

// Corresponding macro

BOOL PropSheet_AddPage(

hPropSheetDlg,

hpage

);

Parameters

hPropSheetDlg

Handle of the property sheet.

hpage

Handle of the page to add. The page must have been created by a previous call to the CreatePropertySheetPage function.

Return Values

No return value.

Remarks

The property sheet is not resized to fit the new page. The new page should be no larger than the largest page currently in the property sheet.
