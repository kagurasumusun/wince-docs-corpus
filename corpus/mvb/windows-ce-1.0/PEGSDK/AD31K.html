PSM_QUERYSIBLINGS

Forwards the message to each page in the property sheet. If a page returns a nonzero value, the property sheet does not send the message to subsequent pages.

wParam = (WPARAM) param1;

lParam = (LPARAM) param2;

// Corresponding macro

int PropSheet_QuerySiblings(

hPropSheetDlg,

param1,

param2

);

Parameters

hPropSheetDlg

Handle of the property sheet.

param1

First application-defined parameter.

param2

Second application-defined parameter.

Return Values

Returns the nonzero value from a page in the property sheet, or zero if no page returns a nonzero value.
