ImageList_GetBkColor

The ImageList_GetBkColor function retrieves the current background color for an image list.

COLORREF WINAPI ImageList_GetBkColor(// commctrl.h
HIMAGELIST himl// handle of the image list
);
Parameters
himl
Handle of the image list.
Return Values
Returns a COLORREF value that specifies the background color.
