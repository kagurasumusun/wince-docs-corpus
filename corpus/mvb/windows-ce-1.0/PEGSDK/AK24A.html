Windows CE SDK Environments

About the Windows CE SDK Environments

There are four specific target environments that Windows CE currently supports:

· Windows CE emulation under NT on an i386 CPU

· HPC target device with an SH3 CPU

· HPC target device with an R4100 CPU

Three of the four environments are installed under a given host computer during setup. Only one host cpu compatible version of the emulation environment is installed, along with the two remote target environments.

Each environment has a corresponding icon in the HPC group window which opens a command line window and sets the environment variables appropriately. See the following topics for specific environment settings and environment variable usage.
