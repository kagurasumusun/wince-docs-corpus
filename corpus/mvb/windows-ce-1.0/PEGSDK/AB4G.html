GetAddressCardIndex

The GetAddressCardIndex function retrieves the position index of the address card that has the given object identifier. The position index is based on the current sort order.

int GetAddressCardIndex(// addrstor.h
PEGOID oidCard// object identifier of address card
);
Parameters
oidCard
Specifies the object identifier of an address card.
Return Values
Returns the position index of the address card if successful, or –1 if an error occurs.
The Contacts database must have been opened by a previous call to the OpenAddressBook function. This function fails if no sort order was specified when the address book was opened.
