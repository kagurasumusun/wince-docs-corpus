TVN_ITEMEXPANDED

Notifies a tree view control's parent window that a parent item's list of child items has expanded or collapsed. This notification message is sent in the form of a WM_NOTIFY message.

pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv

Address of an NM_TREEVIEW structure. The itemNew member is a TV_ITEM structure that contains valid information about the parent item in the hItem, state, and lParam members. The action member indicates whether the list expanded or collapsed. For a list of possible values, see the description of the TVM_EXPAND message.

Return Values

No return value.
