Load Functions

Following is a list of functions available for loading applications.

Load FunctionDescription
LoadMain entry point to download applications from the desktop PC to the HPC
Load_AlreadyInstalledDetermines whether the application is already installed on the HPC
Load_ExitStops the RPC service
Load_InitInitializes the RPC service
Load_PegCpuTypeDetermines type of CPU running on the HPC
Load_PegFreeSpaceDetermines the amount of free memory in the HPC’s object store
Load_RegisterFileInfoRegisters file information with the HPC Explorer
