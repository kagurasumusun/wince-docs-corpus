PegRegEnumKeyEx

The PegRegEnumKeyEx function is the RAPI version of the RegEnumKeyEx function. For more information about using RAPI functions, please see the Remote API Functions overview.

LONG PegRegEnumKeyEx(// rapi.h
HKEY IN hKey,// handle of key to enumerate
DWORD IN dwIndex,// index of subkey to enumerate
LPWSTR OUT lpszName,// address of buffer for subkey name
LPDWORD INOUT lpcchName,// address for size of subkey buffer
LPDWORD NIETHER lpReserved,// reserved
LPWSTR OUT lpszClass,// address of buffer for class string
LPDWORD INOUT lpcchClass,// address for size of class buffer
PFILETIME OUT lpftLastWrite// address for time key last written to
);
Parameters
hKey
Identifies a currently open key or any of the following predefined reserved handle values:
· HKEY_CLASSES_ROOT
· HKEY_CURRENT_USER
· HKEY_LOCAL_MACHINE
· HKEY_USERS
The enumerated keys are subkeys of the key identified by hKey.
dwIndex
Specifies the index of the subkey to retrieve. This parameter should be zero for the first call to the PegRegEnumKeyEx function and then incremented for subsequent calls.
Because subkeys are not ordered, any new subkey will have an arbitrary index. This means that the function may return subkeys in any order.
lpszName
Points to a buffer that receives the name of the subkey, including the terminating null character. The function copies only the name of the subkey, not the full key hierarchy, to the buffer.
lpcchName
Points to a variable that specifies the size, in characters, of the buffer specified by the lpszName parameter. This size should include the terminating null character. When the function returns, the variable pointed to by lpcchName contains the number of characters stored in the buffer. The count returned does not include the terminating null character.
lpReserved
Reserved; must be NULL.
lpszClass
Points to a buffer that contains the class of the enumerated subkey when the function returns. This parameter can be NULL if the class is not required.
lpcchClass
Points to a variable that specifies the size, in characters, of the buffer specified by the lpszClass parameter. The size should include the terminating null character. When the function returns, lpcchClass contains the number of characters stored in the buffer. The count returned does not include the terminating null character. This parameter can be NULL only if lpszClass is NULL.
lpftLastWriteTime
Not used.
Return Values
If the function succeeds, the return value is ERROR_SUCCESS. If the function fails, the return value is an error value.
Remarks
To enumerate subkeys, an application should initially call the PegRegEnumKeyEx function with the dwIndex parameter set to zero. The application should then increment the dwIndex parameter and call PegRegEnumKeyEx until there are no more subkeys (until the function returns ERROR_NO_MORE_ITEMS).
The application can also set dwIndex to the index of the last subkey on the first call to the function and decrement the index until the subkey with the index zero is enumerated. To retrieve the index of the last subkey, use the PegRegQueryInfoKey function.
While an application is using the PegRegEnumKeyEx function, it should not make calls to any registration functions that might change the key being enumerated.
The key identified by hKey must have been opened with KEY_ENUMERATE_SUB_KEYS access (KEY_READ includes KEY_ENUMERATE_SUB_KEYS). Use the PegRegCreateKeyEx or PegRegOpenKeyEx function to open the key.
