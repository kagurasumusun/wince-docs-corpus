BN_DOUBLECLICKED

The BN_DOUBLECLICKED notification message is sent when the user double-taps the pen on the touch-screen. The parent window of the button receives this notification message through the WM_COMMAND message.

Remarks

This notification message applies only to buttons with the BS_RADIOBUTTON and BS_OWNERDRAW styles.
