User Notification Preferences

All user notifications include a taskbar annunciator. The user can also be notified of an event in one of the following ways:

· Playing a .wav file. Currently all hardware manufacturers support this option.

· Flashing the light-emitting diode (LED). Currently some hardware manufacturers offer this option.

· Displaying a dialog box.

· Vibrating the HPC. At present, no hardware manufacturer is supporting this option.

The actions that the system performs for a particular notification should be based on preferences selected by the user. An application uses the PegGetUserNotificationPreferences function to get the user's preferences for a particular notification. The function displays a dialog box containing the options available on the particular HPC (this will vary by manufacturer), and fills a PEG_USER_NOTIFICATION structure with the options that the user selects. The application passes the user's preferences to the system when scheduling an event by specifying the address of the PEG_USER_NOTIFICATION structure as a parameter to the PegSetUserNotification function.

The type of notification is specified by setting the ActionFlags property of the PEG_USER_NOTIFICATION structure before calling PegSetUserNotification.
