SetDlgMsgResult

The SetDlgMsgResult macro calls SetWindowLong and sets the return value of the message processed in the dialog box procedure.

SetDlgMsgResult(
hwnd,
msg,
result
);
If msg is WM_INITDIALOG, then result is returned, cast as a BOOL.
Otherwise, SetWindowLong is called, passing hwnd, DWL_MSGRESULT, and result as the parameters for SetWindowLong.
