ImageList_Add

The ImageList_Add function adds an image or images to an image list.

int WINAPI ImageList_Add(// commctrl.h
HIMAGELIST himl,// handle of the image list
HBITMAP hbmImage,// handle of the bitmap that contains the images
HBITMAP hbmMask// handle of the bitmap that contains the mask
);
Parameters
himl
Handle of the image list.
hbmImage
Handle of the bitmap that contains the image or images. The number of images is inferred from the width of the bitmap.
hbmMask
Handle of the bitmap that contains the mask. If no mask is used with the image list, this parameter is ignored.
Return Values
Returns the index of the first new image if successful or –1 otherwise.
Remarks
This function copies the bitmap to an internal data structure. Be sure to use the DeleteObject function to delete hbmImage and hbmMask after the function returns.
