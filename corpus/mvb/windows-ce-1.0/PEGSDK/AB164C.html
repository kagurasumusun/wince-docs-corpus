CountClipboardFormats

The CountClipboardFormats function retrieves the number of different data formats currently on the clipboard.

int CountClipboardFormats(void);// winuser.h
Parameters
This function has no parameters.
Return Values
If the function succeeds, the return value is the number of different data formats currently on the clipboard. If the function fails, the return value is zero. To get extended error information, call GetLastError.
