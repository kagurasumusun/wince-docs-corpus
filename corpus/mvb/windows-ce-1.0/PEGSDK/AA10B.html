Dialog and Message Boxes

Windows CE supports both modal and modeless Dialog Boxes, with all the predefined controls found in Windows 95. Message boxes are supported, although with fewer styles available than for Windows 95. Refer to the Developers Reference for restrictions on styles and some other aspects of dialog and message box functionality.

Common Dialog boxes

Windows CE supports two of the Win32 common dialog boxes: Open and Save As. The function calls used to invoke them (GetOpenFileName and GetSaveFileName) are identical to those found in Win32. They are similar in on-screen appearance to their Windows 95 equivalents, but with fewer controls (see the end user documentation for details on appearance and use). The available features are :

· Open Dialog

· Application modal, not movable

· Up Folder, List, and Details View buttons

· New Folder button

· Editable Name text box

· Type drop-down list box

· Error message boxes

· Save As Dialog

· Application modal, not movable

· Up Folder, List, and Details View buttons

· New Folder button

· Editable Name text box

· Type drop-down list box

· Error message boxes
