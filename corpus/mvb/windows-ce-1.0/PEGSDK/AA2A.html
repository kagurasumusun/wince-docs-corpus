Windows CE Architecture

Windows CE, Microsoft's software platform for the HPC, consists of a Microsoft Windows–style operating system, a shell, and a suite of personal information manager (PIM) applications that run on the pocket-sized computer.

The HPC is a mobile companion to a personal computer (PC) running Microsoft Windows 95 and Windows 95–based applications. Because the Windows CE shell is similar in most respects to the Windows 95 shell, the learning curve for Windows 95 users should be minimal.

The applications that come bundled with the HPC include pocket versions of Microsoft Word and Microsoft Excel, e-mail, a calendar, a Contacts information manager, and a task manager. Each of these applications has a counterpart that runs on a desktop PC. Windows CE provides a file conversion utility to transfer data files between platforms. Data files can also be synchronized to reflect changes made on either machine. For example, the user can make an entry in the information manager on the HPC or in the Schedule+ database on the desktop PC; then when the machines are connected and synchronization is performed, the entry would be in both databases.
