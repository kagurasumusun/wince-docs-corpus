STYLESTRUCT

The STYLESTRUCT structure contains the window styles for a window.

typedef struct tagSTYLESTRUCT {-  // ss

DWORD styleOld;

DWORD styleNew;

} STYLESTRUCT, * LPSTYLESTRUCT;

Members

styleOld

Previous window style or extended style flags.

styleNew

Current window style or extended style flags.
