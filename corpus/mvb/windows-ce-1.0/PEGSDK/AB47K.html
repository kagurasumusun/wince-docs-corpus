MailGetSvcId

The MailGetSvcId function retrieves the object ID of a mail entry from the message store based on the value of the service ID.

BOOL MailGetSvcId (// msgstore.h
HANDLE hService,// Handle to mail context.
MailMsg* pmm// Item information.
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
pmm
Points to the MailMsg structure containing the service name and ID being passed in and the object ID and associated flags passed back when the function completes successfully.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
