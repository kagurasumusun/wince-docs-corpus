Limitations on available RAM

Devices which run Windows CE will have at least 2 MB of RAM available, although some manufacturers may choose to provide more (probably no more than 4 MB total). Not only is this much less memory than most PCs, it must serve a wider range of purposes.

A significant portion of this memory will be taken up by the operating system kernel, and related RAM-resident parts of the operating system. In addition, an HPC has no hard disk or other mass storage device. While bundled applications such as Pocket Word will reside in ROM when not in use, all other applications along with data and resources must be stored in RAM.

Your application must be able to run in what memory is not being used for these purposes. Memory-related issues are discussed at more length in Chapter 4, "Memory Management".
