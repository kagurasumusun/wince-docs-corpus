User Notification

You can alert the user of application-defined events, such as appointment reminders, using the Windows CE notification interface. Users may be notified by the appearance of an icon in the notification area of the taskbar, the display of a message, sound, and other device-dependent feedback such as lighting of an LED or vibration. To design notification options to be set by the user, use the system-provided notification options dialog box, which allows the user to choose the preferred form of feedback. This also allows your application to support notification without querying for what feedback the host device supports. For example, not all handheld PCs running Windows CE may support a notification LED. To support displaying a message window, the system also supports a standard interface to which you can pass a string.

If users choose no notification option, the system still displays your application’s icon in the notification area of the taskbar. However, your application must handle removing the icon when the user has acknowledged the notification.
