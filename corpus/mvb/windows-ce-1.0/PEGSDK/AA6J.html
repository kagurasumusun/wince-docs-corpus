TAPI Structures

Following is a list describing the TAPI structures supported for Windows CE.

StructureDescription
LINECALLINFOContains information about a call.
LINECALLPARAMSDescribes the parameters used when making a call.
LINEDEVCAPSDescribes the capabilities of a line device.
LINEDEVSTATUSDescribes the current status of a line device.
LINETRANSLATECAPSDescribes address translation capabilities.
These structures are explained in more detail in the reference section of this document.
