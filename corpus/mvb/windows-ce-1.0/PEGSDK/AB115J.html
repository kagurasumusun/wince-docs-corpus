Load_PegCpuType

Retrieves a character string containing the name of the Handheld PC CPU type.

BOOL Load_PegCpuType(// ppcload.h
LPSTR lpszCpu// pointer to a string containing type of CPU running the device
);
Parameters
lpszCpu
Upon successful completion of the function, this parameter points to a string containing the type of CPU running the device
Currently the valid types pointed to by lpszCpu include the following.
HPC CPU Type		String Returned
Hitachi SH3SH3
MIPS R4000MIPS
Return Value
This function returns TRUE if the CPU type was retrieved successfully, or FALSE if an error occurred during the retrieval, or an unknown CPU type was found.
Remarks
For this function to return a CPU type, HPC Explorer must have previously connected to the Handheld PC at least once.
This function is exported by Ppcload.dll, which runs on the desktop PC—it is intended to be called from a setup program.
