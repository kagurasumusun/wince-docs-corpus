ImageList_DragShowNolock

The ImageList_DragShowNolock function shows or hides the image being dragged.

BOOL WINAPI ImageList_DragShowNolock(// commctrl.h
BOOL fShow// value specfying show or hide image
);
Parameters
fShow
Value specifying whether to show or hide the image being dragged. Specify TRUE to show the image; specify FALSE to hide the image.
Return Values
Returns TRUE if successful or FALSE otherwise.
