CreateAddressBook

The CreateAddressBook function creates the Contacts database if it does not already exist.

BOOL CreateAddressBook(// addrstor.h
HHPRTAG *rghhProps,// address of array of property tags
int numProps// number of tags in array
);
Parameters
rghhProps
Points to an array of up to four property tags that identify properties on which the address cards can be sorted. Property tags begin with the HHPR_ prefix. Refer to Properties and Property Tags in the Contacts Database guide chapter for a list of these tags. If this parameter is NULL, the function uses the following property tags by default:
Value		Meaning
HHPR_SURNAMESort based on surnames.
HHPR_COMPANY_NAMESort based on company names.
HHPR_OFFICE_TELEPHONE_NUMBERSort based on the office telephone numbers.
HHPR_HOME_TELEPHONE_NUMBERSort based on home telephone numbers.
numProps
Specifies the number of property tags in the rghhProps array. If rghhProps is NULL, this parameter is ignored.
Return Values
Returns TRUE if the Contacts database was created, or FALSE otherwise. To get extended error information, use the GetLastError function.
Remarks
Before calling this function, an application should use the OpenAddressBook function to determine whether the Contacts database already exists.
