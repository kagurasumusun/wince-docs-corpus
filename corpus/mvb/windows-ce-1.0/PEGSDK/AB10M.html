RasDeleteEntry

The RasDeleteEntry function deletes an entry from the phone book.

Windows CE Notes Does not support the ERROR_INVALID_NAME return value.

DWORD RasDeleteEntry(// afdfunc.h
LPTSTR lpszPhonebook,// full path and file name of the phone book file
LPTSTR lpszEntry// existing entry name that will be deleted
);
Parameters
lpszPhonebook
Points to a null-terminated string that specifies the full path and file name of the phone book file. This parameter can be NULL, in which case the default phone book file is used. This parameter should always be NULL for Windows 95 and Windows CE since the phone book entries are stored in the registry.
lpszEntry
Points to a null-terminated string containing an existing entry name that will be deleted.
Return Values
If the function succeeds, the return value is zero. If the function fails, the return value is one of the following.
Error Code		Description
ERROR_CANNOT_OPEN_PHONEBOOKInvalid phone book entry specified. For Win95 and Windows CE the lpszPhonebook parameter must be NULL.
OthersErrors returned from RegDeleteKey().
