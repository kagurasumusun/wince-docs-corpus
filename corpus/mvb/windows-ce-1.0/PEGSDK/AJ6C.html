New Cross-Development Model

Getting StartedYou do not need a HPC to begin developing Windows CE applications. Just launch Visual C++ for Windows CE and choose File, New, Project Workspace.
Choose a Project TypeApplication, Dynamic-Link Library, Static Library and Makefile are supported project types for Windows CE. (MFC, OLE, Console Applications and Custom AppWizards are not yet supported.)
Choose your Target Platform(s)Win32 (x86EM) emulation on an x86 host
Win32 (PegMIPS) R4100 target device
Win32 (PegSH) SH3 target device
Win32 standard Win32 API
Write your ProgramUse the Win32 for Windows CE API set and the common Windows CE C Run-Time functions for maximum portability across platforms.
Build your ProgramEach target builds with the appropriate compiler and libraries. Flags and options default automatically for debug and release versions for each target platform.
To modify these defaults, choose Build, Settings.
Execute and Debug in EmulationSee how the program runs and use the integrated visual debugger before you even attach an HPC.
Attach the HPC(See release notes for details on remote hardware configuration.)
Execute and Debug RemoteStart the remote debugging version of the IDE (msdev -pegasus) to enable remote debugging. Use remote versions of Spy, RegEdit, MemView and Zoomin and other remote tools.
