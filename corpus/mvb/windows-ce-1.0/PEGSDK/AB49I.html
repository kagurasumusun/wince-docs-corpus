ImageList_DrawEx

The ImageList_DrawEx function draws an image list item in the given device context (DC). The function uses the specified drawing style and blends the image with the specified color.

BOOL WINAPI ImageList_DrawEx(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iDraw,// index of the image to draw.
HDC hdcDst,// handle of the destination DC
int x,// y-coordinate location at which to draw within the specified DC.
int y,// x-coordinate location at which to draw within the specified DC.
int cx,// portion of the image to draw: x-direction
int cy,// portion of the image to draw: y-direction
COLORREF rgbBk,// background color of the image
COLORREF rgbFg,// foreground color of the image
UINT fStyle// flag specifying the drawing style
);
Parameters
himl
Handle of the image list.
iDraw
Index of the image to draw.
hdcDst
Handle of the destination DC.
x and y
x-coordinate and y-coordinate positions that specify the location at which to draw within the specified DC.
cx and cy
Portion of the image to draw, relative to the upper left corner of the image. If these parameters are zero, the function draws the entire image. The function does not ensure that the parameters are valid.
rgbBk
Background color of the image. This parameter can be an application-defined RGB value or one of the following.
Value		Meaning
CLR_NONENo background color. The image is drawn transparently.
CLR_DEFAULTDefault background color. The image is drawn using the background color of the image list.
This parameter is used only if the image list identified by himl was created with the ILC_MASK value.
rgbFg
Foreground color of the image. This parameter can be an application-defined RGB value or one of the following values.
Value		Meaning
CLR_NONENo blend color. The image is blended with the color of the destination DC.
CLR_DEFAULTDefault foreground color. The image is drawn using the system highlight color as the foreground color.
CLR_HILIGHTSame as CLR_DEFAULT
This parameter is used only if fStyle includes the ILD_BLEND25 or ILD_BLEND50 value.
fStyle
Flag specifying the drawing style. This parameter can be one or more of the following values.
Value		Meaning
ILD_BLENDSame as ILD_BLEND25.
ILD_BLEND25Draws the image, blending 25 percent with the blend color specified by rgbFg. This value has no effect if the image list does not contain a mask.
ILD_BLEND50Draws the image, blending 50 percent with the blend color specified by rgbFg. This value has no effect if the image list does not contain a mask.
ILD_FOCUSSame as ILD_BLEND25.
ILD_IMAGEDraws the image. Not recommended.
ILD_MASKDraws the mask. Not recommended.
ILD_NORMALDraws the image using the background color for the image list. If the background color is the CLR_NONE value, the image is drawn transparently using the mask.
ILD_OVERLAYMASKIsolates the one-based index of the overlay image to be drawn. Set the overlay image index using the INDEXTOOVERLAYMASK macro.
ILD_SELECTEDSame as ILD_BLEND50.
ILD_TRANSPARENTDraws the image transparently using the mask, regardless of the background color. This value has no effect if the image list does not contain a mask.
Return Values
Returns TRUE if successful or FALSE otherwise.
See Also
