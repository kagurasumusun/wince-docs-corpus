Notification Dialog Box

A notification dialog box contains the following elements:

· An application-defined title

· Application-defined text

· An OK button

· A Snooze button

The application sets the title and text when calling PegSetUserNotification. The dialog box title is specified by the pwszDialogTitle member of the PEG_USER_NOTIFICATION structure. The dialog box text is specified by the pwszDialogText member of the PEG_USER_NOTIFICATION structure.

If the user taps the OK button, the notification is handled. Tapping the snooze button does not handle the notification. When the user taps snooze, the dialog box is redisplayed after five minutes.
