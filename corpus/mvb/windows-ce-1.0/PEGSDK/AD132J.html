LVM_SETCALLBACKMASK

Sets the callback mask for a list view control. You can send this message explicitly or by using the ListView_SetCallbackMask macro.

wParam = (WPARAM)(UINT) mask;

lParam = 0;

// Corresponding macro

BOOL ListView_SetCallbackMask(

HWND hwnd,

UINT mask

);

Parameters

hwnd

Handle of the list view control.

mask

New value of the callback mask.

Return Values

Returns TRUE if successful or FALSE otherwise.
