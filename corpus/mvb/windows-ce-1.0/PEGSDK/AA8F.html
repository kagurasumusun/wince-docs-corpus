Adding an Address Card

Adding an address card to the database is a multiple step process. First, the application fills an AddressCard structure with information about the new card's properties. Next, the application must make a series of calls to the SetMask function, one call for each property that is present in the new card. The system maintains an internal bitmask for each card that identifies the properties that must be saved in the object store, and SetMask sets the appropriate flags in the bitmask. When calling SetMask, the application specifies the address of the AddressCard structure and the property tag of a property that is present in the card. Finally, the application calls the AddAddressCard function to add a new address card to the database.

To remove an address card from the database, an application uses the DeleteAddressCard function.
