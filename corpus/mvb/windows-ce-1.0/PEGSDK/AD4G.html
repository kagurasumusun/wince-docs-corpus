HDM_GETITEM

Retrieves information about an item in a header control.

wParam = (WPARAM)(int) index;

lParam = (LPARAM)(HD_ITEM FAR*) phdi;

// Corresponding macro

BOOL Header_GetItem(

hwndHD,

index,

phdi

);

Parameters

hwndHD and index

Handle of the header control, and the index of the item for which information is to be retrieved.

phdi

Address of an HD_ITEM structure. When the message is sent, the mask member indicates the type of information being requested. When the message returns, the other members receive the requested information. If the mask member specifies zero, the message returns TRUE but copies no information to the structure.

Return Values

Returns TRUE if successful or FALSE otherwise.

See Also

HD_ITEM, HDM_GETITEMCOUNT, HDM_SETITEM
