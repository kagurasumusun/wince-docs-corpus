Creating Command Bars

An application creates a command bar by using the CommandBar_Create function specifying the following parameters:

· Handle of application instance

· Handle of parent window

· Command bar identifier

The window procedure for a command bar automatically sets the size of the command bar and positions the bar along the top of the parent window client area.

Because a command bar takes up part of the parent window client area, the rectangle retrieved by the GetClientRect function may not reflect the usable portion of the client area. To determine the useable portion, add the height of the command bar to the top coordinate of the rectangle retrieved by GetClientRect. Use the CommandBar_Height function to retrieve the command bar visible height in pixels.

The system automatically destroys a command bar when its parent window is destroyed. Use the CommandBar_Destroy function to destroy the command bar while retaining the parent window.
