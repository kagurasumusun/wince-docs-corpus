TVN_ENDLABELEDIT

Notifies a tree view control's parent window about the end of label editing for an item. This notification message is sent in the form of a WM_NOTIFY message.

ptvdi = (TV_DISPINFO FAR *) lParam

Parameters

ptvdi

Address of a TV_DISPINFO structure. The item member is a TV_ITEM structure containing valid information about the item that was edited in the hItem, lParam, and pszText members. If label editing was canceled, the pszText member is zero.

Return Values

No return value.

See Also

NM_TREEVIEW, TV_ITEM, TVM_EDITLABEL, TVN_BEGINLABELEDIT, WM_NOTIFY
