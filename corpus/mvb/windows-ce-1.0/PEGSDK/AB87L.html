PegFindAllDatabases

PegFindAllDatabases is a remote API function that retrieves information about all databases of a given type residing on the Handheld PC. The function copies information to an array of PEGDB_FIND_DATA structures. For more information about using RAPI functions, please see the Remote API Functions overview.

BOOL PegFindAllDatabases(// rapi.h
DWORD dwDbaseType,// type identifier of databases
WORD wFlags,// retrieval flags
LPWORD cFindData,// address of variable for a count of items retrieved
LPLPPEGDB_FIND_DATA ppFindData// address of pointer to retrieved data
);
Parameters
dwDbaseType
Specifies the type identifier of the of databases to seek.
wFlags
Indicates the members of the PEGDB_FIND_DATA structure that are to be retrieved. This parameter can be one of these values.
Value		Meaning
FAD_OIDRetrieve the OidDb member.
FAD_FLAGSRetrieve the DbInfo.dwFlags member.
FAD_NAMERetrieve the DbInfo.szDbaseName member.
FAD_TYPERetrieve the DbInfo.dwDbaseType member.
FAD_NUM_RECORDSRetrieve the DbInfo.dwNumRecords member.
FAD_NUM_SORT_ORDERRetrieve the DbInfo.dwNumSortOrder member.
FAD_SORT_SPECSRetrieve the DbInfo.rgSortSpecs member.
cFindData
Points to a variable that receives a count of the items found.
ppFindData
Points to the address of an array of PEGDB_FIND_DATA structures that receives information about the found items. It is the application's responsibility to free the memory used by the array. To free the memory you must call RapiFreeBuffer.
Return Values
Returns TRUE if successful or FALSE if an error occurs.
