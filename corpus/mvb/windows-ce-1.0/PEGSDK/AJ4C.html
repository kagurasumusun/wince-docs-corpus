New Packages and Platforms

Microsoft Visual C++ 4.0 for Windows CE provides an overlay of packages that allows you to develop applications for multiple targets simultaneously. On an i86 host machine you can now build programs from a single makefile for execution and debugging in any or all of the following environments in addition to standard Win32:

· Windows CE Emulation Environment (i86EM)

· Windows CE SH3 target device (PegSH)

· Windows CE MIPS target device (PegMIPS)
