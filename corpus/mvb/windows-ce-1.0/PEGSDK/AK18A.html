Remote Registry Editor

The Remote Registry Editor (Pregedit.exe) user interface is identical to the standard Windows RegEdit, except that you are editing a copy of the HPC registry. The actual HPC registry is not affected until you click Export Registry To Peg from the Registry menu. Only the registry portion that was actually modified during your edit session is exported back to the HPC registry. To refresh the display of the HPC registry, click Import Registry From Peg from the Registry menu.

You are prompted to export the registry on exit if you have made changes.
