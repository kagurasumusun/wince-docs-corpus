PSM_CHANGED

Informs a property sheet that information in a page has changed. The property sheet enables the Apply Now button.

wParam = (WPARAM)(HWND) hwndPage;

lParam = 0;

// Corresponding macro

BOOL PropSheet_Changed(

hPropSheetDlg,

hwndPage

);

Parameters

hPropSheetDlg

Handle of the property sheet.

hwndPage

Handle of the page that has changed.

Return Values

No return value.
