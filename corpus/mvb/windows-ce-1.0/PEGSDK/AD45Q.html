TVM_GETITEM

Retrieves some or all of a tree view item's attributes. You can send this message explicitly or by using the TreeView_GetItem macro.

wParam = 0;

lParam = (LPARAM)(TV_ITEM FAR*) pitem;

// Corresponding macro

BOOL TreeView_GetItem(

hwnd,

pitem

);

Parameters

hwnd

Handle of the tree view control.

pitem

Address of a TV_ITEM structure that specifies the information to retrieve and receives information about the item. When the message is sent, the hItem member identifies the item to retrieve information about and the mask member specifies the attributes to retrieve.

If mask specifies the TVIF_TEXT value, the pszText member must contain the address of the buffer that receives the item text and the cchTextMax member must specify the size of the buffer.

If mask specifies the TVIF_STATE value, the stateMask member indicates which item states are to be returned.

Return Values

Returns TRUE if successful or FALSE otherwise.
