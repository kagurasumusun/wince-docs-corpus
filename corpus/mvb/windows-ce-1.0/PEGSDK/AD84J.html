LVM_GETORIGIN

Retrieves the current view origin for a list view control. You can send this message explicitly or by using the ListView_GetOrigin macro.

wParam = 0;

lParam = (LPARAM)(LPPOINT) lpptOrg;

// Corresponding macro

BOOL ListView_GetOrigin(

HWND hwnd,

LPPOINT lpptOrg

);

Parameters

hwnd

Handle of the list view control.

lpptOrg

Address of a POINT structure that receives the view origin.

Return Values

Returns TRUE if successful or FALSE if the current view is list or report view.
