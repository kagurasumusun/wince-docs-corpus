MailOpen

The MailOpen function opens the message store and obtains a handle to the mail context.

BOOL MailOpen (// msgstore.h
HANDLE *NewHandle,// Handle to mail context.
BOOL fAllowCreate,// Allow message store database creation.
);
Parameters
NewHandle
The handle created by this function for identifying the mail context.
fAllowCreate
If this parameter is TRUE this function will attempt to create the message store if it does not already exist. If this parameter is FALSE and the message store does not exist, this function will fail.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
Remarks
Release the handle created by this function with the MailClose function.
