ImageList_SetOverlayImage

The ImageList_ SetOverlayImage function adds the index of an image to the list of images to be used as overlay masks. Up to four indices can be added to the list.

BOOL WINAPI ImageList_SetOverlayImage(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iImage,// index of the image
int iOverlay// one based index of the overlay mask
);
Parameters
himl
Handle of the image list.
iImage
Index of the image to use as an overlay mask.
iOverlay
One-based index of the overlay mask.
Return Values
Returns TRUE if successful or FALSE otherwise.
Remarks
An overlay mask is an image drawn transparently over another image. An overlay mask is drawn over an image by using the ImageList_Draw or ImageList_DrawEx function with the index of the overlay mask. The index must be specified by using the INDEXTOOVERLAYMASK macro.
