Communication API Functions

Listed below are the communication functions available for setting up and using serial devices on the HPC. Code examples of how these functions are used for the HPC built-in serial device are provided with the SDK in the directory \Peg\Samples\Tty.

Getting Serial Device Information

FunctionDescriptionExample Exists In \Peg\Samples\Tty
GetCommMaskGets the value of the event mask for a serial device.No
GetCommModemStatusGets the modem control register values.Yes
GetCommPropertiesGets information about the serial driver.No
GetCommStateGets the current control settings for a serial device and fills in a DCB structure.Yes
GetCommTimeoutsGets time-out parameters for all read and write operations on a serial device.Yes
Setting up the Serial Device Information
Function		DescriptionExample Exists In \Peg\Samples\Tty
SetCommConfigSets the current configuration of a serial device.No
SetCommMaskSpecifies a set of events to be monitored for a serial device.Yes
SetCommStateConfigures a serial device as specified by a device control block (DCB structure).Yes
SetCommTimeoutsSets the time-out parameters for all read and write operations on a serial device.Yes
SetupCommInitializes the communication parameters for a serial device.No
Using the Serial Device
Function		DescriptionExample Exists In \Peg\Samples\Tty
ClearCommBreakRestores character transmission for a serial device—this clears a break state set by SetCommBreak. Note that this can also be accomplished by calling EscapeCommFunction and setting dwFunc to CLRBREAKNo
SetCommBreakSuspends character transmission for a serial device and places the transmission line in a break state.
Note that this can also be accomplished by calling EscapeCommFunction and setting dwFunc to SETBREAK.		No
ClearCommErrorGets information about a communication error and reports the current status of a serial device.No
EscapeCommFunctionDirects a serial device to perform an extended function.Yes
PurgeCommPerforms actions including terminating pending read or write operations, or clearing the serial device’s input or output buffer.No
TransmitCommCharTransmits a specified character ahead of any pending data in the output buffer of the serial device.No
WaitCommEventWaits for an event (specified by SetCommMask) to occur for a serial device.Yes
