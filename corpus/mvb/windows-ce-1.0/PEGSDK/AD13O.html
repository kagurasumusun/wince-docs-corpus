TBM_GETLINESIZE

Retrieves the size of the line for a trackbar. The line size affects how much the slider moves for the TB_LINEUP and TB_LINEDOWN notification messages.

wParam = 0;

lParam = 0;

Parameters

Return Values

Returns a 32-bit value that specifies the size of a line for the trackbar.

Remarks

The default setting for the line size is one (1).
