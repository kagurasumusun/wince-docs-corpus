RasEnumConnections

Lists all active RAS connections. It returns each connection's handle and phone book entry name.

void RasEnumConnections(// afdfunc.h
LPRASCONN lpRasConn,// buffer to receive connections data
LPDWORD lpcb,// buffer size in bytes
LPDWORD lpcConnections// number of connections written to buffer
);
Parameters
lpRasConn
Buffer to receive connections data.
lpcb
Buffer size in bytes.
lpcConnections
Number of connections written to buffer.
Return Values
Returns a DWORD zero for success, or a nonzero failure code defined in Raserror.h.
Error Code		Description
ERROR_INVALID_SIZElpRasConn->dwSize is invalid.
ERROR_BUFFER_TOO_SMALLBuffer size is too small.
