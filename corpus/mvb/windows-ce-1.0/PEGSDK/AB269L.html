PegSHCreateShortcut

The PegSHCreateShortcut function is the RAPI version of the SHCreateShortcut function. For more information about using RAPI functions, please see the Remote API Functions overview.

DWORD PegSHCreateShortcut(// rapi.h
LPWSTR IN lpszShortcut,// address of shortcut name
LPWSTR IN lpszTarget// address of target pathname
);
Parameters
szShortcut
Pointer to a buffer that contains the name of the shortcut to create. Passing a NULL value for this parameter will cause an exception
szTarget
Pointer to a buffer that contains the target path of the shortcut.
