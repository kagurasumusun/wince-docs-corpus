GetClipboardDataAlloc

Retrieves data from the clipboard in the specified format.

Windows CE Notes This function is provided for Windows CE only. This function works like GetClipboardData except that it returns memory that has been allocated in the caller's process. This memory is owned by the calling process and needs to be freed using LocalFree when no longer in use. This function should be used if the caller would normally use GetClipboardData and then do a LocalAlloc and copy the data.

HANDLE GetClipboardDataAlloc(// winuser.h
UINT uFormat// clipboard format
);
Parameters
uFormat
Clipboard format.
Remarks
This function can potentially save an extra memory allocation in cases where the data is being transfered across processes.
