FindWindow

The FindWindow function retrieves the handle to the top-level window whose class name and window name match the specified strings. This function does not search child windows.

Windows CE Notes If lpClassName is an atom, it must be an atom returned from RegisterClass.

HWND FindWindow(// winuser.h
LPCTSTR lpClassName,// pointer to class name
LPCTSTR lpWindowName// pointer to window name
);
Parameters
lpClassName
Points to a null-terminated string that specifies the class name. If lpClassName is an atom, it must be an atom returned from RegisterClass.
lpWindowName
Points to a null-terminated string that specifies the window name (the window's title). If this parameter is NULL, all window names match.
Return Values
If the function succeeds, the return value is the handle to the window that has the specified class name and window name. If the function fails, the return value is NULL. To get extended error information, call GetLastError.
