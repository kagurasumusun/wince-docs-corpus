LVN_GETDISPINFO

Requests a list view control's parent window to provide information needed to display or sort an item. This notification message is sent in the form of a WM_NOTIFY message.

pnmv = (LV_DISPINFO FAR *) lParam;

Parameters

pnmv

Address of an LV_DISPINFO structure that specifies the type of information required and that receives the information.

Return Values

No return value.

See Also

LV_DISPINFO, WM_NOTIFY
