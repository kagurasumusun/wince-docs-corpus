ImageList_GetIcon

The ImageList_GetIcon function creates an icon or cursor based on an image and mask in an image list.

HICON WINAPI ImageList_GetIcon(// commctrl.h
HIMAGELIST himl,// handle of the image list
int iImage,// index of the image
UINT fStyle// combination of flags specifying the drawing style
);
Parameters
himl
Handle of the image list.
iImage
Index of the image.
fstyle
Combination of flags that specify the drawing style. For a list of values, see the fStyle parameter description for the ImageList_Draw function.
Return Values
Returns the handle of the icon or cursor if successful, or NULL otherwise.
See Also
ImageList_Draw, ImageList_ExtractIcon
