Sort Order

The position indexes of the address cards are based on the current sort order of the database. An application can specify up to four different properties that can be used to sort the address cards. Of the four specified properties, only one at a time can be used to sort the address cards.

The initial sort order properties are specified when the Contacts database is created. An application can retrieve the sort order properties using the GetColumnProperties function. An application can change the sort order properties using the SetColumnProperties function. An application specifies which of the four properties the system should use to sort the address cards when calling the OpenAddressBook function to open the database. In addition, an application can use the SetSortOrder function to change the current sort order, and the GetSortOrder function to retrieve the current sort order.
