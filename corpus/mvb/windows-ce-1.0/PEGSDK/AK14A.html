Technical Notes

Before running any of the remote tool clients, the Minerva server “Repllog.Exe” must be running on the HPC.

All of the remote utilities use a common application on the HPC server, Ppprtsvr.exe, which is executed on the HPC via HPC Explorer Remote Procedure Calls (RPC) from whichever remote desktop application is run first.

If the Ppprtsvr.exe file is not already on the HPC the first time you run a remote client, the client will download it from your desktop Windows CE SDK installation directory to your HPC (also via HPC Explorer RPC calls). The client then starts Ppprtsvr.exe on the HPC.
