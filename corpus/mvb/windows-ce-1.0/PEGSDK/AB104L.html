PegFindNextFile

The PegFindNextFile function is the RAPI version of the FindNextFile function. For more information about using RAPI functions, please see the Remote API Functions overview. See the FindNextFile documentation for a description of the parameters and return values.

BOOL PegFindNextFile(// rapi.h
HANDLE hFindFile,// handle of search
LPPEG_FIND_DATA lpFindFileData// address of file information
);
Remarks
Unlike FindFirstFile, the second parameter of the PegFindFirstFile function is the address of a PEG_FIND_DATA structure, not a WIN32_FIND_DATA structure.
