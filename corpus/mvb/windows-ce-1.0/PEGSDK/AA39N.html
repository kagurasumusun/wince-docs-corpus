TransportFreeMsg

BOOL TransportFreeMessage(
MailMsg *MsgPtr// Pointer to MailMsg structure
);
The TransportFreeMsg routine destroys the MailMsg allocated by TransportRecv and resets the heap, header, and message body pointers to NULL.
Parameters
hService
Handle to a SERVICE structure.
Return Value
Returns TRUE if successful. Returns FALSE if MsgPtr is invalid or if or MsgPtr®hHeap does not exist.
