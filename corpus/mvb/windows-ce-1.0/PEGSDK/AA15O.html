copyShared

copyShared sourceDir destinationDir file

The copyShared statement copies a shared file from the desktop PC to the HPC. A shared file is typically a DLL that is used by one or more applications.

Parameters

sourceDir

Specifies the name of the source directory to copy from. The specified directory is relative to the install directory. This argument can be a period (.) to indicate that the source files are to be copied from the install directory on the PC.

destinationDir

Specifies the directory on the HPC that receives the files being copied. This parameter can specify an absolute or relative path.

To specify an absolute path this parameter must start with a backslash (\) to indicate the root directory followed by the complete path. This command will fail if the specified directory does not already exist on the HPC.

To specify a relative path this parameter can be a period (.). This indicates the source files are to be copied to the load directory on the HPC. The load directory is specified by the install_directory argument of the Load function’s command line parameter.

file

Specifies the name of the file to copy.

Remarks

If the destination directory already contains the file specified by the file parameter, the file's time-stamp is compared to that if the source file. The source file is copied only if it is newer than the destination file.

Each shared file has a corresponding reference count in the HPC registry. Copying a shared file to the HPC increments the count. Also, the copied file is added to the unload script. When the user runs the script, the reference count is decremented. When the count reaches zero, the file is removed.

Windows CE does not support the concept of a working directory, so DLLs for all applications must be stored in the default directory (\Windows) or explicitly loaded from the application directory using LoadLibrary. To avoid collisions with DLLs for other applications on the HPC, each DLL should have a long descriptive file name.
