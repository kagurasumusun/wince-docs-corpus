PegClearUserNotification

The PegClearUserNotification function deletes a user notification that was created by a previous call to the PegSetUserNotification.

BOOL PegClearUserNotification(// notify.h
HANDLE hNotification// handle of notification to delete
);
Parameters
hNotification
Identifies the user notification to delete.
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
