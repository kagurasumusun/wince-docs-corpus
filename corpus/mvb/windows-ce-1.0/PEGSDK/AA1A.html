About Windows CE for the HPC

Microsoft Windows CE is an open, scalable Windows operating system platform for a broad range of communication, entertainment, and mobile computing devices. Windows CE makes possible new categories of non-PC hardware devices that can communicate with each other, share data with Windows-based PCs, and connect to the Internet.

This Guide to Programming and the companion API Reference detail Windows CE’s implementation for a category of mobile companion devices to Windows-based PC, the Handheld Personal Computer (HPC).

This chapter provides an overview of Windows CE for the HPC. It covers the basics of the following topics:

· The hardware design and features of Windows CE compatible HPCs

· The Windows CE operating system for the HPC

· The Microsoft Windows CE programming model for the HPC
