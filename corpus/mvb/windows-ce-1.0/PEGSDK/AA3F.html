Object Identifiers and Position Indexes

Each address card has an object identifier that an application can use to refer to the card. The object identifier is a unique value that the system assigns to the address card when the card is added to the Contacts database. An application uses an the object identifier when querying an address card's properties or when modifying or deleting an address card.

In addition to an object identifier, each address card also has a position index which indicates the record's position relative to other address cards in the database. If the application knows an address card's position index, the GetAddressCardOid function can be used to retrieve the object identifier of the card. Alternately, if the application knows the card's object identifier, the GetAddressCardIndex function can be used to retrieve the position index. An application can use the GetNumberOfAddressCards function to determine the number of address cards in the database.
