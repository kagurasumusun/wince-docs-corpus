IsCharLower

The IsCharLower function determines whether a character is lowercase. This determination is based on the semantics of the language selected by the user during setup or by using Control Panel.

Windows CE Notes Supports only the Unicode version of this function.

BOOL IsCharLower(// winbase.h
TCHAR ch// Unicode (wide) character to test
);
Parameters
ch
Specifies the Unicode (wide) character to be tested.
Return Values
If the character is lowercase, the return value is TRUE. If the character is not lower case, the return value is FALSE. To get extended error information, use the GetLastError function.
