LVM_GETSTRINGWIDTH

Determines the width of a given string, using the specified list view control's current font. You can send this message explicitly or by using the ListView_GetStringWidth macro.

wParam = 0;

lParam = (LPARAM)(LPCSTR) psz;

// Corresponding macro

int ListView_GetStringWidth(

HWND hwnd,

LPCSTR psz

);

Parameters

hwnd

Handle of the list view control.

psz

Address of a null-terminated string.

Return Values

Returns the string width if successful or zero otherwise.

Remarks

The return value specifies the string width in the control's current font and a constant that the control uses for column margins. An application can use this value to set column widths in report view. When setting the width of the first column (column zero), an application should add to the return value the width of the small icon and state image, if any.
