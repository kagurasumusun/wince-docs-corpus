ReleaseCapture

The ReleaseCapture function releases the stylus capture from a window in the current thread and restores normal stylus input processing. A window that has captured the stylus receives all stylus input, regardless of the position of the stylus.

BOOL ReleaseCapture(void);// winuser.h
Parameters
This function has no parameters
Return Values
If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.
Remarks
An application calls this function after calling the SetCapture function.
Calling this function causes the window that is losing the capture to receive a WM_CAPTURECHANGED message.
