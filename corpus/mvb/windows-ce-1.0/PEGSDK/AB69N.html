SetBkMode

The SetBkMode function sets the background mix mode of the specified device context. The background mix mode is used with text, hatched brushes, and pen styles that are not solid lines.

Windows CE Notes The iBKMode parameter does not support driver-specific values.

int SetBkMode(// wingdi.h
HDC hdc,// handle of device context
int iBkMode// flag specifying background mode
);
Parameters
hdc
Identifies the device context.
iBkMode
Specifies the background mode. This parameter can be either of the following values.
Value		Description
OPAQUEBackground is filled with the current background color before the text, hatched brush, or pen is drawn.
TRANSPARENTBackground remains untouched.
Return Values
If the function succeeds, the return value specifies the previous background mode. If the function fails, the return value is zero.
