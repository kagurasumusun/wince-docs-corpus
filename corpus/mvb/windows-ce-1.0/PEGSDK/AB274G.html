GetMenuItemInfo

Retrieves information about a menu item.

Windows CE Notes The MENUITEMINFO flag MIIM_CHECKMARKS is not supported for GetMenuItemInfo, and is ignored.

BOOL GetMenuItemInfo(// winuser.h
HMENU hmenu,// handle of menu
UINT uItem,// identifier or position of the menu item to change
BOOL fByPosition// menu item identifier or position
LPMENUITEMINFO pmii// pointer to a MENUITEMINFO structure
);
Parameters
hmenu
handle of menu
uItem
Identifier or position of the menu item to change. The meaning of this parameter depends on the value of fByPosition.
fByPosition
If this parameter is FALSE, uItem is a menu item identifier. Otherwise, it is a menu item position.
pmii
Pointer to a MENUITEMINFO structure.
Return Value
If the function succeeds, the return value is TRUE.
If the function fails, the return value is FALSE. To get extended error information, use the GetLastError function.
