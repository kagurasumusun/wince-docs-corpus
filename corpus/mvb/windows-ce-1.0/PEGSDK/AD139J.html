LVM_SETCOLUMNWIDTH

Changes the width of a column in report or list view. You can send this message explicitly or by using the ListView_SetColumnWidth macro.

wParam = (WPARAM)(int) iCol;

lParam = MAKELPARAM((int) cx, 0);

// Corresponding macro

BOOL ListView_SetColumnWidth(

HWND hwnd,

int iCol,

int cx

);

Parameters

hwnd and iCol

Handle of the list view control, and the index of the column. In list view, the iCol parameter must be –1.

cx

New width of the column, in list view coordinates, or one of the following values.

ValueMeaning
LVSCW_AUTOSIZEAutomatically sizes the column.
LVSCW_AUTOSIZE_USEHEADERAutomatically sizes the column to fit the header text.
Return Values
Returns TRUE if successful or FALSE otherwise.
