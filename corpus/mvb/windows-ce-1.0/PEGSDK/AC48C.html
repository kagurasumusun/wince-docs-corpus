PropertyDataStruct

The PropertyDataStruct structure contains information about a property of an address card in the Contacts database.

typedef struct _PropertyDataStruct {-

TCHAR *pszReserved;

TCHAR *pszPropertyName;

ULONG uPropType;

HHPRTAG hhProp;

} PropertyDataStruct;

Members

pszReserved

Reserved; do not use.

pszPropertyName

Points to the name of the property, as it appears in the Contacts application.

uPropType

Specifies the type of the property. It can be one of the following values.

ValueMeaning
TEXT_PROPERTYA string of text
DATE_PROPERTYA date
PHONE_PROPERTYA telephone number
NAME_PROPERTYA name
ADDRESS_PROPERTYAn address
EMAIL_PROPERTYAn e-mail name
hhProp
Specifies the property tag of the property. Refer to Properties and Property Tags in the Contacts Database guide chapter for a list of these tags.
