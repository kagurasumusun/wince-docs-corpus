ImageList_AddMasked

The ImageList_AddMasked function adds an image or images to an image list, generating a mask from the given bitmap.

int WINAPI ImageList_AddMasked(// commctrl.h
HIMAGELIST himl,// handle of the image list
HBITMAP hbmImage,// handle of the bitmap that contains the images
COLORREF crMask// color use to generate the mask
);
Parameters
himl
Handle of the image list.
hbmImage
Handle of the bitmap that contains one or more images. The number of images is inferred from the width of the bitmap.
crMask
Color used to generate the mask. Each pixel of this color in the given bitmap is changed to black, and the corresponding bit in the mask is set to one.
Return Values
Returns the index of the first new image if successful or –1 otherwise.
Remarks
This function copies the bitmap to an internal data structure. Be sure to use the DeleteObject function to delete hbmImage after the function returns.
