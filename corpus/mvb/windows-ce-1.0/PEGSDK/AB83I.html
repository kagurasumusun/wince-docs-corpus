ImageList_LoadImage

The ImageList_LoadImage function creates an image list from the specified bitmap, cursor, or icon resource.

Windows CE Notes hinst must be an HINSTANCE of an application or DLL containing an image.

uType does not support the IMAGE_CURSOR flag.

uFlags must be zero.

HIMAGELIST WINAPI ImageList_LoadImage(// commctrl.h
HINSTANCE hinst,// handle of an instance containing the resource
LPCSTR lpbmp,// address of the string containing the name of image
int cx,// width of each image
int cGrow,// number of images by which the list can grow
COLORREF crMask,// color used to generate mask
UINT uType,// flag specifying the type of image to load
UINT uFlags// must be zero
);
Parameters
hinst
Handle of the instance that contains the resource. This parameter must be an HINSTANCE of an application or DLL containing an image
lpbmp
Pointer to a null-terminated string that contains the name of the image to load.
cx
Width of each image. The height of each image and the initial number of images are inferred by the dimensions of the given resource.
cGrow
Number of images by which the image list can grow when the system needs to resize the list to make room for new images. This parameter represents the number of new images that the resized image list can contain.
crMask
Color used to generate a mask. Each pixel of this color in the given bitmap, cursor, or icon is changed to black, and the corresponding bit in the mask is set to one. If this parameter is the CLR_NONE value, no mask is generated.
uType
Flag that specifies the type of image to load. This parameter can be one of the following values
Value		Meaning
IMAGE_BITMAPLoads a bitmap.
IMAGE_ICONLoads an icon.
uFlags
Must be zero. This parameter specifies how to load the image.
Return Values
Returns the handle of the image list if successful or NULL otherwise.
