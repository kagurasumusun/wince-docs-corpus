regKeyCreate

regKeyCreate key subkey bUninstall

The regKeyCreate statement creates a key in the HPC registry.

Parameters

key

Specifies the root key under which the new key is to be created. This argument can be the tilde character (~) to specify the “home” key (HKEY_LOCAL_MACHINE\SOFTWARE\Apps\your_app_name), or it can be one of the following values:

· HKEY_CLASSES_ROOT

· HKEY_CURRENT_USER

· HKEY_LOCAL_MACHINE

· HKEY_USERS

subkey

Specifies the name of the key to create.

bUninstall

Specifies whether the key should be added to the list of items to be removed by the uninstall script. Set this argument to one to add the key to the list, or zero otherwise.

Remarks

The setup program should create all possible registry keys and values for the application so they can be removed properly if the application is uninstalled.

The bUninstall argument is ignored unless the tilde (~) character is used to specify the home key in the key argument. This is to facilitate the anticipated future release of the Application Manager. The Application Manager will use the registry values under the home key to determine user-defined preferences that should be saved if the program is uninstalled.
