TransportCount

BOOL TransportCount(
HANDLE hService,// Service handle
LPWORD lpNumMsgs// Pointer to receive the number of messages
);
The TransportCount routine determines the number of pending messages in the mailbox and returns this count in the lpNumMsgs parameter.
For the sample transport service, TransportCount searches the mail directory specified in hService->szMailDir and determines the number of message files present. It sets the values of hService->wNumMsgs and hService->wHighNum accordingly. If lpNumMsgs is a valid pointer, it is set to the number of messages found. This value is also saved in hService->wNumMsgs.
Parameters
hService
Handle to a SERVICE structure.
lpNumMsgs
A pointer to receive the number of messages found in the mailbox.
Return Value
Returns TRUE if successful or FALSE otherwise. To get extended error information, call TransportError or TransportErrorMsg.
