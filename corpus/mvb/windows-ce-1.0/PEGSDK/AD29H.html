LB_GETCURSEL

An application sends an LB_GETCURSEL message to retrieve the index of the currently selected item, if any, in a single-selection list box. This message has no parameters.

wParam = 0; // not used, must be zero

lParam = 0; // not used, must be zero

Return Values

The return value is the zero-based index of the currently selected item, or LB_ERR if no item is currently selected.

Remarks

Use the LB_GETCARETINDEX message to retrieve the index of the item that has the focus rectangle in a multiple-selection list box. An application cannot send the LB_GETCURSEL message to a multiple-selection list box.

See Also
