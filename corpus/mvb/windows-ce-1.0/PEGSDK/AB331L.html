PtInRegion

The PtInRegion function determines whether the specified point is inside the specified region.

BOOL PtInRegion(// wingdi.h
HRGN hrgn,// handle of region
int X,// x-coordinate of point
int Y// y-coordinate of point
);
Parameters
hrgn
Identifies the region to be examined.
X
Specifies the x-coordinate of the point.
Y
Specifies the y-coordinate of the point.
Return Values
If the specified point is in the region, the return value is TRUE. If the function fails, the return value is FALSE.
