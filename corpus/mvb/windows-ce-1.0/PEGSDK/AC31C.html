PEGVALUNION

The PEGVALUNION union contains a value for a property.

typedef union _PEGVALUNION {-

short iVal;

USHORT uiVal;

long lVal;

ULONG ulVal;

FILETIME filetime;

LPWSTR lpwstr;

PEGBLOB  blob;

} PEGVALUNION;

Members

iVal

Specifies an integer.

uiVal

Specifies an unsigned integer.

lVal

Specifies a long integer.

ulVal

Specifies an unsigned long integer.

filetime

Specifies a FILETIME structure.

lpwstr

Points to a null-terminated string.

blob

Specifies a PEGBLOB structure.
