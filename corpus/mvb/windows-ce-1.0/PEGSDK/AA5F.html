Properties and Property Tags

Each address card property has an associated identifier called a property tag. A property tag is unique within the context of a single address card. For example, every address card has a home telephone number property that has a property tag of HHPR_HOME_TELEPHONE_NUMBER. An application must specify a property tag when retrieving information associated with a property, or when specifying the sort order.
