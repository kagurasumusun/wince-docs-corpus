CommandBar_IsVisible

The CommandBar_IsVisible function retrieves the visibility state of a command bar.

BOOL CommandBar_IsVisible(// commctrl.h
HWND hwndCB// handle of command bar
);
Parameters
hwndCB
Handle identifying the command bar to destroy. This handle is returned when the command bar is created by the CommandBar_Create function.
Return Values
If the specified command bar’s parent window has the WS_VISIBLE style, the return value is TRUE; otherwise, it is FALSE. Because the return value specifies whether the window has the WS_VISIBLE style, it may be TRUE even if the window is totally obscured by other windows.
