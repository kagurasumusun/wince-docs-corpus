The Transport Service Registry

Shown below is a sample registry with Inbox running and a SAMPLE service connected. In this example, using Inbox, a service named MyMail has been added. When this is added, Inbox adds the MyMail subkey, which includes information and properties for the service. Note that these properties can be modified by the TransportProps routine.

Under the MyMail subkey, the SvcKey value references the key HKLM\PMail\ServiceLibs\SMTP. This key provides the name of the DLL that Inbox loads when the desired service is connected.

Registering a Transport Service

In order to allow a user to add the new SAMPLE service, you must register the service by adding information about the new service to the Handheld PC (HPC) registry. As part of the application installation and setup (see the “Application Installation” chapter), a SAMPLE key must be created, as shown in the above example. Under this subkey, the SvcName value identifies the name of the service. When a user chooses to Add a service within Inbox, this service name is provided in the list of services the user can add. The SvcLib value identifies the name of the transport service DLL that Inbox will load when connecting (via TransportConnect) to the new service.
