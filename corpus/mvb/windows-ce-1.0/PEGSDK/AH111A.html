Registers

The SH3 has 16 general purpose registers. This calling convention assigns them to the following roles.

R0Return Value - Temporary Register (Note 1)
R1-R3Temporary Registers
R4-R7Arguments - Temporary Registers (Note 2)
R8-R13Permanent Registers
R14Frame Pointer - Permanent Register (Note 3)
R15Stack Pointer - Permanent Register
