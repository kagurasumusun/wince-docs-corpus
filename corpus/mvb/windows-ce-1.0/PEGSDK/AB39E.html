EnumCalendarInfoProc

An EnumCalendarInfoProc function is an application-defined callback function. It is called as a result of a call to the EnumCalendarInfo function, and receives a pointer to a string buffer containing a calendar information string.

The ANSI version of this function is not supported.

BOOL CALLBACK EnumCalendarInfoProc(
LPTSTR lpCalendarInfoString// pointer to calendar information string
);
Parameters
lpCalendarInfoString
Pointer to a string buffer containing a null-terminated calendar information string. This string is formatted according to the CALTYPE value passed to EnumCalendarInfo.
The generic data type LPTSTR is explicitly resolved as LPWSTR for Unicode support. Windows CE expects all string parameters in Unicode.
Return Values
To continue enumeration, the callback function should return TRUE. To stop enumeration, the callback function should return FALSE.
Remarks
EnumCalendarInfoProc is a placeholder for an application-defined function name.
An EnumCalendarInfoProc function can carry out any desired task.
An application registers an EnumCalendarInfoProc function by passing its address to the EnumCalendarInfo function.
A value of type CALINFO_ENUMPROC is a pointer to an EnumCalendarInfoProc function.
