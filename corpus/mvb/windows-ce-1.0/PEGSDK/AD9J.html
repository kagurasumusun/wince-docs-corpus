LVM_DELETECOLUMN

Removes a column from a list view control. You can send this message explicitly or by using the ListView_DeleteColumn macro.

wParam = (WPARAM)(int) iCol;

lParam = 0;

// Corresponding macro

BOOL ListView_DeleteColumn(

HWND hwnd,

int iCol

);

Parameters

hwnd and iCol

Handle of the list view control, and the index of the column to delete.

Return Values

Returns TRUE if successful or FALSE otherwise.
