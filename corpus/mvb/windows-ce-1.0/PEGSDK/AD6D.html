DB_PEGOID_DATABASE_DELETED

The DB_PEGOID_DATABASE_DELETED message is sent when a database has been deleted from the object store.

oidDeletedDB = (PEGOID) wParam; // identifier of deleted database

oidParent = (PEGOID) lParam; // identifier of parent object

Parameters

oidDeletedDB

Value of wParam. Identifies the database that was deleted.

oidParent

Value of lParam. Identifies the parent object of the deleted database.
