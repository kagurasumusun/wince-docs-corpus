PEGDBASEINFO

The PEGDBASEINFO structure contains information about a database object. This structure is used by the PegSetDatabaseInfo function.

typedef struct _PEGDBASEINFO {-  // pegdbi

DWORD dwFlags;

WCHAR szDbaseName[PEGDB_MAXDBASENAMELEN];

DWORD dwDbaseType;

WORD wNumRecords;

WORD wNumSortOrder;

DWORD dwSize;

FILETIME    ftLastModified;
SORTORDERSPEC rgSortSpecs[PEGDB_MAXSORTORDER];

} PEGDBASEINFO;

Members

dwFlags

Indicates the valid members of this structure. This parameter can be a combination of the following values.

ValueMeaning
PEGDB_VALIDNAMEThe szDbaseName member is valid and should be used.
PEGDB_VALIDTYPEThe dwDbaseType member is valid and should be used.
PEGDB_VALIDSORTSPECThe rgSortSpecs member is valid and should be used.
szDbaseName
Specifies a null-terminated string that contains the name of the database. The string can have up to 32 characters, including the terminating null character.
dwDbaseType
Specifies a type identifier for the database.
wNumRecords
Specifies the number of records in the database.
wNumSortOrder
Specifies the number of sort orders active in the database. Up to four sort orderscan be active at a time.
dwSize
Size in bytes that the database is using.
ftLastModified
Last time this database was modified.
rgSortSpecs
Specifies the number of actual sort order descriptions. Only the first n array members are valid, where n is the value specified by the wNumSortOrder member.
