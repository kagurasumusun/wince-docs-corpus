Appendix C Assembler Listing Output Example

C.1 Source Program Listing

The assembler listing shows the result of the assembler processing. The assembler listing consists of a source program listing, a cross-reference listing, and a section information listing.

This appendix describes the content and output format of the assembler listing using the assembly of the source program shown below as an example. This uses the sample program shown in appendix B to calculate the following:

1.5 * 2.25 + 3 / 5

Sample:

.HEADING	"""SAMPLE"""
POINT		.ASSIGNA	16

Parm1 .REG R0

Parm2 .REG R1

WORK1 .REG R2

WORK2 .REG R3

WORK3 .REG R4

WORK4 .REG R5

.SECTION SAMPLE,CODE,ALIGN=4

.INCLUDE "appendix.B"

a .REG R8

b .REG R9

c .REG R10

d .REG R11

start

STS PR,@-SP

MOV #H'00018000,a

MOV #H'00024000,b

MOV #H'00030000,c

MOV #H'00050000,d

MOV a,Parm1

MOV b,Parm2

BSR FIX_MUL

NOP

MOV Parm1,a

MOV c,Parm1

MOV d,Parm2

BSR FIX_DIV

NOP

FIX_ADD a

MOV Parm1,a

LDS @SP+,PR

RTS

NOP

.END
