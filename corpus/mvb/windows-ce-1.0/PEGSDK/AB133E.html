ExtractIconEx

The ExtractIconEx function retrieves one or more icon handles from the given executable file or dynamic-link library (DLL).

Windows CE Notes nIconIndex must be zero or –N where N is a specified resource ID.

nIcons must be one (1).

UINT ExtractIconEx(// shellapi.h
LPCTSTR lpszExeFileName,// filename of file with icon
UINT nIconIndex,// index of icon to extract
HICON *phiconLarge,// address of large icon handle to be returned, may be NULL
HICON *phiconSmall,// address of small icon handle to be returned, may be NULL
UINT nIcons// must be one
);
Parameters
lpszExeFileName
Points to a null-terminated string specifying the name of an executable file, DLL, or icon file.
nIconIndex
Specifies the index of the icon to retrieve. If this value is zero, the function returns the handle of the first icon in the specified file. If it is not zero it must be –N where N is a specified resource ID.
phiconLarge
Large icon handle to be returned. May be NULL.
phiconSmall
Small icon handle to be returned. May be NULL.
nIcons
Must be one (1).
Return Values
If the function succeeds, the return value is the handle to an icon. If the file specified was not an executable file, DLL, or icon file, the return is one (1). If no icons were found in the file, the return value is NULL.
