Accessing Help

Users can access Help in three ways:

· The Help command on the Start menu.

· The question-mark (?) button in a program or dialog box.

· Using the shortcut keys ALT+H.

When the user taps the Help command on the Start button, Pocket Help displays Help for the system including the desktop, My Handheld, the Start menu, and the taskbar.

In a program window or dialog box, users can display Help for the program or dialog box by tapping the question-mark button.

From any Help topic, users can access any other Help file on the system by tapping the Other Help button. Pocket Help searches for all contents files in the Windows folder and displays a list that users can choose from.
