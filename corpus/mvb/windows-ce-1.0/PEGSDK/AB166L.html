PegRapiUninit

Uninitializes the Windows CE Remote API. For more information about using RAPI functions, please see the Remote API Functions overview.

STDAPI PegRapiUninit(void);// rapi.h
Remarks
This function should be called when the application has completed its use of the remote API services. It gracefully closes down the connection to the Handheld PC. If called when not in an initialized state, it will return E_FAIL.
