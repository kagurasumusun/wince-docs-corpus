Mail Flags

One member of the MailMsg structure is dwFlags, which contains the mail flags. Some of these flags are set by the mail and transport functions to denote the status of the message. Some flags are set by your application before calling functions to specify a particular folder or type of message.

The mail flags are divided into three categories, folder flags, status flags, and message flags:

· Folder flags determine which folder to locate or store the message in, or which folder the message will be moved or copied into.

· Status flags determine the type of message being searched for when they are set before a call to retrieve a message, and they contain the status of the message after the function call.

· Message flags determine how much of the message is read into memory when the message is retrieved.

Move and Copy Flags
When Inbox connects to the service provider, the MAIL_STATUS_COPY and MAIL_STATUS_MOVE statuses of all messages in the inbox belonging to that service are checked. When these flags are set they indicate the message is ready to be moved or copied to a new folder:
· If the MAIL_STATUS_MOVE flag is set, the bits from the Copy Destination Folder are moved into the Current Folder. Then the bits in the Copy Destination Folder and the copy flag are cleared. This results in the message being assigned to a new folder.
· If the MAIL_STATUS_COPY flag is set, a new message is inserted into the message store with the copy destination bits from the original message replacing the current folder bits. The original message remains in the message store. The Copy Destination Folder and MAIL_STATUS_COPY bits are cleared on both messages.
Mail Flag Masks
Each category has one flag used as a mask: MAIL_FOLDER_ALL in the folder category, MAIL_STATUS_ALL in the status category, and MAIL_FLAGS_ALL for the message flags. The mask sets all of the bits for that category of flags. Combining the mask with another flag in the same category using the bitwise AND operator filters out the value of the flag for inspection. For example, the following code fragment returns true if the message is in the inbox:
MailMsg mm;
if ((mm.dwFlags & MAIL_FOLDER_ALL) == MAIL_FOLDER_INBOX) return TRUE;
