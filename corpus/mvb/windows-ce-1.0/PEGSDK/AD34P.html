TCM_HITTEST

The TCM_HITTEST message determines which tab, if any, is at a specified screen position. You can send this message explicitly or by using the TabCtrl_HitTest macro.

wParam = 0; // not used; must be zero

lParam = (LPARAM)(TC_HITTESTINFO FAR *) pinfo;

//pointer to struct specifying position to test

// Corresponding macro

int TabCtrl_HitTest(

HWND hwnd,

TC_HITTESTINFO FAR* pinfo

);

Parameters

hwnd

Handle to the tab control.

pinfo

Pointer to a TC_HITTESTINFO structure that specifies the screen position to test.

Return Values

Returns the index of the tab or –1 if no tab is at the specified position.
