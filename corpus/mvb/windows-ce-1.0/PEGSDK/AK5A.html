Running Applications Within Emulation

There are several ways to run an application for emulation:

· Choose Build and click Execute xxx.exe. This will spawn Shell32.exe and Filesys.exe and execute your application within the emulation window.

· Run you application from an Emulation Environment command prompt.

· Run Shell32.exe from an Emulation Environment command prompt and click the emulated Start button, select run, and enter the path and name of your executable file.

Note The emulation window defaults to the uppper left corner of your screen and cannot be moved or resized. To avoid conflicts on your desktop, the following command line switches have been provided.

SwitchMeaning
/BOTTOMRIGHTBottom, right corner.
/BOTTOMLEFTBottom, left corner.
/TOPRIGHTTop, right corner.
/TOPLEFTTop, left corner (default).
/NOSHELLRuns the application without the emulation shell.
