Using the Built-In Serial Port

A device is opened using the file system function CreateFile. When opening a device, the fifth character of the file name (that is, of the lpFileName parameter) must be a colon (:). For example, to open the build-in serial port, you would pass a file name of “COM1:”. Note that this differs from Windows 95 and Windows NT, which do not require the colon.

Once a handle to the device is returned, data can be written to and read from the device using WriteFile and ReadFile file system functions. The device is closed by calling CloseHandle for the device handle.

Listed below are the basic steps required to open and use the built-in serial device:

1. Open the built-in serial port by performing CreateFile on device COM1.

2. Get the existing communication port settings by calling GetCommState.

3. Set up the communication port using the device-control block (a DCB structure) and calling SetCommState .

4. Perform ReadFile and WriteFile operations on the device handle returned from CreateFile. Open the built-in serial port by performing CreateFile on device COM1.

These and other serial communication functions are demonstrated in the sample terminal emulation code provided with the SDK. This sample code is located in the directory \Peg\Samples\Tty.
