Importing and Exporting with Filters

The reference to importing and exporting files is relative to the HPC. So, to import a file (using a file filter) means to transfer a file from the desktop PC to the HPC. To export a file (using a file filter) means to transfer a file from the HPC to the desktop PC. Note that implementing a file filter for either importing or exporting files is basically done in the same way. The only implementation difference is in the registry settings.

The registry key HKEY_CLASSES_ROOT\CLSID\CLSID\PegasusFilters determines whether the filter is to be used for importing or for exporting. Under this key, if the Import value named value exists, the conversion type is for importing files to the HPC. Otherwise, the conversion type is for exporting files from the HPC. This is discussed in the topics “File Filter Registry Entries” and “Extension Keys”.
