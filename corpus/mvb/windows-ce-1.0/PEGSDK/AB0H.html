HeapAlloc

The HeapAlloc function allocates a block of memory from a heap. The allocated memory is not movable.

Windows CE Notes The dwFlags value HEAP_GENERATE_EXCEPTIONS is not supported.

LPVOID HeapAlloc(// winbase.h
HANDLE hHeap,// handle of the private heap block
DWORD dwFlags,// heap allocation control flags
DWORD dwBytes// number of bytes to allocate
);
Parameters
hHeap
Specifies the heap within which the memory will be allocated. This is a handle returned by the HeapCreate function.
dwFlags
Specifies several controllable aspects of heap allocation. Specifying any of these flags will override the corresponding flag specified when the heap was created with the HeapCreate function. You can use one or more of the following values.
Value		Meaning
HEAP_NO_SERIALIZESpecifies that mutual exclusion will not be used while this function is accessing the heap. For more information about HEAP_NO_SERIALIZE, see the HeapCreate function.
HEAP_ZERO_MEMORYSpecifies that the allocated memory will be initialized to zero.
dwBytes
Specifies the number of bytes to be allocated.
Return Values
If the function succeeds, the return value is a pointer to the allocated memory block.
If the function fails the return value is NULL.
Remarks
If the HeapAlloc function succeeds, it allocates at least the amount of memory requested. If the actual amount allocated is greater than the amount requested, the process can use the entire amount. To determine the actual size of the allocated block, use the HeapSize function.
To free a block of memory allocated by HeapAlloc, use the HeapFree function.
Memory allocated by HeapAlloc is not movable. Since the memory is not movable, it is possible for the heap to become fragmented.
Note that, if HEAP_ZERO_MEMORY is not specified, the allocated memory will not be initialized to zero.
