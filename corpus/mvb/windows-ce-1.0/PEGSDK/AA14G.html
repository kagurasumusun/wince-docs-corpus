System Event Notifications

A system event notification occurs based on a set of pre-defined system events. Some examples of system events are:

Establishing a network connection

Completion of data synchronization

Applications register for a system event by calling the PegRunAppAtEvent function once for each event. Whenever the event occurs, the system starts the application with a system-defined command line parameter. For a complete list of events and command line parameters, see the PegRunAppAtEvent description in the Windows CE Programmer's Reference.

Once a notification is registered for a system event, the notification will occur each time the event happens. An application can de-register for all system events for an application by calling PegRunAppAtEvent specifying NULL as the second parameter.
