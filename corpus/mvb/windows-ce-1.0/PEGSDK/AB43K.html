MailGetFolderName

The MailGetFolderName function retrieves the name of a mail folder from the message store.

BOOL MailGetFolderName (// msgstore.h
HANDLE hService,// Handle to mail context.
int* piId,// Folder ID.
int* piLen// Length of folder name.
LPWSTR szName// Folder name.
);
Parameters
hService
Handle identifying the mail context. This handle is created by the MailOpen function.
piId
Points to the identification number specifying the mail folder. The identifier, a unique integer from zero to 255, is set by the MailPutFolder function.
piLen
Points to the length, in characters, of the szName buffer parameter. If the string is longer than (piLen - 1), it is truncated. After calling this function, the value pointed to by piLen is the actual number of characters needed for the string being passed back to szName plus a NULL terminator character.
szName
Points to the buffer receiving the name of the mail folder corresponding with the specified identification number.
Return Value
This function returns TRUE if successful; FALSE if it fails. To get extended error information, use MailError or MailErrorMsg.
See Also
Mail Interface, MailPutFolder, MailGetFolderId
