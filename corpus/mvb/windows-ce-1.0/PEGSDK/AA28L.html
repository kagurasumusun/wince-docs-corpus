IPegasusFileFilterSite::CloseSourceFile

The IPegasusFileFilterSite::CloseSourceFile member function is used by a file filter to close a source file.

STDMETHODIMP IPegasusFileFilterSite::CloseSourceFile(

LPUNKNOWN pObj

);

Parameters

pObj

Pointer to the IUnknown object returned from the IPegasusFileFilterSite::OpenSourceFile method.

Return Value

If the function succeeds, the return value is NOERROR. If the function fails, the return value is an HRESULT_FROM_WIN32 error code.
