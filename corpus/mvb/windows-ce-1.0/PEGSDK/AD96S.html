WM_GETICON

The WM_GETICON message is sent to a window to retrieve the handle of the big or small icon associated with a window.

Windows CE Notes Icons are stored per window class, not per window.

fType = (BOOL) wParam; // icon-size flag

Parameters

fType

Value of wParam. Specifies the icon to retrieve. If TRUE, the message retrieves the big icon; if FALSE, it retrieves the small icon.

Return Values

The return value is the handle of the big or small icon, depending on the value of fType. When an application receives this message, it can return the handle of a big or small icon, or pass the message to DefWindowProc.

Remarks

DefWindowProc returns the handle of the big or small icon associated with the window, depending on the value of fType.
