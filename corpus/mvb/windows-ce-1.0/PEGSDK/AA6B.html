Other Hardware Considerations

Although the Windows CE graphical user interface is very similar to that of Windows 95, users interact through a touch-screen rather than a mouse. While this approach provides much the same functionality as a mouse, there are some differences that will have to be accommodated.

Windows CE has a 240 x 480 pixel LCD screen (roughly 2.25 x 4.5 inches). It is monochrome, with a 2-bits per pixel gray-scale capability (white, black, and two shades of gray). You will have to ensure that your screen display is comprehensible given these limitations on resolution and palette.

The HPC keyboard (like all other similar devices) is much smaller than that found on a PC. Normal touch-typing will be difficult if not impossible. In addition, the HPC may be used in circumstances which would make even two-handed "hunt-and-peck" typing difficult (balanced on one knee, for instance). Your user interface may need to be modified so that these limitations do not pose problems for your target users.

PortTool

PortTool was originally developed to facilitate porting Win16 applications to Win32. The Port.ini file has been modified to allow this tool to be used for porting Windows 95 and Windows NT applications to the Windows CE platform. Note that this tool is intended to make the porting process easier and faster, but it is not exhaustive, nor is it guaranteed to produce fully compatible code. Additional modifications to your code may still be necessary.

PortTool is very simple to use and largely self-explanatory. It basically steps you through your file, highlighting each instance of a programming element that might need modification. It also may offer suggestions or pointers for further reference. PortTool supports a set of standard editing tools that allow you change your code immediately, or flag items to be attended to later.

You should first examine the Port.ini file, which contains the Windows CE-specific information used by PortTool. If necessary, change the location of your Windows CE Help file (it will be set to c:\pegsdk\help\peg32p.hlp initially). The porting information is in a simple and straightforward format, and can be easily modified and extended to suit your particular needs.

To run PortTool, enter porttool.exe [filename] in the Run dialog box. If you omit the filename, you will get a blank client area and you can then enter a file by using the Open command from the File menu. To run the porting tool, click Current File Interactively on the Port menu. PortTool will highlight the first element in need of attention, and bring up a modeless dialog box which will allow you to manage the remainder of the session.
