How to Display an HTML Document

Once the first three items listed above have been completed, an application can use the HTML Control interface to display an HTML document. To display an HTML document, an application performs the following steps.

Application sends a WM_SETTEXT message to clear the current contents of the HTML Control.

Application sends a sequence of either DTM_ADDTEXT (ANSI version) or DTM_ADDTEXTW (Unicode version) messages, in order to populate the control.

For each NM_INLINE_IMAGE callback, the application loads the image and sends one of the following messages.

MessageUsage
DTM_SETIMAGEContains the HBITMAP of the image to be displayed.
DTM_IMAGEFAILIndicates that the message could not be loaded and the broken image icon should be displayed.
(No message sent)Image loading icon will be displayed.
For each NM_INLINE_SOUND callback, the application loads and plays the sound the indicated number of times (if desired).
Application sends a DTM_ENDOFSOURCE message indicating that the processing of the document is complete.
Application receives an NM_HOTSPOT callback message if the user taps on a link or submits a form.
The following code fragment shows the creation of an HTML Control window and demonstrates some of the HTML Control functionality.
#define DISPLAYCLASS TEXT("DISPLAYCLASS")
BOOL g_bMakeFit = TRUE; // DTM_ENABLESHRINK Shrink-enable flag
TCHAR const c_szHTMLControlLibrary[] = TEXT("htmlview.dll");
// HTML Control DLL
HINSTANCE g_hInstHTMLCtrl; // Instance of HTML Control Viewer
HINSTANCE hInstance; // Instance of application
HWND m_hwndHtml; // Handle to HTML “DISPLAYCLASS” window
. . . . . . . . .
// Load HTML Viewer Control (Htmlview.dll)
g_hInstHTMLCtrl = LoadLibrary(c_szHTMLControlLibrary);
. . . . . . . . .
// Initialize the HTML Viewer Control, passing the instance
// of the calling application.
InitHTMLControl(hInstance);
. . . . . . . . . . . .
switch (message)
{-
case WM_CREATE:
{-
RECT rc;
if(!(pWebView = new CWebViewer(hWnd))) {-
return -1;
}
SetWindowLong(hWnd, 0, (LONG)pWebView);
SendMessage(hWnd, WM_SETICON, FALSE, (LPARAM)g_hiconViewing);
GetClientRect(hWnd, &rc);
pWebView->m_hwndCmdBar = CreateCommandBar(hWnd);
rc.top += CommandBar_Height(pWebView->m_hwndCmdBar);
m_hwndHtml = CreateWindow(
DISPLAYCLASS,
NULL,
WS_CHILD | WS_VISIBLE | WS_VSCROLL | WS_CLIPSIBLINGS,
rc.left,
rc.top,
rc.right - rc.left,
rc.bottom - rc.top,
hWnd,
(HMENU) IDC_HTMLVIEW,
g_hInst,
NULL);
SetFocus(m_hwndHtml);
. . . . . . . . .
PostMessage(m_hwndHtml, DTM_ENABLESHRINK,
0, g_bMakeFit);
}
break; /* WM_CREATE */
