PSM_UNCHANGED

Informs a property sheet that information in a page has reverted to the previously saved state. The property sheet disables the Apply Now button if no other pages have registered changes with the property sheet.

wParam = (WPARAM)(HWND) hwndPage;

lParam = 0;

// Corresponding macro

void PropSheet_UnChanged(

hPropSheetDlg,

hwndPage

);

Parameters

hPropSheetDlg

Handle of the property sheet.

hwndPage

Handle of the page that has reverted to the previously saved state.

Return Values

No return value.
