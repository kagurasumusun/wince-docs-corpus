Specifying the Remote Path

Part of the build process involves copying the executable file to the target device. After the executable file has been created on your development computer, a dialog box asks you to specify its remote name and path. Figure 1 shows the RAM Card driver (Ramcard.dll) with its name and path specified as “\Windows\ramcard.dll”. Click the OK button to copy the executable file to the target device.

Figure 1. Dialog box For Entering the Remote Path and File Name

If you plan on debugging, specify the remote file name the same as the file name that you are building.

You can also define the remote path and file name in the Project Settings dialog box. To display this dialog box, click Settings on the Build menu, and then click the Debug tab. You can then complete the Remote executable path and file name list box.

If your target-host connection is not working properly, you will get a build error stating “Failed to open destination file.” The executable file will exist on your development computer if there are no other errors. You can copy it to the target device later using the Pegasus Manager application provided with the SDK, or you can simply rebuild the executable file by clicking Rebuild All on the Build menu.
