Chapter 4 Sample Memory PC Card Device Driver

Introduction to Memory PC Card Device Driver

This application note describes developing a memory PC Card driver for the Pegasus operating system, installing it, and testing it with write and read applications. An SRAM card was selected for the sample driver. This type of driver uses the stream interface functions and the Device Manager loads it using a detection function.

Use this application note as a guide through the memory PC Card driver source code. This application note highlights and summarizes the important files and functions used for this driver. Because the descriptions in this application note reference the functions in the source code and complement its comments, you might want to print the source files or display them in a text editor so you can cross reference them.
