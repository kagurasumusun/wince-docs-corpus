Steps to Creating a Pager Driver

To develop a pager driver

1. Create a DLL entry function.

2. Define global variables, structures, and function prototypes specific to the pager device.

3. Define the stream interface functions the operating system needs to access the driver. For more information on the stream interface functions, see Chapter 3, “Stream Interface Reference.”

4. Define a PC Card Services status callback function to process the callback events of interest to the pager device. For information about the PC Card Services functions, see Chapter 4, “PC Card Services Reference.”

5. Build the device driver as a DLL that exports the stream interface functions.
