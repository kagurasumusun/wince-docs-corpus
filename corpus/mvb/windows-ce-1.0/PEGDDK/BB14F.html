Using the Emulator Test Utilities

The utility EPREG.EXE lets you dump, write, or delete keys and values in the emulated registry. The file DDKREG.INI contains keys and values needed for the sample DDK drivers. You can use DDKREG.INI with EPREG.EXE to update the emulated registry.

The SSTEST.EXE (socket service test) utility lets you map card attribute and common memory into a window in the ISA address space (640K–1M). You can use this utility to locate an open address space for the common and attribute windows used by PC Cards. You can also use this utility to read from and write to PC Cards. This utility has commands to read, write, and fill the card memory.
