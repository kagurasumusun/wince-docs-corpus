CardRequestConfiguration

STATUS CardRequestConfiguration(
CARD_CLIENT_HANDLE hCardClient
PCARD_CONFIG_INFO pParms
);
The CardRequestConfiguration function configures socket attributes, interface type, voltage, and registers as specified by the CARD_CONFIG_INFO structure.
Parameters
hCardClient
Specifies the client handle obtained from CardRegisterClient.
pParms
Points to a CARD_CONFIG_INFO structure.
Return Value
If the function succeeds, the return value is CERR_SUCCESS; otherwise, it is one of the following:
Value		Description
CERR_BAD_ARGSIndicates the pointer specified for pParms is invalid.
CERR_BAD_HANDLEIndicates the driver specified for hCardClient is invalid.
CERR_BAD_SOCKETIndicates the socket identifier specified in the hSocket member of the CARD_CONFIG_INFO structure is invalid, or a PC Card not inserted.
CERR_BAD_VCCIndicates the voltage setting specified in the uVcc member of the CARD_CONFIG_INFO structure is invalid.
CERR_BAD_VPPIndicates a voltage setting specified in the uVpp1 or uVpp2 member of the CARD_CONFIG_INFO structure is invalid.
CERR_IN_USEIndicates the configuration is owned by another driver.
CERR_WRITE_FAILUREIndicates the function unable to write configuration registers.
Remarks
If power to the socket was off, CardRequestConfiguration turns it on.
Values specified in the CARD_CONFIG_INFO structure are written to the card’s configuration registers.
