Installing the Test Driver

When you build a driver, the build process normally copies the driver from the development to the target computer. If the build process did not copy the Cardtest.dll file, copy it from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

To have the Device Manager load Cardtest.dll when the test card device is inserted, you must create detect and device keys and add information about the detection function and the test client driver to the operating system registry. The registry entries required for Cardtest.dll are:

· A integer subkey for the detect key containing the following:

· The Dll identifier specifying the file name of the DLL

· An entry identifier specifying the name of the detection function in the driver

· A subkey for the PCMCIA key using the name of the device key returned by the detection function. (This sample driver returns “CardTest.”) This subkey has the following entries:

· The Dll identifier specifying the file name of the DLL

· The Prefix identifier specifying the three-character prefix used for the stream interface functions

To edit the registry, use Pregedit as described in the SDK. Add the following card test device information to the registry:

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Detect\05]

SZ: Dll = Cardtest.dll

SZ: Entry = DetectionFunction

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CardTest]

SZ: Dll = Cardtest.dll

SZ: Prefix = PTD
