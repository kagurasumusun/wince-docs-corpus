CARD_STATUS, PCARD_STATUS

typedef struct {-

CARD_SOCKET_HANDLE hSocket;

UINT16 fCardState;

UINT16 fSocketState;

} CARD_STATUS, *PCARD_STATUS;

The CardGetStatus function uses the CARD_STATUS structure to return data.

Members

hSocket

Specifies a handle to a socket and function pair.

fCardState

Specifies a bitmask indicating current card state. See “Event Masks.” (Output)

fSocketState

Specifies a bitmask indicating card state changes. See “Event Masks.” (Output)
