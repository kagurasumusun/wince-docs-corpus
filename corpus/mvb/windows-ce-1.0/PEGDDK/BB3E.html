Loading the RAM Card Project

The sample drivers and applications in the DDK can be built using the Microsoft Visual C++ 4.0 compatible NMAKE files supplied with the DDK.

To open the Ramcard project:

1. Start the Microsoft Developer Studio application.

2. Click File on the main menu.

3. Click Open Workspace.

4. Select “Makefiles (*.mak)” as the type of project file you want to open in the List Files of Type list box.

5. Use the Drives and Directories list boxes to specify the location of the RAM Card project makefile. Select the Ramcard.mak file and click the OK button.

The native project file type for the Microsoft Developer Studio is a Project Workspace file (*.mdp). After closing the project workspace you opened using an NMAKE file, the Microsoft Developer Studio automatically saves a Project Workspace file into the same directory as the original NMAKE file. The next time you open the project, you can use the Project Workspace file (for this example, Ramcard.mdp) to open the Project Workspace instead of the NMAKE file.
