About the Tty Source Files

The Port.c file defines the main functions Tty operation. The Port.c file contains functions for the following operations:

· Opening a serial device

· Initializing the device’s communication values

· Reading and writing data bytes one at a time

The Port.c file is located in the \PEGDDK\SAMPLES\SERIAL\TTY directory.

InitPort

The InitPort function opens a serial device, modifies the device’s communication settings, specifies that the terminal is ready to send and receive data, and starts a read thread.

PortWrite

The PortWrite function transmits bytes one at a time from a buffer to the serial device.

ReadThread

The ReadThread function receives bytes one at a time from the serial device and stores them in a buffer.
