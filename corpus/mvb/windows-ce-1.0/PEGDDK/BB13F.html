Testing the Installation of PEPCMCIA

1. If necessary, copy PEGFILE.DAT into the \MSDEV\PEG\EMUL directory of your development computer. This file is the emulated file system containing the emulated registry.

2. Remove any PC Cards from the PC Card socket.

3. If necessary, start PEPCMCIA with the command

net start pepcmcia

4. Start a command window and run SHELL32.EXE. This application automatically starts DEVICE.EXE. DEVICE.EXE creates a command window for printing debug messages from the PC Card drivers.

5. To test DEVICE.EXE for operation, insert a memory PC Card into a PC Card socket. If the installation is correct, the emulator prints messages about the PC Card in the DEVICE.EXE window. Depending on values stored in the emulated registry and which detectors are available, the driver for the PC Card may or may not be loaded.

If the driver for the PC Card is loaded, its test application can be started from another command line window. The client driver debug messages appear in the DEVICE.EXE window, since the driver executes in its context.

6. When you select suspend from the emulated Pegasus Start Menu, the emulator, its support programs, and DEVICE.EXE exit.

When building test drivers and applications for the emulator, make sure the drivers are copied into the emulated file system when they are built. If desired, you can copy them manually into the \MSDEV\PEG\EMULf directory at a later time. Before testing your driver, add the registry information about your driver to the emulated registry with EPREG.EXE so the Device Manage can find and load your driver. To determine which driver has been loaded, run EPREG.EXE with the following command:

epreg -d HKEY_LOCAL_MACHINE\Drivers\Active

The sample drivers use the DbgPrintfW function in UTILS.LIB to print debug messages. Before building sample drivers, build UTILS.LIB in the samples\utils directory for this support. By first building the samples in debug mode, you can use the debug messages to check the operation of the driver.
