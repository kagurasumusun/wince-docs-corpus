Overview on Adding PC Card Support to the Emulator

The following list summarizes the steps in adding PC Card support to the emulator:

To add emulator PC Card support

1. Install the PC Card hardware on the development (desktop) computer.

2. Install the emulator from the SDK on the development computer.

3. Copy the DDK emulation software to the development computer.

4. Select the hardware resources (ISA bus windows).

5. Install the device driver (PEPCMCIA.SYS) for PC Card support.

6. Test the PC Card hardware, PEPCMCIA driver, and selected ISA bus windows with SSTEST.EXE.

7. Test the emulator installation with SHELL32.EXE.

For information on installing the PC Card hardware, see the installation procedures included with the hardware. For information on installing the emulator from the SDK, see the Pegasus SDK Reference and Programmer’s Guide.

The Pegasus DDK Setup program copies the emulation files into the required directories and creates the required registry entries. Use the information in this document to test the installation and diagnose problems with the installation if necessary.
