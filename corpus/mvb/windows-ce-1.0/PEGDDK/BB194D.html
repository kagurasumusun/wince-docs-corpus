Window Attributes

Window attribute masks define memory or I/O window configurations. The following window attribute masks are defined:

Attribute MaskBitwise Values
WIN_ATTR_IO_SPACE1 = I/O window, 0 = memory window
WIN_ATTR_ATTRIBUTE1 = attribute, 0 = common
WIN_ATTR_ENABLED1 = window enabled, 0 = window disabled
WIN_ATTR_16BIT1 = 16 bit, 0 = 8 bit
WIN_ATTR_PAGED1 = size is 16K multiple
WIN_ATTR_SHARED1 = shared memory request
WIN_ATTR_FIRST_SHARED1 = first shared request
WIN_ATTR_OFFSETS_SIZEDCard offsets window sized.
WIN_ATTR_ACCESS_SPEED_VALIDCauses window's access speed change.
