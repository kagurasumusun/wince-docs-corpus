Testing and Getting Information About a PC Card

The test application exercises the test client driver by calling system functions, CreateFile, DeviceIoControl, and CloseHandle. To keep the application simple, it outputs debug print messages in a debug terminal on your development computer.

The CreateFile function opens the PTD1: card device and the DeviceIoControl function performs the operation, specified in the Run command line, on the inserted PC Card. The CloseHandle function closes the PTD1: card device.

Prior to running the test applications, connect one end of the serial debug cable to the serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.
