Contents of the DDK Directories

The DDK is installed in the root directory of your Microsoft Visual C++ 4.0 installation. The root directory for this DDK is PEGDDK by default. The PEGDDK directory contains the following sub-directories:

This subdirectoryContains
HELPDocumentation for developing installable drivers
SAMPLESSample installable drivers and applications that use them.
Setup copies the Pegasus DDK library and header files into the SDK lib and include directories, respectively.
