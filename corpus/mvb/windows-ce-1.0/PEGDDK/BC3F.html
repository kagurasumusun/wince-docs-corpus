Developing a Memory PC Card Driver

To develop a memory PC Card driver

1. Create a DLL entry function.

2. Create a PC Card detection function. For information on the detection function, see Chapter 2, “The Device Manager.”

3. Define the stream interface functions the operating system needs to access the driver. For information on the stream interface functions, see Chapter 3, “Stream Interface Reference.”

4. Define a Card Services status callback function to process the status callback events of interest to the memory card device. For information about the Card Services functions, see Chapter 4, “Card Services Reference.”

5. Build the client driver as a DLL that exports the stream interface functions.
