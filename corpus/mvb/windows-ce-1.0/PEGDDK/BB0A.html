Chapter 1 Introduction to the Pegasus DDK

About the Pegasus Device Driver Kit

The Pegasus Device Driver Kit (DDK) provides the information, tools, and samples you need to develop installable device drivers for the handheld computer. The documentation for the DDK includes the following major topics:

· How the Device Manager loads and unloads built-in and installable device drivers

· Using the stream interface entry-point functions in an installable device driver

· Using PC Card Services from an installable device driver

· Using the development environment to build installable device drivers

· Building and using the sample device drivers

· Creating installable device drivers for PC Cards

· Creating installable device drivers for serial and modem devices
