Building and Using the Sample Cardtest Driver

This section describes how to build, load, and use the sample PC Card test driver. The examples in this section are based on the Cardtest sample driver and the Testapp test application provided with the DDK. The source code for these examples is located in the \PEGDDK\SAMPLES\PCMCIA\TEST directory of your DDK installation directory. For more information on this test driver, see Application Note 3, “sample Test PC Card Device Driver.”
