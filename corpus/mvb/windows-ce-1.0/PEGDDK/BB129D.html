SocketFunctionInterrupt

void SocketFunctionInterrupt(// or whatever name you give this function
UINT32 uISRContextData
);
When a PC Card generates an interrupt on the PC Card interrupt line, Card Services calls an interrupt service function handler, such as SocketFunctionInterrupt, that is associated with a specified socket and function pair.
Note The interrupt service function handler, such as SocketFunctionInterrupt, is not a true kernel-mode interrupt service routine, it is a user-mode callback function that Card Services will callback directly.
Parameters
uISRContextData
Contains context data specified by CardRequestIRQ that the driver can interpret as needed. This parameter is usually a pointer to a structure representing the state of the socket and function pair.
Return Value
None.
Remarks
When a PC Card generates an interrupt, Card Services determines which function caused the interrupt and then calls the interrupt service routine (CARD_ISR) associated with the specified socket and function pair. For single function cards, the function number is zero.
A card-specific driver calls CardRequestIRQ to register an interrupt service routine for a specified socket and function pair.
Card Services clears the interrupt condition in the card configuration registers when the interrupt callback function returns.
The interrupt callback function must clear the function interrupt request source on the card and return as quickly as possible. If more time is required for processing the interrupt, the callback function should determine what needs to be done and spawn a thread to do further processing.
