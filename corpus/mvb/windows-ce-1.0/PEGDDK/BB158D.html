CARD_REGISTER_PARMS, PCARD_REGISTER_PARMS

typedef struct {-

UINT16 fAttributes;

UINT16 fEventMask;

UINT32 uClientData;

} CARD_REGISTER_PARMS, *PCARD_REGISTER_PARMS;

The CARD_REGISTER_PARMS structure contains driver characteristics passed to CardRegisterClient. All members are input only.

fAttributes

Specifies the attributes bitmask:

Bit-maskDescription
CLIENT_ATTR_MEM_DRIVERMemory driver
CLIENT_ATTR_MTD_DRIVERMemory technology driver
CLIENT_ATTR_IO_DRIVERI/O driver
CLIENT_ATTR_NOTIFY_SHAREDSharable PC Card
CLIENT_ATTR_NOTIFY_EXCLUSIVEExclusively used PC Card
fEventMask
Specifies a global socket events bitmask. See “Event Masks.”
uClientData
Specifies 32 bits of context data sent to the client’s callback function. This data is usually a pointer to a data structure.
Remarks
The client data (uClientData) is passed as is to the client driver’s callback function. The client can interpret this context data in any manner it chooses.
