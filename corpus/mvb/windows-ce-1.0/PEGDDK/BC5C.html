Building the NewsCard Pager Test Application

To build the Pagecomm.exe test application

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Newscard.mak project and build a Pagecomm.exe file specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\PAGECOMM.EXE.

The resultant Pagecomm.exe file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\PAGER\PAGECOMM specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Pagecomm.exe file is placed in the \PEGDDK\SAMPLES\PCMCIA\PAGER\PAGECOMM\PEGSHDBG directory.
