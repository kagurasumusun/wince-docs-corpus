Build and Load the PCMCIA Test Project

Open the Cardtest project workspace which also includes the Testapp project. The Testapp project is a simple application that uses the Cardtest client driver (Cardtest .dll) to test a block of memory on a memory PC Card, or to dump attribute memory or tuple information from a PC Card. The following table summarizes the modules and the important functions used in the Cardtest project:

ModuleFunctionDescription
CARDTEST.CPTD_*PC Card driver that exports the PTD_* functions.
MEMORY.CmemoryTestTests a region of memory in a PC Card memory card.
ATTRIBUT.CattributeTestDumps the attribute memory space in a PC Card memory card.
TUPLES.CtuplesTestDumps the tuples in a PC Card.
TESTAPP.CtestappTest application that opens the PTD device.
Using the target selection (Default Project Configuration) list box, select the Testapp project and build Testapp.exe for your target computer. Select the Cardtest project and build Cardtest .dll. Verify that Testapp.exe and Cardtest.dll were copied to to your Pegasus computer.
