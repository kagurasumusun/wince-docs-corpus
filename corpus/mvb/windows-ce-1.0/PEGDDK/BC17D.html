Installing an I/O Card Driver

When you build an driver, the build process normally copies the driver from the development computer to the target computer. If the 16550mod.dll file is not on your target computer, copy it from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

To have the Device Manager load 16550mod.dll when the modem device is inserted, you must add information about the modem device to the operating system registry. The following values are the necessary pieces of information to add to the registry:

· The PCMCIA device key that specifies the Plug and Play identifier value

· The Dll client driver file name

· The three-character Prefix string of the stream interface functions of the driver

To edit the registry, use Pregedit as described in the SDK. For example, if you have a MEGAHERTZ PCMCIA modem, add the following modem device information to the registry:

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\MEGAHERTZ-XJ1144-5C3E]

"Dll"="16550MOD.DLL"

"Prefix"="PDM"

In the above information, the Plug and Play ID of the modem, MEGAHERTZ-XJ1144-5C3E, is the registry key.

When you insert the modem card, it becomes available to applications as device PDM1:.

Note If your target computer has a second PC Card slot and you insert a second modem card identical to the first, it becomes available to applications as device PDM2:.
