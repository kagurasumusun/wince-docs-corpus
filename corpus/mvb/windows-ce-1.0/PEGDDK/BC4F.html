Building the Memory Driver

To build the memory driver as a DLL

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Ramcard.mak project and build a Ramcard.dll file specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\RAMCARD.DLL.

The resultant Ramcard.dll file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\RAMCARD directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Ramcard.dll file is placed in the \PEGDDK\SAMPLES\PCMCIA\RAMCARD\PEGSHDBG directory.
