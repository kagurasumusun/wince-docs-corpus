Sample Installable Drivers for PC Cards

A series of application notes in the Developer’s Guide outline the sample device drivers included with the DDK.

Sample PC Card Pager Client

Application Note 1, “Sample Pager PC Card Device Driver” shows how to develop a memory PC Card client driver. The example is based upon development of the Motorola NewsCard pager client.

Sample PC Card I/O Card Client

Application Note 2, “Sample I/O PC Card Device Driver” shows how to develop an I/O card PC Card client driver. The example develops a client device driver based upon a generic 16550-style PC Card modem.

Sample PC Card Test Client

Application Note 3, “Sample Test PC Card Device Driver” explains how a client device driver and a related test application can test a PC Card inserted in the PC Card slot and provide you with information about it.

Sample PC Card Memory Client

Application Note 4, “Sample Memory PC Card Device Driver” shows the development of an example PC Card client driver for a static RAM PC Card.

Installable Serial and Modem Device Driver

Application Note 5, “Serial and Modem Device Driver” explains how serial devices communicate with applications. The section also provides a list of PC Card modem devices contained in the registry that communicate with applications through a pre-loaded serial driver.
