Files for Extending the Emulator

The following list summarizes the required files for running the SDK emulator with PC Card hardware:

FileDescription
PEPCMCIA.SYSThe PC Card device driver for the emulator. (Setup puts this file in C:\WINNT\SYSTEM32\DRIVERS.)
DEVICE.EXECreates a window to display debug messages. The emulated drivers run in the context of device.exe. (Setup puts this file in the \MSDEV\PEG\EMUL\BIN.)
PCMCIA.DLLContains the library functions required by the emulator for PC Card support. (Setup puts this file in the \MSDEV\PEG\EMUL.)
