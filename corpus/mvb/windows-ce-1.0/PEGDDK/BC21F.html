Using the Test Applications

To test a memory driver

1. Build the test applications Writetst.exe and Readtest.exe.

2. If not currently installed on your target computer, copy the test applications from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

3. Connect a serial debug cable between the serial ports on your development computer and your target computer.

4. Start a terminal application on your development computer.

5. Insert a memory card device in the PC Card slot on your target computer.

6. Run the Writetst.exe test application that writes to the memory card.

7. Run the Readtest.exe test application that reads from the memory card.

Starting a Terminal on your Development Computer

Connect one end of the serial debug cable to the serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.

Start a terminal on your Development Computer with the following settings:

· 19200 baud

· 8 data bits

· no parity

· 1 stop bit

· no flow control

· COM1 or COM2 corresponding to the serial port used on the development computer

Starting and Using the Test Application

To start and use the WriteTst application

1. Insert the ram PC Card to load the driver.

2. On the target computer graphical interface, tap the Start button.

3. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

4. In the Open box, type Writetst, and then tap the OK button.

5. Debug print statements should appear in the debug terminal on your development computer. The following debug messages appear in the debug terminal:

RAMCard: RAM_Open().

RAMcard device opened.

RAMCard: RAM_Seek(): retVal=100.

26 bytes written.

RAMCard: RAM_Close().

To start and use the ReadTest applications

1. On the target computer graphical interface, tap the Start button.

2. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

3. In the Open box, type Readtest, and then tap the OK button.

4. Debug print statements should appear in the debug terminal on your development computer and a message box appears on your target computer display. The following debug messages appear in the debug terminal:

RAMCard: RAM_Open().

RAM device opened.RAMCard: RAM_Seek(): retVal=100.

Read Test: 40 bytes read.

Read Test: String returned = Pegasus DDK

RAMCard: RAM_Close().
