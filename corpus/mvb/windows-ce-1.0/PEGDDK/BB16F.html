SSTEST.EXE

The SSTEST.EXE utility lets you quickly find working windows in the 640K–1M range of the ISA address space. In case your windows are different from what you entered into registry during driver’s installation, use REGEDT32.EXE to modify the values under key HKEY_LOCAL_MACHINE\SYSTEM\CurrentControSet\Services\pepcmcia

To run SSTEST.EXE, start the pepcmia.sys driver if necessary, then, at a command line prompt, type:

sstest [0 | 1]

The command sstest 0 tests the PC Card in socket 0; sstest 1 tests the PC Card in socket 1.

When running, SSTEST.EXE displays the prompt sstest> in a command window. All SSTEST.EXE commands are then entered at the sstest> prompt. The following commands are available at the sstest> prompt:

SSTEST.EXE CommandDescription
mapa start len offsetMaps the attribute window. Substitute the starting address for start. Substitute the length of the window for len. Substitute the offset into the PC Card memory with offset.
mapc start len offsetMaps common window. Substitute the starting address for start. Substitute the length of the window for len. Substitute the offset into the PC Card memory with offset.
ra offset lenReads the attribute window. Substitute the offset into the PC Card memory with offset. Substitute the number of bytes to read for len.
rc offset lenRead the common window. Substitute the offset into the PC Card memory with offset. Substitute the number of bytes to read for len.
wc offset stringWrites an ANSI string into the common window. Substitute the offset into the PC Card memory with offset. Substitute the string data for string.
wuc offset stringWrites a Unicode string into the common window. Substitute the offset into the PC Card memory with offset. Substitute the string data for string.
fc offset len valFills the common area with the value specified for val. Substitute the offset into the PC Card memory with offset. Substitute the number of bytes to fill for len. The integer value must be between 0–255.
HelpPrints help text.
ExitExits sstest.

Note An SRAM memory card has only one memory block and does not distinguish between attribute and common memory. So if you read 50 bytes from attribute memory, you actually get its common memory.
The following table shows other commands used with SSTEST.EXE:
Comand Example		Description
mapa 0xb0000 0x8000Maps the attribute window to address 0xb0000 with a length of 0x8000 byes.
mapc 0xc0000 0x20000Maps the common window to address 0xc0000 with a length of 0x20000 byes.
ra 0x150 0x80Reads 128 bytes from the attribute window bytes starting at offset 0x150.
rc 0x10000 0x100Reads 256 bytes from the common window bytes starting at offset 64K.
wuc 100 PegasusDDKWrites an unicode string starting at offset 100
fc offset 100 32Fills common memory with value 32 (base 10)
