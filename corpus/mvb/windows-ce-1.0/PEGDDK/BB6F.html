Files for Modifying the Development Computer's Registry

Before you can run the emulator to test PC Card device drivers, you need to modify the development computer’s registry to have it load and run the emulation driver for PC Cards. You can use the following DDK files to modify the desktop computer’s registry:

FileDescription
REGINI.EXEInstallation application for updating registry with information in PEPCMCIA.INI. (Setup puts this file in the \MSDEV\PEG\EMUL\BIN directory.)
PEPCMCIA.INIRegistry initialization file for PEPCMCIA. (Setup puts this file in the \MSDEV\PEG\EMUL\BIN directory.)
