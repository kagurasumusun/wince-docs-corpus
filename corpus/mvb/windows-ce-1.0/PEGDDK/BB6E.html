Configuring the Registry

To load the RAM PC Card sample driver, you must add entries in the Pegasus registry so the Device Manager will run the detection routine and load the driver. The SDK includes the Pegasus Remote Registry Editor, Pregedit, for viewing, creating, modifying, and deleting registry entries. Pregedit is very similar to the registry editor Regedit for Windows 95 and Windows NT. To start Pregedit, click Tools and then click Remote Registry Editor. For information on how to use the Pegasus Remote Registry Editor, see the Pegasus SDK and the Windows 95 or Windows NT user guides.

The Device Manager requires two registry keys in the Pegasus registry to detect and load the RAM Card sample driver. The first key is under the HKEY_LOCAL_MACHINE \Drivers\PCMCIA\Detect key as shown in the following example:

HKEY_LOCAL_MACHINE

[Drivers]

[PCMCIA]

[Detect]

[20]

SZ: Entry = DetectRAMCard

SZ: Dll = RAMCARD.dll

This example shows the detect key named 20 for the RAM Card driver. The detection function has the name DetectRAMCard, and it has been exported by Ramcard.dll. If the detection function fails (the card was not recognized), the detection function returns NULL and the Device Manager calls the next detection function. If the detection succeeds (the card is recognized), the detection function returns a pointer to a string specifying the name of the key in HKEY_LOCAL_MACHINE \Drivers\PCMCIA (that is, RAMCard). This key contains the information necessary for the Device Manager to load the driver as shown in the following example:

HKEY_LOCAL_MACHINE

[Drivers]

[PCMCIA]

[RAMCard]

SZ: Prefix = RAM

SZ: Dll = RAMCARD.DLL
