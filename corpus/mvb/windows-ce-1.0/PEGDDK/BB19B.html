Unloading PC Card Drivers

When a device is removed from the PC Card socket, the Device Manager calls the driver's de-installation function (for more information on the de-installation function, see Chapter 3, “Sream Interface Reference”), which handles the freeing of the driver's own resources. The Device Manager then calls DeregisterDevice and unloads the client driver DLL. The Device Manager removes the client driver's tracking information from the HKEY_LOCAL_MACHINE\Drivers\Active\nn registry key.
