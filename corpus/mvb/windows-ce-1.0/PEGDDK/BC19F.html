Installing the Memory Driver

When you build an driver, the build process normally copies the driver from the development to the target computer. If the build process did not copy the Ramcard.dll file, copy it from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

To have the Device Manager load the Ramcard.dll when a memory card is inserted, you must add information about the memory device to the operating system registry. The following values are the necessary pieces of information to add to the registry:

· A integer subkey for the detect key containing the following:

· The Dll identifier specifying the file name of the DLL

· An entry identifier specifying the name of the detection function in the memory driver

· A subkey for the PCMCIA key using the name of the device key returned by the detect function. (This sample driver returns “RAMCard.”) This subkey has the following entries:

· The DLL identifier specifying the file name of the DLL

· The Prefix identifier specifying the three-character prefix used for the stream interface functions

To edit the registry, use Pregedit as described in the SDK. Add the following SRAM card device information to the registry:

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Detect\20]

SZ: Dll = Ramcard.dll

SZ: Entry = DetectRAMCard

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\RAMCard]

SZ: Dll = Ramcard.dll

SZ: Prefix = RAM

When you insert the memory card, it becomes available to applications as device RAM1:.

Note If your target computer has a second PC Card slot and you inserted a second memory card, it becomes available to applications as device RAM2:.
