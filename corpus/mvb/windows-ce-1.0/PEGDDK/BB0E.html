Chapter 5 Building Installable Device Drivers

About The DDK Build Environment

The Pegasus Device Driver Kit (DDK) uses the Microsoft Visual C++ 4.0 Integrated Development Environment (IDE) for building the device drivers. Before you can install and use the Pegasus DDK you must have the following components installed:

· Microsoft Windows NT Version 4.0

· Microsoft Visual C++ Version 4.0

· Microsoft Pegasus Software Development Kit SDK

After installing the SDK onto your development platform, you will have the tools required to build applications; the DDK uses these tools for building installable device drivers. For information on how to use the development tools, please refer to the SDK documentation and the Microsoft Visual C++ users guide.
