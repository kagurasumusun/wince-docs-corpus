Setting Hardware Resources

The PEPCMCIA driver requires the following hardware resources:

· two I/O ports for accessing the Intel PCIC controller

· two ranges of physical addresses for PC Card attribute memory window

· two ranges of physical addresses for PC Card common memory window

The addresses for these resources are specified in the registry for the development computer. You can use REGINI with the PEPCMCIA.INI initialization file to update the registry with the keys required to load the PEPCMCIA driver. The following example shows this file with typical values:

\registry\machine\system\currentcontrolset\services\pepcmcia

Type = REG_DWORD 0x00000001

Start = REG_DWORD 0x00000003

Group = Extended base

ErrorControl = REG_DWORD 0x00000001

IndexRegister = REG_DWORD 0x3e0

DataRegister = REG_DWORD 0x3e1

AttrMemWindowStart_Sock0 = REG_DWORD 0xd0000

AttrMemWindowLen_Sock0 = REG_DWORD 0x4000

CommMemWindowStart_Sock0 = REG_DWORD 0xd4000

CommMemWindowLen_Sock0 = REG_DWORD 0x4000

AttrMemWindowStart_Sock1 = REG_DWORD 0xd8000

AttrMemWindowLen_Sock1 = REG_DWORD 0x4000

CommMemWindowStart_Sock1 = REG_DWORD 0xdc000

CommMemWindowLen_Sock1 = REG_DWORD 0x4000

Edit PEPCMCIA.INI if your adapter uses other ports, or if you need to change the start or length of the memory windows. The following table defines the keywords used for the address values in PEPCMCIA.INI:

ValueDescription
IndexRegisterSpecifies the port address of PCIC index register.
DataRegisterSpecifies the port address of PCIC data register.
AttrMemWindowStart_Sock0
AttrMemWindowStart_Sock1		Specifies the ISA bus address for attribute memory for the PC Card in socket 0 or 1.
AttrMemWindowLen_Sock0
AttrMemWindowLen_Sock1		Specifies the window length for attribute memory for the PC Card in socket 0 or 1. This is typically 16K.
CommMemWindowStart_Sock0
CommMemWindowStart_Sock1		Specifies the ISA bus address for common (data) memory for the PC Card in socket 0 or 1.
CommMemWindowLen_Sock0
CommMemWindowLen_Sock1		Specifies the window length for common memory for the PC Card in socket 0 or 1. This is typically 16K or greater.
Note The memory windows need to be in the 0–16M range (the address range of the ISA bus). Since most of this range is typically used by system memory, you will probably place the windows in the 640K–1M range. Portions of that range may already be taken by other devices—for example, video hardware typically uses range 0xa0000–0xc8000. Check the registry (under HKEY_LOCAL_MACHINE / HARDWARE / RESOURCEMAP) to make sure your windows do not overlap physical addresses used by other devices.
