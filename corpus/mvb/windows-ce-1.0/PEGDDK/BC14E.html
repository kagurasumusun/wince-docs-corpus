About the Memory.c Source File

The memory test code in Memory.c tests memory PC Cards. The MemoryTest function is passed the number of memory bytes to test. Starting from zero offset, this function then repeatedly writes to and reads from card-mapped memory until all memory bytes are tested. A message then informs you of the success of the memory test operation, whether the information read equals the information written.

The PTD_IOControl function in the card test client driver calls the MemoryTest function. The memory size to test, 4096, is passed as a parameter to the MemoryTest function.
