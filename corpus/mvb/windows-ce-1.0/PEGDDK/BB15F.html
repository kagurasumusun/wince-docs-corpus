EPREG.EXE

The EPREG.EXE utility operates from the command line. To use it, you must specify a command line switch followed by a key name or filename.

To dump a key and its subkey type epreg -d key where key specifies a key in the registry. For example, to dump the subkeys and entries for the HKEY_LOCAL_MACHINE key, enter the following command:

epreg -d HKEY_LOCAL_KEY

You can also use EPREG.EXE to add entries to the registry. For this command you must create an initialization file containing the entries you want to add. For example, the DDKREG.INI file has the following entries for the example drivers:

; Registry values for Emulated Pegasus DDK client drivers.

; For the Newscard client.

HKEY_LOCAL_MACHINE\Drivers\PCMCIA\

Motorola,_Inc.-NewsCard_Data_Receiver-E6DD

SZ: Dll = NEWSCARD.DLL

SZ: Prefix = PGR

DWORD: Index = 0x1

; For the Ramcard client.

HKEY_LOCAL_MACHINE\Drivers\PCMCIA\RAMCard

SZ: Dll = RAMCARD.DLL

SZ: Prefix = RAM

HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Detect\06

SZ: Dll = RAMCARD.DLL

SZ: Entry = DetectRAMCard

; For the Test client.

;HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CardTest

; SZ: Dll = CardTest.DLL

; SZ: Prefix = PTD

;HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Detect\05

; SZ: Dll = CardTest.DLL

; SZ: Entry = DetectionFunction

The text in the initialization file must have the following format:

· The line specifying a key cannot have leading whitespace.

· A key must be fully qualified (that is, it must start from HKEY_LOCAL_MACHINE).

· Lines specifying values for a key are under the key line.

· Each value line must include leading whitespace.

· The format for a value line is same as that produced by the dump option. Only DWORD and SZ values are currently supported.

· Any line starting with a semicolon is a comment.

To add the entries specified in the initialization file, type epreg -i filename where filename specifies your initialization file. For example, to add the entries in the DDKREG.INI file, enter the following command:

epreg -i ddkreg.ini

The final use for EPREG.EXE is to delete keys and related entries subkeys from the registry. To delete a key and its entries type epreg -r key where key specifies a key in the registry. For example, to delete the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\RAMCard key and its entries, enter the following command:

epreg -r HKEY_LOCAL_MACHINE\Drivers\PCMCIA\RAMCard
