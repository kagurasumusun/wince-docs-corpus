Write to and Read from the RAM Card

You can now run the sample test applications to write to and read from the RAM card, in order to verify that the RAM Card driver functions properly.

Run the Writetst Application

Select the Writetst target (for example, “writetst - Win32 (PegSH) Debug”) and build Writetst.exe.

After Writetst.exe has been copied to your target computer, you can run the Writetst test application by tapping Start, Run, and typing writetst in the Open listbox.

The test program will write the string “Pegasus DDK” into the memory card. If you have a terminal monitor connected to the target computer’s debug serial port, you will see the following messages displayed:

RAMCard: RAM_Open().

Write Test: Opened RAMCard device.

RAMCard: RAM_Seek(): retVal=100.

Write Test: 26 bytes written.

RAMCard: RAM_Close().

Run the Readtest Application

Select the Readtest target (for example, “readtest - Win32 (PegSH) Debug”) and build Readtest.exe.

After Readtest.exe has been copied to your target computer, you can run the Readtest test application.

The test program will read the string “Pegasus DDK” (written by Writetst) from the memory card. If you have a terminal monitor connected to the target computer’s debug serial port, you will see the following messages:

RAMCard: RAM_Open().

Read Test: Opened RAMCard device.

RAMCard: RAM_Seek(): retVal=100

Read Test: 40 bytes read.

Read Test: String read = Pegasus DDK

RAMCard: RAM_Close().
