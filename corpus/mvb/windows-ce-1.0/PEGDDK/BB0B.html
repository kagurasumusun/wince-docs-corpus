Chapter 2 The Device Manager

About the Device Manager

As part of the operating system, the Device Manager loads and tracks installable devices as well as some built-in devices. This chapter describes the interaction among a device driver, the Device Manager, and other components in the system when the Device Manager loads or unloads a driver. This chapter includes the following Device Manager topics:

· The Device Manager architecture

· Using the registry to load and track drivers

· Loading built-in device drivers

· Loading and unloading drivers

· Using the Device Manager functions to register drivers

· Driver functions required by the Device Manager
