xxx_Init

DWORD xxx_Init(

DWORD dwContext

);

The xxx_Init function initializes a PC Card device.

Parameters

dwContext

Specifies a pointer to a string containing the registry path to the active key for the installed device.

Return Value

Returns a handle to the device context created. This handle is passed to the xxx_Open, xxx_IOControl, xxx_PowerDown, xxx_PowerUp, and xxx_Deinit functions.

Remarks

When the user inserts the PC Card into its socket, the Device Manager calls this function to initialize the device.

The Device Manager specifies a pointer to a string containing the registry path to the active key of the specific PC Card device in the dwContext parameter. For example, the string contains “HKEY_LOCAL_MACHINE\Drivers\Active\nn” where nn is the device number assigned to the device. Your initialization function might use this information to access data stored in the registry.

Some tasks this function might perform include:

· Initialize the installed device to a default state.

· Allocate resources used globally by the device driver.

· Register a status callback function with Card services. When the status of the PC Card device changes, the operating system calls this status callback function. For example, the status of a PC Card changes when you insert it or remove it.

· Map system memory and I/O space to the PC Card device’s memory and I/O space.

· Request notification on specific callback events.

· For an interrupt-driven I/O PC Card device, register an interrupt callback function with Card Services. When the PC Card device generates an I/O interrupt, the operating system calls this interrupt callback function.

After this function returns, the Device Manager optionally calls xxx_IOControl. Your driver can use this function to finish initializing itself after it has been installed. For example, a driver might load additional modules that require the underlying driver to be installed before they can load.
