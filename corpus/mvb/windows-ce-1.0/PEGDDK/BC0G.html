Chapter 5 Serial and Modem Device Driver

Introduction to the Serial and Modem Driver

This application note describes the serial and modem driver included in the Pegasus operating system and demonstrates an application communicating with a serial device.

Use this application note as a guide through the serial and modem driver source code. This application note highlights and summarizes the important files and functions used for this driver. Because the descriptions in this application note reference the functions in the source code and complement its comments, you might want to print the source files or display them in a text editor so you can cross reference them.
