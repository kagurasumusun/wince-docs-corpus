Building the Tty.exe Application

To build the Tty test application

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Tty.mak project and build a Tty.exe file specific to your Pegasus computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\TTY.EXE.

The resultant Tty.exe file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\SERIAL\TTY directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Tty.exe file is placed in the \PEGDDK\SAMPLES\SERIAL\TTY\PEGSHDBG directory.
