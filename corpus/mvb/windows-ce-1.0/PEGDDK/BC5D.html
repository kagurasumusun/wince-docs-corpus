Building the Test Application

To build the test application

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the 16550mod.mak project and build the test application specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\16550TST.EXE.

The resultant 16550tst.exe file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\16550MOD\16550TST directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 computer, the test application is placed in the \PEGDDK\SAMPLES\PCMCIA\16550MOD\16550TST\PEGSHDBG directory.
