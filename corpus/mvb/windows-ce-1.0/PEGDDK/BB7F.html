Files for Modifying the Emulator's Registry

You might need to modify the emulator’s registry to have it load and run the PC Card driver you are developing. You can use the following files to modify the emulator’s registry:

FileDescription
EPREG.EXECommand line utility for examining and updating the emulated Pegasus registry. (Setup puts this file in the \MSDEV\PEG\EMUL\BIN directory.)
DDKREG.INIRegistry values for the sample PC Card drivers. (Setup puts this file in the \MSDEV\PEG\EMUL\BIN directory.)
