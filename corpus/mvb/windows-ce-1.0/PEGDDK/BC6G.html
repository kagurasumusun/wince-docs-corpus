About the Source Files for the Serial and Modem Driver

The following source files are used to build the Tty application. These source files are located in the \PEGDDK\SAMPLES\SERIAL\TTY directory.

FileDescription
Port.cSource code for the DLL entry function
Tty.*Source code for Tty; definitions for Tty; project files
Resource.H
Screen.cSource code for display operations
Settings.CSource code for selecting operational settings
