xxx_Read

DWORD xxx_Read(

DWORD hOpenContext,

LPVOID pBuffer,

DWORD Count

);

The xxx_Read function reads data from the PC Card device identified by the open context.

Parameters

hOpenContext

Specifies a handle that identifies the open context of the PC Card device. The xxx_Open function creates and returns this identifier.

pBuffer

Points to the buffer which stores the data read from the PC Card device. This buffer should be at least Count bytes.

Count

Specifies the number of bytes to read from the PC Card device into pBuffer.

Return Value

Returns 0 for the end-of-file, –1 for an error, or the number of bytes read for success.

Remarks

An application calls ReadFile(hFile, pData, Size, pSizeRead, NULL) to read from the PC Card device. The operating system, in turn, invokes xxx_Read. The hFile argument is a handle for your PC Card device. The pData argument points to the buffer that contains the data read from the PC Card device. The Size argument indicates the number of bytes you want to read from the PC Card device. The pSizeRead argument is the address of a value that holds the number of bytes actually read from the PC Card device into the buffer. The value returned from xxx_Read is equal to the value contained in pSizeRead.
