Using the Test Application for an I/O Card Driver

To test and get information about a PC Card

1. Build the test application, Testapp.exe.

2. Install the test application on your Target computer. To install, copy the test application from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

3. Connect a serial debug cable between the serial ports on your development computer and your target computer.

4. Start a terminal application on your development computer.

5. Insert a PC Card device in the PC Card slot on your target computer.

6. Run the test application that tests a memory PC Card or gets information about other types of PC Cards.

Starting a Terminal on your Development Computer

Connect one end of the serial debug cable to the debug serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.

Start a terminal on your development computer with the following settings:

· 19200 baud

· 8 data bits

· no parity

· 1 stop bit

· no flow control

· COM1 or COM2 corresponding to the serial port used on the development computer

Starting and Using the Test Application

To start and use the test application

1. On the graphical interface of the target computer, tap the Start button.

2. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

3. In the Open box, type Testapp {-memory | attribute | tuples}, and then tap the OK button. If you want to test a memory PC Card, use the memory argument. If you want to get the attribute or tuple information of other types of PC Cards, use the attribute or tuples arguments respectively.

4. Debug print statements should appear in the debug terminal on your development computer. The following debug messages appear in the debug terminal when you insert a PC Card:

CARDTESTDLL: DllEntry(): dll attach.

CARDTESTDLL: DetectionFunction().

CARDTESTDLL: DllEntry(): dll dettach.

CARDTESTDLL: DllEntry(): dll attach.

CARDTESTDLL: PTD_Init().
