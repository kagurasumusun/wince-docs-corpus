About the Source Files for the Test PC Card Driver

The following source files are used to build the test client device driver. These source files are located in the \PEGDDK\SAMPLES\PCMCIA\TEST directory.

FileDescription
Cardtest.*Source files defining the DLL entry function, a card detect function, the stream interface functions, and the status callback function; definitions of the memory, attribute, and tuple control I/O codes; project files
Private.hFunction prototypes for the memory test, attribute test, and tuples test functions
Attribut.cAttribute test code that dumps the attribute memory space in a PC Card
Memory.cMemory test code that tests a region of memory in a memory PC Card
Nttuple.hTuple definitions, macros, and structures
Tuples.cTuples test code that dumps the tuples in a PC Card
