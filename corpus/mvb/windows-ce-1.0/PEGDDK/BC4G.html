Using Unsupported PC Card Modem Devices

To use other PC Card modem or fax devices, you must add information about them to the registry. To edit the registry, use Pregedit supplied with the SDK. The following sample registry values are for a Hayes PC Card:

;********  Registry values for the Hayes PC Card *******************

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\

Hayes-OPTIMA_288_+_FAX_for_PCMCIA_with_EZ-4FA5]

SZ: Tsp = Unimodem.dll

DWORD: DeviceArrayIndex = 1

SZ: Prefix = COM

SZ: Dll = Serial.dll

SZ: FriendlyName = Hayes 28.8 + Fax

DWORD: DeviceType = 3

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\

Hayes-OPTIMA_288_+_FAX_for_PCMCIA_with_EZ-4FA5\Init]

SZ: 3 = AT&FW1<cr>

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\

Hayes-OPTIMA_288_+_FAX_for_PCMCIA_with_EZ-4FA5\Settings]

SZ: FlowHard = AT&K3<cr>

SZ: FlowSoft = AT&K4<cr>

SZ: FlowOff = AT&K0<cr>

The operating system locates unimodem values under the Default Unimodem values if it does not find them under a specific device key. If you do not register an overriding unimodem value for your PC Card device, the operating system uses the following default unimodem values:

;*********************  Default Unimodem values. ***********************

[HKEY_LOCAL_MACHINE\Drivers\Unimodem]

HEX: DevConfig = 10,00, 00,00, 78,00,00,00, 10,01,00,00, 00,4B,00,00,

00,00, 08, 00, 00, 00,00,00,00

[HKEY_LOCAL_MACHINE\Drivers\Unimodem\Init]

SZ: 1 = AT<cr>

SZ: 1 = ATE0V1&C1&D2<cr>

[HKEY_LOCAL_MACHINE\Drivers\Unimodem\Settings]

SZ: Prefix = AT

SZ: Terminator = <cr>

SZ: DialPrefix = D

SZ: DialSuffix = ;

SZ: Pulse = P

SZ: Tone = T

SZ: Blind_Off = X4

SZ: Blind_On = X3

SZ: CallSetupFailTimeout = S7=<#>

SZ: Reset = ATZ<cr>
