Insert the PC Card

You are now ready to test the new RAM Card driver. Insert a memory card into the PC Card slot of the target computer. If the Device Manager has succeeded in detecting the driver, the following debug messages appear on a terminal monitor connected to your target computer’s debug serial port:

RAMCard: CardRegisterClient() succeeded.
RAMCard: CardRequestWindow() succeeded.
