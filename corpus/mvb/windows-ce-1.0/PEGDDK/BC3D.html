Steps to Creating an I/O PC Card Driver

To develop an I/O PC Card driver

1. Create a DLL entry function.

2. Define the stream interface functions the operating system needs to access the driver. For information about the stream interface functions, see Chapter 3, “Stream Interface Reference.”

3. Define a Card Services status callback function to process the status callback events of interest to the I/O card device. For information about the Card Services functions, see Chapter 4, “Card Services Reference.”

4. Define a Card Services interrupt callback function to process the interrupts generated by the I/O card device.

5. Build the driver as a DLL that exports the stream interface functions.
