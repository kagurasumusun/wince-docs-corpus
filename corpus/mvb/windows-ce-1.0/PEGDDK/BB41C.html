xxx_Write

DWORD xxx_Write(

DWORD hOpenContext

LPCVOID pSourceBytes

DWORD NumberOfBytes

);

The xxx_Write function writes data to the PC Card device.

Parameters

hOpenContext

Specifies a handle that identifies the open context of the PC Card device. The xxx_Open call returns this identifier.

pSourceBytes

Specifies the address of the buffer from which the PC Card device gets data.

NumberOfBytes

Specifies the number of bytes to write from the pSourceBytes buffer into the PC Card device.

Return Value

Returns –1 for an error, or the number of bytes written for success.

Remarks

An application uses WriteFile(hFile, pData, Size, pSizeWritten, NULL) to write to the PC Card device. The operating system, in turn, invokes xxx_Write. The hFile argument is a handle for your PC Card device. The pData argument points to the buffer that contains the data to transmit to the PC Card device. The Size argument indicates the number of bytes you want to transmit. The pSizeWritten argument is the address of a value that holds the number of bytes actually transmitted from the buffer into the PC Card device. The value returned from xxx_Write is equal to the value contained in pSizeWritten.
