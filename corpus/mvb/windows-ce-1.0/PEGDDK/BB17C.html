xxx_IOControl

BOOL xxx_IOControl(

DWORD hOpenContext

DWORD dwCode

PBYTE pBufIn

DWORD dwLenIn

PBYTE pBufOut

DWORD dwLenOut

PDWORD pdwActualOut

);

The xxx_IOControl function sends a command to the PC Card device.

Parameters

hOpenContext

Specifies a handle identifying the open context of the PC Card device. The xxx_Open or xxx_Init function creates and returns this identifier.

dwCode

Specifies a value indicating the I/O control operation to perform.

pBufIn

Points to the buffer containing the data transferred to the PC Card device.

dwLenIn

Specifies the number of bytes of data in the buffer specified for pBufIn.

pBufOut

Points to the buffer used to transfer the output data from the PC Card device.

dwLenOut

Specifies the maximum number of bytes in the buffer specified by pBufOut

pdwActualOut

Points to DWORD buffer the function uses to return the actual number of bytes received from the PC Card device.

Return Value

Returns TRUE if the device successfully completed its specified I/O control operation, otherwise it returns FALSE.

Remarks

If the Ctrl registry value is defined for your device driver, the Device Manager calls this function right after it calls xxx_Init. The Device Manager also specifies NULL for the pBufIn and pBufOut arguments. Your device might use this option to load other modules that require the basic device driver to be installed.

An application uses DeviceIOControl(hFile, dwCode, pDataIn, dwSizeIn, pDataOut, SizeOut, pByteCnt, NULL) to specify an operation to be performed. The operating system, in turn, invokes xxx_IOControl. The hFile argument is the handle created for your PC Card device driver’s xxx_OPEN function. The dwCode argument contains the input or output operation requested. The pDataIn argument points to the buffer containing the data the application supplies. The pDataOut argument points to the buffer that stores the data the application receives. The pByteCnt argument is the address of a value that specifies the number of bytes stored in the pDataOut buffer.
