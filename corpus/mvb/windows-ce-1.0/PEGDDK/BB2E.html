Building and Installing a Sample Device Driver

This section describes the process of building an installable device driver using the tools provided with the SDK. The examples in this section are based on the RAM Card sample driver located in the \PEGDDK\SAMPLES\PCMCIA\RAMCARD directory of your DDK installation directory.

To build and install a sample device driver:

1. Load the project

2. Select the targe and build it

3. Specify the remote path

4. Configure the registry
