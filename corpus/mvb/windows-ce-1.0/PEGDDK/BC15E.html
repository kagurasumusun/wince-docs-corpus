About the Attribut.c Source File

The attribute test code in Attribut.c displays 256 bytes of a PC Card’s attribute memory region. The PTD_IOControl function in the card test client driver calls the AttributeTest function. The size of the attribute memory region is passed as a parameter to the AttributeTest function.

Note The size of the card-mapped window is twice the size of the displayed attribute memory. The doubled card-mapped window size is necessary because only the even bytes of attribute memory space contain valid data. Therefore, the allocated buffer size must be twice the number of read attribute memory bytes.
