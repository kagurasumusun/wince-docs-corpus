Building the Test Applications

To build the memory driver test applications

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Ramcard.mak project and build the test applications specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\WRITETST.EXE or \WINDOWS\READTEST.EXE for the write test or read test application.

The resultant test applications are placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\RAMCARD\WRITETST or \PEGDDK\SAMPLES\PCMCIA\RAMCARD\READTEST directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Writetst.exe test application is placed in the \PEGDDK\SAMPLES\PCMCIA\RAMCARD\WRITETST\PEGSHDBG directory and the Readtest.exe test application is placed in the \PEGDDK\SAMPLES\PCMCIA\RAMCARD\READTEST\PEGSHDBG directory.
