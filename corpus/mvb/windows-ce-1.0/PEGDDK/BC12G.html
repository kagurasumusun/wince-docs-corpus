Testing the Serial Driver

The application Tty creates a terminal on your Pegasus computer that can communicate with a terminal application on your development computer.

To demonstrate an application communicating with a serial device

1. Build the Tty.exe application. The project file, Tty.mak, can be found in the PEGDDK\SAMPLES\SERIAL\TTY directory.

2. Install the Tty.exe application on your target computer. To install, copy Tty.exe into the \WINDOWS directory of your target computer using the Pegasus Manager. The Pegasus Manager is described in the SDK.

3. Connect a null modem serial cable between the serial ports on your development computer and your target computer.

4. Start a terminal application on your development computer.

5. Run the Tty.exe terminal application on your target computer.

6. Type data on both your development computer keyboard and your target computer keyboard.

7. Verify the data typed on the target keyboard displays on the development computer terminal and the data typed on the development computer keyboard displays on the target computer terminal.

Starting a Terminal on your Development Computer

Connect one end of the serial debug cable to the serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.

Start a terminal on your Development Computer with the following settings:

· 19200 baud

· 8 data bits

· no parity

· 1 stop bit

· no flow control

· COM1 or COM2 corresponding to the serial port used on the development computer

Set the terminal to append line feeds with line ends on your incoming and outgoing transmissions. For example, change carriage returns without line feeds to carriage returns with line feeds.

Starting and Using the Tty.exe Application

To start and use the Tty.exe application

1. On the Pegasus graphical interface, tap the Start button.

2. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

3. In the Open box, type Tty COM1:, and then tap the OK button. This opens a Pegasus terminal window. Figure 1 depicts the Pegasus terminal. The check boxes on the Pegasus terminal indicate modem control and modem status settings. You can modify the modem control settings (DTR and RTS); the modem status settings (DSR, CTS, DCD, and RING) cannot be changed.

4. While in the Pegasus terminal window, type information on your Pegasus keyboard and verify that the information appears on your development computer terminal.

5. While in the development computer terminal, type information on your development computer keyboard and verify that the information appears on your Pegasus terminal as shown in Figure 2.
