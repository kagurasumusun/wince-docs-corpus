About the Serial and Modem Driver

When the operating system starts, it loads a serial driver (Serial.dll), a telephony service provider driver (Unimodem.dll), and a telephony application programming interface driver (Tapi.dll).

The operating system Device Manager identifies serial I/O devices connected to the serial port as COM1: and serial I/O devices inserted in the PC Card slot (for example, a PC Card modem and fax PC Card) as COM2:. (COM3 is used for the built-in infrared port.) Applications communicate directly with these serial devices, or indirectly through the telephony drivers with the standard Win32 functions. To communicate directly with a serial device, an application must open the serial device with the CreateFile function. To receive information from the device, an application uses ReadFile and specifies the handle to the device. To send information, an application uses WriteFile and specifies the handle to the device.

Telephony services (Tapi.dll and Unimodem.dll) support telephony applications. The telephony services provider driver (Unimodem.dll) communicates with modem and fax devices through the serial driver (Serial.dll).
