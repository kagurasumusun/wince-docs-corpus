Chapter 1 Sample Pager PC Card Device Driver

Introduction to the Sample Pager PC Card Device Driver

This application note describes developing a pager PC Card installable device driver for the Pegasus operating system, installing it, and testing it with an application. The development process is explained by using the development of the Motorola NewsCard pager as an example. The Motorola NewsCard pager is a memory PC card device; that is, it does not receive I/O interrupts.

Use this application note as a guide through the pager driver source code. This application note highlights and summarizes the important files and functions used for this driver. Because the descriptions in this application note reference the functions in the source code and complement its comments, you might want to print the source files or display them in a text editor so you can cross reference them.
