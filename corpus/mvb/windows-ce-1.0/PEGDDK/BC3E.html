Steps to Building the Test Driver

To build the test driver as a DLL

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Cardtest.mak project and build a Cardtest.dll file specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\CARDTEST.DLL.

The resultant Cardtest.dll file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\CARDTEST directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Cardtest.dll file is placed in the \PEGDDK\SAMPLES\PCMCIA\CARDTEST\PEGSHDBG directory.
