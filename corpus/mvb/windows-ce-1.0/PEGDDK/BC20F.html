Testing a Memory Driver

To keep the application simple, Writetst outputs debug print messages in a debug terminal on your development computer. In operation, Writetst performs the following activities:

· Opens the RAM1: memory card with CreateFile.

· Sets the offset of the memory card to 100 bytes with SetFilePointer.

· Writes “Pegasus DDK” to the memory card with WriteFile.

· Closes the RAM1: memory card with CloseHandle.

The Readtest test application reads a small block of memory from the memory card. In operation, Readtest performs the following activities:

· Opens the RAM1: memory card with CreateFile.

· Sets the offset of the memory card to 100 bytes with SetFilePointer.

· Reads 40 bytes from the memory card with ReadFile.

· Closes the RAM1: memory card with CloseHandle.
