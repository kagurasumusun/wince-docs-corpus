Loading PC Card Drivers With a Plug and Play ID

When a Plug and Play PC Card is inserted into or removed from the PC Card socket, Card Services calls the Device Manager's status callback function with manufacturers Plug and Play ID read from the PC card's card information structure (CIS). The Device Manager then performs the following tasks:

· Finds the appropriate driver for the inserted device. The Device Manager reads the HKEY_LOCAL_MACHINE \Drivers\PCMCIA registry key for a key corresponding to the Plug and Play identifier passed to the callback function.

· Loads the driver DLL identified for the Dll entry.

· If the Device manager finds the Dll and Prefix entries, it tracks the driver. To track the driver, the Device Manager adds information to the HKEY_LOCAL_MACHINE\Drivers\Active\nn key for the driver being loaded.

· Checks for uniqueness of the driver by using the Index registry entry. This value is used to reference a unique device associated with the driver. The Index value can be a number from 0 through 9. Using the NewsCard pager driver as an example, the Device Manager will load a PGR1 (where 1 is the Index).

· Calls the stream interface initialization function for the driver. (For information on this function see Chapter 3, “Stream Interface Reference.”)

· If the Ioctl registry value is present, the Device Manager passes the Ioctl value to the stream interface I/O control function for the driver. This lets a driver perform any necessary post-initialization processing for the device. (For information on this function see Chapter 3, “Stream Interface Reference.”)
