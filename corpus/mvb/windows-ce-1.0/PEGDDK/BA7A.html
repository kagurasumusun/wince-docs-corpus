Required Libraries

The SDK provides the core libraries that link with your installable driver. Other libraries you might need to link are dependent on your application. To build a PC Card client driver, you need to link with PCMCIA.LIB. This library is in the DDK directory PEGDDK\LIB\PEGMIPS (for MIPS based computers), the directory PEGDDK\LIB\PEGSH (for SH3 based computers), or the directory PEGDDK\LIB\X86EM (for NT emulation).

LibraryDescription
PCMCIA.LIBThis DDK library provides the Card Services interface required for your PC Card installable driver. For information on using Card Services, see Chapter 4, “Card Services.”
UTILS.LIBContains utility functions need for MIPS and SH3 computers. The library is in the \PEGDDK\LIB\PEGSH directory. Source code for the library is in the \PEGDDK\SAMPLES\UTILS directory.
