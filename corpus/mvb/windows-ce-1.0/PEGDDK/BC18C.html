Testing a Pager Driver

The Pagecomm.exe application creates a Inbox window with five command buttons, and starts a thread that reads pager messages. In this thread, the application calls system functions, and the system in turn calls the corresponding client driver functions.

To test a pager installable driver

1. Build the Pagecomm.cpp source file as an executable program, Pagecomm.exe. The Pagecomm.cpp source file is located in the \PEGDDK\SAMPLES\PCMCIA\PAGER directory.

2. Install the Pagecomm.exe test application on your target computer. To install, copy Pagecomm.exe into the \WINDOWS directory of your target computer using the Pegasus Manager.

3. Insert the Motorola NewsCard pager device in the PC Card slot on your target computer.

4. Run the Pagecomm.exe Windows-based application that receives pager device messages.

5. Send a message to the pager device using your paging provider services.

6. Verify on the target platform display that the application received the message.

Starting and Using the Pagecomm.exe Application

To start and use the Pagecomm.exe application

1. On the graphical interface of the target computer, tap the Start button.

2. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

The table below describes the function of each command button.

ButtonFunction
DeleteDeletes the pager message that has the focus.
PrevGives the focus to the previous pager message in the list.
NextGives the focus to the next pager message in the list.
ViewCreates a pop-up window displaying the pager message that has the focus.
ExitQuits the Pagecomm.exe application
