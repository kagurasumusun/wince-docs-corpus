CARD_WINDOW_PARMS, PCARD_WINDOW_PARMS

typedef struct {-

CARD_SOCKET_HANDLE hSocket;

UINT16 fAttributes;

UINT32 uWindowSize;

UINT8 fAccessSpeed;

} CARD_WINDOW_PARMS, *PCARD_WINDOW_PARMS;

The CARD_WINDOW_PARMS structure contains desired memory or I/O window characteristics passed to CardRequestWindow.

Members

hSocket

Specifies a handle to a socket and function pair.

fAttributes

Specifies a bitmap for attributes for the memory or I/O window. See “Window Attributes.” (Input)

uWindowSize

Specifies the desired window size in bytes. (Input/Output)

fAccessSpeed

Specifies a bit-encoded access speed characteristics for memory windows, or number of I/O address lines for I/O windows. See “Window Speeds.” (Input)
