Installing a Pager Driver

When you build an driver, the build process normally copies the driver from the development computer to the target computer. If the build process did not copy the Newscard.dll file, copy it from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

To have the Device Manager load the Newscard.dll when the pager device is inserted, you must add information about the pager device to the operating system registry. The following values are the necessary pieces of information to add to the registry:

· The PCMCIA device key that specifies the Plug and Play identifier value

· The DLL file name for the Dll value

· The three-character Prefix string that is unique to the pager client driver

· An Index value that specifies the pager device number

To edit the registry, use the Pregedit as described in the SDK. Add the following pager device information to the registry:

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Motorola,_Inc.-

NewsCard_Data_Receiver-E6DD]

SZ: Dll = NEWSCARD.DLL

SZ: Prefix = PGR

DWORD: Index = 1

In the Motorola NewsCard pager device key, the PCMCIA part identifies that the device is on the PC Card bus. The Motorola,_Inc.-NewsCard_Data_Receiver part is an identifier supplied by the pager device. E6DD is a 16-bit number created from the tuples on the pager device.

Applications open the pager device by specifying its name. The name of the pager device is a combination of its prefix and index values. The registry establishes the Motorola NewsCard pager name as PGR1:.
