About the Stream Interface

With very few exceptions, installable device drivers are Dynamic Link Libraries (DLLs). These DLL’s export a set of functions that are identified by the operating system with a unique prefix. These functions comprise the stream interface. The exported functions for the stream interface include:

· xxx_Init

· xxx_Deinit

· xxx_Open

· xxx_Close

· xxx_Read

· xxx_Write

· xxx_Seek

· xxx_IOControl

· xxx_PowerDown

· xxx_PowerUp

Note The prefix xxx indicates a 3 character prefix defined for each driver. This prefix (as well the filename of the DLL) is added to the registry when an installable device is installed. For example, a serial PC Cards uses the prefix COM and its initialization function name has the name COM_INIT. For more information on the registry entries, see Chapter 2, “The Device Manager.”

This interface is referred to as the “stream type device driver interface,” or simply the “stream interface.” When creating a driver DLL, check for the following:

· The application for installing your device driver updates the registry with the prefix used for the stream interface functions in your driver.

· Use a stub for a stream function if it is not used by your driver

· Export the stream functions your driver implements in its module definition file.

The following example shows a sample module definition file for exporting all the stream functions:

LIBRARY RAMCARD

DESCRIPTION 'Pegasus Template Driver for PCMCIA RAM Card Devices'

CODE EXECUTE READ SHARED

EXPORTS RAM_Init

RAM_Deinit

RAM_Open

RAM_Close

RAM_Read

RAM_Write

RAM_Seek

RAM_IOControl

RAM_PowerDown

RAM_PowerUp

DetectRAMCard

This example also exports the DetectRamCard function. This function is used for card detection purposes in the sample device driver.
