Chapter 6 NT Pegasus Emulation Using PC Card Hardware

About Pegasus Emulation with PC Card Hardware

The Pegasus DDK includes extensions to the Pegasus emulator that let you test and debug PC Card device drivers on a development computer before building them for a Pegasus computer for final testing. For information on installing and using the Pegasus emulator, see the Pegasus SDK.

Note Emulation on NT currently works only for memory PC Card drivers. The 16550MOD GPS, and TTY sample drivers do not build under emulation
