Using the Test Applications

To test an I/O PC Card driver

1. Build the test application 16550tst.exe.

2. Install the test application on your target computer. To install, copy the test application from your development computer into the \WINDOWS directory of your target computer using the Pegasus Manager.

3. Connect a serial debug cable between the serial ports on your development computer and your target computer.

4. Start a terminal application on your development computer.

5. Insert the 16550 PCMCIA modem device in the PC Card slot on your target computer.

6. Run the test application that sends a few AT commands to the modem device and receives responses from the modem device.

Starting a Terminal on your Development Computer

Connect one end of the serial debug cable to the serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.

Start a terminal on your development computer with the following settings:

· 19200 baud

· 8 data bits

· no parity

· 1 stop bit

· no flow control

· COM1 or COM2 corresponding to the serial port used on the development computer

Starting and Using the Test Application

To start and use the 16550tst.exe test application

1. On the Pegasus graphical interface, tap the Start button.

2. On the Start button’s pop-up menu, tap Run to open the Run dialog box.

3. In the Open box, type 16550tst, and then tap the OK button.

4. Debug print statements should appear in the debug terminal on your development computer. The application prefixes debug statements with 16550APP, the client driver prefixes debug statements with 16550DLL.
