Insert the PC Card to Test

To use the Cardtest driver, first insert a PC card. If the Device Manager detects the driver, it prints the following debug messages to a terminal monitor connected to your target computer’s debug serial port:

CARDTESTDLL: DllMain(): dll attach.

CARDTESTDLL: DetectionFunction().

CARDTESTDLL: DllMain(): dll dettach.

CARDTESTDLL: DllMain(): dll attach.

CARDTESTDLL: PTD_Init().
