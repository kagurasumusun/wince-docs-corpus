xxx_Deinit

BOOL xxx_Deinit(

DWORD hDeviceContext

);

The xxx_Deinit function de-initializes a PC Card device.

Parameters

hDeviceContext

Specifies a handle used to identify the device context. The xxx_Init function creates and returns this identifier.

Return Value

Returns TRUE if the device successfully de-initialized, otherwise it returns FALSE.

Remarks

When the user removes the PC Card from its socket, the operating system Device Manager calls this function.

Your device driver should free any resources that it has allocated and terminate.
