ClientCallback

STATUS ClientCallback(// or whatever name you give this function
CARD_EVENT CardEvent
CARD_SOCKET_HANDLE hSocket
PCARD_EVENT_PARMS pCardEventParms
);
The Card Services driver calls a callback function, such as ClientCallback, to notify the driver of a PC Card event.
Parameters
CardEvent
Contains one of the Card Services callback event codes. See “Event Codes.”
hSocket
Contains a handle to a socket and function pair.
pCardEventParms
Points to the parameters associated with CardEvent.
Return Value
If the function succeeds, return CERR_SUCCESS; otherwise, set it to one of the following:
Value		Description
CERR_BAD_ARGSIndicates the pointer specified for pCardEventParms is invalid.
CERR_BAD_SOCKETIndicates the socket identifier specified for hSocket is invalid or a PC Card is not inserted.
Remarks
When a PC Card event occurs, Card Services notifies drivers by calling their registered callback functions. The callback function must following the syntax as the ClientCallback function above.
Drivers can indicate for which events they want notification when they register with CardRegisterClient.
CardRequestSocketMask and CardSetEventMask can be used to request event notification for a specific socket and function pair.
