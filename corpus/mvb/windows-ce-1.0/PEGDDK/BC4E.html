Building the Test Application

To build the test application

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Cardtest.mak project and build the test application specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\TESTAPP.EXE.

The resultant Testapp.dll file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\TEST\TESTAPP directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Testapp.exe file is placed in the \PEGDDK\SAMPLES\PCMCIA\TEST\TESTAPP\PEGSHDBG directory.
