About the Source Files for the Memory Card Driver

The following source files are used to build the memory card driver. These files are located in the PEGDDK\SAMPLES\PCMCIA\RAMCARD directory.

FileDescription
Ramcard.*Source files containing the DLL entry function, a card detect function, the stream interface functions, and the status callback function; definition for the memory test I/O control code; project files
Readtest.c
Writetst.c		Source files for the read and write test applications that use the Ramcard driver.
