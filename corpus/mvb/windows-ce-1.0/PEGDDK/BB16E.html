About the Testapp Application

Copy Testapp.exe to your target computer and run it by tapping Start, Run, and typing testapp <test type argument> in the Open listbox.

The application takes one argument, as shown in the following command line syntax:

testapp {-memory | attribute | tuples}

When run, Testapp.exe performs the following actions:

· Uses CreateFile to open the PTD1 device.

· Uses DeviceIoControl to access the Cardtest driver’s PTD_IOControl function which invokes the memory test, attribute test or tuples test.

· Uses CloseHandle to close the PTD1 device.

The Memory Card Test

The memory test code in the file Memory.C tests a PC Card memory card. The memoryTest routine writes to and reads back 4096 bytes of memory, starting at a zero offset address. The test code displays a message indicating whether or not the test is successful. The memory size under test, defined as 4096 bytes in the application, is passed to memoryTest and can be increased or decreased. The memoryTest routine is called from the Cardtest driver function PTD_IOControl (located in Cardtest.C).

The Attribute Memory Dump Test

The attributeTest routine displays 256 bytes of the attribute memory region of a PC card. This function is called from the Cardtest driver function PTD_IOControl. The memory region size, defined as 256 bytes in the application, is passed as a parameter to attributeTest and can be changed if desired. The file Attribut.C contains the source code for attributeTest. The file Cardtest.C contains the source code for PTD_IOControl.

Notice the mapped window (the call to CardMapWindow in attributeTest) is twice the size of the attribute memory to be displayed. The mapped window must be twice the size of the number of attribute memory bytes read because only every other byte of attribute memory contains valid data.

The Tuple Dump Test

The source code for the tuplesTest routine is in Tuples.c. This routine scans the PC card’s Card Information Structure (CIS) and displays the following tuple information:

CISTPL_DEVICE
CISTPL_VERS_1
CISTPL_CONFIG
CISTPL_CFTABLE_ENTRY
CISTPL_MANFID
CISTPL_FUNCID
CISTPL_FUNCE

The tuplesTest routine also exercises the Card Services CardGetParsedTuple function using the CISTPL_CONFIG and CISTPL_CFTABLE_ENTRY tuples.
