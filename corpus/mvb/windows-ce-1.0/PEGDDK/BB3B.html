Functions Used by Drivers

Drivers use the following function sets for system operation and communication:

· the stream type driver interface functions (the stream interface)

· the Card Services functions

· the Device Manager functions

The system uses the functions defined for stream interface to initialize, control, and access a driver. Drivers must include these functions for operation with the system. The Device Manager uses the following stream interface functions when it loads and unloads drivers:

For this Device Manager operationSee this stream interface function
Initializationxxx_Init
De-initializationxxx_Deinit
I/O controlxxx_IOControl
For more information on the stream type driver interface, see Chapter 3, “Stream Interface Reference.”
D drivers for PC Cards use the Card Services functions to register their callback functions with Card Services, to obtain information from Card Services, and to set the event masks Card Services uses to trigger the callbacks. For more information on Card Services, see Chapter 4, “Card Services Reference.”
