Verify the Debug Serial Port Settings

If you are using the Windows Debugger (Windbg.exe) supplied with the SDK to debug your application, verify your Windbg serial settings. From the Microsoft Developer Studio, click Tools on the main menu, and then click Remote Connection. You will be presented with a Remote Connection dialog; select your computer and connection type and click Settings. You will be presented with the Windbg Serial Settings dialog shown in Figure 2. Verify the settings are correct and make changes if required.

Note that Windbg uses a different serial port than Pegasus Manager (running on your target-host connection). Therefore, to use Windbg, two serial cables are required. The serial connection settings shown in Figure 2 are for the debug serial connection. To change these dialogs, click Remote Connection on the Tools menu.
