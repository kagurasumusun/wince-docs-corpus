Configure the Remote Registry on Pegasus

To load the Cardtest sample driver, you must edit the remote registry with Pregedit so that the Device Manager will run the detection routine and load the Cardtest.dll driver.

For the Device Manager to detect the Cardtest sample driver, you must:

· Add a numeric key and the Dll and Entry values for it under the HKEY_LOCAL_MACHINE \Drivers\PCMCIA\Detect key in the registry. For example, create a new key named 05. Under this key, add the following string values:

HKEY_LOCAL_MACHINE

[Drivers]

[PCMCIA]

[Detect]

[5]

SZ: Entry = DetectionFunction

SZ: Dll = Cardtest.dll

· Create a Cardtest key under the HKEY_LOCAL_MACHINE \Drivers\PCMCIA\ key in the Pegasus registry. Then, under the Cardtest key, add the following string values:

HKEY_LOCAL_MACHINE

[Drivers]

[PCMCIA]

[Cardtest]

SZ: Prefix = PTD

SZ: Dll = CARDTEST.DLL

If the registry key HKEY_LOCAL_MACHINE \Drivers\PCMCIA already contains a Plug and Play ID key that matches the ID for your PC card, you must delete or rename the ID key.
