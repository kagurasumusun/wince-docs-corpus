Case Study: Building the NewsCard Pager Driver

To build the NewsCard pager driver as a DLL

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the Newscard.mak project and build a Newscard.dll file specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\NEWSCARD.DLL.

The resultant Newscard.dll file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\PAGER specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 target computer, the Newscard.dll file is placed in the \PEGDDK\SAMPLES\PCMCIA\PAGER\PEGSHDBG directory.
