About the Source Files for the Pager Driver

The following source files are used to build the pager driver. These source files are located in the PEGDDK\SAMPLES\PCMCIA\PAGER directory.

FileDescription
Pager.cSource code for the DLL entry function, the stream interface functions, and the status callback function
Newscard.*Source code for reading and deleting pager messages from the Motorola NewsCard; definitions for the Motorola NewsCard; project files
