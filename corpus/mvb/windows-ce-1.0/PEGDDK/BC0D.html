Chapter 2 Sample I/O PC Card Device Driver

Introduction to the Sample I/O PC Card Device Driver

This application note describes developing an I/O PC Card installable device driver for the Pegasus operating system, installing it, and testing it with an application. Since a 16550-style PC Card modem is a common I/O card, it was selected for the sample driver. To focus on the development of an I/O card driver, specific code for the 16550-style PCMCIA modem was minimized.

Use this application note as a guide through the I/O driver source code. This application note highlights and summarizes the important files and functions used for this driver. Because the descriptions in this application note reference the functions in the source code and complement its comments, you might want to print the source files or display them in a text editor so you can cross reference them.
