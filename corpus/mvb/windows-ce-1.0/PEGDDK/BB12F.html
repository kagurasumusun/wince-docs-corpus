Installing the pepcmcia Device Driver

To install the PEPCMCIA NT Device Driver

1. Copy PEPCMCIA.SYS into your device driver directory (for example, C:\WINNT\SYSTEM32\DRIVERS).

2. Update the NT registry for the PEPCMCIA driver. If you have updated the PEPCMCIA.INI file with the values for configuration, you can update the registry by running the following command

regini pepcmcia.ini

3. Reboot your computer.

After rebooting the computer, you can manually start or stop the PEPCMCIA device with the command:

net [start|stop] pepcmcia

You can also use the Devices application in the Control Panel to arrange for automatic start of the PEPCMCIA driver each time you boot your computer.

Note Disable the stock NT 4.0 PCMCIA driver when running the PEPCMCIA driver—only one driver can be in control of the Intel PCIC chip.
