Chapter 3 Sample Test PC Card Device Driver

Introduction

This application note describes developing a test PC Card installable device driver and its test application. This driver and the test application can test and provide you with information about a PC Card inserted in the PC Card slot.

Use this application note as a guide through the test PC Card driver source code. This application note highlights and summarizes the important files and functions used for this driver. Because the descriptions in this application note reference the functions in the source code and complement its comments, you might want to print the source files or display them in a text editor so you can cross reference them.
