Case Study: Building the 16550 Modem Driver

To build the 16550 modem driver as a DLL

1. Start Microsoft Visual C++ 4.0 Developer Studio.

2. Open the 16550mod.mak project and build a 16550mod.dll file specific to your target computer and build type.

3. When prompted to enter the remote executable path and file name, type \WINDOWS\16550MOD.DLL.

The resultant 16550mod.dll file is placed under the following directories:

· the \WINDOWS directory of your target computer

· a \PEGDDK\SAMPLES\PCMCIA\16550MOD directory specific to your target computer and build type

For example, if you build in the debug mode for an Sh3 computer, the 16550mod.dll file is in the \PEGDDK\SAMPLES\PCMCIA\16550MOD\PEGSHDBG directory.
