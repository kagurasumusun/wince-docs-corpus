Testing an I/O PC Card Driver

The test application exercises the client driver by calling system functions, CreateFile, WriteFile, ReadFile, and CloseHandle. To keep the application simple, it outputs debug print messages in a debug terminal on your development computer.

The WriteFile and ReadFile functions repeat a few times, each time sending an AT command to the modem device and reading the response bytes from the modem device.

Prior to starting the test applications, connect one end of the serial debug cable to the debug serial port on your target computer and the other end to a serial port on your development computer. For example, you can connect to the COM2 port on your development computer.
