Stream Interface Functions

As indicated by xxx in each function definition, each PC Card installable device driver has a unique three-character prefix string. For example, the prefix string for the serial driver is COM. When the user inserts a PC Card in the PC Card slot, the operating system finds this prefix string and other registration information in its registry. The operating system identifies each exported DLL function for stream type drivers by this prefix string.

To create a driver DLL you must export all of the stream interface functions and provide the logic for the stream interface functions that are of interest to your PC Card.

The stream interface defines the following functions:

FunctionDescription
xxx_InitInitializes a PC Card device.
xxx_DeinitDe-initializes a PC Card device.
xxx_OpenOpens a PC Card device for reading and/or writing.
xxx_CloseCloses a PC Card device.
xxx_ReadReads data from a PC Card device.
xxx_WriteWrites data to a PC Card device.
xxx_SeekMoves the data pointer in a PC Card device.
xxx_PowerUpRestores PC Card device power.
xxx_PowerDownSuspends PC Card device power.
xxx_IOControlSends a command to a PC Card device.
