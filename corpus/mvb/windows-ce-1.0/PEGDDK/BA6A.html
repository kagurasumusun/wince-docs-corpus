Required Header Files

The following DDK header files provide the definitions of the constants, data structures, and function prototypes you need to write an installable driver. The DDK header files are located in PEGDDK\INCLUDE.

Include FileDescription
CARDSERV.HContains the Card Services structures, definitions, and function prototypes. This file defines the Card Services interface exposed by the PC Card driver and is required to build a PC Card installable driver.
DEVLOAD.HContains definitions for the device loader and registry.
TUPLE.HContains definitions for accessing the elements of a tuple. It also defines the tuple code constants.
DBGPRINT.HContains the DEBUGMSG macro.
