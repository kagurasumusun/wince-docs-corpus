About the Source Files for the I/O PC Card Driver

The following source files are used to build the 16550mod driver. These source files are located in the \PEGDDK\SAMPLES\PCMCIA\16550MOD directory.

FileDescription
16550mod.*Source code for the DLL entry function, the stream interface functions, and the status and interrupt callback functions; project files
16550.hDefinitions for the 16550 universal asynchronous receiver-transmitter (UART)
