Selecting the Target and Build

Visual C++ (Microsoft Developer Studio) builds one target at a time; therefore, you must specify the target prior to performing a build. The RAM Card project includes build targets for MIPS and SH3 computers, and the NT Pegasus emulator.

The RAM Card project workspace includes the following project:

· Ramcard

· Readtest

· Writetst

The Ramcard project is the actual PC Card driver. Readtest is a simple application that reads bytes from the RAM card. Writetst is a simple application that writes bytes to the RAM card. Select the project you want to build using the target selection (Default Project Configuration) list box.

After selecting the project you want to build, build it by clicking the target file in the Build menu. For example, build the “ramcard - Win32 (PegSH) Debug” target by clicking Build Ramcard.dll on the Build menu. For more information on how to configure and use the Microsoft Developer Studio, refer to the Microsoft Visual C++ 4.0 User Guide.
