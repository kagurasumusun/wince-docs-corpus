CardReleaseWindow

STATUS CardReleaseWindow(
CARD_WINDOW_HANDLE hCardWin
);
The CardReleaseWindow function releases a memory or I/O window allocated by CardRequestWindow.
Parameter
hCardWin
Specifies a memory window handle from CardRequestWindow.
Return Value
If the function succeeds, the return value is CERR_SUCCESS; otherwise, it is one of the following:
Value		Description
CERR_BAD_HANDLEIndicates an invalid memory window handle specified for hCardWin.
CERR_CONFIGURATION_
LOCKED		Indicates the PC Card must be placed in memory-only mode with CardReleaseConfiguration before an I/O window can be released.
See Also
CardRequestWindow, CardReleaseConfiguration
