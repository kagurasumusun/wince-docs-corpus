PFN_DETECT_ENTRY

typedef LPTSTR (*PFN_DETECT_ENTRY)(

CARD_SOCKET_HANDLE,

UCHAR,

LPTSTR,

DWORD

);

Function signature definition for a detection function called by the Device Manager.

Parameters

CARD_SOCKET_HANDLE

Specifies the socket containing the card to detect.

UCHAR

Specifies the device type from the CISTPL_FUNCID tuple, or 0xff for unknown.

LPTSTR

Specifies a pointer to a buffer used to return the name of device key.

DWORD

Specifies the length (number of characters) in the buffer parameter.

Return Value

The detection function must return an LPTSTR.

Remarks

A NULL return from the detection function indicates that it did not recognize the card. If the card is recognized, then the detection function copies the string name of the key under \Drivers\PCMCIA for the driver that can control that card and returns a pointer to the string.
