About the Tuples.c Source File

The tuples test code in Tuples.c scans the PC Card’s Card Information Structure (CIS) and displays the following tuple information:

CISTPL_DEVICE

CISTPL_VERS_1

CISTPL_CONFIG

CISTPL_CFTABLE_ENTRY

CISTPL_FUNCID

CISTPL_FUNCE

The PTD_IOControl function in the card test client driver calls the TuplesTest function. The TuplesTest function exercises the Card Services CardGetParsedTuple function, using the CISTPL_CONFIG and CISTPL_CFTABLE_ENTRY tuples.
