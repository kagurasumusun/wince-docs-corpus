Key to the Buttons in the Help Window

A series of buttons are displayed at the top of the Help window. The commands in the button bar help you navigate through help.
CommandDescription
ContentsDisplays the table of contents for help topics.
SearchLists all the keywords in Help. By typing or selecting a keyword, you can search for and go to specific Help topics.
BackDisplays the previous help topic.
HistoryDisplays a list of the last 40 opened help topics viewed. Double-click a title to display that help topic.
