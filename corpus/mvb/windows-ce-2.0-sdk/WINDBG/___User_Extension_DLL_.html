! (User Extension DLL)

Syntax

! [[filename.]]function [[string]]

Parameters

filename

Name of the DLL to call (without the .DLL extension), followed by a period (.). The default filename is NTSDEXTS.DLL.

Windows CE Note: If you are developing Win32p applications and doing remote debugging on a Windows CE device, much of the following information does not apply. For information about configuring hardware and build settings, transferring files to the Windows CE device, and other Windows CE-specific topics, please refer to the Windows CE documentation.:

Non-Windows CE Help:

In kernel debugging, the default extension DLL depends upon the target platform:

Target PlatformDefault Extension DLL
x86KDEXTX86.DLL
MIPSKDEXTMIP.DLL
ALPHAKDEXTALP.DLL
function
Name of the DLL function to call.
string
String to pass to the DLL function.
Description
Calls a DLL function from WinDbg. Use this command to call special routines while debugging. For a complete list of the built-in extension commands, enter !? at the WinDbg prompt. See also Kernel Debugging Extensions and Creating Extensions.
