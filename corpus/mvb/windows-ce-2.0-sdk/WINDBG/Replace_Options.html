Replace Options

Option or CommandDescription
Match Whole Word Only optionMatches all occurrences of the Find What string that are not preceded or followed by an alphanumeric character or the underscore (_).
Match Case optionReplaces text that matches the capitalization of the text string.
Regular Expression optionUses special characters to define the Find What search string.
Find Next commandFinds the next occurrence of the text string w/o replace.
Replace commandReplaces the text string and finds the next one. This command is available only after you choose the Find Next command.
Replace All commandReplaces all occurrences of the text string.
