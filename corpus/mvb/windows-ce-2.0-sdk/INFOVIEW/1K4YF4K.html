Click the type of project you want to create. The types displayed are based on the products you have installed. You must also type a project name in the Project Name box. A default location for the new project is supplied automatically, but you can change the drive and path. To add the new project to the open workspace, select Add to Current Workspace. Otherwise, a new workspace is created automatically to contain the new project. To make the new project a subproject of an existing project, select Dependency Of and specify the project name. Select the appropriate platform or platforms.

Because Developer Studio registers projects by name, you should use a unique name for each project you create. This enables Developer Studio to support workspaces that contain projects that are in different layouts and locations.

Note for Visual J++ users: Changing the default location is not recommended for Visual J++ projects. For the platform, select only the Java Virtual Machine.
