Selected Object Properties: Attributes

Attributes

This tab displays the defined attributes for the selected object. That object may be a method, a property, an implemented method or property, or a function. The title bar of the Properties sheet displays the type of object. With your cursor in the Atttributes field, you can type a letter to jump to any attribute in the list that starts with the letter you’ve typed. However, you cannot enter text into this field.
