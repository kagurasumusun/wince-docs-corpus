Sample Application

Use the Sample Application dialog box to choose sample applications to copy to your local hard drive.

Files

Lists the files comprising the sample application.

View

Click to look at a particular file in the Text editor.

Copy

Click to copy one or more selected files to your hard drive. After copying, the local (copied) files are opened. If you want to copy and open the project, click Copy all, then select the project in the Files list and click View.

Copy all

Click to copy all files comprising the sample to your local hard drive. If you want to copy and open the project, click Copy all, then select the project in the Files list and click View.
