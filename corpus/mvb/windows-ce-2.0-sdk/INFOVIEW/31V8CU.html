Copy

Use the Copy dialog box to specify the local drive and directory where you want to copy sample application files.

Copy files

Provides a space for you to enter or choose the sample file or files you want to copy.

To directory

Provides a space for you to enter or choose the directory where you want sample files copied.

Drive

Provides a space for you to enter or choose the drive where you want to copy the sample files.

Network

Opens a dialog box that allows you to connect to a networked drive.
