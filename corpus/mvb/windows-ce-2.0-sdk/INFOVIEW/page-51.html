Default Shortcut Menu

The shortcut menu shows commands you can use to customize your development environment. This menu contains the following commands.

Shortcut menu commandDescription
OutputShows/hides the Output window.
Watch (if debugging)Shows/hides the Watch window.
Variables (if debugging)Shows/hides the Variables window.
Registers (if debugging)Shows/hides the Registers window.
Memory (if debugging)Shows/hides the Memory window.
Call Stack (if debugging)Shows/hides the Call Stack window.
WorkspaceShows/hides the Workspace window.
StandardShows/hides the Standard toolbar.
BuildShows/hides the Build toolbar.
Build MiniBarShows/hides the Build MiniBar toolbar
ResourceShows/hides the Resource toolbar.
InfoViewerShows/hides the InfoViewer toolbar.
EditShows/hides the Edit toolbar.
DebugShows/hides the Debug toolbar.
BrowseShows/hides the Browse toolbar.
DatabaseShows/hides the Database toolbar.
Wizard BarShows/hides the Wizard Bar toolbar.
CustomizeDisplays the Customize dialog box, in which you can customize your development environment to a greater extent.
