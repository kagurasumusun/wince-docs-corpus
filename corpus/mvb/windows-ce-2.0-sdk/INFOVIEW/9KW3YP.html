Lists commands you have added to the Tools menu. You can add commands to the Tools menu by installing additional Developer Studio products, or you can use this dialog box to add individual commands.

To add a command, click the New button above the Menu Contents list, type the text for the menu item in the box at the end of the Menu Contents list, and provide the necessary information in the boxes below. Placing an ampersand (&) before a letter in the menu item text makes the letter an accelerator key. To modify a command, select it in the Menu Contents list and change the information specified in the boxes below. To delete a command, select it and click the Delete button above the Menu Contents list. To move a command up or down on the Tools menu, select the command in the Menu Contents list and click one of the arrows above the list.
