The interface you create for your object. This interface contains your custom methods. For ATL Controls, Internet Explorer Controls, Simple Objects, Internet Explorer Objects, Add-in Objects, ActiveX Server Components, and MS Transaction Server Components, the wizard creates an interface with the name you specify. For Property Page objects, no custom interface is created, and the wizard assigns IUnknown as the object interface. For Component Registrar objects, no custom interface is created, and the wizard assigns IComponentRegistrar as the object interface. Dialog objects do not create an interface.
