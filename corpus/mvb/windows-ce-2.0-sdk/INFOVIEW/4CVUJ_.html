Text Tool Window

The Text Tool window is used to add text information to a cursor, bitmap, or icon resource.

The text area of the window contains the text that appears as part of the resource. Initially this area is empty.

Click the Font button to change the font, style, or size of the cursor font.

The text tool window uses the default shortcut menu, which contains a list of windows and toolbars and the Toolbars and Customize commands.
