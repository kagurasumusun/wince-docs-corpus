-------------------------------------------------------------------------------

SUMMARY
=======

This article describes the limitations of the Text property of a Text box
control and the Caption property of a Label control in the Windows CE Toolkit
for Visual Basic (VBCE).

MORE INFORMATION
================

In the Windows CE Toolkit for Visual Basic, the Text property of a Text box has
a limit of 32,766 characters.

The Caption property of a label control has a maximum of 65,535 characters.
