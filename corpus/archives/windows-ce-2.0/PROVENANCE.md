# Windows CE 2.0 documentation — provenance

* Item: `Windows_CE_2.0_Technical_Information_Microsoft_1997`
  "Windows CE 2.0 Technical Information (Microsoft) (1997)"
* URL: https://archive.org/details/Windows_CE_2.0_Technical_Information_Microsoft_1997
* ISO: `Windows_CE_2.0_Technical_Information_Microsoft_1997.iso`
  (565,833,728 bytes; CDIMAGE; Microsoft Corporation; 1997-10-27)
* Collected: 2026-09-14 (JST).

## Contents (documents only)

`ce20/developer/` — the official Microsoft "Windows CE Developer" site
mirror shipped on the CD (40 HTML pages), including the CE 2.0-era
technical white papers:

* `technical/w32model.htm` — the Windows CE Win32 model
* `technical/porting.htm` — porting desktop code to Windows CE
* `technical/comm_mod.htm` — the CE communications model
* `technical/mgdidft1.htm` / `mgdiview.htm` — CE GDI overview
* `technical/vcceembo.htm`, `rtdraft5.htm` — VC++ for CE / real-time notes
* `prodinfo/`, `download/`, `resources/` — product & program info pages

The CD also carries third-party vendor folders (AMD/Ardis/Bsquare/Hitachi/
NEC/Toshiba/...), the CE Value Components binaries (Pocket PowerPoint/
Pocket Streets/ethernet drivers), and OS/toolchain binaries — **none of
these are Microsoft documentation** and none are preserved here (documents
only, no shared source, no code; policy: wince-api docs/iso-collection.md).

Note: the CE 2.0 Win32 **API reference** lives in the CE 2.0 SDK "Books
Online" (a separate SDK CD, not this Technical Information CD); that CD is
sought separately (see `ce2x/` when obtained).
