To configure the PPTP implementation on a Windows CE-based platform, you can set the following optional registry values on the client device.

The following table describes the registry settings for HKEY_LOCAL_MACHINE\Comm\Pptp1\Parms.

Registry Value Type Default Description
TcpPortNumber SHORT 1723 Specifies a TCP port number of the PPTP server the device is trying to connect to.
UdpPortNumber USHORT 47 Specifies the UDP port to which to send UDP encapsulated tunneled packets.
MaxWanEndpoints ULONG 1 Sets the number of PPTP sessions a WAN miniport can have.
MaxTransmit ULONG 32 Sets the maximum number of outstanding send packets the PPTP WAN miniport will accept.
InactivityIdleSeconds ULONG 60 Starts a timer that measures the number of seconds between packets. When the timer reaches the default of 60 seconds, it instructs the system to send a control channel packet to the server.
AlwaysEcho BOOL 1 Setting this parameter to 1 instructs the receiving device to always send an echo back to the sender.
TunnelConfig ULONG 0 Specifies a routing configuration for tunneling clients. The value is a bitmask. If Bit 0 is set to 1, UDP will be used to encapsulate tunneled packets.
TcpDisconnectTimeout ULONG 30 Specifies the length of time to wait for the peer to acknowledge a disconnect request when disconnecting a TCP connection.
TcpConnectTimeout ULONG 30 Specifies the length of the timeout to use when establishing a TCP connection.
