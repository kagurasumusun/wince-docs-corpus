The dxmasf module contains all WMT core components.

Dxmasf Components

The dxmasf module contains the following components.

Component Description
ACMOBJ Audio dispatcher.
ERRORMSGS Error stringtable resource.
FILESTRM Supports local file streaming.
HTTPSTRM Supports HTTP streaming.
ICMOBJ Video dispatcher.
M3UPLAYL Provides .M3U file support.
MSBSTRM Supports MS Broadcast and Multy Bit-Rate (MBR) streaming.
MSSTRM Supports MMS streaming.
NSCFILEPARSER Provides .NSC file support.
URLGRAB URL grabber.
URLOBJ URL dispatcher.
XMLPLAYL Provides .ASX version 3 support.
