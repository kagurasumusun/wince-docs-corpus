The GET_LPDDRAWSURFACE_GBL_MORE macro traverses from a DDRAWI_DDRAWSURFACE_GBL structure to a DDRAWI_DDRAWSURFACE_GBL_MORE structure. 

GET_LPDDRAWSURFACE_GBL_MORE( psurf_gbl )      \
 (*(LPDDRAWI_DDRAWSURFACE_GBL_MORE *)        \
 ((BYTE *)psurf_gbl - sizeof( DWORD )))

Parameters

psurf_gbl
The current surface global object.

Returns

A pointer to the DDRAWI_DDRAWSURFACE_GBL_MORE structure for the given surface global object.
