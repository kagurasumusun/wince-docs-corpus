This structure specifies that a mutex handle has been closed with CloseHandle.

typedef struct __CEL_MUTEX_CLOSE {
HANDLE hMutex;
} CEL_MUTEX_CLOSE, *PCEL_MUTEX_CLOSE;

Members

hMutex
Handle of the mutex that has been closed.
