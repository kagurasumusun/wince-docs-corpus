CardModifyWindow

This function changes the attributes of a memory window opened by the CardRequestWindow function. This function has unintended side effects, and should not be used. To modify a window, release it and request a new window with the desired attributes.

STATUS CardModifyWindow(
CARD_WINDOW_HANDLE hCardWindow 
UINT16 fAttributes 
UINT8 fAccessSpeed );

Parameters

hCardWindow
Handle to a memory window returned by CardRequestWindow.
fAttributes
Specifies a bit-encoded window attributes mask.
fAccessSpeed
Specifies a bit-encoded access speed mask.

Return Values

CERR_SUCCESS indicates success. One of the following values indicates failure:

CERR_BAD_ARGS
Indicates that a value for fAttributes or fAccessSpeed is invalid.
CERR_BAD_HANDLE
Indicates that a driver handle specified for hCardWindow is invalid.

Driver name

PCMCIA

Requirements

Windows CE OS 1.0 and later
