IPOutlookApp::GetDefaultFolder

Important:

This method is not supported in Windows CE Platform Builder 3.0.

This method returns an IFolder object for one of the five folders provided by Pocket Outlook.

HRESULT GetDefaultFolder( int olFolder, IFolder **ppIFolder );

Parameters

olFolder
[in] Specifies which folder to get. This parameter can be one of the following: olFolderCalendar, olFolderTasks, olFolderContacts, olFolderCities, or olFolderInfrared.
ppIFolder
[out] Pointer to a pointer for a folder object.

Return Values

S_OK indicates success. If an error occurs, the appropriate HRESULT value is returned.

Code Example [Visual Basic]

The following Visual Basic code snippet shows how to get the Pocket Outlook Cities folder:

Sub GetCitiesFolder(polApp As PocketOutlook.Application)
Dim polCitiesFdr As PocketOutlook.Folder
Set polCitiesFdr = polApp.GetDefaultFolder(olFolderCities)
End Sub
