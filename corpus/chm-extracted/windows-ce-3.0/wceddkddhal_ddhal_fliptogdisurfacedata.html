DDHAL_FLIPTOGDISURFACEDATA

The DDHAL_FLIPTOGDISURFACEDATA structure contains information necessary to make the surface to which the GDI writes the primary surface. This structure passes the information to the DirectDraw HAL FlipToGDISurface callback function. 

typedef struct _DDHAL_FLIPTOGDISURFACEDATA
{
LPDDRAWI_DIRECTDRAW_GBL     lpDD;
DWORD                       dwToGDI;
DWORD                       dwReserved;
HRESULT                     ddRVal;
LPDDHAL_FLIPTOGDISURFACE    FlipToGDISurface;
} DDHAL_FLIPTOGDISURFACEDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
dwToGDI
Set to TRUE to flip to the GDI surface, or FALSE to flip away from the GDI surface.
dwReserved
Reserved for future use.
ddRVal
Passes the DirectDraw return values.
FlipToGDISurface
This member is used by DirectDraw and should not be filled in by the driver.
