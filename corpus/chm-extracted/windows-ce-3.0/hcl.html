Introduction

This hardware compatibility list provides a representative list of hardware peripherals that are compatible with the Microsoft Windows CE operating system. Microsoft has validated the compatibility of the hardware peripherals on an x86-based Windows CE hardware reference platform. This page does not guarantee the hardware compatibility for targeted Windows CE products such as Pocket PC. If you have questions about hardware compatibility for a targeted Windows CE product, see the Microsoft Windows CE Web site.

This list is divided into two sections:

  • Hardware Compatibility List for Microsoft Windows CE Version 3.0
  • Hardware Compatibility List for Windows CE Version 2.11
