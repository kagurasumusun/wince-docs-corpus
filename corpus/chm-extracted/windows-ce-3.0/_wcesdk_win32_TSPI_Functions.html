The following section contains a list of the TSPI line device, phone device and service provider functions supported in Windows CE 3.0.

Some of the functions listed below, such as TSPI_lineCompleteCall, are not called by TAPI. Windows CE 3.0 still supports these functions to maintain backwards compatibility with older versions of the operating system.

A TSP must support the TSPI_provider functions that are called by TAPI. A TSP can choose not to support almost any other function in the table. The entry in the table can point to a function that returns the LINEERR_UNSUPPORTED error message.

  • In Windows CE 3.0, the only required DLL export function from a TSPI DLL is the TSPI_lineGetProcTable function. This function is used to return to TAPI the addresses of the interface functions of the TSP. 
    LONG TSPIAPI TSPI_lineGetProcTable 
(
LPTSPI_PROCS *lplpTSpiProcs
)
;

The lplpTSpiProcs parameter is a pointer to the TSPI_PROCS structure, which is defined in the Tapicomn.h header file. TSPI_PROCS contains the table of function addresses that is returned when the TSPI_lineGetProcTable function is called.
