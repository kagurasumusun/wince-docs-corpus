This function retrieves a handle to the display monitor that contains a specified point. 

HMONITOR MonitorFromPoint(
POINT pt,
DWORD dwFlags
);

Parameters

pt
[in] POINT structure that specifies the coordinates of the point of interest in virtual screen coordinates.
dwFlags
[in] DWORD that determines the return value of the function when none of the display monitors contain the point. It is one of the following values:
Value Description
MONITOR_DEFAULTTONEAREST Return value is a handle to the display monitor that is nearest to the point.
MONITOR_DEFAULTTONULL Return value is NULL.
MONITOR_DEFAULTTOPRIMARY Return value is a handle to the primary display monitor.

Return Values

If one of the display monitors contains the point, the return value is an HMONITOR handle to that display monitor. If none of the display monitors contains the point, the return value depends on the value of dwFlags.
