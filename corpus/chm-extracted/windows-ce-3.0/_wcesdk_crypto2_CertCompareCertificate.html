This function compares two certificates to determine whether they are identical.

BOOL WINAPI CertCompareCertificate(
DWORD dwCertEncodingType,
PCERT_INFO pCertId1,
PCERT_INFO pCertId2
);

Parameters

dwCertEncodingType
[in] Specifies the encoding type used. Currently, only X509_ASN_ENCODING is used; however, additional encoding types may be added in the future.
pCertId1
[in] Pointer to the CERT_INFO structure for the first certificate in the comparison.
pCertId2
[in] Pointer to the CERT_INFO structure for the second certificate in the comparison.

Return Values

If the certificates are identical and function succeeds, the return value is nonzero (TRUE).

If the function fails, the return value is zero (FALSE).

Remarks

The desktop platform supports the PKCS_7_ASN_ENCODING flag, but Windows CE does not. Windows CE ignores the flag when it is specified.
