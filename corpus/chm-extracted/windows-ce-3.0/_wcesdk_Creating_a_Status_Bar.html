Creating a Status Bar

A status bar, which is known also as a status window, is a horizontal window that is positioned at the bottom of a parent window. It displays status information that is defined by the application. The following screen shot shows a status bar.

You create a status bar by calling the CreateStatusWindow function. The class for the status bar is registered when the DLL for the common control is loaded. You can use the InitCommonControls function to ensure that this DLL is loaded. To register the class for the status bar by using the InitCommonControlsEx function, specify the ICC_BAR_CLASSES flag as the dwICC member of the INITCOMMONCONTROLSEX structure that you pass in the lpInitCtrls parameter.

Because status bars are windows, you can create a status bar by calling the CreateWindow function or the CreateWindowEx function and specifying the STATUSCLASSNAME window class.

The window procedure for the status bar control automatically sets the initial size and position of the window. The width is the same as that of the client area of the parent window. The height is based on the width of the borders of the window and on the metrics of the font that currently is selected into the device context of the status bar.

The window procedure automatically adjusts the size of the status bar when it receives a WM_SIZE message. Typically, when the size of the parent window changes, the parent window sends WM_SIZE to the status bar.

An application can set the minimum height of the drawing area of a status bar by sending the window an SB_SETMINHEIGHT message that specifies the minimum height in pixels. The drawing area does not include the window borders.

You retrieve the widths of the borders of a status bar by sending the window an SB_GETBORDERS message. The message includes the address of a three-element array that receives the widths.
