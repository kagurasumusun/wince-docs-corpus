Handling Errors

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

When an error occurs and RasDial is operating asynchronously, RAS sends a message to the notification window. The wParam in the message is the connection state (rasconnstate) and the lParam indicates what error occurred. In these cases, the notification handler should call the RasHangUp function to end the RAS connection.
