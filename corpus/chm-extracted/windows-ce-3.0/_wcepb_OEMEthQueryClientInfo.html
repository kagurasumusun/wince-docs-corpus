This function retrieves platform-specific information for debug Ethernet services.

BOOL OEMEthQueryClientInfo (
UCHAR Id, 
EDBG_ADDR *pPeerAddr, 
PUCHAR pWindowSize, 
PUCHAR *ppBufferPool );

Parameters

Id
[in] Service identifier, which can be one of the following EDBG_SVC_* values defined in Ethdbg.h.
Value Description
EDBG_SVC_DBGMSG Debug messages.
EDBG_SVC_PPSH Parallel port text shell and file system supported by Cesh.exe.
EDBG_SVC_KDBG Kernel debugger.
pPeerAddr
Peer Ethernet Internet Protocol (IP) address and UDP port number. If the address information is not known, pPeerAddr should be set to 0. This information is contained in the command "JUMPING" sent by the instance of Eshell that runs on the development workstation, and it is typically saved in RAM by the boot loader.
pWindowSize
Client window size.
ppBufferPool
Packet buffer pool address.

Return Values

TRUE if the requested service is supported on the target device; otherwise, FALSE.

Remarks

This function is called by the EDBG subsystem when the default Ethernet services are configured. Examples of these services include debug messages, CESH, and kernel debugger. The platform needs to return address information and a buffer pool for the specified client. The buffers are used for formatting and receiving EDBG packets. Each buffer pool is divided into two buffers: one receive buffer and one transmit buffer.

You can specify a smaller window size to consume less memory, but the protocol is less efficient. The standard window size is EDBG_WINDOW_SIZE and the maximum window size is EDBG_MAX_WINDOW_SIZE. The amount of memory required per client is 2*(window size)*1500 bytes.

To reserve a separate memory location for loading the Windows CE OS image, edit the Config.bib binary image builder file. Loading the OS image into a separate memory location prevents the Ethernet boot loader from being overwritten. It also sets aside in the .bib file the necessary RAM for the packet buffers used by the EDBG library. For an example, see IMGEBOOT in %_WINCEROOT%\Platform\Odo\Files\Config.bib.
