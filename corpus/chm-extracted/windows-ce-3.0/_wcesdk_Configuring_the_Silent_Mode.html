Configuring the Silent Mode

The behavior of the Silent Mode is controlled by the Silent.ini file, which contains the options for the setup. The administrator can write any valid value for each parameter in the INI file to control the setup program execution. The following code sample describes a simple Silent.ini file.

; Settings for silent install
[ActiveSync]
InstallDir = %ProgramFilesDir%\Microsoft ActiveSync
UsePreviousPort = 1
CommPort =
ResetRasServerPorts = 1
DesktopIcon = 1
Reboot = 1

The file structure is the same as Windows INI files, and contains the following syntax:

  • Comments on lines that begin with a semicolon(;)
  • Sections begin with a name in brackets. Silent.ini file contains only one section name: "[ActiveSync]"
  • Within sections, a file contains "Setting = Value" commands. Setting/Value commands answer questions that would normally appear during setup.

A Silent.ini file contains six settings. Any settings can have no value, such as the CommPort setting in the above example. If the file contains no value, ActiveSync uses the default value.

InstallDir %ProgramFilesDir%\Path or %SystemDrive%\Path or
Path

The InstallDir setting describes where Setup should place the ActiveSync 3.0 files. Setup replaces %ProgramFilesDir% with the path to the Program Files directory of the Windows disk, such as "C:\Program Files". ActiveSync replaces %SystemDrive% with the drive letter of the Windows Disk, such as "C:" Path can be any directory. Setup creates the directory if the directory does not exist. If you do not set a value, Setup defaults to %ProgramFilesDir%\ActiveSync. Setup ignores the InstallDir setting if ActiveSync or WCES is already installed on the user's system. Instead, Setup uses the existing directory.

UsePreviousPort 1 or
0

The UserPreviousPort setting declares if Setup should use an existing COM port setting, if such a setting exists. 1 means yes, and 0 means no. By default, the value is 1. Setup ignores the UserPreviousPort setting if ActiveSync or WCES is already installed on the user's system.

CommPort COM1 or
COM2 or
COM3 or
COM4

The CommPort setting describes which COM port ActiveSync should check for devices. By defualt, no COM port is selected. ActiveSync 3.0 uses the port declared in previous versions of ActiveSync. Setup ignores the CommPort setting if UsePreviousPort is set to 1, ActiveSync or WCES is already installed on the system, and a COM port was previously set.

ResetRasServerPorts 1 or
0

The ResetRasServerPorts setting declares if Setup should reset the COM ports used by RAS. 1 means yes, and 0 means no. By default, the value is 1. Setup ignores the ResetRasServerPorts if the CommPort setting is non-empty, or if Setup finds a previously-declared port.

DesktopIcon 1 or
0

The DesktopIcon setting declares if Setup should put a shortcut to ActiveSync on the user's desktop. 1 means yes, and 0 means no. By defualt, the value is 1.

Reboot 1 or
0

The Reboot setting declares if Setup should reboot the machine. 1 means yes, and 0 means no. By default, the value is 1. If the value is 0, ActiveSync will not force a reboot. However, the user may still require a reboot. The setup log will show if a reboot is necessary.
