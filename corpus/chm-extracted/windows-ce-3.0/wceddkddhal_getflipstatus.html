The GetFlipStatus callback function indicates whether the surface has finished its flipping process. 

DWORD __stdcall GetFlipStatus(
LPDDHAL_GETFLIPSTATUSDATA pgfsd );

Parameters

pgfsd
Pointer to a DDHAL_GETFLIPSTATUSDATA structure that contains information necessary to determine whether a previous flip has finished and the current flip can proceed.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

An example implementation of this callback function (GetFlipStatus32) can be found in the IGS sample driver source code.
