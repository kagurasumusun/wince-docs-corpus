IOCTL_HAL_INIT_RTC

This input/output control supports resetting of the real-time clock (RTC) by calling OEMSetRealTime. A request to call OEMSetRealTime is made by calling OEMIoControl with IOCTL_HAL_INIT_RTC.

Parameters

dwIoControlCode
Set to IOCTL_HAL_INIT_RTC. Supports resetting of the real-time clock by calling OEMSetRealTime.
lpInBuf
Pointer to the input buffer that contains a SYSTEMTIME structure.
nInBufsize
Size in bytes of lpInBuf. This should be the size of the SYSTEMTIME structure.
lpOutBuf
Not used; set to NULL.
nOutBufSize
Not used; set to 0.
lpBytesReturned
Not used; may be set to NULL.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Remarks

The kernel will call this input/output control on a cold boot. Systems with a battery-backed real-time clock can then determine whether the current clock time appears to be valid, and if so, ignore the time provided by the kernel; otherwise set the RTC to match the provided time. Systems without a battery-backed clock should normally use the default time provided by the kernel to initialize their RTC as part of the cold boot sequence.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
