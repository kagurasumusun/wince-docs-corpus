The modules that are included in the ie group provide Internet functionality for Windows CE–based platforms.

The ie group contains the following modules.

Module Description Notes Import file
IESAMPLE Builds an Internet-demonstration system using Microsoft Internet Explorer components. Exposes no public functions. Iesample.lib
MLANG Implements a set of services that support the internationalization of Internet data. Exposes no public functions. Mlang.lib
MSCEFILE Implements an ActiveX control for Microsoft Internet Explorer that manages files. Exposes no public functions. Mscefile.lib
MSHTML Provides support for the Microsoft HTML parsing and rendering engine (MSHTML). Exposes no public functions. Mshtml.lib
SHDOCVW ActiveX control that is known also as the Layout Manager. This module acts as a wrapper that adds a number of high-level functions, which include navigation functions, to a Web browser. Exposes no public functions. Shdocvw.lib
URLMON Provides support for urlmon. This module monitors Uniform Resource Locators (URLs) and reports changes to Web sites. Exposes no public functions. Urlmon.lib
WININET Supports the Microsoft Win32 Internet API set. This module can be used to make the Internet an integral part of any application.   Wininet.lib
WPLAYER Implements a wave file player. Exposes no public functions. Wplayer.lib
