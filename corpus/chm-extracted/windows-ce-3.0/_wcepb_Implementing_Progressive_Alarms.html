Implementing Progressive Alarms

To implement a progressive alarm, the base notification engine reserves one notification called User Alarm. Your notification UI can set this notification by calling the CeNotifyPrivate_SetUserAlarm function. Once the alarm is set, the base notification engine activates it by calling the CeNotifyPublic_UserAlarmSignalled function. To cancel the alarm, you can call the CeNotifyPrivate_ClearAlarm function.
