This function searches for a specific interface on a USB device.

LPCUSB_INTERFACE FindInterface(
LPCUSB_DEVICE lpDeviceInfo, 
UCHAR bInterfaceNumber,
UCHAR bAlternateSetting );

Parameters

lpDeviceInfo
[IN] Pointer to a device information structure, which is returned from the GetDeviceInfo function.
bInterfaceNumber
[IN] Specifies the interface number.
bAlternateSetting
[IN] Specifies an alternate interface setting.

Return Values

A pointer to a USB_INTERFACE structure indicates success. NULL indicates failure.

Remarks

Alternate settings are used to supply alternate interfaces that can be selected by driver software. For a device with no alternate settings, use a value of 0.

Requirements

Windows CE OS 2.10 and later
