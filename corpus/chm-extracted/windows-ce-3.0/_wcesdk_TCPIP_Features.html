TCP/IP Features

The TCP/IP suite for Windows CE was designed to ease integration of Microsoft systems into the embedded market, telecommunications, the enterprise, the consumer market, government, and public networks; and to provide the ability to operate over those networks with enhanced security. Windows CE is an "Internet ready" operating system.

Windows CE supports the following standard features:

  • The ability to bind to multiple network adapters with different media types (802.3 and 802.5)
  • Logical and physical multihoming capabilities
  • Internal IP routing capability
  • Internet Group Management Protocol (IGMP) Version 2 (IP Multicasting)
  • Duplicate IP address detection
  • Multiple default gateways
  • Dead gateway detection
  • Automatic Path Maximum Transmission Unit (PMTU) discovery
  • Virtual Private Networks (VPNs)

Windows CE also has the following performance improvements:

  • Protocol stack tuning, including increased default window sizes
  • TCP Scalable Window sizes (RFC 1323 support)
  • Selective Acknowledgments (SACK)
  • TCP Fast Retransmit

Windows CE provides the following services:

  • Dynamic Host Configuration Protocol (DHCP) client
  • Windows Internet Name Service (WINS), a NetBIOS name client
  • Domain Name System (DNS) client
  • Dial-up (PPP/SLIP) support
  • TCP/IP network printing. No built-in support for lpr or lpd is provided. However, independent software vendors (ISVs) and original equipment manufacturers (OEMs) could add support for lpr/lpd to Windows CE.
  • SNMP extension agent, providing a MIB-2 subagent that allows the state of TCP/IP to be monitored and controlled
  • Windows Sockets (Winsock) Version 1.1 interface
  • Wide Area Network (WAN) support
  • Basic TCP/IP connectivity utilities, including FTP and telnet.
  • Sample applications and diagnostic tools for TCP/IP management (route, ipconfig and ping)
    Note   Windows CE customers have the necessary Winsock support to add a number of utilities and applications which are not available on Windows CE, for example: arp, hostname, lpq, nbtstat, netstat, route, nslookup, tracert, Echo, Discard, Character Generator, daytime, and Quote of the Day.
