Internet Explorer Multiple-Language API Registry Settings (Windows Embedded CE 6.0)

In this article

1/6/2010

The HKEY_CURRENT_USER\Software\Microsoft\Internet Explorer\International registry key and its subkeys contain the international settings for Internet Explorer.

The subkey nnnn is a three-digit or four-digit number that identifies a particular code page in Microsoft Windows. The subkey ss, used as a child of the Scripts key, is a number in the range 0-255 that identifies a particular script.

Note

For Windows Embedded CE, the default registry values vary depending on which Catalog items are included in your OS design. For more information, see Default Registry Settings.

The following table shows the named values.

Subkey\Value : type Description

Default_CodePage : REG_DWORD

Specifies the default code page. Default setting in hex. The following list shows the default values.

  • 0411 - hex:f4,c6,00,00
  • 0412 - hex:b5,03,00,00
  • 0404 - hex:b6,03,00,00
  • 0804 - hex:a8,03,00,00

For all other locales, the default value is hex:e4,04,00,00.

AcceptLanguage : REG_SZ

Specifies the default language(s). The following list shows the default values.

  • 0411 - "ja,en-us;q=0.5"
  • 0412 - "ko,en-us;q-0.5"
  • 0404 - "zh-tw;en-us;q=0.5"
  • 0804 - "zh-cn;en-us;q=0.5"

For all other locales, the default setting is "en-us".

AutoDetect :REG_DWORD

For Windows Embedded CE 6.0, AutoDetect determines whether the browser automatically detects character encoding when viewing a Web page. The default setting is 0. If it is set to 1, autodetecting is enabled. It does not apply to the sysgened Internet Explorer, which does not support the Auto Select functionality.

nnnn\Script : REG_SZ

Specifies the default alphabet to use for this locale, for example, "Universal Alphabet" or "Cyrillic."

nnnn\Default_InternetEncoding : REG_DWORD

Specifies the default Internet Encoding scheme to use, in the following format, hex:nn,nn,nn,nn.

Scripts\ss\IEFixedFontName : REG_SZ

Specifies the default fixed-width font, for example, "Lucida Console."

Scripts\ss\IEFontSize: REG_DWORD

In Windows Embedded CE 6.0, this setting determines the font size that the browser uses.

Smallest: "IEFontSize"=hex:00,00,00,00

Smaller: "IEFontSize"=hex:01,00,00,00

Medium: "IEFontSize"=hex:02,00,00,00

Larger: "IEFontSize"=hex:03,00,00,00

Largest: "IEFontSize"=hex:04,00,00,00

The default setting is "hex:02,00,00,00". The easiest way to get all of the font sizes set back to the default setting (Medium) is to delete the IEFontSize values.

Scripts\ss\IEPropFontName : REG_SZ

Specifies the default proportional-width font, for example, "Arial."

MIME Database Codepage Settings

The subkeys of the HKEY_CLASSES_ROOT\MIME\Database\Codepage registry key contain settings for a particular MIME code page, as specified by the subkey nnnn.

The following table shows the named values.

Subkey\Value : type Description

nnnn\BodyCharset : REG_SZ

Specifies the default charset, for example, "ibm852".

nnnn\Description : REG_SZ

Specifies the locale description, for example, LOC_DESCRIPTION_852.

nnnn\FixedWidthFont : REG_SZ

Specifies the default fixed-width font.

nnnn\ProportionalFont : REG_SZ

Specifies the default proportional-width font.

nnnn\Encoding : REG_DWORD

Specifies the type of Internet encoding, in the following format: hex:nn,nn,nn,nn.

nnnn\Family : REG_DWORD

Specifies the code page family, for example, 000004e2.

MIME Database RFC1766 Settings

By default, MLang uses internal data to map Rfc1766 code page identifiers to their respective languages. You can instruct MLang to use mapping information in the HKEY_CLASSES_ROOT\MIME\Database\Rfc1766 registry key instead by calling the IMultiLanguage2::SetMimeDBSource method and passing MIMECONTF_MIME_REGISTRY.
