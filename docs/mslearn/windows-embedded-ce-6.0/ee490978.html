International Catalog Items (Windows Embedded CE 6.0)

In this article

1/6/2010

The following table shows the catalog items for International features.

Catalog item SYSGEN variable Description

Input Method Manager

SYSGEN_IMM

Adds Input Method Manager (IMM). IMM manages the communication between an Input Method Editor (IME) and an application.

English (US) National Language Support only

SYSGEN_LOCUSA

Provides support for the English (US) locale.

The following functions will return an ERROR_NOT_SUPPORTED exception under SYSGEN_LOCUSA:

  • SetACP
  • SetOEMCP
  • SetSystemDefaultLCID
  • SetUserDefaultLCID
  • SetLocaleInfo
  • LCMapString when flag LCMAP_SORTKEY is used.

National Language Support (NLS)

SYSGEN_CORELOC

Adds NLS support. NLS supports the different locale-specific needs of users around the world.

Arabic Keyboard (101)

SYSGEN_KBD_ARABIC_101

Adds a keyboard layout for the Arabic locales.

Arial (subset 1_08)

SYSGEN_FONTS_ARIAL_1_08

Adds a subset of the Arial font for the Arabic and Hebrew locales.

Arial Bold (subset 1_08)

SYSGEN_FONTS_ARIALBD_1_08

Adds a subset of the Arial Bold font for the Arabic and Hebrew locales.

Courier New (subset 1_08)

SYSGEN_FONTS_COUR_1_08

Adds a subset of the Courier New font for the Arabic and Hebrew locales.

Tahoma (subset 1_08)

SYSGEN_FONTS_TAHOMA_1_08

Adds a subset of the Tahoma font for the Arabic, Hebrew, and Thai locales.

Tahoma Bold (subset 1_08)

SYSGEN_FONTS_TAHOMABD_1_08

Adds a subset of the Tahoma Bold font for the Arabic and Hebrew locales.

Agfa AC3 Font Compression

SYSGEN_AGFA_FONT

Adds Agfa AC3 font compression for a reduced memory footprint.

SimSun & NSimSun

SYSGEN_FONTS_SIMSUN

Adds the SimSun & NSimSun fonts for Simplified Chinese.

SimSun & NSimSun (Subset 2_20)

SYSGEN_FONTS_SIMSUN_2_20

Adds the SimSun & NSimSun (Subset 2_20) font for Simplified Chinese.

SimSun & NSimSun (Subset 2_50)

SYSGEN_FONTS_SIMSUN_2_50

Adds the SimSun & NSimSun (Subset 2_50) font for Simplified Chinese.

SimSun & NSimSun (Subset 2_60)

SYSGEN_FONTS_SIMSUN_2_60

Adds the SimSun & NSimSun (Subset 2_60) font for Simplified Chinese.

SimSun & NSimSun (Subset 2_70)

SYSGEN_FONTS_SIMSUN_2_70

Adds the SimSun & NSimSun (Subset 2_70) font for Simplified Chinese.

SimSun & NSimSun (Subset 2_80)

SYSGEN_FONTS_SIMSUN_2_80

Adds the SimSun & NSimSun (Subset 2_80) font for Simplified Chinese.

SimSun & NSimSun (Subset 2_90)

SYSGEN_FONTS_SIMSUN_2_90

Adds the SimSun & NSimSun (Subset 2_90) font for Simplified Chinese.

GB18030 text converter

SYSGEN_GB18030

GB18030-2000 is a new Chinese character encoding standard set by the People's Republic of China. The standard contains many characters and has new conformance requirements for desktop operating systems.

MSPY 3.0 for Windows Embedded CE

SYSGEN_MSPY3_SC

Adds the Microsoft Pinyin (MSPY) Input Method Editor (IME) 3.0 for Simplified Chinese. MSPY 3.0 functions as a sentence–based input method. It uses an intelligent, bigram–based language model and has self–learning capability with a high degree of accuracy. MSPY 3.0 allows you to select one of three lexical databases, as shown in the following table.

East Asian Edit Control

SYSGEN_EDIMEFE

East Asian edit control to add to a UI.

East Asian Word Wrap

SYSGEN_MGFE

Support for word wrap for East Asian languages.

Double Spelling (Shuang Pin) soft keyboard - Large

SYSGEN_SPIM_MSPY_LARGE

Adds a large keyboard for the Shuang Pin input method.This input method provides an advanced phonetic input model that requires fewer keystrokes.

Double Spelling (Shuang Pin) soft keyboard - Small

SYSGEN_SPIM_MSPY

Adds a small keyboard for the Shuang Pin input method.This input method provides an advanced phonetic input model that requires fewer keystrokes.

1.1 MB - Minimal Database

SYSGEN_MSPY3_DB_1

Adds the 1.1 MB (minimal) version of the lexical database for MSPY 3.0.

1.3 MB - Minimal Database

SYSGEN_MSPY3_DB_3

Adds the 1.3 MB (compact) version of the lexical database for MSPY 3.0.

1.7 MB - Minimal Database

SYSGEN_MSPY3_DB_7

Adds the 1.7 MB (standard) version of the lexical database for MSPY 3.0.

Pocket IME

SYSGEN_PIME_SC

Adds Pocket IME for Simplified Chinese. This IME provides options for customizing its behavior in your OS design. Pocket IME is a small IME that can support both keyboard systems and keyboard-less embedded systems that have small screens and a minimum memory footprint.

Double Spelling (Shuang Pin) soft keyboard - Small

SYSGEN_SPIM

Adds a small Double Spelling (Shuang Pin) on-screen keyboard IM for Pocket IME.

MingLiU & PMingLiU

SYSGEN_FONTS_MINGLIU

Adds the MingLiU & PMingLiU font for Traditional Chinese.

MingLiU & PMingLiU (Subset 2_70)

SYSGEN_FONTS_MINGLIU_2_70

Adds the MingLiU & PMingLiU (Subset 2_70) font for Traditional Chinese.

MingLiU & PMingLiU (Subset 2_80)

SYSGEN_FONTS_MINGLIU_2_80

Adds the MingLiU & PMingLiU (Subset 2_80) font for Traditional Chinese.

MingLiU & PMingLiU (Subset 2_90)

SYSGEN_FONTS_MINGLIU_2_90

Adds the MingLiU & PMingLiU (Subset 2_90) font for Traditional Chinese.

Pocket IME

SYSGEN_PIME_TC

Adds Pocket IME for Traditional Chinese, a compact IME that provides a sample customizable UI model. Users can choose between phonetic input and input by radical. Soft keyboards are included for both inputs.

Handwriting Recognizer Engine (HWX)

SYSGEN_HWX

Provides a handwriting recognition engine that supports user-drawn ideographs and characters.

MboxCHT HWX Sample UI

SYSGEN_MBOXCHT

Adds a sample IM for Traditional Chinese handwriting input that works with the HWX engine. .

Input by Radical (Chang Jei)

SYSGEN_CHAJEIIM

Adds a sample IM for Traditional Chinese with an on-screen keyboard that allows for Chang Jei input and is closely tied to the Chang Jei IME. Allows input by radical characters.

Phonetic Input (Bopomofo)

SYSGEN_PHONIM

Adds a sample IM for Traditional Chinese with an on-screen keyboard that accepts phonetic input based on the Bopomofo standard. It is closely tied to the Phonetic IME.

Transcriber Handwriting Recognition Application

SYSGEN_TRANSCRIBER

The Transcriber is a handwriting recognition application for English (US), German, and French. It recognizes all handwriting, cursive or printed. In addition to recognizing letters, numbers, and words, the Transcriber recognizes common symbols and different control gestures.

US Keyboard

SYSGEN_KBD_US

English (U.S.) keyboard layout.

Handwriter Recognizer Engine (HWX)

SYSGEN_USA_HWX

Handwriting recognition engine that supports user-drawn ideographs and characters.

For more information, see Handwriting Recognizer Engine (HWX).

Hebrew Keyboard

SYSGEN_KBD_HEBREW

Adds a keyboard layout for the Hebrew locale.

Shruti

SYSGEN_FONTS_SHRUTI

Adds the Shruti font for the Gujarati locale.

Gujarati Keyboard

SYSGEN_KBD_GUJARATI

Adds a keyboard layout for the Gujarati locale.

Mangal

SYSGEN_FONTS_MANGAL

Adds the Mangal font for the Hindi and Marathi locales.

Hindi Traditional Keyboard

SYSGEN_KBD_HINDI_TRADITIONAL

Adds a traditional keyboard layout for the Hindi locale.

Tunga

SYSGEN_FONTS_TUNGA

Adds the Tunga font for the Kannada locale.

Kannada Keyboard

SYSGEN_KBD_KANNADA

Adds a keyboard layout for the Kannada locale.

Marathi Keyboard

SYSGEN_KBD_MARATHI

Adds a keyboard layout for the Marathi locale.

Raavi

SYSGEN_FONTS_RAAVI

Adds the Raavi font for the Punjabi locale.

Punjabi Keyboard

SYSGEN_KBD_PUNJABI

Adds a keyboard layout for the Punjabi locale.

Latha

SYSGEN_FONTS_LATHA

Adds the Latha font for the Tamil locale.

Tamil Keyboard

SYSGEN_KBD_TAMIL

Adds a keyboard layout for the Tamil locale.

Gautami

SYSGEN_FONTS_GAUTAMI

Adds the Gautami font for the Telugu locale.

Telugu Keyboard

SYSGEN_KBD_TELUGU

Adds a keyboard layout for the Telugu locale.

MS Gothic & MS PGothic & MS UI Gothic

SYSGEN_FONTS_MSGOTHIC

Adds the MS Gothic & MS PGothic & MS UI Gothic font set for Japanese.

MS Gothic & MS PGothic & MS UI Gothic (Subset 1_50)

SYSGEN_FONTS_MSGOTHIC_1_50

Adds the MS Gothic & MS PGothic & MS UI Gothic font set (Subset 1_50) for Japanese.

MS Gothic & MS PGothic & MS UI Gothic (Subset 1_60)

SYSGEN_FONTS_MSGOTHIC_1_60

Adds the MS Gothic & MS PGothic & MS UI Gothic font set (Subset 1_60) for Japanese.

MS Gothic & MS PGothic & MS UI Gothic (Subset 1_80)

SYSGEN_FONTS_MSGOTHIC_1_80

Adds the MS Gothic & MS PGothic & MS UI Gothic font set (Subset 1_80) for Japanese.

MS Gothic & MS PGothic & MS UI Gothic (Subset 1_90)

SYSGEN_FONTS_MSGOTHIC_1_90

Adds the MS Gothic & MS PGothic & MS UI Gothic font set (Subset 1_90) for Japanese.

MS Gothic & MS PGothic & MS UI Gothic (Subset 1_70)

SYSGEN_FONTS_MSGOTHIC_1_70

Adds the MS Gothic & MS PGothic & MS UI Gothic font set (Subset 1_70) for Japanese.

MS Gothic & MS PGothic (Subset 30)

SYSGEN_FONTS_MSGOTHIC30

Adds the MS Gothic & MS PGothic font set (Subset 30) for Japanese.

MS Gothic & MS PGothic (Subset 30_1_19)

SYSGEN_FONTS_MSGOTHIC30_1_19

Adds the MS Gothic & MS PGothic font set (Subset 30_1_1_19) for Japanese.

MS Mincho & MS PMincho

SYSGEN_FONTS_MSMINCHO

Adds the MS Mincho & MS PMincho font set for Japanese.

IME 3.1

SYSGEN_IMEJPN

Adds IME 3.1 for Japanese. IME 3.1 lets users type complex characters and symbols, such as Japanese Kanji characters, by using a standard keyboard.

Compact Database

SYSGEN_IMEJPN_DB_COMPACT

Adds the compact database for IME 3.1.

Standard Database

SYSGEN_IMEJPN_DB_STANDARD

Adds the standard database for IME 3.1.

Dictionary Tool

SYSGEN_IMEJPN_DICTIONARY_TOOL

Adds the dictionary tool for IME 3.1.

Properties Dialog Box

SYSGEN_IMEJPN_PROPERTY

Adds the property dialog box for IME 3.1.

Advanced Settings Dialog Box (Landscape mode only)

SYSGEN_IMEJPN_ADVANCED_SETTING

Adds the advanced settings dialog box in landscape mode for IME 3.1.

System Tray Icon Manager

SYSGEN_IMEJPN_SYSTRAY

Adds notification area icon support for IME 3.1.

Pocket IME

SYSGEN_PIME

Adds Japanese Pocket IME 2.0. Pocket IME is a small-size IME that can support embedded systems without keyboards that have small screens and a minimum memory footprint.

Name/Place Database

SYSGEN_PIME_NAME_PLACE_DATA

Adds the name and location database for Japanese Pocket IME.

Supplemental Database

SYSGEN_PIME_SUPPLEMENTAL_DATA

Adds the supplemental database for Japanese Pocket IME.

All Characters List

SYSGEN_IM_ALLCHAR

Adds the All Characters List IM, a sample IM that enables character input based on a comprehensive character list.

Handwriter Recognizer Engine (HWX)

SYSGEN_JPN_HWX

Handwriting recognizer engine for Japanese characters.

Character Auto Complete - HWX Sample UI

SYSGEN_CACJPN

Adds the Character Auto Complete sample UI that works with the Japanese handwriting recognizer engine.

Multibox HWX Sample UI

SYSGEN_MULTIBOX

Adds the Multibox sample UI for Japanese handwriting input that works with IME 3.1 and with Pocket IME.

Kana Soft Keyboard

SYSGEN_IM_KANA

Adds an on–screen keyboard that enables input of hiragana and katakana directly. This IM is provided as sample code.

Romaji/English Soft Keyboard

SYSGEN_IM_ROMA

Adds an on-screen keyboard that enables input of the Western alphabet. This IM is provided as sample code.

Search by Radical

SYSGEN_IM_RADICAL

Adds a search by radical engine that enables complex kanji character selection based on radicals. UI is provided as a sample for customization.

Search by Stroke

SYSGEN_IM_STROKE

Adds a search by stroke engine that enables complex kanji character selection based on character strokes. UI is provided as a sample for customization.

Japanese Keyboard

SYSGEN_KBD_JAPANESE

Japanese keyboard layout.

Gulim (GL_CE)

SYSGEN_FONTS_GL_CE

Adds the Gulim (GL_CE) font for Korean.

Gulim & GulimChe (Subset 1_30)

SYSGEN_FONTS_GULIM_1_30

Adds the Gulim & GulimChe font set (Subset 1_30) for Korean.

Gulim & GulimChe (Subset 1_40)

SYSGEN_FONTS_GULIM_1_40

Adds the Gulim & GulimChe font set (Subset 1_40) for Korean.

Gulim & GulimChe (Subset 1_50)

SYSGEN_FONTS_GULIM_1_50

Adds the Gulim & GulimChe font set (Subset 1_50) for Korean.

Gulim & GulimChe (Subset 1_60)

SYSGEN_FONTS_GULIM_1_60

Adds the Gulim & GulimChe font set (Subset 1_60) for Korean.

IME 97

SYSGEN_K_IME97

Adds Korean IME 97. IME 97 contains a customizable UI sample, based on the Microsoft Windows 95 IME.

Handwriting Recognizer Engine (HWX)

SYSGEN_KOR_HWX

The Korean handwriting recognition engine.

MboxKOR HWX Sample UI

SYSGEN_MBOXKOR

Adds the Mboxkor sample UI, a sample IM for Korean Handwriting input that works with the Korean HWX engine.

Korean Soft Keyboard Sample

SYSGEN_MSIMK

Adds the Korean Soft Keyboard Sample, a sample on-screen keyboard IM that accepts input and is closely tied to IME 97.

Korean Keyboard

SYSGEN_KBD_KOREAN

Korean keyboard layout.

Thai Kedmanee Keyboard

SYSGEN_KEYBD_THAI_KEDMANEE

Adds the Kedmanee keyboard layout for the Thai locale.

Multilingual User Interface (MUI)

SYSGEN_MULTIUI

Adds support for MUI. MUI enables you to create one run–time image for devices with multiple languages, and therefore let the end–user switch the user interface language.

Unicode Script Processor for Complex Scripts

SYSGEN_UNISCRIBE

Supports scripts that require special processing to show and edit because the characters are not laid out in a linear progression from left to right. Windows Embedded CE provides the correct text handling and layout for these scripts, and also for mirroring capabilities.
