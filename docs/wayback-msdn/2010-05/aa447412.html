OUTREG8

Windows CE 5.0
Send Feedback

This macro writes a byte to a specified address.

Copy 
#define OUTREG8(x, y)

Parameters

x
Specifies the address. The memory address space is used for all hardware platforms.
y
Byte to write to the specified address.

Return Values

None.

Remarks

Requirements

OS Versions: Windows CE Version 5.0 and later
Header: Oal_io.h
