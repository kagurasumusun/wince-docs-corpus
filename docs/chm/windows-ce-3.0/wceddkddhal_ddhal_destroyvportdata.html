DDHAL_DESTROYVPORTDATA

The DDHAL_DESTROYVPORTDATA structure contains information necessary to destroy a specified video port. This structure passes the information to the DirectDraw HAL DestroyVideoPort callback function. 

typedef struct _DDHAL_DESTROYVPORTDATA
{
LPDDRAWI_DIRECTDRAW_LCL        lpDD;
LPDDRAWI_DDVIDEOPORT_LCL       lpVideoPort;
HRESULT                        ddRVal;
LPDDHALVPORTCB_DESTROYVPORT    DestroyVideoPort;
} DDHAL_DESTROYVPORTDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_LCL structure that represents the DirectDraw object.
lpVideoPort
Pointer to the DDRAWI_DDVIDEOPORT_LCL structure that represents this video port.
ddRVal
Passes the DirectDraw return values.
DestroyVideoPort
This member is used by DirectDraw and should not be filled in by the driver.
