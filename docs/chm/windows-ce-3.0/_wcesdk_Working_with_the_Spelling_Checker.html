Working with the Spelling Checker

Windows CE provides a spelling-checker engine. Unlike the Help engine, the spelling checker is integrated into the Windows CE OS as a module; also, the spelling checker does not have any user interface (UI). Instead, your application passes text strings directly to the spelling checker. The spelling checker searches the supplied dictionaries and returns suggestions for correct spelling. You must decide how to display this data to users.

To integrate the spelling-checker engine into an application

  1. Initialize the spelling-checker engine by calling the SplInit function.

    Use the call to the SplInit function to add any user-defined spelling dictionaries and initialize user settings.

  2. Use the SplCheck, SplSuggest, SplOptionSet, SplReplace, and SplLimitSet functions to check spelling, suggest alternate words, and replace misspellings.
  3. When you are finished, close the spelling-checker engine by calling the SplQuit function.
