dwCeLogTLBMiss

This global variable specifies how many translation look-aside buffer (TLB) misses have occurred for the last thread that was running. This global variable is reset after each thread switch. To make use of this value, an OEM can declare dwCeLogTLBMiss in their OAL and read it whenever a CELID_THREAD_SWITCH event occurs. When replacing the logging engine, the OEM is responsible for resetting the counter to 0 after logging it.

extern dwCeLogTLBMiss;
