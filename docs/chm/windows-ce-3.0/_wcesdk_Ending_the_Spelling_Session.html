Ending the Spelling Session

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

After you finish using the spelling checker, you should call the SplQuit function to end the spelling session. SplQuit performs the following tasks:

  • It invalidates the spelling-session handle that was created in the call to the SplInit function.
  • It frees all of the resources that were allocated by the SplInit function.
  • It deletes the internal user dictionaries.
  • It saves external user dictionaries to the files that are specified in the parameters of the SplInit function.
