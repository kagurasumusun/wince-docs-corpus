This macro registers the current module (a DLL or process) and its associated debug zone with the kernel debug subsystem.

DEBUGREGISTER (hMod)

Return Values

None.

Remarks

Any module (a DLL or process) can register an associated debug zone mask with the kernel debug subsystem using this macro. Once the debug zones are registered, a user can then turn debug zones on or off programmatically using the DEBUGZONE macro. Debug zones may also be turned on or off interactively from the prompt Windows CE> of the Windows CE Console Debug Shell tool (Cesh.exe). You can interactively turn debug zones on or off by modifying bits of the registered debug zone mask. Calling this macro assumes that a global variable dpCurSettings has already been defined, where dpCurSettings must be a DBGPARAM structure.
