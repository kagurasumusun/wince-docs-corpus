This function allows a device driver to cause an artificial interrupt event.

BOOL SetInterruptEvent ( 
DWORD idInt );

Parameters

idInt
Identifier number for the interrupt caused by the driver.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

A device driver may call this function only when it is in power-off or power-on processing — situations which occur when the device driver's PowerOn and PowerOff power handler functions are called by other operating system components. A driver should only call SetInterruptEvent from these functions because the power handler routines are called in a special, nonpreemptible kernel mode in which most API calls are not permitted. In other contexts, simulated interrupts can be generated with the SetEvent API.
