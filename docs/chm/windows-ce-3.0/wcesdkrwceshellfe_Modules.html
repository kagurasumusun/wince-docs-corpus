The wceshellfe module group supports the following Windows CE shell-related modules: Handheld PC–style shell, Pocket Internet Explorer, Help for Windows CE, Control Panel applications.

The wceshellfe group contains the following modules.

Module Description Notes Library
ASFORM Shell support module. Required for Handheld PC–style shell, included in the full-version OS. Asform.lib
CESHELL Shell support module. Required for Handheld PC–style shell, included in the full-version OS. Ceshell.lib
CONTROL Control panel application module. Required for Windows CE Control Panel, included in the full-version OS. Control.lib
CPLMAIN This module supports the main control panel application. The Windows CE Control Panel allows users to set a variety of system-wide properties, such as mouse sensitivity, network configuration, and the desktop color scheme. This module includes a set of components. Contains components required for Windows CE Control Panel.. This module is included in the full-version OS. Cplmain.lib
CTLPNL Control Panel helper process module. Required for Windows CE Control Panel, included in the full-version OS. Ctlpnl.lib
EXPLORER Supports Handheld PC–style shell. Included in the full-version OS. Explorer.lib
HTMLVIEW Hypertext Markup Language (HTML) Help engine control module. Included in the full-version OS. Htmlview.lib
IEXPLORE Supports Microsoft Pocket Internet Explorer browser. Included in the full-version OS. Iexplore.lib
IMGDECMP Supports Pocket Internet Explorer image decompression. Included in the full-version OS. Imgdecmp.lib
INTLL Regional Settings Control Panel application module for landscape orientation. Included in the full-version OS. Intll.lib
INTLP Regional Settings Control Panel application module for portrait orientation Included in the full-version OS. Intlp.lib
PEGHELP Supports HTML-based help files. Included in the full-version OS. Peghelp.lib
WEBVIEW Pocket Internet Explorer HTML module. Included in the full-version OS. Webview.lib
