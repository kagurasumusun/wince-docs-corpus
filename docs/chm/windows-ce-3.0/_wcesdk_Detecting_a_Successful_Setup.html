Detecting a Successful Setup

ActiveSync places any error messages into a file during installation. This file provides a log of what occurred during the setup attempt, including any errors and whether setup completed successfully. The setup log information is placed in the wcesetup.log file. ActiveSync creates wcesetup.log in a temporary directory, and copies wcesetup.log to the directory that ActiveSync is currently installed. ActiveSync creates a log file when running in Silent or normal mode. If the setup fails, ActiveSync places wcesetup.log in the directory specified by the TMP environment variable. Any reinstall or upgrade of ActiveSync will overwrite the log wcesetup.log. Further, deleting ActiveSync will also delete wcesetup.log.

Note   You can find the ActiveSync installation directory in the HKEY_LOCAL_MACHINE\Software\Microsoft\Windows CE Services\InstalledDir registry key.

The following table describes the three types of messages that ActiveSync places in wcesetup.log.

Message Description
ERROR Setup has encountered a condition that is preventing Setup from continuing, such as not enough disk space, incorrect OS, or a minimum requirement not met. In such circumstances, Setup places an ERROR message in the log prior to exiting.
WARNING Setup has experienced a non-fatal problem. The WARNING message exists so that the administrator can take preventative measures to ensure successive silent setups will not run into problems.
STATUS Setup adds a STATUS message for every step in the setup process. The STATUS message exists to tell the administrator about the entire setup process.
