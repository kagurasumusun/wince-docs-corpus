This function establishes the window procedure for the Chooser dialog box.

BOOL waveui_AcmDlgProc (
HWND hwnd, 
UINT uMsg, 
WPARAM wParam, 
LPARAM lParam);

Parameters

hwnd
Handle to the dialog window.
uMsg
Specifies any window messages (for example, WM_CLOSE).
wParam
Message-specific parameter.
lParam
Message-specific parameter.

Return Values

This function generally returns FALSE. The most likely case for returning TRUE is if a new control is added to the dialog box, and that control sends private messages. If the function returns TRUE, the default window procedure is not used. You should use caution if you choose to have this function return TRUE.

Remarks

This function follows the same format as an application programming interface (API)-replaceable window hook.
