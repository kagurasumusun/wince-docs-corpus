hal Component

The hal component is the OEM component that abstracts the kernel from the hardware. The OEM creates this component that is then linked to the kernel to provide a seamless interface to the hardware. This component is required for all configurations.

Functions for Operating System Developers

The hal component includes the following functions for operating system configuration, which are defined in the Cache.s, Cfwp2.c, Client.c, Ethdbg.h Fwpc.c, Halether.h, Mkfuncs.h, Nkintr.h, Pkfuncs.h, Profiler.h, Oemboot.c, Oeminit.asm, and Oemioctl.c files.
