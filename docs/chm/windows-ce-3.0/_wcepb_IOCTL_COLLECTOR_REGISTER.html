IOCTL_COLLECTOR_REGISTER

Important:

This input/output control makes a request to call Ioctl_Register_DataCollector. This request is made by calling KernelIoControl with IOCTL_COLLECTOR_REGISTER.

Parameters

dwIoControlCode
Set to IOCTL_COLLECTOR_REGISTER. Supports calling Ioctl_Register_DataCollector.
lpInBuf
Set to Ioctl_Register_DataCollector PId parameter.
nInBufSize
Set to Ioctl_Register_DataCollector dwIDSize parameter.
lpOutBuf
Set to Ioctl_Register_DataCollector pBuffer parameter.
nOutBufSize
Set to Ioctl_Register_DataCollector dwBufSize parameter.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
