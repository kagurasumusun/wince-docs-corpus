Virtual Memory

Windows CE implements a paged virtual memory management system similar to the other Win32-based operating systems. Under Windows CE, a page comprises either 1,024 or 4,096 bytes depending on the microprocessor. Because most Windows CE-based platforms have limited RAM, most Windows CE developers prefer the 1KB page size. Each process in Windows CE has only 32MB of virtual address space. This is space used for your process, DLLs, heaps, stacks and virtual memory allocations. Memory allocated through memory mapped files is not part of a process' virtual address space.
