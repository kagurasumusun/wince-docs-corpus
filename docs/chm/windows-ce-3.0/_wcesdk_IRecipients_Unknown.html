This interface is not supported in Windows CE Platform Builder 3.0.

This interface provides a collection of recipients for an appointment that is a meeting request. You can get this collection with the Recipients property of an AppointmentItem. Use the methods of this interface to add, retrieve, or remove a recipient in the collection.

Methods in Vtable Order

Method Description
IRecipients::Add Adds a recipient to the recipient list for a meeting request.
IRecipients::Item Gets a person in the recipient list.
IRecipients::Remove Removes a person from the recipient list.
