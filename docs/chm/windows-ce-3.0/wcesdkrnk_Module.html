The nk module supports Windows CE kernel functionality and is required for all configurations.

Functions for Operating System Developers

The nk module includes the following functions for operating system configuration, which are defined in the Celog.h, Kerninst.c, Mkfuncs.h, Nkintr.h, Oemioctl.c, Pkfuncs.h, Profiler.h, Pwindbas.h, Pwinuser.h, Winbase.h, Windev.h, and Winnt.h header files.
