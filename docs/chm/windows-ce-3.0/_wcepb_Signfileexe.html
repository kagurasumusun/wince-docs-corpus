This tool signs an executable with a supplied private key.

You can use the following command line parameters with this tool.

signfile [ parameters ]

Parameters

-f PEFile
Specifies the file to be signed.
-a
Appends signature to PE File.
-k KeyName
Uses private key from named CryptoAPI key container.
-p Cfile
Outputs the public key to a file as a C structure.
-s AttribString
Specifies an optional attribute string to be included in signature. For example, you could add a string to indicate the trust level of the application.
-p SignFile
Outputs the signature to a file.

The following command line example shows how to sign Xyz.dll using the private key in key container TESTKEY1024.

Signfile -fXyz.dll -a -kTESTKEY1024

For more information about this tool, see Creating a Signature.
