SetDriverData

This function is used to store any data your driver wishes to attach to the DDGPESurf object, regardless of how you have subclassed it in your driver.

The driver data is neither created nor released by the DDGPESurf object; the driver is responsible for this. The DDGPESurf object simply stores a pointer to the memory you have allocated. If you are setting the driver data, your driver should be sure to check that the driver data that is already attached to the selected object is properly released.

virtual void SetDriverData (
DDGPEDriverData *pDriverData );

Parameters

pDriverData
A pointer to the driver data that should be attached to this DDGPESurf object. Your driver is responsible for allocating and releasing the memory associated with this object.

Return Values

None
