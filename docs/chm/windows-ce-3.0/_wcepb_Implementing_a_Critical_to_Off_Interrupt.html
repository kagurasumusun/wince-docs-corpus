Implementing a Critical-to-Off Interrupt

To implement the critical-to-off transition, implement a voltage comparator that generates a nonmaskable interrupt (NMI).

The following code example demonstrates a possible implementation for an NMI interrupt service routine (ISR) function. This ISR should verify that there is a critically low battery condition, power down all peripherals as quickly as possible, place the RAM in the self-refresh state, and suspend the CPU. If the CPU continues from the suspend power state after the wake-up event, it needs to jump to the reset vector code. The following code example shows the CPU startup code that should execute when the CPU is reset. This code example will be the last item to get executed by the operating system and may not be supported by all processors.

NmiISR:
Mask NMI              ; Keep NMI from occurring

; Make sure there is truly a low battery condition
for (i=0; i < 10; i++) {
   Check Battery Level
   If (Battery Level == OK) {
      return SYSINTR_NOP;
   }
}

Power off all peripherals
Put RAM in self refresh
Suspend CPU
Jump reset vector   ; For CPUs that would continue after the wake-up 
                    ; condition

For an example implementation of reset vector code, see the ResetVector routine in \Platform\Odo\Kernel\Hal\Ppc\.

In the x86 platform the kernel exports the OEMNMIHandler function, which the OEM can use to capture critical events in the system.
