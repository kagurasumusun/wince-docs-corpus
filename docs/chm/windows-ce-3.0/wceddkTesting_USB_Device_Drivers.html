Testing USB Device Drivers

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

There is no extensive USB test suite for Windows CE at this time. The sample USB HID driver and the USB 8x930Ax peripheral kit and evaluation board from Intel Corporation can be used to assist in testing USB scenarios. These are the methods used at Microsoft to test the USB system software for Windows CE. Further details on testing a USB system and the device drivers on an OEM platform are available in the Windows CE Platform Builder.
