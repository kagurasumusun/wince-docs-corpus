Thread Priorities

DirectSound playback quality is very sensitive to system-wide thread priorities. Each of the DirectSound components has its own thread priority, which can be adjusted via a registry key. The priorities can be adjusted relative to other threads in the system, but it is recommended that the relative ordering of these thread priorities not be changed (e.g. the DirectSound HAL should always have a higher priority than the DirectSound Mixer). Audio component thread priorities are shown in the following table.

Component DLL Name Registry Key Default Value (hex) Decimal
DirectSound HAL Emulation (Playback) IDsWave.dll HKEY_LOCAL_MACHINE\Drivers\Dsound\Wavedev\ThreadPriority256 D2 210
DirectSound HAL Emulation (Capture) IDsWave.dll HKEY_LOCAL_MACHINE\Drivers\DsoundCapture\Wavedev\ThreadPriority256 D7 215
DirectSound Waveform Driver Emulation WaveBuff.dll HKEY_LOCAL_MACHINE\Drivers\BuiltIn\WAVEBUFF\ThreadPriority256 DC 220
DirectSound Mixer dsounds.dll HKEY_LOCAL_MACHINE\Drivers\BuiltIn\DSOUNDS\ThreadPriority256 C8 200
DirectSound HAL (Playback) <dshalname.dll> HKEY_LOCAL_MACHINE\Drivers\Dsound\<dshalname>\ThreadPriority256 96 150
DirectSound HAL (Capture) <dshalname.dll> HKEY_LOCAL_MACHINE\Drivers\DsoundCapture\<dshalname>\ThreadPriority256 E6 230
Waveform driver Wavedev.dll HKEY_LOCAL_MACHINE\Drivers\BuiltIn\wavedev\ThreadPriority256 96 150
