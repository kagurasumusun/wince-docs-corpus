Allocating Memory

Applications often must allocate blocks of memory while they are running. When writing an application for a Windows CE-based platform, you can choose from a number of different methods for allocating memory. To decide which memory allocation method works the best for your application, choose from the following criteria:

  • For a single, large data item with multiple pages that has a size of greater than 64K, use the virtual memory API set. For more information on how to use virtual memory, see Using Virtual Memory.
  • For small items with random, overlapping lifetimes, allocate memory from the local heap. Try to maintain a consistent heap size. For more information on how to allocate memory from the local heap, see Using the Local Heap.
  • For a set of smaller data items that have the same lifetime, allocate memory from a separate heap created by a call to the HeapCreate function. For more information on how to allocate memory from a separate heap, see Using a Separate Heap.
  • For data items that exist for the lifetime of the application, move the items to the R/W static data section, if there is sufficient space. For more information on how to use static data, see Using the Static Data Block.
  • For small data items that exist for the scope of a function, allocate memory from the stack.
