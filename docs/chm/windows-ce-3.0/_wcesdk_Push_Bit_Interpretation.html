Push Bit Interpretation

Important:

By default, Windows CE TCP/IP calls the recv function when one of the following conditions is met:

  • Data arrives with the PUSH bit set.
  • The user recv buffer is full.
  • 0.5 seconds have elapsed since any data has arrived.

If a client application is run on a computer with a TCP/IP implementation that does not set the push bit on send operations, response delays may result. It is best to correct this on the client; however, a configuration parameter, IgnorePushBitOnReceives, was added to Afd.sys in Windows NT 4.0 and Windows 2000 to force it to treat all arriving packets as though the push bit were set. Windows CE 3.0 does not support IgnorePushBitOnReceives.
