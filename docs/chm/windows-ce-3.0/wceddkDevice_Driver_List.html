This appendix lists the device drivers that are present in the Windows CE Platform Builder 3.0 and what platforms the sample source code supports. "CEPC" is the PC hardware based Windows CE reference platform. "D9000" is the Hitachi D9000 Windows CE reference platform, also known as "ODO".
