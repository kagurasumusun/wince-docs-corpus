The Online Help Guide discusses the Help engine, how the Help engine works, and how you can use the capabilities of the Help engine in your applications.

An engine is a section of an application that determines how that application manages and manipulates a type of data. From a developmental standpoint, an engine can also be application or module with an open application programming interface (API) to which your application passes data in order to accesses the engine's processing capabilities.

An engine can be another application, such as the Microsoft Help for Windows CE system. Applications pass Help files to the Help system, and Help for Windows CE displays those files.

The Online Help Guide includes sections that show how to:

  • Create the Help file.
  • Add content to a Help file.
  • Test a Help file.
  • Add Help to an application.
