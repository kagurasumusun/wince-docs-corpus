Common Dialog Boxes

Common dialog boxes are system-defined dialog boxes that standardize how users perform common, complex operations. Windows CE supports the Color, Open, Save As, and Print common dialog boxes. To support the Color and Print common dialog boxes, include the Commdlg component in your Cesysgen.bat file. To support the Open and Save As common dialog boxes, include the Fileopen component of the Coredll module in your Cesysgen.bat file.

The following table shows each of the common dialog boxes that Windows CE supports.

Common dialog box Description
Color Enables users to select a color from a set of custom colors or from a set of basic colors as determined by the display driver
Open Enables users to select a file to open
Save As Enables users to save a file under another file name
Print Enables users to select printer options

Refer to the Cesysgen.bat file in the Maxall and Minshell configurations for examples of ways to add support for common dialog boxes to a shell.
