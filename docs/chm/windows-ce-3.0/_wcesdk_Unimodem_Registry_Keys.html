The following section specifies all of the modem-related registry keys and values for PC Card and non-PC Card modems.

To enable multiple TSPs, the registry values for a particular device that are specific to a service provider are located in a subkey of the device. When a new device driver is loaded, the device manager looks for a subkey that contains a "TSP" value, and then notifies TAPI. TAPI then loads the service provider and passes a pointer to its specific values.
