Ignoring a Spelling Error or Moving to the Next Word

There might be times in which you want to skip an error without correcting it. For example, a user might type his or her name and choose not to add it to one of the dictionaries. Because the name might not appear in any defined dictionary, it will show up as a spelling error. Therefore, you must instruct the spelling checker to skip over a word. You should use the same technique to move to the next misspelled word in the input buffer.

To ignore a spelling error or to move to the next word

  1. To continue with a spelling check:
    • If you are skipping a misspelled word, set the dwMode parameter of the SPLBUFFER structure to SPL_IS_CONTINUED.

      SPL_IS_CONTINUED instructs the spelling checker to ignore the spelling error.

    • If you are continuing with the spelling check after correcting a misspelled word, set the dwMode parameter to SPL_IS_EDITED_CHANGE.
  2. Call the SplCheck function.

    The SplCheck function will replace the value that is contained in the iwcIn parameter with the value that is contained in the iwcErr parameter, plus the value that is contained in the cwcEIrr parameter. SplCheck continues the spelling check immediately after the misspelled word.
