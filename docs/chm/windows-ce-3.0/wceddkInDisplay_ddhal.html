InDisplay

This function returns whether the scanline is in display. The default implementation returns 0. Your driver is supposed to override this function by polling the hardware register(s).

virtual int InDisplay (void );

Parameters

None

Return Values

0 indicates that the scanline is not in display. 1 indicates otherwise.
