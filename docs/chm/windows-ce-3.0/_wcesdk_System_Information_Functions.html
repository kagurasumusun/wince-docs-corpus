The following table shows the RAPI system information functions. Most will be familiar to those of you working with Windows CE APIs, with the possible exception of CeCheckPassword and CeGetDesktopDeviceCaps. The CeCheckPassword function compares a string to the current system password. If the strings match, the function returns TRUE. Note that the comparison is case-specific. The CeGetDesktopDeviceCaps function is identical to the Windows CE counterpart, which is GetDeviceCaps.
