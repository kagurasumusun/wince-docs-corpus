In the International Organization for Standardization Open Systems Interconnection (ISO/OSI) model for network communication, serial communications operates between the physical layer and the application layer. The RS–232–C standard describes the physical layer. Serial device drivers are stored in the next layer, the data-link layer. The Windows CE serial communications functions enable applications to exchange data by way of serial hardware.
