Using the Local Heap

Important:

A heap is a region of reserved virtual memory space that Windows CE manages for your application. The original heap is called the local heap. Unlike with the VirtualAlloc function, you can allocate memory on a heap in 4-byte or 8-byte units, depending on your CPU type. In addition to being more efficient for small sizes, the heap can be used to avoid having to deal with the different sizes of memory pages that different microprocessors support. The heap also has no set limits. However, any heap allocations greater than 192 KB are fulfilled with a call to VirtualAlloc. If you attempt to allocate more memory than Windows CE originally set aside for a heap, the system attempts to find unreserved memory. Like virtual memory mapping, this memory might not be physically located next to the original heap. Also, because Windows CE allocates memory in fixed blocks, the heap might become fragmented over time.

Windows CE supports the same API set for heaps as Windows NT or Windows 98. The only noticeable difference is a lack of support for the HEAP_GENERATE_ EXCEPTIONS flag. Under Windows NT, this flag causes the system to generate an exception if an allocation request cannot be accommodated.

The heap management implemented in Windows CE differs from the way Windows NT manages heaps. Although the heap API set support in Windows CE resembles the standard Win32 heap API, Windows CE implements these APIs in a different way. For example, the HeapCreate function has parameters that allow a program to specify how much memory to allocate and reserve for a heap. Windows CE ignores these values.

Use the local heap when you need to allocate specific sizes of memory on a regular basis. Because Windows CE reclaims a memory page only if that page is totally free, ensure that you deallocate memory blocks correctly when you are using the heap. This becomes an issue with applications that run for a long time, such as applications that are designed for the Palm-size PC device category.

To allocate and deallocate memory by using the local heap

  1. Call the LocalAlloc function with the size of the memory block passed in the uBytes parameter.

    The LocalAlloc function returns a handle to the virtual memory block that is allocated to your application. At this time, Windows CE also maps the virtual memory block to a physical memory block.

  2. Use the memory that is allocated to your application.
  3. If necessary, call the LocalSize and LocalReAlloc functions to reallocate the local heap memory.

    If you need to increase the size of a block, call the LocalSize function to determine that the block contains enough space. Then, call the LocalReAlloc function either to add memory to the top of the allocation or to move the block to a larger area.

  4. Call the LocalFree function to return the memory to Windows CE.
Note   The HeapAlloc function also can allocate memory outside of the local heap by using the handle that is returned by the GetProcessHeap function.

The following code example shows how to allocate a set number of bytes from the local heap.

LPBYTE pbMyPointer = NULL;
HLOCAL hlHeapMemory = NULL;
HLOCAL hlHeapMem2 = NULL;
UINT uiSize;

hlHeapMemory = LocalAlloc (LPTR,    // FIXED and ZEROINIT
                           42);     // Number of bytes 

if (hlHeapMemory == NULL)
{
  // Your error-handling code goes here. You can use
  // the GetLastError function to obtain more information.
}

// The return value is actually the address of the memory.
pbMyPointer = (LPBYTE)hlHeapMemory;

// Your code to use the memory goes here.
// SomeFunctionCall (pbMyPointer, and so on)
// . . .

The following code example shows how to check the size of a piece of the local heap by using the LocalSize function.

uiSize = LocalSize (hlHeapMemory);
if (uiSize == 0)
{
  // Your error-handling code goes here. You can use
  // the GetLastError function to obtain more information.
}

The following code example shows how to change the size of a piece of the local heap by using the LocalReAlloc function.

hlHeapMem2 = LocalReAlloc (hlHeapMemory,  // Existing handle
                           100,           // New size, in bytes
                           0);            // Options (none)

if (hlHeapMem2 == NULL)
{
  // Your error-handling code goes here. You can use
  // the GetLastError function to obtain more information.
}

// The return value is actually the address of the memory.
pbMyPointer = (LPBYTE)hlHeapMem2;

The following code example shows how to free memory from the local heap.

hlHeapMem2 = LocalFree (hlHeapMem2);

// The pointer that is returned should be NULL.
if (hlHeapMem2 != NULL)
{
  // Your error-handling code goes here. You can use
  // the GetLastError function to obtain more information.
}
