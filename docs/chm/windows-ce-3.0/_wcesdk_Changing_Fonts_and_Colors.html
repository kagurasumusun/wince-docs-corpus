Changing Fonts and Colors

Important:

Your application can use the custom draw service to change an item font. To change an item font, select the HFONT that you want into the device context that is specified by the hdc member of the NMCUSTOMDRAW structure that is associated with the notification message for that is specific for that item. Because the font that you select might have different metrics from the default font, be sure that you include the CDRF_NEWFONT bit in the return value in the message for the item for which you want to change the font.

The font that your application specifies is used to display that item when it is not selected. The custom draw service does not enable you to change the font attributes for selected items.
