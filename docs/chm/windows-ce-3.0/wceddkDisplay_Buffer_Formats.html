Display Buffer Formats

The Windows CE GDI supports displays with a wide variety of color depths and color models, ranging from 1-bit color to palettized color to true 32-bit red, green, and blue (RGB) color. Each format also supports several pixel orderings, depending on whether access to the display memory is by bytes, WORDs, or DWORDs.

For all display buffer formats, the order of pixels on the display is from left to right and from top to bottom. That is, pixel (0,0) appears at the upper-left corner of the display, and pixel (width–1, height–1) appears at the lower-right corner.
