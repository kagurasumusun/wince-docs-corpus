STORAGE_IDENTIFICATION

This structure provides identification information that can be used to create a globally unique storage ID. The STORAGE_IDENTIFICATION structure provides two separate values that can be combined to create a unique storage ID. This structure is used in conjunction with the IOCTL_DISK_GET_STORAGEID I/O control code.

typedef struct _STORAGE_IDENTIFICATION {
DWORD dwSize;
DWORD dwFlags;
DWORD dwManufactureIDOffset;
DWORD dwSerialNumOffset;
} STORAGE_IDENTIFICATION, *PSTORAGE_IDENTIFICATION;

Members   

dwSize
Size of the allocated structure plus memory for the IDs.
dwFlags
The flags parameter provides information about the Manufacturer ID and serial number.
Flag Meaning
MANUFACTURERID_INVALID The manufacturer's ID is not valid.
SERIALNUM_INVALID The serial number is not valid.
dwManufactureIDOffset
The manufacture ID is located at the end of the structure, dwManufactureIDOffset bytes from the beginning of the structure. If this value is set to 0 then there is no manufacture's ID provided.
dwSerialNumOffset
The serial number is located at the end of the structure, dwSerialNumOffset bytes from the beginning of the structure. If this value is set to 0 then there is no Serial number provided.

Remarks

To determine the required size of the buffer, allocate a buffer the size of the STORAGE_IDENTIFICATION structure. The buffer must be at least this size in order to for the dwSize parameter to be set to the required size. The serial number and module number are NULL terminated ASCII strings.
