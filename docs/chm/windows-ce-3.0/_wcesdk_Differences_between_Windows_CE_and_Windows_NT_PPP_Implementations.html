Differences between Windows CE and Windows NT PPP Implementations

The following exaplain the differences between Windows CE and Windows NT PPP implementations

  • The Windows CE implementation of PPP provides a subset of features provided in the Windows NT implementation of PPP.
  • Unlike Windows NT, Windows CE does not support multilink PPP.
  • Windows CE does not support NetBEUI and IPX.
  • In Windows CE, PPP talks to the AsyncMAC miniport, and the AsyncMAC miniport performs MAC layer framing. In Windows NT, MAC layer framing is performed by the NDISWAN extension library.
  • Windows CE now supports the Microsoft Challenge Handshake Protocol version 2.0 (MS-CHAPv2), but the user interface (UI) does not let the user change the password if it has expired.
