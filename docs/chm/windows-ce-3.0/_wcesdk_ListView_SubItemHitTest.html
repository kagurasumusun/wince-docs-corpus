This macro determines which list view item or subitem is located at a specified position.

INT ListView_SubItemHitTest(
HWND hwndLV, 
LPLVHITTESTINFO pInfo );

Parameters

hwndLV
Handle to the list view control that will be hit-tested.
pInfo
Pointer to an LVHITTESTINFO structure. The POINT structure within LVHITTESTINFO must be set to the client coordinates to be hit-tested.

Return Values

Returns the index of the item or subitem tested, if any, or –1 otherwise. If an item or subitem is at the specified coordinates, the fields of the LVHITTESTINFO structure will be filled with the applicable hit information.

Remarks

Related message: LVM_SUBITEMHITTEST

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
