The OEM implements this function to provide FIQ (Fast Interrupt reQuest) support for the ARM microprocessor. 

void OEMInterruptHandlerFIQ (void);

Return Values

None.

Remarks

This function must be part of the OAL for any ARM build to succeed, even if it is just a stub. This function has a C-calling convention with a limited stack space of 256 bytes. If no FIQ's are generated by the hardware, then the function should remain empty. The FIQ is intended as a quick entry/exit interrupt. As such, there are a few limitations on this code:

  • OEMInterruptHandlerFIQ cannot return a value to the kernel to invoke an IST. However, it can perform urgent processing and generate an IRQ, which may then return a SYSINTR value. The SA1100 Odo OAL shows an example of this.
  • FIQs do not nest; FIQs may interrupt any IRQ interrupt handler.

    Nested interrupts can be achieved in OEMInterruptHandler by calling INTERRUPTS_ON.

  • FIQs are masked by INTERRUPTS_OFF.
  • An FIQ ISR may not alter any memory that is updated elsewhere with the interlocked functions. To maintain performance of the FIQ handling, interlocked restart is not enabled for FIQ.
