Host Name Resolution Using a NetBIOS Server

Important:

NetBIOS name resolution is the process of successfully mapping a NetBIOS name to an IP address. A NetBIOS name is a 16-byte address used to identify a NetBIOS resource on the network.

The NetBIOS name acts as a session layer application identifier. For example, the NetBIOS Session service operates over TCP port 139. All NetBIOS over TCP/IP session requests will be addressed to TCP destination port 139. To identify the NetBIOS application with which to establish a NetBIOS session, the NetBIOS name is used.

NetBIOS name resolution uses an algorithm similar to the algorithm described previously in "Host Name Resolution Using a DNS Server." The exact mechanism by which NetBIOS names are resolved to IP addresses depends on the node's configured NetBIOS Node Type. Windows CE only supports H-Mode. You cannot configure a Windows CE-based device to use a different mode. H-node uses a NetBIOS name server for both registration and resolution. Microsoft ships a NetBIOS name server known as the Windows Internet Name Service (WINS).

Note   Windows CE does not support a WINS server running on Windows CE at this time.
Windows NT-based computers are B-node by default and become H-node when configured for a WINS server. Most Windows NT and Windows 95/98 WINS clients are set up as H-nodes; that is, they first attempt to register and resolve names using WINS, and if that fails, they try local subnet broadcasts. It is possible to configure Windows NT and Windows 95/98 to a specific node. For more information on NetBIOS node types, see the Windows NT documentation on TCP/IP and NetBIOS.

For Windows NT and Windows 95/98, name/ip address mappings are automatically added during the boot process. For Windows CE the redirector has to be manually started by a user to register the name with WINS.

Note   If MSMQ is part of your device configuration and you run an application that uses MSMQ, the name is automatically registered with WINS.

An OEM who requires the name of the device to be registered with WINS should use the following programming tip:

  1. Set the host name by calling sethostname.
  2. Use the IP Helper API to wait for address change notifications that indicate that new interfaces are available.
  3. Add the host name on the network by invoking the redirector — for example, by calling the CreateFile function on a nonexistent universal naming convention (UNC) path — to register the host name on the available interface.
