Manually Configuring an IP Address

You can configure the address of a Window CE device manually by assigning the appropriate values in the registry for the IP address, subnetmask, default gateway, and DNS and WINS servers.

Note   If you plan to statically configure your adapter with an IP address, you need to be sure that you set the EnableDHCP registry key to 0. This setting is the default setting for Windows CE.

When you select an IP address for the devices on your network, be sure that each address is unique, and that the addresses are in appropriate subnets. If you do not have an address assigned to you, contact your network administrator.

Note   To update the registry, you can use a Registry Editor program, or you can use the IP Helper APIs to add IP addresses programmatically. For more information on using IP Helper, see Internet Protocol Helper APIs.

Static IP address settings are stored under the IPAddress, DefaultGateway, SubnetMask, DNS, and WINS registry keys.

Note   If you plan to statically configure the device, you need to configure all of these registry keys to enable the system to function correctly.
