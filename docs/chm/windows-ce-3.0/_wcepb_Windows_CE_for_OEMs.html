Platform Builder enables you to create an operating system (OS) that is tailored to the requirements and capabilities of a specific target device. For example, you can change portions of the user interface (UI), or change the file system to be compatible with the hardware.

This topic describes ways to modify Windows CE features and components to create a customized OS for a target device. The following list shows the OS features and functions you can modify:

  • Kernel features such as thread priority and interrupt handling, or more extensive customization, such as real-time performance tuning
  • User interface (UI) features such as fonts and message boxes, as well as specific UIs, such as the UI for the Startup Dialog or notifications
  • The sample shell
  • The file system
  • The TrueFFS driver
  • Security
  • Power management
  • Distributed COM (DCOM) support
  • Network user interface support
