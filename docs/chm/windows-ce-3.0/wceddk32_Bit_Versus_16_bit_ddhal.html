Microsoft Windows CE 3.0  

32-Bit Versus 16-bit

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

Windows CE is a purely 32-bit environment. This means that its DirectDraw implementation is not compatible with the 16-bit mechanism offered by the Desktop DDHAL model. Any callbacks you have implemented in 16 bits must be converted to 32 bits when moving to the Windows CE DirectDraw HAL implementation.
