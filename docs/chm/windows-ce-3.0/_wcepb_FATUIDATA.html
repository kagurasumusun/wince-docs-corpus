FATUIDATA

This structure retains all information necessary for the processing of a file allocation table (FAT) file system disk event.

struct _FATUIDATA { 
DWORD dwSize; 
DWORD dwFlags; 
DWORD idsEvent; 
DWORD idsEventCaption; 
DWORD cuiParams; 
UIPARAM auiParams[4]; };
typedef struct _FATUIDATA FATUIDATA, *PFATUIDATA;

Members

dwSize
Set to the size of the FATUIDATA structure.
dwFlags
Event response flags. For a list of possible flags, see FATUIEvent.
idsEvent
Identifier of a scan, format, or other disk event. Can be zero or one of the following:
  • IDS_FATUI_COMPRESSED_WARNING
  • IDS_FATUI_UNCERTAIN_WARNING
  • IDS_FATUI_UNSUPPORTED_WARNING
  • IDS_FATUI_FORMATSTART_WARNING
  • IDS_FATUI_FORMATDONE_WARNING
  • IDS_FATUI_FORMATERROR_WARNING
  • IDS_FATUI_DIRTYVOL_WARNING
  • IDS_FATUI_RETRY_WARNING
  • IDS_FATUI_WRITEVERIFY_WARNING
  • IDS_FATUI_SCANSTART_WARNING
  • IDS_FATUI_SCANDONE_WARNING
  • IDS_FATUI_SCANERR_UNKNOWN
  • IDS_FATUI_SCANERR_DIR_BADDATA
  • IDS_FATUI_SCANERR_DIR_BADCLUS
  • IDS_FATUI_SCANERR_DIR_BADSIZE
  • IDS_FATUI_SCANERR_FAT_BADINDEX
  • IDS_FATUI_SCANERR_FAT_CROSSLINK
  • IDS_FATUI_SCANERR_FAT_WASTED
idsEventCaption
String resource identifier of the event caption. May be one of the following:
  • IDS_FATUI_WARNING
  • IDS_FATUI_ERROR
cuiParams
Count of elements in the UIPARAM array.
auiParams[4]
An array of UIPARAM structures, zero or more. At present, this is set to four elements, but the number may increase in future versions.

Remarks

Use FormatMessage to properly format event messages.

The idsEvent identifiers are defined as follows:

IDS_FATUI_COMPRESSED_WARNING
Text displayed: "The %1!s! folder contains a %2!s! compressed volume file named %3!s!. The system cannot access files inside compressed volumes. If you do not need the compressed volume, select the file in the %1!s! folder and delete it."

The first three elements of the auiParam array are set to the following:

  1. The registered name of the volume.
  2. IDS_FATUI_HIDDEN_STRING or –1.
  3. The full path name of the compressed volume file.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_UNCERTAIN_WARNING
Text displayed: "An error occurred while reading the %1!s! folder. If you are unable to use this storage card, try reinserting it, or try a different card."

The first element of the auiParam array is set to the registered name of the volume.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_UNSUPPORTED_WARNING
Text displayed: "The %1!s! folder contains data in an unsupported format. The system cannot access any information currently stored on the storage card."

This message can occur if memory is unavailable to complete the operation, the volume format is unsupported, or the volume is corrupt.

The first element of the auiParam array is set to the registered name of the volume.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_FORMATSTART_WARNING
Text displayed: "Would you like the system to format the %1!s! folder so that the system can use it? WARNING: If you select Yes, any files in the %1!s! folder will be erased!"

The first element of the auiParam array is set to the registered name of the volume.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    To proceed with formatting

  • FATUI_NO

    To leave the media unchanged, albeit unusable

  • FATUI_NONE

    Same as FATUI_NO

IDS_FATUI_FORMATDONE_WARNING
Text displayed: "The %1!s! folder has been successfully formatted. It contains approximately %2!d!Mb of usable space."

The first two elements of the auiParam array are set to the following:

  1. The registered name of the volume.
  2. The number of megabytes of usable space on the media.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_FORMATERROR_WARNING
Text displayed: "An error occurred while formatting the %1!s! folder (error code %2!d!)."

The first two elements of the auiParam array are set to the following:

  1. The registered name of the volume.
  2. The Win32 error code from the format operation.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_DIRTYVOL_WARNING
Text displayed: "The system has not finished updating the files in the %1!s! folder. Please reinsert the storage card now. WARNING: Failure to do so may result in lost data on the storage card."

The first element of the auiParam array is set to the registered name of the volume.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_RETRY_WARNING
Text displayed: "The system encountered a storage card error (error code %1!d!). If a storage card was removed, please reinsert it, and then select Yes to retry or No to fail. WARNING: Failing this error may result in lost data."

The first element of the auiParam array is set to the error code from the last operation.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    To proceed with formatting

  • FATUI_NO

    To leave the media unchanged, albeit unusable

  • FATUI_NONE

    Same as FATUI_NO

IDS_FATUI_WRITEVERIFY_WARNING
Text displayed: "There was an error verifying a write operation to sector %1!d!. The storage card may be faulty or unsupported (error code: %2!d!). Do you want to ignore this error?"

The first time a write operation is performed after the FAT file system driver is loaded, the FAT file system driver performs a single write test. If an error occurs, the error is reported.

The first two elements of the auiParam array are set to the following:

  1. The first sector number of the last write operation.
  2. The error code from the write operation.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_SCANSTART_WARNING
No text displayed.

The FAT file system has begun scanning a disk.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_SCANDONE_WARNING
No text displayed.

The FAT file system has completed scanning the disk.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_SCANERR_UNKNOWN
Text displayed: "This storage card may contain errors. You should insert the card in a Windows desktop or laptop system and run SCANDISK to confirm and repair any problems."

This error occurs when memory is insufficient to complete the required scan operation.

The minimum set of allowed responses from FATUIEvent includes FATUI_NONE.

IDS_FATUI_SCANERR_DIR_BADDATA
Text displayed: "The directory entry for '%2!s!' is not valid. %1!s!"

This error occurs when either the directory has garbage characters in its name or there are random garbage clusters.

The first three elements of the auiParam array are set to the following:

  1. A string identifier

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The name of the file.
  3. The full path of the directory containing the file.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; repair the entry.

  • FATUI_NO

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; leave the entry unchanged.

  • FATUI_DELETE

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; delete the entry.

  • FATUI_CANCEL

    No action taken; entire scan operation is aborted.

  • FATUI_NONE

    No action taken.

IDS_FATUI_SCANERR_DIR_BADCLUS
Text displayed: "The directory entry for '%2!s!' contains an invalid cluster number. %1!s!"

The first three elements of the auiParam array are set to the following:

  1. A string identifier.

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The name of the file.
  3. The full path of the directory containing the file.

The minimum set of allowed responses from FATUIEvent includes one or more of the following:

  • FATUI_YES

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; repair the entry.

  • FATUI_NO

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; leave the entry unchanged.

  • FATUI_DELETE

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; delete the entry.

  • FATUI_CANCEL

    No action taken; entire scan operation is aborted.

  • FATUI_NONE

    No action taken.

IDS_FATUI_SCANERR_DIR_BADSIZE
Text displayed: "The directory entry for '%2!s!' specifies an incorrect file size. %1!s!"

The first three elements of the auiParam array are set to the following:

  1. A string identifier.

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The name of the file.
  3. The full path of the directory containing the file.

The minimum set of allowed responses from FATUIEvent includes one or more of the following:

  • FATUI_YES

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; repair the entry.

  • FATUI_NO

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; leave the entry unchanged.

  • FATUI_DELETE

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; delete the entry.

  • FATUI_CANCEL

    No action taken; entire scan operation is aborted.

  • FATUI_NONE

    No action taken.

IDS_FATUI_SCANERR_FAT_BADINDEX
Text displayed: "The cluster chain for '%2!s!' contains an invalid cluster number. %1!s!"

The first three elements of the auiParam array are set to the following:

  1. A string identifier.

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The name of the file.
  3. The full path of the directory containing the file.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; repair the entry.

  • FATUI_NO

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; leave the entry unchanged.

  • FATUI_DELETE

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; delete the entry.

  • FATUI_CANCEL

    No action taken; entire scan operation is aborted.

  • FATUI_NONE

IDS_FATUI_SCANERR_FAT_CROSSLINK
Text displayed: "The cluster chain for '%2!s!' refers to a cluster that is being used by another file. %1!s!"

The first three elements of the auiParam array are set to the following:

  1. A string identifier.

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The name of the file.
  3. The full path of the directory containing the file.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; repair the entry.

  • FATUI_NO

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; leave the entry unchanged.

  • FATUI_DELETE

    Only if the string identifier is IDS_FATUI_SCANERR_REPAIR; delete the entry.

  • FATUI_CANCEL

  • FATUI_NONE

IDS_FATUI_SCANERR_FAT_WASTED
Text displayed: "There are %2!d! lost clusters in %3!d! chains. They will be saved in one or more FILEnnnn.CHK files in the %4!s! folder. %1!s!"

The four elements of the auiParam array are set to one of the following:

  1. A string identifier.

    For example, IDS_FATUI_SCANERR_REPAIR or IDS_FATUI_SCANERR_ADVISE.

  2. The number of lost clusters.
  3. The number of lost cluster chains.
  4. The registered name of the volume.

The minimum set of allowed responses from FATUIEvent includes one of the following:

  • FATUI_YES

    Only if IDS_FATUI_SCANERR_REPAIR; reclaim all lost clusters as files.

  • FATUI_NO

    Only if IDS_FATUI_SCANERR_REPAIR; leave all lost clusters unreclaimed.

  • FATUI_DELETE

    Only if IDS_FATUI_SCANERR_REPAIR; free all lost clusters.

  • FATUI_CANCEL

    No action taken; entire scan operation is aborted.

  • FATUI_NONE

    No action taken.
