SNMP Structures

The following table shows the SNMP structures that are supported by Windows CE.

Structure Description
AsnAny Contains an SNMP variable type and value. This structure is a member of the SnmpVarBind structure that is used as a parameter in many of the SNMP functions.
AsnCounter64 Contains a 64-bit unsigned integer value and represents a 64-bit counter. This structure is used by multiple SNMP functions.
AsnObjectIdentifier Represents OIDs. This structure is used by multiple SNMP functions.
AsnOctetString Contains octet quantities, usually bytes. This structure is used by multiple SNMP functions.
SnmpVarBind Represents an SNMP variable binding.
SnmpVarBindList Represents a list of SNMP variable bindings.
