The coreimm component supports the Input Method Manager (IMM). The IMM handles communication between input method editors and applications.

Functions for Application Developers

The coreimm component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the coreimm.lib file.
