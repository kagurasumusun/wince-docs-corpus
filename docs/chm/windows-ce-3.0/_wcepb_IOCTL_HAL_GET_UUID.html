IOCTL_HAL_GET_UUID

This input/output control returns the universally unique identifier (UUID), which is also known as a globally unique identifier (GUID). The UUID is a 16-byte integer that is represented as a string and is guaranteed to be unique. Each Windows-based Terminal (Windows Thin Client) must have a UUID in order to be licensed with a Windows Terminal Server.

Parameters

dwIoControlCode
[in] Set to IOCTL_HAL_GET_UUID to retrieve a UUID based upon an OEM-defined device hardware identifier. The OEM must implement the section of code in the OEM Adaptation Layer (OAL) to handle the call to the KernelIoControl function.
lpInBuf
[in] Set to NULL.
nInBufSize
[in] Set to zero.
lpOutBuf
[in] Set to the address of an allocated UUID structure.

[out] A filled UUID structure.

nOutBufSize
[in] Set to the size of the UUID structure.
lpBytesReturned
[in] Address of a DWORD that receives the size in bytes of the data returned.

[out] Set to the number of bytes written to the supplied buffer.

Return Values

If the function succeeds, the return value is a nonzero value (TRUE). If the function fails, the return value is zero (FALSE). If support is not provided for IOCTL_HAL_GET_UUID within the OEMIoControl function or if the request fails, FALSE is returned.
