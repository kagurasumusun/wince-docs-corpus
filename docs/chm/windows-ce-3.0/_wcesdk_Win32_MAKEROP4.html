MAKEROP4

This macro creates a quaternary raster operation (ROP) code for use by the MaskBlt function. The macro takes two ternary ROP codes as input, one for the foreground and one for the background, and packs their Boolean operation indexes into the high-order word of a 32-bit value. MAKEROP4 ignores the low-order word.

DWORD MAKEROP4(
DWORD fore, 
DWORD back
);

Parameters

fore
Specifies a foreground ternary raster operation code.
back
Specifies a background ternary raster operation code

Return Values

The return value is a DWORD quaternary raster operation code for use with the MaskBlt function.

Remarks

The MAKEROP4 macro is defined as follows. 

#define MAKEROP4(fore,back) 
          (DWORD)((((back) << 8) & 0xFF000000) | (fore))
