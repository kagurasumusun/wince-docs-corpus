WRITE_PORT_BUFFER_USHORT

This macro writes a number of USHORT values from a buffer to the specified port address.

VOID WRITE_PORT_BUFFER_ULONG (
PULONG Port, 
PULONG Buffer, 
ULONG Count )

Parameters

Port
[in] Pointer to the port, which must be a mapped memory range in I/O space.
Buffer
[in] [out] Pointer to a buffer from which an array of USHORT values is to be written.
Count
[in] Specifies the number of USHORT values to be written to the port.

Return Values

None.

Remarks

The size of the buffer must be large enough to contain at least the specified number of USHORT values.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
