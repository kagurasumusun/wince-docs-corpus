PDCardReadAttrByte

This function reads the byte at the specified offset in a card's attribute memory space.

UINT8 PDCardReadAttrByte(
PVOID pCardMem, 
UINT32 uOffset );

Parameters

pCardMem
Pointer to PC Card attribute memory obtained from the CardMapMemory function.
uOffset
Integer setting the offset into the card's attribute memory.

Return Values

Returns the byte read.

Remarks

This function is called within a try-except statement in case the card is removed and the memory access results in a fault.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later
