Deleting a Database Volume

Important:
This is retired content. This content is outdated and is no longer being maintained. It is provided as a courtesy for individuals who are still using these technologies. This content may contain URLs that were valid when originally published, but now link to sites or pages that no longer exist.

To delete a database volume, first unmount the volume by calling the CeUnmountDBVol function. See Mounting and Unmounting a Database Volume. Then, call the DeleteFile function with a pointer to the volume name.
