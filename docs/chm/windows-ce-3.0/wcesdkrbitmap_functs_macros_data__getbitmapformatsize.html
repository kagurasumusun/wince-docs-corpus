Finds the size (in bytes) needed to build a VIDEOINFOHEADER structure and related data. 

LONG GetBitmapFormatSize(
const BITMAPINFOHEADER *pHeader);

Parameters

pHeader
Pointer to a Win32 BITMAPINFOHEADER structure.

Return Values

Returns the number of bytes for the VIDEOINFOHEADERstructure described by this BITMAPINFOHEADER, including prefix information, the BITMAPINFOHEADER field, and any other color information on the end.
