This structure is used as a flexible means of uniquely identifying a certificate.

typedef struct _CERT_ID {
DWORD dwIdChoice;
  union {
CERT_ISSUER_SERIAL_NUMBER IssuerSerialNumber;
CRYPT_HASH_BLOB KeyId;
CRYPT_HASH_BLOB HashId;
  };
} CERT_ID,  *PCERT_ID;

Members

dwIdChoice
DWORD indicating which member of the union is being used. The following table shows possible values.
Value Union member used
CERT_ID_ISSUER_SERIAL_NUMBER IssuerSerialNumber
CERT_ID_KEY_IDENTIFIER KeyId
CERT_ID_SHA1_HASH HashId
IssuerSerialNumber
The CERT_ISSUER_SERIAL_NUMBER structure that uniquely identifies a certificate.
KeyId
The CRYPT_HASH_BLOB structure containing a certificate key identifier.
HashId
The CRYPT_HASH_BLOB structure containing an SHA1 hash of the certificate to be used as a unique identifier of the certificate.
