Microsoft® Announces Windows® CE 2.0 for the Handheld PC
Microsoft Windows CE 2.0 for the Handheld PC is the best desktop PC companion for the mobile professional. The new H/PC includes many advanced features, including enterprise-wide connectivity, richer synchronization options, and new and improved “pocket” applications such as Pocket PowerPoint, Pocket Outlook, and a frames-capable version of Pocket Internet Explorer that integrates browsing your files with browsing the Web.

Microsoft Announces the Windows CE Embedded Toolkit for Visual C++ 5.0
On September 29, 1997, Microsoft announced Microsoft Windows CE Embedded Toolkit for Visual C++® 5.0, an add-in to Microsoft Visual C++ 5.0 designed to make it easy for OEMs and embedded developers to build new products for the Windows CE v2 operating system.

Microsoft Announces the Windows CE Toolkits for Visual Basic®, Visual C++, and Visual J++™
On September 29, 1997, Microsoft announced three new development tool products for the Microsoft Windows CE 2.0 operating system: The Microsoft Windows CE Toolkit for Visual Basic 5.0, the Microsoft Windows CE Toolkit for Visual C++ 5.0, and the Microsoft Windows CE Toolkit for Visual J++ 1.1. These Toolkits enable Win32 developers to apply their knowledge in Windows programming to building applications for Windows CE-based devices and create new business opportunities and solutions.
