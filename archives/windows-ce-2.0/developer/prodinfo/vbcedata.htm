Microsoft® Windows® CE Toolkit for Visual Basic® 5.0
Bringing the Ease of Visual Basic to Windows CE

Build dynamic Windows CE-based solutions from within the familiar Visual Basic development environment. Capitalize on your current Visual Basic expertise¾and hit the ground running.

The Microsoft Windows CE operating system is a 32-bit, multithreaded operating system for the handheld PC and other mobile and embedded devices. With its cross-processor support, plus industry backing for a number of future non-PC devices, Windows CE provides a wealth of development opportunities. And with the rapidly expanding market for this new platform, the need for quality Visual Basic-based applications and solutions continues to grow.

Capitalize on your Visual Basic expertise.

Apply your current knowledge of the Visual Basic programming model, environment, and language to building Windows CE-based solutions and applications. The Windows CE Toolkit for Visual Basic 5.0 is an add-in to the Visual Basic 5.0 product. The toolkit provides Windows CE versions of the most commonly used ActiveX™ Controls, as well as new ActiveX Controls that provide Windows CE-specific functionality.

Streamline development.

The Windows CE Toolkit for Visual Basic 5.0 puts a leading-edge emulator on your PC that gives you the look and function of a Windows CE-based device. Develop, test, and debug your programs on your desktop-no device is needed.

And when you can work directly with a Windows CE-based device, programs are transferred to the device automatically through a standard connection. You can also monitor and debug your applications remotely, right from your PC.

Plus, Windows CE cross-processor support means you can code your Windows CE-based solutions once, and then use them on a variety of processors.

New opportunities for Visual Basic developers. Now is the time to start developing solutions for the Windows CE platform. Support for Windows CE by many hardware manufacturers, plus the wide variety of non-PC devices currently entering the market, add up to countless new opportunities for developing Windows CE-based solutions.

The dynamic combination of the Windows CE Toolkit for Visual Basic 5.0 and your Visual Basic expertise can help you unlock this new market's potential-and put you on the fast track to delivering world-class solutions for Windows CE.

Specifications
To run the Microsoft Windows CE Toolkit for Visual Basic 5.0, you need:
· PC with a 486/66 MHz or higher processor; Pentium or higher processor recommended

· Microsoft Windows 95 operating system, Microsoft Windows NT® Workstation operating system version 4.0; Windows NT Workstation 4.0 is required for emulation

· Microsoft Visual Basic, Professional or Enterprise edition, version 5.0

· 24 MB of RAM; 32 MB recommended

· Hard-disk space required:

- Minimum installation: 30 MB

- Complete installation: 115 MB; 220 MB required if installing online documentation

· CD-ROM drive

· VGA or higher-resolution monitor; Super VGA recommended

· Microsoft Mouse or compatible pointing device
