The Power of Windows® Development comes to Embedded Systems

The Embedded Toolkit enables system adaptation by OEMs and development of ROM-based applications and drivers by third-party developers against componentized versions of the Windows CE operating system using reference hardware.

Complete Set of Tools for Building Embedded Applications
The Embedded Toolkit for Visual C++® includes a complete set of tools for building embedded applications targeting the Windows CE operating system and using Windows NT® as the host development environment.

Full Integration into Developer Studio Environment
The Windows CE Embedded Toolkit for Visual C++ 5.0 integrates with the award winning productivity and project management features of the Developer Studio development environment used by Visual C++. The Developer Studio environment consists of an integrated set of windows, tools, menus, toolbars, directories and other elements that allow developers to create, test, and refine their code all from one environment.
