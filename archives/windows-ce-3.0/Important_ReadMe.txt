You may need to "unblock" this CHM file for it to work correctly. 

Instructions for unblocking a CHM file:

After you download this ZIP file and extract the files (click "Extract All Files" or "Extract Files"), use these steps to unblock your CHM file.

1. Right-click the CHM file, and select "Properties".


2. On the "General" tab look for an "Unblock" button. If the file is not blocked, this button does not appear and you can close the window and go to step 4.
 
3. Click the "Unblock" button, and then click "OK" to close the dialog box.


4. Double-click the CHM file to open it.
