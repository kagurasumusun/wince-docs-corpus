What's New


Microsoft® Windows® CE .NET 4.2 with Microsoft Platform Builder 4.2 contains the following broad range of new and enhanced features:

  • Base configurations, including Digital Media Receiver, Enterprise Terminal, Gateway, and IP Phone
  • Improved Windows CE .NET Test Kit (CETK) features and a new Modular Stress Test for the CETK
  • Board support packages (BSPs) for two new boards: Samsung SMDK-2410 hardware platform based on the S3C2410X01 CPU (ARM920T core) and NEC Solution Gear2 (SG2) series platform based on MIPS CPUs
  • Four pre-qualified Bluetooth profiles: Dial-up Networking Profile, LAN Access Profile, Object Push Profile, and File Transfer Profile
  • New drivers and enhanced drivers, including Flash Media, Human Interface Device (HID), and Unified Keyboard
  • Internet Explorer for Windows CE with Internet Explorer 6.0 features, Multiple Language (MLANG) support, and more cascading style sheets (CSS)
  • Optional application programming interface (API) compatibility with the Microsoft Pocket PC 2002 shell
  • Voice over IP (VoIP) API
  • How-to Help topics, which provide you with step-by-step instructions on how to use the command line and the Platform Builder IDE to accomplish large-scale development tasks

Platform Builder 4.2 New Features

The following table shows the new features for Platform Builder 4.2.

Feature Description
Base configurations Base configurations serve as starting points for the creation of an operating system (OS) image. The new configurations in Platform Builder 4.2 include:
  • Digital Media Receiver, which provides functionality for a wide range of devices, for which media delivery is the key feature.
  • Enterprise Terminal, which can be configured in various ways to fit your needs.
  • Gateway, which provides connection-sharing services from a single Internet connection to a number of computers and other devices on an internal private network.
  • IP Phone, with which you can build a basic or advanced Internet Protocol (IP) Phone device. This configuration includes all the necessary networking infrastructure, a voice over IP (VoIP) middleware layer, and a user interface to build an advanced IP Phone with logging capability.
CETK context-sensitive Help A feature that displays Help for a selected CETK test. Information about the test appears when you right-click the test, and then choose Test Information.

Online Help for each CETK dialog box is now available.
Emulator features The Emulator contains the following new features:
  • Ability to run different versions of the Emulator side-by-side on a development workstation
  • Faster data transfer rate over the direct memory access (DMA) transport
  • Ability to map a directory to a Windows CE OS running in the Emulator window, which enables you to use the Emulator to test and develop an application that requires an additional drive or storage device
Improved CETK features The improved CETK features show both the CETK tests that the target device supports and the remaining tests that the CETK could run if the target device supported the hardware required by those tests. Categories of unsupported tests are identified by a red backslash (\) through the name of the category. Displaying unsupported tests provides a means to see all the tests that the CETK offers and a way to recognize when there is a problem detecting hardware that the target device is designed to support or a problem with the hardware or driver itself.

CETK support for headless devices is now also available.
Keyboard layout generator A tool that produces Windows CE input language and device layout source files from a Windows-based desktop platform keyboard layout DLL.
Modular Stress Test for the CETK A test consisting of a test harness and multiple test modules. The set of ready-to-use test modules are primarily designed to stress a Windows CE-based platform to assess the stability of the platform.
WCE Tux Dynamic-Link Library A new type of project for Platform Builder 4.2. This project provides the framework for a module that defines a test for the CETK. With this feature, you can add your own code to the framework and then build the project to create a custom test module. The Tux test harness for the CETK can then execute this module to add the functionality of the test to the CETK.


Windows CE .NET 4.2 OS New Features

The following table shows the new OS features for Windows CE .NET 4.2.

Feature Description
Additional wake-up sources Universal serial bus (USB) devices can now be configured as wake-up sources.
Alternate power management scheme for mobile devices A power management scheme consisting of a set of system power states customized for personal digital assistants (PDAs).
Binary ROM Image File System (BinFS) A file system that enables OEMs to store compressed and multi-XIP OS images on an external media, such as NOR or NAND flash memory, and then demand page the required modules for execution in RAM. With this file system, OEMs can make significant tradeoffs in choosing between NAND, NOR or RAM on their devices.
Bluetooth Profiles Profiles that conform to the Bluetooth Profiles Specification Version 1.1. With this feature, interoperability between qualified devices is guaranteed. The following four Bluetooth profiles were granted prequalified conformance status from the specification:
  • Dial-up Networking Profile. Defines the protocol and procedures for network access over Bluetooth through a dial-up modem session.
  • LAN Access Profile. Defines the protocol and procedures for network access over Bluetooth through a Point-to-Point Protocol (PPP) session.
  • Object Push Profile. Defines the protocol and procedures for providing the Inbox service using Object Exchange Protocol (OBEX) over Bluetooth.
  • File Transfer Profile. Defines the protocol and procedures for providing the file browser service using OBEX over Bluetooth.
Board support packages (BSPs) Prebuilt support for the following retail standard development boards (SDBs), which provide device driver and OEM adaptation layer (OAL) infrastructure to develop BSPs for custom hardware and SDBs by re-using existing driver code:
  • SMDK2410 Samsung MCU Development Kit for ARMV4 or ARMV4I microprocessors
  • NEC Solution Gear 2 Series Development Kit for MIPSII, MIPSII_FP, MIPSIV, or MIPSIV_FP microprocessors
Device management enhancement A service that contains a more reliable protocol.
Diffie-Hellman Cryptographic Service Provider A feature that supports hashing, generating Diffie-Hellman (D-H) keys, exchanging D-H keys, and exporting a D-H key.
Display driver enhancements The following list shows the new features, registry settings, functions, and I/O control codes (IOCTLs) available to display drivers:
  • Flexible Microsoft ClearType® implementation. To add ClearType support to a Graphics Primitive Engine (GPE)-based display driver, set SYSGEN_GPE_CLEARTYPE.
  • Gradient fill in a display driver, set SYSGEN_GRADFILL.
  • Gradient fill in a GPE-based display driver, set SYSGEN_GPE_GRADFILL.
  • GPE-based display driver without emulated block image transfer (blit) function, set SYSGEN_GPE_NOEMUL.
  • Raster font support, set SYSGEN_GDI_RASTERFONT.
  • RGB(16, 132, 208) registry setting for the COLOR_GRADIENTACTIVECAPTION system color table.
  • RBG(181, 181, 181) registry setting for the COLOR_GRADIENTINACTIVECAPTION system color table.
  • GradientFill to fill rectangle structures.
  • InvertRect inverts a rectangle in a window by performing a logical NOT operation on the color values for each pixel in the rectangle's interior.
  • EnumDisplaySettings retrieves information about one of the graphics modes for a display device. To retrieve information for all the graphics modes for a display device, make a series of calls to this function.
  • EnumDisplayDevices obtains information about the display devices in a system.
  • GetCharABCWidths retrieves the widths, in logical units, of consecutive characters in a specified range from the current TrueType font. This function succeeds only with TrueType fonts.
  • IOCTL_HAL_QUERY_DISPLAYSETTINGS provides information about the preferred display resolution for the system.
Enhanced Internet Explorer for Windows CE functionality Microsoft Internet Explorer 6.0 for Windows CE now includes the following features:
  • Internet Explorer 6.0 functionality. Includes .png file-format, image filter plug-in, and support for HTML Applications. HTML Applications are trusted applications that display on the menus, icons, toolbars, and title information that a Web developer creates. Because they are trusted applications, HTML Applications provide the functionality and power of Internet Explorer — its object model, performance, rendering power, and protocol support — without enforcing the strict security model and user interface (UI) of the browser.
  • Peghelp. The Windows CE Help viewer which was previously available only through Pocket Internet Explorer, is now supported by Internet Explorer.
  • The Multiple Language (MLANG) support. Further componentized to reduce the size of the system registry. OEMs can now choose the level of language support that suits their target device.
  • Full World Wide Web Consortium (W3C) Document Object Model (DOM) Level 1 support.
  • More cascading style sheets (CSS) features.
File Server A feature that enables clients to access files and other resources over a network.
Flash Media driver A driver that provides an infrastructure for OEMs and flash memory vendors to plug in support for various types of types of NOR and NAND flash memory and other media types.
Human Interface Device (HID) Client driver A componentized HID client driver that supports more USB mice and USB keyboards from various manufacturers than previous versions of the driver. This driver also supports consumer keys and power buttons.

Windows CE also implements a HID parser similar to the Windows-based desktop platform HID parser. The HID parser automatically recognizes the special keys on these peripherals.
Internationalization A collection of features that provide general locale services and locale-specific support. Internationalization now includes the following new and enhanced features:
  • All character list input method (IM). A new sample IM for Japanese that enables character input based on an all-inclusive character list.
  • Bushu-kensaku search engine. An IM for Japanese with which users can find a character based on its radicals. The UI can now be customized.
  • Character Auto Complete (CAC) IM. A sample IM for Japanese handwriting recognition that works with the handwriting recognition engine. This IM provides a list of likely characters that are updated as the user enters the character strokes.
  • Fonts. The East Asian font files now includes the following new fonts:
    • MSMincho.ttc, which is a font for Japanese that is targeted for printing.
    • Simsun_2_20.ttf, which is a font for Simplified Chinese that contains PRC Standard Body bitmaps.
  • Japanese Input Method Editor (IME) 3.0. A desktop-style IME that provides the following features:
    • Support for the property dialog boxes, dictionary tool dialog box, and system tray icon is now separated to enable OEMs to select a set of UI components.
    • Support for portrait and landscape orientation.
    • A dictionary compiler tool is provided to enable OEMs to create a custom dictionary for their device.
    • Sample skins with which OEMs can customize the IME toolbar, candidate window, and default composition window.
  • Korean IME. The Korean IME 97 now includes an optional vertical candidate list that enables OEMs to choose between a horizontal and a vertical candidate list. This feature also enables OEMs to hide the Status window.
  • Microsoft Kana IM. A soft keyboard IM for Japanese that is now provided as sample code.
  • Microsoft Roma IM. A soft keyboard IM for Japanese that is now provided as sample code.
  • Multilingual User Interface (MUI) Registry. A feature that enables one registry entry to point to several localized strings with an active value that is based on current locale settings. The localized strings are kept in a resource section of a module, either a .dll or .exe file.
  • Simplified Chinese Pocket IME. A small-sized IME for Simplified Chinese targeted towards embedded systems with and without keyboards that have small screens and a minimum memory footprint. OEMs can now display or hide the Status window. The IME hardware keyboard support has been enhanced.
  • Soukakusu-kensaku search engine. An IM for Japanese that enables users to find a character based on its strokes. The UI can now be customized.
  • Traditional Chinese IMs. The Chang Jei and Phonetic IMs are now available as sample code.
  • Traditional Chinese Pocket IME. A small-sized IME for Traditional Chinese targeted towards embedded systems with and without keyboards that have small screens and a minimum memory footprint. OEMs can now display or hide the Status window. The IME hardware keyboard support has been enhanced.
IP Firewall A service typically used on an Internet gateway device. The IP Firewall protects the device on which it runs and protects a device on the private side of the gateway. The IP firewall uses rules to determine whether to block, allow, or log inbound or outbound traffic at the IP and transport layers.
Kernel enhancements The kernel has been enhanced with the following new features:
  • The kernel was updated for ARM and x86 microprocessor architectures so that the OS's virtual memory structures match the CPU's hardware page tables. Any change to the virtual memory is now reflected directly on the hardware page tables. This update eliminates the need for the kernel to reload pages on every translation look-aside buffer (TLB) miss and leads to significant performance improvements on many types of OS operations, including Web browsing.
  • The current algorithm for compressing the OS modules in ROM was improved. This provides significant ROM size savings on OEM devices. This improvement applies only to OS modules. The compression engine used for the object store cannot be changed.
  • The kernel has been updated to call a new OEMCacheRangeFlush OAL function. This provides flexibility to OEMs to control the flushing of the TLB, instruction and data caches, and replace the flushing algorithms used by the OS. By writing highly tuned caching routines that match their device, OEMs can significantly improve the performance of their device.
  • Resource libraries can now be loaded into the second gigabyte (GB) of address space in shared memory to save process virtual memory space. This feature is very useful when using large resource files such as megabytes (MB) of localization and Unicode character mappings.
  • OEMs can now define a static pool of virtual memory that is used for read-only code and data. When the pool is filled, the memory is paged out using a first in, first out (FIFO) model. This reduces the amount of memory paging on devices that frequently experience low memory conditions.
Keyboard driver improvements Improved keyboard driver architecture. The Layout Manager enables driver developers to switch locales at run-time and supports multiple types of keyboards and input panels.
Layer 2 Tunneling Protocol (L2TP)/IP Security Protocol (IPSec) A protocol that enables a secure virtual private network (VPN) client connection from a Windows CE-based device to a corporate server. This feature includes support for public key certificates and preshared keys, encryption with data encryption standard (DES) and 3DES, and Internet Key Exchange (IKE), which supports authentication and key exchange using the D-H algorithm.
NAND boot loader A boot loader that can boot either typical or multi-region OS images from NAND flash memory.
Optional application programming interface (API) compatibility with the Microsoft Pocket PC 2002 shell A feature that enables most Pocket PC 2002-based applications to run on the Windows CE-based device after being recompiled for the OEM's Windows CE-based platform.
Pocket Internet Explorer browser A browser that will be available in Pocket PC 2003. This browser supports IPv6, multiple zoom levels, DOM, CSS Mobile Profile, and cookies.

Additional features include: event support for Microsoft ActiveX® controls and more Hypertext Markup Language (HTML) tags compliant to HTML 3.2 such as <CAPTION ALIGN=""> or <BASEFONT COLOR="">. With the HTML Control API application developers can create custom applications that can render HTML, including hyperlinks.
Print Server A feature that enables clients to access printers over a network.
Protected Extensible Authentication Protocol (PEAP) A protection mechanism for EAP communication between an EAP client and an EAP authenticator. The PEAP mechanism uses Transport Layer Security (TLS) to create an end-to-end, EAP client to EAP-authenticator, encrypted channel after verifying the identity of the authenticator. The EAP protocol packets are exchanged over this encrypted channel.
Real-Time Communications (RTC) Client API version 1.2 The RTC Client API has the following new functionalities:
  • Improved multiple service connection support
  • Session Initiation Protocol (SIP)-based user search behavior
  • Logical buddy groupings
  • Contact roaming behavior
  • Event handling of the SIP INFO request
  • Custom presence properties
  • Access control list-based contact access
Remote Desktop client user interface (UI) The Remote Desktop Protocol (RDP) client name has changed from Microsoft Terminal Services Client to Windows CE Terminal Services Client (MSTSC to CETSC). The source code for the UI is now public and can be modified if needed.
Smart Device Authentication Utility, SDAuthUtilDevice.exe A component to help facilitate Windows CE .NET development on Microsoft Visual Studio® .NET 2003. OEMs can add this component to an OS image that does not have the Microsoft ActiveSync® feature.
Simple Network Time Protocol (SNTP) A protocol that synchronizes the system time on a computer with that of a server that has been synchronized by a reference source, such as a radio, satellite receiver, or modem.
Tracert A new command-line tool that sends Internet Control Message Protocol (ICMP) v6 or ICMP Echo Request messages to produce command-line report information about each router that is crossed and the roundtrip time for each hop.
Transaction-Safe FAT (TFAT) file system A file system designed specifically to provide transaction safety for data stored on a disk. A TFAT file system guarantees that the file allocation table will remain intact if power loss occurs. In order to accomplish this, the data will either be completely written or completely not written per transaction.
Voice over IP (VoIP) API A new middleware layer that enables OEMs to quickly build IP telephony solutions. The API automates the following tasks:
  • Provisioning the IP phone
  • Registering the phone with a Session Initiation Protocol (SIP) server
  • Logging calls
An IP phone UI sample application that uses VoIP middleware is included.
Web Distributed Authoring and Versioning (WebDAV) A Web server standards-based file sharing mechanism built over Hypertext Transfer Protocol (HTTP). It enables remote users to browse, download, and upload files to the virtual roots on the Web server using a WebDAV client. With WebDAV, Microsoft Windows XP and Microsoft Windows Server can map a Windows CE virtual root to a network drive.
Wi-Fi Protected Access (WPA) An implementation based on a subset of the IEEE 802.11i standard. This framework, together with Temporal Key Integrity Protocol and the Message Integrity Check (MIC) algorithm Michael, provides security over an 802.11 authenticated wireless networks.
Microsoft Windows Media 9 Series codes Support for Windows Media 9 Series codes in Windows Media Player, including Windows Media Audio 9 Voice and Windows Media Video 9 Image.
Windows Internet API (WinInet) optimization WinInet has been optimized for performance and a smaller amount of required memory. Passport Single Sign In (SSI) 1.4 authentication is now a separate, optional component.
XML MIME-type viewer Internet Explorer now has the ability to display Extensible Markup Language (XML) files directory within the browser window. To add the Multipurpose Internet Mail Extensions (MIME) viewer to a project, set the SYSGEN_MSXML_MIMEVIEWER flag. This will also bring in the XML DOM and XML Stylesheet Language Transformations (XSLT) features.
